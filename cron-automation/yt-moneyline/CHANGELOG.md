# YT Moneyline 更新日誌

所有錢線百分百自動處理系統的重要變更都會記錄在此檔案。

本專案遵循 [Keep a Changelog](https://keepachangelog.com/zh-TW/1.0.0/) 格式規範。

---

## [1.0.0] - 2026-02-07

### Added
- ✅ 初始版本發布
- ✅ 自動抓取錢線百分百最新三集（上、中、下）
- ✅ 使用 whisper-cpp 轉換為中文逐字稿
- ✅ AI 分析產生結構化報告
- ✅ 產生每日整合摘要
- ✅ 支援 cron 自動化執行
- ✅ 完整的日誌記錄系統
- ✅ 錯誤處理與重試機制

### 檔案清單
- `execute.sh` - 主執行腳本
- `run.sh` - Cron 執行腳本（含日誌管理）
- `analyze_transcript.py` - AI 分析程式
- `README.md` - 完整說明文件
- `CHANGELOG.md` - 本更新日誌

### 功能特色
- 自動識別同一天的上中下三集
- 依序處理避免系統負載過高
- 支援跳過已處理的檔案（斷點續傳）
- 支援指定日期和集數處理
- 支援簡易分析模式（無 API Key）
- 完整的錯誤處理與使用者提示
