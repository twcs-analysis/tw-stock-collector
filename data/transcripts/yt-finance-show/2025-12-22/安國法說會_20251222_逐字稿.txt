[開場 - 財務長報告]

各位投資先進，安國國際科技股份有限公司法人說明會正式開始。

接下來我先把時間交給財務長。

謝謝。下午就很快跟大家報告一下，安國及安國的轉投資三家子公司，到目前 9 月底的財務狀況。

我想這個可能有很多投資先進，我們已經看過很多次了，就是安國大概旗下就是安國的預保、訓結這三家公司。

我們今年大概是從營收的狀況看起來，是每一季都在往上升，但是毛利率看起來好像逐漸在下降。那我想這主要的影響因素，主要來自安國。因為安國在 2025 是轉型，從 Design Service 的第一年，那初期剛開始跟客人收的錢，可能都是前期的一些費用比較多，相對可能毛利率的金額沒有那麼大。

所以整個合併的概念看起來，好像集團的毛利率是 40、30、20 這樣掉。但是我想除了安國以外，其他子公司的毛利率應該都是相當平穩的。

好，那這邊我就簡單地從我們的財務報表跟大家說明。我們到 Q3 的累計營收是 8.8 億，那我們的平均毛利率大概落在 28%。那剛剛有跟大家簡單地做了說明，集團的營業費用大概是在將近十億的狀況。

那營業外收益這邊有一筆其他收益，主要來自安國在年初的股份轉換所得到的利益。那整體的稅前淨利是在約當現金的部分。

那從下面看得出來，這主要來自於安國。安國因為今年是一個轉型的一年，那在從過去的 IP 授權轉型到後面的 Design Service，也在設立實際上的晶片設計服務。我們過去的來自很多 IP 授權，那在去年最大的就是來自 Andes（安第斯）的 IP 授權。那因為那個金額很大，所以每個月的攤銷數字大概都在 1,600 萬左右，所以在帳上看起來安國的虧損是比較大。

然後再來我們看一下我們的資產負債表。我們就是安國旗下三家轉投資公司加起來，約當現金剛才有合計。那預付款項這邊，大概主要是安國，因為安國對台積電要下單可能都有一些預付款項要先行支付。

然後再來我們的長期借款，可能在過去的投資人對我們來講也比較了解，我們是比較沒有借款的。但是因為主要的借款都是來自於安國，我們今年在產業模式上的轉換，所以需要的營運資金是比較多的，所以這個部分大部分都要去借款。

那再來就是合約負債，16 億。那這個代表什麼呢？就是安國，因為要跟我們的客戶，在他需要我們的服務或下產能的訂單時，他要先付給我們相當的一個預付款。那在財報上這個部分，我們就是認列為對客戶的一個負債，所以這主要都是來自於安國。

那我想剛剛是很簡單地向各位投資先進做的報告，那底下我就把時間交給我們總經理。

[總經理技術報告]

首先非常感謝各位投資先進，撥冗代表安國 2025 年的法說會，以及感謝大家持續關注安國的一個進展，也希望大家繼續支持。

那接著我會針對安國的一個主要的營業項目做說明。那目前安國在這邊主要的在平台上的優勢：

第一個是我們採用了 ARM 最高等級的 Neoverse V3 CPU。

那另外我們也在針對 AI 的加速器做整合，我們在 Chiplet 技術，以及我們看到未來其實在 SoC 上面越來越複雜，我們需要用到缺陣的技術。

最後其實在先進封裝的部分，目前在近期包含 2.5D，以及未來在 3D 設計邁進這樣子。

目前我們在 AI 加速的這一塊，除了主要 CPU 的設計以外，我們也有在 AI PC 的應用場景，以及我們在 AI 加速 LLM 推理加速，這都是我們目前在進行的主要項目。

這個是我們為什麼採用 ARM 的 CPU，它的好處其實是能夠提供高效的節能，及它最好的擴充性。那因為在 ARM 的伺服器目前遇到的一個主要在散熱的技術上面的問題，採用 ARM 其實可以解決這樣子的散熱的議題。

從這邊可以看到 ARM 在伺服器的領域，它的市占率其實是一直往上提升的。我們在安國在去年的 10 月，已經是 ARM 的 Total Design Partner，這個是 ARM 對安國的一個肯定。

這個是我們目前最新的 ARM Neoverse V3 的芯片，它主要的亮點在效能的 Performance 部分做最佳化。因為我們也提供一個 Power Switch 的方式，可以讓 CPU 在多核心的狀況下，可以針對某個核心去做開關，能夠讓我們的功耗管理更加有效率。

當然就是在整個擴充性的部分，我們利用 ARM Chiplet 的技術，能夠讓整個擴充能夠最佳化這樣子。

以及我們在強化了安全性，除了支持 ARM TrustZone 以及系統級的安全，我們也加入了 CPU 系統級的 Post-Quantum（後量子）加密技術，能夠讓整個安全性更能夠提升到更高階這樣子。

那以及在記憶體的部分，我們採用的是 DDR5-5200，以及在 PCIe 5.0，尤其在對於 HPC 系統、AI 以及雲端運算的需求，能夠符合我們目前的客戶能夠支持的整個擴充性的部分做最佳化。

那我們在安國的 Package 封裝技術，我們可以支持多晶片整合，就是 CPU 兩顆 CPU 連結在同一個 Package 裡面，能夠讓整個 CPU 的性能提升。

那另外在單一的 Package 的部分，我們可以支持 CPU 加上 AI 加速器，同時在一個 Package 裡面，達到 I/O 的整合。

另外除了在同一個 Package 以外，我們也支持了 MXAN（音譯）介面，可以在同一個 Package 裡面插上不同的板卡，達到擴充性。所以這個擴充除了 CPU 對 CPU 以外，我們也可以支持 CPU 對 AI 加速器，除了物理的整合以及 I/O 的整合都可以支持。

這個是我們目前在整個 UCIe 1.3 的介面規範。我們在今年 10 月也參加了 OCP，對於我們 8 核心的 Emulator 進行展示。目前芯片也在台積電已經進入到後端的階段。

這個是我們目前在 Package 的技術上面，除了我們需要針對 Advanced Substrate（先進基板）的設計，我們需要有高速的 IP，以及在材料的選擇上面，尤其在模擬分析，除了 Signal Integrity（訊號完整性）以及 Power Integrity（電源完整性），以及 Thermal（熱管理）的要求，這個是整個 Package 蠻重要的一環。

那我們目前除了 2.5D 的 CoWoS 專案在進行，我們也開始 3D Wafer-on-Wafer 這樣子的技術在邁進。

謝謝大家。

[Q&A 環節]

那另外就是我們已經收到在 Q&A 的部分，針對各位投資先進的提問，我們有做統整並回答。

【提問 1：營收成長的原因】

安國去年底完成「新和」的股權合併，合併所帶來的資產，讓安國今年在 Design Service 上有顯著成長。今年的營收也較去年有大幅的成長，主要來自我們持續進行的先進製程專案。

【提問 2：2026 年成長動能及展望】

我們著重於高效能運算、ARM CPU、AI 加速器，以及先進加密貨幣晶片，包含了 3nm、5nm 的指標性專案。隨著專案的進行，我們開始陸續認列營收，預期將為業績帶來顯著的成長動能。

【提問 3：3nm 晶片的進度】

安國今年 10 月參加了美國 2025 OCP 峰會，展示了 ARM 最新的 CSS V3 八核心模擬平台。這個 V3 CPU 我們預期在明年會投片台積電 3nm 製程。此晶片也兼顧效能、效率以及擴充性，符合 ARM Total Design 架構，能夠讓全球 AI、HPC 伺服器能夠提供更靈活且高效能的解決方案。
