## 🌍 市場總體觀察

### 台股市況分析

#### 大盤表現
- **收盤表現**: 小漲24點，由黑翻紅，收盤22,577點
- **成交量**: 約3,000億元（較前一日4,000億元明顯縮量）
- **盤面特色**: 開盤平淡，尾盤台積電爆出5,400萬張（約915張）買單，硬拉大盤10點翻紅
- **主要輪動**: IC設計、PCB、水資源、觀光旅遊族群表現較佳

#### 法人動向
- **外資**: 現貨買超70多億元，持續買入
- **外資期貨空單**: 今日增加2,429口，累積淨空單達54,946口（創歷史新高）
- **三手策略解讀**: 外資現貨買、期貨空、匯率避險 -- 屬於「避險式買超」而非真正看空

#### 新台幣匯率
- **盤中最低**: 28.95（再度觸及28字頭）
- **收盤**: 仍大幅升值1.6角
- **美元指數**: 昨日破底後出現下影線，今日出現紅黑棒（止跌訊號）
- **關鍵觀察**: 台幣第二季的強勢升值已是最嚴重階段，第三季若為緩升，企業仍可做匯避

### 國際市場與事件

#### 七月九日關稅大限
- **川普最新表態**: 不考慮延長7/9對等關稅緩衝期限
- **日本談判**: 川普稱日本「很強硬」，談判可能破裂，日本恐面臨30-35%關稅
- **印度進展**: 最快一週內可能達成協議，有望大幅降低關稅
- **台灣情勢**: 外媒傳台灣有機會在7/9前完成談判，最低門檻約10-15%

#### 大而美法案（Big Beautiful Bill）
- 參議院已通過，接下來將在眾議院投票
- 2026年赴美設廠投資優惠從25%提高至35%
- 台積電及供應鏈赴美盟友將受惠
- 對台灣半導體設備股、基礎建設概念股有利

#### 台經院景氣燈號
- 5月製造業景氣燈號從「黃藍燈」降為「藍燈」（衰退）
- 創下2024年3月以來新低
- 主因：台幣升值壓力導致出口訂單、生產物價、銷售指標全面縮小
- 電子電機大類仍表現不錯，傳產（焦拉、民生類）全面不佳

#### 成名電 (3570)

- **操作建議**: 等待出量站上壓力位才能轉向，否則維持區間操作
- **停損點**: 跌破三角形下緣

#### 勤誠 (8210)
- **題材**: 散熱族群龍頭，帶動整個散熱族群
- **基本面**: 6月營收為GB200出貨高峰，營收仍佳
- **操作建議**: 長線以月線為出場參考，短線以最大量區間低點為出場參考
- **停損點**: 長線跌破月線，短線跌破大量區間低點（約461元）

### 三、七月選股五大條件（子當老師）

1. **統計勝率**: 過去7月上漲次數超過10次，上漲機率至少70%以上
2. **高毛利率**: 產業前段班，即便台幣升值、關稅衝擊仍能獲利正成長
3. **第三季為產業旺季**: 或個股有特殊性利多
4. **股價位置偏右下角**: 尚未大幅上漲，具抗跌功能
5. **內外資不要有對做**: 避免出現暴力換股或外資大規模倒貨

### 四、七月精選四檔個股

#### 世芯-KY (3661)
- **統計勝率**: 過去11次7月上漲機率82%
- **題材**: ASIC概念股，亞馬遜主要合作廠商，Nvidia跨足車用/機器人
- **毛利率**: 23%（同業平均39%，因統包服務模式毛利率較低但深受客戶喜愛）
- **本益比**: 約38倍（IC雙雄過去合理本益比50倍以上，世芯仍具吸引力）
- **目標價**: 隨AI伺服器需求成長，有望挑戰前高
- **停損點**: 跌破月線

#### 懷華藥 (6446)
- **統計勝率**: 7月上漲機率偏高（新藥股7月為升級月）
- **題材**: 新藥股龍頭，毛利率88.9%（同業前三名），可望於明年申請切入中國市場
- **匯損影響**: 公司承認受台幣升值影響，但股價從右下角穩步向右上角發展
- **操作建議**: 右下角啟動，趨勢溫和向上
- **目標價**: 持續向上挑戰前高
- **停損點**: 跌破近期上升趨勢線

#### 台郡 (6269)
- **題材**: 蘋果摺疊手機軟板概念、Nvidia AI伺服器感測散熱，Computex展上宣布切入輝達AI伺服器
- **技術面**: 突破景（季）線，有機會上攻年線
- **操作建議**: 等拉回再買，WD底部一半位置為支撐
- **目標價**: 年線附近
- **停損點**: 跌破WD底部一半位置

#### 新漢 (8234)
- **題材**: 輝達供應鏈（自駕車+機器人），工業電腦，以色列機場開放後以色列訂單有望出貨
- **營收結構**: 歐洲市場為主（歐元也強勢，匯損影響較小）
- **操作建議**: 目前在右下角，穩步操作，年線半年線之間有區間利潤
- **目標價**: 年線附近
- **停損點**: 跌破近期低點支撐

## 💰 匯率分析（期戰老師）

### 台幣走勢
- **週K線分析**: 4月以來台幣持續升值（美元兌台幣從32以上降至28.99）
- **關鍵位置**: 28.95-29.3區間震盪
- **轉折觀察**: 若今晚ADP就業數據超過10萬人，美元有機會破底反彈

### 美元指數
- **當前位置**: 196.377（持續破底，創三年多新低）
- **技術面**: 高點持續遞低，月均線壓制，除非站上99.4-100才算轉折
- **政策面壓力**: 大而美法案若過關，財政赤字擴大2-3兆，美元承壓

### 匯率投資建議
- **歐元**: 洗盤告一段落後有機會往上，可做為台幣升值的對沖工具
- **日幣**: 美元兌日幣在139-149區間整理，低檔買入可行
- **日本旅遊**: 日幣匯率0.2左右，消費划算（特別是非大城市地區）
- **美元保單**: 台幣強勢下相對便宜，但短期不太會漲；不會再出現5月初那種急升壓力

## 📈 技術面分析與操作策略

### 大盤技術面
- **KD指標**: 高檔區域，有交叉向下風險
- **量能觀察**: 今日僅3,000億元，高檔無量不宜追高
- **短線策略**: KD指標在80以上時需有量有價才可追，否則只能低接或資金分批進場

### 個股操作原則
1. **高毛利族群優先**: PCB漲價潮、IC設計（ASIC概念）受關稅影響較小
2. **右下角個股**: 股價尚未大幅上漲者，抗跌能力較強
3. **均線糾結觀察**: 等待帶量突破才是真突破，否則維持區間操作

## 📋 投資策略總結

### 短線操作（7/9前）
- 持有高毛利、AI相關族群不須恐慌
- PCB族群有漲價潮支撐，關稅影響比例極小
- KD高檔注意量能配合，無量時不追高

### 中線布局（7月）
- 七月選股以高勝率、高毛利、旺季題材為核心
- 世芯(3661)、懷華藥(6446)、台郡(6269)、新漢(8234)四檔可留意
- 外資空單為避險性質，非看空，7/9後空單將大幅減少

### 匯率策略
- 台幣第三季仍有升值壓力但不會如Q2急劇
- 可買入歐元或日幣做為對沖
- 美元保單相對便宜但短期難以獲利

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **對等關稅** | 川普政府對各國實施的對等報復性關稅，7/9為緩衝期限 |
| **大而美法案** | Big Beautiful Bill，美國國會法案，涵蓋稅改、移民、基建等內容 |
| **三手策略** | 外資同時操作現貨（買）、期貨（空）、匯率（避險）的組合策略 |
| **KD指標** | 隨機指標，用於判斷股價超買超賣，80以上為超買區 |
| **券資比** | 融券餘額占融資餘額的比例，比例越高代表放空力道越大 |
| **ASIC** | 專用積體電路，為特定客戶設計的客製化晶片 |
| **景氣藍燈** | 台經院景氣燈號最低級別，代表景氣衰退 |
| **ADP就業數據** | 美國ADP私人就業報告，為非農就業數據的先行指標 |
