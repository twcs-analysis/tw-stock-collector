## 📊 市場總體觀察

### 聯電（2303）深度分析
- 外資買超第一名，買了 59,000 張
- 投信買超第一名，合計買了近 70,000 張
- 但股價開高走低，出現巨量長黑

#### 量能解讀
- 大量來源並非全是法人，還有大量「隔日沖」資金
- 現代交易環境允許先賣後買的當沖，造成成交量放大
- 股票實際換手可能不如表面成交量那麼大

#### 技術面判斷
- 短線在此區間震盪整理，等待方向
- 線形上屬於強勢：突破過去 50 元整理平台
- 趨勢已改變，單日長黑未改變趨勢
- 仍在 20 日均線之上，且過了前波高點

#### 殖利率支撐
- 過去平均殖利率約 4.8%
- 去年 EPS 約 2 元多，過去五年配發率約六成多
- 預估今年配息約 2 元出頭，殖利率仍有 4%+
- 價差不夠，股利來湊

### 三、面板族群 -- 題材大於基本面

#### 面板產業現況
- **漲價幅度有限**：電視面板漲 2-3%（vs. 記憶體漲 60-70%）
- **NB 面板被壓**：記憶體價格太貴，擠壓其他零組件
- 中國面板廠紅海廝殺已久，可能開始追求高毛利產品
- 若政府補貼減少，面板價格有機會翻漲

#### 群創 CES 展新技術
- 展出超級透明、高亮度 **Micro LED 面板**
- 可用於博物館展示、百貨公司櫥窗
- 結合 AI 可動態變化，為面板產業大型轉機

#### 面板隱藏版受惠股 -- 華宏（8240）

| 指標 | 內容 |
|------|------|
| 主要產品 | 光學膜（群創/友達供應夥伴）、車載防爆膜、機能材料 |
| 車載布局 | 已出貨給中國電動車廠 |

| FOPOP 題材 | 國產化熱解黏材料，用於晶片切割時固定與脫模 |

#### FOPOP 熱解黏材料說明
- 在晶片切割時，用膠將基板固定避免偏移
- 「熱解黏」= 加熱後黏性消失，一甩就脫落
- 國產化替代進口，為 FOPOP 製程必需品

## 📈 技術面分析與操作策略

### 低位階題材股操作心法
1. **題材面 > 基本面**：這類股票常常漲得沒有原因，故事說得精彩就夠
2. **辨識進場訊號**：出現扭轉力道的 K 線（帶量紅 K 或扭轉 K 棒）
3. **停損設定**：跌破當日開盤價或低點即出場
4. **選擇有延續力的題材**

### 大盤操作結論（葵國老師盤後）
- 「把握這波拉回，選好股做多」
- 34 天空方轉折 + 國安基金開會 + 爆量修正 → 震盪整理
- **長線沒有任何改變，多頭趨勢未變**
- 高基期股票 → 逢高賣
- 低基期股票 → 一定要提前卡位

## 📋 投資策略總結

### 短期（1-2 週）
- 1/9-1/12 為關鍵轉折（台積電營收 + 國安基金開會 + 空方轉折）
- 大盤偏向震盪修正，但不會做頭
- 聯電短線震盪整理，等待新方向
- 面板題材股跟緊群創指標

### 中期（1-3 個月）
- IC 設計為 2026 年重點機會：世芯、電源管理 IC（矽力、致新）
- Intel 概念股隨 18A 製程量產逐步發酵
- 軍工、航空為落後補漲候選
- 董事會行情（2-3 月）為高殖利率股操作黃金期

### 風險評估
- 面板股題材炒作為主，基本面漲價幅度有限，追高風險大
- 聯電巨量長黑後隔日沖資金消化需時間
- IC 設計族群去年表現極差，反轉需要催化劑
- 軍工股波動大，一天漲一天休息的特性需耐心

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| 18A 製程 | Intel 的 1.8 奈米製程節點，對標台積電 2 奈米 |
| Panther Lake | Intel 第三代 Core Ultra 處理器代號 |
| PowerVia | Intel 的背面供電技術，將供電線路移至晶片背面以提升效能 |
| ASIC | Application-Specific Integrated Circuit，特定應用積體電路，為客戶量身定做的晶片 |
| FOPOP | Fan-Out Panel Level Packaging，扇出型面板級封裝 |
| 熱解黏材料 | 加熱後黏性消失的材料，用於晶片切割製程中的臨時固定 |
| Micro LED | 微型發光二極體，次世代顯示技術，具透明、高亮度特性 |
| 隔日沖 | 今日買進隔日賣出的超短線操作方式，造成成交量放大 |
| 晶片法案（CHIPS Act）| 美國政府補貼半導體製造的法案 |
| DDR5 | 第五代雙倍資料率同步動態隨機存取記憶體，需獨立電源管理晶片 |
| 1.6T 交換機 | 1.6 Tbps 速率的網路交換機，為 AI 資料中心升級需求 |
