  - 台鋼集團成員，位階極低
  - 今日漲停，操作建議等隔日沖消化後，站上年線回測不破再布局
- **儲存代理**：新巨大（新普大）-- 代理凱俠、西捷、長江存儲
  - 在中國大陸市場有布局
  - 長江存儲 Q1 SSD 預計漲價
  - 本益比較低，漲幅較少

## 📈 技術面分析與操作策略

### 大盤技術面
- 五日均線未破，多方結構完整
- 跳空缺口為重要觀察點：不補 = 多方延續，補了 = 進入整理
- KD 指標過高，葵國老師預告 34 天空方轉折即將到來

### 操作策略
1. **台積電**：短線操作看五日線，中線看跳空缺口
2. **記憶體**：已漲多者勿追，轉往 SSD/HDD/儲存代理等低位階標的
3. **面板**：群創為指標，群創不弱友達等才有戲；但爆大量後短期宜觀望
4. **聯電**：昨日紅 K 一半為多空分水嶺

## 📋 投資策略總結

### 短期（1-2 週）
- 台積電法說會前可能有短線行情，但營收公布後有利多出盡風險

- Flash/SSD/HDD 等儲存產業鏈有補漲空間

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| KV Cache | Key-Value 快取，AI 推論時將已計算的 Key/Value 儲存下來，避免重複計算，提升推論效率 |
| FOPOP | Fan-Out Panel Level Packaging，扇出型面板級封裝，將晶片封裝製程從晶圓級擴展到面板級 |
| HBM | High Bandwidth Memory，高頻寬記憶體，用於 AI 加速器的堆疊式 DRAM |
| 隔日沖 | 當日買進，隔日開盤即賣出的短線操作手法 |
| 紅 K 一半 | 將前一日紅 K 棒的開盤價與收盤價平均，作為短線多空分水嶺 |
| 殖利率 | 現金股利 / 股價，衡量股息報酬率的指標 |
| CoWoS | Chip on Wafer on Substrate，台積電先進封裝技術 |
| 18A 製程 | Intel 的 1.8 奈米製程技術節點 |
