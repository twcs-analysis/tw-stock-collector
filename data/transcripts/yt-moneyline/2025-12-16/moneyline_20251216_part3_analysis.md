## 市場總體觀察

### 台股結構性變化

- **核心議題**：台股雖在創歷史新高的軌跡上，但截至12月15日，能呈現四條均線（月線、季線、半年線、年線）多頭排列的個股僅**238家**
- **佔比**：不到總上市櫃公司的**14%**
- **反面意義**：**86%的股票**無法走出像樣的多頭行情
- **結論**：台股已進入「AI股與非AI股」的極端二元結構

### 投資人的真實感受
- 有投資AI股票的投資人：績效亮眼
- 未投資AI股票的投資人：即使大盤創新高，個股績效仍然悲哀
- 這是台股近兩年最大的共同現象

## 產業分析與投資建議

### 一、AI投資實戰案例——京元電子（2449）

#### 持股明細

| 項目 | 數值 |
|------|------|
| 股票代號 | 2449 京元電子 |
| 持有張數 | 130張 |
| 成本價 | 59.64元 |
| 今日盤中價 | 217元 |
| 持有成本 | 775萬 |
| 目前市值 | 2,810萬 |
| 價差獲利 | 2,033萬 |
| 累計股利 | 130萬 |
| 未實現獲利 | **2,169萬** |
| 報酬率 | **279%** |

#### 買進理由
1. 殖利率好、本益比相對偏低
2. 與半導體產業相關
3. 判斷台灣半導體在2025年大爆發
4. 底部開始建立部位

#### 不賣的理由
- AI發展前景持續看好
- 京元電子董事長發表談話：「AI時代的測試業，就像是二十年前的晶圓代工產業，正要迎接屬於自己的高成長階段」

#### 半導體測試產業趨勢

| 項目 | 傳統晶片 | AI晶片 |
|------|----------|--------|
| 外接腳位 | 30-40個 | **6萬-10萬個** |
| 測試複雜度 | 低 | 極高 |
| 晶片成本 | 相對便宜 | 數億美金研發投資 |
| 測試定位 | 品質確保 | **系統能否啟動的關鍵核心** |

- AI時代，測試不再只是確保品質，更是整個系統能否運作的關鍵
- 測試業正要走出自己的高成長軌跡，如同20年前的晶圓代工

#### 個人投資組合配置
- AI股票佔比：**88%**
- 非AI股票佔比：約12%
- **投資哲學**：TAIWN = Taiwan + AI + Win，台灣因AI贏好多年

### 二、非AI投資的警示案例——拓凱（4536）

#### 持股明細

| 項目 | 數值 |
|------|------|
| 股票代號 | 4536 拓凱 |
| 持有張數 | 24張 |
| 成本價 | 191元 |
| 今日市價 | 157元 |
| 持有成本 | 459萬 |
| 目前市值 | 378萬 |
| 價差虧損 | -82萬 |
| 累計股利 | 26.4萬 |
| 未實現虧損 | **-56.4萬** |
| 報酬率 | **-12.28%** |

#### 拓凱的競爭力
- **碳纖維材料**專家
- 材料特性：密度比鋁小、重量比鋁輕、比鋼還耐高溫耐疲勞、強度比鋼大、熱脹冷縮幾乎不變形、導電性佳、比不鏽鋼更耐腐蝕
- **應用領域**：
  - 自行車（50%營收）——但自行車產業這幾年辛苦
  - 航太（成長方向）——飛機輕量化降低燃油成本
  - 網球拍（起家業務）

#### 航太轉型困境
- 波音與空巴訂單充沛（未來10年訂單保證）
- 但引擎做不出來，飛機無法如期出貨
- 航太營收成長不如預期

#### 堅持持有的理由
1. **本益比**不到10倍
2. **殖利率**相對較高（去年配發11元現金股利）
3. **營業EPS**（扣除業外）持續上升：3.28 → 16.07 → 16.70
4. **當初看好的理由沒有消失**——航太升級之路只是延後，並非不來
5. 等待航太產業出貨量放大的時機

#### 投資啟示
> 是否繼續持有破底股票，關鍵在於「當初看好的理由有沒有不見」

### 三、雙D產業（面板+記憶體）展望（郡州）

#### 記憶體——已顯然翻身
- 華邦電：16元漲到75元（今年8月至今）
- 南亞科：今年最低點短短3個月大幅上漲
- DDR4缺貨漲價 + DDR5主流需求 → 記憶體翻身

#### 面板（TFT LCD）——仍在等待

##### 面板價格走勢
- 今年1月至今：筆電/電腦螢幕面板——小幅波動，12月已不再跌
- 32吋電視面板：回跌到與1月相同水準，但12月幾乎止跌
- **判斷**：打底止跌中，明年有機會開始上漲

##### 面板廠獲利現況

| 廠商 | 前三季獲利 | 年增 |
|------|-----------|------|
| 友達 | 39.6億 | 轉虧為盈（去年-46.8億） |
| 群創 | 營收持平 | 持平表現 |
| 元太 | 94億 | 大幅成長（去年53億） |

##### 標準化 vs 客製化產品

**標準化產品**（手機、筆電、電視面板）：
- 今年成長個位數或小幅衰退
- 明年變化不大
- 約佔50%營收，成長動能有限

**客製化產品**（車用、工控、醫療）：
- 友達收購德商，車用營收佔比2024年17% → 2025年24% → 目標28%+
- 群創收購日本廠，車用佔比也在提升
- 產品整合（車載空調+人機介面）→ 提高ASP
- 群創Micro LED初期量產，今年可貢獻有意義營收

##### 面板業的兩大變數
1. **關稅後續**：中美談判結果影響筆電面板出口（台灣→中國→美國路徑）
2. **美國國防授權法**：軍用顯示面板禁用中國製品 → 台灣面板廠轉單效應

##### 面板能否複製記憶體行情？
- **困難**：中國產能仍大，價格難以大漲
- 但有機會在客製化領域逐步改善
- Micro LED若有突破，獲利可倍速成長

##### 元太（E Ink）特別觀察
- 電子紙全球市佔率超過90%
- 生產線持續擴大
- 獲利逐年成長（今年EPS預估約10元）
- **問題**：外資持續賣超，股價表現落後
- 屬於「局部在身上」的標準案例

- 從60元一路走到235元最高
- 最近雖有回檔，但不影響持股信心

- 成本191元，目前已破底
- 帳面虧損中，但營業利益持續成長
- 等待航太出貨量放大的催化劑

### 面板族群技術面
- 友達：前三季轉虧為盈，但股價表現平平
- 元太：獲利好但外資持續賣，股價壓抑
- 群創：Micro LED量產是潛在催化劑

## 名詞解釋

| 名詞 | 說明 |
|------|------|
| 四條均線多頭排列 | 月線、季線、半年線、年線由上而下排列且均向上，代表強勢多頭格局 |

| 國防授權法 | 美國國會通過的年度國防預算與政策法案，近年包含對中國技術限制條款 |
