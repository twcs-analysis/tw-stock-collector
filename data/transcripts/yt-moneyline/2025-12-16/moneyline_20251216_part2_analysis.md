## 市場總體觀察

### 外資動態與內資角色

- **外資**：連續兩天大賣，放假前仍不安心，持續減碼
- **內資現況**：投信沒有積極買進，但真正的內資力量不在投信上面
- **大戶動態**：大戶（包括投信外圍、法人、中實戶）近期出現不一樣的信號
- **內資布局特色**：年底偏好「敢做夢、會看門道」的股票，特別是之前沒漲的標的

### 外資賣超明細
- 050反向ETF：賣不夠
- 台灣五十：反向賣超百億
- 權值股下殺：台積電、鴻海、群創、華邦電、旺宏等均遭賣超
- **影響判斷**：外資通常跟國際股市聯動，既是領先指標也是落後指標，不如直接觀察美股

### 美國期貨盤觀察（錄影時間下午5:40）
- 期貨盤賣壓正在收斂（從4點多的0.8%跌幅逐漸縮小）
- 台積電ADR盤前小跌

## 產業分析與投資建議

### 一、光通訊族群——配角變主角

#### 產業趨勢分析
- **天上（太空光通訊）**：
  - SpaceX星鏈第二代已開始採用ISO光通訊
  - 星鏈第三代將更快速、更廣泛使用光傳輸
  - 亞馬遜Kuiper也開始大量部署
  - **趨勢**：巨頭全面採用「光」作為衛星間傳輸方式

- **地上（AI資料中心光通訊）**：
  - Google OCS（光路交換器）：傳輸改用光
  - 無光電轉換 → 耗電下降 → 模型訓練成本下降
  - 算力提升，10秒內可重組一次

- **核心結論**：天上太空、地上AI資料中心，共同語言就是「光」

#### 光聖（6442）——光通訊龍頭深度分析

| 項目 | 內容 |
|------|------|
| 定位 | 台灣光通訊市值與獲利王 |
| 核心產品 | 被動元件、高頻連接器 |
| 毛利率 | 極高 |
| 主要客戶 | Google佔比約70%（含整體約90%光通訊出貨） |
| 上下游佈局 | 子公司核聖科技（CPO關鍵模組）、收購IT KY、與Lumentum合作 |
| 國際對標 | 與Lumentum（美股持續創新高）地位相當 |

- **三位一體佈局**：IT KY → 光聖 → Lumentum（777萊得），從上游到太空、到資料中心
- 國際對標PE：若明年EPS達50元以上，與國際股市相比PE差距仍大
- **操作建議**：處置股期間沿月線操作，注意五日線有無跌破

#### 統新——光通訊關鍵元件

##### 產品定位
- **光柵光片**（Diffraction Grating）：將光的不同波長分開的關鍵元件
- 市場僅少數廠商能做，全球寡占
- **客戶**：Coherent（美股創新高）、Lumentum、國內新光、福懋

##### 應用場景
- 光纖通訊濾波器的核心
- 從發光源（磷化鎵、磷化銦、紅外線）到光柵分光，是整條光通訊供應鏈的關鍵環節
- 已開始出貨給SpaceX（太空相關）

##### 財務面
- 第三季已開始賺錢
- 對比聯亞（僅6毛EPS），統新已具備獲利能力
- 股價約90多元，僅聯亞（200多元）的一半

##### 技術面分析
- 打完大底後噴出，突破後回測
- 短線創高後正當整理（太強所致）
- **操作方式**：沿五日線操作，五日線未跌破前持續持有
- 量能觀察：沉電很久後剛上來，大戶在近兩根K線建立成本

### 二、建廠工程族群——營收認列第一排

#### 產業邏輯
- 半導體廠擴建順序：**無塵室工程（最先）→ 管線設備 → 機台進駐**
- 投信主動式策略：買在營收認列的第一波
- 台積電高雄廠、南亞科林口廠等大規模擴建進行中

#### 漢唐（2404）

| 項目 | 內容 |
|------|------|
| 定位 | 無塵室/潔淨室工程龍頭 |
| 客戶 | 台積電、日月光、京元電、力成、南科 |
| 關鍵數據 | 在手訂單85億（歷史新高），明年可能突破100億 |
| 合約負債 | 連增933%（從4,900萬暴增至5億） |
| 今日收盤 | 220.5元 |

- **獲利推估**：若100億訂單在一年多內完成，明年獲利可能有大幅上調空間
- PE不到10倍（相較其他設備股15-20倍）
- **技術面**：底部打完後連續兩天大漲，沉電很久開始噴出
- **操作**：沿五日線操作，股價評價來看空間仍大

### 五、GDP指引下的跨年投資方向（謝老師）

#### 2025年GDP回顧
- 全年約7%（創15年新高）
- 走勢：開低走高（Q1 5.5% → Q2 7.7% → Q3 8.21%）
- 主要貢獻：外銷（電子/AI）獨強，消費貢獻度偏低

#### 2026年GDP預測
- **三大機構一致預測**：開高走低
  - 元富：Q1 6.6% → Q2 4.6% → Q3 3.9% → Q4 2.9%
  - 主計處：Q1 6% → Q2 4.2% → Q3 2.4% → Q4 1.9%（更保守）
  - 台新金控：趨勢一致

#### 2026年三大投資方向

**方向一：上半年留意多頭回檔**
- GDP開高走低暗示股市高點可能在上半年
- 多頭年回檔也不可輕忽（今年4月低點17,300 vs 歷史高28,000+，回檔超過萬點）

**方向二：跨年度雙題材股（低基期 + 有夢可做）**

| 標的 | 代號 | 題材 | 關鍵資訊 |
|------|------|------|----------|
| 元晶 | 6443 | 太空太陽能 | 唯一與SpaceX合作台廠，但已大漲需等拉回 |
| 萬泰科 | 6190 | AI高速線材 + 太空通訊 | 毛利率25-35%，PCIe Cable擴產計劃明確 |

##### 萬泰科（6190）深度分析
- **主營**：雙體電線電纜，應用數據中心、遠端基站建設
- **AI布局**：PCIe Cable（InTra → Tray to Tray → Rack to Rack）
  - 2025年：內部線（InTra），毛利20-30%
  - 2026年：外部線（Rack to Rack），ASP與毛利最高
  - 規格從PCIe 5.0 → 6.0 → 7.0升級
  - 單價越來越高，毛利率有機會越來越高
- **太空通訊**：衛星通訊線材也有佈局
- **催化劑**：近日將舉行法說會
- 今日收盤：45.3元
- 技術面：W底格局打完，外資悄悄買超，量能逐漸放大
- 週線圖：長線打底後有向上攻擊態勢

**方向三：低基期轉機傳產股**

| 標的 | 代號 | 題材 | 關鍵資訊 |
|------|------|------|----------|

| 中鋼 | 2002 | BDI概念 | 年訂21萬噸散裝船，11月EPS 0.36創6年最佳 |

- 台塑化今日收盤：32.45元，強勢盤整在所有均線之上
- 中鋼：底部形態突破後拉回，月線/季線附近有支撐

### 六、金融族群——歷史新高的秘密（郡州）

#### 金融指數創歷史新高
- 大盤四天跌1,200點，但金融指數連漲四天創歷史新高
- **原因**：金融業獲利也是歷史新高

#### 銀行業獲利結構
1. **淨利差（50%）**：約9,000億，穩定成長（AI/半導體投資貸款+台商回流）
2. **手續費（財富管理）**：約4,000億，穩定成長
3. **投資收益**：約5,000億，波動較大但整體向上
- 三項合計約1.8兆

#### 保險業獲利結構
- **資金運用收益**是最大收入來源
- 全台保險業資金約31.2兆拿來投資
- 海外投資約22-23兆，匯率影響極大
  - 台幣每升值1元 = 損失3,000億
  - 今年4月台幣大幅升值造成壽險業匯損
- 富邦金/國泰金已分別提列700億/500億外匯價變動準備金，風險逐步降低

#### 2026年金融業展望
- **有利因素**：AI投資帶動放款、經濟穩定成長、財富管理法規鬆綁
- **不利因素**：地緣政治風險、打房管制影響房貸放款、IFRS 17新保險會計準則

#### 金融股選股方向

| 類型 | 標的 | 選股理由 |
|------|------|----------|
| 壽險型 | 富邦金（2881）、國泰金（2882） | 外匯準備金已充足，風險降低 |
| 銀行型 | 中信金（2891）、E.SUN（玉山金） | 存放款與財富管理表現佳 |
| 換匯型 | 兆豐金（2886） | 台股所有外匯兌換都經過兆豐金，換匯交易收益穩定 |
| 中小企業型 | 合庫金（5880）、台企銀 | 中小企業放款利率較高，獲利較佳 |

- **短期（5年）vs 長期（10-20年）**各有所好

## 技術面分析與操作策略

### 明日盤面觀察重點（會自老師）

1. **台幣匯率**：31.5元附近能否止穩
2. **期貨結算**：今日是否已提前反應賣壓？若明日不破今日低點，有機會向上
3. **季線支撐**：收腳往上走，經驗裡下引線出來，止跌訊號較大
4. **台積電**：大盤大跌但台積電跌幅相對有限，低接買盤介入
5. **人氣指標**：新概念股（太空通訊、光通訊、半導體建廠）維持熱度
6. **處置風險**：元晶、金居可能被處置，不一定要追，觀察效應是否擴散至族群

### 操作節奏建議
- 高成長、國際部署為主
- 光通訊、半導體建廠概念可作為盤面人氣參考指標
- 今日低點為初步換手點判斷，守住則行情有機會慢慢向上

## 名詞解釋

| 名詞 | 說明 |
|------|------|
| OCS（光路交換器） | Optical Circuit Switch，Google採用的全光交換技術，省去光電轉換步驟，降低耗電與延遲 |
| 光柵光片 | 利用光的繞射原理將不同波長的光分開的元件，是光通訊濾波器的核心 |
| LTCC | Low Temperature Co-fired Ceramics，低溫共燒陶瓷，太空與無線通訊的關鍵元件 |
| 合約負債 | 已收取客戶訂金但尚未交貨的金額，代表未來將認列的營收 |
| PCIe Cable | Peripheral Component Interconnect Express連接線，AI伺服器內部/外部高速傳輸的關鍵 |
| InTra / Tray to Tray / Rack to Rack | 伺服器內部線 / 層間連接線 / 機櫃間連接線，難度與ASP依序遞增 |
| BDI | Baltic Dry Index，波羅的海乾散貨指數，反映全球散裝航運景氣 |
| IFRS 17 | 國際財務報導準則第17號——保險合約，改變保險業收入認列方式 |
| 淨利差 | Net Interest Margin，銀行放款利率與存款利率的差額，是銀行最主要的獲利來源 |
| 外匯價變動準備金 | 壽險公司預先提列的準備金，用於吸收匯率波動對海外投資的影響 |
