## 📊 市場總體觀察

### 投信動態轉變

- **投信連續買超12天**台股後，今日**轉賣25.5億元**
- 這波投信買盤包含被動式ETF與主動式操作
- 投信賣出的個股，外資同步在承接（對做格局）
  - 例：國泰金 → 投信賣、外資買
  - 例：台泥 → 投信砍出（ETF換股）、外資越跌越買
- **核心問題**: 投信從連買12天轉賣，是否代表投信節帳期提前？

### 外資動向觀察

- 外資今日在櫃買市場買超前十名中，前六名全是**債券ETF**
  - 包含美債、投資等級債、金融債
- 外資最近大買**長天期美債ETF**
- 外資在個股上呈現「投信砍、外資接」的對做格局

### 債券市場大環境

- 國泰投信張錫建議下半年**股債均配**
- 預期聯準會**9月可能第一次降息**，12月再降一次
- 但降息速度非常慢、幅度非常小
- 美國「大而美」減稅法案引發公債供給增加疑慮，但可能沒有減那麼多

### 三、債券ETF投資策略（七分老師深度分析）

#### 各類債券ETF今年表現

| 類型 | 今年以來 | 一年報酬 | 兩年報酬 | 特色 |
|------|----------|----------|----------|------|
| 非投資等級債 | 約-6% | 約持平 | +10%以上 | 高配息，價格波動較小 |
| 短天期債券 | 較抗跌 | 較佳 | 較佳 | 貼近票面，波動最小 |
| 長天期美債 | **約-10%** | 較差 | **-22%** | 價格波動大，外資在買但風險高 |

- **今年所有債券ETF都呈虧損**，最少-6%、最嚴重-10%
- 但拉長到兩年，部分標的仍有+10%以上報酬

#### 台幣升值是最大殺手

**以非投資等級債ETF為例的拆解**:

| 項目 | 數字 |
|------|------|
| 今年以來價格跌幅 | -6% |
| 今年配息收入 | +2% |
| 台幣升值匯損 | **-8%** |
| **結論** | 下跌主因 = 台幣升值匯損 |

- **台幣每升值1元 ≈ 匯損3.3%**
- 萬一台幣升到29元，還要再承擔3.3%匯損
- 殖利率能否撐得住台幣升值的匯損？這是核心問題

#### 降息前景分析

| 時間 | 預期動作 |
|------|----------|
| 2025年9月 | 最快第一次降息 |
| 2025年12月 | 可能第二次降息 |
| 2025全年 | 最多降兩碼 |
| 2026全年 | 再降兩碼 |
| 降息特徵 | **速度非常慢、幅度非常小** |

**結論**: 期待大幅降息推升債券價格大反彈 → 機率非常低

#### 美國公債違約風險

- 違約機率非常小
- 近日債券殖利率小波動主因是「大而美」減稅法案
- 若減稅規模小於預期 → 公債供給不會大增 → 殖利率小幅回落
- 但整體趨勢未改變

#### 債券ETF操作策略總整理

| 投資人類型 | 具體建議 |
|------------|----------|
| **已套牢者** | 不建議現在賣（已跌一大段，賣了沒意義）。若目標是收息 → 趁下跌加碼增加單位數 → 提升配息能力 |
| **想賺價差者** | 很難，降息速度慢、匯率風險大 → 建議減碼離場 |
| **空手觀望者** | 可分批小額買進。現在債券殖利率在相對高水準，買進可配到較好利息 |
| **手上有美元者** | 直接用美元買美元計價債券基金，完全避開匯率風險 |

#### 推薦債券類型優先順序

| 優先順序 | 類型 | 理由 |
|----------|------|------|
| 1 | **非投資等級債** | 高配息、價格波動小、時間拉長報酬佳 |
| 2 | **短天期債券** | 貼近票面價值、波動最小 |
| 3 | 長天期美債 | 適合賺價差但風險高，**買點尚未到**（七分老師明確表態） |

#### AI概念股技術面

**廣達 (2382)**:
- 今日低點剛好卡在多方缺口上緣 → 轉強訊號
- 站穩年線 → 偏多
- 等待5月營收驗證（緯創已交出月增50%+年增160%的成績）

**台達電 (2308)**:
- 突破下降軌道
- 之前突破後回來測試、再突破 → 趨勢壓力逐步化解
- 穩健向上型，回檔即站在買方

**新穎材**:
- 拉一根紅K棒就整理、再拉一根再整理
- 整理過程很強勢，不破前低
- **節奏**: 不要追大漲日（追了要等很久才解套），要在整理時低接
- 紅K棒一半不跌破即續持

**勤誠**（AI機殼）:
- 股價已近翻倍，位階偏高
- 沿上升軌道操作，觸壓力或破軌道即出場
- 回檔不破軌道可再進場
- 機殼族群是否擴散值得觀察

1. **籌碼選股法**: 投信＋外資＋主力＋千張大戶四重確認，投信持股<10%排除被動買盤

4. **大盤操作**: 到多空交戰區就賣出保留現金，等拉回再買

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **投信作帳/節帳** | 投信基金在季末拉抬或調節持股以美化績效報表的行為 |
| **千張大戶** | 持有超過1,000張股票的大額投資人，其持股變動常反映機構或大戶信心 |
| **非投資等級債** | 信用評等BBB以下的債券，又稱高收益債，配息較高但信用風險較大 |
| **短天期債券** | 到期日較短（通常1~3年）的債券，價格波動小、貼近票面價值 |
| **長天期美債** | 到期日10年以上的美國公債，對利率變動敏感度最高 |
| **匯損/匯率風險** | 因匯率變動導致的投資損失。台幣升值時，以外幣計價的資產換算回台幣會縮水 |
| **限空令** | 政府在股市大跌時限制放空的禁令，退場代表回歸正常市場機制 |
| **上升軌道** | 連結股價波段低點形成的上升趨勢線，股價在軌道之上代表上升趨勢持續 |
| **大量紅K棒一半** | 帶量上漲K線的中間價位，技術分析中常作為短線支撐判斷依據 |
| **GB200/GB300** | NVIDIA新一代AI伺服器機架規格，GB200良率已解決，GB300即將接力，推動散熱等零組件需求 |
| **多方缺口** | 股價向上跳空留下的缺口，缺口上緣常成為回檔支撐 |
| **對做** | 投信賣出的同時外資買進（或反之），兩方法人操作方向相反 |
