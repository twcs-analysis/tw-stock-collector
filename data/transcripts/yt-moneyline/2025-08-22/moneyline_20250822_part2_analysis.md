## 💼 產業分析與投資建議

### PCB族群分析

#### 台播（董娘賣股事件）
- **事件**: 董娘賣出1,700萬元股票
- **影響**: 造成整個PCB族群大跌，市值蒸發數百億
- **判斷**: 短線利空，但基本面未變
- **技術面**: 爆出大量，30元附近會踩煞車
- **處置風險**: 可能面臨處置股票（天量天價後回落）
- **操作建議**: 因董娘事件暫時避開，選擇其他替代標的

#### 南亞（PCB波段部）
- **量能**: 沒有超級大量
- **支撐**: 40元月線位置正常會守住
- **更差情境**: 回到長紅起點也是買點
- **操作建議**: 買點幾乎很接近，短線可做

| 項目 | 數據 |
|------|------|
| 支撐位 | 40元（月線） |
| 第二支撐 | 長紅起漲點 |
| 操作建議 | 拉回買進 |

#### 副橋（PCB波段部）
- **量能**: 與前面比較不太大
- **技術面**: 紅棒只要守住就沒問題
- **判斷**: 最差回來月線就會回穩
- **操作建議**: PCB上游中相對安全

#### 金居（PCB最強標的）
- **量能**: 最大量距離現在非常遙遠，套牢人不多
- **近期表現**: 三天三根紅黑交替（但金居三根紅棒）
- **特色**: 被處置但股價持續上漲
- **結論**: 「你關不住我的心碼」
- **操作建議**: 上游首選，選最強的

| 項目 | 數據 |
|------|------|
| 最大量位置 | 距離現價非常遙遠 |
| 籌碼狀態 | 套牢盤極少 |
| 近期走勢 | 處置期間仍持續創高 |
| 操作建議 | PCB族群首選 |

- **過熱訊號**: 出現第一次過熱訊號（警告踩煞車）
- **非全面回檔**: 尚未到全面性回檔時間

- **關鍵觀察**: 有出大量位置的股票，不要跌破大量低點

#### 台光電與台燿（ABF/CCL指標）

## 📚 名詞解釋

### 市場術語

**二八分化**
- 定義：市場中20%的股票上漲帶動指數，80%的股票沒有漲或下跌
- 意義：指數創新高但市場寬度不足，是不健康的漲勢
- 風險：領漲股一旦回檔，大盤可能快速下跌

**融資餘額**
- 定義：投資人向券商借錢買股票的未還金額
- 意義：反映散戶槓桿操作程度
- 應用：融資過高為過熱訊號，融資低位表示市場偏冷

**處置股票**
- 定義：證交所對股價異常波動個股採取的交易限制措施
- 影響：限制盤中漲跌、增加信用交易保證金
- 觀察：處置期間仍能上漲的股票，通常是真正的強勢股

**隔日沖**
- 定義：今天買進、隔天賣出的極短線操作
- 目的：賺取價差，降低持股風險
- 應用：本集提到雷虎出關後有隔日沖賣壓

### 國際經濟術語

**傑克森霍爾年會（Jackson Hole Symposium）**
- 定義：堪薩斯聯儲銀行主辦的全球央行年度研討會
- 時間：每年8月底
- 重要性：聯準會主席演說被視為貨幣政策風向球
- 歷史：2022年鮑爾強硬講話後股市跌到10月

**232條款（Section 232）**
- 定義：美國1962年《貿易擴張法》第232條
- 內容：允許總統以國家安全為由對進口商品加徵關稅
- 影響：可能對半導體、電子產品課徵額外關稅

**對等關稅**
- 定義：對貿易夥伴課徵與其對美國商品相同稅率的關稅
- 影響：主要衝擊傳統產業
- 風險：可能擴大至電子資訊產品

### 技術分析術語

**長黑K棒**
- 定義：開高收低、實體部分很長的陰線
- 意義：強烈賣壓訊號
- 本集應用：週三長黑是必要修正，甩掉浮額

**量增價漲**
- 定義：成交量增加的同時價格上漲
- 意義：多方力道強勁的正面訊號
- 本集應用：OTC量增價漲，中小型股前景看好

**量先行**
- 定義：成交量領先於價格變化
- 意義：大量出現在創高時，通常價格還會繼續上漲
- 本集應用：一起（無人機）爆量創高，量先行
