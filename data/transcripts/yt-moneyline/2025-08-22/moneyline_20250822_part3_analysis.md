### 資產傳承 - 嫁妝保護策略（蘇律師專題）

#### 案例：母親為女兒準備嫁妝（40坪房子+4,000萬現金）

#### 三大擔憂
1. **離婚時財產被分走**: 女婿分走一半
2. **女兒被洗腦**: 房產被偷龍換鳳轉移
3. **安全風險**: 女兒因財產面臨人身風險

#### 保護策略（依女兒個性分類）

**策略一：有主見的女兒 - 婚前贈與**
- **做法**: 婚前將房子贈與登記在女兒名下
- **效果**: 婚前財產不列入夫妻財產分配
- **注意**: 婚後贈與也算，但需保留證據
- **重點**: 專用帳戶，不要與婚後收入混在一起
- **進階**: 約定分別財產制（最直接）

| 財產類型 | 離婚時分配 |
|----------|-----------|
| 贈與本金 | 不需分配 |
| 本金產生的利息 | 需要分配 |
| 本金買股票的資本利得 | 股票本金不分，股利要分 |
| 定存利息 | 需要分配 |

**策略二：心軟的女兒 - 信託保護**
- **做法**: 將房子信託給銀行，期限20年
- **結構**:
  - 委託人：母親
  - 受託人：銀行
  - 受益人：女兒
- **效果**:
  - 女兒有使用權和收益權
  - 女兒沒有處分權（不能賣）
  - 銀行名下，女婿無法動手
  - 不能拿房子去貸款
- **為何20年**: 結婚20年後風險降低，智慧也足夠
- **成本**: 信託費約千分之三到四（不高）

**策略三：極度軟弱的女兒 - 保留在父母名下**
- **做法**: 房子登記在父母名下，不實際過戶
- **外觀**: 像是嫁妝（面子上交代得過去）
- **實際**: 保護在父母手裡
- **操作**: 每月提供女兒生活費（如每月5萬元）
- **節稅**: 利用每年贈與免稅額（父母各244萬）
- **最終**: 用遺囑確保房子最終歸女兒

#### 常見問題解答

| 問題 | 答案 |
|------|------|
| 女兒先過世，財產歸誰？ | 看繼承人（女婿+父母親均分） |
| 離婚時繼承財產能否分配？ | 不行，繼承的財產女婿不能分 |
| 女兒婚前把房子賣掉改登記女婿？ | 這就麻煩了，所以第三策略最安全 |
| 信託費用高嗎？ | 千分之三到四，千萬級約3-4萬/年 |
| 遺囑需要公證嗎？ | 不一定，但寫清楚很重要 |
| 遺囑執行人怎麼選？ | 拿最多錢的人/家族長輩/律師 |

## 📚 名詞解釋

### 央行與貨幣政策術語

**傑克森霍爾年會（Jackson Hole Symposium）**
- 定義：每年8月底在美國懷俄明州傑克森霍爾舉辦的全球央行年度研討會
- 主辦：堪薩斯聯邦儲備銀行
- 重要性：聯準會主席演說被視為貨幣政策方向的最重要風向球
- 2025年焦點：鮑爾是否釋放9月降息訊號

**非農就業數據（Non-Farm Payrolls, NFP）**
- 定義：美國勞工部每月公布的非農業部門新增就業人數
- 重要性：聯準會決定利率政策的重要參考指標
- 本集提到：新增人數不如預期，失業率上升，前幾月數據下修

**PPI（Producer Price Index，生產者物價指數）**
- 定義：衡量生產者端物價變動的指標
- 與CPI差異：PPI反映上游成本，CPI反映消費端價格
- 本集提到：PPI往上翹，對通膨控制不利

**殖利率（Yield）**
- 定義：債券投資的年化報酬率
- 與債券價格關係：反向（殖利率下降→債券價格上升）
- 本集應用：降息→殖利率下降→債券價格上漲

### 投資工具術語

**非必需性消費（Consumer Discretionary）**
- 定義：消費者有錢時會買、沒錢時會暫停的商品和服務
- 代表公司：亞馬遜、特斯拉
- 特性：與經濟景氣高度正相關
- 本集：降息後第二強勢的產業

**ETF（Exchange Traded Fund，指數股票型基金）**
- 定義：在證券交易所掛牌交易的基金
- 類型：股票型、債券型、商品型
- 本集應用：科技ETF、美債ETF、大盤ETF

**匯損（Currency Loss）**
- 定義：因匯率變動導致的投資損失
- 本集情境：買美國資產 → 台幣升值 → 換回台幣時虧損
- 對策：分散配置台灣與美國資產

### 法律與資產術語

**信託（Trust）**
- 定義：委託人將財產交付受託人（通常為銀行），依約定管理並分配給受益人
- 結構：委託人→受託人→受益人
- 特色：受益人有使用權但無處分權
- 費用：約千分之三到四（年費）

**贈與免稅額**
- 定義：每年贈與給每位受贈人免課贈與稅的額度
- 2025年額度：每人每年244萬元（夫妻合計488萬）
- 應用：化整為零，分年贈與節稅

**分別財產制**
- 定義：夫妻各自管理、使用、處分自己的財產
- 效果：離婚時不需進行剩餘財產分配
- 適用：有主見、能獨立管理財產的女性

**遺囑加信託**
- 定義：在遺囑中指定財產以信託方式管理
- 效果：過世後財產由信託保護，受益人只能使用不能處分
- 適用：擔心繼承人無法妥善管理財產的情境
