## 📈 技術面分析與操作策略

### 大盤技術面
- 跳空開高走高，多頭格局確立，五大紀錄同步創新高
- 連假前需留意節前賣壓（參考上週五跌440點經驗）
- 下週僅三個交易日，行情容易中斷

### 操作建議
1. **在車上的人不急下車**：多頭格局持續，重點做高低積極轉換
2. **台積電不追高**：正乖離率大，持有即可，不加碼
3. **連假前打短**：以短打為主，關注營收公告後股價表態
4. **弱勢股先汰換**：大盤創新高但個股仍破底者，趁機調整
5. **持股水位六到八成**：偏多操作，選股不選市
6. **選股三大方向**：AI工廠基礎建設、電力設備、設備股

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| 主權AI | 各國政府自主建設的AI基礎設施，包含自主AI模型與運算中心，避免資料外洩至他國雲端服務 |
| AI工廠 | 由多個資料中心組成的大規模AI基礎建設，整合GPU、高速網路、散熱、儲存與電力，實現算力大幅提升 |
| 摩爾電力2.0 | 黃仁勳提出的概念，指透過AI工廠整合使每代算力增加一倍，不再僅依賴GPU單一元件的進步 |
| 二奈米 | 台積電最新先進製程，第四季開始量產，超過15家客戶搶訂，建廠基地在新竹寶山與高雄 |
| 正乖離率 | 股價偏離均線向上的程度，乖離越大代表短線過熱，回檔機率增加 |
| 霸服（Buff） | 源自遊戲用語，指強化某事物的效果；此處指降息對科技股產生正面的強化效應 |
| 預防性降息 | 央行在經濟尚未明顯衰退前先行降息，以防止經濟下行風險 |
| GICS | 全球產業分類標準（Global Industry Classification Standard），由S&P與MSCI推出的11個產業分類系統 |
| 標普科技精選行業指數 | 從S&P 500中篩選資訊科技產業股票組成的指數，純科技持股，報酬表現優於那斯達克100 |
| 最惠國待遇 | 指某國給予另一國的貿易優惠不得低於給予第三國的待遇；川普要求藥價比照其他已開發國家最低價 |
