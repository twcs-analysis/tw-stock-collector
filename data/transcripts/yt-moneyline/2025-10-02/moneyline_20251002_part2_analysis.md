### 八、股票分拆（拆股）專題

#### 分拆概念解析
- **定義**: 類似換鈔票，1,000元換成10張100元，總價值不變但股數增加
- **多頭訊號**: 歷史上分拆通常釋放多頭訊號
- **目的**:
  1. 公司股價上漲、前景可期
  2. 增加股票流動性，讓更多投資人參與
  3. 配合增資、發行庫藏股等資本運作

#### 美股分拆案例

| 公司 | 分拆歷史 | 累計拆股倍數 | 還原股價 |
|------|---------|------------|---------|
| Apple | 5次（1987-2020），最近一次1拆4 | 約200倍 | 約5萬美元 |
| NVIDIA | 2次（2020年1拆10、2021年1拆4） | 約40倍 | 約7,480美元 |
| Google | 多次分拆 | - | - |
| Tesla | 1拆3（2022年） | - | - |

- 美股七巨頭全部拆過股，且拆後股價均創歷史新高

#### 台股分拆案例

**成功案例**:
- **國巨（2327）**: 一拆四後股價慢慢墊高，還原後接近去年高點
- **0050（元大台灣50）**: 一拆四後還原已創歷史新高
- **0063（國泰永續高股息）**: 拆後創新高
- **四季材料**: 拆完繼續漲

**失敗案例**:
- **KY材料**: 拆完後營收有漲但獲利沒上來（地緣政治影響），新台幣升值也不利
- **教訓**: 拆補不一定是萬靈丹，還需要獲利市場肯定

#### 康普（4739）資本運作分析
- **資本運作手法**: 拆分 -> 拉股價 -> 納入MSCI指數 -> 被動式ETF買進 -> 市值膨脹
- **目標達成**: 已納入0050（台灣50 ETF）
- **風險提醒**: 基本面獲利不突出，已達中級目標，接下來空間可能有限
- **納入0050後**: 反而開始出現調節動作

#### 即將分拆的標的：0052（富邦科技）
- **持股結構**: 台積電佔比高達70%，前四大（F4）加起來約80%
- **別名**: 「小台積電」
- **本益比**: 今年度約10元EPS，相對穩健
- **還原股價**: 約680元（去年高點800多元）
- **空間**: 以資本運作角度看仍有向上空間

### 九、生技醫療專題：輝瑞降藥價協議

#### 輝瑞與川普協議四大重點
1. **最惠國待遇**: 美國藥價對標其他已開發國家最低價格
2. **自願降價**: 處方藥平均降價50%以上，最高達80%
3. **Trump RX**: 政府直銷藥品平台
4. **輝瑞承諾**: 投資700億美元在美國設藥廠與研發設施，換取3年進口藥品免關稅

#### 台灣受惠廠商三大方向

**1. 代工與合作藥廠（CDMO）**
- 需求增加：美國藥品需求大增但建廠需時間，外包訂單增加

**2. 學名藥廠與專利挑戰公司**
- 美國藥價調整後，效果相同但價格更低的學名藥有機會搶市

**3. 高階研發技術合作**
- 輝瑞與台大醫院等合作精準醫療與癌症基因檢測

#### 台灣生技受惠標的

| 股票代號 | 公司名稱 | 業務類型 | 重點分析 |
|---------|---------|---------|---------|
| 6446 | 藥華藥 | 新藥研發 | 被0050踢出後投信大賣，還原後其實創高；等投信賣壓結束後有機會 |
| 6731 | 美時 | 學名藥/癌症學名藥製造 | 被處置中，投信積極買超6,468張；收購美國愛威群（6.85億美元），成為全球前20大學名藥商；毛利率相近（美時60%/愛威群50%），併購不拖累獲利；明年EPS預估突破25元 |
| 6541 | 台鋼生 | CDMO/新藥開發 | 生物相似藥已在台灣上市、歐盟取得藥證；美國FDA建議終止三期臨床（加速上市）；大股東為鴻家軍（鴻準）；推動美國CDMO產能併購 |

#### 處置股觀察（重要提醒）
- **躲處置 vs 不躲處置**: 美時昨天跌幅可以讓它不進入處置，但它選擇不躲
- **解讀**: 主力不怕處置代表對基本面有信心
- **案例**: 台升科（3533）躲處置導致股價急跌；聯鈞（3450）不躲處置反而後續創新高
- **投資啟示**: 躲處置的股票要小心，不躲處置的反而有機會

## 名詞解釋

| 名詞 | 解釋 |
|------|------|
| 股票分拆（拆股） | 將一股拆分為多股，如1拆4，股價降為四分之一但股數增加四倍，總價值不變 |
| 處置股 | 股價異常波動被交易所列為處置股票，改為分盤交易（每5分鐘撮合一次），限制投機交易 |
| 躲處置 | 主力刻意壓低股價避免觸發處置門檻（如漲幅不超過一定比例） |
| CDMO | 委託開發暨製造服務（Contract Development and Manufacturing Organization），藥品從研發到生產的外包服務 |
| 學名藥 | 原廠藥專利到期後，其他藥廠以相同成分製造的藥品，價格較低 |
| 生物相似藥 | 類似學名藥概念，但針對生物製劑（蛋白質藥物），需證明與原廠藥高度相似 |
| MSCI指數 | 摩根士丹利資本國際指數，全球被動式ETF追蹤的重要指數，被納入會帶來被動買盤 |
| 資本運作 | 透過拆股、增資、市值管理等手段提升公司在指數中的權重，吸引被動資金流入 |
| Trump RX | 川普政府推出的藥品直銷平台，讓美國民眾以較低價格購買處方藥 |
