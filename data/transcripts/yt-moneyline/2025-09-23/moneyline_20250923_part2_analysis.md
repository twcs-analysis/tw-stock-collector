## 🌍 市場總體觀察

### 集團股排行榜

- **一週漲幅排行**: 經過濾除小量股後，華新麗華集團、台塑集團、國巨集團、台積電集團成員紛紛上榜
- **集團色彩濃郁**: 近期標股排行榜充滿集團作帳痕跡，不僅是第三季作帳，更是布局第四季與明年的大波段行情
- **AI三大漲價列車**: 記憶體、被動元件、PCB 同時啟動漲價，各集團紛紛搭上

### AI零組件升級趨勢

- **伺服器功耗指數型跳躍**: CPU 層數從數千上升至數十萬層，明年將迎接新世代產品
- **PCB材料升級**: 速度越快需要更低的 DK/DF 值，帶動高階材料需求
- **被動元件用量暴增**: 傳統伺服器電容約 2,000 顆 → HGS 系列 20,000 顆 → GB200 約 200,000 顆 → GB300 更多
- **電力革命**: GPU、HBM、被動元件用量全面增加，從 PCB 擴散到機櫃再到被動元件

### 外資動向

- **外資連續兩天轉賣後回補**: 前兩天賣超今日全數補回
- **鴻海 (2317)**: 外資今日買超五萬多張，突破北京太壓力位，出量明顯
- **聯發科 (2454)**: 外資昨日賣超後今日大量買回，直攻漲停，但短線五日線仍有壓力

### 蘋果 (AAPL) 最新動態

- **股價**: 過去兩個月漲 21%，距離歷史新高 260 美元僅差 4 美元
- **iPhone 17 預購超預期**: 備貨 9,000 萬支（去年 8,600 萬支），預購超乎預期
- **供不應求**: 通知鴻海、和碩兩大組裝廠日產能提高 30%
- **中國市場交貨排程延長至 27 天**: 愛國化疑慮消退，中國預購意外強勁
- **全球換機潮**: 15 億支 iPhone 中有超過半數四年未更新，推估 iPhone 17 銷量可高出 10-15%
- **明年出貨量**: 上看 2.4-2.5 億支

## 📋 投資策略總結

### 短期策略（1-2 週）
- **持續偏多**: 五大變盤條件僅少數成立，籌碼面全面偏多
- **台積電**: 創高後若衝太高可先不追，等正常拉回
- **集團股輪動**: 華新麗華、國巨、能緑三大集團起漲，跟隨集團龍頭操作
- **蘋概股佈局**: iPhone 17 預購超預期，關注鴻海、和碩、大立光、玉晶光

### 中期策略（1-3 個月）
- **AI 漲價循環延續**: 記憶體、被動元件、PCB 三大漲價從第四季延伸至明年
- **物理 AI 新主軸**: 機器人、自駕車相關的能緑集團值得長線佈局
- **蘋果供應鏈復甦**: iPhone 17 若銷量如預期，Q4 營收將明顯反映
- **中秋節前後**: 目前無變盤訊號，但需持續觀察外資空單變化

### 風險評估
- **台積電過度集中**: 大盤漲幅高度依賴台積電，若台積電休息中小型股壓力大
- **蘋概股估值偏低但動能未明**: 部分蘋概股本益比低但營收尚未轉正
- **集團股短線漲多**: 華新科等短線急漲後有拉回壓力，勿追高
- **國際連假風險**: 10 月中秋、國慶連假多，需留意國際事件

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **集團作帳** | 上市公司集團在季末透過買進旗下子公司股票，拉抬股價以美化財報持股市值 |
| **被動元件** | 電子零組件中不需外部電源即可運作的元件，如電容、電阻、電感 |
| **MLCC（積層陶瓷電容）** | 多層陶瓷電容器，廣泛用於電子產品中的關鍵被動元件 |
| **DK/DF 值** | 介電常數(DK)與散逸因子(DF)，PCB 材料的關鍵參數，越低代表訊號傳輸品質越好 |
| **GB200/GB300** | NVIDIA 下一代 AI 伺服器平台，較前代大幅增加被動元件用量 |
| **HBM（高頻寬記憶體）** | High Bandwidth Memory，AI 晶片專用的高速記憶體堆疊技術 |
| **物理 AI** | 相對於軟體 AI，指將 AI 應用於實體世界的技術，如機器人、自駕車 |
| **人形機器人** | 模仿人類外形與動作的機器人，為 AI 從虛擬走向實體的關鍵應用 |
| **分盤交易** | 證交所對異常股票實施的處置措施，限制每五分鐘撮合一次，降低投機交易 |
| **破底翻** | 股價跌破前低後迅速反彈翻上，為強力反轉訊號 |
| **股票期貨** | 以個股為標的之期貨商品，一口代表兩張股票，適合短線操作 |
