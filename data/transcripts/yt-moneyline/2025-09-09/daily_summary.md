- **收盤點位**: 24,855點（+307點），盤中高點24,880點

- **資金三大去向**: 股市（融資成本降低）、黃金（站穩3,600美元）、加密貨幣（比特幣站穩11萬美元）

## 📋 投資策略總結

### 短期策略（1-2週）

1. **半導體展（本週）+ 軍工展（下週）+ Meta眼鏡（9/17）** 三大催化劑連發，相關概念股短線有表現空間
2. **台積電9/16除息**（配5元歷史最高），持有者等填息，空手等除息後拉回布局
3. **8月營收選股**: 聚焦萬里無雲、籌碼不亂、族群性強的個股
4. **BPU族群**: AES能否突破1,450元為族群續強關鍵
5. **MACD翻紅股**: 台積電、台達電、華碩翻紅為起漲訊號
6. **操作紀律**: 分批進場，以關鍵均線作為停損停利點

### 中期策略（1-3月）

1. **降息循環啟動**: 資金行情有利股市，第三季作帳+第四季作夢
2. **Rubin世代供應鏈**: 探針卡（旺矽、京元電）、PCB（金居、台光電）、電源（光寶科、台達電）、散熱（建準、奇鋐）
3. **投信作帳風格轉變**: 更大膽、更廣泛，連軍工股都追高買
4. **半導體設備輪動**: 耗材漲完漲設備（均華、升陽半），下半年業績展望佳
5. **紡織股觀察**: 亞馬遜網紅經濟學帶來新想像空間，先放口袋觀察等風向轉變
6. **數位金融配置**: 比特幣ETF（00909）、市值型ETF（00905）適合長期定期定額

## 📚 名詞解釋（全集整合）

| 名詞 | 解釋 |
|------|------|
| **矽光子（Silicon Photonics）** | 利用矽材料整合光學與電子元件的技術，解決GPU運算瓶頸 |
| **Rubin** | NVIDIA下一代GPU架構，首次結合HBM4與三奈米製程，性能比GB300提高3.3倍 |
| **BPU（Ball Process Unit）** | 球閥/管件處理單元，用於半導體製程流體控制，隨AI需求增加用量提升 |
| **HVLP4** | 超低損耗銅箔基板等級，NVIDIA新世代GPU的關鍵材料 |
| **HVDC** | 高壓直流輸電，AI伺服器資料中心使用的電力傳輸方式 |
| **TIM1（Thermal Interface Material 1）** | 直接接觸晶片表面的散熱材料，技術門檻極高 |
| **PEEK材料** | 聚醚醚酮，高強度耐高溫高分子材料，適用於無人機與機器人 |
| **探針卡（Probe Card）** | 半導體晶圓測試關鍵耗材，隨GPU複雜度增加需求大增 |
| **老化測試（Burn-in Test）** | 晶片在高溫下運行測試穩定性，篩選不良品 |
| **萬里無雲** | 股價在歷史高檔區，上方無套牢賣壓，漲升阻力最小 |
| **M頭（雙重頂）** | 股價二度挑戰同一高點失敗後回落的看跌型態 |
| **Smart Beta** | 透過量化因子（品質、價值、動能等）系統性選股的投資策略 |
| **投信作帳** | 投信基金在季度末前積極操作以提升績效的行為 |
| **MACD黃金交叉** | MACD指標從負值翻正，通常視為多方起漲訊號 |
| **利多出盡** | 好消息公布後股價反跌，因市場已提前反映 |
| **Re-Rating** | 市場對公司估值重新評價，給予更高本益比 |
| **快時尚（Fast Fashion）** | 快速將流行設計轉化為成衣大量銷售的商業模式 |
| **網紅經濟學** | 透過網紅影響力帶動商品銷售的商業模式 |
| **衰退型降息 vs 預防型降息** | 衰退型因經濟已衰退；預防型為預防性降息，對股市較有利 |
| **分盤交易** | 新上市/上櫃股票初期的分段撮合交易方式 |
