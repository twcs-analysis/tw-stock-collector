### 8月營收總體概況

- 截至節目錄影時，台股已有 **820 家以上** 公司公布8月營收
- 其中 **148 家** 創下歷史最旺營收紀錄
- 明天（9/10）為營收公布截止日，全部數據將揭曉
- 台灣受惠AI浪潮，整體營收表現相當亮眼

### 8月營收選股四大原則

節目提出營收創新高後的選股邏輯，避免踩雷：

#### 應避免的兩類股票
1. **營收公布前已大漲過多者** - 市場已先行壓寶，營收公布反成利多出盡
2. **前方有套牢賣壓者** - 即使營收利多，股價挑戰前波大量高檔區時仍會遭解套賣壓壓制

#### 應優先選擇的四個條件
1. **族群性、題材性** - 整個族群都在創高，具續航力
2. **營收穩定成長** - 趨勢向上，非一次性暴衝暴跌
3. **籌碼不亂** - 外資、投信仍在買方，避免法人減碼股
4. **萬里無雲** - 上方無套牢賣壓，股價在歷史高檔區

### 國際品牌消費產業觀察

#### 全球品牌服飾今年表現疲弱
- **Lululemon（路路利檬）**: 今年股價腰斬（跌逾五成），庫存增加、營收零增長、全年營收下修
- **Uniqlo/GU（迅銷集團）**: 今年股價大跌
- **品牌服飾整體**: 多數品牌遭遇逆風，唯獨亞瑟士（ASICS）在日本掛牌逆勢上漲

#### 亞馬遜網紅經濟學 - 快時尚2.0

- **背景**: 亞馬遜2024年10月起與千萬粉絲網紅Sophia合作，推出聯名親子/家居用品，意外大賣
- **快時尚2.0 vs 1.0**: 亞馬遜擁有全球電商近四成市占率，自有品牌服飾市占0.6%（約10.2億美元/300億台幣），加上網紅帶貨能力，規模可期
- **核心優勢**: 共享大數據（掌握哪款賣得好）+ 網紅全面可知 + 亞馬遜龐大流量平台
- **計畫擴張**: 今年年底前將再找更多網紅合作

## 💼 產業分析與投資建議

### 一、8月營收創高且股價有反應 - BPU族群

#### 1. 穿骨（2009）- 社交華貴/機器人概念
- **產業**: 華貴（閥門/流體控制）龍頭，主要做社交華貴
- **亮點**:
  - 新產品持續推出，鋸壁三百下半年接棒，新世代華貴需求提升
  - 美國製造布局：去年在休斯頓取得土地，明年量產，增加產品線
  - 評估切入機器人領域，提供想像空間
  - 明年法人推估EPS大幅成長，本益比約26倍（以明年EPS計算，已Re-Rating）
- **技術面**: 萬里無雲，股價創歷史新高區，上方無套牢賣壓
- **操作建議**: 外資有小幅調節但正常，過去每次回測至五日線/軍線附近都是好的布局點，分批進場
- **目標價**: 持續創高
- **停損點**: 跌破五日線或十日線支撐

#### 2. AES（代號未明確提及）- BPU族群毛利率最高
- **產業**: BPU（球閥/管件）供應商，供貨四大雲端業者
- **亮點**:
  - BPU族群中毛利率最高
  - 受惠NVIDIA規格提升（BNCA規格升級），BPU需求用量增加
  - 今年與明年本益比均不算貴
- **技術面**: 股價約1,395元，挑戰前高1,450元為關鍵
  - 若突破1,450元則續攻
  - 若無法突破回落，恐形成M頭或箱型整理
- **操作建議**: 關注1,450元能否突破，突破則加碼，失敗則觀望
- **目標價**: 突破1,450元後看更高
- **停損點**: 跌破箱型整理下緣

### 二、半導體設備股 - 耗材漲完漲設備

#### 3. 均華（6640）- 半導體設備
- **產業**: 半導體設備廠商
- **亮點**:
  - 8月營收創歷史新高
  - 公司預期下半年比上半年更好
  - AI帶動需求增加，設備認列加速
  - 明年EPS推估本益比約30倍
- **股價**: 收盤754元
- **技術面**: 今日出現上影線但有創高，代表前方套牢者已可獲利了結、無人歸潛（套牢壓力小）。外資回買、投信也在買方，均線完成黃金交叉後重新翻揚，具續攻態勢
- **操作建議**: 上影線不需過於擔心，均線翻揚後持有，拉回至均線附近加碼
- **目標價**: 持續創高
- **停損點**: 跌破近期整理平台低點

#### 4. 升陽半（8028）- 半導體設備/擴產概念
- **產業**: 半導體設備/材料
- **亮點**:
  - 前8月營收非常穩定
  - 追加資本支出，不斷擴充產能，代表已接到訂單
  - 上修再升經營目標
  - 8月營收再創歷史新高
  - 明年推估本益比不算高
- **股價**: 收盤1,804元
- **技術面**: 挑戰前高（約1,855元小高點），第一次突破失敗後回測至均線支撐，第二次攻擊量能若持續增加，有機會全面突破
- **操作建議**: 觀察量能是否持續放大，放大則有機會突破前高，分批布局
- **目標價**: 突破1,855元前高後看更高
- **停損點**: 跌破回測低點支撐

### 三、併購題材股 - 營收因併購大跳升

## 📋 投資策略總結

### 短期策略（1-2週）

1. **8月營收選股**: 聚焦營收創高且「萬里無雲」的個股（穿骨、均華），避開已大漲或前方有套牢賣壓者
2. **展覽行情**: 半導體展（本週）、軍工展（下週）、Meta眼鏡（9/17），相關概念股短線有催化劑
3. **BPU族群**: AES挑戰1,450元為關鍵分水嶺，突破則族群續強
4. **操作紀律**: 分批進場，以關鍵均線（五日線/十日線）作為停損停利參考點

### 中期策略（1-3月）

1. **半導體設備**: 耗材漲完輪到設備（均華、升陽半），下半年業績看好
2. **併購題材**: 台特化等併購帶動營收跳升的個股，後續貢獻將逐步顯現
3. **紡織股等待翼變**: 全球品牌服飾處於逆風，但亞馬遜網紅經濟學帶來新想像空間，正大環球（4411）為核心供應商。目前先觀察，等風向轉變

- 營收公布前已大漲的個股，利多出盡風險高

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **BPU（Ball Process Unit）** | 球閥/管件處理單元，用於半導體製程中的流體控制，隨AI需求增加用量跟著提升 |
| **萬里無雲** | 技術分析術語，指股價在歷史高檔區，上方完全沒有套牢賣壓，漲升阻力最小 |
| **利多出盡** | 好消息公布後股價反而下跌的現象，因市場已提前反映利多，公布時反成出貨時機 |
| **M頭（雙重頂）** | 技術分析型態，股價二度挑戰同一高點失敗後回落，形成像字母M的形狀，為看跌訊號 |
| **快時尚（Fast Fashion）** | 快速將流行設計轉化為成衣並大量銷售的商業模式，強調速度與價格競爭力 |
| **網紅經濟學** | 透過網路紅人的影響力與粉絲基礎，帶動商品銷售與品牌推廣的商業模式 |
| **Re-Rating** | 市場對公司估值重新評價，通常因基本面改變（如切入新領域）而給予更高本益比 |
| **套牢賣壓** | 先前在高檔買進的投資人，股價回升至其成本價附近時傾向賣出（解套），形成上方賣壓 |
| **箱型整理** | 股價在一定區間內上下波動，上有壓力、下有支撐，形成方形整理格局 |
