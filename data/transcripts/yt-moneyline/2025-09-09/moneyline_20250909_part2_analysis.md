## 🌍 市場總體觀察

### 投信第三季作帳新動態

#### 作帳風格轉變
- 今年上半年投信績效不佳（4-6月股市大幅震盪），第三季開始積極衝績效
- **新特點一**: 個股操作比以前更大膽，不再保守
- **新特點二**: AI布局面向拉寬，不再集中同一族群
- **新特點三**: 連軍工股都開始積極買進，且不是買低檔而是追高買
- **核心邏輯**: 第三季打底，若不做起來第四季更辛苦

### 外資個股買超分析

#### 現貨買超前十名重點解析

**1. 寶成（9904）- 外資買超第一名**
- 買超13萬張（但大部分為盤後巨額對敲/換手）
- 盤中走勢未見特殊漲幅
- **操作建議**: 需確認是否為策略性新買盤，目前參考意義有限

**2. 鴻海（2317）- 外資持續買超**
- 買超33,000多張
- 盤中一度漲幅亮眼
- 技術面：所有均線向上，拉回有支撐
- **操作建議**: 中線持有，空手可等拉回至均線附近布局

**3. 東元（1504）- 連買三天**
- 買超25,000多張
- 今日一根紅K棒表態，挑戰前高
- 外資操作節奏：連買3-4天 → 拉回1天 → 再買
- **操作建議**: 靠近五日線乖離大時外資會調節，等拉回至十日線附近再介入

**4. 華邦電（2344）vs 南亞科（2408）- DRAM雙雄**
- 華邦電強度較強：關鍵紅K棒上方正常回測五日線
- 南亞科：關鍵紅K棒處一度有穿越現象，大量日壓力較大
- **操作建議**: 先看華邦電，若華邦電創新高才會帶動南亞科
- DRAM漲價對兩者均有利，漲價幅度需後續觀察

**5. 鴻達電（暫無代號提及）- 眼鏡概念**
- 外資近期買進約10,000張
- 高檔出現盤整跡象，需注意十日線是否下彎
- 9月17日Meta眼鏡發表為催化劑，但發表後可能出現比價效應
- **操作建議**: 關鍵觀察未來2-3天能否往上拉，否則十日線下彎形成頭部疑慮

**6. 台達電（6169）- 投信主導**
- 盤中一度漲停，股價接近800元
- 投信積極買進（非外資主導今日漲幅）
- **操作建議**: 800元為心理關卡，拉回至均線附近接比較安全

### 二、投信作帳可搭車標的

#### 1. 日月光（3711）
- **理由**: 投信積極買至漲停，但整體漲幅不多，底型仍在
- **目標價**: 挑戰前波高點
- **停損點**: 跌破近期底部支撐

#### 2. 龍德（6753）
- **股價**: 約185元
- **理由**: 投信剛開始買，絕非短線題材，布局第四季至明年軍工需求
- **目標價**: 持續向上
- **停損點**: 跌破投信進場成本區

#### 3. 盛群（6202）集團（含鵬藝、瑞澤）
- **理由**: 台積電後段製程供應鏈，三家公司整合赴日本、新加坡、美國擴張
- **盛群**: 五層次與基板整合
- **鵬藝**: 水與化學品供應
- **瑞澤**: 半導體氣體配管（一次/二次工程），客戶含台積電、美光
- **目標價**: 今年到明年營運展望佳
- **停損點**: 跌破季線支撐

#### 4. 海華（3694）- 無人機/AI眼鏡/機器人
- **股價**: 約85.8元
- **產業**: 無線通訊模組龍頭
- **亮點**:
  - 無人機方案：常態偵通訊模組 + 特殊鏡頭模組（常態用、夜視用、廣角用）
  - AI眼鏡：台灣少數具高整合度微小化智慧眼鏡模組（支援AR、語音控制、機器翻譯）
  - AI物體辨識：機器人視覺應用
- **投信買進位置**: 在約85-90元區間大買，成本比當前價格略高
- **操作建議**: 短線回到起漲量能區布局，投信成本在此附近
- **目標價**: 挑戰前波高點（約110元以上）
- **停損點**: 跌破近期低點約78元

#### 5. 晴台（暫無代號）- 散熱材料/AI眼鏡材料
- **股價**: 約179元（分盤交易中）
- **產業**: 導電漿龍頭，新切入TIM1（熱界面材料）
- **亮點**:
  - TIM1：直接接觸晶片表面的散熱材料，技術門檻極高
  - 已導入日月光等封測廠
  - 台灣首家本土TIM1供應商，取代國外廠商
  - 新合金材料切入AI眼鏡高頻高速傳輸與高導熱
- **操作建議**: 目前分盤交易過半，後半段可留意。中長線爆發力大
- **目標價**: 分盤交易結束後挑戰新高
- **停損點**: 跌破分盤交易期間低點

### 三、NVIDIA Rubin世代受惠股

#### Rubin規格升級重點
- 首次結合HBM4與三奈米製程
- 性能比GB300提高3.3倍
- 功耗提升至2,300-2,400瓦
- NVIDIA以研發為標準定價，通通給研發等級價格

#### 受惠族群與個股

##### (1) 探針卡/測試 - 旺矽（6223）
- **亮點**: 多數客戶端為第一供應商，積極擴產至200萬針規模
- **產能**: 目前單案3-10萬針，預期訂單可達20倍以上
- **明年EPS**: 47.5元，本益比31.8倍（歷史合理水準）
- **操作建議**: 紅K棒後整理不跌破即可加碼續抱
- **目標價**: 持續創高
- **停損點**: 跌破紅K棒低點

##### (2) 探針卡/測試 - 京元電（2449）
- **亮點**: Rubin系列有機會拿下全部老化測試（Burn-in Test）與最終測試（Final Test）訂單
- **老化測試**: Blackwell到Rubin多出一次老化測試 + 一次最終測試
- 8月營收年月雙增，創37個月新高
- **明年EPS**: 市場預估8.5元（可能不止），本益比約20倍
- **競爭優勢**: 灰達（NVIDIA）越化的三家中，另兩家（越光、愛德萬）測試狀況較弱
- **操作建議**: 跳空上漲後觀察大量高點16.5元是否跌破
- **目標價**: 挑戰前波高點
- **停損點**: 跌破16.5元支撐

##### (3) PCB - 金居（8358）
- **亮點**: 台灣唯一能量產HVLP4等級銅箔的廠商，具獨家定價權
- 加工費有調漲傳聞
- 投信持續加碼，追高照買
- **操作建議**: 跟著投信做，投信大規模轉賣前持有
- **目標價**: 持續創高
- **停損點**: 投信轉為大規模賣超

##### (4) PCB - 複橋（暫無代號）
- **產品**: 高階銅箔基板
- **近況**: 受日東電工擴產三倍消息影響，股價短期走弱
- **操作建議**: 觀察能否突破上方壓力（前波力量出+月線），突破則重新轉強
- **停損點**: 跌破近期低點

##### (5) PCB材料 - 台光電（2383）
- **亮點**: NVIDIA全系列95%主力供應商，韓國斗山搶單影響有限（僅5-10%）
- **操作建議**: 姿態穩健，今日站上月線，有拉回可買進
- **目標價**: 挑戰歷史高點
- **停損點**: 跌破月線

##### (6) 電源供應器 - 光寶科（2301）
- **亮點**: NVIDIA官方公布的HVDC高壓直流輸電供應商（與台達電並列）

- 明年EPS相對台達電本益比更低，補漲空間大

- **股價**: 約145元

- **目標價**: 挑戰歷史高點
- **停損點**: 跌破近期支撐區

##### (7) 散熱 - 建準（2421）/ 奇鋐（3017）/ 雙鴻（3324）
- **建準**: 均熱片領導廠商，新品MCL一體到上蓋水冷版，價格高3-4倍，股價持續推升（本益比偏高）

- **操作建議**: 若追求穩健，偏好奇鋐；建準本益比高但動能最強

## 📈 技術面分析與操作策略

### MACD選股教學（領中獨家）

#### 大盤籌碼面確認
1. **外資期貨**: 均線趨勢向上，空單低於過去10天平均，目前還有約5,000口減碼空間
2. **散戶指標（閃護）**: 做空四天，對大盤是加分
3. **自營商選擇權**: 持續做多（賣賣權收權利金）
4. **外資選擇權**: 持續買買權，與4月股災時完全相反
- **結論**: 籌碼大幅偏多，短線不宜做空

#### 九條件選股法更新
- 條件：最近一個月投信持股超過100檔 + 營收年增超過30%
- 篩選出7檔：建準（2421）、奇鋐（3017）、台積電（2330）、台光電（2383）、廣達（2382）、智邦（2345）、川湖（2059）
- **觀察**: 7檔走勢分歧，並非同步創高，大盤偏向個股表現

#### MACD翻紅操作法
- **鴻海（2317）**: MACD負值開始收斂，接近翻紅 → 若翻紅為起漲點
- **京元電（2449）**: 法人買超 + 營收年增26% + 本益比僅17.8倍 → 等MACD翻紅
- **台積電（2330）**: MACD今日翻紅第一天，若強勢將帶動大盤
- **台達電（6169）**: MACD今日翻紅第一天，期貨價格做多有機會
- **華碩（2357）**: MACD近兩天翻紅，AIPC題材，均線開始往上
- **廣達（2382）**: MACD翻紅，老AI股，本益比低，適合不追高的投資人

#### 鴻海（2317）股息量觀察法
- 股息（期貨）量若跌至五天均量以下，需特別留意（參考2021年案例）
- 目前量能正常，尚未出現警訊

## 📋 投資策略總結

### 短期策略（1-2週）
1. 台積電MACD翻紅為大盤風向球，若持續強勢可偏多操作
2. 投信作帳積極，跟著投信買的標的（日月光、京元電、金居、光寶科）留意
3. 9/17 Meta眼鏡發表前，相關概念股（海華、隱碩、鴻達電）有炒作空間
4. 外資買超東元、鴻海等傳產/AI股，短線跟節奏操作
5. PCB族群MACD負值往下，左側交易者可開始關注黑K棒高點畫線等買點

### 中期策略（1-3月）
1. Rubin世代規格確定，供應鏈開始排時程：探針卡（旺矽、京元電）、PCB材料（金居、台光電）、電源（台達電、光寶科）、散熱（建準、奇鋐）
2. 投信作帳從第三季延伸到第四季，風格更大膽更廣泛
3. 台積電概念集團（盛群、鵬藝、瑞澤）赴海外擴張，中長線看好
4. 晴台（TIM1散熱材料）從今年到明年具中線爆發力

### 風險評估
- 展覽後利多出盡風險（半導體展、軍工展）
- 鴻達電眼鏡概念需觀察十日線是否下彎
- PCB族群短期技術面偏弱（MACD負值），需等訊號確認
- 日東電工擴產對複橋等銅箔基板廠的中期影響
- 高本益比股票（建準）追高風險

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **Rubin** | NVIDIA下一代GPU架構，首次結合HBM4與三奈米製程，性能比GB300提高3.3倍 |
| **老化測試（Burn-in Test）** | 將晶片在高溫環境下運行一段時間，測試其耐熱能力與穩定性，篩選出不良品 |
| **HVLP4** | 超低損耗銅箔基板等級，用於高頻高速PCB，NVIDIA新世代GPU需求的關鍵材料 |
| **HVDC** | 高壓直流輸電，AI伺服器資料中心使用的電力傳輸方式，效率高於傳統交流 |
| **TIM1（Thermal Interface Material 1）** | 熱界面材料第一層，直接接觸晶片表面的散熱材料，技術門檻極高 |
| **投信作帳** | 投信基金經理人在季度末（如9月底）前積極操作，以提升季度績效的行為 |
| **MACD黃金交叉** | MACD指標從負值翻正（柱狀體由綠轉紅），通常視為多方訊號 |
| **分盤交易** | 新上市/上櫃股票在初期採取的分段撮合交易方式，限制漲跌幅 |
| **MCL一體到上蓋水冷版** | 散熱新技術，將均熱片與水冷上蓋整合為一體，提升散熱效率，價格為傳統的3-4倍 |
