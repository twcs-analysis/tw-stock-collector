## 📊 市場總體觀察

### 台幣匯損——三大產業衝擊

| 產業 | 衝擊程度 | 說明 |
|------|----------|------|
| 台積電 | 中度 | Q2業績展望假設匯率32.25，實際已到28字頭；每升值1%減損營業利率0.4%，升值10%=減損4% |
| 壽險業 | 災難級 | 5月單月稅前虧損1,066億元（史上最慘），1-4月獲利全數吐光 |
| 機械業 | 嚴重 | 擔心出現倒閉潮，出口型企業幾乎無避險（「自然避險就是沒有避險」） |

### 國際局勢——三大變數

#### 1. 以伊衝突：暫停不等於結束
- **12天戰爭**後按下暫停鍵，但矛盾完全沒有解決
- 伊朗加速研發核武（「2000顆飛彈不如一顆核子彈」）
- 以色列強化鐵穹防空系統
- **對金融市場影響有限**：除非涉及核武，否則再來一次也不會有太大衝擊

#### 2. 對等關稅：真心要課，不是隨便喊喊
- 7月8~9日為90天暫緩期大限，川普暗示可能再延長
- 川普宣稱與中國簽署「貿易協議」→白宮澄清為「框架協議」（僅為談判起點）
- **歐盟**：對18.5%關稅要報復，不會讓步
- **日本**：談判11輪陷僵局，汽車關稅25%無解，另有安保協議（軍費GDP 2%→5%）難題
- **延後≠好事**：突顯川普是真心要達成對美國有利的協議，不會輕易放手

#### 3. 美國減稅法案
- 預計7月4日通過
- 移除第89條（報復性課稅條款），利好美股
- 同步提高國債上限，美國繼續發債→不利美債投資人
- **川普搞半天，還是走拜登的老路——繼續發債、繼續破表**

### 聯準會——降息預期升溫

| 日期 | 預期 | 機率 |
|------|------|------|
| 7月3日 | 按兵不動 | 七成以上 |
| 9月 | 首次降息 | 70%（本週從50%→60%→70%快速升溫） |
| 10月 | 再降一次 | 市場定價中 |
| 12月 | 又再降一次 | 市場定價中 |

- **川普壓力**：準備3~4位人選接替鮑威爾，影子主席效應浮現
- **SLR調降**：可能降低補充槓桿比率，銀行釋出準備金買入長天期美債，增加市場流動性
- **那斯達克強勢**：與降息預期升溫高度相關

### 景氣燈號

- **國發會最新公佈**：台灣景氣燈號從黃紅燈轉為綠燈
- **變化原因**：批發零售與餐飲業營業額從紅燈直接降為綠燈，扣兩分變綠

### 其他重要風險

- **日圓套利交易**：全球借低利率貨幣（日圓、台幣）投資美國資產的套利交易規模龐大，一旦反轉將引發類似去年8月的黑天鵝
- **美國經濟放緩**：高利率壓制消費、商用不動產風險持續、企業多以現金回購股票而非實際投資
- **川普護盤**：刻意維護美股榮景（炸伊朗專挑週末、隨時救市），但經不起真正的風吹草動

## 📈 技術面分析與操作策略

### 輝達突破後的對應分析

- **輝達**：經過約13個月的大箱型整理（105~150美元），6月終於突破創新高
- **微軟**：Copilot帶動，股價也在創高，六月走勢比輝達更強
- **Palantir**：軍事AI應用，2024~2025兩年漲約8倍，六月缺口出來後完全不回頭
- **結論**：軟體＞硬體的趨勢在2025年5月後確立

### 個股技術面

- **台積電**：1,080元為波段高點，ADR距新高不遠，國內投資人保守形成壓力。若整理超過一個月，7月9日後可能加速補漲
- **緯創**：對應輝達位置在箱型上緣，突破機率增加
- **定穎**：週線雙底完成，打底兩年後開始切入AI，從無到有的起漲點

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| 對等關稅 | 川普政府對各國課徵與該國對美國相同稅率的關稅，原定7月9日為90天暫緩期大限 |
| 框架協議 | 雙邊同意的原則性文件，僅為談判起點，尚需後續落實具體條款，不等於正式貿易協議 |
| SLR（補充槓桿比率） | 美國銀行的資本適足率指標，類似台灣的存款準備率。降低SLR可讓銀行釋出更多資金購買國債 |
| 日圓套利交易 | 借入低利率日圓轉投資美國等高收益資產賺取利差。日圓升值時將引發大規模平倉潮 |
| ASIC（特殊應用積體電路） | 為特定用途客製化設計的晶片，如Google TPU、Amazon Trainium。AI推論需求帶動高速成長 |
| IP（矽智財） | 半導體設計的智慧財產權模組，可授權給其他公司使用以加速晶片設計。創意、世芯為代表 |
| BBU（備用電池單元） | Backup Battery Unit，用於AI伺服器不斷電系統，確保運算不中斷 |
| Palantir | 美國AI軟體公司，利用AI分析協助軍事與政府決策，2024~2025年股價漲約8倍 |
| 第89條 | 美國減稅法案中的爭議條款，允許對不友好國家的投資課徵報復性稅金，已被移除 |
