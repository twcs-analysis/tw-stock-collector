## 📊 市場總體觀察

### 川普關稅與原物料避險

#### 關稅戰升溫
- 川普在4月2日「解放日」前開了第一槍，宣布汽車關稅
- 市場預期4月2日將有更多關稅措施推出
- 資金從股市流向避險商品（貴金屬與一般金屬）

#### 資金避險方向
- **黃金**: 避險需求推升金價走高
- **銅**: 銅價創新高，LME倫敦金屬交易所銅庫存大幅減少
- **鋼鐵**: 抗跌族群，大成鋼、高新鋼、中鋼等走強
- **重電/電纜**: 同步受惠銅價上漲與電價調漲題材

#### 通膨與油價分析（張星觀點）
- 川普第一任期間加關稅時，通膨實際是往下走的
- 關鍵在於**壓低油價**：OPEC協議 + 增產壓制油價
- 西德州原油期貨持續受壓，油價上漲空間有限
- **結論**: 本波通膨上升是短線預期，非結構性改變（與2021年供需失衡不同）
- 原物料行情呈現「一段一段」的短波行情，而非大行情爆發

### 台股盤面觀察

#### 逆勢抗跌族群
- **金屬概念股**: 銅、鋼鐵相關個股走高
- **重電/電纜類股**: 受銅價上漲與電價調漲雙重題材帶動
- 歷史性抗跌走高的個股多為金屬概念股

#### 大盤風險
- 台幣持續貶值，已逼近33元關卡
- 外資期貨空單增加，需觀察是否突破4萬口
- 若5日均線3天內未站回，最差將下探整理
- 明天（3/28）多檔權值股若續跌將破近年低點（台積電、廣達、鴻海）
- 成交量持續萎縮，反彈力道不會太強

## 💼 產業分析與投資建議

### 一、鋼鐵族群（張星分析）

#### 產業背景
- **美國鋼鐵需求**: 川普「美國優先」政策推動，但美國成本高，實際需求提升有限
- **中國鋼鐵需求**: 房地產從去年9月開始資金大水灌溉，房市止穩跡象，新訂單開始往上
- **需求結構**: 建築用鋼材（鋼筋）+ 消費型鋼材（汽車、冰箱等消費電子）
- **今年趨勢**: 房地產需求僅做複縮止穩，消費端需求已開始成長

#### 選股邏輯
- 優先選擇**台灣內需導向**的鋼鐵股，波動較小
- 避免過度偏重**美國出口導向**的標的（受關稅波動影響大）
- 台灣建築交屋潮帶動鋼鐵需求（前幾年預售屋陸續交屋）

#### 個股推薦

| 股票 | 殖利率 | 股價淨值比 | 亮點 | 風險 |
|------|--------|-----------|------|------|
| 東和鋼鐵 | 6.82% | 1.1倍 | 月營收成長、高殖利率、台灣內需建築為主 | - |
| 豐興 | 4% | 低 | 殖利率穩定、台灣內需鋼鐵 | - |
| 春雨 | 1.6萬（高殖利率） | 低 | 股價僅二十幾元、殖利率高 | 股本較小 |
| 中鋼/中鋼構 | - | - | 今日上漲 | 去年獲利不穩定、外銷為主 |

- **首選**: 東和鋼鐵、春雨 - 高殖利率 + 台灣內需 + 股價淨值比低
- **觀望**: 中鋼 - 獲利不穩定，受國際鋼價波動影響大

### 二、銅價概念股（張星 + 健成分析）

#### 銅價走勢分析
- LME倫敦金屬交易所銅庫存大幅減少
- 現貨銅從倫敦運往紐約套利（因預期美國加徵25%關稅）
- 紐約銅期貨價格持續創新高（一度逼近10,000美元/噸）
- **關鍵時間點**: 4月2日後若紐約銅期貨合約到期，價差可能收斂，漲勢可能結束

#### 個股分析

| 股票 | 類型 | 評價 | 操作建議 |
|------|------|------|---------|
| 第一銅 | 銅價概念股 | 股性活潑但毛利率低、EPS不佳 | 短線題材搶短，銅價創新高時才漲，追高風險大 |
| 金居 (6164) | 銅箔基板 | 業績有支撐、今年度銅價上漲可轉嫁消費者 | 長線穩健，銅價概念 + 重電概念 |
| 台燿 (6274) | 銅箔基板 | 業績本身就很好、今日收平盤抗跌 | 跌深後有支撐，觀察是否打底完成 |
| 亞力 (1514) | 重電 + 電纜 | 有重電概念 + 電價概念 | 今日盤面往上拉，穩健標的 |

#### 銅價投資重點提醒
- 銅價衝高主因是套利行為（倫敦運往紐約），並非真正實體需求大增
- 4月2日後套利空間可能消失，漲勢可能告一段落
- **投資銅的概念**: 選擇有業績支撐的個股（金居、台燿），避免純投機（第一銅）

### 三、散裝航運股（張星分析）

- BCI海岬型指數已開始飆升
- 航運法說會對今年展望正面，面租都有正向反應

#### 投資邏輯分類
- **貨櫃三雄**（長榮、陽明、萬海）: 高殖利率 + 高穩定性，吸引退休族群穩健買盤
- **散裝航運股**: 與原物料族群連動，資金輪動操作
- 兩類買盤不同，不會互相排擠

### 四、電價調漲與重電概念股（健成分析）

- 美國電網升級也在同步進行

#### 重電股技術面分析 - 華城 (1519)
- **前高**: 約1,030元（去年7月高點）
- **前低**: 478元
- **現價**: 約520元
- **技術面**: 突破下降趨勢線，量縮整理後若出量往上攻，趨勢扭轉
- **反彈目標**: 高點下來的跌幅反彈一半，機會存在
- **停損**: 前低478元不能破，破即退場

#### 電纜/電線概念股
- 銅價上漲 + 電價調漲雙重題材
- **華新 (1605)**: 觀察重點，但注意融資快到解約期限，籌碼風險
- **大亞 (1609)**: 籌碼較好，銅價概念首選觀察標的
- 低價二線電纜股有機會跟漲

#### 操作策略
- **中長線**: 重電股是焦點，清明節前後若避風港效應 + 電價確定調漲 = 至少受惠
- **短線**: 可先用電纜股做短沖（股性活潑、銅價題材）
- **順序**: 華城先動 → 中興電跟進 → 亞力跟漲 → 士電最後

## 📋 投資策略總結

### 第二季投資主軸

1. **原物料避險**: 黃金、銅、鋼鐵為資金避險方向
2. **重電/電網**: 電價調漲 + 台美電網升級計劃 = 中長線趨勢
3. **散裝航運**: 俄烏和平協議預期 + BCI指數回升
4. **內需鋼鐵**: 台灣交屋潮帶動建築鋼鐵需求

### 操作原則

1. **不追高原物料**: 銅、黃金短線衝高可能是套利行為，非實體需求
2. **選有業績的股票**: 盤面不穩定時，業績支撐是安全邊際
3. **關注股價淨值比低的標的**: 風險有限，下檔空間小
4. **等待4月2日關稅明朗化**: 變數未消除前，反彈力道受限

### 風險控管

- **停損紀律**: 破前低即退場（如華城破478元）
- **資金控管**: 大盤不穩定，不宜重壓
- **時間風險**: 4月2日解放日前，市場波動加大
- **匯率風險**: 台幣續貶將加速外資出走

1. **張星**: 「川普加關稅是手段，但要控制通膨的關鍵是壓低油價。油價壓下來，通膨就壓下來。」
2. **張星**: 「原物料行情是一段一段的，不是大行情爆發。長態度的時候去追高，要先搞清楚是真實需求還是資金短期避險。」
3. **張星**: 「東和鋼鐵跟春雨的法說會都提到一個重點：今年台灣鋼鐵建築需求不錯，跟房屋賣得好沒有絕對關係，是跟前幾年賣的現在要交屋有關。」
4. **張星**: 「散裝航運今年度最大的利多，可能就是俄烏和平協議。簽下去之後，運費會再飆升一段。」

6. **健成**: 「華城從1,030跌到478，反彈一半到750都有機會。但478不能破，破了就先退場。」

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| 解放日 | 川普預告4月2日將對全球實施對等關稅的日期 |
| LME | 倫敦金屬交易所（London Metal Exchange），全球最大的金屬現貨交易所 |
| BCI海岬型指數 | 波羅的海海岬型運費指數，反映大型散裝船（鐵礦砂、煤炭）的運費趨勢 |
| 股價淨值比 | 股價除以每股淨值，低於1代表股價低於公司帳面價值，具安全邊際 |
| 殖利率 | 每股股利除以股價，衡量現金股利回報率 |
| 強韌電網計劃 | 台灣十年五千億的電網升級計劃，包含變壓器、配電設備全面更換 |
| 套利交易 | 利用不同市場間的價差進行低買高賣獲利，如倫敦銅運往紐約套取關稅價差 |
| 電價審議委員會 | 每半年召開一次，決定下半年電價調整幅度的官方委員會 |
| 融資解約期限 | 融資買進股票後到期需還款的時間，到期前可能出現賣壓 |
