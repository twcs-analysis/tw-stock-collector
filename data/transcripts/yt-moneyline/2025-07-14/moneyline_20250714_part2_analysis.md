## 💼 產業分析與投資建議

### ASIC vs GPU vs CPU 完整比較

#### GPU vs ASIC 比較

| 比較項目 | GPU | ASIC |
|---------|-----|------|
| **類型** | 通用型 | 客製化/特殊目的 |
| **主要用途** | AI訓練、影像處理、遊戲繪圖 | AI推論、挖礦、特定應用 |
| **效能** | 性能很強但非專用 | 單位性能最強（只做一件事） |
| **能效比** | 中等，功耗較高 | 最高，功耗較低 |
| **價格** | 單價較高（輝達已開發好） | 初期開發成本高，量產後單價低 |
| **彈性** | 高度彈性，可調整 | 固定用途，無法改變 |
| **開發時間** | 直接購買即可 | 需6-24個月設計驗證 |
| **壽命/可更新** | 可透過軟體/韌體升級 | 升級需重做晶片 |
| **年複合成長率** | 13-28%（高速運算） | **38%以上（高速運算ASIC）** |

#### CPU vs GPU vs ASIC 運算原理

**CPU**: 序列運算 → 先算左上角、再算右上角、再算左下角、再算右下角 → 最慢
**GPU**: 平行運算 → 四個角同時算 → 速度快，但每次還需跑回記憶體
**ASIC**: 矩陣運算 → 含HBM高速記憶體在內 → 不需每次跑回記憶體，速度最快

#### ASIC 市場趨勢
- 從去年開始AI訓練中心佈局完成，現在開始往**推論方向**走
- 推論需求增加 → ASIC用量上升
- 成長性：ASIC（38%+）遠高於GPU（13-28%）
- **結論**: ASIC是AI產業下一個爆發點

### 補漲股操作三部曲（遇堂分析）

#### 選股四大面向

1. **產業面**: 找趨勢明確的產業（CPO、PCB、ASIC、半導體設備）
2. **技術面**: 區間整理或打底型態，底部放量突破壓力區
3. **籌碼面**: 法人領先卡位，投信或外資連續買超
4. **催化劑**: 新產品、新技術、新訂單尚未反映在股價

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **ASIC** | Application-Specific Integrated Circuit，特殊應用積體電路，為特定用途設計的晶片 |
| **GPU** | Graphics Processing Unit，圖形處理器，通用型平行運算晶片 |
| **CPU** | Central Processing Unit，中央處理器，序列運算為主 |
| **HBM** | High Bandwidth Memory，高頻寬記憶體，用於AI晶片的高速存取 |
| **NRE** | Non-Recurring Engineering，一次性工程費用，ASIC設計初期的開發成本 |
| **TPU** | Tensor Processing Unit，Google開發的ASIC晶片，專用於AI運算 |
| **CPO** | Co-Packaged Optics，共封裝光學，下一代光通訊技術 |
| **ACC** | Active Copper Cable，主動式銅纜，用於伺服器機櫃連接 |
| **HVLP4** | 高階銅箔材料規格，傳輸速率達224 GBPS |
| **補漲股** | 同族群中尚未跟上漲勢的個股，具備追漲潛力 |
