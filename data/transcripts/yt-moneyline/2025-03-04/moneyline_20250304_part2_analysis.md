## 🌍 市場總體觀察

### 高股息概念股季節性行情

#### 三月份高股息行情啟動
- 年報陸續公佈，市場積極押寶高配息個股
- 三月份為高股息概念股最熱鬧的月份
- 不是高獲利就一定會高配息，需注意配息率與公司文化

#### 高配息的三大陷阱
1. **賺多配少型**: 如上盈配息率僅30~43%，台積電約20~30%（因需保留資金擴廠）
2. **帳面獲利非現金型**: 如華新麗華2020年EPS 5.45元，但多為轉投資收益，實際僅配1.8元
3. **稅務考量型**: 如金層(2524)蔡家人為大股東多年不配息；龍巖因董事長持加拿大籍稅率高而不配息

### 政府基金進場動態（郡源觀點）

#### 勞動基金
- **總規模**: 1,520億元
- **絕對報酬**: 800億元（主動選股打帶跑，目標6%獲利即走）
- **相對報酬**: 720億元（被動追蹤大盤指數，長抱權值股）
- **3月4日**: 已有200億元絕對報酬資金播款入場

#### 退撫基金
- 另有170億元
- 合計勞動基金+退撫基金 = 1,690億元

#### 八大官股券商
- 昨日起已開始進場買進
- 買進量為開紅盤以來最大買超量
- 主要買進: 台積電、聯發科、鴻海、世界先進、聯電

#### 壽險基金
- 國泰、富邦、元大、台灣中國信託等券商買進
- 屬相對報酬型壽險基金，持有期較長
- 長抱鴻海、廣達、台積電者的好朋友

### 櫃買指數關鍵觀察（郡源觀點）

#### 三月份為關鍵月份
- 櫃買已拉過季線扣底後拉回
- 三月底收盤能否站在季線上方非常重要
- 若站上季線: 後續仍有行情
- 若跌破季線: OTC賣壓將比大盤重，且通常比大盤晚一個月見低點

#### 歷史參考: 2022年第一季
- 當時OTC反攻過不了季線，進入四月份死亡交叉彎頭向下
- 整個櫃買指數出現一個回檔，第一低點比大盤晚了一個月

#### 三月份潛在風險
- 台積電3/18除息後可能出現拉積盤（只拉台積電，其他股下跌）
- 中小型股資金將被排擠
- 護盤資金中的絕對報酬部分也會打帶跑（賺6%就走）

## 💼 產業分析與投資建議

### 一、高股息概念股（冠軍推薦）

#### 1. 東科 (5225)
- **產業**: 聲霸（Soundbar）、耳機產品、骨聽器
- **主要客戶**: 三星
- **EPS**: 12.68元
- **配息**: 10.47元（配息率83%）
- **殖利率**: 約7.72%（以今日股價計算）
- **特色**: 三月董事會後即公告除息，四月就發股利
- **展望**: 公司法說會表示今年訂單超過去年，未來極極樂觀
- **操作建議**: 殖利率7.72%遠超過代操要求的6%，可安心持有

#### 2. 美律 (2439)
- **產業**: 揚聲器、助聽器、麥克風產品
- **EPS**: 9.26元（五年新高）
- **配息**: 7.3元（配息率79%，創近年新高）
- **殖利率**: 約6.3%
- **法說會亮點**（3/3召開）:
  - 第一季營收比去年同期微幅成長
  - 揚聲器年增成長
  - 美國OTC助聽器市場開始發酵
  - 麥克風產品大幅成長（加入新產品出貨）
  - 毛利率持續改善: Q1 12.5% → Q4 13.86%
- **中國境外產能**: 從30%提升至50%（應對關稅政策）
- **股價**: 約100元附近整理已久，尚未回到去年7~8月的142元高點
- **操作建議**: 基本面改善+殖利率6.3%+法說會利多，可抱著等除息

#### 3. 廣達 (2382)

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **配息率** | 公司將獲利分配給股東的比率（配息/EPS），越高代表越大方 |
| **殖利率** | 每股股息除以股價，衡量投資報酬率的指標 |
| **絕對報酬** | 政府基金主動選股操作方式，追求固定目標報酬率（如6%） |
| **相對報酬** | 政府基金被動追蹤指數操作方式，績效對標大盤 |
| **OTC櫃買指數** | 台灣櫃檯買賣中心指數，代表中小型股表現 |
| **季線扣底** | 季線（60日均線）計算起始點的位置，影響均線方向 |
| **死亡交叉** | 短期均線由上往下穿越長期均線，為空頭訊號 |
| **BDI指數** | 波羅的海乾散貨指數，衡量散裝航運市場景氣 |
| **月KD黃金交叉** | 月線KD指標K值由下往上穿越D值，為中期多頭訊號 |
| **Stargate計畫** | OpenAI主導的AI基礎建設計畫，第一期投資1,000億美元 |
