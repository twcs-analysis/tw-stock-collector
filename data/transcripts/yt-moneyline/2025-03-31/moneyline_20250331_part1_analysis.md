## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| 對等關稅 | 川普政府依各國對美國商品課徵的關稅稅率，對等課徵相同水準的關稅 |
| 融資斷頭 | 投資人以融資方式買進股票，當股價下跌導致維持率不足，券商強制賣出 |
| 景氣對策信號 | 國發會每月公布的經濟指標，以燈號表示景氣狀態（藍/黃藍/綠/黃紅/紅） |
| 倒掛K線分析法 | 將K線圖上下翻轉，以做多思維分析空頭走勢，幫助不習慣看跌勢的投資人 |
| 跳空缺口 | K線圖上因價格跳空而產生的缺口，通常代表強烈的多空轉換訊號 |
| 錯殺股 | 因系統性風險被無差別賣出的個股，基本面並未受到實質影響 |
| 苦盡甘來股 | 經歷產業轉型陣痛期後，營運開始出現結構性改善的公司 |
