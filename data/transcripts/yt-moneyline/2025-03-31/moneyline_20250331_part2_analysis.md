## 🌍 市場總體觀察

### 美國關稅政策全貌（君老師）

#### 川普馬卡新政的脈絡
1. **對內**: 解決美國赤字與36兆美元國債問題
   - DOGE（政府效率部門）大砍浪費與貪腐支出
   - 9兆美元國債在今年底到期或再融資
   - 希望壓低殖利率以降低國債利息負擔
2. **對外**: 改善貿易逆差（去年高達1.21兆美元）
   - 當堂五國（中國、台灣、德國、日本等）賺走美國大量外匯
   - 180天內對各國關稅做評估報告（首批4月1日）
   - 考量項目：關稅、非關稅壁壘（技術移轉、準入規定）、匯率操縱

#### 先救債市再救股市
- **國債價格走勢**: 川普就任以來，國債價格上漲（殖利率下降）
- **股市走勢**: 納斯達克指數大跌
- **邏輯**: 先不破產（降低利息支出）→ 再發展經濟
- **參考案例**: 阿根廷米雷的休克療法改革（前年底上任，經歷衰退後今年強勁正成長）

#### 美國個人收入與消費
- **個人收入月增率**: +0.8%（超預期，一年多來新高）
- **個人消費支出**: +0.4%
- **解讀**: 收入增加但消費保守 → 美國人開始儲蓄，因應不確定性

## 💼 產業分析與投資建議

### 汽車零組件產業（直東）

#### 汽車關稅影響評估
- **4月3日起**: 進口車全面課徵25%關稅（整車+引擎+變速箱+驅動裝置）
- **在美國製造者免課**: 川普鼓勵回美製造
- **美國汽車自製率**: 約40-50%，進口約50%
- **皮卡稅歷史**: 60年前「雞肉稅」保護下，美國皮卡自製率100%且最賺錢

#### 副委託股票提醒
- **必須避開**: 在德國股市交易的福斯、韓國現代、日產等整車廠
- 這些整車廠對美銷售占比極高（如福斯約80%），關稅衝擊最大

#### 美國消費者趨勢
- 新車銷售下滑 → 消費者轉向二手車市場（AM市場）
- 新車貸款年限拉長至近6年，違約率上升
- 二手車零組件需求反而有機會

#### 推薦個股

**1. 金剛（1580）- 鈦合金/軍工**
- **投資邏輯**: 生產鈦合金材料，供應軍工國防+美系飛機引擎大廠
- **北美布局**: 今年延伸至北美市場，自評可吃到中美關稅戰轉單效應
- **獨特性**: 全球生產海綿鈦的廠商極少（中國、烏克蘭/俄羅斯）
- **營收**: 今年應相對穩健，法說會提到獲得美系飛機引擎訂單
- **技術面**: 軍工股上漲時未跟上，目前反而在相對低點
- **操作建議**: 軍工股中較安全的標的，兼具關稅受惠與國防題材

**2. 東陽（1319）- 汽車AM零組件龍頭**
- **投資邏輯**: AM（售後維修市場）零組件龍頭，2017年川普1.0時已積極擴廠
- **AM市場利多**: 車險大廠State Farm 2023年改變規則，擴大採用白牌零組件
- **白牌占比**: 目前美國僅5-10%，成長空間巨大
- **籌碼面**: 外資連8買
- **技術面**: 沿月線上攻，來到月線支撐區
- **存貨營收比**: 正常水準，為產業龍頭

**3. 耿鼎（1524）- 汽車AM零組件**
- **投資邏輯**: 與東陽同業，存貨營收比稍高
- **附加價值**: 若原物料（銅、鋼）漲價，高庫存反而有利（低成本庫存+高售價）
- **籌碼面**: 外資近期轉買
- **操作建議**: 作為東陽的對照組，存貨營收比較高的標的

**4. 伸興（1558，推測）- 車用擴建零組件**
- **投資邏輯**: 主要供應中國農業機具零組件，正轉型美國二手車市場
- **美國投產計畫**: 已規劃在美國設廠，符合「在美製造」趨勢
- **存貨營收比**: 零組件中較高，後續若漲價有利
- **籌碼面**: 股價下跌時外資反而在買方
- **操作建議**: 成交量較小，留意流動性

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| 雞肉稅（Chicken Tax） | 1960年代美國對歐洲皮卡課徵25%關稅的報復性措施，至今仍在，保護美國皮卡產業 |
| AM市場（Aftermarket） | 汽車售後維修零組件市場，相對於原廠OEM零件 |
| PMI（採購經理人指數） | 衡量製造業景氣的領先指標，50以上為擴張、以下為收縮 |
| 存貨營收比 | 存貨除以營收的比率，正常越低越好，但原物料漲價時高存貨反而有利 |
| 滯脹（Stagflation） | 經濟停滯與通膨同時發生的狀態，央行左右為難 |
| 對等關稅 | 川普依各國對美關稅水準，對等課徵相同稅率的政策 |
| GDPNow | 亞特蘭大聯儲的即時GDP預測模型，隨數據更新即時調整 |
| 匯率操縱國 | 美國財政部認定刻意壓低匯率以取得貿易優勢的國家 |
