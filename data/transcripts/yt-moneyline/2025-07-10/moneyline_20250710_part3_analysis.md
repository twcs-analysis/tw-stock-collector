## 📈 技術面分析與操作策略

### 外資期貨結算研判（遇恨分析）

#### 外資空單現況
- 外資台指期空單：每天創歷史新高（5.5萬→5.6萬→5.7萬→5.8萬口）
- **但**: 外資現貨同步大買，空單與現貨對沖
- **選擇權**: 外資賣權部位為負值（當莊家），大跌機會不大
- **歷史規律**: 外資當賣權莊家時，行情不太會跌，甚至盤整偏多

#### 七月合約結算情境分析

| 情境 | 機率 | 描述 | 對應策略 |
|------|------|------|---------|
| **情境一：偏多** | 60%+ | 月線之上站穩，挑戰23,000點 | 選權值股（台積電、廣達、鴻海）、AI領頭羊 |
| **情境二：盤整** | 30% | 攻到前高附近休息，底部不破 | 資金輪動快，選股重於選市，低位階補漲股 |
| **情境三：偏空** | <10% | 跌破月線往下 | 需國際重大利空配合，機率很低 |

#### 結算關鍵觀察指標
1. **七月結算收盤位置**: 收紅棒 → 八月開始不會太差；收十字線 → 八月初偏弱
2. **外資期貨空單**: 若開始減少 → 真正多頭啟動訊號
3. **外資賣權部位**: 維持負值（莊家角色）→ 大跌機率低；轉正 → 需警戒

#### 中長線訊號
- 外資大台空單高位不減 → 真正大多頭尚未啟動
- 空單開始減少甚至翻多時 → 才是大多頭確認
- 目前：盤整偏多，上攻前高壓力大，追高需謹慎

### 總經風險觀察

#### 美國降息預期變化
- **7/30 FOMC**: 93%維持不動
- **9月降息**: 機率從七成多下降
- **10月降息**: 僅四成
- **全年**: 可能降兩次，但機率都未到七成
- **關鍵**: 美國經濟強勁不支持降息，鮑威爾傾向觀望

#### 台灣景氣燈號
- 6月底公布5月景氣燈號：從黃紅燈轉為綠燈
- **歷史經驗**: 黃紅轉綠，中長線不太好
- **但**: 5月景氣低迷受4月恐慌影響，6月可能回升至黃紅燈
- **樂觀情境**: 僅一顆綠燈就回升 → 盤整偏多
- **悲觀情境**: 關稅實施後持續轉綠 → 需非常緊張

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **TACO交易** | Trump Always Chickens Out（川普總是退縮），基於川普關稅威脅後退縮的規律進行的交易策略 |
| **外資賣權莊家** | 外資在選擇權市場賣出賣權（Put），收取權利金，當行情不大跌時獲利，代表外資不看大跌 |
| **FOMC** | Federal Open Market Committee（聯邦公開市場委員會），美聯儲決定利率政策的機構 |
| **景氣燈號** | 台灣國發會每月公布的景氣綜合判斷，紅燈=過熱、黃紅燈=穩定偏熱、綠燈=穩定、藍燈=低迷 |
| **月線** | 20日移動平均線，中期趨勢指標，站上月線代表中期偏多 |
| **換倉日** | 期貨合約到期前將部位轉移至下月合約的日期 |
| **EIA** | 美國能源資訊署，定期公布原油產量與庫存數據 |
| **COMEX** | 紐約商品交易所，美國銅期貨主要交易場所 |
| **LME** | 倫敦金屬交易所，全球銅現貨與期貨主要交易場所 |
| **大減稅法案** | 川普推動的減稅法案，市場擔心擴大財政赤字影響美債 |
