## 🌍 市場總體觀察

### 台股市況分析

#### 大盤表現
- **收盤表現**: 中場上漲166點，盤中最高來到22,693點
- **成交量**: 3,248億元（量能持續偏低）
- **特色**: 指數連續好幾天都收在盤中高點附近

#### 法人動向
- **三大法人**: 同步站在買方
- **外資**: 現貨買超超過100億元，期貨空單終於回補2,300多口
- **台指期空單**: 雖然有所降溫，但外資期貨空單仍居歷史高位（5.5萬～5.8萬口）

#### 市場特殊現象
1. **漲停家數增加**: 約22家漲停，僅2家跌停
2. **創歷史新高家數增加**: 多檔個股股價創歷史新高
3. **台幣連續五天降溫**: 央行干預匯率效果顯現，對台股資金行情有正面影響

### 美股影響

#### 輝達（NVIDIA）創歷史新高
- **市值**: 盤中突破全球第一家公司市值超過**4兆美元**
- **外資目標價**:
  - 微軟報告：市場逼近200級，供不應求
  - Rub Capital：目標價從175美元上調至250美元
  - 若股價到175美元 → 市值穩4兆美元
  - 若到250美元 → 市值達6兆美元

#### 高盛最新報告 - 光收發模組需求大增
- **H100/GB200**: 每顆搭配3顆 800G 光收發模組
- **GB300**: 每顆搭配4～5顆光收發模組
- **特定S系列**: 搭配到8顆
- 高盛上調光收發模組銷售預估：今年+10%、明年+58%
- 市場規模：今年成長68%、明年成長58%

### 二、台積電（2330）- 匯損壓力下中性看待

#### 六月營收解讀
- **六月營收**: 2,637億元，月減17.7%（近四個月新低）
- **第二季營收**: 符合財測目標
- **上半年**: 年增約40%（遠優於公司全年預估的20幾%成長）
- **美元計價**: 表現不錯，年增26.9%
- **ADR**: 已衝到歷史新高一段時間

#### 股價表現
- **收盤**: 1,100元（四個月來第一次收在1,100元）
- **技術面**: 力道上沒有很強，量能縮小
- **短期策略**: 區間來回操作，接近前高可先獲利了結
- **目標價**: 短線壓力在前高附近
- **停損點**: 跌破1,050元需留意

#### 關鍵風險
- 7月17日大立光法說會將定調匯損影響
- 第二季財報（8月公布）匯損壓力存在
- 台幣大幅升值影響下半年毛利率

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **矽光子（Silicon Photonics）** | 利用矽基材料製造光學元件的技術，可實現高速光通訊，是AI伺服器下一代關鍵技術 |
| **CPO（Co-Packaged Optics）** | 共同封裝光學，將光學元件與晶片封裝在一起，提升傳輸效率與降低功耗 |
| **光收發模組** | 負責將電訊號轉換為光訊號進行高速傳輸的模組，800G為目前主流規格 |
| **GB300** | NVIDIA下一代AI加速器，需搭配更多光收發模組 |
| **TACO交易** | Trump's Always Chickens Out，指川普在關稅威脅後總是退縮的交易策略 |
| **年化配息率** | 將單次配息金額換算為全年配息率，月配型ETF需乘以12 |
| **ROE** | 股東權益報酬率，衡量公司運用股東資金創造獲利的效率 |
| **ESG** | 環境（Environmental）、社會（Social）、治理（Governance）的企業永續評估指標 |
