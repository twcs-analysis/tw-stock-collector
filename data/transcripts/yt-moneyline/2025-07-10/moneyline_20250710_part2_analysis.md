### 二、中砂（1560）- 鑽石碟龍頭，穩定成長股

#### 產業邏輯
- 二代奈米晶圓需背面供電（BSPDN），需要化學機械研磨（CMP）曝光
- 八寸晶圓鑽石碟可磨8,000次，十二寸僅2,000～3,000次 → 需求增4倍
- 二代奈米更僅能磨600次 → 需求增16倍
- 中砂在此領域市占率從54%提升至80%
- 競爭者極少，技術護城河深

#### 財務數據
- **今年EPS預估**: 9.57元
- **收盤價**: 357元（約37倍本益比）
- **營收**: 穩定成長（非爆發性）
- **產能擴張**: 二代奈米從2萬片 → 5萬片 → 明年9萬片

#### 操作建議
- **定位**: 穩定成長型，非短線飆股
- **目標價**: 隨營收成長逐步墊高，長線看400元以上
- **停損點**: 跌破300元（季線支撐）
- **策略**: 拉回找買點，長期持有

### 三、先進封裝 - WNCM技術革命

#### 技術突破
- **傳統CoWoS**: 一次只能封裝一顆晶粒，需要載板與中介層
- **WNCM（Wafer-level Non-Carrier Module）**: 不用載板與中介層，更薄、多晶粒整合
- **單價提升**: 從1,000～1,800元提升至3,000～4,000元（增加一倍以上）

### 四、無人機產業 - 台灣技術崛起

#### 產業現況
- **雷虎**: 6月營收年增72%，月增5.8%，創新高
- 三月赴歐洲參展拿到訂單，台灣自主設計（不用中國零件）
- GPS定位與晶片發射精準度達高水準
- **全球無人機市場**: 2025年約731億 → 2030年1,636億（年複合成長14%）

#### 技術亮點
- AI自主導航、全自動能力
- 完成60公里長距離航行測試
- 軍用與商用（物流配送、農業巡視、建築測繪）雙軌發展

#### 中國管制影響
- 中國將漢翔等廠商列為管制廠
- 影響有限：台灣國防晶片自主性提高，訂單主要來自波音等歐美客戶
- 台灣對中國需求持續降低

#### 操作建議
- **雷虎**: 營收持續創新高，股價位階為好的買點
- **目標價**: 隨營收增長逐步調升
- **停損點**: 跌破季線支撐

## 📋 投資策略總結

### 上半年營收史上最強的啟示
1. **AI需求不減**: 交換機、伺服器、散熱等族群營收持續創高
2. **匯損是短期雜音**: 台幣升值影響大，但美元計價營收仍強勁
3. **好股票拉回找買點**: 創新高的股票回檔就是進場機會
4. **三三策略選股**: 基本面+籌碼面+技術面三重篩選，降低風險

### 關稅不影響AI趨勢
- 關稅4月已反映過一次大跌
- 利空已經消化，除非有更嚴重的新利空
- 聯發科等以中國為主要市場的公司，匯率影響較小（人民幣計價）
- 避開美國的供應鏈反而不受關稅衝擊

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **800G/1.6T交換機** | 高速網路交換設備，800G指800 Gbps傳輸速率，1.6T指1.6 Tbps，為AI資料中心必備 |
| **BSPDN（背面供電）** | 二代奈米製程的關鍵技術，將供電線路移至晶片背面，提升效能降低功耗 |
| **鑽石碟** | 化學機械研磨（CMP）製程的消耗品，用於晶圓表面拋光平坦化 |
| **WNCM** | Wafer-level Non-Carrier Module，無載板封裝技術，更薄且可整合多晶粒 |
| **CoWoS** | Chip on Wafer on Substrate，台積電先進封裝技術 |
| **三三策略** | 盡老師提出的選股法，基本面+籌碼面+技術面各三個條件，共九項篩選 |
| **白牌交換機** | 非品牌交換機，由ODM廠代工生產，主要供雲端服務商使用 |
| **乖離率** | 股價與均線之間的偏離程度，過大代表短線超買或超賣 |
