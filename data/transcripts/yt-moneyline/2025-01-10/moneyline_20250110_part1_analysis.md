## 📊 市場總體觀察

### 台股

- **收盤數據**：大盤下跌69點，收在23,011點，已連續下跌四天
- **成交量**：量能萎縮至3,300多億元
- **三大法人**：三大法人連續三天同步站在賣方
  - 外資：當日賣超171億元，期貨空單增加948口，總數逼近42,000口
- **櫃買指數**：盤中一度跌破波段低點，回測去年8月股災低點
- **台幣**：持續貶值，盤中最低一度逼近32.996元，接近33元大關

### 盤面觀察

- **抗跌族群**：生技族群、部分光學族群回升、BBU族群、航運族群有個股點亮
- **壓盤族群**：金融股賣壓較重
- **結構警訊**：
  1. 大盤拉回第四天，跌破季線
  2. 櫃買指數更弱，盤中一度跌破波段低點
  3. 三大法人同步站在賣方，外資空單高達近42,000口

### 台積電營收

- 台積電公布12月營收2,780億元
  - 月增0.8%
  - 年增57.8%
  - 歷年以來同期最好表現
- 2024年全年營收創歷史新高
- 市場解讀為「平平」，已預期利多，股價兩天收黑線

### CES展後市場反應

- **黃仁勳演講評價**：未帶來特別驚喜
  - RTX 50系列（5070/5080/5090）發布，售價有性價比
  - 推出COSMOS自駕車/機器人模擬系統
  - 未提及B300/Ruby等AI伺服器新世代晶片
  - 數位孿生、智慧工廠等概念均為舊題材重講
- **爆款品缺席**：與過去一兩年黃仁勳推A100/H100/B200即大爆款不同，本次缺乏企業立即下單的產品
- **聯發科亮點**：被黃仁勳點名合作，推出Project DIGITS小型AI電腦

## 💼 產業分析與投資建議

**核心觀察**：AI硬體進入階段性停頓期

- 信華（BMC伺服器遠端控制IC）在新一代B300架構中不再受益
- 鴻海K線圖走勢不像「AI上機」，已出現假突破真下跌型態

### 2. 融資觀帳效應分析（子燈）

**核心觀察**：丙種觀帳壓力正要開始

- 農曆年封關1/22，提前T+2交割，**1/17為丙種觀帳最後賣出日**
- 過去三年融資餘額封關前減幅：
  - 2022年：減少9.5%（放假天數多）
  - 2023年：減少10%
  - 2024年：減少0.4%（放假天數少）
- **警訊**：2025年放假11天，但融資餘額至1/9為3,256億，比12/23的3,233億反而微增，尚未開始減碼

**融資使用率偏高個股（須留意賣壓）**：

| 個股 | 類別 | 風險提示 |
|------|------|----------|
| 新勝利 | 4930（上櫃） | 融資率最高，BPU概念跟風漲但非正宗，翻轉速度快 |
| 晨明電 | 3013（上市） | 營收創歷史新高，但硬體非當前主流，融資偏高 |
| 海灣 | 上櫃 | 融資率偏高，須留意 |
| 波羅威 | 上櫃 | 融資率偏高，但近期股價表現尚可 |

## 📈 技術面分析與操作策略（鄭華）

### 大盤技術面

- **騰弱指標**（上漲家數-下跌家數累加）：自去年24,416高點以來持續走低，形成下降趨勢
- 指數反彈時，每天下跌家數仍多於上漲家數
- **最後一棒效應**：資金只買台積電，賣其他所有股票

### 櫃買指數

- 已跌至去年8月股災低點附近，應有**強力支撐**
- 很多權值較重的個股已比櫃買指數跌得更深
- **跌深股買點已浮現**

### KD指標判斷法

| 型態 | KD位置 | 操作 |
|------|--------|------|
| 正常多頭 | KD在20-80之間來回 | 每次到80回到20時為買點 |
| 極強多頭 | KD在80以上超過3天 | 拉回死亡交叉為買點 |
| 空頭弱勢 | KD在20以下超過3天 | 不要嘗試抄底，反彈都是壓力 |

### 個股技術面判斷

| 個股 | 技術判斷 | 操作建議 |
|------|----------|----------|
| 紅凱LED | 加入矽光子聯盟，修正回到起漲點 | 買點浮現，可切入 |
| 康配（新藥） | 2B實驗順利達標，投信在低檔布局 | 看好投信養股，有機會成為Q1標股 |
| 奇鋐 | 營收不錯但價格未過前高812 | 短線無質問味道，長線有支撐 |
| 幸福型（PCB） | KD在20以下超過10天 | 所有反彈幾乎無效，不建議抄底 |
| 羽隆（AI+車用） | KD在80以上夠久，但距離起漲線不夠遠 | 差一點味道，等確定大長紅再進 |

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| 丙種資金 | 民間非正規管道的股票融資，利息以日計算，年利率可達10-50%以上 |
| 觀帳 | 農曆年前因利息成本過高，融資者提前賣出股票還款的現象 |
| 融資餘額 | 投資人向券商借錢買股的總金額，反映市場槓桿程度 |
| 騰弱指標 | 每日上漲家數減下跌家數的累計值，反映市場內部強弱 |
| KD指標 | 隨機指標，用於判斷股票超買超賣，80以上為超買、20以下為超賣 |
| BMC | 基板管理控制器（Baseboard Management Controller），伺服器遠端管理晶片 |
| Burn-in測試 | GPU封裝完成後的高溫/電流老化測試，篩選不良品 |
| PCB | 印刷電路板（Printed Circuit Board），AI伺服器關鍵零組件 |
| UBB | 統一基板（Universal Baseboard），伺服器GPU上的PCB板 |
