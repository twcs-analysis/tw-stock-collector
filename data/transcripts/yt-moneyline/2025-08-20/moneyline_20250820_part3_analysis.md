### 俄烏停戰進展

- 川普與烏克蘭總統澤倫斯基會談40分鐘，態度正面
- 川普表示若順利，兩週內將與普丁三方會談
- 烏克蘭願意與歐盟共同向美國採購軍備、加入類北約組織
- 地緣政治風險若下降→不利黃金續漲，但避險買盤可能從地緣轉向股市避險

### 黃金走勢

- **歷史高點**：3,005美元（4月22日）
- **目前走勢**：高檔震盪收斂，可能三角收斂突破
- **最佳劇本**：慢慢收斂→等待聯準會降息訊號→創新高噴出
- **盤整區間**：低點3,000美元附近、高點3,150美元
- **操作建議**：接近低點325美元附近較安全；若降息確認則有機會突破

### 油價走勢

- 若俄烏停戰→俄羅斯原油制裁解除→供給爆增→油價承壓
- OPEC+已上調今年需求預估，但供給可能大幅增加
- 目前油價緩跌格局未改變
- 操作建議：保守為主，趨勢偏弱

## 📈 技術面分析與操作策略

### 明日操作策略（舒方老師）

1. **急速下殺→慣性反彈**：若明天急殺且乖離率大，當日有技術性反彈機會
2. **短線KD已交叉向下**：做短者等指標交叉向上再進場
3. **選股兩原則**：
   - 大盤跌破月線時→選相對比大盤強、守住月線的個股
   - 跌線扣底到相對低檔→短期接近季線不管、季線逢低不破→不要殺跌
4. **指標股看台積電**：
   - 台積電止穩→半導體止穩→大盤止穩
   - 政府護盤也會從台積電入手
5. **資金切割至少兩份**：不要一次All-in，留後備彈藥

### 黃金操作策略

- **三角收斂中**：盤整區間低點3,000美元附近、高點3,150美元
- **收斂突破方向未定**：若降息訊號明確→向上突破；若經濟好+通膨高→可能向下
- **盤整時策略**：接近低點布局較安全，接近高點風險較大
- **9月後才明朗**：降息與俄烏談判結果都在9月後才有結論

### 油價操作策略

- **趨勢偏弱**：緩跌格局未改變
- **停戰風險**：若制裁解除→俄羅斯供給爆出→油價壓力大
- **操作建議**：保守為主，不宜做多

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| AI眼鏡 | 搭載人工智慧助理的智慧眼鏡，具備語音助理、拍照翻譯、圖文辨識等功能 |
| Google Gemini | Google推出的多模態AI大型語言模型，可處理文字、圖像、語音等多種輸入 |
| Hive Nova | Meta預計推出的自有品牌AI眼鏡，搭載AI顯示螢幕 |
| CIS（CMOS Image Sensor） | CMOS影像感測器，用於手機、相機等裝置的影像擷取核心元件 |
| 三角收斂 | 技術分析形態，股價高低點逐漸收窄形成三角形，通常預示即將突破 |
| 類北約組織 | 非正式的軍事互助聯盟，類似北約但不屬北約正式成員，提供一定程度的軍事保護 |
| OPEC+ | 石油輸出國組織及其合作夥伴，共同協調石油產量以影響油價 |
| 處置股 | 因股價異常波動被證交所列為注意股後進一步處置的股票，採分盤交易方式 |
