## 📊 市場總體觀察

### 台股走勢

- **歷史統計**：今日728點跌幅為今年以來第六大、歷史第十一大單日跌點
- **大跌後反彈機率**：過去前十次台股大跌之後一個月，只有一次是跌的，其餘少則反彈1.5%、多則18%
- **外資賣超明細**：
  - 台灣50（0050）：賣超13萬張（系統性賣出）
  - 台積電、聯電等大型權值股同步被賣
  - 被動型基金因台幣貶值強迫性賣股
- **成交量分析**：今日5,653億為出量但非巨量（巨量標準為超過前次5,700億的最大量）
- **KD指標**：已交叉向下，短線技術面轉弱

### 美股影響

- 美股科技股前日下跌為台股今日重挫的重要觸發因素
- 美國期貨盤在節目錄影時（下午5:40）跌幅已收斂，台指期夜盤率先翻紅

### 台幣匯率

- **新台幣重貶1.8角**，突破近期低點
- 台幣轉弱格局確認，技術線圖開始下行沾到均線上方
- 外資看台幣貶值→賣出龍頭型權值股（尤其是台灣50）
- 預估台幣不會急速貶至31元，可能緩慢貶值至30.45附近挑戰

### 聯準會降息預測

- **9月17日FOMC會議**：降息機率從本週一的九成多降至八成二
- **10月**：降息機率已歸零
- **12月**：降息機率僅剩46%
- **今年降息次數**：可能減為兩碼
- **關鍵數據**：
  1. 9月5日：美國失業率與非農就業（若失業率從4.2降至4.1、非農回到10-12萬→經濟好→不降息也非壞事）
  2. 9月11日：CPI數據（若CPI從2.7降、核心CPI維持3.1→有降息機會）
- **結論**：不降息不一定是壞事，代表美國經濟良好

## 📈 技術面分析與操作策略

### 大盤操作策略

1. **大跌後一個月反彈機率極高**：歷史統計十次僅一次下跌，分批向下承接為主
2. **融資是關鍵指標**：
   - 融資大減→恐懼到極致→底部訊號（好事）
   - 融資不大減→還不夠恐懼→可能再修正
3. **KD指標交叉向下**：短線做多者應等指標交叉向上再進場
4. **量能觀察**：今日為出量非巨量（未超過前次5,700億），若出現爆巨量+隔日開低走跌→確認頭部
5. **頭部判斷**：左邊量大、右邊反彈過高量小→確認頭部；目前尚未出現明顯轉勢訊號

### 個股停損原則

- **巨量黑K後跌破大量區間低點或缺口**→結碼
- **跌破慣性軌道線**（如月線過去都守住，這次灌破三天以上）→減碼
- **10%停損紀律**：100萬跌10%變90萬，再賺10%回99萬接近成本；若跌20%到80萬，賺10%僅回88萬，越深越難翻身

### 融資操作提醒

- **絕對不要用融資做擴張信用操作**：一個跌停板融資虧25%（現股僅10%）
- 融資套牢不能用「存股」心態硬撐，必須嚴守停損
- 現股投資可用時間換空間，融資不行

### 美債ETF策略

- **領息為主**：不降息時沒有價差，但債息收益穩定，可做為現金部位
- **降息反而可能不利長天期債**：降息後通膨可能因關稅持續上調而走高，長債殖利率反而上升
- **30年期公債殖利率觀察**：5.0%-5.2%區間為追高位置；若期待價差，通膨持續上升則不太可能賺到
- **建議**：維持領息策略，不追價差

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| KD指標 | 隨機指標（Stochastic Oscillator），用於判斷股票超買或超賣狀態，交叉向上為買訊、向下為賣訊 |
| 融資餘額 | 投資人向券商借錢買股票的總金額，融資增加代表散戶積極做多 |
| 巨量 | 成交量創下近期最大量，通常為重要轉折訊號 |
| CPO（Co-Packaged Optics） | 共封裝光學技術，將光學元件與交換晶片整合封裝，提升AI伺服器傳輸效率 |
| BPU（Battery Power Unit） | 電池電源單元，用於資料中心備援電力系統 |
| 傑克森霍爾年會 | 美國聯準會每年8月在懷俄明州傑克森霍爾舉辦的全球央行年會，主席演說為市場重要風向指標 |
| 標準普爾信評 | 全球三大信用評等機構之一，對國家或企業的償債能力進行評級 |
| 本益比（P/E Ratio） | 股價除以每股盈餘，用於衡量股票估值高低 |
