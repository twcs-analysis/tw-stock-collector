## 🌍 市場總體觀察

### 一、對等關稅深度分析（王健全副院長觀點 - 續）

#### 高科技產業影響
- **IEEPA涵蓋台灣30%產品**: 其餘70%產品不受IEEPA額外條款影響，這也是為何股市仍有上漲動能
- **晶片關稅100%威脅**: 目前美國聲稱可豁免，但具體課稅範圍（設備、材料、供應鏈）尚未白紙黑字確認
- **蘋果供應鏈暫時豁免**: 蘋果承諾投資6,000億美金，其手機、筆電供應鏈暫時免稅
- **三星供應鏈**: 同樣因投資承諾而暫時豁免
- **連電等供應商**: 即使客戶（如AI伺服器廠商）在美國有投資，自身未赴美投資者能否免稅仍不確定

#### 台積電赴美投資的連鎖效應
- **台積電承諾**: 3座先進晶圓廠 + 2座先進封裝廠
- **供應鏈跟進**: 設備、封測、口罩等供應商都將赴美投資
- **經濟安全疑慮**: 前有「浪貨油」（供應鏈外移風險），需注意人才與技術外流
- **建議**: 設立主權基金，投資EV、AI、機器人、新能源等新領域，且應雙向投資（將美國技術帶回台灣）

#### 台灣談判策略建議
1. **蘋果模式**: 盤點廣達、聯電、日月光等企業的投資，湊出大數字與川普談判
2. **韓國模式**: 協助美國製造業復興（如韓國協助美國造船業），台灣可以工具機、精密機械、紡織等產業赴美投資
3. **經濟特區策略**: 保障美國市場20年，換取對等關稅降低
4. **雙向投資**: 赴美投資同時，將美國的軟體技術、創投技術帶回台灣
5. **資本市場鏈結**: 鼓勵台灣企業赴美掛牌（如日月光、聯發科技等），吸引美國資金與人才

#### 服務業機會
- **台灣村商機**: 台積電在Arizona、Dallas、Houston設廠後，將形成「台灣村」，服務業可拓展海外
- **MIT品牌**: 台灣可打造MIT品牌，利用美國市場擴張
- **服務業升級**: 從傳統外勞與看護，轉型為養生醫材、陪伴商機、心理諮商、文創觀光、精準理財

#### 全球布局調度
- **各國關稅比較**: 越南20%、印度較高、中國30%（90天緩和期後）、墨西哥未定
- **台灣產業韌性**: 全球布局可調度生產基地，實際衝擊低於帳面稅率
- **反洗產地**: 川普要求實質製造，不能僅藉轉口貿易規避關稅

### 二、出口市場分散策略
- **歐盟**: 需配合數位與綠色轉型要求，台灣已與波蘭、斯洛伐克、立陶宛展開研發合作
- **東南亞**: 從製造基地升級為營運總部，利用AI、電商等科技工具
- **台灣順差**: 對美順差今年第一季已達7,700多億美金，為美國第五大順差國，分散市場迫在眉睫

## 💼 產業分析與投資建議

### 一、無人機產業 - 國防部5萬架500億商機

#### 產業政策背景
- **國防預算**: 總統推動國防預算GDP佔比3%，約8,000億元
- **採購規模**: 國防部宣布未來兩年採購48,750架軍用商規無人機，預算上看500億元
- **行政院加碼**: 航太小組有意再加購近5萬架，總規模可能翻倍
- **國產化要求**: 強調飛控供應鏈整合與國產化

#### 無人機概念股漲幅驚人
- 過去一個月漲幅前20檔股票中，扣除成交股後有5檔與無人機相關
- 與PCB/CCL相關的有10檔，兩大主流合計佔前20名的75%

#### 個股推薦

- **推薦來賓**: 祺升
- **題材**:
  - 攻擊型無人機今年第二季開始出貨
  - 6月營收已達歷史新高
  - 去年全年營收約12億元
- **籌碼面**: 400張大戶持股連續增加，資金持續流入
- **營收表現**: 7月營收表現相當不錯
- **操作建議**: 營收持續成長，大戶籌碼鎖定，可留意回檔布局
- **目標價**: 隨營收持續放量，股價有望持續挑戰新高
- **停損點**: 跌破近期起漲平台

**雅含（漢翔，2634）** ⭐
- **推薦來賓**: 祺升
- **題材**:
  - 首家獲得中科院複合技術授權與複合機體製造技術授權
  - 在手訂單223億元（軍用維修為主）
  - 能見度達2030年以上
  - 去年營收約502億元
- **籌碼面**: 400張大戶持股持續增加
- **營收表現**: 7月營收表現不錯
- **操作建議**: 長線訂單能見度高，大戶持續佈局
- **目標價**: 隨訂單交付，營收逐步放量

- **推薦來賓**: 祺升

- **注意**: 目前處於處置股限制交易中，但處置期間股價仍持續上漲

**經緯（景明）** ⭐⭐ - 隱藏版概念股
- **推薦來賓**: 祺升
- **股價**: 目前相對低位階
- **題材**:
  - 原本做筆電與消費性產品，已切入無人機領域

  - 主要工廠分布：雷波與昆察（60%營收在昆察）

- **操作建議**: 漲幅尚未如其他無人機股般大，量能持續增加有望向上攻擊

- **停損點**: 跌破頸線支撐

  - AI伺服器機櫃：立蒙生產IGT伺服器機殼及水冷專案，客戶含蘋果、亞馬遜、廣達、技嘉

- **技術面**: 尚未完全站上3月平台，形成大型頸線即將突破
- **操作建議**: AI伺服器 + 無人機雙題材，量能增加有望向上攻擊
- **目標價**: 突破3月平台壓力後看更高
- **停損點**: 跌破近期整理區間低點

## 📈 技術面分析與操作策略

### 大盤技術面總結（會是老師觀點）

#### 多頭確認指標
1. **均線**: 嚴重多頭排列走勢，非常強勢
2. **成交量**: 連續四天在4,000億以上，量能潮回歸，不是一天量

4. **週KD**: 動態整理中

#### 盤面主流三大方向
1. **PCB/CCL產業鏈**: 報價上漲+產能趨緊
2. **機器人產業鏈**: 展覽密集+技術突破

#### 關鍵觀察
- **領先指標**: 台積電（2330）、台光電（2383）站在均線之上即偏多
- **族群擴散**: 多頭市場特有的往外擴散現象，為健康訊號
- **反映未來**: 股價反映今年底到明年的產業題材，不要以當前基本面判斷高低

## 📋 投資策略總結

### 短期（1-2週）

1. **無人機族群持續關注**: 國防部5萬架500億商機為政策紅利，短線資金持續流入
2. **PCB/機器人/無人機三大主流輪動**: 過去一個月漲幅前20名中PCB佔10檔、無人機佔5檔
3. **注意漲幅過大個股風險**: 長榮航太已漲70%且處置中，短線追高風險大
4. **關注景明、金魚等低位階補漲股**: 漲幅尚小但題材明確

### 中期（1-3個月）

1. **國防預算持續擴張**: GDP 3%約8,000億，無人機與無人艇為重點採購項目
2. **台灣無人機外銷創新高**: 上半年外銷年增750%，國際市場正在打開
3. **關稅衝擊下半年浮現**: GDP成長從6.73%降至1%，傳產首當其衝
4. **服務業國際化新契機**: 台灣村、MIT品牌、雙向投資為長線機會
5. **房地產持續降溫**: PMI下滑、泡沫疑慮增加，避開營建相關標的

### 風險評估

| 風險項目 | 風險等級 | 說明 |

| 疊加關稅實施 | 🔴 高 | 台灣工具機等傳產與日本稅率差距10%，競爭力受損 |
| 半導體關稅不確定性 | 🟡 中高 | 100%晶片關稅威脅未完全排除，設備材料範圍不明 |
| 無人機概念股過熱 | 🟡 中 | 部分個股漲幅已達50-70%，短線回檔風險升高 |

| 下半年GDP放緩 | 🟡 中 | 從6.73%降至1%，消費與服務業將連帶受影響 |

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **IEEPA** | International Emergency Economic Powers Act，美國國際緊急經濟權力法，授權總統在國家緊急狀態下對特定國家實施經濟制裁或加徵關稅 |
| **疊加關稅** | 原有的基礎關稅加上新增的對等關稅，使實際稅率遠高於單一稅率 |
| **CMMC Level 2** | 美國國防部網路安全成熟度模型認證第二級，是向美國軍方供貨的必要資格 |
| **USV（無人艇）** | Unmanned Surface Vehicle，無人水面載具，用於海域巡邏、偵察等軍事用途 |
| **MIT（台灣製造）** | Made in Taiwan，強調國產化供應鏈，符合國防部國產化要求 |
| **IGT** | 全球最大的博弈遊戲機製造商，在2,800個地區有認證 |
| **處置股** | 證交所對交易異常的股票實施處置措施，限制交易方式（如預收款項、延長撮合時間等） |
| **順差** | 出口金額大於進口金額的貿易差額，台灣對美順差持續擴大 |
| **雙向投資** | 台灣企業赴美投資的同時，將美國的技術、人才、資金帶回台灣 |
| **頸線突破** | 技術分析中，股價突破長期整理區間的上緣（頸線位置），視為多頭啟動訊號 |
