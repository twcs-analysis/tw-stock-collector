## 💼 產業分析與投資建議

### 一、台積電 (2330) - 填息完成，壓力仍在

**基本面分析**:
- 今日收盤1,070元，為2月24日以來新高
- 花了十天完成填息
- 1,065附近有18,000多張賣壓湧出
- 1,050以上籌碼壓力沉重（解套賣壓+空方缺口）
- 1,100以上到前高之間有大量套牢籌碼

**操作建議**:
- **波段操作者**: 設月線為停利/停損參考（月線目前約1,070，持續上移）
- **低位持有者**（800-825元以下買進）: 以月線為守線，未跌破前續抱
- **解套者**: 1,065為關鍵支撐，跌破考慮減碼
- **無持股者**: 不建議追高，火伴族群（廣達等）漲幅更快
- **目標價**: 外資最保守目標約1,065，最樂觀目標1,200+
- **停損點**: 月線（約1,070持續上移），跌破月線出場

### 二、華碩 (2357) - ETF換股推升，消費性電子隱憂

**基本面分析**:
- 昨日因ETF換股拉抬，今日反向回跌6%
- 昨日成交量達54億
- 法人目標價7,500-8,500元
- 消費性電子端需求不確定性高
- 對新台幣匯率敏感度高

**操作建議**:
- **短線套牢者**: 以昨日低點為出場參考價
- **中長線持有者**: 設月線附近為停損支撐
- **0029 ETF觀察**: 華碩非ETF主要組成，漲跌不影響0029走勢
- **停損點**: 昨日低點或月線位置

### 三、南亞科 (2408) / 華邦電 (2344) - DRAM報價長但股價不動

**基本面分析**:
- DDR5報價大漲，六月份不僅大漲，上一代價格竟比新一代漲了一倍
- 南亞科淨值約50元，股價接近淨值壓力
- 華邦電淨值約21-22元，本益比偏高
- DDR5非AI主流（DDR5不如DDR5 → 不如HBM）
- 報價上漲屬供給減少而非需求拉動（類似LCD產業）

**操作建議**:
- **南亞科**: 報價漲至第三季可能是賣點，不建議追高
- **華邦電**: 雖轉虧為盈但獲利有限，淨值比偏高，不建議追高
- **景氣循環股邏輯**: 報價推升時買入、賺錢時賣出（買在虧損、賣在獲利）
- 留意是否有法人持續出貨跡象

### 四、台揚 (2314) - 低軌衛星題材，大戶自救行情

**基本面分析**:
- 連飆五根漲停（從約7元漲至11.45元）
- 曾因淨值低於5元面臨下市危機
- 接獲低軌衛星訂單（紅海秘門會議相關）
- 凱基大戶持股曝光，最低買在11.75元附近
- 歷史上曾多次透過減資後接單恢復獲利

**操作建議**:
- **被套牢者**: 等待低軌衛星+國防型態訂單兌現
- **新進者**: 不建議追漲停，有大戶解套出貨風險
- **目標價**: 短期看大戶成本區（11.75元附近為壓力）
- **停損點**: 跌回7元附近（減資後成本區）

### 五、亞翔 (6139) - 營造工程股，在手訂單創新高

**基本面分析**:
- 法說會/股東會透露在手訂單達2,000億（歷史新高）
- 第二季營收年減衰退，上半年也衰退
- 工程營收集中在下半年
- 新台幣升值對獲利影響大（5月單月獲利僅0.4億，匯損吃掉大部分）

**操作建議**:
- **已持有者**: 守住多方缺口（跳空缺口下緣），未跌破續抱
- **新進者**: 營造工程股需放長時間投資
- **目標價**: 下半年工程營收放量後有望帶動股價
- **停損點**: 多方缺口跌破出場

### 六、散熱產業 - AI晶片功耗飆升的最大受惠者

#### 產業趨勢
- GPU功耗從B200的1,200瓦 → B300的1,400瓦 → Rubin/FAMIN 2,000瓦以上
- AMD MI300X到MI3200也持續攀升
- CoWoS尺寸從80x80mm → 111x100mm → 122x100mm，均熱片需求同步放大
- VC Lid（均熱片蓋）技術成為關鍵：真空蒸氣腔體，利用水量蒸發凝結循環達到快速散熱

#### 建準 (2421) - 均熱片龍頭
- 均熱片做最多，營運逐季走揚
- 大園新廠動工，今年Q4投產
- B200/B300/GB300高功耗驅動需求
- 股價已從700多元漲至1,500多元
- 10日線未跌破，外資近期加碼買進
- **目標價**: 趨勢持續看多，但股價已不便宜
- **停損點**: 10日線

#### 一詮 (2486) - 散熱轉型股，VC Lid新技術

**基本面分析**:
- 原做導線架，轉型半導體散熱領域
- 與工研院合作開發VC Lid（均熱片蓋）水冷技術
- 散熱量可從700瓦提升至1,000瓦
- 均熱片+TIM熱界面材料+VC Lid三合一布局
- 今年量產，營收占比預估30%，單價為傳統十倍
- 今日收盤80.3元（股價低基期）

**操作建議**:
- 屬於右下角低位整理股，剛突破均線
- 前波高點附近有壓力（今日留長上影線）
- **買進時機**: 明日收盤價站穩前波高點上方，確認波段起攻
- **目標價**: 低位風險有限，上方想像空間大
- **停損點**: 低點支撐（底部區域約70元附近）

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **VC Lid** | Vapor Chamber Lid，均熱片蓋，利用真空蒸氣腔體內水量蒸發與凝結循環，達到快速散熱效果 |

| **均熱片** | Vapor Chamber，利用真空蒸氣進行晶片內的水量蒸發與凝結，達到快速傳熱降溫 |

| **KD指標** | 隨機指標，50以上為多方區域，交叉向上為買訊 |
| **PCE** | Personal Consumption Expenditures，個人消費支出物價指數，聯準會偏好的通膨指標 |
