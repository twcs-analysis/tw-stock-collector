## 🌍 市場總體觀察

### 鴻海（2317）閉門法說會深度解讀

#### 董事長劉揚偉關鍵發言

1. **AI伺服器訂單**: 能見度長達2027年，國外數千億美元大型AI專案「一定在裡面」
2. **訂單不是問題，產能才是問題**: 暗示需求強勁但產能瓶頸待克服
3. **三大未來願景**:
   - **電動車**: 隨時隨市場為客戶生產電動車（但川普退出巴黎協定、與裕隆合作面臨關稅衝擊）
   - **人型機器人**: AI終極革命方向，可為不同客戶生產（但今年無法貢獻營收獲利）
   - **法國合作**: 與歐洲法國合作半導體與低軌衛星（想像空間大）

4. **股東會花絮**:
   - 劉揚偉續任董事長，郭台銘持股13%但未出席投票（棄權）
   - 小股東給99.9分，扣0.1分是因「股價差」
   - 小股東建議「找大股東投資人多吃飯，股價才會提上去」

#### 外資 vs 投信對決
- **投信今日買超**: 8,427張（看好閉門法說正面訊號）
- **外資今日賣超**: 8,194張（參加閉門法說後反而賣出）
- 外資利用台灣ETF進行結構性賣超，眼光較長
- 投信主動式換股操作，眼光較短

### 紅海集團相關個股分析

#### 鴻海（2317）操作建議

**基本面分析**:
- 扣掉Q1業外賣場，紀念成長幅度不如純AI伺服器廠
- 加上業外，EPS約13元，本益比不高
- 體質穩健但AI純度不足，想像空間有限
- 配息5.8元（殖利率尚可），下週四除息

**操作建議**:
- **區間操作**: 150-180元（季線至上方壓力區）
- **除息策略**: 有持股可參與除息（配息5.8元）
- **上檔壓力**: 180-200元區間獲利了結
- **目標價**: 180元（短線壓力）、200元（大盤配合衝高時）
- **停損點**: 季線（約150元）跌破出場

#### 廣宇 (2328) - 機器人題材一日遊

**基本面分析**:
- 昨日因機器人題材攻漲停，今日開高走低收最低
- 當沖比例高達70%
- 機器人題材「真的太久了，還久得很」

**操作建議**:
- 屬右下角股票，守住前方缺口不破仍在打底
- 轉強未成功，需等台股信心恢復後才有機會
- **停損點**: 前方跳空缺口下緣

#### 椅射/以盛 (5765/推測) - 紅家軍中率先啟動

**基本面分析**:
- 鴻海集團中最早公布免稅額度
- 具備車用、人型機器人硬體、低軌衛星三大題材
- 若紅家軍要動，椅射可能率先領漲

**操作建議**:
- 關注是否領先鴻海集團啟動
- 線形呈上升走勢

#### 廣達 (2382) - AI伺服器首選

**基本面分析**:
- 以AI伺服器出發點，廣達優於鴻海
- 今日創高，外資+ETF持續買進
- 配息13元，殖利率計算約在2,600元有支撐
- KD指標呈雙背離（短線過熱訊號）

**操作建議**:
- **較安全價格**: 2,600元附近（配息殖利率支撐）
- **目前位階**: 創高但KD雙背離，短線不建議追高
- **波段操作**: 年線附近考慮布局
- **目標價**: 視台股能否走向多頭而定
- **停損點**: 年線跌破出場

## 💼 下半年主流產業布局（世堅老師專題）

### AI產業三大輪動主軸

#### 主軸一：BBU（電池備援單元）
- 順達 (3211) 日線連三紅噴出
- 週線呈大底右肩突破格局
- 高配息特性，第一根紅棒沒追到等回檔再看

#### 主軸二：CPO（共同封裝光學）/ 矽光子
- 聯亞為矽光子重要指標股（動不動就被關禁，接近解放）
- 中國一線CSP也採用矽光子產品
- 聯亞不漲，其他矽光子股難動

#### 主軸三：物理AI（機器人）
- 三大主軸輪流表現
- 昨天CPO、今天BBU、明天可能輪到物理AI

### 下半年指數區間預估
- **箱型整理**: 21,500 - 23,000點
- **特性**: 往上墊高的箱型整理
- **結構**: AI伺服器為絕對主軸
- 台股相對美股費半、那斯達克偏弱

### 先進製程受惠股

#### 弘塑 (3131) - 設備股王
- 盤整底部連續日線連三紅噴出
- CoWoS口徑石設備龍頭
- 年線位置為壓力

#### 萬潤 (6187) - 設備股
- 同樣日線連三紅
- 盤整底部噴出格局
- 年線附近需關注突破

#### WFCM（晶圓級多晶片模組）新技術

**技術說明**:
- Wafer-level Multi-Chip Module，先封裝再切割（vs 傳統先切割再封裝）
- 密度更高、傳輸效率更好、熱導管效果更佳
- 將原本獨立的電子元件（如DRAM）整合進基體
- 台積電先進封裝持續領先，應用於高階封裝

#### 辛耘 (3583) - WFCM受惠股

**基本面分析**:
- 蝕刻製程設備（與弘塑類似領域）
- 貼膜玻璃設備（晶圓製造後期關鍵製程）
- 供應亞利桑那廠CoWoS設備
- 在先進封裝的前段與晶圓後段佔有一席之地

**操作建議**:
- 股價相對弘塑低位，壓力不大
- 沿5日線/10日線上行
- **買進時機**: 拉回前波高點附近
- **目標價**: 盤整格局中逢低布局
- **停損點**: 5日線/10日線跌破

### 不怕台幣匯率升值的個股

#### 唯創 (3231) - 訓練晶片封測龍頭

**基本面分析**:
- 5月營收20,841元（月增55%、年增81%）創歷史新高
- 亞馬遜自研訓練晶片Trainium年底上線
- META新一代ASIC也找唯創
- GB200四部曲出貨+下半年GB300加分
- 今日大量突破季線，外資買超第四名

**操作建議**:
- 季線放量突破，三個月最大量（籌碼清洗完畢）
- 跳空突破第一根，要進場就進場
- **買進時機**: 5日線/10日線附近或前高位置
- **目標價**: 趨勢向上，過關斬將
- **停損點**: 跳空缺口下緣

#### 辛耘 (3583) - 台幣升值反而加分（補充說明）
- 85%營收來自台灣（新台幣計價）
- 台幣升值對毛利率有正面幫助
- 先進製程設備零件清洗頻率與清潔度要求更高
- 兩奈米設備清洗量為五奈米的2.1-2.3倍
- **短線不追**: 今日大漲後留長上影線
- **買進時機**: 價穩量縮時介入

### 矽光子交點股

#### 聯亞 (3081) - 矽光子指標股
- 整體上面有整合良好
- 中國一線CSP也採用其產品
- 動不動被關（漲停鎖死），接近解放
- **操作**: 聯亞動則矽光子動，觀察是否突破盤整

#### 博錸爾/波若威 (3163) - CPO合作夥伴

## 📋 投資策略總結

### 核心觀點

1. **鴻海體質穩健但想像空間有限**: AI純度不如廣達，區間操作為主
2. **下半年三大主軸輪動**: BBU、CPO/矽光子、物理AI
3. **先進製程設備股啟動**: 弘塑、萬潤噴出，WFCM新技術帶動辛耘
4. **台幣升值選股邏輯**: 優先選擇營收以台幣計價、台灣市場為主的公司
5. **投信與外資對決**: 避開投信主動式換股標的，留意法人新布局個股

### 風險因素
- 外資參加鴻海閉門法說後賣出（訊號偏負面）
- 台幣持續升值壓縮電子股獲利
- 消費性電子端需求疲弱（電動車、手機）
- 蘋果今年新手機規格尚未明朗
- 投信頻繁換股造成市場波動

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **WFCM** | Wafer-level Multi-Chip Module，晶圓級多晶片模組，先封裝再切割的先進封裝技術 |
| **BBU** | Battery Backup Unit，電池備援單元，AI伺服器不斷電系統的核心元件 |
| **CPO** | Co-Packaged Optics，共同封裝光學，將光學元件與晶片封裝在一起的技術 |
| **閉門法說** | 非公開的法人說明會，僅限特定法人機構參加 |
| **除息** | 上市公司發放現金股利，股價相應扣除股利金額 |
| **填息** | 除息後股價回到除息前水準，代表投資人實質獲利 |
| **季線** | 60日移動平均線，代表中期趨勢方向 |
| **年線** | 240日移動平均線，代表長期趨勢方向 |
| **Trainium** | 亞馬遜自研AI訓練晶片，由唯創進行封測 |
