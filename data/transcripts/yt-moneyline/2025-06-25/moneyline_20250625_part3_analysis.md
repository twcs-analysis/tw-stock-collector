## 🌍 市場總體觀察

### 半導體全球布局：先進製程 vs 成熟製程的兩個世界

#### 全球晶片市場最新數據（2025年1-4月）
| 地區 | 成長率 | 說明 |
|------|--------|------|
| **美國** | **+44%** | 全球最快，AI驅動先進製程需求爆發 |
| **亞太（含台韓）** | +23% | 穩健成長 |
| **中國** | +14% | 中等成長 |
| **日本** | +4% | 成熟製程為主，成長緩慢 |
| **歐洲** | 0% | 零成長，車用/工業晶片疲弱 |

#### 未來十年半導體成長預估
- 過去十年全球半導體成長81%（中國為成長最快地區）
- **未來十年預估成長108%**（超越過去十年）
- **美國將取代中國**成為全球晶片成長最快地區
- 台積電在美國布局獨霸先進製程市場

### 台積電全球擴廠現況

#### 美國亞利桑那 - 全速推進
| 廠房 | 製程 | 狀態 | 量產時間 |
|------|------|------|----------|
| 一廠 | 4奈米 | **已量產** | 2024年（耗時4年建廠） |
| 二廠 | 3奈米 | 興建中 | 2028年量產 |
| 三廠 | **2奈米/A16** | **2025年提前動工**（原定2026） | 2029年量產（縮短至2年建廠） |

- 二奈米需求太熱，台積電主動提前半年動工三廠
- 美國勞工逐漸累積建廠經驗，建廠速度從4年縮短至2年
- 美國差台灣約4年（台灣2025年高雄/新竹寶三量產2奈米）
- 雜音幾乎消失：從「台積電掏空台灣」到「全力支持美國投資」

#### 日本熊本 - 觸礁觀望

**問題核心**:
- 一廠已完工（2024年），準備量產
- **二廠延後**: 原定今年動工，延後至Q3-Q4
- 魏哲家在股東會稱「交通二話」導致延後
- **日本經產大臣打臉**: 政府未收到因交通問題延後開工的報告
- 實際原因：日本客戶（Sony、電裝、豐田）下單觀望

**深層危機**:
- 日本2023-2025年新蓋7座晶圓廠，**4座養蚊子**（超過58%閒置）
- 全部以成熟製程為主（12-28奈米）
- 兩大衝擊：全球車市衰退 + 對等關稅觀望
- 中國成熟製程產能大開，壓力外溢

#### 德國德勒斯登 - 客戶財困

**問題核心**:
- 合作夥伴為英飛凌、恩智浦、博世（車用/工業晶片大廠）
- 2024年已動工，原定2027年量產
- **三家合作夥伴今年都傳出裁員數千人或宣布裁員計畫**
- 車用與工業用晶片需求疲軟
- 台積電在觀望客戶狀況，量產時程可能出現變數

#### 關鍵結論：一個半導體，兩個世界
| 面向 | 先進製程（2奈米/3奈米） | 成熟製程（12-28奈米） |
|------|------------------------|----------------------|
| 地區 | 美國為主 | 日本、德國為主 |
| 需求 | AI驅動，需求爆發 | 車用/工業，需求疲軟 |
| 台積電態度 | 加速擴廠、提前動工 | 觀望、可能延後 |
| 供應鏈影響 | 美國供應鏈大發特發 | 日本/德國供應鏈需觀望 |
| 競爭威脅 | 三星、英特爾落後 | 中國成熟製程大量產能 |

## 💼 產業分析與投資建議

### 一、矽光子（CPO）產業深度分析

#### 產業催化劑：科技巨頭態度轉變

1. **黃仁勳 (NVIDIA)**: 2025年3月GTC大會宣布「矽光子時間點已到」，比原預期提前一年
2. **博通 (Broadcom)**: 推出Hook 6網路交換器，處理量超過100 Terabit/sec（比上一代提升6倍），7月下半年全面出貨
3. **AMD (超微)**: 2025年5月收購矽光子新創公司，直接買下來整合到現有AI晶片與CPU產品線
4. **輝達**: 推出Spectrum-X網路交換器（框棚/今年下半年）+ 明年推出被創交換器

#### 全球只有兩家超過100 Terabit/sec
- **輝達** (GPU路線) + **博通** (ASIC路線)
- 博通用3奈米生產，輝達亦找台積電
- 網路交換器傳輸速度決定AI伺服器整體效能

#### CPO市場規模與成長
- 2025年市場規模約1,400萬美元（約4-5億台幣）
- 2029年預估約5,000萬美元（成長4倍）
- **年複合成長率達35%**（遠超半導體平均的10-20%）
- 市場看的是成長率而非絕對規模

#### 台灣矽光子生態系（全球最完備）

**台積電主導的產業聯盟**:
- 製造輝達、博通的3奈米矽光子大單
- 英特爾與三星在先進封裝完全落後
- 聯盟目標：知識共享、支援者專業計畫、制定產業標準

**台灣矽光子供應鏈全覽**:

| 環節 | 代表廠商 |
|------|----------|
| 元件設計 | 聯發科、聯詠、茂迪、光聖、延創 |
| 光源 | 連準、複財 |
| 機構件 | 聯鈞、上詮（過去一年半漲幅最大） |
| 先進封裝前段 | 台積電、世界先進、日月光、採域 |
| 測試/封測 | 穩懋、綠衛光、矽品、立成、矽格、金元電子（新增） |
| 設備（增加最多） | 近一年大幅增加多家 |
| 模組件 | 變化不大 |

#### 矽光子個股操作建議

**聯亞 (3081) - 矽光子指標股**:
- 中國一線CSP也採用產品
- 反覆整理接近突破
- 動不動被關漲停（籌碼面緊俏）
- **操作**: 聯亞突破=矽光子全面啟動信號
- **停損點**: 盤整區間下緣

**波若威 (3163) - 最強題材**:
- 台積電與輝達欽點合作夥伴
- 目前量縮至極低，等待放量
- **買點**: 季線位置+除息日附近
- **停損點**: 季線下方

### 二、避險商品分析（伊朗vs以色列衝突背景）

#### 黃金 - 漲幅過大，高檔整理

**現況分析**:
- 年初約2,600美元，最高曾達3,500美元（年初至今漲幅超30%）
- 近期最高3,450美元，有過前高但未過歷史新高
- 上方賣壓沉重（年初至今漲幅過大）
- 伊朗以色列衝突「不打沒事，打了反而跌」

**為何黃金不漲**:
1. 年初以來漲幅過大（30%+），獲利了結賣壓重
2. 衝突並未擴大（未演變為全面戰爭）
3. 美股沒跌，避險需求不足
4. 上方3,300-3,500區間反覆上衝下跌，賣壓厚

**操作建議**:
- 長線多頭格局未變，分批投資仍可
- 短線期待大幅價差不現實
- 需等待3,000-3,050美元附近打底完成後再上攻
- **催化劑**: 聯準會降息 + 美元走弱 + 美股下跌風險
- **目標價**: 22%央行預期金價將突破3,500美元
- **支撐區**: 3,000-3,050美元

#### 原油 - 衝高回落，需時間整理

**現況分析**:
- 衝突前從64-65美元漲至近78美元（漲幅20%+）
- 但市場期待封鎖荷莫茲海峽衝到100美元以上未兌現
- 伊朗理智回擊（軍事/核設施為主），未失控
- 川普持續喊油價下跌（施壓）

**為何原油不續漲**:
1. 衝突未擴大至鄰國（伊拉克等未參戰）
2. 美國即時出手斡旋
3. 川普持續施壓壓低油價
4. 市場偏向樂觀（不會全面戰爭）

**操作建議**:
- 暴衝後回落，需時間整理消化賣壓
- 底部已出現，但不要期待馬上爆漲
- **策略**: 不破底用慢慢築底角度化解上方套牢
- 等川普不再喊壓油價後再期待上攻

## 📋 投資策略總結

### 核心觀點

1. **一個半導體，兩個世界**: 先進製程（美國）全速前進，成熟製程（日本/德國）觀望延後
2. **矽光子進入爆發期**: 黃仁勳宣布時間點到了，台灣生態系全球最完備
3. **避險商品需耐心等待**: 黃金高檔整理、原油衝高回落，短線不急
4. **台積電全球布局分化**: 美國供應鏈大受惠，日本/德國供應鏈需觀望
5. **CPO年複合成長35%**: 看成長率而非絕對市場規模

### 風險因素
- 日本/德國成熟製程廠閒置率高（7座新廠4座養蚊子）
- 中國成熟製程產能大開，全球可能供過於求
- 台幣升值持續壓縮出口型電子股獲利
- 伊朗以色列衝突若擴大將改變避險商品格局
- 蘋果新手機規格至今未明朗

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **CPO** | Co-Packaged Optics，共同封裝光學，將光學元件直接與交換器晶片封裝在一起，大幅提升傳輸效率 |
| **矽光子** | Silicon Photonics，在矽晶片上整合光學元件的技術，利用光速傳輸取代電子訊號，解決能耗與發熱問題 |
| **Terabit/sec** | 每秒兆位元傳輸速度，100 Tb/s即每秒傳輸100兆位元資料 |
| **Hook 6** | 博通推出的最新網路交換器，傳輸速度超過100 Tb/s |
| **成熟製程** | 12奈米至28奈米以上的半導體製程，主要用於車用、工業、消費性電子 |
| **先進製程** | 7奈米以下（5nm、3nm、2nm），主要用於AI晶片、高效能運算 |
| **荷莫茲海峽** | Strait of Hormuz，連接波斯灣與阿曼灣的戰略性海上通道，全球約20%石油運輸經過此處 |
| **避難包** | 緊急避難時隨身攜帶的求生包，內含證件、食物、藥品、飲水、手電筒、行動電源等 |
| **CSP** | Cloud Service Provider，雲端服務供應商（如AWS、Google Cloud、Azure） |
| **A16** | 台積電下一代1.6奈米製程，預計為最先進的量產製程之一 |
