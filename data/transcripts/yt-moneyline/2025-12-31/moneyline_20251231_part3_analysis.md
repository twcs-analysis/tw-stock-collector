## 聯準會FOMC會議紀要深度解析

### 為何在數據不足下仍決定降息？四大原因

| 原因 | 詳細說明 |
|------|----------|
| 1. 勞動市場風險 | 失業率可能持續上升，企業「凍住」員工但未聘新人 |
| 2. 關稅推動通膨 | 川普關稅造成通膨上升，但預期可望在高基期下回落 |
| 3. 政府關門衝擊 | 不發薪 → 不消費 → 經濟惡化，需先行因應 |
| 4. 市場流動性轉壞 | QT（縮表）後預備金持續下降，需降息+放緩縮表避免資金斷鏈 |

### 2026年聯準會展望

- **投票委員輪換**：2026年新上任四位地方聯儲理事，多數不支持降息
- **通膨目標**：回到2%的時間點可能延至2027年
- **鮑威爾任期**：至5月底，川普可能提前提名繼任者
- **關鍵風險**：若繼任者明確支持大幅降息，市場可能提前反應

## 名詞解釋

| 名詞 | 說明 |
|------|------|
| FOMC（Federal Open Market Committee） | 聯邦公開市場委員會，美國聯準會負責貨幣政策決策的機構 |
| QT（Quantitative Tightening） | 量化緊縮，聯準會縮減資產負債表的行為 |
| 預備金（Reserve） | 銀行存放在聯準會的資金，反映市場流動性 |
| 美元指數（DXY） | 衡量美元對六種主要貨幣的加權平均匯率指標 |
| KD指標 | 隨機指標（Stochastic），判斷超買超賣的技術指標 |
| CPO（Co-Packaged Optics） | 共封裝光學，將光學元件與交換晶片整合封裝的技術 |
| Palantir | 美國大數據分析公司，大量承接國防部與政府合約 |
| SpaceX | 馬斯克旗下太空探索公司，預計2026年IPO掛牌 |
| ASIC | 特殊應用積體電路，為特定用途客製化設計的晶片 |
| 債務上限（Debt Ceiling） | 美國政府法定的舉債上限，到期需國會表決延長 |
| 政府關門（Government Shutdown） | 美國預算未通過時政府機構停擺的狀態 |
