## 產業分析與投資建議

### 1. 信驊（5765）——股王分析

**獨霸AI伺服器BMC（遠端控制晶片）的三大壁壘**：

| 壁壘類型 | 內容 |
|----------|------|
| 資金壁壘 | 每款晶片研發成本約2,000萬美元，遠超一般競爭者承受能力 |
| 時間壁壘 | 從開發到驗證到量產需3-4年甚至十幾年，八個世代研發經驗 |
| 客製化壁壘 | 為客戶量身打造產品，非通用型，深度綁定供應鏈 |

**關鍵轉型**：成功從消費性電子BMC轉型為AI伺服器BMC，是少數從消費性電子成功轉型AI基礎建設的公司。

**公司特色**：
- 員工僅144人，「藍海戰術」非「人海戰術」
- 章程明訂：年度獲利提撥八成給員工分紅
- 2011年獲英特爾投資，2016年被博通旗下子公司併購後整合軟硬體能力

| 操作建議 | 內容 |
|----------|------|
| 支撐價位 | 收盤守住本波低點6,405元不會轉弱 |
| 觀察指標 | 十日均線為轉弱關鍵 |
| 風險 | 競爭者進入威脅，高本益比 |
| 催化劑 | 主動式ETF（00981、00991）大量納入 |

#### 個股詳細分析

**聯測（6658）**
- 做AI視覺檢測，可應用於PCB組裝、智慧管理
- 股價約58元，價格不貴
- 12月底開始放量突破，資金壓寶題材
- 模式：前段跌不動、近期開始放量 = 有戲

**宇隆**
- 從汽車金屬機構件轉型至伺服器水冷快接頭
- 股價約200元，中長線看
- 外資12月有回補跡象
- 為轉型股，比較需要時間

**億頂（SSD/記憶體概念）**
- 類似群聯第二，有SSD業務
- 正從記憶體循環谷轉型至邊緣AI
- 沿月線上攻模式，跌到月線後反彈
- 與預創（5351）均有參展CES

**新科**
- 進度把材與感測材料供應
- FOP封裝與低軌衛星經片合拍
- 美國客戶擴產
- 12月慢慢放量上攻

## 黃金與白銀分析（起展）

### 白銀趨勢

| 項目 | 分析 |
|------|------|
| 歷史走勢 | 2000年4美元 → 2008年21美元 → 2011年49美元（12-13倍） |
| 本波起點 | 2020年11美元，最高已達83美元 |
| 上看目標 | 若參照歷史漲幅倍數，上看100美元有機會 |
| 短線風險 | 交易所調高保證金，短線高檔震盪 |
| 投資方式 | 實體銀磚較重不便利，建議透過ETF、CFD、期貨投資 |

**四大上漲驅動力**：
1. 基建題材（星際資料中心、太陽能用銀需求）
2. 太陽能與電動車需求
3. 產能難以增加（銀為副產品，需其他礦場一起開採）
4. 避險資金與投資需求

### 黃金趨勢

| 項目 | 分析 |
|------|------|
| 瑞銀目標價 | 5,000美元 |
| 技術面 | 沿月線上攻格局，回測月線守住即續漲 |
| 關鍵支撐 | 月線（移動平均線），跌破則面臨較大修正 |
| 短線 | 調高保證金後先軋空再回落，高檔震盪 |

**黃金持續看多五大因素（瑞銀觀點）**：
1. 美國低利率環境，存款吸引力下降
2. 全球經濟風險的避險需求
3. 全球央行買盤（資產多樣化、去美元化）
4. 各國債務持續創新高，通膨率為隱憂
5. 黃金有實體投資價值，不會被無限印製

### 美元指數

- 今年貼幅接近9%
- 從年初超過4.8%一路下行
- 目前被月線壓住，若持續被壓制代表修正未結束
- 關鍵變數：2026年關稅政策能否順利推行

## 技術面分析與操作策略

### 黃金操作策略
- **多頭格局**：沿月線上攻，回測月線守住就續漲
- **關鍵價位**：月線為多空分界
- **守住 = 長多拉回**；跌破 = 面臨較深修正

### 白銀操作策略
- 短線高檔震盪，交易所調高保證金洗籌碼
- 從高點回落約200美元（以期貨計），已洗掉部分投機資金
- 守住月線後可望沿線慢慢向上

### CES概念股操作策略
- 選股標準：股價不貴 + 12月才開始上漲 + 有放量
- 模式：前段跌不動 → 12月底放量突破 = 壓寶2026年Q1旺季
- 聯測、宇隆、新科均符合此模式
