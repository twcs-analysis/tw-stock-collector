## 市場總體觀察

### 台股

- **封關數據**：2025年12月31日台股亮麗封關，大盤上漲256點，收在28,963點，距離29,000點僅一步之遙

- **年度漲幅**：台股全年上漲5,928點，漲幅25.7%
- **五大紀錄**：
  1. 台積電再創歷史新天價，全年漲幅46%，市值突破40兆

  3. 股王信驊漲至7,715元，創台股天花板
  4. 台面上27檔千金股
  5. 電子指數、金融指數均創歷史新高
- **三大法人**：外資、投信、自營商均呈現賣超，但台積電帶動指數上漲
- **年度漲幅前十**：德鴻、南亞科、堅鼎、華邦電、金居、凱威、華東、國精化、傾沉、竹身科技

## 技術面分析與操作策略

### 大盤技術面
- 大盤收28,963點，上漲256點
- 29,000點為短期天花板，台積電帶動
- 電子佔比偏高（80%），非電子僅17%，有過熱疑慮

### 個股操作策略
1. **半導體封裝**：嚴守週線操作，跌破五日均線需注意
2. **創近期高個股**：以十日線或月均線為強弱關鍵
3. **台積電法說（1/15）**：為半導體產業轉折時點，此前偏多操作
4. **舊曆年前**：族群輪動搶紅包行情，1/15後可能開始變化
5. **2月工作天數少、3月公布年報**：投機股需謹慎

### 反應順序
1. 12月先動：封裝測試
2. 1月：特用化學
3. 2月：碳測三雄
4. 3月：觀察外資是否回補

## 名詞解釋

| 名詞 | 說明 |
|------|------|
| GAA（Gate All Around） | 環繞式閘極技術，台積電2奈米製程採用，取代FinFET，蝕刻難度更高 |
| FinFET | 鰭式場效電晶體，3奈米及以上製程使用的電晶體結構 |
| CoWoS | 台積電先進封裝技術（Chip on Wafer on Substrate） |
| FoWLP（Fan-Out Wafer Level Packaging） | 扇出型晶圓級封裝，群創佈局的先進封裝技術 |
| BMC（Baseboard Management Controller） | 基板管理控制器，信驊獨霸的AI伺服器遠端控制晶片 |
| KD指標 | 隨機指標，用於判斷超買超賣及趨勢轉折 |
| 碳測三雄 | 指閎康、汎銓、驗測三家半導體檢測公司 |
| 主動式ETF | 由基金經理人主動選股操作的ETF，與被動追蹤指數不同 |
