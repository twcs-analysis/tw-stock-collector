## 💼 產業分析與投資建議

### 1. 聯電（2303）— 價值投資標的浮現
- 外資從9月以後幾乎持續買進，今日大買54,000張
- 打入美國機器人製造供應鏈的題材發酵
- 晶圓代工產業中，獲利遠超力積電，但股價漲幅遠不及
- **50元為頸線壓力**，突破後加上投資美國題材，有機會加速漲勢
- **展望**：明年成長性絕對比今年好，外資仍會繼續買進

### 2. PCB族群 — ABF載板主題
- **欣興（3037）**：創歷史新高，外資與投信同步買超
  - 前三大買進券商無台積太費（非隔日沖訊號），可稍微放心
- **南電（8046）**：PCB專業，法人布局中
- **大量（3167）**：PCB專業廠，投信買超
- **操作建議**：PCB族群走勢整齊，下週ABF載板有望成為輪動方向

### 3. 12月操作策略 — 至英老師完整框架

#### 時間節奏
| 時間段 | 策略重點 |
|--------|---------|
| 12月上旬 | 外資主導，跟著外資買的大型AI股操作 |
| 12月中旬（15日） | 分水嶺，外資影響力減弱（準備放假） |
| 12月中下旬 | 投信主導（拚年底績效），跟著投信買的股票操作 |
| 12月底 | 跌深中小型股有一擊之力，做夢時間到來 |

#### 核心邏輯
- 營收公布完後，到明年1月財報、3-4月年報前，沒有基本面地雷風險
- **最強做夢時間**：12月中下旬開始，中小型股一定有表現機會
- 題材主導盤面，看市場接受什麼新花樣
- 手上跌深股不要再殺，資金還是會輪到

### 4. 軍工族群 — 投信最愛的中小型股
- **政策題材**：全球軍備擴張，無人機為國家戰略方向
- **雷虎（8033）**：
  - 無人機國家隊領頭羊，明年法人預估EPS約9-10元
  - 本益比約13-15倍，不算高
  - 目前被處置交易（關起來），量縮有利短線當沖籌碼洗清
  - 技術面：缺口支撐未補，底部整理完成，準備挑戰前高
  - **放出來之前就會先漲**
- **億勤（2465）**：
  - 所有軍事進攻彈藥獨佔，萬台標案商機
  - 連續被處置（關20分鐘），越關越大量
  - 底部整理中，準備挑戰前高
- **其他**：中光電（5371）、韓翔——量大適合當沖/隔日沖

### 5. 記憶體 — 整理期操作法
- **南亞科（2408）**：150元以下買進，若回到160-170再減碼，區間操作
- **華邦電（2344）**：60元以下買進，接近68-69先賣一次
- **群聯（8299）**：股價從1,300-1,400跌到1,050附近，空間大
  - 1,000元以上都是買點，至少有一成多空間
- **創見（2451）**：營收漂亮但沒漲，外資在賣，通路模組利潤不如顆粒廠
- **核心觀點**：記憶體重點在顆粒（華邦電、南亞科），非模組/通路

### 6. BPU（不斷電系統）— 即將輪動的主流
- **台達電（2308）**：龍頭，需站穩1,000元才能帶動族群
  - 回到頸線打底，趨勢準備向上突破
- **AES-KY（6781）**：法人預估明年成長不遜今年
- **系統電（5309）**：除BPU外還有無人機題材，Google似乎供應鏈
- **新盛力（4931）**：低價股，被處置中，底部整理完成
  - 量從放大到縮小，代表籌碼沉澱，下週仍有攻擊力
  - **至英老師短線首選**
- **觀察重點**：近兩週AI盤中常有人點火BPU個股（盛達、新盛力、順達），籌碼面偏多

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **MSCI成分股調整** | 摩根士丹利資本國際指數定期調整成分股，新納入個股將吸引被動式基金（ETF）強制買進 |
| **集團作帳** | 年底集團透過旗下公司互相買進股票以維護股價、美化財報的行為 |
| **ABF載板** | Ajinomoto Build-up Film的縮寫，高階IC封裝載板，為AI晶片封裝關鍵材料 |
| **台灣病** | 經濟學人提出的概念，指台灣長期壓低匯率促進出口，導致低薪高房價、消費疲弱的結構性問題 |
| **荷蘭病** | 一個產業（如能源）特別好導致匯率升值，打擊其他產業出口競爭力的經濟現象 |
| **處置交易** | 證交所對連續漲停或異常交易股票實施的限制措施，如需預收款項、每20分鐘撮合一次等 |
| **類主權基金** | 利用國家外匯存底或公共資金設立的投資基金，用於投資國內外產業促進經濟轉型 |
