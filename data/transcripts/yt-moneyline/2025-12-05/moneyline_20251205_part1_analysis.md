# 錢線百分百分析報告 - 2025-12-05（上集）

## 📺 節目資訊
- 播出日期：2025-12-05
- 集數：上集
- 來賓：王健全（中經院副院長）、至英老師（技術分析專家）
- 主持人：鄧海明
- 主題：聯準會降息前瞻、台股逼近28000點、散熱族群創高、美國期中選舉年電力商機

## 📊 市場總體觀察

### 台股走勢
- **收盤**：27,980點，上漲185點，差20點即回到28,000點大關
- **成交量**：4,500億元
- **外資動態**：大幅買超368億元，12月已累計買超525億元，連續4天站在買方，顯示12月外資態度轉趨積極
- **投信動態**：連日調節轉賣，但規模不大（不到5億）
- **自營商**：買超56億
- **三大法人合計**：買超420億
- **龍頭股表現**：台積電收1,460元（+15元），鴻海收231元（+2.5元），尾盤拉抬貢獻大盤約120點

### 美股影響
- 納斯達克與費半均回到挑戰前高位置，市場等待聯準會12月利率決議
- 降息預期從兩週前的37%升至本週的90%，幾乎板上釘釘
- 市場真正關注的是降息後鮑爾的談話——偏「鴿派」還是「鷹派」，這將決定明年降息節奏
- 高盛報告暗示明年利率可能跌破3%

### 國際市場動態
- **聯準會新主席人選**：哈薩特（Kevin Hassett）呼之欲出，曾任川普第一任經濟顧問，主張大幅降息，甚至表態「應一次降兩碼」
- **華爾街擔憂**：哈薩特若上任，聯準會恐失去獨立性，財政主導貨幣政策，類似1971年尼克森時代的伯恩斯（Arthur Burns），可能引發通膨與美元信用危機
- **歷史對照**：英國特拉斯（2022年財政擴張引發債市崩盤）、日本高市早苗（延續安倍經濟學的擴張性財政）
- **BDI指數**：突然跳水，傳因俄烏停戰談判受阻，散裝航運股出現回檔

## 💼 產業分析與投資建議

### 1. 散熱族群 — 健策（3653）突破天花板
- **健策**：衝破3,000元大關，外資目標價喊到5,000元，成交僅4,000多張，籌碼被鎖定
  - 外資有備而來，報告確認前景，領頭羊地位確立
  - 被納入MSCI 0.5零成分股調整名單，有望持續吸引被動式基金買盤
- **奇鋐（3017）、雙鴻（3324）**：低檔整理完畢，下週若健策繼續走高，這兩檔有望跟進
- **操作建議**：散熱族群為下週重點觀察方向，健策站穩3,000元後可順勢做多，奇鋐與雙鴻為補漲標的

### 2. 記憶體族群 — 利多不漲，耐心等待
- **南亞科（2408）**：形態整理中，判斷將持續整理到月底，高出低進操作
- **華邦電（2344）**：相對較強，60元附近為操作區間
- **基本面**：DDR5報價趨緩但DDR4持續上漲，美光宣布消費性記憶體產品停產有利漲價
- **操作建議**：11月中高點後降溫已半個多月，短線以區間操作為主，等待更大利多催化劑

### 3. 機器人族群 — 短線題材，非主流
- 羅昇（8374）、銀漢等持續亮燈，但索羅門（2359）今天開高走低
- 機器人股缺乏獲利數字支撐，目前為做夢階段，適合隔日沖或當沖，不適合波段操作
- **結論**：資金主流仍繞著AI走，機器人族群走不遠

### 4. 台積電（2330）與鴻海（2317）— 穩健但缺乏爆發力
- **台積電**：
  - 今年EPS約65元，明年預估78-80元，本益比18倍「太便宜」
  - 若以明年80元EPS乘以25倍本益比，合理價2,000元
  - 外資12月已轉買超，累計買超4,900張
  - 短線受限於資金面（市場焦點在Google TPU相關概念股），非基本面問題
- **鴻海**：
  - 營收月減5.7%為正常季節性表現（每年10月為年度高點，11月都會回落）
  - AI營收佔比尚未達五成以上，待明年毛利率數據確認AI挹注力道
  - 月線233元為關鍵支撐，守穩後底部完成
  - 明年法人預估EPS 7-19元，本益比約13倍，估值不貴

### 5. 電力基建 — 川普救民調的選舉年商機

#### 背景分析
- 川普支持度民調僅36%，65%受訪者不滿生活成本，電價四年漲約四成
- 資料中心需求從60GW將翻倍至130GW（2030年），美國電網平均使用壽命超過40年
- 川普10月底簽署行政命令解決電力問題，選舉行情由此開打

#### 三大商機與個股
**（一）變壓器**
- **華城（1519）**：外銷比重五成，訂單看到2028年，有機會提前出貨
  - 法人預估EPS 21-27元，目標價800-1,000元
  - 技術面：打底完成後突破頸線，回測位置為波段甜蜜價
  - **至英老師首選**
- **士電（1503）**：股價僅百元出頭，外銷比重15%且有機會攀高
  - 法人預估EPS約9.18元，相對安全

**（二）燃料電池（SOFC）**
- **高力（8996）**：Bloom Energy供應鏈，明年為燃料電池元年
  - 法人預估EPS 17-25元，目標價約700元

**（三）BPU（不斷電系統）**
- **AES-KY（6781）**：營收年增約七成，明年EPS預估挑戰60元
  - BBU成本低（每機櫃約20萬美元 vs. GPU 300-400萬美元），資料中心必備保險
  - 注意：近期漲幅大，12月20日開始解除分盤交易

- **康舒（6282）**：寶佳團隊旗下，Bloom Energy相關供應鏈

## 📈 技術面分析與操作策略

### 大盤技術面
- **均線**：週線開口未縮小，五日線支撐良好，從26,000上來無破五日線
- **KD指標**：已進入高檔區，但在外資持續買超下有機會鈍化
- **關鍵支撐**：27,400點（週線支撐）、五日線
- **關鍵壓力**：28,000點
- **操作策略**：除非收盤跌破五日線才需轉保守，否則維持做多

### OTC櫃買指數
- 相對較弱，之前跌破頸線後重新站回，仍在整理格局
- AI股較少，12月中下旬跌深股有望補漲
- 上旬資金仍偏向AI主流，中下旬才可能輪動到中小型股

### 下週操作建議
- **前半週**：美股與台股可能維持整理，等待12月18日（週三）聯準會決議
- **後半週**：決議公布後才決定真正走向
- **12月15日分水嶺**：15日前外資主導（大型股為主），15日後投信主導（中小型股為主）

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **RMP（Reserve Management Purchases）** | 準備金管理採購，聯準會可能採用的新型量化寬鬆（QE）方式，購買短期國債，每月約注入200億美元流動性 |
| **YCC（Yield Curve Control）** | 殖利率曲線控制，日本央行透過大量購債來壓低長期利率的政策工具 |
| **SOFC（Solid Oxide Fuel Cell）** | 固體氧化物燃料電池，透過天然氣轉換成電力，轉換率可達60%，部署時間僅90-120天 |
| **BBU/BPU（Battery Backup Unit）** | 電池備援裝置，資料中心用於防止停電導致設備損壞的備用電源 |
| **KD鈍化** | KD指標在高檔區持續運行而不回落，通常發生在強勢多頭行情中 |
| **伯恩斯（Arthur Burns）** | 1970年代聯準會主席，在尼克森施壓下大幅降息，導致後來的高通膨 |
| **尼克森震撼** | 1971年美國宣布美元與黃金脫鉤，結束布列頓森林體系，引發國際金融恐慌 |
