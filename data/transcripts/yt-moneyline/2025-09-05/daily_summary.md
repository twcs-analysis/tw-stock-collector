- **台積電**: 尾盤拉升20元做收，距歷史新高價僅差20元

#### 外資動態（關鍵訊號）
- **連續第四天加碼**，每天買得比前一天更多
- 現貨買超282億元，台積電為買超第一名（11,000多張）
- 期貨空單一口氣回補2,199口，空單水位降至近期新低（21,000多口）
- **台幣升值**：盤中升值超過1.6角，創四個月來新高
- **核心判斷**: 台幣升值 + 外資買超 + 空單減少 = **真正看多的外資**（非套匯資金）

### 二、美股與國際市場

#### 美股動態
- NASDAQ/費半：高點附近震盪，費半尚未跌破頸線
- 輝達：財報不如極高預期，但股價仍在區間震盪未崩
- 蘋果：出現跳空多方缺口，高點239.899美元
- 9月降息機率已達99%，確定降息

#### 全球長債風暴（重大風險警示）

| 國家 | 30年期殖利率 | 風險狀況 |
|------|------------|---------|
| 英國 | 5.7% | 創1998年來新高，英鎊跳水，養老基金高槓桿風險 |
| 法國 | 4.5% | 政局不穩，9/8信任投票，右翼可能擴大支出 |
| 日本 | 持續上升 | 放棄YCC，40%預算用於償債，利率上升惡化財政 |
| 美國 | 暫穩（4.15%） | 達理歐警告已近危險區，關稅收入是國債信心關鍵 |

- **黃金大漲原因**: 主要國家公債全面出問題，大資金別無選擇只能買黃金
- **死亡螺旋風險**: 財政赤字擴大 → 發債增加 → 殖利率飆高 → 利息更多 → 赤字更大
- **降息矛盾**: 聯準會降短期利率，但房貸車貸綁定10年期長債。去年降息後10年期反升1.1%

## 📚 名詞解釋

### 總經與債市

| 術語 | 定義 |
|------|------|
| **殖利率** | 債券持有至到期的年化報酬率。殖利率上升 = 債券價格下跌 |
| **YCC** | 日本央行控制10年期公債殖利率在特定範圍的政策（已放棄） |
| **QE/QT** | 量化寬鬆（央行買債注入流動性）/ 量化緊縮（央行縮減資產負債表） |
| **死亡螺旋** | 赤字→發債→殖利率升→利息增→赤字更大的惡性循環 |
| **套匯外資** | 透過現貨買超 + 期貨放空賺匯差的外資，特徵是台幣升值時空單增加 |

### AI與半導體

| 術語 | 定義 |
|------|------|
| **MCIO連接器** | 專供AI伺服器的高速連接器，價值是通用型的2-3倍 |
| **矽光子** | 用矽基材料製造光學元件，取代銅線連接的技術 |
| **LPO** | 線性驅動可插拔光模組，400G/800G已商用 |
| **CPO** | 共同封裝光學，光學晶片與AI晶片封裝在一起，2026年商用 |
| **1.6T** | 下一代光模組傳輸速率，800G的升級版 |
| **TKR14** | 高階印刷電路板用高頻高速低損耗基板材料 |

### 蘋果與通訊

| 術語 | 定義 |
|------|------|
| **Apple Intelligence** | 蘋果AI功能套件，含翻譯、視覺辨識、來電過濾等 |
| **WiFi 7** | 最新無線通訊標準（802.11be），更高頻寬更低延遲 |
| **低軌衛星** | 距地面500-2,000公里的通訊衛星（如SpaceX Starlink） |

### 技術分析

| 術語 | 定義 |
|------|------|
| **飆股「一座山」** | 快速上漲3-6個月後，1-3年跌回起漲點的走勢形態 |
| **本夢比** | 公司尚未獲利或獲利極低時，以未來夢想估算的估值 |
| **資金外溢效應** | 某族群獲利了結後，資金轉向同產業中尚未大漲的標的 |
| **處置股** | 股價連續大幅波動後被交易所限制交易的股票，通常難再創新高 |
| **現貨價穿越合約價** | 供不應求訊號，代表未來合約價將上調（報價黃金交叉） |
