### 美股市場觀察

#### NVIDIA（輝達）技術分析
- 股價在半年線附近獲得支撐
- 上週五從低點反彈，站回180美元附近
- 有機會形成小雙腳底部型態
- **關鍵突破點**: 季線（突破後短底正式成型）
- 輝達帶動台積電與鴻海轉折

#### 博通（Broadcom）
- 近期修正屬於本益比修正
- 已來到半年線附近，修正幅度已過大
- 基本面無虞，短線先看反彈
- 成長性高的產業本益比修正後容易回升

#### Palantir（盤貼）
- 從200美元修正，本益比過高導致劇烈修正
- 目前走勢類似盤整，可參考過去盤整後的漲勢

#### 甲骨文（Oracle）
- 負債很高、合約金額龐大（歐本等約5,000億）
- 市場擔憂AI泡沫，部分法人將甲骨文當作AI泡沫的對沖標的
- 若跌不下去，代表AI泡沫避險需求消退，對整體AI族群有利
- **關鍵位置**: 需回到年線以上站穩

#### 其他美股觀察
- **美光**: 創歷史新高（280+），財報與展望俱佳，明年持續缺貨，本益比僅10倍出頭
- **Lumentum（努門騰）**: 光通訊龍頭，股價接近歷史新高，AI修正與其無關
- **MangoDB**: 資料庫管理（橫向管理），AI應用需求強勁，股價創歷史新高

### 2026年AI產業展望

#### 雲端與硬體持續強勢
- 全球資料中心資本支出可能挑戰6,000億美元（今年約3,000-4,000億）
- 主權AI加入佈局（星際資本、日本、中東等國家級資金）

#### ASIC崛起
- 資料中心優化與降低成本需求
- Google TPU等客製化晶片需求增加

#### 半導體先進製程紅利
- GPU或ASIC都需要台積電代工
- 三奈米量產最成熟，明年開始轉向兩奈米
- 台積電三奈米與兩奈米供不應求

#### 推論市場爆發
- NVIDIA GPU開始量產出貨
- 訓練完大模型後進入推論應用階段
- Gemini、ChatGPT等應用帶動推論需求

#### 2026年AI六大趨勢
1. **AI代理人與多智慧系統**: 從聊天機器人升級為可自主執行的AI代理人
2. **多代理協作**: 不同AI系統互相對話與協作（矽基勞動力團隊）
3. **實體AI與機器人**: 工業5.0（AI+機器人），特斯拉Robo Taxi、人形機器人
4. **邊緣AI滲透率激增**: 解決隱私問題與低延遲需求
5. **通用大模型與特定領域模型分流**: 小型化模型針對醫療、法律、製造等領域
6. **AI應用大規模部署**: 帶動軟體、邊緣運算、雲端服務全面成長

### 台積電 (2330) 法說會前瞻

#### 法說會三大亮點

**亮點一：廠務工程與二次配**
- 台積電資本支出歷史最高（約1.5兆台幣）
- 70-80%投入先進製程與產能擴充
- 20-30%投入CoWoS升級與全球建廠
- **第一波投資機會: 二次配廠商**
  - 二次配 = 將昂貴機台接上水電瓦斯，使其運作
  - 包含電力、氣體、化學品、超純水、真空與排氣

**二次配相關個股**:

| 股票 | 在手訂單 | 本益比 | 備註 |
|------|---------|--------|------|
| 亞翔 | 2,208億元 | 24倍 | 股性活潑，訂單最多，但估值已高 |
| 漢唐 | 1,000多億元 | - | 上週轉強，修正過本益比 |
| 帆宣 (6196) | 900億元 | 最便宜 | 相對低價，推薦首選 |
| 央機工程 | 約500億元 | - | 上半年先動 |
| 聖暉 | 約500億元 | - | - |

- **推薦策略**: 保守選帆宣（最便宜），強勢股選亞翔（拉回時佈局）

**亮點二：三奈米相關設備**
- AI晶片全部導入三奈米，台積電轉價能力強
- 客戶不敢取消訂單（怕CSP廠搶走）
- **推薦個股**:
  - **弘塑 (3131)**: 先進封裝設備，機台訂單已到明年上半年，法人預估EPS 52元，目標價合理在2,000元以上（40倍本益比），目前在年線附近糾結，等法說會確認產能後可能發動
  - **低價設備股**: 高階PCB含先進封裝比重接近六成，近期拉回修正中

**亮點三：兩奈米相關耗材**
- 兩奈米切入GAA（閘極全環）與背面供電
- 需要更多耗材
- **推薦個股**:
  - **光洋科**: 法說會預估靶材營收比重拉高到20%，EPS預估4.3元，本益比20倍目標價86元（現價64元），K線底部型態突破均線
  - **崇山**: 背面供電需將晶片磨更薄，法人持續買超，整理太強幾乎是無量整理
  - **模樣科**: 碳化矽晶圓用量增加，已做資本支出擴大，明年產能120萬片，法人預估EPS 7元，目標價挑戰200元

- **股性比較**: 股性最活潑是崇山，空間最大是光洋科

## 名詞解釋

| 名詞 | 解釋 |
|------|------|
| 二次配 | 半導體廠務工程中，將機台設備接上水電、氣體、化學品等使其運作的工程 |
| CoWoS | 台積電先進封裝技術（Chip on Wafer on Substrate） |

| 背面供電（BSPDN） | A16製程技術，從晶片背面供電以提升效能 |
| NanoFlex | A14製程技術，彈性奈米片可變寬或變窄 |
| 主權AI | 各國政府主導的AI投資計畫，如美國星際資本、日本、中東等 |
| ASIC | 特殊應用積體電路，針對特定應用設計的客製化晶片 |
| SMR | 小型模組化核反應器（Small Modular Reactor），建制成本低、可靈活部署 |
