### 台積電 (2330) 核心價值深度分析

#### 營收成長動能計算
- **三奈米**: 今年底產能11萬片 -> 明年底16萬片（月增加5萬片）
- **兩奈米**: 今年底4萬片 -> 明年底10萬片（月增加6萬片）
- **兩奈米單價**: 約3萬美元/片
- **增量營收估算**:
  - 兩奈米增加6萬片 x 3萬美元 = 18億美元/月 = 540億台幣
  - 三奈米增加約4萬片 -> 約200多億台幣
  - 合計增加約700-800億/月
  - 台積電目前月營收約3,500億，增幅達20%+
- **結論**: 外資預估營收成長三成合理

#### 外資目標價彙整

| 外資機構 | 目標價（台幣） | 備註 |
|---------|--------------|------|
| 某外資 | 2,100 | 最早預估破2,000 |
| 花旗 | 2,050 | - |
| 摩根、史萊尼 | 1,888 | 用2027年EPS 104元 x 18倍，偏保守 |
| 法人平均 | 1,800 | - |
| ADR換算 | 2,200-2,500 | 扣除溢價後約1,800-2,000 |

#### 大摩估值解析
- 使用2027年EPS 104元 x 18倍本益比 = 1,872元（四捨五入1,888）
- **質疑**: 台積電過去平均本益比約20倍，18倍偏保守
- **若用20倍**: 104 x 20 = 2,080元（兩千並不難）

#### 台積電對大盤貢獻度
- 台積電每漲1元，貢獻台股約8點
- 若帶動日月光、精圓電、鴻海等權值股，每點貢獻約12點
- **若台積電漲至1,888元**: 從今日收盤1,465元計算，漲423元
  - 帶動指數約5,000點
  - 大盤可望來到33,000多點

#### 台積電技術面
- 今日重新站回所有均線
- 季線已多次測試不破
- 突破下降反壓線後，將形成波段漲勢
- 盤後巨額交易以漲停價成交（不需過度解讀）
- **空壓工具**: 之前因台指結算與三巫日被壓，現在空壓任務解除

## 全球央行政策與降息展望（提號分析）

### 美國經濟數據矛盾

#### CPI通膨數據疑慮
- CPI年增率僅2.7%，遠低於市場預期
- 住房通膨月增幅僅0.13%（過去平均約0.5%），下滑過快
- **質疑原因**:
  - 10月政府停擺導致統計數據失真
  - 美國勞工統計局（BLS）僅剩1,900人（川普裁員）
  - 數據採集比例從90%下滑到60%
  - 40%物價用網路推算（非實地調查）
- **結論**: 趨勢確實往下，但幅度可能有失真

#### 就業數據分化
- 非農新增6.4萬個就業崗位（好消息）
- 失業率卻創4年新高至4.6%（壞消息）
- **關鍵發現**: 2022年後標普指數持續上漲，但職位空缺數持續下降
- **解讀**: AI改變勞動力市場結構，企業採用AI減少員工 -> 企業利潤提升 -> 股市上漲
- 就業數據與股市已脫鉤

#### 通膨下行風險評估
- 大宗商品ETF流入量持續增加（金價、銀價、銅價輪流創高）
- 工業用原物料年增率已達10%
- 歷史上這兩個指標與CPI高度連動
- **擔憂**: 2026年若經濟持續好轉，通膨可能失控

### 2026年降息展望

#### 提號觀點: 降息將超過點陣圖預期
- 點陣圖預期降息1-2碼
- 實際可能降息3-4碼
- **核心邏輯**: AI生產力週期加速 -> 科技產品成本下降 -> 通縮效應 -> 允許在稍高通膨（2-3%）下繼續降息

#### 格林斯潘1990年代先例
- 1997年通膨接近3%，格林斯潘僅升息一碼
- 相信網路革命的生產力提升速度夠快會壓低物價
- 1995-2000年維持低利率，那斯達克從1,000點漲至6,000點（翻6倍）
- **類比**: 2026年AI生產力週期 = 1990年代網路革命

#### 川普因素
- 民調從年初14%降至36%（蓋洛普），中期選舉壓力大
- 已進行大規模農產品關稅撤銷（咖啡、香蕉、牛肉等）
- 各國實際對等關稅比重不高（台灣僅23%，半導體關稅可能永遠不會出來）
- **唯一風險**: 電力價格（AI資料中心用電推升）

#### 投資結論
1. **利率敏感資產有機會拉升**: 債券型資產、景氣循環股、實業股
2. **中小型企業脫氣太久**: 不管美國還是台灣，過去十年中小型企業與傳產都沒有真正脾氣太大，明年可能迎來真正的景氣復甦
3. **AI生產力提升速度是關鍵**: 若速度夠快 -> 低通膨+大降息+股價持續上漲（重現1990年代末榮景）

## 名詞解釋

| 名詞 | 解釋 |
|------|------|
| 隔日沖 | 外資或主力當日大買推升股價，隔日開高即賣出獲利了結的短線操作手法 |
| 點陣圖 | 美國聯準會成員對未來利率預期的投票分佈圖 |
| 三巫日 | 美國股票期權、指數期權、指數期貨同時到期的日子（每季第三個週五） |
| FOMC | 美國聯邦公開市場委員會，決定利率政策的機構 |
| BLS | 美國勞工統計局（Bureau of Labor Statistics），負責統計就業與物價數據 |
| 格林斯潘 | 前美國聯準會主席（1987-2006），1990年代維持低利率支撐科技股 |
| 生產力週期 | 科技創新（如AI）提升生產效率，降低成本，產生通縮效應的經濟循環 |
| K型經濟 | 經濟復甦呈現K字形分化，部分產業（如科技）大好，部分產業（如傳統）衰退 |
| 光纖陀螺儀（FOG） | 利用光纖中光束干涉原理測量角速度的感測器，用於導航定位 |
| CSP | 雲端服務供應商（Cloud Service Provider），如AWS、Azure、Google Cloud |
