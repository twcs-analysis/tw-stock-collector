## 📊 市場總體觀察

### 美股與總經環境

#### 聯準會經濟預測（2025-2028）
- **GDP成長率**: 2025年約1.6%，2026年1.8%，2027年持續上升 → 經濟成長趨勢明確
- **失業率**: 從4.5%逐步下降至4.3% → 就業市場穩定
- **通膨率**: 今年約3%，明年降至2.6%，後年降至2.1% → 不存在停滯性通膨疑慮
- **結論**: 經濟成長、失業率下降、通膨可控 → 股市完美劇本

#### Morgan Stanley（大摩）觀點
- 鮑爾雖表示美股估值偏高，但大摩認為即便修正也只是小幅休息
- 今年年初漲的股票，年末還會再漲一次

### 台股判斷：主升段還是末升段？

#### 非末升段的四大證據

|------|-----------|---------|------|
| **成交量** | 價漲量縮，追價力不足 | 維持5,000億，量價配合正常 | 非末升段 |
| **融資餘額** | 快速飆高 | 未出現大幅增加 | 非末升段 |
| **法人動態** | 法人轉大量賣出 | 外資仍有買超日，投信季節性調節 | 非末升段 |
| **投機氛圍** | 全面瘋狂追價 | 仍以法人、散戶均衡買進 | 非末升段 |

#### 大盤走勢分析
- 從股災低點至今日高點，加權指數上漲9,098點（近萬點）
- 若排除4月關稅恐慌的急跌急漲，實際走勢為一條漂亮的上升趨勢線
- AI產業景氣自2023年啟動，參照過去手機十年、電腦十多年的循環，目前僅第二至三年，不會太早結束

### 資金與籌碼面
- 融資餘額：4月份曾減少約1,000億，目前回補不到十分之一至二
- 外資：近期小幅賣出但未大規模出逃
- 投信：整個9月持續賣超，但屬季節性調節
- **判斷**: 投信10月有望牛轉，當加權指數在26,000點以上而中小型股轉強時，投信就會回來

## 💼 產業分析與投資建議

### 一、第四季布局策略 — GB300放量帶動

#### GB300出貨展望
- 原定第二季末出貨，延遲至9月開始小量出貨
- 第四季將正式放量，且延續至2026年全年
- 技嘉等廠商已開始出貨

**受惠產業鏈**:
- 台積電 → 散熱 → PCB → 銅箔基板 → 機殼 → BBU
- **結論**: 上個月（9月中旬前）流行的AI供應鏈族群，有機會在第四季再跑一輪

#### 第四季選股策略

**策略一**: 上個月流行的AI族群拉回後再度發動
- PCB、銅箔基板、散熱、機殼、BBU等
- 股價整理過後反而是好的買點

**策略二**: 法人持續進場 + 融資未大幅追加 + 長線低檔區
- 找籌碼穩定、法人買進、股價在長線低檔區的標的
- 包括被動元件族群也符合此條件

### 二、記憶體產業 — AI推論時代接棒

#### 從AI訓練到AI推論的轉換

**AI訓練時代（過去兩年）**:
- 以HBM（高頻寬記憶體）為主
- 大量矩陣運算、隨機存取
- 台廠優勢有限（花邦電的「類HBM」）

**AI推論時代（現在開始）**:
- 以DRAM/NAND為主，台廠長期耕耘的領域
- 需要大量存取、資料存儲
- 算力需求低於訓練，但資料吞吐量更大
- 美光直接承認此次漲價非利潤性調整，而是供需失衡的急迫反應

**時程預估**:
- 2026年：推論營收與訓練營收達到1:1（均為千億美元級別）
- 2027年：資料中心建置高峰期
- 2030年：AI推論全面普及

**投資建議**:
- 記憶體短線漲多休息，但不會消聲匿跡
- 產業基本面支撐明確，拉回後仍有機會

#### Oroco聯盟 — 永動機模式

**資金循環邏輯**:
1. NVIDIA投資OpenAI → OpenAI有錢下訂單給甲骨文
2. 甲骨文向NVIDIA買GPU → NVIDIA營收來源
3. OpenAI租用甲骨文雲端資源 → 甲骨文營收來源

**市場意義**:
- 不會只漲一段就結束
- 每家公司互相補充資金缺口，形成良性循環
- 即使AI訓練休息，推論商機也會接棒

### 三、AI推論五大受惠產業（按順序）

| 順序 | 產業 | 說明 | 預估爆發時間 |
|------|------|------|-------------|
| 1 | **記憶體** | 推論需大量存取，DRAM/NAND為主力 | 2025-2026（進行中） |
| 2 | **AI自研晶片** | 低功耗、小尺寸、即時運算的客製化晶片 | 2026起 |
| 3 | **感測器與影像處理** | 推論需輸入影像、聲音等感測數據 | 2026-2027 |

| 5 | **中端裝置 (AIPC/手機)** | 推論普及到消費端裝置 | 2028-2030 |

#### 第二棒：AI自研晶片

##### 力積電 (6770)

**基本面**:
- 外資9月份買超整整12萬張
- 主攻消費性電子，部分切入客製化晶片
- 營收表現普通，股價便宜
- 市場傳說「黃董帶我飛」

**投資建議**:
- 關週個人對力積電持保留態度
- 股價已有一段漲幅
- 公司治理與經營者爭議是考量因素

##### 晶心科 (6533) — 關週更看好的標的

**基本面**:
- RISC-V架構台廠獨特標的，無可類比
- 經典指令集可應用在ASIC客製化晶片
- 8月份營收表現不錯，股本較小
- 外資開始小幅買進佈局

**投資建議**:
- **股價**: 約630元
- **操作策略**: 多方結構未被破壞，外資溫和佈局
- **優勢**: 台廠RISC-V獨門獨戶，無可替代
- **替代方案**: 股價太高可買零股
- **比較**: 關週個人較願意買晶心科，勝過力積電

#### 第三棒：感測器與影像處理

##### 原相 (3227) — 三選一首選

**基本面**:

- 過去幾年已切入AIoT的感測器應用

- 股價約212元

**投資建議**:
- **操作策略**: 等拉回至月線附近買進
- **停損**: 多方結構不被破壞為前提
- 本週下半有美國三五日事（就業數據），可能帶來修正買點
- 三選一（原相、經相光、亞龍電）中，關週選原相（較安全）

##### 亞龍電 — 影像訊號處理晶片

- 也有切入無人機市場
- 目前股價尚未發動
- 做影像訊號處理晶片，與原相互補

### 五、巴菲特投資動態 — 賣中國、買日本

#### 比亞迪全數出清

**投資歷程**:
- 2008年買進（蒙格建議），持有17年
- 最高持股約10%，邊拉邊賣逐步獲利了結
- 2025年第一季完全出清
- **報酬率**: 保守估計3,890%（一度超過4,800%）

**出清原因**:
- 中國電動車市場競爭過度激烈（小米等新進者加入）
- 互相降價導致各大廠獲利下降
- 中國經濟不佳、需求不振
- 美國電動車補助9月底到期，後續銷售可能腰斬
- 歐洲車廠也面臨中國車的價格競爭

#### 積極買進日本五大商社

**投資標的**: 三井物產等五大商社

**日本股市現況**:
- 日經指數今年4月以來漲幅約50%（從3萬左右漲到4.5萬）
- 東證指數也在高檔附近，多頭格局未破壞
- 月線支撐明確

**波克夏海瑟威近期表現**:
- 近五年漲幅約134%（SMP500約100%、日經約100%）
- 今年以來表現落後大盤（因未持有大型科技股）
- 可能因此被低估

**台灣追蹤日本的ETF整理**:

| 類型 | 今年以來報酬 | 特色 |
|------|------------|------|
| 日經225市值型 | 約13% | 標準指數型 |
| 半導體相關 | 更高 | 受惠費半上漲 |
| 高股息型 | 略低 | 較安心穩定 |
| 五大商社型 | 值得關注 | 最像巴菲特策略 |

**投資建議**:

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **AI推論 (Inference)** | AI模型訓練完成後，實際應用於預測、辨識等任務的過程，需要大量資料存取但算力需求較訓練低 |
| **RISC-V** | 開源精簡指令集架構，可用於客製化AI晶片設計，晶心科為台灣代表廠商 |
| **ASIC (Application-Specific Integrated Circuit)** | 特殊應用積體電路，為特定用途量身打造的晶片，如Google TPU、博通AI晶片 |
| **邊緣運算 (Edge Computing)** | 將運算處理放在靠近資料來源的裝置端，而非集中在雲端資料中心 |
| **觀景窗 (處置期間)** | 證交所對異常交易股票實施的觀察期，期間改為逐筆撮合交易 |
| **馬其諾防線** | 此處指大盤的關鍵支撐點位（25,780點），跌破則多頭格局可能改變 |
| **永動機循環** | 指NVIDIA、OpenAI、甲骨文三方透過互相投資與下訂單形成的資金閉環 |
| **五大商社** | 日本五大綜合商社：三井物產、三菱商事、住友商事、伊藤忠商事、丸紅，巴菲特重點投資標的 |
| **停滯性通膨 (Stagflation)** | 經濟停滯與高通膨同時發生的情況，是最不利股市的經濟環境 |
