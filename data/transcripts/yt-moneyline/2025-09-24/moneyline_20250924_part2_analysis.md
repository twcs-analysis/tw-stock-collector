## 📊 市場總體觀察

### 台股盤勢特徵

#### 投機力大於投資力
- 大盤盤中一度跌超過200點，籌碼極度混亂
- 近期台北股市投機氣氛濃厚，做短油利成為主流
- 買指數（如0050）才賺得到錢，買個股反而很多人沒賺到
- 昨日大盤漲366點，台積電就貢獻了341點

#### 電子資金比重過熱
- 上週四、五電子股資金比重高達80%，屬於過熱區域
- 今日回落至73%，略有降溫
- 過熱導致後座力：部分強勢股開高走跌、甚至殺跌停
- **操作原則**: 電子資金比重未降至70%以下前，投資組合仍應以電子股為主（至少五成）

#### 籌碼面觀察
- 集中市場昨日大漲，但OTC市場反而下跌家數是漲家數的一倍
- 騰弱指標顯示台北股市不健康
- 外資近期由買轉賣，投信持續賣超
- 內資力量成為短線關鍵（投信與業內資金）

### 市場主流風格

當前台北股市流行四大操作風格：
1. **權值股拉抬**: 直接買權值個股
2. **低價同族群比價低的**: 找同族群中股價最低的標的
3. **右下角補漲股**: 過去沒有漲到的個股
4. **漲價效應股**: 受惠漲價題材的個股

#### NVIDIA（輝達）生態系打群架

**相關概念股轉強**:
- NVIDIA MV2相關：AI伺服器組裝公司全面轉強

### 四、被動元件 — 第三波景氣循環啟動

#### 產業循環分析

**歷史三波循環**:
| 波次 | 時間 | 驅動因素 | 代表事件 |
|------|------|---------|---------|
| 第一波 | 2012-2018 | 春天製作所產能缺口 | 國巨從300元漲到1,300元，華新科從100元漲到400元 |
| 第二波 | 2020-2021 | 疫情居家需求 | 全球搶購3C產品帶動被動元件 |
| 第三波 | 2025起 | AI產業升級 | 出貨金額已超越2018年全盛時期 |

**AI帶動的需求升級**:
- AI伺服器（如GB200/B300）每台使用約40萬顆MLCC，傳統伺服器僅2,000顆
- AI應用需要更高階規格，價格較一般品高30%-50%
- MLCC BB比（訂單出貨比）開始上升，高階產品利用率超過80%
- 應用場景涵蓋：AIPC、AI手機、電動車、機器人

**被動元件在AI產業鏈的角色**:
- **陶瓷電容 (MLCC)**: 電源穩壓、避免電壓跳動
- **電感**: 功率轉換、雜訊抑制
- **電阻**: 電流檢測
- **濾波器**: 高頻通信

## 📋 投資策略總結

### 資金配置建議
1. **現金部位**: 保持30%現金，因投機力大、風險偏高
2. **電子部位**: 電子資金比重仍站七成以上，至少五成資金放在電子股
3. **非電部位**: 電子降至七成以下才拉高非電子投資比重
4. **分批買進**: 切割資金為兩份，不要一次全押

### 強勢股處理原則
- **強勢股轉弱** → 先賣掉（如已漲一倍以上且破軌道線）
- **弱勢股被打壓許久** → 再給一點時間，可能輪動到它

### 短線操作核心
- 跟著市場主流走，不要逆勢操作
- 打群架策略：一加一大於二，跟著題材集中火力
- 輪動速度極快，需隨時調整

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **MLCC (Multi-Layer Ceramic Capacitor)** | 積層陶瓷電容，被動元件中最重要的品項，用於電源穩壓與濾波，AI伺服器大量使用 |
| **BB比 (Book-to-Bill Ratio)** | 訂單出貨比，大於1代表訂單大於出貨，產業景氣上升 |
| **CPO (Co-Packaged Optics)** | 共封裝光學，將光收發模組直接封裝在交換晶片旁，大幅提升資料傳輸效率 |
| **矽光子 (Silicon Photonics)** | 以矽為基礎的光電整合技術，用於高速資料傳輸，台積電主導的下一代封裝技術 |
| **BBU (Battery Backup Unit)** | 備用電池單元，用於伺服器斷電時保護資料完整性 |
| **Rubin** | NVIDIA下一代GPU架構代號，預計2026年推出，散熱需求大幅提升 |
| **永動機 (Perpetual Motion Machine)** | 此處指NVIDIA、OpenAI、甲骨文之間的資金循環模式，互相投資與下訂形成閉環 |
| **分盤交易** | 證交所對異常交易股票實施的交易管制措施，改為逐筆撮合，限制交易頻率 |
