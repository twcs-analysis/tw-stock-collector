## 3. 產業分析與投資建議

### 光通訊產業（本集核心主題）

**美股新路隊長：Lumentum（魯門鐵）**
- 市值：412 億美元，持續創新高
- 最新一季營收年增 60%，連續兩季創新高
- 下季營收指引中值 8.05 億美元，年增達 85%
- **關鍵訊號**：
  - 光源產能 100% 鎖定至 2027 年，需求超過供給 30%
  - 額外產能直接加價出貨
  - OCS（全光交換器）積壓訂單超過 4 億美元，提前爆發
  - 高功率雷射多筆百萬級訂單，2026 下半年廣泛放量
  - 外部光源讓單客戶營收含量提高 2-2.5 倍
  - 1.6T 平台快速遷移中

**供應鏈重組：去中國化**
- CSP 廠商改為直接下單上游（Lumentum、Coherent），跳過中國中間商（中際旭創）
- 優先非中供應鏈，台灣因與美系關係深、技術強、彈性大而首先受惠
- 毛利回流實質紅利：中國中間商利潤被擠出，台灣可吃到中間利潤

**台灣受惠標的**

| 個股 | 股價 | 亮點 |
|------|------|------|
| 光聖 | ~2,000 元（盤中觸及，創光通訊新高） | 綁定 CSP 大廠、OCS 關鍵供應商、高階 FPU、與 II-VI 策略聯盟、外資目標價 3,000 元 |
| II-VI（穩懋聯盟） | 較光聖便宜 | Coherent 供應商、電磁閥獨家供應、軍工國防概念 |
| 華星光 | ~300 元 | 打入 Google，CSP 客戶從 1 家增至 3 家、800G 主力產品、1.6T 今年導入、CW 雷射產能翻倍（1.5KK→4KK→6KK） |
| 全新 | ~190 元 | 與 Google 關係深、CW 雷射訂單增長、擴充 5 台機台（4 台磷化銦）、磷化銦稀缺、位階低且未被法人盤 |

**1.6T 升級關鍵點**
- ASP 比 800G 多 30-50%
- 結合 CW 雷射技術
- 技術難度大幅提升（200G x 8 通道）
- 今年準備全面爆發

2. **先進製程與封裝** - 今年展望佳

## 4. 技術面分析與操作策略

### MSCI 調整（健序分析）

**可能納入 MSCI 成分股**

| 排名變化 | 個股 | 市值 | 說明 |
|----------|------|------|------|
| 51→11 | 南亞科 | ~1 兆 | 記憶體大漲推升 |
| 1,922→13 | 宏碁（鴻鑑） | - | 進步驚人 |
| 80→20 | 華邦電 | - | 記憶體族群 |

**候選名單**：台塑化、力積電、南電、旺奇、穩懋、華通

**可能被踢出**：豐泰（93→124）、振興（95→119）、儒鴻

**MSCI 權重調升邏輯**
- 台股自上次 11 月調整以來漲了 14%，亞洲僅次於韓國
- 目前權重 13.79%，可能調升約 0.8%
- 生效日 2/27，開紅盤後僅 4 個交易日可調整
- 被動資金需在極短時間內進場，推升開紅盤行情

### 外資最後一報：高盛 ABF 報告
- ABF（Ajinomoto Build-up Film）供需缺口：今年 5%、明年 27%、2028 年估 40%
- 高盛首選：欣興
- 新興電子：長約價多，漲價空間受限
- 建議：拉回時可注意布局

### 技術面操作策略（顧總分析）

**大盤技術面**
- KD 黃金交叉向上（多方市場）
- MACD 收斂，賣方轉弱→買方市場
- 短線無危險，可安心抱股過年

**當沖熱門股判斷三符號**
1. **A 型反轉** - 單日反轉訊號
2. **N 型雙頭不過** - 兩個高點未突破，跌下來後反彈要賣
3. **三尊頭/多重頂** - 反彈站在賣方

**應退場個股**
| 個股 | 技術型態 | 建議 |
|------|----------|------|
| 力積電 | 三重頂，三次都沒過高 | 退場，設停損 |
| 華邦電 | A 型反轉 | 反彈不過壓力線就退場 |
| 耀華 | A 型反轉 + MACD 柱狀體翻負 | 反彈賣出，換股操作 |
| 群創 | M 頭（雙頭），低點出現後反彈至 0.5-0.618 為賣點 | 反彈換股 |
| 有達 | M 頭 + 漲停後回落至 0.618 精準反壓 | 反彈站在賣方 |

## 7. 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **OCS (Optical Circuit Switch)** | 全光交換器，用於資料中心內光訊號交換，Google 與 Meta 大規模部署中 |
| **CW 雷射 (Continuous Wave Laser)** | 連續波雷射，用於光通訊中的光源，1.6T 平台關鍵技術 |
| **1.6T** | 1.6 Terabit 傳輸速率，下一代光通訊規格，ASP 比 800G 高 30-50% |
| **FPU (Fiber Processing Unit)** | 光纖處理單元，光聖的核心產品 |
| **磷化銦 (InP)** | 重要的 III-V 族半導體材料，用於製作高速光電元件，目前極度稀缺 |
| **Scale Up / Scale Out / Scale Cross** | 資料中心連結層次：機櫃內（Up）、機櫃間（Out）、跨資料中心（Cross） |
| **MSCI** | 摩根士丹利資本國際指數，全球追蹤資金約 15 兆美元 |
| **ABF (Ajinomoto Build-up Film)** | 味之素增層膜，用於先進封裝的關鍵材料，供需缺口持續擴大 |
| **供應鏈重組** | CSP 廠商跳過中國中間商，直接下單上游，優先非中供應鏈 |
| **A 型反轉** | 技術分析中的單日反轉型態，代表趨勢可能改變 |
| **KD 指標** | 隨機指標，用於判斷超買超賣，20 以下黃金交叉為買訊 |
| **MACD** | 移動平均收斂擴散指標，柱狀體翻正代表多方轉強 |
