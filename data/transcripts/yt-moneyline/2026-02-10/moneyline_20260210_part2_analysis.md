## 3. 產業分析與投資建議

### 低價轉機股（會氏推薦 - 本集核心主題）

#### 群創（21 元）
- **三大題材**：FoPoP（扇出型封裝）、車用、太空
- 已進入 SpaceX 供應鏈
- 將 FoPoP 技術導入太空應用
- 車用子公司併購日本公司，全新領域
- 淨值 27 元，股價 21 元，低於淨值
- 外資目標價 30 元
- 拉回至半價位置，相對安全

#### 國碩（28 元）
- **三大題材**：太陽能上游材料、鈣鈦礦電池、太空
- 台灣屋頂型新制強制政策利多
- 內銷案源穩固，目標 20 幾萬、年訂單保證 27 萬
- **鈣鈦礦電池**：與台灣蓋太礦科技（台蓋科）合作，直接出貨材料
  - 鈣鈦礦特性：透光、可彎曲，適合太空衛星使用
  - 衛星唯一能源來源就是太陽能
  - 中國太陽能受高關稅限制（累計超過 100%），台灣有替代優勢
  - SpaceX 為美國國安資產，不太可能大量使用中國零件
- 股價在 26-33 元區間整理，拉回後可注意

#### 新科（60 幾元）
- **三大題材**：鈣鈦礦靶材、FoPoP/SpaceX、貴金屬
- 鈣鈦礦電極層靶材供應商（銀靶、薄靶等關鍵材料）
- 切入台蓋科供應鏈，高純度靶材薄膜
- 與群創有關聯，出貨至 SpaceX
- 子公司做銅箔引線的代紡，今年第二季量產
- **貴金屬隱藏版**：1月營收年增 157%
- 股價 55-65 元整理，站上年線後回測

### SpaceX 與太空產業投資邏輯
- 太空衛星唯一能源來源 = 太陽能
- 鈣鈦礦太陽能電池優勢：可彎曲、透光、適合太空捲收
- 中國太陽能面臨：
  1. 美國高關稅（幾十趴 + 100%）
  2. 國安限制（NASA、軍方不用中國零件）
  3. SpaceX 為美國國安資產
- 台灣優勢：技術領先、非中供應鏈、與美系關係深

## 4. 年後選股名單（第一金投顧 黃董事長）

### 看好台股後市的理由

1. **AI 資本支出持續擴大**
   - 四大 CSP 今年資本支出 6,600-6,700 億美元，年增 62%
   - 台灣供應鏈上中下游一條龍受惠

2. **台美關稅 15% 最優惠國待遇**
   - 有利傳產出口（自動化設備、汽車零組件等）
   - 去年受關稅壓力表現不佳的傳產今年有機會反彈

3. **中國過剩產能控款**
   - 鋼鐵產能控款已達標，設出口上限
   - 塑化報價回溫，有利台灣傳產

4. **企業獲利展望**
   - 去年高基期下，今年獲利再成長 20% 以上，仍有上修空間

5. **資金充沛**
   - 台灣超額儲蓄突破紀錄
   - 房市停滯，資金轉向股市

6. **經濟成長**
   - 去年 GDP 成長 7.5%
   - 今年主計處估 3.4%，第一金預估仍有上修空間

### 電子股首選

**AI 伺服器**
- 受惠標的：台積電、廣達、緯創、緯穎、台達電、川湖、鴻海等
- 今年 Blackwell → Ruby 世代轉換，下半年放量

**PCB 板**
- 受惠標的：金像電、景碩（做彭博）、台燿、傾向電、副橋
- AI 伺服器需求帶動高階 PCB 用量

**光通訊**
- 受惠標的：聯亞、光聖、佩克恩、波若威、華星光
- 佩克恩與康寧緊密合作，康寧近期接到大單

**太空**
- SpaceX 今年 IPO，併購後估值約 1.25 兆美元，可能 IPO 即破兆
- 亞馬遜加速 Project Kuiper，第一季預估發射
- 受惠標的：華通、其陽、升達科、台德光電

**記憶體**
- 2026 年仍是漲價缺料格局
- 最快的新產能開出在 2027 年底之後
- 休息整理後有機會再漲

## 5. 投資策略總結

### 低價轉機股策略
- 群創 21 元：太空 + FoPoP + 車用，最便宜的太空概念股
- 國碩 28 元：鈣鈦礦 + 太陽能 + 太空，政策利多
- 新科 60 元：鈣鈦礦靶材 + 貴金屬 + SpaceX，營收已開始爆發

### 年後布局重點
1. **電子為王**：1月出口 657 億美元，年增 70%，電子占比 77.7%
2. **AI 伺服器**：加量加價，營收增長顯著
3. **光通訊**：新路隊長，台灣供應鏈重組受惠
4. **太空**：SpaceX IPO 年、多國布局
5. **傳產復甦**：塑化、鋼鐵報價回溫

### 投資風格建議
- 持有做頭個股者：反彈換股
- 空手者：布局低位階、營收佳但股價委屈的個股
- 智邦等高價創新高股：持有者可抱，空手者不追

## 7. 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **FoPoP (Fan-Out Panel Level Packaging)** | 扇出型面板級封裝，群創的先進封裝技術，可應用於太空領域 |
| **鈣鈦礦電池 (Perovskite Solar Cell)** | 新一代太陽能電池，具備透光、可彎曲特性，適合太空衛星使用 |
| **靶材 (Sputtering Target)** | 濺鍍靶材，用於薄膜沉積製程，鈣鈦礦電池的電極層需使用銀靶、薄靶等 |
| **CSP (Cloud Service Provider)** | 雲端服務供應商，如 Google、Meta、Amazon、Microsoft 等 |
| **SpaceX** | 馬斯克創辦的太空探索公司，今年規劃 IPO，估值約 1.25 兆美元 |
| **Project Kuiper** | 亞馬遜的低軌衛星計畫，與 SpaceX Starlink 競爭 |
| **墓碑線** | K 線型態之一，高檔出現代表做頭訊號，上影線極長、實體極短 |
| **空方吞噬** | 技術分析中的反轉型態，大黑K完全包覆前一根紅K |
| **PCB (Printed Circuit Board)** | 印刷電路板，AI 伺服器的關鍵零組件 |
| **淨值比 (P/B Ratio)** | 股價除以每股淨值，低於 1 代表股價低於帳面價值 |
| **台蓋科** | 台灣蓋太礦科技公司，台灣鈣鈦礦技術領先者，未上市 |
| **232 產業調查** | 美國貿易法 232 條款調查，針對進口產品是否影響國家安全 |
