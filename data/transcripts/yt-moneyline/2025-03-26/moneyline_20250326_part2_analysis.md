- **風險**: 下一步可能調降美國信評

- **結論**: 經濟變差+通膨上升 = 停滯性通膨（stagflation）風險

- **齊臻觀點**: 目前還不會衰退，但停滯性通膨是最可能出現的狀況
- 連續兩季GDP萎縮才算衰退，短期內壓力來自Q1數據

### 二、叔方老師教學：股票何時該賣

#### 基本面判斷法（三步驟）

**第一步：檢視買進理由**
- 營收與獲利是否符合預期
- 不如預期 → 減碼出場
- 符合或優於預期 → 進入第二步

**第二步：利多不漲的警訊**
- 利多出來後觀察三天
- 三天利多都不漲 → 有人比你先知道後面有利空 → 減碼
- 反之：利空不跌 → 有人利用利空接籌碼 → 順水推舟可加碼

**第三步：技術面操作**

**買進信號（反向即為賣出信號）**:
1. 均線糾結開口向上 → 抱
2. 突破頸線 → 第一買點
3. 拉回頸線不破 → 第二買點（加碼）
4. 帶量長紅棒（馬其諾防線）→ 中線買點

**短線 vs 波段**:
- 短線：看日K線，跌破5日線出場
- 波段：看周K線，最大量區間守住為中線買點

**軌道線操作法**:
- 貼著5日線上漲 → 回到5日線買
- 貼著月均線上漲 → 回到月均線買
- 跌破軌道線 → 出場

### 三、籌碼面教學（叔方老師）

#### 如何判斷主力進場

**優先觀察（第一優先）**:
- 主動式投信基金買超 + 股價強勢或穩定

**防跌站判斷（第二優先）**:
- 買得動的股票（量價配合）
- 賣不下去的股票（利空不跌）

#### 融資券判斷
- 融資比20-30% → 留意
- 融資比30-50% → 觀察
- 融資比超過50% → 留意賣點（業內主力可能已獲利一倍）
- 券餘量需對比每日成交量（至少佔成交量一成以上才有意義）

#### 千張大戶的陷阱
- 千張大戶增加包含投信法人的買進
- 外資買賣也可能超過千張
- **結論**: 千張大戶數據不準確，除非能扣除法人進出
