## 📈 技術面分析

### 大盤量能分析（叔方老師專題）

**極縮量的歷史經驗法則**:

今日成交量2,154億元為近兩年新低，叔方老師以歷史案例解析：

**案例一：2022年5月3日**
- 出現極縮量後歐動量（窒息量）
- **當時環境**: 季線與年線同步下彎（中空+長空格局）
- **結果**: 新低量後出現新低價，反彈未過高再創新低

**案例二：2022年12月26日**
- 同樣出現更低量
- **當時環境**: 從低檔反彈，季線開始翻揚向上
- **結果**: 歐動量後出量向上，突破前高，形成底部

**三個關鍵判斷條件**:
1. 是否完整波浪跌了幾波（頭部剛下跌 vs 低檔反彈扭轉）
2. 歐動量後反彈是否過高（過高=底部，未過高=空頭延續）
3. 季線與年線方向（翻揚=多頭信號，下彎=空頭延續）

**對照目前大盤**:
- **季線**: 下彎（中空格局）
- **年線**: 不會短期下彎（去年3月點位比現在低很多，年線扣抵不會向下）
- **結論**: 目前為中空格局，但長線並非空頭；多空各半，需觀察後續量能方向

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| 窒息量/極縮量 | 成交量縮至極低水位，代表市場觀望情緒濃厚 |
| 歐動量 | 窒息量之後出現的放量行為，方向決定後續走勢 |
| 季線/年線 | 60日均線/240日均線，中期/長期趨勢指標 |
| 均線糾結開口向上 | 多條均線在同一區間收斂後向上發散，為多頭啟動信號 |
| 短多 | 短期看多但中長期不確定，適合做短線波段 |
| NAND Flash | 非揮發性記憶體，用於SSD等儲存設備 |
| 本益比(PE) | 股價除以每股盈餘，衡量估值高低的指標 |
| 淨值 | 公司每股帳面價值，股價低於淨值可能代表被低估 |
