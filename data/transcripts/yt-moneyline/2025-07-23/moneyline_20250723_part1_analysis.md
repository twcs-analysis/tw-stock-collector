### 六、ETF 市場趨勢 - 主動式 vs 被動式

#### 主動式ETF崛起
- 七月最熱門ETF多為主動式
- 成立不到三個月，投資報酬率接近20%
- 目前台灣六檔主動式ETF（五檔台股、一檔海外）

#### 主動式ETF優勢
1. 超越指數為目標（被動式僅追蹤指數）
2. 基金經理人可主動調整持股
3. 盤中可掛單交易（比主動式基金更有效率）
4. 透明度高（持股即時可見）
5. 費用率介於被動式ETF與主動式基金之間

#### 高股息ETF調整趨勢
- 配息率回歸6~8%為常態
- 「超配」爭議：資本損益平準金不可拿來配息
- 0918已在調整，符合金管會規定
- **選ETF應看「總報酬」而非「年化配息率」**

#### 配置建議
- 追求資本利得 → 主動式ETF配多一點
- 追求穩定現金流 → 被動式高股息ETF配多一點
- 建議均衡配置

## 📈 技術面分析與操作策略

### 大盤技術面
- 前日長黑上影線後隔日反彈，顯示多方力道仍在
- 兩萬三千點為重要心理關卡，已收復
- 成交量3,581億偏低，量能不足需留意

### 個股操作原則
1. **強勢股不可跌破月均線**：跌破月均線代表慣性改變
2. **五日均線操作法**：貼近五日均線買進，破十日線出場
3. **背離訊號注意**：過高時量能背離，短線應減碼
4. **千金股與低價股輪動**：資金從高價流向低價是正常輪動，非崩盤訊號

### 操作情境分析

| 情境 | 條件 | 選股方向 |
|------|------|---------|
| 關稅偏低（≤15%） | 台灣關稅與日本相當 | 科技出口股、半導體 |
| 關稅中性（15~25%） | 台灣與韓國相當 | AI供應鏈中游零組件 |
| 關稅偏高（>25%） | 台灣高於韓國 | 內需股、綠電、軍工國防 |

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **ABF載板** | Ajinomoto Build-up Film，高階IC載板材料，AI晶片封裝必需品 |
| **BT載板** | Bismaleimide Triazine，一種PCB載板材料，用於中低階IC封裝 |
| **軋空** | 空方被迫回補空單，推升股價急漲的現象 |
| **融券餘額** | 市場上尚未回補的融券賣出張數 |
| **RWA** | Real World Assets，現實世界資產代幣化 |
| **SaaS** | Software as a Service，軟體即服務，雲端平台訂閱模式 |
| **主動式ETF** | 基金經理人主動選股調整的ETF，目標超越指數表現 |
| **被動式ETF** | 追蹤特定指數的ETF，成分股固定不可調整 |
| **鉅額交易** | 盤後大量股票交易，通常為法人或大戶操作 |
| **本益比（P/E）** | 股價除以每股盈餘，衡量股票是否合理的指標 |
