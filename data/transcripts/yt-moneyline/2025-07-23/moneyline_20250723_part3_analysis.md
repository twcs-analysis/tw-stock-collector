## 🌍 市場總體觀察

### 川普穩定幣法案與加密貨幣新局

#### 三大加密貨幣法案通過
- 美國眾議院通過三大加密貨幣法案
- 穩定幣法案（GENIUS Act/天才法案）取得法律依據
- 未來監管機關確認後，新的ICO（代幣發行）也可合法進行
- 聯準會未來發行數位貨幣的權利被拿掉，留給美國行政機關

#### 比特幣走勢
- 上週創新高衝上123,218美元
- 創高後出現長上影線，短線高檔震盪
- 底部持續墊高（盤整格局）
- **法案利多但未再創新高 → 利多出盡風險**

#### 川普加密貨幣布局
- 川普媒體集團持有20億美元比特幣
- 考慮開放美國退休金投資加密貨幣
- 小摩（JP Morgan）考慮接受加密貨幣擔保貸款
- 策略公司（MicroStrategy）持有全球3%比特幣，今年股價漲49%

#### 以太幣（ETH）漲幅超越比特幣
- 原因：穩定幣多走以太坊網路，消耗以太幣
- 但實際上穩定幣會走多條鏈，以太坊不一定獨佔
- 其他主流幣種也跟漲

#### 穩定幣的戰略意義
- **核心目的：鞏固美元霸權**
- 穩定幣與美元綁定 → 全球使用者手上都是美元
- 傳統跨境匯款需三到五天 → 穩定幣兩分鐘到帳
- 香港最早通過穩定幣法，美國急起直追
- 穩定幣發行需要擔保 → 擔保品為美國國債 → 增加美債需求

#### 投資風險提醒
- 比特幣曾從歷史高點（1月川普就職日）大幅下跌
- 短期創高後仍有回測至10萬甚至9萬多美元的可能
- 不是只看利多，要了解風險

## 📊 國際匯率與資產配置

### 美元資產信任危機

#### 各國央行動向
- 全球央行開始減持美元資產
- 積極增持黃金、人民幣、歐元
- 美元與美債讓市場不放心

#### 各資產分析

| 資產 | 短期展望 | 分析 |
|------|---------|------|
| 人民幣 | 緩升有機會，大漲難 | 中美未談完 + 結構轉型中，大升不利出口 |
| 歐元 | 表現不錯 | 看明天歐洲央行利率決議，若不降息則歐元走強 |
| 歐債 | 留意下跌壓力 | 殖利率走平未大幅走低，若不降息可能小跌 |
| 黃金 | 高檔震盪 | 歷史高點4/22的3,500美元未突破，底部墊高中 |
| 美債 | 短債優於長債 | 建議「賣長買短」策略，避免長債通膨風險 |

#### 美債「賣長買短」策略
- **長債（10年期）殖利率**: 約4.4%，通膨壓力下持續偏高
- **短債（2年期）殖利率**: 約3.8%，相對穩定
- **策略**: 把長天期美債轉為短天期，保留接近4%利息，避免長債價格下跌風險
- **邏輯**: 通膨是長天期公債最大敵人，短債受通膨影響較小

#### 黃金操作建議
- 3,500美元為歷史高點壓力
- 3,100~3,500美元為盤整區間
- 高點每次追都比較危險
- 建議分批投資，等突破3,500後再加碼

## 📈 技術面分析與操作策略

### 新股抽籤專題

#### 抽籤入門重點
- 只看兩個數字：**承銷價**（需要多少錢）與**溢價率**（能賺多少）
- 溢價率 > 28% 以上可考慮抽
- 每人限抽一次（身分證認證），公平機制
- 工本費損失約20元

#### 近期新股抽籤資金凍結

| 新股 | 凍結資金 | 申購期間 | 抽籤日 | 資金釋放 |
|------|---------|---------|--------|---------|
| 維層氏 | ~115億 | 7/17~7/21 | 7/23 | 7/25（週五） |
| 樹網 | ~150億 | 7/17~7/21 | 7/23 | 7/25（週五） |
| 信紅科 | ~321億 | 稍晚 | 稍晚 | 下週一 |

- **合計凍結約586億元**，影響台股成交量

#### 新股抽籤的指標意義

- 去年熱門：新宇航空（航空產業正旺）
- 今年上半年：AI軟體熱門股
- 近期新股方向：
  - **維層氏**: 電子支付概念

  - **新雅**: 大型戶外數位顯示面板（明年有世足賽題材）

#### 半導體廠務工程族群
- 信紅科、繁旋、朋億為代表

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **穩定幣（Stablecoin）** | 與法幣（如美元）1:1掛鉤的加密貨幣，價值穩定 |
| **GENIUS Act** | 美國參眾兩院通過的穩定幣監管法案（天才法案） |
| **ICO** | Initial Coin Offering，首次代幣發行，類似IPO |
| **RWA** | Real World Assets，將現實資產（如房地產）代幣化在區塊鏈上交易 |
| **SaaS** | Software as a Service，軟體即服務，雲端訂閱模式 |
| **代幣化（Tokenization）** | 將資產轉化為區塊鏈上的數位代幣，方便分割交易 |
| **廠務工程** | 半導體工廠的基礎設施建設與維護工程 |
| **新股抽籤** | 公司IPO時透過抽籤方式分配新股給一般投資人 |
| **溢價率** | 新股承銷價與市價之間的價差百分比 |
| **Gamma擠壓（Gamma Squeeze）** | 選擇權造市者被迫買入現貨避險，推升股價的連鎖效應 |
| **以太坊（Ethereum）** | 第二大加密貨幣平台，支援智能合約與去中心化應用 |
| **殖利率曲線** | 不同天期公債殖利率的連線，反映市場對未來經濟與通膨的預期 |
