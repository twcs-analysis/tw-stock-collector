## 💼 產業分析與投資建議

### 一、台玻（1802）- 玻纖布/玻纖紗概念

#### 基本面
- 主業為玻璃公司，但有生產玻纖布與玻纖紗
- 正在尋求AI領域認證
- 與金居、副橋相比，**股價極低（不到20元）**
- 台塑集團個股，受集團資金推動

#### 技術面
- 今日衝上漲停板，盤中打開
- 最大量出現在今日起漲點
- **關鍵停損**：今日低點（約17元），「一紅吃五黑」格局

#### 操作建議
- **目標價**: 22~25元（比價效應，玻纖類股漲至20倍以上）
- **停損點**: 17元（今日低點）
- **注意**: 部分外資買盤可能為偏短操作（黑頭髮外資），隔日10點前注意賣壓

### 二、南亞科（2408）- DDR4反彈

#### 基本面
- DDR4記憶體價格持續下跌，但非AI相關（HBM、DDR5才是主流）
- 跌價原因：市場資源集中AI的HBM與DDR5，DDR4遭忽略
- 第三季報價仍好，但屬於跌深反彈格局

#### 技術面
- 已回到半年線位置
- 外資大賣後出現反彈
- 投信也開始小量回補

#### 操作建議
- **性質**: 跌深反彈，非主流趨勢
- **目標價**: 反彈至月均線50~55元附近
- **停損點**: 跌破本波低點40.2元
- **策略**: 反彈至55元附近可考慮減碼，不宜追高

### 三、華城（1519）- 重電龍頭

#### 基本面
- 川普推動美國AI基礎建設，需要大量變電器
- 部分產品出口至美國市場
- 股本比中興電小得多，更具股價活潑性
- 若台灣關稅偏高，華城反而受惠（內需重電概念）

#### 技術面
- 昨日回測十二日均線後守住
- 今日反彈站回
- 月均線從未有效跌破

#### 操作建議
- **目標價**: 持續創高（660+52元漲至660元附近）
- **停損點**: 十二日均線（短線）；月均線（中線）
- **邏輯**: 關稅越高 → 內需股越強 → 華城受惠

### 四、每旗半（4121）- 電磁材料

#### 基本面
- 中國被美國限制電磁材料相關產品，台灣替代受惠
- 與特斯拉財報連動（電磁材料供應鏈）
- 外資今年以來持續賣出，但股價仍能漲到平盤

#### 技術面
- 均線剛開口向上
- 今日爆出近期最大量
- 從歷史高點大幅回落後，目前在長線低點反彈

#### 操作建議
- **目標價**: 中短線看90~100元
- **停損點**: 77.2元（今日低點）
- **注意**: 外資仍在賣，需觀察內資主力動向

### 五、散熱股 - 奇鋐概念

#### 七鋐基本面
- 第二季營收季增正26%，超越台幣升值幅度
- 毛利率向上
- 單季EPS預估10.4元（全年預估40~41元）
- 第三季：原為持平，因接到ASIC訂單轉為正18%~13%成長
- 明年EPS預估54元

#### 操作建議
- **目標價**: 今年41元EPS × 25倍 = 1,025元；明年54元 × 20倍 = 1,080元
- **停損點**: 跌破月均線
- **特點**: 台積電代工概念，匯率影響較小

### 六、四星（日月光投控概念）- 先進封測

#### 基本面

- 三代先進封裝代工費用是七代的三倍

#### 操作建議
- **目標價**: 明年以20倍本益比計算 = 2,800元（長線）
- **停損點**: 月均線
- **策略**: 不要太急，第四季營收才大幅成長，目前等待期
- **來賓比喻**: 「台北沒上車，南港沒上車，台中總要上車」

## 📈 技術面分析與操作策略

### 三大情境選股策略

#### 情境一：第二季財報是現在的谷底，未來更好
- 選股邏輯：找**匯損造成EPS谷底**但下半年營收爆發的公司
- 不要看到PCB三個字就買 → 要AI的PCB
- 新切入產品的公司，基期低、成長性強
- **推薦方向**: ASC/AI ASIC、GB300、新產品線

#### 情境二：擔心匯退損失
- 季增幅度需大於新台幣升值幅度
- 投信因第二季財報差持續賣超
- **策略**: 避開上游半導體（關稅風險高），選中游零組件

#### 情境三：台灣關稅偏高
- 三條路轉路就要轉：
  1. **美國製造**: 在美國設廠的公司不受關稅影響
  2. **內銷為主**: 綠電、重電、食品等內需產業
  3. **廠務工程**: 各國去設廠帶動廠務需求
- 綠電：台電強韌電網第四季發標，開始認列營收
- 新加坡等低關稅國家的建廠帶動常駐工程需求

### 關鍵技術面指標
1. **週均線**為極短線強弱分界
2. 跌破週均線兩個營業日 = 有效跌破
3. KD指標若交叉向下，短線先退出
4. 消息面大於技術面的格局下，保持三成現金不回補

## 📋 投資策略總結

### 核心觀點
1. 外資偏空但買低價股，市場風格轉向低位階補漲
2. 關稅結果是決定選股方向的最大變數
3. 第二季財報普遍差（匯損），但下半年看好者可逢低布局
4. PCB、軍工、內需為三大確定性較高的方向
5. 保持三成現金應對不確定性

### 風險提示
- 自營商買超100億可能為避險式買盤，隔日恐反手賣
- 新台幣未持續升值，外資期貨端仍偏空
- 本週美股重要財報密集，可能影響台股走勢
- 關稅談判結果隨時可能改變市場風向

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **DDR4/DDR5** | 動態隨機存取記憶體世代，DDR5為最新主流，DDR4為舊世代 |
| **HBM** | High Bandwidth Memory，高頻寬記憶體，AI晶片核心元件 |
| **ASIC** | Application Specific Integrated Circuit，客製化晶片 |
| **GB200/GB300** | NVIDIA新世代AI伺服器平台代號 |
| **ASC** | AI Super Computer，AI超級電腦 |
| **CoWoS** | Chip on Wafer on Substrate，台積電先進封裝技術 |
| **玻纖布/玻纖紗** | PCB基材原料，用於製作銅箔基板的關鍵材料 |
| **匯損** | 因新台幣升值導致以美元計價營收換算後減少的損失 |
| **避險式買盤** | 自營商因持有選擇權等衍生性商品，依法規需買入現貨避險 |
| **黑頭髮外資** | 指實際為本土資金透過海外帳戶回流的假外資 |
