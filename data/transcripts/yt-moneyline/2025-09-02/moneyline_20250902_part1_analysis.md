### 三、價值投資心法（慶龍分享）

#### 漢唐 (2404) 的啟示
- **案例**: 學生2020年疫情期間，以60元成本買進漢唐，至今一張未賣，最高漲至1,245元
- **慶龍自身經驗**: 2016年以47-52元買進86張（投入450萬），在100-200元區間賣出，獲利不到1,000萬；若持有至今，市值超過1億元，每年現金股利100-200萬
- **進場方法**: 五年平均殖利率達7%時進場

#### 價值投資三大心法
1. **專注累積股票，而非交易股票**: 找到好公司後持續買進，不要頻繁交易
2. **短期是投票機，長期是體重機**: 格拉漢的名言，市場短期受情緒影響，長期反映企業真實價值
3. **持有優質公司股權，讓時間累積資產**: 好公司定義 = 獲利能夠持續成長的公司

#### 實戰案例：台藥 (6274)
- **慶龍持股**: 2023年起以61元開始買進，至今累積42張，投入438萬元
- **加碼策略**: 每次回檔即加碼（108元加8張、148元加7張、156元加5張、133元加5張）
- **目前股價**: 372元，一張未賣
- **預計持有期限**: 至2027年，按產業規劃仍有相對高點
- **投資建議**: 一張不賣，相信好公司能持續創造投資效益

### 大盤技術面
- **月線**: 尚未站回，為短線多空關鍵
- **外資期貨**: 空單大幅回補，轉趨中性偏多
- **研判**: 多頭回檔，非轉弱訊號

### PCB族群操作策略
1. **月線多空分界**:
   - 領頭股以月線為上升軌道，破月線三天不站回 = 進入休息
   - 強勢股以十日線為上升軌道，破十日線三天不站回 = 需減碼
2. **量能觀察**: 破線後量縮 = 長時間整理；破線後有買盤拉回 = 仍有新高

## 📋 投資策略總結

### 短期策略（1-2週）
- 九月初台股進入震盪整理，PCB族群分化加劇
- 關注本週五非農就業數據，若不如預期反而有利台股（降息預期增溫）
- 外資連五賣後回頭買超，短期止穩訊號明確
- PCB族群以「月線」和「十日線」為操作分界，破線三天未站回則減碼

### 中期策略（1-3個月）
- 九月歷史統計上漲機率僅30%（過去5年全跌），但10-12月反彈力道強勁
- 九月若敢買，11-12月可享受大行情
- PCB主升段可延續至Q4，AI伺服器升級需求未減
- 擴廠概念股（豐達科、神達科、穩德）因資本支出擴大，中長線看好

### 風險評估
1. **九月魔咒**: 統計上為全年最弱月份，短線波動加大
2. **匯損風險**: 台幣走勢不明，出口導向企業Q2-Q3獲利受壓
3. **PCB籌碼風險**: 融資增幅大於股價漲幅的個股需特別留意（如台燿）
4. **日東紡擴廠**: 短線心理衝擊，但實際影響在明年底以後
5. **外資動向**: 雖然回頭買超，但需觀察是否持續

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **PCB** | 印刷電路板（Printed Circuit Board），電子產品的基礎元件 |
| **日東紡** | 日本日東紡績株式會社，PCB上游材料（ABF載板基材）供應商 |
| **ABF載板** | Ajinomoto Build-up Film，用於高階IC封裝的載板材料 |
| **HDI** | 高密度互連板（High Density Interconnect），高階PCB技術 |
| **月線** | 20日移動平均線，中期多空分界 |
| **十日線** | 10日移動平均線，短期多空分界 |
| **殖利率** | 現金股利除以股價，衡量投資報酬率 |
| **本益比** | 股價除以每股盈餘（EPS），衡量股價是否合理 |
| **BBU** | 備用電池單元（Battery Backup Unit），資料中心不斷電裝置 |
| **CDU** | 冷卻分配單元（Cooling Distribution Unit），用於液冷散熱系統 |
| **ISL** | 衛星間鏈結（Inter-Satellite Link），衛星通訊技術 |
| **非農就業** | 美國非農業就業人數，聯準會貨幣政策重要參考指標 |
