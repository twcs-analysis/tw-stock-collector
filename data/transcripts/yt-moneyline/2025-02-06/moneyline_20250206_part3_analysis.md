## 💼 產業分析與投資建議

### 一、低本益比 + 低股價淨值比選股策略（建大哥）

#### 選股哲學

建大哥提出「川普頭部」時代的投資對策：

1. **產業趨勢是王道**: 題材不可信，但產業趨勢（AI、機器人）是川普一個人改變不了的
2. **企業體質才是真理**: 不要追炒作的題材股，有真金白銀的獲利才經得起火煉
3. **法人籌碼是力量**: 外資、投信的持續買進比主力短線炒作更可靠；主力買可能隔日沖
4. **操作紀律**: 不要擋鬆（不要做隔日沖）、融資少用、避開高本益比/高位階股票

### 二、金融股存股策略（明哲）

#### 進可攻退可守的選擇方向

1. **平均填息天數最短**: 元大金（約65天）
   - 證券業龍頭，行情波動大反而有利
   - 殖利率約4%
   - 快速填息 + 可賺價差

2. **現金殖利率最高**: 兆豐金
   - 官股代表，殖利率高
   - 過去一兩年開始配股票股利

3. **中信金**: 也是不錯的選擇
   - 壽險業龍頭
   - 殖利率約4.45%，穩定配息

#### 金融股操作三段式策略
1. **第一段 - 卡位**: 現在已知獲利不錯，公布配息前先卡位
2. **第二段 - 低接**: 公布配息後股價若拉回，殖利率變高時逢低買進
3. **第三段 - 除息前獲利**: 在除息前若股價漲幅超過殖利率，可先獲利了結

### 下集核心要點

1. **金融業大賺**: 2024年金融三業獲利1兆585億元（年增50%），銀行、證券創歷史新高

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| 金融三業 | 銀行、保險、證券三大金融產業的統稱 |
| 配息中位數 | 取近五年配息金額排列後的中間值，用以預估未來配息水準 |
| 股價淨值比（PBR） | 股價除以每股淨值，低於1倍代表股價低於帳面資產價值 |
| 本益比（PER） | 股價除以每股盈餘，反映投資人願意為每元獲利付出的倍數 |
| 景氣循環股 | 營收獲利隨景氣循環大幅波動的股票，如鋼鐵、石化、航運 |
| 填息 | 除息後股價回升至除息前水準，代表投資人實質獲得股利收益 |
| 掉度能力 | 廠商在不同生產據點間靈活調度產能的能力，貿易戰中特別重要 |
| ODM | 原始設計製造商，為品牌客戶設計並製造產品 |
| 殖利率 | 現金股息除以股價，衡量股息報酬率的指標 |
