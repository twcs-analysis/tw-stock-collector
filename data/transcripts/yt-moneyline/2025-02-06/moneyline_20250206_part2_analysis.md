## 🌍 市場總體觀察

### 三大反轉訊號詳解（規模老師）

#### 訊號一：K線高低點判斷法
- 多頭行情中：每天低點比前一天低點高、高點比前一天高點高
- 反轉訊號：高點不再過高、低點開始破低
- **目前狀態**: 尚未出現（低點仍在墊高、高點仍在創新高）
- 反轉通常在第5天、第8天、第13天或第21天出現

#### 訊號二：八大官股券商動向
- 低檔時官股百億以上大買 → 指數隨後拉升
- 高檔時官股持續賣出 → 壓力不過高後反轉向下
- **目前狀態**: 已出現！官股從買轉賣

#### 訊號三：量價背離
- 指數上漲但成交量下降
- **目前狀態**: 已出現！連三天反彈量能遞減

### 川普任期股市展望

#### 第一任期回顧（2017-2021）
| 年份 | 事件 | 股市表現 |
|------|------|---------|
| 2017 | 減稅政策（企業稅從35%降至21%） | 道瓊+25%、S&P+19%、費半+38% |
| 2018 | 美中關稅開打、聯準會升息四次 | 下跌 |
| 2019 | 關稅戰緩和、聯準會降息 | 上漲 |
| 2020 | 疫情暴跌後反彈、零利率+無限QE | 上漲 |
| **四年合計** | - | 道瓊+56%、那斯達克+138%、S&P+67%、費半+208% |

#### 第二任期展望（2025-2029）
- **結論**: 股市仍會漲，但漲幅將遠低於第一任期
- **原因**: 基期已高、減稅空間有限、市場對川普操作已有經驗
- **風險**: 關稅戰不確定性高，「今天宣布利多明天就翻臉」

## 💼 產業分析與投資建議

### 一、NVIDIA RTX 5090顯卡賣爆 - 板卡供應鏈受惠

#### 產業背景
- RTX 5090於1月30日正式開賣，全球搶購一空
- 搭載BlackWell晶片，AI算力超過3,352 TOPS
- 定價1,999美元（約6萬台幣），黃牛價翻三倍（近20-30萬）
- RTX 5060預計下月開賣，CP值更高

#### NVIDIA顯卡上市與板卡股價歷史對照
- 2020年9月RTX 3000系列發布 → 微星（2377）股價大漲
- 2022年9月RTX 4000系列發布 → 板卡股價亦走高
- 2025年1月RTX 5000系列開賣 → 歷史經驗顯示板卡股有望跟漲

#### 板卡四雄中最純的標的
- **微星（2377）**: 顯卡佔比最高、事業體比較單純
- 目前在箱型整理中，市場預期年報公布後外資將重新評價
- 長線上看整數關卡200元

#### DeepSeek效應對邊緣AI的推動

**DeepSeek關鍵數據：**
- 前訓練成本僅約532萬美元（VS OpenAI數十億美元）
- 使用較低階晶片即可訓練
- 完全開源（Open Source）

**對邊緣AI的影響：**
1. 訓練成本大幅降低 → 小企業也能自行訓練AI
2. 顯卡可用於訓練小型專家系統（類似5-6年前挖礦/AI車牌辨識）
3. AIPC需求加速 → 升級顯卡需求增加
4. 開源促進邊緣AI落地 → ODM廠商、CRM/EIP系統導入AI功能

## 📈 技術面分析與操作策略

### 第一季選股五大方向（規模老師）

1. **聚焦產業趨勢**: AI、機器人等明確成長產業，拉回翻多時站在買方
2. **控管資金風險**: 今年波動更大，需分散配置、靈活調節
3. **留意貿易政策影響**: 關稅增加導致供應鏈成本上升的企業要避開
4. **技術面輔助決策**: 利用KD、MACD等指標捕捉關鍵轉折
5. **逢低布局**: 選擇股價在低位、具基本面優勢或高殖利率的個股

## 📋 投資策略總結

### 中集核心要點

1. **三大反轉訊號**: 已出現兩個（官股轉賣、量價背離），僅剩K線高低點尚未觸發，操作需謹慎
2. **川普第二任期**: 股市仍會漲但幅度遠低於第一任期，波動加大是常態
3. **2月18日關鍵日**: 晶片關稅利空直接針對台積電，但也是最佳買點
4. **NVIDIA顯卡賣爆**: RTX 5090全球搶購，歷史經驗顯示板卡股將受惠（微星為首）
5. **DeepSeek推動邊緣AI**: 訓練成本暴降 + 開源 → AIPC、顯卡、資訊服務股受惠
6. **去年主流股分化**: 台積電、聯發科仍強；鴻海、長榮轉弱但有反彈機會；緯穎受關稅衝擊最大
