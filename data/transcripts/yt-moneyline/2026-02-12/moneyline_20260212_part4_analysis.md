| 預估 EPS | 89.79 元 |

| **合理價格** | **1,841 元** |
| 歷史最高本益比 | 26-28 倍 |
| **過熱價格** | **約 2,400 元** |

**操作建議**:
- 合理價格約 1,841 元，與現價差距不大
- 今年高檔預估在 2,000 元上下
- 第一季有機會往 2,000 元邁進
- **重點在價差操作，而非預測最高點**
- 若回檔做休息，反而是好事（可以做價差）
- 過熱價格 2,400 元與歷亞（外資）目標價相近
- 非經濟因素（川普）可能帶來額外波動機會

### 第一季焦點股：記憶體

**明哲老師首選**: 記憶體類股

**看好理由**:
1. 集邦科技（TrendForce）預期 Q1 DRAM 報價漲幅比 Q4 更高
2. 記憶體是電子族群的「景氣循環股」，獲利全部來自報價表現
3. Q1 仍有財報保護，股價不至於表現太差
4. 封關前的跌幅主要是年終結帳的籌碼面因素，非基本面問題

**風險因素**:
- 中國新廠擴產，下半年可能造成供給增加
- 但短期內價格拋售的可能性不大
- 東西賣得出去的情況下，頂多微幅降價

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| 本益比（P/E） | 股價除以每股盈餘，衡量股票估值是否合理的指標 |
| 合理價格 | 以預估 EPS 乘以近 5 年平均本益比計算出的價格 |
| 過熱價格 | 以預估 EPS 乘以歷史最高本益比計算出的極端價格 |
| 景氣循環股 | 獲利高度依賴產品報價的股票，如記憶體、面板 |
| 集邦科技（TrendForce）| 全球知名半導體市場研究機構，提供 DRAM 報價預測 |
| 價差操作 | 利用股價波動在低點買進、高點賣出賺取差價 |
| 法說會 | 上市公司法人說明會，公布營運展望與財務數據 |
| 毛利率 | （營收 - 成本）/ 營收，衡量公司基本獲利能力 |
