## 🌍 市場總體觀察

### AI泡沫疑慮與大摩報告

#### 近期AI利空因素
1. **微軟退租資料中心**: 一個月前微軟全球多個資料中心喊停
2. **華為AI晶片威脅**: 華為昇騰910D晶片進行測試，直接對標NVIDIA高階產品
3. **客戶縮減硬體預算**: 市場擔心AI硬體預算被逐步削減

#### 大摩（Morgan Stanley）最新報告 - 打臉泡沫論
- **目標價**: NVIDIA 160美元（從162略降2元）
- **核心觀點**: 市場擔心AI泡沫「非常可笑」
- **關鍵論據**:
  - 推論晶片需求呈「爆炸性成長」
  - 營收動能遠未被充分反映
  - AI首選仍是NVIDIA
  - 微軟退租是「重新配置」而非需求減弱（OpenAI轉向Stargate資料中心）
  - Meta與Google迅速補上微軟空出的資料中心需求

#### 全球算力供不應求的證據
1. **Lambda Labs（浪達類似）** - 全球第四大算力租賃中心
   - GPU需求「非常瘋狂」（insane）
   - 今年僅剩8K的B200可用
   - 已開始接受GB300預訂，可用數量超過50K
2. **Google PCR**
   - GB200搭載Gemini 2.5是目前最聰明的模型
   - ASUD與GB200 API活躍用戶一個月成長超過8%
3. **OpenAI**
   - 全力衝刺，請求有H100K規模GPU算力者聯絡
   - ChatGPT推出26個月，用戶突破100萬人
4. **xAI Grok**
   - 全球使用量快速上升，正努力擴充GPU應對需求高峰

### 台幣升值影響分析

#### 資金行情觀察（長星觀點）
- 目前是「去美元化」過程，美元換成新台幣
- 外資主動回頭買尚未出現，屬被動升值
- 央行可能要求外資進來須買台幣趴停（防止套匯）
- 主動外資資金行情目前還沒看到

#### 籌碼面分析（長星觀點）
- **外資**: 從年初持續減碼，期貨空單水位已減少，但動能不足
- **融資**: 已減到2023年初的低點水位（約2,000億）
- **融資維持率**: 跌到120%（扣繳單水位）
- **結論**: 籌碼非常乾淨，殺無可殺，容易做拉抬

## 💼 產業分析與投資建議

### 一、長星選股邏輯：三大策略

#### 策略一：融資大減 + 低本益比 + 營收成長

**1. 神達 (3706)**
- **本益比**: 16倍
- **全年EPS**: 2.3-2.8元
- **3月營收**: 月增12.78%，年增146%
- **融資減幅**: 一個月減少約12,000張
- **題材**: AI伺服器概念股，本益比低但業績持續成長
- **操作建議**: 容易點火就往上拉

**2. 鴻基 (2546)**
- **本益比**: 偏低
- **3月營收**: 年增71%
- **題材**: 加緊出貨概念（趕在關稅前出貨）
- **操作建議**: 4、5月份公布法說會時營收還會往上

**3. 光量科 (4956)**
- **本益比**: 相對較低
- **營收**: 年增月增均有
- **題材**: 台積電相關概念股
- **排列**: K線排列比較強勢

**4. 榮鋼 (5009)**
- **本益比**: 10倍
- **特點**: 特殊鋼鐵，受關稅影響相對小（因關稅已反映）
- **融資**: 開始減肥
- **操作建議**: 營收越增越多，融資開始減少的組合

#### 策略二：台積電資本支出概念股（高殖利率 + 低本益比）

**5. 漢唐 (2404)**
- **特點**: 廠務設備股，本益比相對最低
- **殖利率**: 高
- **走勢**: 這一波幾乎沒什麼跌

**6. 亞翔 (6139)**
- **特點**: 廠務設備股
- **走勢**: 底部吃吃吃吃完後一個拉抬就拉上去
- **選股邏輯**: 高殖利率退可守 + 低本益比進可攻
- **優勢**: 毛利率28%以上，不怕關稅衝擊；多數在美國蓋廠，關稅影響降到最低

#### 策略三：口罩/KOMAX概念股（高毛利率 + 低本益比）

**7. 萬潤 (6187)**
- **本益比**: 約8倍（最低）
- **毛利率**: 最高
- **特點**: 營收好但股價低，短線已開始運量反彈
- **操作建議**: 兩高一低（高毛利率、高殖利率、低本益比）

**8. 鴻碩 (3092)**
- **毛利率**: 不錯
- **走勢**: 這一波上比較強勢，已開始做反彈

### 二、台幣升值受惠 - 資產內股

- 股價淨值比低於1
- 有營收、有殖利率
- 有土地資產或改建資產價值

**9. 台肥 (1722)**
- **資產規模**: 約800多億台幣
- **股價淨值比**: 低於1
- **殖利率**: 有配息
- **題材**: 資產內股，台幣升值受惠

**10. 遠東新 (1402)**
- **資產規模**: 千億級以上
- **股價淨值比**: 0.70倍
- **現金殖利率**: 5%
- **操作建議**: 資產內股行情剛要開始

### 三、冠軍老師推薦 - AI算力租賃與AI供應鏈

**11. 鴻翼股 / 宏碁資訊 (6811)**
- **股價**: 約51.4元
- **本益比**: 21.5倍
- **融資減幅**: -40%
- **基本面**:
  - 旗下GMI Club為台灣第一家獲NVIDIA認證雲服務商（NCP）
  - 算力業務去年7月開始帶來收益
  - 第一批52台H100：每月貢獻約600萬淨利
  - **第二批127台H200**：本季（4月）開始投入，預估每月淨利增至1,200萬以上
  - 合計每月約1,800萬淨利，年化約2億元（佔紅翼股獲利可能達一半）
  - AI設備全數出租給GMI Club，且目前滿載運作
  - 本業為IC通路股：車用電子產品出貨年增15%
  - AIPC、機器人、語音AI應用擴散
  - OTC輔助產品（醫療器材）：與遊合作，今年開始量產
- **技術面**: 缺口已補回來，下一步目標回到70元區間
- **操作建議**: 浪達類似樂觀，算力租賃業者前景看好

**12. 緯創 (3231)**
- **融資減幅**: -45%（血洗類）
- **本益比**: 17倍
- **基本面**:
  - 產線很早退出中國（2020年7月賣中國廠給力碩，2023年7月賣力碩股票）
  - 2023年10月退出印度iPhone主裝產線
  - 重心轉至台灣、菲律賓、墨西哥、越南
  - NVIDIA 2024年年報僅列三個製造夥伴：**緯創、鴻海、台積電**
  - DGS超級電腦伺服器代工由緯創承接（與黃仁勳有革命情感）
  - NVIDIA Ariot模組供應：含古瑞石+不會為模組
  - **xAI下個隊友51萬訂單最大社會股就是緯創**
  - 與NVIDIA在達拉斯建AI超級兩公廠（10-15個月內運作）
- **技術面**: 這一波跌到73.38元為最強（鴻海、緯創、廣達中最強）
- **操作建議**: 可期待回到今年高點，AI沒那麼快走完

**13. 嘉澤 (3533)**
- **本益比**: 不到15倍（法說會後更低至14.84倍）
- **融資減幅**: -19%
- **基本面**:
  - AI伺服器相關營收年增15%
  - 參加NVIDIA GTC展，在MGS生態系連接線展區
  - 與嘉策（千元股）、貿聯（五六百元）並列展出
  - 提供OCP V3（開放基架標準第三版）包匯品
  - 88系電源線、PCIe 6.0內部傳輸線
  - 水冷快接頭通過開放一專機LCP認證
  - 多項產品打入NVIDIA GB300供應鏈
- **技術面**: 法說會後漲停板，現在回測位置本益比不到15倍
- **操作建議**: 跟嘉策（千元）、復世達（400多元）比較，嘉澤價位相對便宜

## 📋 投資策略總結

### 巨眼操作SOP
1. **勞動節後觀察量能**: 有量才追，無量觀望
2. **已補缺口股**: 往上拉時先行獲利了結
3. **未補缺口股**: 資金輪動時的承接標的
4. **不要期待快速攻前波高點**: 大盤沒量就不追
5. **缺口不一定要補**: 但有大量幫忙時會幫找各股賣點

### 長星資金配置建議
1. **不找超大型股**: 鎖定中型股、中大型股
2. **融資乾淨的優先**: 殺無可殺容易拉抬
3. **三大策略**:
   - 融資大減 + 低本益比 + 營收成長
   - 台積電資本支出概念股（高殖利率防守型）
   - 資產內股（台幣升值概念）

### 景氣燈號觀察
- 昨日景氣燈號為黃紅燈（過熱轉折訊號）
- 還沒有消退，但需留意第二季底到第三季可能測底
- 最危險時期：第二季底到第三季

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **算力租賃（GPU-as-a-Service）** | 企業不自購AI晶片，而是向算力中心租用GPU運算資源 |
| **NCP（NVIDIA Cloud Partner）** | NVIDIA認證的雲服務合作夥伴 |
| **Lambda Labs** | 全球第四大算力租賃中心，投資者包括彭博、核酸、尾創等 |
| **推論晶片（Inference Chip）** | 用於AI模型推論（非訓練）的晶片，需求正爆發性成長 |
| **GB200/GB300** | NVIDIA新一代AI加速器，GB300尚未出貨但已開始預訂 |
| **去美元化** | 減持美元資產，轉換為其他貨幣或資產的趨勢 |
| **資產內股** | 擁有大量土地、不動產等實質資產的股票，台幣升值時受惠 |
| **股價淨值比（P/B）** | 股價除以每股淨值，低於1表示股價低於帳面價值 |
| **OCP V3** | 開放計算平台第三版標準，資料中心硬體規格 |
| **DGS** | NVIDIA DGX SuperPOD，超級電腦伺服器系統 |
| **景氣燈號** | 國發會編製的景氣對策信號，黃紅燈代表景氣偏熱 |
