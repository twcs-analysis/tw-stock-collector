## 📈 技術面分析

### 大盤技術面觀點

#### 巨眼（近眼）- 歷史數據統計

1. **四月跌五月必漲定律**
   - 過去十年，四月下跌的年份（2016、2018、2020、2022、2023），五月全數上漲
   - 平均漲幅：2.9%
   - 本次可期待2%-4%的漲幅

2. **融資維持率心低後必漲**
   - 融資維持率創波段新低後，下一個月必漲
   - 本次融資維持率最低在4月9日（118%），推算5月9日前後為關鍵觀察點
   - 最大漲幅歷史紀錄：22.07%
   - 從17,306至今已漲16.99%，剩餘空間約5%

3. **三角收斂跌破後的反彈模式**
   - 今年與2018年（中美貿易戰）、2021年（歐債危機）走勢相似
   - 暴跌後最大一段反彈出現在下一個月
   - 5月高點非常有可能是第二季高點
   - 今年比2018、2021年更樂觀：反彈第一段就已觸及景線（19,662），強於前兩次

4. **川普執政百日效應**
   - 美元指數創52年最大跌幅
   - 5月份川普可能收斂
   - 6月9日聯準會降息觀察點

#### 阿波塞 - 反彈幅度判斷
- 反彈二分之一位置約在20,620-21,000點有壓力
- 原因：Tesla法說會利多（2026下半年數百萬輛自駕車、Robotaxi）+Google財報利好+資本支出未減
- 壓力後可能回檔800-1,000點
- 催化時間點：90天關稅談判進入攤牌期

#### 長星 - 資金流向判斷
- 美元弱勢，資金往亞洲流動
- 目前漲的是中小型股多、大型股少
- 外資主力尚未真正回來，目前是「房皮膚」外資（新加坡等亞洲資金）
- 台幣升值有利資產內股
- 關鍵時間點：5月7日半導體關稅宣布

### 季度行情節奏預測
- **5月**: 短多有機會，可期待2%-4%漲幅
- **6月**: 小心回檔風險，可能是空間較大的調整
- **Q2整體**: 以盤帶跌
- **最大行情**: 在第四季（Q4）

## 📋 投資策略總結

### 短線操作策略
1. **越往上漲，現金比例應提高**，不宜追買
2. 針對還沒補4月7日缺口的個股，按照KD、SOP操作較保險
3. 回補缺口（約20,600點）後應考慮下車而非上車
4. 5月1日勞動節休市後，觀察是否帶量上攻

### 選股邏輯
1. **融資大減肥** + **低本益比** + **營收成長** = 三重篩選
2. 避開超大型股，鎖定中型股、中大型股
3. 找融資清得比較乾淨的上市櫃個股

### 風險提示
- 半導體關稅尚未宣布，5月7日為關鍵觀察日
- 關稅最終稅率仍有不確定性（市場預估10%-17%）
- 台幣升值對出口導向大型股不利

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **對等關稅** | 川普政府4月2日宣布的對各國課徵的對等性關稅，引發全球股市動盪 |
| **融資維持率** | 融資擔保維持率，低於130%時會被追繳，118%已低於金融海嘯水準 |
| **三角收斂** | 技術分析型態，股價高點越來越低、低點越來越高，最終選邊突破 |
| **景線（頸線）** | 技術分析中的支撐或壓力參考線，本次指去年8/5低點19,662 |
| **缺口回補** | 股價跳空下跌形成的缺口，通常需回補才視為走勢恢復正常 |
| **本益比（P/E）** | 股價除以每股盈餘，越低代表股價相對便宜 |
| **BPU** | 基板電源單元（Baseboard Power Unit），伺服器供電關鍵零組件 |
| **一貫化生產線** | 從模具設計到成品組裝的完整生產流程，減少外包提升效率 |
| **Robotaxi** | 無人駕駛計程車服務，Tesla計劃2026下半年推出 |
