## 📊 市場總體觀察

### 投資稅務重點提醒

#### 海外基金轉換的稅務陷阱
- **常見誤解**: 投資人以為在投資型保單中轉換海外基金（從A基金換成B基金），因為沒有實際提取現金，就不算所得、不需申報
- **正確認知**: 國稅局與法院判例已確認，海外基金轉換等同於「贖回舊基金＋申購新基金」，即使沒有現金流入流出，也視為「實現獲利」
- **後果**: 未申報將面臨補稅處分，可能連續多年的報酬率都被吃掉

#### 海外所得課稅規則
- **最低稅負制適用**: 海外所得在100萬元以下不需計入
- **免稅額**: 個人基本所得額扣除750萬元後，乘以20%計算基本稅額
- **比較原則**: 基本稅額與一般綜合所得稅額比較，取較高者繳納
- **重要**: 每次基金轉換都算一次獲利實現，必須保留所有交易明細、原始購買價格等資料

#### 投資型保單注意事項
- 投資型保單 = 投資 + 保險兩個部分
- 投資部分適用一般所得稅法與基本所得稅法
- 保單中基金轉換同樣視為贖回再申購，須申報所得

## 💼 產業分析與投資建議

### 一、處置股出關行情（政華重點分析）

#### 飆股急漲後的觀察要點

**判斷是否被「錢鬥大挪移」（主力換股）的關鍵**:
1. 急漲兩到三天後，出現開高走低的長黑K線 → 短線先獲利了結
2. 連續短線急漲超過40%以上，六天都不跌，第一天出現比前一天還低 → 先減碼
3. KD碰到80就下跌（而非穿越80繼續漲）→ 先出場觀察
4. 法說會前突然急拉，賺三成以上先賣 → 「法說先漲了先賣」策略

**十日均線為大型股操作關鍵**:
- 推薦使用十日線（比五日線穩定，不易被假訊號干擾）
- 跌破十日線需要較長整理時間
- 站穩十日線上方則趨勢偏多

#### 搶帽（處置股案例分析）
- 連續漲幅超過四成後，首次跌破前一天低點 → 短線先出
- 跌破十日線後需要較久時間整理
- 可能出現「大挪移」（主力資金轉移到其他標的）

### 三、處置股操作策略總整理

**出關行情操作SOP**:
1. **觀察期**: 處置期間注意股價是否守住關鍵支撐、主力是否離場
2. **卡位期**: 出關前一到兩天提前佈局
3. **出關日**: 若趨勢向上，出關後往往有更大波段行情
4. **關鍵判斷**: 處置期間收盤穩定＋主力未離場＋族群趨勢向上 = 出關後看多

**被處置不一定是壞事**:
- 處置期間股價下跌可能是洗盤，套牢賣壓在出關拉升時反而有解套動力
- 關到第七、八天若仍未崩盤，出關時往往是買回時機
- 得宏為最新成功案例：處置期間下跌，出關後連續漲停

## 📈 技術面分析

### KD指標實戰應用

#### KD高檔死亡交叉解讀
- 一檔股票從底部啟動到頂部，過程中可能出現四次死亡交叉，但只有最後一次是真的
- **本週KD高檔下彎個股**: 望紅、南亞科、立基電、華邦電 → 法人在賣，需留意
- **本週KD黃金交叉個股**: 花成、亞利、玩與穩貌、金上電（PCB）、視電、台紅、台光電 → 重點關注

#### KD碰到80的兩種情境
1. **碰到80就跌下來**: 危險訊號，先出場
2. **穿越80繼續在上方運行**: 超強勢，48小時內價格續創新高就繼續看漲
- **實戰**: 穿越80後若被處置關進去，等關到第七、八天出來時反而要買回

### 十日均線操作法
- **大型股**: 直接看十日線比五日線穩定
- **站穩十日線**: 多頭趨勢持續
- **跌破十日線**: 需要較長整理期，短線先避開

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **投資型保單** | 結合保險保障與投資功能的保單，保戶可在保單中選擇投資標的（如基金），投資收益與風險由保戶自行承擔 |
| **最低稅負制** | 台灣的「基本稅額條例」，確保高所得者不會因各種免稅優惠而完全不用繳稅，海外所得超過100萬需計入 |
| **基本所得額** | 綜合所得淨額加上特定免稅所得（如海外所得、特定保險給付等）的合計金額 |
| **免稅額750萬** | 基本所得額在扣除750萬元後，才需以20%稅率計算基本稅額 |
| **處置股** | 因股價異常波動被交易所實施處置措施的股票，通常限制為預收款項後才能委託買賣，交易受限 |
| **出關行情** | 處置股解除處置（俗稱出關）後，因交易限制解除且籌碼經過沉澱，可能出現的一波上漲行情 |
| **錢鬥大挪移** | 市場主力資金從原本強勢的股票撤出，轉移到其他新的標的上的現象 |
| **KD指標** | 隨機指標（Stochastic Oscillator），由K值與D值組成，用於判斷超買（>80）超賣（<20）區域 |
| **十日均線** | 過去10個交易日的收盤價平均值連線，為短中期趨勢判斷的重要依據 |
| **四倍七（4U7）** | AI伺服器機架規格，代表4U高度、7個GPU的高密度運算配置 |
