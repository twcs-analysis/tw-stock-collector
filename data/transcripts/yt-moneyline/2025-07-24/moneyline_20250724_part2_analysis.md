## 💼 產業分析與投資建議

### 1. HBM（高頻寬記憶體）價格下跌警訊

**核心邏輯**：高盛預估HBM明年價格將下跌10%。GPU從200到GB300再到未來路線圖，HBM用量沒有增加，但產能持續擴張，導致供過於求風險。

| 個股 | 代號 | 影響分析 | 操作建議 |
|------|------|----------|----------|
| 美光（MU） | 美股 | HBM價格下跌10%消息衝擊，股價修正中 | 觀望為主，HBM成長性最高但價格壓力浮現 |

### 2. NVIDIA B30 中國市場佈局

**核心邏輯**：NVIDIA原本的H20被禁售，改推B30（RTX90系列改版的AI晶片），性能低於H20以符合美國法規，價格30-40萬美元。大摩預估明年中國營收可達250億美元（今年僅17億），出貨量可達200-300萬顆。

| 要點 | 說明 |
|------|------|
| 今年中國營收 | 僅17億美元（因禁售） |
| 明年中國營收預估 | 250億美元（B30開賣） |
| B30年出貨量 | 200-300萬顆（H20僅100萬顆） |
| 影響 | H20不生產不需擔心，NVIDIA早已規劃B30替代方案 |

### 3. AI資本支出持續成長

| 公司 | 去年資本支出 | 今年資本支出 | 變化 |
|------|------------|------------|------|
| 星際之門（Stargate） | - | 4,510億美元（美國資料中心的1/4規模） | 新宣布 |

### 4. 矽晶圓漲價概念

**核心邏輯**：先進製程與BN（後段封裝）需要矽晶圓，但矽晶圓供過於求（10-15%），僅先進製程（佔總需求不到10%）表現佳。漲價力道有限，不宜過度追高。

| 中美晶 | 5473 | 同屬矽晶圓概念，消息面跳漲 | 同上，不宜追高 |

### 5. 第三代半導體

**核心邏輯**：台積電不生產第三代半導體，轉到力積電等廠商。但第三代半導體主要用於碳化矽（SiC）車用領域，百分之百電動車僅佔5-7%，市場太小，規模經濟不足。

| 個股 | 代號 | 分析 | 操作建議 |
|------|------|------|----------|
| 力積電 | 6770 | 因台積電轉單消息跳漲，但市場規模太小 | 消息面跳漲後已回落，不宜追高 |

### 6. RISC-V 指令集架構 - AI新藍海

**核心邏輯**：NVIDIA CUDA支援RISC-V架構，這是RISC-V的重大突破。過去RISC-V在PC（x86）和手機（ARM）都會降速而無用武之地，但在AI與車用領域找到大市場。CUDA花了17年打造生態系，現在AI需要RISC-V，Meta的MTIA晶片也採用RISC-V。

| 要點 | 說明 |
|------|------|
| RISC-V在AI營收佔比 | 已達32%，為最大應用場景 |
| 處理器複合成長率 | 2022-2030年超過50% |
| Meta支援 | Meta的MTIA自研晶片採用RISC-V |
| 獲利預估 | 今年EPS 2.87元，明年可能跳升至6.07元 |

**操作建議**：RISC-V為AI生態中的重要指令集架構，相關概念股值得長線觀察。

### 7. 核能電廠概念股 - 跟著川普走

**核心邏輯**：川普力挺核能電廠，目標2035年核能產能達400GW（現有的4倍）。核能電廠需要大量變壓器（345-505KW等級），用量與價格均為傳統電力公司的5倍以上。

| 個股 | 代號 | 目標價 | 停損點 | 操作建議 |
|------|------|--------|--------|----------|
| 華城 | 1519 | 跟隨美國GE Vernova走勢持續走高 | 前波低點 | 近期接到大訂單：新機制門20億變壓器子訂單 + AI資料中心60億訂單，在手訂單上百億。跟著美國核能政策走 |

**核能電廠變壓器需求**：
- 啟動裝置變壓器
- 升壓變壓器
- 主變壓器（持續運作）
- 備用變壓器（防斷電瞬斷）

相關個股：華城（1519）、中興電（1513）、大同（2371）、螺華等

### 鴻海（2317）技術面

- **多方訊號**：跳空缺口 + 帶量紅K線
- **外資動態**：今日買超第一名58,000張，外資+投信同步買超
- **壓力位**：年線附近有反壓（去年7月前高位置套牢盤）
- **支撐位**：跳空缺口不跌破即偏多
- **策略**：紅K棒一半位置不破 → 強勢整理 → 慢慢低接布局

- 多數個股在骨底區，均線糾結
- 共同特徵：缺量，需等帶量突破才能確認方向
- 光聖為率先指標，其表現決定族群動能

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| HBM（High Bandwidth Memory） | 高頻寬記憶體，AI晶片的關鍵配件，提供高速資料傳輸能力 |
| B30 | NVIDIA針對中國市場開發的AI晶片，RTX90系列改版，符合美國出口管制規定 |
| RISC-V | 開源指令集架構，與x86（PC）和ARM（手機）並列的第三大架構，在AI與車用領域快速成長 |
| CUDA | NVIDIA開發的GPU平行運算平台，花17年建立生態系，為AI訓練與推理的核心 |
| MTIA | Meta自研的AI推理晶片，採用RISC-V架構 |
| 碳化矽（SiC） | 第三代半導體材料，主要用於電動車電力系統，耐高壓高溫 |
| 共同封裝（Co-packaged Optics） | 將光學元件與電子晶片封裝在一起的技術，為矽光子的關鍵應用 |
| GW（Gigawatt） | 十億瓦特，電力容量單位。川普目標2035年核能達400GW |
| 變壓器 | 電力系統中用於升壓或降壓的設備，核能電廠需要345-505KW等級的高規格變壓器 |
| 骨底（打底） | 股價在低檔區域長期整理，形成底部型態，為未來上漲奠定基礎 |
