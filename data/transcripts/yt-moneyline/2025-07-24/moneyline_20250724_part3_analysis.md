### 3. CDMO代工股 - 保瑞（6472）

**核心邏輯**：阿文哥個人認為未來CDMO（委託開發暨製造服務）空間比新藥大。台灣代工能力最強，替國際大廠代工的獲利穩定度較新藥高。保瑞透過併購策略快速成長，2021-2024年獲利成長4倍。

| 個股 | 代號 | 目標價 | 停損點 | 操作建議 |
|------|------|--------|--------|----------|
| 保瑞 | 6472 | 挑戰900元（前高） | 800元支撐區 | 併購效應持續發酵，營收從6億成長至36億。今年EPS預估40.9元、明年49.5元、後年99元。盤久待突破，需要時間但會過 |

**保瑞併購效益**：
- 併購美國馬里蘭州無菌藥廠 → 營收從6億增至36億

- 明尼蘇達藥廠去年營收9億

### 4. Tesla Diner 與機器人應用

**核心資訊**：
- **開幕日期**：7月21日，位於洛杉磯
- **餐廳特色**：復古美式 + 科技元素、汽車電影院、兩座45吋LED巨型螢幕、80個V4超級充電座（支援250千瓦，可擴充至500千瓦）、超過250個座位、24小時營業
- **營收表現**：開業首日前6小時營收約4.7萬美元（約150萬台幣），高出鄰近麥當勞30%
- **機器人應用**：目前以Optimus機器人做飲料遞送為主，應用尚在初期階段
- **擴張計畫**：第二家分店確認設在德州SpaceX總部附近

**Tesla Diner營收推估**：
- 若展店至240家，餐飲營收可媲美摩托羅拉的一個銷售營收
- 相當於Tesla同期汽車業務的42.6%
- 與車業相輔相成，充電站帶動來客

### 6. 主動式ETF全面剖析

**市場現況**：
- 台灣主動式ETF從2025年5月開始掛牌
- 目前共5檔，總資產規模約150億元
- 受益人數：先掛牌的已突破2萬人

**五檔主動式ETF比較**：

| ETF特色 | 操作方式 | 配息 | 經理費 |
|---------|----------|------|--------|
| 安聯高息型 | 6成高股息 + 4成成長股 | 季配息 | 較高 |
| 靈銳成長型 | 主動追求大成長 | 年配息 | 較高 |
| 復邦科技型 | 主動追求科技成長 | 年配息 | 較高 |
| 也穿台灣五十 | 7成前50大公司 + 3成中小型 | 季配息 | 中等 |
| 中信創新型（與方舟合作） | 主動式顛覆創新 | 待觀察 | 較高 |

**主動式ETF vs 被動式ETF vs 主動基金 三方比較**：

| 比較項目 | 被動式ETF | 主動式ETF | 主動基金 |
|----------|-----------|-----------|----------|
| 手續費 | 千分之四（較高） | 中等 | 平台零手續費（較低） |
| 經理費 | 千分之一~四（最低） | 約被動式的兩倍 | 最高 |
| 調整彈性 | 小（追蹤指數） | 大（經理人決定） | 大 |
| 穩定度 | 高 | 中 | 中 |
| 適合投資人 | 穩健型 | 積極追求報酬 | 已習慣買基金者 |

**績效回測**：以主動基金過去5年績效（作為主動ETF的參考）：
- 科技型主動基金：5年表現不輸甚至超越0050、復邦科技ETF
- 一般型主動基金：前三家表現佳，群益稍落後
- 結論：主動式操作有機會打敗被動式ETF

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| CDMO（Contract Development and Manufacturing Organization） | 委託開發暨製造服務組織，為藥廠提供藥物的開發、生產代工服務 |
| GLP-1（Glucagon-Like Peptide-1） | 類升糖素胜肽-1，用於治療第二型糖尿病與肥胖的藥物靶點 |
| 三期臨床試驗 | 新藥開發最後階段的大規模人體試驗，通過後即可申請上市 |
| 權利金（Royalty） | 新藥授權後，按銷售額比例持續收取的費用 |
| 里程碑金（Milestone Payment） | 新藥開發達到特定進度時，被授權方支付的款項 |
| 學名藥 | 原廠專利過期後，其他藥廠依相同配方生產的藥物，價格較低 |
| 緩釋藥物 | 透過特殊技術使藥效從2小時延長至3-4小時的藥物 |
| 主動式ETF | 由基金經理人主動選股操作的ETF，介於被動式ETF與傳統主動基金之間 |
| V4超級充電座 | Tesla最新版充電設備，支援250千瓦充電，可擴充至500千瓦 |
| Optimus | Tesla開發的人形機器人，目標價格1-5萬美元，用於製造業與家庭 |
| Neuralink | 馬斯克創辦的腦機介面公司，可植入微型電極至大腦 |
