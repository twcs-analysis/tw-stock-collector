## 💼 產業分析與投資建議

### 1. 美日關稅協議與台灣展望

**核心邏輯**：美日關稅從25%降至15%，日本股市連噴兩日。市場期待台灣也能談到類似稅率，若台灣關稅落在15%，台股將跟進大漲。

| 情境 | 關稅稅率 | 股市反應預估 |
|------|----------|--------------|
| 最佳情境 | 15% | 台股跟隨日本股市大漲，市場狂歡 |
| 中性情境 | 18% | 可接受範圍，股市溫和反應 |
| 不利情境 | 25%以上 | 台股面臨下跌壓力，競爭力受損 |
| 白日夢 | 10% | 不要做白日夢，可能性極低 |

**操作建議**：8月11日前台灣關稅結果將揭曉，投資人應留意此關鍵變數，控制持股水位。

- 低位階股票相對安全，但100元以下、EPS超過1元的被低估股很多

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| 對等關稅 | 美國針對貿易夥伴國所設定的關稅稅率，以回應對方對美國商品的關稅 |
| 矽光子（Silicon Photonics） | 利用矽製程製造光學元件的技術，用於高速數據傳輸，為AI時代關鍵技術 |
| 銅箔基板（CCL） | PCB的核心材料，AI伺服器對高階銅箔基板需求大增 |
| ABF載板（Ajinomoto Build-up Film） | 用於IC封裝的高階基板，供不應求延續至明年 |
| 跳空缺口 | 股價跳空上漲留下的價格空白區，代表多方力量強勁，通常為重要支撐 |
| 法說會（法人說明會） | 上市櫃公司向法人投資者報告營運成果與展望的會議 |
| FNG | 追蹤美國十大科技龍頭股的ETF，每家均等投資10% |
| 殖利率 | 現金股利除以股價，衡量股票配息回報的指標 |
