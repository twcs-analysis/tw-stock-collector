## 市場總體觀察

### 處置股現象 -- 多頭格局的副產品
- 近期記憶體、PCB、矽光子等熱門族群頻繁被列入注意或處置
- 江湖傳說「越關越大尾」持續被市場驗證
- **核心觀點**: 在多頭格局下，處置股是熱門股的「日常」，不應全面迴避

### 高股息 ETF 困境
- 2025年大盤漲幅 **24%**，但主流高股息 ETF 表現遠遠落後
- 0056：含息報酬率約 11%（最佳表現）
- 00919、00929、00878：淨值成長接近零，報酬幾乎全靠配息
- **2026年展望**: 會比2025年好一些，但仍會落後市值型 ETF

### 債券 ETF 持續困境
- 2025年表現：新興市場債最佳，長天期公債最弱
- 美國長天期公債殖利率跌不下來 → 價格漲不上去
- **2026年風險加劇**: 五大雲端公司預計大量發行公司債 → 供給增加 → 殖利率上升壓力

## 產業分析與投資建議

### 一、處置股操作完整攻略

#### 被列入注意/警示的常見條件
| 條件類型 | 具體標準 | 說明 |
|----------|----------|------|
| 漲幅 | 30個交易日漲100% | 動能交易者的選股條件之一 |
| 漲幅 | 60個交易日漲130% | 累積漲幅觸發 |
| 漲幅 | 90個交易日以上持續推升 | 長期累積 |
| 周轉率 | 當日10%以上 | 單日爆量 |
| 周轉率 | 累積50%以上 | 連續爆量 |
| 成交量 | 放大倍數異常 | 主管機關有裁量權 |
| 本益比 | 股價淨值比異常 | 主管機關有裁量權 |

**重要觀念**: 現代熱門股的當沖率不超過50%就不會漲，當沖客是高手，他們懂題材，能當熱門股的基本條件就是高當沖率。

#### 三階段操作策略

**第一階段：入關前（預防性操作）**
- 當你已獲利且判斷即將被處置時 → **先出場**
- 大部分第一次被關會跌1-3天
- 連續被列注意三天 → 幾乎確定要被處置
- 長到第四、五根漲停再追 → 不建議，等入關後第7天再買

**第二階段：處置期間（等待策略）**
- 五分鐘撮合一次 → 影響較小，仍可交易
- 二十分鐘撮合一次 → 流動性大幅下降，操作困難
- 可考慮買同族群替代股

**第三階段：出關交易（核心策略）**

| 情境 | 操作方式 | 成功率 | 範例 |
|------|----------|--------|------|
| 同族群已大漲 | 出關首日追進 | 極高 | 矽光子 CPO 股，入關時同族群已漲到天上 |
| 出關首日跌但同族群仍強 | 第二天買進 | 高 | 博錸衛（3316）出關首日跌，隔日走主升段 |
| 連續處置兩次 | 不追 | 低 | 注意通知重疊，動能被阻斷 |
| 高於前高位置出關 | 警戒 | 中低 | 可能關下來再上去，但風險較高 |

#### 處置股替代策略
- 當龍頭被關 → 買同題材、同產業的替代股
- 範例：經緯航太被關 → 買融哥（題材相同、價格更低、股性類似）
- 銅箔基板類：同族群大漲帶來的概念股

### 四、債券 ETF 2026 年展望

**不看好的理由**:
1. **降息空間有限**: 市場預估2026年最多降息兩碼
2. **長天期殖利率跌不下來**: 美國財政惡化 + 日本財政擴張
3. **新增公司債供給**: 五大雲端公司（Meta、Google、Amazon、Microsoft、Apple）預計大量發行公司債，供給增加壓低價格
4. **匯損風險**: 若美元走弱台幣升值，持有美債 ETF 還要承擔匯損

**相對較佳的選擇**:
| 債券類型 | 展望 | 原因 |
|----------|------|------|
| 新興市場債 | 較佳 | 2025年表現最好，持續受益 |
| 短天期/中天期 | 較佳 | 風險較低，受長端利率影響小 |
| 非投資等級債 | 可持有 | 經濟未衰退前仍可獲取較高配息 |
| 長天期公債 | 不佳 | 殖利率難降、價格難漲 |
| 投資等級債 | 不佳 | 供給增加壓力 |

## 技術面分析與操作策略

### 處置股技術面判斷
1. **華新科光電（矽光子代表）**: 當沖率50%以上才會漲，低於50%不動
2. **出關位置判斷**: 出關時若低於前高 → 安全；高於前高 → 危險
3. **同族群比價**: 出關後看同族群是否仍在漲 → 決定是否追進

### 高股息 ETF 操作建議
- 不建議只持有高股息 ETF，應分散至市值型或科技型
- 2026年傳產部分產業（軍工、紡織）可能好轉，但整體仍落後科技
- 建議：高股息 + 市值型科技 ETF 組合配置

## 投資策略總結

1. **處置股不可怕**: 多頭格局下，被處置是熱門股的「成人禮」，掌握入關前出場、出關後進場的節奏
2. **出關交易是機會**: 同族群仍強勢時，出關第一天跌可買第二天；同族群已大漲時，出關首日直接追
3. **替代股策略**: 龍頭被關找同題材替代股（如經緯 → 融哥）
4. **高股息 ETF**: 2026年會比2025年好，但仍落後市值型；可分散至國際高股息
5. **債券 ETF**: 2026年仍辛苦，偏好新興市場債與短中天期，避開長天期公債
6. **年底三大觀察**: 川普關稅是否被最高法院撤銷、日本財務省干預日圓可能性、白銀銅等原物料金屬噴出行情

## 名詞解釋

| 名詞 | 說明 |
|------|------|
| **處置股** | 因股價異常波動被證交所列入處置的股票，交易改為集合競價（5分鐘或20分鐘撮合一次） |
| **注意股** | 股價異常波動的第一階段警示，下一階段為警示，再下一階段為處置 |
| **出關交易** | 股票從處置期間結束恢復正常交易後的第一波交易機會 |
| **當沖率** | 當日沖銷交易量占總成交量的比率 |
| **五分鐘撮合** | 處置期間每五分鐘集合競價一次，影響較小 |
| **二十分鐘撮合** | 處置期間每二十分鐘集合競價一次，流動性大幅下降 |
| **含息報酬率** | 將股價漲跌與配息合計的總報酬率 |
| **投資等級債** | 信用評等 BBB- 以上的公司債券，風險較低 |
| **非投資等級債** | 信用評等 BB+ 以下的債券（又稱高收益債），配息較高但風險也較高 |
| **CDS** | Credit Default Swap，信用違約交換，衡量債券違約風險的工具 |
| **CPO** | Co-Packaged Optics，共封裝光學，矽光子技術的應用 |
| **新興市場債** | 由新興市場國家政府或企業發行的債券 |
