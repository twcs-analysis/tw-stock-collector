### 除權息行情操作策略（明翰教學）

#### 核心觀念：吃大戶的豆腐

1. **為何有機會**: 大戶稅率高（所得稅40%或分離課稅20%），一般投資人稅率低甚至免稅
2. **大戶避稅行為**: 除息日前賣出現貨、買各股期貨避開稅負
3. **操作原理**: 大戶必須賣出 → 產生棄息賣壓 → 越跌越開心 → 除息後賣壓消失、大戶回補現貨

#### 操作步驟

1. **篩選高殖利率概念股**: 找出6~8月除權息標的
2. **往前推算前三年慣性**: 確認該股除息前後的股價表現規律
3. **區分長前面 vs 長後面**: 如正新輪胎（2105）習慣漲前面，長榮（2603）習慣漲後面
4. **介入時機**: 除息前棄息賣壓越大越開心，最後一天甚至最後一盤勇敢切入
5. **出場原則**: 股價轉弱就下車，或填息即出場

#### 操作三原則

- **大漲不追**: 除息前大漲就放棄，找下一檔
- **流動性**: 分批布局3檔以上，不集中單一標的
- **股價轉弱出場**: 第一天漲、第二天漲、第三天翻黑就賣掉

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **棄息賣壓** | 大戶為避稅在除息日前賣出持股，造成股價下跌壓力 |
| **還原權值** | 將除權息配發的股利加回股價計算，反映真實報酬率 |
| **殖利率** | 現金股利 / 股價 x 100%，衡量股票配息報酬率 |
| **填息** | 除息後股價回到除息前價位，代表投資人賺到股利又不虧本金 |
| **BMC晶片** | 伺服器基板管理控制器晶片，信驊為全球龍頭 |
| **非農就業數據** | 美國每月公布的就業人口變化，影響聯準會利率決策 |
| **費半指數** | 費城半導體指數，追蹤全球主要半導體公司股價表現 |
