## 🌍 市場總體觀察

### 六月全球風險評估

#### 關稅議題已降溫

- **VIX恐慌指數回顧**: 對等關稅期間VIX飆升至僅次於2008金融風暴與2020疫情的歷史紀錄
- **市場已麻痺**: 從加拿大、墨西哥關稅到歐洲50%關稅威脅，市場反應一次比一次弱
- **結論**: 關稅議題已不再是市場焦點，未來再度利用關稅議題大跌時，反而是買進機會

#### 美債到期風險（六月核心議題）

- **問題本質**: 今年美國國債大量到期，幾乎集中在第二季，尤其六月
- **到期規模**: 全年約36兆美元國債中，大量集中在六月需要「借新還舊」
- **恐慌來源**: 關稅讓各國對美國不滿，市場擔心「為什麼還要借錢給美國」
- **實際數據**: 美國十年期公債投標倍數持續走高（約2.6倍），代表需求仍然充沛
- **短線波動**: 五月份部分標售不太順利，但屬正常波動，長期趨勢仍上升

#### 美債不會倒的核心邏輯

1. **美元霸權循環**: 全球外銷收美元 → 銀行換給央行 → 央行持有外匯存底 → 最終只能買美債
2. **各國持有狀況**: 日本高檔盤整、中國持續減持，但其他國家仍持續增持
3. **中國減持的啟示**: 賣美債只能買黃金，但黃金流動性差、大量變現會崩盤、降低國際信認度
4. **美元結算佔比**: 全球結算仍有近50%使用美元，歐元僅約20%，20年來比例幾乎未變
5. **規模問題**: 美債總量36兆美元，全球黃金市場都無法容納如此龐大資金
6. **結論**: 只要美元霸權存在，美債就不會倒。10年內美元霸權動搖的機率極低

#### 股債配置觀念

- **長期規律**: 股市與債券價格呈反向走勢（股跌債漲、股漲債跌）
- **近期股債雙殺**: 屬短線特殊現象，長線一定回歸反向
- **正確操作**: 債券是「存錢」用途，股市崩盤時賣債買股
- **當前環境**: 關稅風險降低，股優於債是正常的
- **債券建議**: 不要進來賺價差，存錢的才適合投資債券

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **GDR** | 全球存託憑證（Global Depositary Receipt），企業在海外發行的有價證券，代表一定數量的原股 |
| **借券賣出** | 向券商借入股票後賣出，預期股價下跌後回補獲利，為做空手段之一 |
| **投標倍數** | 政府公債標售時，投標金額與發行金額的比值，越高代表需求越旺 |
| **借新還舊** | 發行新債券來償還到期的舊債券，政府維持財政運作的常見手法 |
| **美元霸權** | 美元在全球貿易結算、外匯存底中占絕對主導地位的現象 |
| **VIX恐慌指數** | 芝加哥選擇權交易所波動率指數，反映市場對未來30天波動的預期 |
| **SCFI** | 上海出口集裝箱運價指數，衡量全球貨櫃航運運價的重要指標 |
| **DDR4/DDR5** | 第四代/第五代雙倍資料速率記憶體，DDR5為新一代規格，速度更快、功耗更低 |
| **景氣循環股** | 獲利隨景氣週期大幅波動的股票（如記憶體、航運），操作邏輯與成長股不同 |
| **主動式 ETF** | 由基金經理人主動選股操盤的ETF，有別於被動追蹤指數的傳統ETF |
| **BT材料** | 高階封裝用的關鍵基板材料（Bismaleimide Triazine），用於先進封裝製程 |
| **股債齊殺** | 股票與債券同時下跌的異常現象，通常為短線特殊事件 |
| **ETF成分股調整** | 指數型基金定期調整持股，被納入的股票會有投信被動買盤 |
