## 🌍 市場總體觀察

### 韓國新總統李在明就任分析

#### 基本背景

- **當選者**: 李在明（進步派領袖），61歲，得票率約49.1%
- **政治立場**: 親中派（前任尹錫悅為強烈親美派）
- **選情特色**: 兩大陣營勢均力敵，以些微差距勝出
- **核心問題**: 親中路線可能成為川普的「統戰時間」，美國需花時間搞定韓國

#### 李在明面臨三大議題

**1. 韓國內部政治分裂**
- 親中派與親美派勢均力敵，內部四分五裂
- 優先事項：團結國內、避免繼續撕裂
- 多位政治人物面臨官司纏身
- 若無法團結內部，難以在國際上展現強大民意支持

**2. 經濟困境**
- 韓國與德國同為出口導向經濟體，高度依賴中國市場
- **中國市場四大風險**:
  - 經濟收縮：皇帝上的房地產、地方政府債務問題未解決
  - 強迫技術轉讓：進入中國市場必須交出關鍵技術給中方合作夥伴
  - 進口替代：中國企業模仿外資後，替代國內市場再搶國外市場
  - 產能過剩：電動車、太陽能板、鋼鐵等低價傾銷全球
- 韓國記憶體產業面臨中國模仿追趕威脅
- 資金外流加劇 → 中國可能加強資本管制

**3. 關稅談判困境**
- 李在明想在美中之間「左右逢源、兩邊下注」
- 但美中關係本質是對抗，韓國不可能維持平衡
- 美國對盟友課關稅的真正目的：要盟友選邊站、對抗中國
- 越南案例：美國要求對中國原料加徵35%~50%關稅，否則維持46%對等關稅
- 英國案例：簽貿易協議的前提是不與非市場經濟體（中國）做協議

#### 美國對韓國的戰略調整

- **駐韓美軍戰略彈性**: 投票前美國宣布將28,500名駐韓美軍中的16%（4,500人）調往其他地區
- **歷史先例**: 2003年曾將駐韓美軍部分調往中東
- **訊號意義**: 韓國不聽話 → 美國減少軍事承諾 → 更需要拉攏台灣與日本

#### 對台灣的影響與機會

| 面向 | 分析 |
|------|------|
| **美國不會修理台灣** | 需要台灣製造業赴美投資（重電、金屬加工、工具機、機器人） |
| **關稅不會放過** | 台灣對美順差排第6，2,300萬人口順差與德國（9千萬人）、日本（1.2億人）平起平坐 |
| **搶頭香建議** | 台灣應搶先成為亞洲第一個與美國簽貿易協議的國家 |
| **頭香好處** | 美國會給臺面下好處，並以台灣為模板與其他國家談判 |
| **預估稅率** | 從32%對等關稅降至15%~6%，不會比斯里蘭卡低 |
| **韓國籌碼** | 造船業可作為談判籌碼（日本也以造船業換取降稅） |
| **風險** | 若被韓國搶先簽成，台灣將處於不利地位 |

## 📈 技術面分析與操作策略

### 期貨選擇權觀察（藝恆分析）

#### 2020年類比框架

- **相似點**: 2020年3月疫情爆發（全球航運中斷）→ 國安基金進場 → 一路多頭
- **2025年**: 川普關稅亂搞（全球貿易中斷）→ 國安基金進場 → 開始反彈
- **若6月收紅棒+7月也收紅棒** → 類似2020年一路多頭過高，挑戰22,000點以上
- **若6月收黑棒** → 回測20,000點附近支撐

#### 6月合約三大觀察指標

**指標一：台指期合約方向**

| 項目 | 數據 |
|------|------|
| 換倉開盤價 | 21,670點（5/21下午3點後近月合約） |
| 多方有利 | 合約價在21,670之上 |
| 空方有利 | 合約價在21,670之下 |
| 目前狀態 | 回到平盤附近（多空交戰關鍵位置） |
| 注意事項 | 6月有台積電等除息扣點約100點，與加權指數有價差是正常的 |

**指標二：外資期貨空單**

| 項目 | 數據 |
|------|------|
| 換倉時空單 | 38,800口 |
| 曾增至 | 45,000口（下跌過程中加空） |
| 目前 | 回到38,000口附近（回到開盤水位） |
| 性質 | 非新增空單，是從載入指數後一路流倉的舊單 |

- **歷史規律**:
  - 外資一路做多（空單減少）→ 指數容易上漲
  - 外資一路做空（空單增加）→ 即便上漲也會砍坎科科、最終崩跌
- **觀察重點**:
  - 空單持續回補至35,000→32,000口 → 6月合約收紅棒，可偏多操作
  - 空單增加至39,000→40,000→41,000口 → 6月合約往下走

**指標三：外資選擇權賣權籌碼**

| 項目 | 說明 |
|------|------|
| 目前狀態 | 外資在賣權做莊家（Sell PUT），淨精耳為負值 |
| 歷史意義 | 外資做Sell PUT時，最多高檔盤整，不會崩跌 |
| 異常訊號 | 外資很少長期做買方（買PUT），一旦轉為大量Buy PUT才是真正要跌 |
| 當前解讀 | 即便指數往下跌，也不用太過擔心；除非看到CPUT大幅減少甚至轉正 |

#### 6月行情三種情境

| 情境 | 機率評估 | 條件 | 操作建議 |
|------|---------|------|---------|
| **偏多挑戰22,000點** | 中 | 站穩開盤價+營收利多帶動+無國際利空 | 積極做多，佈局市值型與趨勢個股 |
| **高檔盤整（最大機率）** | 最高 | 7月關稅到期前觀望+上有壓下有撐+國際時好時壞 | 區間操作，控制倉位 |
| **偏弱回測底部** | 低 | 6/4紅棒底部跌破+外資大幅加空+CPUT轉買方 | 減碼防守 |

**藝恆個人判斷**: 高檔盤整的機率最大，真正的事件在7月才會出來（關稅寬限期到期），6月是觀望期。

### 下週大盤操作重點（薄潔老師）

#### 台積電（2330）除息 - 下週四（6/12）

| 項目 | 分析 |
|------|------|
| 配息 | 4.5元 |
| 填息預期 | 若無天災人禍，應會填息 |
| 外資態度 | 仍有機會繼續買 |
| 操作建議 | 壓回買進；若填息後站穩1,000元 → 目標往1,100元 |
| 策略 | 先賺息、再賺價差；填息後留在裡面等衝過1,000元 |

#### 信驊（5274）除息 - 下週五（6/13）

| 項目 | 分析 |
|------|------|
| 殖利率 | 僅1%多，價格高不怕填息 |
| 除息前 | 可能有賣壓 |
| 除息後 | 因金額小，填息障礙不大 |
| 均線狀態 | 尚未呈現多頭排列（排列收斂中），需時間整理 |
| 操作建議 | 壓回佈局，等均線集結成軍後發動 |

#### 衝關五大觀察

1. **電子成交比重**: 必須達60%以上，靠金融與航運衝關無效（今天僅58%）
2. **量能要求**: 需要「試撐一」等級的量能放大
3. **營收反應**: 業績成長股公布利多後，股價要正向反應（不能像緯創利多出盡）
4. **AI主導**: AI族群續漲同時讓其他族群表現是健康的；若換主流離開AI則有疑慮
5. **加權指數**: 目前壓在年線與半年線之下整理，大跌機率不高但要大漲需量能配合

#### 今晚非農數據的理想情境

- **太好**: 不會降息 → 麻煩
- **太壞**: 引發衰退恐慌 → 也麻煩
- **剛好差一點**: 有利降息預期 → 最理想

### 6月行情判斷

- **最可能情境**: 高檔盤整、上下洗刷
- **多方條件**: 電子比重>60%、AI主導、量能放大、外資空單回補
- **空方條件**: 外資空單增加、CPUT轉買方、6/4紅棒底部跌破

### 地緣政治投資框架

| 趨勢 | 投資方向 | 時間軸 |
|------|---------|--------|
| 韓國親中 → 美國更需台灣 | 台灣半導體長線利多 | 長線 |
| 美國對盟友要求選邊站 | 台灣若搶到頭香有利 | 中線 |
| 美中對抗持續升級 | AI、半導體、軍工受惠 | 長線 |
| 亞洲貿易協議競賽 | 搶先簽約的國家受惠 | 中線 |

### 風險因素

| 風險 | 評估 | 影響程度 |
|------|------|---------|
| 川普政策變數 | 隨時可能拋出炸彈 | 中高 |
| 7/9關稅寬限期到期 | 6月中後段開始反應 | 中 |
| 非農數據 | 太好或太壞都不利 | 中（短線） |
| 韓國外交搖擺 | 增加東北亞不確定性 | 低（對台灣反而可能利多） |

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **台指期合約** | 台灣加權指數期貨合約，每月結算一次，是觀察法人多空態度的重要指標 |
| **換倉/轉倉** | 期貨合約到期前，將部位從即將到期的近月合約移至下一個月的動作 |
| **Sell PUT（賣權莊家）** | 外資在選擇權市場賣出賣權，收取權利金，代表看好後市不會大跌 |
| **Buy PUT（買賣權）** | 買進賣權，預期指數下跌時獲利，為看空訊號 |
| **淨精耳** | 選擇權的淨權利金收支，負值代表做莊家（賣方）、正值代表做買方 |
| **試撐一** | 台股成交量放大至一定水準（通常3,000億以上），代表有足夠資金推動行情 |
| **開盤缺口** | 股價跳空開盤形成的價格空白區域，具有支撐或壓力意義 |
| **對等關稅** | 美國對貿易夥伴課徵與對方對美國同等稅率的關稅政策 |
| **洗產地** | 將中國製商品透過第三國轉口，規避美國對中國課徵的高關稅 |
| **駐韓美軍戰略彈性** | 美國保留將駐韓美軍調派至其他地區的權力，作為對韓國施壓的工具 |
| **進口替代** | 一國企業透過模仿外國技術，以國產品取代進口品的經濟策略 |
| **填息** | 除息後股價回到除息前價位，代表投資人賺到股利又不虧本金 |
