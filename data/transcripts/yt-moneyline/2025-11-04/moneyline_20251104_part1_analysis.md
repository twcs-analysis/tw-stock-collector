## 產業分析與投資建議

### 投信買超布局觀察 - 第四季法人建倉邏輯

**推薦來賓**: 會是老師

**核心觀點**: 法人機構在第四季通常最忙，因為開始展望明年數字。如果看好某公司明年整年有大幅上漲潛力，不會等到明年才買，而是在今年先建立基本部位。投信今天轉為買超，代表法人已開始「拉回就買」，為明年積極布局。

---

### 個股推薦一：群聯（8299）- 記憶體龍頭

**推薦來賓**: 會是老師

**投信積極布局跡象**:
- 投信在群聯的操作呈現「每一波都是投信點火」的型態
- 分盤交易期間無法買入，一解禁就馬上進場
- 從頭到尾持續買進，展現堅定做多意志

**基本面亮點**:
1. **記憶體需求結構性成長**: HBM（高頻寬記憶體）需求爆發，明年供需缺口擴大
2. **PLC技術領先**: 功耗較低、處理速度更快，取代傳統產品趨勢明確
3. **全球記憶體需求年增39%**: 而供給僅增加12個百分點，供需缺口巨大
4. **文生圖等AI模型持續耗用容量**: 明年需求量更大

**估值分析**:
- 今年EPS預估約35元，市場給予約30倍本益比
- 明年EPS若達60元，以30倍本益比計算，目標價約1,800元
- 本益比有機會隨漲價循環進一步調高

**操作建議**:
- 收盤價約1,004元
- 上升趨勢線與季日線靠近，為重要支撐
- 跳空缺口也是換手成本區
- 靠近支撐線附近可多加留意進場

## 族群拉回觀察 - 記憶體、PCB、被動元件

**推薦來賓**: 其真

### 核心觀點
三大族群（記憶體、PCB、被動元件）皆為「漲多拉回找買點」。

### 記憶體族群分析
- **大循環趨勢不變**: AI正在徹底重寫記憶體產業邏輯，從景氣循環股轉為成長股
- **今天拉回原因**: 旺宏Q3財報不如預期，引發獲利了結
- **三星暫停DDR5合約報價**: 暗示原廠惜售、供給趨緊
- **海力士前景正面**: 長期看好DDR5需求
- **選股原則**: 買DDR不要買模組，買工控不要買消費
- **首選南亞科**: 明年有望成為最大DDR5供應商
- **華邦電次選**: 但南亞科優先

### 新股推薦：檸檬化（記憶體模組新股）
- 8月6日新櫃轉上市
- DDR/NAND Flash/SSD固態硬碟全產品線
- 68%基礎產品、31%高難度系統廠與政府標案
- 已拿到印度政府裝暗標案
- 2022年獲得DDR記憶體模組規格認證，已切入伺服器領域
- EPS從0.3→1.3→2.3，連續16年穩定獲利

**操作建議**:
- 今天破線，先不要進場
- 觀察40元附近能否持穩
- 等記憶體整體重新轉強後再關注

### PCB族群分析
- **2026/2027/2028規劃已確定**: 台灣廠商至少吃三年利潤
- **整理兩個月籌碼已較乾淨**: 拉回更應站在買方
- **重點標的**:
  - 景向電 - 美系客戶產品換代，後續有更多CSP客戶量產
  - 定穎控 - 車用轉型AI GPU，海外高階製程能力，明年成長可達67-90%

### 被動元件族群
- 節目中提及但未深入討論，整體邏輯與記憶體、PCB相同：漲多拉回找買點

## 名詞解釋

| 名詞 | 說明 |
|------|------|
| **HBM** | High Bandwidth Memory，高頻寬記憶體，AI加速器不可或缺的關鍵元件 |
| **PLC** | Penta-Level Cell，五層式儲存單元，記憶體密度更高、功耗更低 |
| **HVLP** | High Volume Low Profile，高容量低剖面銅箔基板材料，PCB先進製程關鍵 |
| **T2/T3** | 指AI伺服器機櫃連接器規格世代，T3需求比T2更大 |
| **GB300** | NVIDIA下一代AI伺服器平台，帶動散熱/連接器/PCB等供應鏈需求 |
| **分盤交易** | 當個股成交量過大或波動劇烈時，主管機關實施的限制交易措施，改為每五分鐘集合競價一次 |
| **假跌破真突破** | 股價先跌破支撐線吸引空方賣出，隨後快速收回並突破，屬洗盤手法 |
| **DDR5** | 第五代雙倍資料傳輸率記憶體，AI伺服器與高階PC的主流規格 |
