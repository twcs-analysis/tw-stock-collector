## 產業分析與投資建議

### 低價萬元放大術 - 五檔精選

**推薦來賓**: 會是老師

**選股邏輯**:
1. 產業趨勢對的，市場餅在變大
2. 少數人有的不可取代性
3. 新規格或產業發展重點
4. 股價便宜（低價股）
5. 中線轉機強

### 個股推薦一：歐格（PDU電力管理設備）

**推薦來賓**: 會是老師

**公司基本面**:
- 主營PDU（Power Distribution Unit，配電單元）
- 在資料中心/伺服器機櫃中分配電力的關鍵設備
- 已從一般工業用/消費用，轉型切入AI資料中心用途

**投資亮點**:
1. **AI資料中心必備**: 高功率AI伺服器需要穩定供電，PDU確保電力分配避免運算中斷
2. **從單相轉三相電源**: AI機櫃需要更高功率（60千瓦級），三相電源更穩定
3. **轉型AI用途帶動評價提升**: 從低階工業用轉至高階AI用，心態面與估值面同步拉升
4. **今年已開始出貨**: 營收貢獻明年比重將提升至三成以上
5. **EPS已轉虧為盈**: 轉型效果明顯
6. **營收年增率連續六個月轉正**: 基本面轉強力道明確

**操作建議**:
- 收盤價22元（一張僅2.2萬元）
- 技術面：已差一點創新高，今天隨大盤拉回
- 月線附近為支撐，貼著重要均線操作
- 波動較大（低價轉機股特性），不宜追高，拉回月線附近可布局
- 停損：跌破月線且無法收回

### 個股推薦二：得紅（PCB高頻材料）

**推薦來賓**: 會是老師

**公司基本面**:
- 做石英布（Quartz Fiber）材料，全球獨家技術，台灣唯一量產
- 高速傳輸從56G到112G到224G，必須使用低介電材料
- 今年漲幅已達450%（從個位數起漲）

**投資亮點**:
1. **石英布全球獨家**: DK/DF值極低，是高頻PCB不可或缺的材料
2. **應用範圍廣泛**: 先進封裝基板、5G/6G基地台、高速HPC、半導體材版、軍工（飛彈鼻罩、天線罩）
3. **耐高溫1,050度**: 化學穩定性佳（700度以上不變質），熱膨脹係數低
4. **6G需求即將到來**: 黃仁勳與Nokia合作推動6G，石英布為必要材料
5. **光通訊也需使用**: 跨領域應用擴大
6. **供給極有限**: 全球就這麼幾家，需求持續擴大

**操作建議**:
- 收盤價62元
- 今年已漲450%，短線不宜追高
- 但長線趨勢類比航運股（長榮從16元起漲），技術難度更高的產品漲幅可能更大
- 仍有機會再創新高

## 名詞解釋

| 名詞 | 說明 |
|------|------|
| **PDU** | Power Distribution Unit，配電單元，在資料中心機櫃中分配電力至各設備的關鍵裝置 |
| **石英布** | Quartz Fiber Cloth，以石英纖維製成的高頻基板材料，具極低介電常數（DK）與介電損耗（DF） |
| **BGA** | Ball Grid Array，球柵陣列封裝，半導體先進封裝技術，使用焊球連接晶片與基板 |
| **SMT** | Surface Mount Technology，表面黏著技術，將電子零件焊接在PCB表面的製程 |
| **FOWLP** | Fan-Out Wafer Level Packaging，扇出型晶圓級封裝，先進封裝技術之一 |
| **DK/DF** | 介電常數/介電損耗因子，PCB材料的關鍵指標，越低越適合高頻高速傳輸 |
| **主動式ETF** | 由基金經理人主動選股與調整持股的ETF，相較被動式追蹤指數更靈活 |
| **ESG** | Environment, Social, Governance，環境、社會、公司治理，企業永續發展指標 |
| **GDP** | Gross Domestic Product，國內生產毛額，衡量國家經濟活動的總量指標 |
