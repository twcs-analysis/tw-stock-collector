## 產業分析與投資建議

### 一、2026年六大科技趨勢

#### 趨勢一：半導體先進製程（鐵砂級趨勢）

**核心數據**：
- 3奈米製程成長率：2023年+68%、2024年+64%、2025年+54%、2026年預估+43%
- 連續四年維持40%以上高成長
- AI強勁需求推動GPU導入3奈米
- 手機推陳出新導入2奈米

**關鍵事件**：
- 台積電（2330）已通知供應鏈：**2026年至2029年連續漲價四年**
- 漲幅約3%至18%，採逐步調漲方式
- 2奈米產能被客戶搶下極單，供不應求

**受惠族群**：

| 族群 | 受惠邏輯 | 代表公司 |
|------|----------|----------|
| 台積電 | 先進製程漲價直接受惠 | 台積電（2330） |
| 半導體設備 | 跟隨台積電擴廠漲價 | 設備供應鏈 |
| 半導體材料 | 通口漲價+2奈米良率提升過程中成本墊高 | 材料供應鏈 |

#### 趨勢二：AI伺服器（鐵砂級趨勢）

**核心數據**：
- 一般AI伺服器2026年預估出貨450萬台，年增28%
- **高端AI伺服器（GB200/GB300）**：
  - 2025年約2.7萬至3萬櫃
  - 本土法人估2026年達6萬櫃（成長一倍）
  - 外資更樂觀，估7.5萬櫃（成長1.5倍）
- 雲端大廠與AI新創持續投入數千億美元採購

**受惠族群**：

| 族群 | 代表公司 | 備註 |
|------|----------|------|
| 系統廠 | 鴻海、廣達、緯創 | GB200/GB300組裝 |
| 散熱 | 散熱供應鏈 | AI伺服器散熱需求大增 |
| 主機板/基礎 | 華碩 | 伺服器主機板 |
| 連接器 | 連接器廠商 | 高速傳輸需求 |

#### 趨勢三：邊緣AI（Edge AI）

**核心數據**：
- 邊緣AI未來五年平均每年成長28%
- 硬體滲透率已達約20%，進入爆發期
- 應用領域：製造業、醫療業、零售業

**關鍵優勢**：
- 中小型AI模型已成熟
- 可提供高效率、低延遲的AI應用場景
- 滲透率突破20%後將出現規模經濟

**受惠族群**：

| 族群 | 說明 |
|------|------|
| 工業電腦 | 研華、樺漢等邊緣AI硬體廠 |
| 高效能IC設計 | 做HPC晶片的IC設計公司 |

#### 趨勢四：AI智慧眼鏡

**核心數據**：
- 2025年預估出貨520萬副，年增92%
- 2026年預估出貨950萬副，年增82%
- 連續兩年近乎翻倍成長

**關鍵技術突破**：
1. 低功耗晶片可裝入眼鏡
2. 感測器與鏡頭模組成本下降，消費者買得起

**顛覆性觀點**：
- AI應用落地，眼鏡可能比手機、比電腦更早
- 生成式AI隨時可用，不需要APP
- 眼鏡裝不了太多APP，反而推動AI語音交互

**受惠族群**：

| 族群 | 說明 |
|------|------|
| 晶片 | AR/VR專用低功耗晶片 |
| 鏡頭/感測器 | 微型鏡頭模組、感測器 |
| 系統廠商 | AI眼鏡組裝與設計 |
| 軟體開發商 | 「殺手級應用」待出現 |

#### 趨勢五：無人機

**核心數據**：
- 2026年全球市場規模達250億美元
- 台灣國防部計畫明後年採購近5萬架有人/無人機
- 供應鏈除本土市場，美國與波蘭也在向台灣採購

**受惠邏輯**：做晶片比做組裝受惠更大，因為晶片可外銷全球供應鏈

**受惠族群**：

| 族群 | 說明 | 代表公司 |
|------|------|----------|
| 組裝 | 無人機整機組裝 | 雷虎、中光電、長榮航太 |
| 飛行控制晶片 | 核心零組件，可外銷 | IC設計公司 |
| 通訊晶片 | 無人機通訊必備 | 通訊IC設計 |
| 衛星定位晶片 | 避免碰撞，精準飛行 | 衛星定位IC |
| 軟體 | 飛行控制與地面控制軟體 | 軟體開發商 |

#### 趨勢六：低軌衛星

**核心數據**：
- 全球低軌衛星數量已近1.2萬顆
- 用戶數已突破1,000萬
- 基期低，成長幅度大

**關鍵驅動力**：
- 3GPP已將非地面網路納入5G/6G標準
- 未來通訊標準將整合地面+海面+太空一體化
- 地緣政治緊張推升國防應用價值
- 深山、地下室、外島不再擔心無訊號

**受惠族群**：地面衛星零組件、訊號接收裝置廠商

**其他待展開趨勢**（自彩老師將另闢專集介紹）：
- 人形機器人
- 量子運算
- 自駕車
- 軟體

### 二、華爾街投行2026年展望

#### 高盛（Goldman Sachs）：相對樂觀

| 項目 | 預估值 | 備註 |
|------|--------|------|
| 全球經濟成長率 | 2.8% | 算高 |
| 美國經濟成長 | 高於美國自己政府預估 | 樂觀 |
| 中國經濟成長 | 4.8% | - |
| 歐元區經濟成長 | 1.3% | 持平 |
| 全球股市報酬 | 約15% | 與幾家投行差不多 |
| 存眷就價格（EPS驅動） | 約13% | - |

**重點觀察**：
- 高盛認為2026年應**回歸企業基本面**，不再靠估值擴張
- 2025年靠本益比拉升（做夢行情），2026年須看實際獲利
- **新興市場**：2025年MSCI新興市場漲38%，2026年雖稍低但仍優於標普
- **黃金**：基本面還是往上，但漲幅空間變小（2025年已漲70%）
- **日本**：看好，新苗經濟學（石破茂政府）支撐
- **特別點名個股**：鴻海（在全球國際級報告中被直接點名，非常罕見）
- 投資建議：大型股不要再追，分散到中小型股；AI供應鏈持續看好

#### 小摩（J.P. Morgan）：相對保守

| 項目 | 預估值 | 備註 |
|------|--------|------|
| 全球經濟成長率 | 較高盛低 | 偏保守 |
| 美國通膨 | 約2.7% | 下不來 |
| 衰退機率 | 35% | 算高，不太安定 |
| 企業獲利成長 | 13-15% | 與高盛一致 |
| 標普500報酬空間 | 約8-15% | 比2025年低 |

**重點觀察**：
- 雖然偏保守，但**企業獲利仍強**（EPS年增12-13%）
- 歐洲有13%機會，互升3%約12%漲幅
- **看好日本**：「新苗經濟學」（石破茂版安倍經濟學）
- **韓國**：2025年全球第一名（漲70.7%），2026年仍有機會，且不只科技股，軍工股也漲100%以上
- **拉美地區**：2026年有5個國家選舉，尤其巴西10月總統大選
- **黃金預估**：比高盛再高一點
- 看弱美元，歐元看多

#### 巴克萊（Barclays）：英國觀點

| 項目 | 預估值 | 備註 |
|------|--------|------|
| 全球經濟增長 | 3%+ | 算高 |
| 美股預估 | 偏低標 | 保守 |
| 歐洲 | 相對看好 | 莫里大概成長 |

**重點觀察**：
- AI仍是重點，但美國大型科技股以外的機會更大
- 建議投資人選英國、歐洲與部分新興市場
- **減少現金持有**：趕快進市場，不要再抱現金
- 看好美元走弱
- 美國降息預估兩次

#### 野村證券（Nomura）：亞洲觀點

| 項目 | 預估值 | 備註 |
|------|--------|------|
| 美國降息 | 兩次 | 與巴克萊一致 |
| 日本升息 | 不會或頂多一次 | 與市場共識不同 |
| 台股 | 特別看好 | 尤其電子股 |

**重點觀察**：
- 多看好美、台、日、中
- **台股電子股與高位表現**受特別肯定
- 日本升息看法偏鴿（多數市場預期連續升息）

### 四、2025年基金績效回顧

#### 台股基金
- 近200檔中，僅5檔負報酬
- 扣除ETF後幾乎全數正報酬
- **表現最差的特徵**：帶有「股息」、「高息」、「無息」關鍵字的ETF，屬於1貼不來
- 只有兩檔沒有帶號的（非槓桿），都是1貼型

#### 海外ETF績效
- **最佳主題**：貴金屬/黃金基金，包括一檔報酬率達158.7%
- **第二名**：韓國股市基金
- **拉美基金**：因去年基期低，表現也很好
- 如果要買ETF：避開台股ETF反而更好，投資國外的ETF金效都很好

## 名詞解釋

| 名詞 | 說明 |
|------|------|
| **CES** | Consumer Electronics Show，消費性電子展，每年1月在美國拉斯維加斯舉辦的全球最大消費電子展 |
| **MIC** | 資策會產業情報研究所（Market Intelligence & Consulting Institute），台灣重要的科技產業研究機構 |
| **3奈米/2奈米** | 半導體先進製程節點，數字越小代表電晶體越小、效能越高、功耗越低 |
| **GB200/GB300** | NVIDIA高端AI伺服器機櫃產品，整合GPU與網路設備的超級運算單元 |
| **邊緣AI（Edge AI）** | 在終端設備而非雲端進行AI運算，特點為低延遲、高隱私、即時反應 |
| **3GPP** | 第三代合作夥伴計畫，制定全球通訊標準（3G/4G/5G/6G）的國際組織 |
| **低軌衛星** | Low Earth Orbit Satellite，軌道高度約160-2,000公里的衛星，延遲低、覆蓋廣 |
| **新苗經濟學** | 日本首相石破茂推動的經濟政策，類比安倍經濟學（Abenomics） |
| **金銅比** | 黃金價格除以銅價的比率，用於衡量市場風險偏好與銅價補漲空間 |
| **鐵砂級趨勢** | 自彩老師用語，形容像鐵砂般堅固不可逆轉的強勁產業趨勢 |
| **投等債** | 投資等級債券（Investment Grade Bond），信用評等BBB以上的債券 |
| **高收債** | 高收益債券（High Yield Bond），信用評等BB以下但殖利率較高的債券 |
