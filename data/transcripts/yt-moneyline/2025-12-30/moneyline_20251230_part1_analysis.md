## 產業分析與投資建議

### 個股推薦一：結創科技（剛掛牌新股）

**推薦來賓**: 會是老師

**公司基本面**:
- 剛轉上市櫃，掛牌時間不久
- 屬於半導體設備服務類型公司
- 股本僅約2億元
- 毛利率達48%
- 第一大股東持股23%

**核心競爭優勢**:
1. **全球測試設備官方技術委外合作**: 與半導體測試四大天王（愛德萬、市德科技、安捷倫科技、互力所法）均有官方技術委外合作
2. **獨家延壽服務商機**: 原廠設備保固期後的維護、裝機、校驗服務，原廠授權線路圖與技術，形成獨家商機
3. **現金流穩定**: 愛德萬全球裝機量三萬套，陸續到期需要延壽維護
4. **AI智慧監測平台**: 將感測器與AI演算法整合，監測氣體、震動、影像，預測故障避免無預警停機（類似上聲概念，當年從200元漲到1,000元）
5. **Kampus探針座鎖定系統**: 解決AI晶片測試時間拉長、氣壓波動導致探針頭位移問題，已獲客戶指定採用，明年有望成為標配

**操作建議**:
- 目標價: 尚在觀察（小型股需時間驗證）
- 進場策略: 五日線附近可慢慢布局，分批進場
- 注意事項: 成交量較小，不宜追高，應分批布局
- 籌碼面: 外資僅小量跟買，投信尚未進場，籌碼非常乾淨

### 個股推薦二：會特（矽光子/化合物半導體轉型股）

**推薦來賓**: 會是老師

**公司基本面**:
- 從LED產業轉型到矽光子/化合物半導體
- 核心技術為光的量測與精密分學
- 擁有自製設備能力（成本較低、改裝速度更快）

**投資亮點**:
1. **華麗轉身**: 脫離LED紅海，切入高階化合物半導體與矽光子市場
2. **與博通合作代工**: 博通只做前段，後段委託會特代工
3. **一條龍服務**: 自製設備+代工，成本優勢明顯
4. **矽光子切入領域**: 貼合機、單點點測機、光圈陣列測試檢測、移除機等
5. **探針卡清潔技術**: 延長探針卡壽命，商機巨大（探針卡買一次、清潔多次）
6. **法說會揭露**: 未來矽光子營收佔比將達50%以上
7. **訴訟案回轉**: 一月可能結案，若回轉可增加EPS約6元

**操作建議**:
- 目前股價尚在底部區域（年線剛打出大底）
- 適合中長期布局
- 進場策略: 等待均線靠近時逢低承接

### 個股推薦三：記憶體模組股（十銓科技暗示）

**推薦來賓**: 會是老師

**投資亮點**:
1. **DRAM大量淘汰**: 淘汰量達股本的5.1倍
2. **現有庫存數字僅為第三季底的數字**: 第四季現貨漲二到三倍，數字還要再成長
3. **模組廠漲勢最強**: 因為看到的價格數字還沒加上第四季
4. **前高壓力184.5元**: 但目前獲利比之前好太多，過前高機率大

**操作建議**:
- 目前在暖升階段，走一段停一段，緩步墊高
- 進場時機: 前高突破後可加碼
- 注意: 量能開始出來但還未全力噴出

## 記憶體漲價深度分析

### 總老師的消費性電子漲價全解析

**推薦來賓**: 總老師

#### PC市場
- **CES展會**（1/6-1/9）即將展出最新AIPC
- Intel推Cove Slot Ciri3（提升AI運算效能、降低能耗）
- AMD推Ryzen AI 400系列（強化AIPC算力）
- **DRAM漲幅驚人**: 7-8月至今不到半年漲了2到2.5倍
- PC品牌商已產生囤貨策略（預期1月再漲，乾脆一次囤足）
- **新品漲幅**: 一般機種漲15%以上，高階機種漲30%
- **消費者觀望**: 漲價已產生延遲採購效應

#### 手機市場
- **中階手機**（中國品牌為主：小米、OPPO、vivo、華為、榮耀）
  - 10月已漲3-8%，明年預計再漲3-8%
  - 記憶體佔成本比重15-20%
- **高階手機**（三星、蘋果）
  - 長期合約議價能力強，漲幅較小（3%以下）
  - 不太可能大幅升級或大幅漲價

#### 遊戲機市場
- Sony PlayStation、微軟Xbox、任天堂Switch
- 規劃明年起未來兩年漲10-15%
- 但上半年關稅已漲過一波，主裝廠自行吸收
- 遊戲機市場成長率從預估9.78%降至5.88%，明年預估衰退4.4%

#### 記憶體漲價能否延續到2027年？
**供給面隱憂**:
1. 三星重新投入生產
2. 中國長江存儲/長鑫存儲大量擴建，明年產能將釋出
3. AI伺服器搶買現貨（只要GPU和記憶體），排擠效應嚴重

**需求面風險**:
- PC/手機漲價已引發消費者觀望
- 光華商場反映延遲採購效應
- 品牌商開始延緩出貨

**供應鏈預估**: 漲幅到明年五六月趨緩，下半年逐漸回穩

## 名詞解釋

| 名詞 | 說明 |
|------|------|
| **CES** | Consumer Electronics Show，消費性電子展，每年1月在美國拉斯維加斯舉辦的全球最大消費電子展 |
| **AIPC** | AI Personal Computer，搭載AI加速晶片的個人電腦，為2025-2026年PC市場升級換代方向 |
| **矽光子** | Silicon Photonics，利用矽基材料製造光學元件的技術，應用於高速光通訊 |
| **CWL** | Continuous Wave Laser，連續波雷射，華新科用於光通訊的關鍵產品 |
| **探針卡** | Probe Card，半導體測試中用於接觸晶圓的精密元件，隨製程進步測試時間拉長 |
| **金銅比** | 黃金價格除以銅價的比率，當此比率在歷史高位時暗示銅價有補漲空間 |
| **囤貨策略** | 品牌商預期漲價持續而提前大量採購備料的行為 |
| **延壽服務** | 設備原廠保固期過後的維護、校驗、零件更換服務 |
