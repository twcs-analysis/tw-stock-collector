## 🌍 市場總體觀察

### 大盤現況與底部判斷

#### 書方老師三大底部確認法

**第一條件：空頭推動波結束**
- 空頭推動波 = 不斷進行ABC修正（A下跌、B反彈、C破底）
- C波跌幅大於A波
- **關鍵**: 守住17,306點（C波主跌段低點不再被跌破）才算空頭推動波結束

**第二條件：底部確立的兩種模式**

1. **三不再高有先折名（技術面）**
   - 「有先」= 看不到的 = 技術面籌碼面先行
   - 帶大量突破頸線（20,023）→ 回測守住 → 底型確立
   - 無量突破不算數，可能變成收斂型或複合底型

2. **水不再升有龍折禮（基本面）**
   - 技術面空頭時，基本面（獲利＝龍）是折禮（底部訊號）
   - 如台積電300~500元都是技術面空頭，但獲利支撐底部

**第三條件：巨量式的長黑可以**
- 所有人該賣的都在一天賣光
- 特徵：融資大減百億以上 + 三個營業日內盤中過高
- **本次台股符合**: 17,306低點出現巨量式長黑，融資大減，一天就過高

### 關稅三種情境分析（關週）

#### 情境一：最樂觀（機率50%）
- 除中國外，各國維持10%基本關稅
- 經濟影響：轉弱但可控
- 去中化持續（美國去中化、中國去美化）
- **股市**: 短中線回檔後較快築底回升
- **降息**: 可能年內1~2次降息

#### 情境二：基準情境（機率最大）
- 談判後各國關稅降至10%~15%，中國可能降至14.5%
- 全球經濟面臨停滯風險
- 經濟二元化更明顯（中國一邊、美國一邊）
- **股市**: 有限幅度的盤整格局，年底不太可能大漲
- **降息**: 近年度不會降息（需防通膨上升）

#### 情境三：最悲觀（機率較小但嚴重）
- 維持4月號對等關稅水準，半導體與醫藥另加額外關稅
- 全球經濟嚴重衰退、停滯性通膨
- **股市**: 進入長期回檔
- **降息**: 不降息（怕通膨）也不升息（怕經濟），進退兩難

### 落底訊號已出現

#### 融資大減（歷史驗證）
- **4月以來融資減幅**: 超過30%（從3,000多億降至2,000億左右）
- **歷史對照**:
  - 2008年金融海嘯：融資大減 → 底部 → 後續上漲
  - 2015年中國股災：融資大減 → 盤底 → 後續上漲
  - 2020年COVID-19（8,523）：融資單日減1,108億 → 底部 → V型反轉
  - 2022年俄烏戰爭：融資大減 → 底部 → 後續上漲
- **本次特徵**: 融資減幅大於指數減幅，代表籌碼有效清洗
- **結論**: 籌碼已乾淨，有利大盤慢慢築底

#### 大戶轉多
- 期貨大戶（前十大交易人）近日以做多為主
- 國安基金已宣示護盤
- 往下壓的力道有限

### 五、庫藏股分析（子東）

#### 庫藏股三大觀察重點
1. **買回目的**: 維護股東權益（48家） vs 轉讓給員工（81家）
2. **買回比例與張數**: 法規限制每日不超過規定比例的1/3
3. **買回區間價格**: 判斷公司是否有誠意的關鍵

#### 有誠意的判斷標準
- 若股價100元，公司設定買回區間70~80元 → 無誠意（買不到）
- 若股價100元，公司設定買回區間100~150元 → 有誠意（隨時可買）
- 法規：上限可設為前30日均價的150%，下限為當日價格的70%

#### 實證案例
- **立特**: 4月14日開始執行，1,000張全部買回，期間股價漲16%
- **圍身**: 4月7日低點殺到64元，公告80~120元買回 → 非常有誠意

## 📈 技術面分析

### 底部型態教學（書方老師 - 歷史案例）

#### 案例一：1990年石油危機（指數285點）
- **特徵**: 有時間不確定性（不知戰爭何時結束）
- **歐動量**: 量縮到極致 → 開始放量向上突破
- **突破頸線**: 帶量紅棒突破 → 回測頸線不破 → 溫和上漲
- **主升段**: 等均線全部向上後才啟動
- **教訓**: 有不確定性的底部不會一口氣漲上去，需要時間

#### 案例二：2020年COVID-19（8,523點）
- **特徵**: 有時間不確定性 + 國安基金進場 + 十年線支撐
- **巨量長黑**: 當日融資減1,108億，所有人排隊賣股票
- **三個營業日過高**: 直接放量往上帶，V型反轉
- **原因**: 後來有疫苗（不確定性消除較快）

#### 案例三：2022年俄烏戰爭（13,950~12,690點）
- **國安基金進場**: 進場點13,950，但融資僅減21億（不如COVID）
- **有破底**: 跌至12,690出現融資大減661億 + KD低檔背離
- **突破頸線**: 帶大量突破 → 底型確立
- **國安基金定律**: 進場點就算被跌破，也一定是左肩（必過）

#### 本次台股底部特徵
- **符合**: 巨量式長黑 + 三個營業日過高 + 融資大減
- **不符合**: 未到十年線（與8,523不同）
- **符合**: 融資持續減少 + 國安基金進場
- **預判圖形**: 介於COVID-19（V轉）與2022年俄烏（有拉回打底）之間
- **時間**: 因90天關稅不確定性，不會V轉，可能需1~3個月區間震盪

### 投信動向分析（書方老師）
- 投信近期從被動式操作轉為增加主動式操作
- 上市買超多為高股息ETF被動買盤
- **上櫃買超**: 更多主動式操作個股出現 → 信心恢復訊號
- 業內主力 + 投信主動買進的個股開始轉強

### 均線與扣抵分析
- 均線目前扣底區，向上翻揚需時間
- 台股變盤轉折可能在5~6月（主升段起點）
- 出升段有機會現在就開始，但漲幅小於主升段

### 基本面時間軸
- **5月5日**: 公布第一季財報
- **5月10日前**: 公布4月營收
- **注意**: 4月份營收因關稅影響會有斷層（4月2日起出貨停滯），不要管4月營收
- **5月營收會好**: 因為又可以出貨了
- **財報利多個股要帶頭衝**: 才代表市場信心恢復

## 📈 黃金市場分析（七招）

### 價格動態
- 昨日創3,500美元歷史新高
- 今日盤中低點3,291美元（24小時內高低差約200美元）
- 波動劇烈

### 西方投資者回歸
- 4月份西方投資者大量買入黃金
- 買入量 = 過去三年賣出量的一半（在一個月內買回）
- 有人看到金價上看5,000美元

### 川普的黃金法則推文
- 川普推文：「談判的黃金法則：誰有黃金誰制定規則」
- **七招解讀**: 川普說的「黃金」指的是權力與財富的代稱，不一定是黃金商品本身
- 但也可理解為：掌握黃金儲備 = 更有信心（美元不信任時期）

### 技術面分析
- **歷史規律**: 黃金每次長上影線後都會拉回修正
  - 2,430 → 拉回、2,449 → 拉回、2,483 → 拉回、2,721 → 拉回、2,940 → 拉回、3,194 → 拉回
- **本次**: 3,500長上影線 → 預期拉回
- **下檔支撐**: 3,200整數關卡、前波低點3,166
- **結論**: 長上影線後拉回正常，多頭趨勢尚未改變

### 拉回原因
- 美元、美債反彈 → 不需要黃金避險 → 資金流出
- 短線漲太多（年初至今已漲超過30%），適度回檔正常
- 近期波動幅度越來越大，挖鋒式走勢

### 投資建議
- **短線價差**: 不建議（黃金純責買賣價差高，需漲5%以上才有獲利機會）
- **衍生性商品（ETF）**: 有技術面操作能力者可考慮
- **分批投資**: 多頭趨勢未結束，拉回到3,300附近可分批佈局
- **黃金存摺**: 長期投資可慢慢投入

### 白銀分析
- **金銀比**: 歷史上70~100之間，目前仍在高位
- **白銀表現**: 近一年從24元漲到35元（不到50%），遠輸黃金
- **歷史高點**: 白銀歷史高點約50元，目前才30多元
- **結論**: 不容易補漲，黃金不漲白銀也難漲；流通性遠不如黃金；建議投資黃金

## 📋 投資策略總結

### 底部判斷結論
1. 台股已符合多項底部確認訊號（巨量長黑、融資大減、三日過高、國安基金進場）
2. 但因90天關稅不確定性，不會V型反轉，需時間震盪打底
3. 預判5~6月可能出現主升段起點
4. 出升段漲幅有限，主升段漲幅更大

### 操作重點
1. **財報期**: 5月上中旬是關鍵（Q1財報 + 4月營收），利多個股要帶頭衝
2. **4月營收斷層**: 不要因4月營收不好就恐慌，5月會恢復
3. **庫藏股**: 選有誠意（買回區間貼近現價）+ 產業面受委屈的標的
4. **黃金**: 分批佈局，不追高，等拉回到3,200~3,300附近

### 風險提示
- 關稅情境二（基準情境）最可能發生，股市為有限幅度盤整
- 關稅情境三若發生，將進入長期回檔
- 川普政策朝令夕改，需隨時關注最新動態

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **空頭推動波** | 由ABC三波構成的下跌走勢，C波跌幅大於A波 |
| **巨量式長黑** | 單日出現巨大成交量伴隨大跌，代表恐慌性賣壓一次宣洩完畢 |
| **歐動量** | 量縮到極致後開始放量，通常出現在不確定性高的底部 |
| **十年線** | 120月均線，長期多空分界線，觸及常為重要底部 |
| **國安基金** | 國家金融安定基金，政府在股市異常波動時進場護盤的資金 |
| **融資餘額** | 投資人向券商借錢買股票的總金額，大幅減少代表散戶出場 |
| **庫藏股** | 公司買回自家已發行在外的股票，用於維護股東權益或轉讓員工 |
| **S&P Buyback指數** | 標普回購指數，追蹤S&P 500中執行庫藏股或減資的100家公司 |
| **金銀比** | 黃金與白銀價格的比值，歷史區間約70~100 |
| **長上影線** | K線上影線較長，代表盤中衝高後被賣壓打回，短線見高點訊號 |
| **SCFI** | 上海出口集裝箱運價指數 |
| **停滯性通膨** | 經濟停滯 + 物價上漲同時發生的困境 |
