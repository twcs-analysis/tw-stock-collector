## 🌍 市場總體觀察

### 中美關稅戰不會打太久的五大證據（關週分析）

#### 一、美國國內反對聲浪高漲
- 美國「50501運動」：50個州、50場遊行、一天之內
- 三個週末已有500萬人上街反對川普經濟政策與關稅政策
- **川普支持率創新低**：經濟政策滿意度僅43%，關稅支持度僅35%

#### 二、大國反制效果顯著
- 歐盟（原本盟友）、中國等均採取反制態度
- 目前沒有任何一國跟美國談成協議
- 中國底氣硬，完全不打電話給美國

#### 三、美國自身弱點明顯
- 通膨壓力上升
- 公債殖利率維持高位
- 美元弱勢持續

#### 四、中國對美外銷品 = 美國生活必需品（難以替代）

| 品項 | 說明 |
|------|------|
| 電腦、筆電 | 中國主要供應 |
| 家用家電 | 各類家用家電 |
| 電動車電池與零件 | 中國為全球最大電動車市場 |
| 玩具、塑膠製品 | 中國為全球最大玩具生產國之一 |
| 服裝、紡織品 | 各類服飾 |
| 機械設備、電子零件 | 工業機械、家用電器 |

- **關鍵**: 美國暫時找不到同等規模的替代供應國

#### 五、美國對中外銷品 = 中國可替代（非必需）

| 品項 | 替代來源 |
|------|----------|
| 農產品（大豆、玉米） | 巴西正積極搶占中國市場 |
| 能源（石油、天然氣） | 俄羅斯管線直接供應 |
| 航空設備（波音） | 已被禁止進入中國 |
| 高科技/半導體 | 早就被禁止出口 |
| 服務出口（教育、專利） | 可尋求替代 |

- **結論**: 中國不跟美國買也能從其他國家找到替代品

### 避險商品轉折觀察（關週）

#### 三大避險商品 + VIX關鍵價位

| 商品 | 關鍵價位 | 轉折意義 |
|------|----------|----------|
| **日圓** | 突破144附近前低 | 日圓走弱 = 避險需求降低 |
| **黃金** | 跌破3,245美元 | 黃金轉弱 = 恐慌消退 |

- **判讀方法**: 三大避險商品同步到達轉弱關鍵價 + VIX跌破30 → 關稅緊張局勢真正緩和
- **目前VIX**: 昨日S&P 500漲12%，VIX從60以上回到約30附近
- **最關鍵催化劑**: 中美正式針對關稅進行談判 → 只要有動作（不管談成什麼）都是好的循環

## 💼 產業分析與投資建議

### 跌過頭的成長股已具價值（關週推薦）

#### 核心觀點
- AI伺服器、端側AI、矽光子、航空航運等過去主流族群，股價已大幅修正
- 用本益比、股息殖利率、配息角度看，估值已變便宜
- 唯一好處：現在都變便宜了

#### 推薦標的

**緯穎** - AI伺服器指標
- 今年預估EPS約160.7元
- 本益比約12~13倍
- 之前HPC（高效能運算）價格3,000多元，現在不到2,000元

**聯發科（2454）** - AI手機/AIPC
- 今年預估EPS約137元
- 本益比約12倍
- **額外利多**: 高通晶片受關稅影響，聯發科成為社會替代首選
- 4月份Q1財報亮眼，下半年還有天璣9.5

**同欣電** - AI應用受惠
- 今年預估EPS約40元
- 本益比約12倍
- 各項AI應用的受惠指標

**波路威** - 矽光子
- 目前NVIDIA光纖連接器唯一供應商
- 股價已來到年線附近，相對低檔區
- 今年可能無獲利數字，但2026年開始放量，2027年放量更多

**聯亞** - 光通訊中繼站
- 相對低檔位置
- 跌了很多，風險偏低，適合長期佈局

## 📈 美元、美債、匯率分析（七招）

### 聯準會獨立性議題

#### 川普 vs 鮑爾
- 川普心裡想換掉鮑爾（鮑爾不聽話，做法與川普方向相反）
- 研究後發現沒有合法理由 → 改口「只是希望降息」
- **市場影響**: 聯準會獨立性若受損，對金融市場衝擊巨大（比關稅更嚴重）

#### 川普要求降息的邏輯
- CPI年增率已下降、雞蛋價格也回落 → 通膨壓力正在緩解
- 暗示關稅不會維持高標準（要談判下調）
- **真正擔心**: 經濟衰退已成定局
  - 零售數據不佳
  - 亞特蘭大聯準銀行GDPNow模型預估Q1 GDP年率萎縮2.2%
- **結論**: 怕小衰退變大衰退，趕快降息救經濟

### 美元指數分析

#### 走勢現況
- 跌至97.921後稍微反彈，但屬弱勢反彈
- 空方高點越來越低（100.17 → 持續下降）
- 第二季結束前基本偏弱

#### 三大壓力因素
1. **川普信任度不足**: 朝令夕改，市場對美元沒信心 → 威脅美元霸權（未來10~20年議題）
2. **降息預期擴大**: 利率期貨反映今年可能降3~4碼，甚至更多
   - 歐元區也在降息，但歐元反而走強（資金不信任美元所致）
3. **經濟需好轉**: 第二季GDP若未轉好，美元持續偏弱

#### 關鍵價位
- **100.23~100.3**: 若美元指數無法站上，空頭延續
- **歐元**: 有機會在未來幾年成為更強的主要儲備貨幣

### 台幣換美元策略

- 目前美元確實便宜（台幣約32.5附近）
- **分批操作**: 往下到31.9左右可加碼
- **長期可行**: 拉長時間看是合理的投資
- **短期價差**: 很困難（不知何時見底）
- **注意**: 台幣後續若有資金外流可能，美元可能出現反彈

### 美債分析（美國10年期公債殖利率）

#### 走勢
- 4月7日對等關稅後，殖利率攀升（債券價格下跌）
- 日本4月以來賣出外國債券200億美元（多為美債）
- 國際機構警告：背後恐有未知力量持續拋售美債

#### 美債已從避險資產變成風險商品
- 4月3~4日市場恐慌時，美債ETF價格不降反升（異常現象）
- 看起來便宜，但實際買盤越來越少
- 區間：4.5%~4.6%盤整

#### 操作建議
- **撿便宜**: 相對可以，但可能更便宜
- **技術面確認**: 降到4.25%以下才算消化完壓力
- **最大利多情境**: 經濟爛到聯準會必須無限QE（大幅降息+量化寬鬆）→ 美債快速走強
- **機率**: 不高，但告訴投資人什麼情況美債會快速回升

## 📈 技術面分析

### 大盤總結（書方老師最終建議）

#### 操作策略
- **偏多操作**: KD指標不交叉向下就持續做多
- **一段一段操作**: 不要急，慢工出細活
- **參考KD指標**: 偏多時日KD不要交叉向下，一旦交叉向下就短線賣出

#### 反彈目標與量能要求
- **目標**: 帶量挑戰並突破20,023頸線
- **量能要求**: 至少4,000億元以上（今日約2,700億元不夠）
- **今日不是過頸線**: 所以量不足可以接受
- **過頸線當天**: 一定要大量湧動

#### 底型確立最終條件
- 帶量突破20,023 → 守住20,023 → 底型確立
- 確立後謹慎投入

#### 台股四大族群分類

| 類型 | 代表族群 | 操作方式 |
|------|----------|----------|
| **當沖短線** | 支付概念股、安控概念股 | 南極型，當沖為主 |
| **突破觀察** | AI相關族群 | 看能否帶量突破頸線 |
| **利多反應** | 面板級扇出型封裝、CPO | 台積電技術論壇帶動 |
| **先進製程** | 半導體先進製程設備 | 北極型，跟隨技術論壇 |

#### 台積電底型確立條件
- 外資回補 + 突破903元 → 台積電底型確立

## 📋 投資策略總結

### 關稅戰展望
1. 中美關稅戰不會打太久（美國國內壓力 + 中國替代品充足）
2. 追蹤三大避險商品 + VIX是否同步轉弱 → 確認緊張緩和
3. 中美正式坐下來談判 = 最大正面催化劑

### 美元美債策略
1. 美元短期偏弱，分批換匯長期可行但不急
2. 美債為風險商品，等殖利率降至4.25%以下再積極佈局
3. 降息預期擴大對美元不利，但對股市有利

### 台股操作
1. 偏多操作，KD不交叉向下就持續做多
2. 20,023頸線為關鍵：帶量突破 + 守住 = 底型確立
3. 成長股估值便宜：緯穎、聯發科、同欣電本益比約12倍
4. 台積電：等外資回補 + 突破903元

### 風險提示
- 川普信任度問題短期內不會解決，隨時可能反覆
- 經濟衰退可能已成定局（Q1 GDP萎縮預估）
- 美債從避險資產變風險商品，需持續追蹤
- 90天關稅暫緩到期後的結果仍是最大不確定性

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **VIX恐慌指數** | 芝加哥選擇權交易所波動率指數，反映市場對未來30天波動的預期。20以下為樂觀，30以上為恐慌 |
| **50501運動** | 美國反川普示威活動：50州、50場遊行、1天之內完成 |
| **美元指數（DXY）** | 衡量美元對一籃子六種主要貨幣的強弱指標 |
| **10年期美債殖利率** | 美國10年期公債殖利率，全球利率基準，影響房貸、企業融資成本 |
| **QE（量化寬鬆）** | Quantitative Easing，央行大量購買公債等資產向市場注入流動性 |
| **GDPNow** | 亞特蘭大聯準銀行的即時GDP預測模型，根據最新經濟數據估算當季GDP成長率 |
| **對等關稅** | 川普政府依各國對美國商品課徵的關稅水準，對等課徵相同稅率的政策 |
| **瑞士法郎** | 傳統避險貨幣，因瑞士中立國地位，市場恐慌時資金流入 |
| **日圓避險** | 日圓在市場恐慌時通常走強，因資金去槓桿回流日本 |
| **停滯性通膨** | Stagflation，經濟停滯與通貨膨脹同時發生的困難處境 |
| **美元霸權** | 美元作為全球主要儲備貨幣與國際貿易結算貨幣的主導地位 |
| **利率期貨** | 反映市場對未來利率變化預期的金融期貨商品 |
