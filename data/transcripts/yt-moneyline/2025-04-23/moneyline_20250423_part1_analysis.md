#### 來賓觀點

### 二、台積電供應鏈（子東推薦優於台積電本身）

1. **股本小**: 拉抬幅度與空間更大，適合賺價差
2. **關稅影響小**: 台積電可能不轉嫁成本給供應鏈，供應鏈反而受惠
3. **2奈米世代利多**: 台積電進入2奈米，蘋果下單，設備股等待更久、反彈力道更足

## 📈 技術面分析

### 大盤技術面（書方老師）
- **KD指標**: 昨日回測50附近後今日向上，屬「強勢性整理」
- **強勢性整理定義**: KD在50附近向上，基本上會挑戰前高
- **關鍵位置**: 頸線20,023（第一隻腳高點）
- **底型確認條件**: 帶量突破20,023 → 拉回守住20,023 → 底型確立
- **節奏**: 慢工出細活，突破頸線後不可能一氣呵成挑戰更高壓力

### 量能分析
- 今日量能不夠（約2,700億），反彈初期可接受
- 未來挑戰20,023突破時必須帶量
- 至少需要4,000億以上的量能才能確認突破有效

### 個股技術面要點
| 型態 | 條件 | 適用 |
|------|------|------|
| **W底** | 帶量突破頸線 + 回測守住 | 兩隻腳的底型 |
| **暗字底（L型底）** | 持續放量，量滾量上升 | 無明顯第二隻腳 |
| **真突破** | 第一天帶大量突破可追 | 量能充足 |
| **假突破風險** | 無量突破，需等拉回守住再買 | 量能不足 |

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **KD指標** | 隨機指標（Stochastic Oscillator），50為多空分界，用於判斷超買超賣 |
| **頸線** | 技術分析中底部型態的關鍵突破水平線，突破代表趨勢翻轉 |
| **W底** | 雙重底型態，股價形成兩個相近低點後反彈突破頸線 |
| **暗字底（L型底）** | 股價急跌後橫盤整理，需持續放量（量滾量）才能推升 |
| **面板級扇出型封裝** | Panel-level Fan-out Packaging，先進封裝技術，台積電結合CPO的一體化方案 |
| **CPO** | Co-Packaged Optics，共同封裝光學，矽光子技術在資料傳輸的應用 |
| **NRE** | Non-Recurring Engineering，客製化委託設計的一次性工程費用 |
| **HBM4** | High Bandwidth Memory 第4代，新一代高頻寬記憶體技術 |
| **2奈米世代** | 台積電次世代先進製程節點 |
| **本益比（P/E）** | 股價除以每股盈餘，衡量股票估值高低的指標 |
| **61.8%黃金分割** | 費波那契回撤比率，技術分析中重要的支撐/壓力位 |
