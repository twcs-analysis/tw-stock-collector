### 二、記憶體族群 - DDR4 漲價超級循環

#### 核心邏輯
- 全球大廠（三星、海力士、美光）全力投入 HBM 及 DDR5 產能
- DDR4 產能快速縮減，供給短缺推升報價
- 中國大陸廠商不僅全面停止報價，甚至「一天一報價，坐地起價」
- DDR4 報價維持高檔或持續上漲的時間可能延續至 2026 年中

#### 重點個股

| 股票代號 | 公司名稱 | 定位 | 操作建議 |
|---------|---------|------|---------|
| 2408 | 南亞科 | 一線首選（有產能） | 分兩批買進，拉回 5 日線接第二批。今日漲停買不到 |
| 2344 | 華邦電 | 一線首選（有產能） | 處置股，不易買進。開高爆量可稍等 |
| 3260 | 威剛 | 搭配操作 | 有庫存優勢，但後期注意庫存風險 |
| 2379 | 群聯 | 搭配操作 | 產品偏 NAND Flash，非 DRAM 主力 |

| - | 力積電 | 補漲 | 未創新高，補漲性質 |

#### DDR4 循環展望
- HBM 產能已被預訂至 2026 年底
- DDR4 新產能（華邦電等）預期到 2027 年才能大量開出
- 類比 2017-2018 年被動元件因日廠退出中低階市場，國巨從 300 元漲至 1,300 元的劇本
- **技術面操作**: 南亞科以 20 日均線為買點，拉回接近均線不要害怕

### 大盤技術分析
- **多頭排列**: 5、10、20、60、120 日均線全部向上，標準多頭排列

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| DDR4 | 第四代雙倍資料率同步動態隨機存取記憶體，目前消費性電子主流規格 |
| DDR5 | 第五代記憶體，效能更高，AI 伺服器與新世代 PC 主力 |
| HBM (High Bandwidth Memory) | 高頻寬記憶體，AI 加速器（如 GPU）必備，由三星、海力士、美光供應 |
| GTC DC | NVIDIA GPU Technology Conference DC，輝達在華盛頓舉辦的技術大會 |
| 處置股 | 因股價異常波動被證交所列為注意股後進一步實施分盤交易的股票 |
| MLCC | 積層陶瓷電容器（Multi-Layer Ceramic Capacitor），被動元件主力產品 |
| 多頭排列 | 短天期均線在上、長天期均線在下的排列方式，代表趨勢向上 |
| 保證金餘額 | 投資人向券商融資買股的金額總和，反映市場資金與槓桿水準 |
| QT (Quantitative Tightening) | 量化緊縮，聯準會縮減資產負債表以收回市場資金 |
| OTC | 櫃買中心交易市場，以中小型股為主 |
