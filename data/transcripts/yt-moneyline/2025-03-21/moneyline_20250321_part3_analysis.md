## 🌍 市場總體觀察

### 全球股市結構性變化

#### 「買便宜」成為全球投資顯學
- 2025年以來台股大盤下跌3.59%，但個股漲幅前20名翻倍以上
- 漲最多的股票特色：過去陌生、股價長期低迷、今年突然竄出頭
- 全球趨勢：過去漲多的（美國科技）轉弱，過去跌深的反而轉強

#### 全球股市排名變化
- 去年表現好的市場（台灣、美國科技）→ 今年轉弱
- 去年表現差的市場 → 今年反彈
- 科技股在全球範圍持續弱勢

#### NASDAQ相對強弱指標
- NASDAQ除以綜合指數 → 持續往下跌
- 無法回到年線上方
- 代表科技股持續弱勢

### 全球資金流向

#### 區域市場表現
| 市場 | 今年表現 | 特色 |
|------|---------|------|
| 德國 | 大漲 | 軟體公司（AI應用）、軍工股領漲 |
| 越南 | 今年漲幅可觀 | 年初低點反彈，國內ETF表現更優 |
| 黃金 | 持續創高 | 從2018-19年至今近翻倍，不確定性越高越受惠 |
| 香港/中國 | 有反彈 | 阿里巴巴等AI概念受惠，可能用AI降低成本 |

#### 黃金觀點轉變
- 過去認為黃金「沒有殖利」不值得持有
- 現在認知：黃金多頭已走一千多年（人類歷史即多頭）
- 川普任期還有好幾年 → 不確定性持續 → 黃金有支撐
- 關稅塵埃落定後可能短暫震盪，但趨勢未結束

#### 台灣黃金概念股
- 交融、金鼎等概念股尚未有明顯營收成長連動
- 若出現第一根長紅可以追進
- 目前仍在等待催化劑

## 💼 產業分析與投資建議

### 一、高殖利率投資策略 -- 明漢

#### 核心邏輯
- 盤勢不好時，高殖利率族群相對強勢（歷史經驗）
- 每年農曆年後開始布局 → 董事會公布配息 → 股東會行情 → 除權息（到夏天）
- 特色：賺不了大錢，但勝率很高；用大資金多檔布局，長跌互抵後資產仍向上

#### 0056 vs 0050 相對強弱
- 0056（高股息ETF）除以0050（市值型ETF）→ 過去2-3年弱勢，今年1月後轉強
- 代表資金正在從科技股往高殖利率移動
- 趨勢持續到美國科技股大漲才會休息

#### 殖利率陷阱辨識
- **警戒線**: 殖利率超過10%要特別當心（多為一次性）
- **辨識方法**: 查看去年四季獲利是否穩定（如2-2-2-2），若某季暴增（如2-2-8-2）代表一次性
- **真殖利率 vs 假殖利率**: 賣廠、保險金等一次性收入造成的高殖利率不會持續
- **假殖利率特色**: 除權息前會轉強，但填息力道非常弱

#### 進可攻退可守的高殖利率個股 -- 明漢精選

### 全球趨勢反轉信號
- 科技股相對弱勢指標持續下行
- 高殖利率族群相對轉強（0056/0050比值翻揚）
- 原物料族群逆勢走強（鋼鐵、銅等）
- 非電族群只要便宜就有資金進駐

- 華邦電未測季線即止穩 → 籌碼已沉澱
- 整體記憶體族群與美光同步性提高

- 從2018-19年至今已近翻倍
- 月線支撐完整
- 川普任期結束前不確定性持續 → 趨勢未變

## 📋 投資策略總結

### 短線策略
1. **下週關稅壓力加大**: 越接近4月2日，川普放話越重
2. **電子弱勢 → 非電轉強**: 高殖利率、原物料、軍工為避風港
3. **記憶體**: 南亞科、華邦電洗盤完畢可觀察

### 中線策略（到夏天前）
1. **高殖利率三寶**: 統一（鉛酸電池）、有會（光學膜）、利揚（聲學）
2. **營建股輪動**: 至除權息前持續有行情
3. **資產配置**: 關稅風暴大 → 高殖利率配置多一些；關稅快結束 → 電子可以多一些

### 長線觀點
1. **關稅結束後**: 跌深科技股將反轉走強，高殖利率族群休息
2. **黃金**: 川普任期內不確定性持續，長線多頭不變
3. **買便宜顯學**: 全球資金從高估值科技流向低估值傳產/原物料的趨勢

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **買便宜顯學** | 2025年全球投資趨勢，資金從高估值科技股流向低估值、低基期股票 |
| **高殖利率** | 現金股利除以股價的比率，通常5%以上被視為高殖利率 |
| **假殖利率** | 因一次性收入（賣廠、保險金等）造成的高配息，不具持續性 |
| **0056/0050比值** | 高股息ETF與市值型ETF的相對強弱指標，比值上升代表高股息轉強 |
| **填息** | 除權息後股價回到除息前水準，代表市場認同配息價值 |
| **股東會行情** | 每年5-6月股東會前後，公司釋放利多帶動股價的效應 |
| **除權息行情** | 每年6-8月除權息前的搶權行情與除息後的填息行情 |
| **量子點膜** | 新型光學膜技術，具有更高色彩純度與色域，應用於高階顯示器 |
| **鉛酸電池** | 傳統儲能電池，因成本低、技術成熟，仍為資料中心UPS主要選擇 |
| **股票分割** | 將面額拆小以降低每股價格，增加流動性（如10元→0.5元，一張變20張） |
