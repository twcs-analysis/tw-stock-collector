#### 個股分析

| 華邦電 | 年線處爆大量（套牢賣壓出清） | 年線與半年線之間高出低進；避免追高，回到半年線是買點 |

### 四、關稅情境沙盤推演 -- 明漢

**三種情境分析**:

1. **部分課稅（基準情境，機率最高）**: 課15國中部分國家 → 市場已預期，衝擊有限，整理為主
2. **全面課稅（嚴重情境）**: 15國全課+半導體、汽車、藥品 → 短線必跌，往下錯殺
3. **延期取消（最差情境）**: 反覆不確定，資金持續進出 → 股市不斷震盪，最令人不安

**核心觀點**:
- 課稅反而對股市較好（利空出盡）
- 最怕延期取消導致不確定性持續
- 川普壓力大：反對率已超過支持率（死亡交叉）
- 4月2日前一週賣壓將最大（參考上次提前5天釋放壓力）

### 五、台積電赴美投資解讀 -- 明漢

**重要釐清**:
- 台積電赴美非被逼迫，2020年拜登時代即啟動第一座廠
- 六座廠為原始規劃（非新增），只是提前公佈時程
- 一千億投資未明確說四年內完成，可能是10-20-30年
- **潛在利空**: 台灣產能90%仍在台灣，未來可能被課關稅

### 六、MACD技術分析教學 -- 正華

**MACD底部確認三階段**:
1. **底背離**: 股價創新低但MACD交叉位置越來越高（跌勢減緩）
2. **復翻正**: MACD穿越零軸上方，確認由反彈轉為回升
3. **唐老鴨嘴（加速階段）**: MACD差點交叉又張開，代表加速上漲

**個股MACD分析**:

| 股票 | MACD階段 | 操作建議 |
|------|---------|---------|
| 廣宇 | 已完成唐老鴨嘴（加速階段） | 拉回即支撐，首次唐老鴨嘴為最佳進場點 |
| 不落貴（BPU） | 穿越零軸後尚未加速 | 等待唐老鴨嘴出現再積極介入 |
| 立積 | 穿過零軸完成回升 | 形成短線唐老鴨嘴可追 |
| 致易 | 始終在零軸上方（網通設備） | 符合美國重建概念，股價偏高注意風險 |

### 短線策略（1-2週）
1. **4月1-2日前謹慎應對**: 預期賣壓最重，可適度減碼
2. **BPU族群**: 新勝利追量攻擊、嘉白玉低檔布局
3. **軍工股**: 下週一觀察保一是否回測五日線出現買點
4. **避免追高**: 拉回半年線才是安全買點

### 中線策略（1-3月）
1. **關稅利空出盡後**: 堅信經濟不會衰退，跳空下跌時是買進機會
2. **記憶體**: 等營收驗證後再積極布局
3. **台積電與市值型ETF**: 分批布局，黑天鵝出現時反而要買

### 核心原則
- 利空不怕次數，只怕大小
- 4月2日課稅後，最大利空出盡，股市反而有望轉強
- 信念最重要：相信關稅會課、經濟不會衰退

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **對等關稅** | 川普政府4月2日起實施的關稅政策，對貿易不公平的國家徵收對等稅率 |
| **Dirty Fifties（骯髒十五國）** | 美國財政部列出的15個對美國徵收高關稅且貿易順差大的國家 |
| **停滯性通膨（Stagflation）** | GDP成長下降但物價上升的經濟狀態，聯準會難以應對 |
| **BPU** | 備用電力系統（Backup Power Unit），AI資料中心不斷電系統 |
| **MACD底背離** | 股價創新低但MACD指標位置較前次高，代表跌勢動能減緩 |
| **唐老鴨嘴** | MACD技術型態，差點死亡交叉又張開上揚，代表趨勢加速 |
| **復翻正** | MACD由負值穿越零軸轉正，確認從反彈進入回升階段 |
| **鴨子理論** | 形容聯準會表面鎮靜但實際緊張應對的狀態 |
| **年線** | 240日移動平均線，代表長期多空分界 |
