### 美國經濟四階段歷史演變（鄭老師白板教學）

| 階段 | 時間 | GDP | 物價 | 利率 | 股市 |
|------|------|-----|------|------|------|
| 第一階段 | 2010-2020 | 上升 | 持平 | 低檔 | 大好（最美好成長期） |
| 第二階段 | 2020-2024中 | 上升 | 上升 | 大幅升息至5% | 科技七巨頭獨強 |

**關鍵概念**: 第四階段為「停滯性通膨」前兆，GDP下行+物價上行，聯準會進退維谷。

### 川普關稅的歷史縱深

#### 90年前的歷史教訓
- **1930年斯姆特-霍利法案（Smoot-Hawley Tariff Act）**: 胡佛總統簽署，上萬種商品關稅拉高至50%
- 加拿大、英國、法國反擊，法國對某些商品課400%
- 結果：經濟大蕭條加劇，胡佛四年後選輸
- **1934年互惠貿易協定法**: 羅斯福上台後簽訂，為GATT（關稅暨貿易總協定）前身，再演變為WTO
- **過去90年**: 全球關稅持續下降，享受自由貿易紅利

**川普的邏輯**: 仿效90年前的保護主義，從「自由貿易」轉向「公平貿易」。

#### 川普是灰犀牛，非黑天鵝
- **黑天鵝**: 完全無法預期的事件（如新冠肺炎）
- **灰犀牛**: 利空擺在眼前卻被忽視，一旦發生衝擊極大
- 川普從選前到執政始終如一，講什麼做什麼
- 市場過去認為「只是談判手段」，現在發現是真的要做

### 安章十五國與台灣的風險

#### 台灣被列入風險
- 台灣對美貿易順差排名第六
- 但2018-2024年順差增加幅度最大（11.9% → 23.5%）
- 台灣財經官員解釋為AI與半導體需求所致，但美方是否接受未知

#### 台積電赴美的隱藏利空
- 亞利桑那州工廠供應鏈廠商被「邀請」赴美設廠
- 赴美生產成本大增，影響毛利率與獲利
- 中小型供應鏈無法如台積電般轉嫁成本
- **最大隱憂**: 台灣產能90%仍在本土，可能全部被課關稅（不分台積電或聯電）

#### 張忠謀名言（三年前即預言）
- 「全球化已死」
- 「自由貿易已死」
- 台灣產業需轉型，不能再過度依賴半導體

### 台股技術面關鍵警訊

#### 跌破年線的嚴重性
- **年線多頭時代結束**: 過去只要股價在年線上方，任何拉回找買點
- 現在台股與美國七大科技股幾乎全部跌破年線（僅Meta接近但未破）
- 上次類似情境：2000年網路泡沫（同為科技相關）
- 包括蘋果、特斯拉均已跌破年線

#### 內外資失衡問題
- 外資今年已賣超5,000億元
- 內資（散戶+政府基金+壽險）已全數接手
- 問題：內資還有多少子彈？國安基金極限約5,000億
- 外資預估仍有5,000億賣壓待出

## 📈 技術面分析

- PCE上修至2.8%（停滯性通膨前兆）

### 台灣央行技術面影響
- 連四凍利率不變，無寬鬆條件
- 房貸條件趨嚴（加強金檢）
- 經濟成長率下修至3.05%（仍健康）

### 歐元與美元趨勢翻轉
- 一個月前：歐洲爛到底 → 歐元弱、美元強
- 現在：歐洲擴軍+基建 → 歐元強、美元跌
- 歐洲可能暫停降息 + 美國可能被迫降息 = 歐強美弱

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **停滯性通膨（Stagflation）** | GDP下降同時物價上升的經濟困境，央行難以同時應對兩者 |
| **斯姆特-霍利法案** | 1930年美國通過的關稅法案，對上萬種商品課徵高關稅（最高50%），加劇大蕭條 |
| **GATT** | 關稅暨貿易總協定，1934年互惠貿易協定法的延伸，WTO前身 |
| **灰犀牛** | 明顯可見但被忽視的重大風險，一旦發生衝擊極大 |
| **黑天鵝** | 完全無法預期的重大事件 |
| **鴨子理論** | 表面鎮靜但暗中緊張應對的狀態（鴨子水上優雅、水下拼命划水） |
| **公平貿易** | 川普主張的貿易模式，要求各國對美國的關稅與非關稅壁壘對等 |
| **非關稅壁壘** | 除關稅外的貿易障礙，如進口限制、政府補貼、貨幣操縱、勞工壓榨等 |
| **連四凍** | 央行連續四次維持利率不變 |
| **信用管制** | 央行對不動產貸款的限制措施（如限貸成數、提高利率等） |
