### 市值型 vs 高股息 ETF 配置建議

- **外資動態**：近期賣超0050（賣在台股相對高點），轉賣高股息ETF
- **建議比例**：長線投資 -- 市值型70% + 高股息30%；短線各50%亦可
- **年輕人**：高市值型為主，不必過度關注高股息
- **退休族**：仍需配置部分高股息以提供穩定現金流

## 策略總結

1. **大盤**：KD低檔壓縮到極致，只欠一個多頭訊號（輝達財報或台積電結算），指數低點有限
2. **操作策略**：大型權值股拉回為買進機會，勿追高；利空打下來時買進
3. **集團作帳**：年底前一個半月為集團作帳黃金期，首選華新（1605）、安國（8054）、國巨（2327）
4. **ETF配置**：年輕人選0052（純科技、成長性強），穩健型選0050；市值型與高股息比例建議7:3
5. **記憶體**：華邦電明日出關偏多看待，力積電優於旺宏（代工價格反應落後3-4個月）
6. **風險管控**：鴻華先進、裕隆等汽車概念股有反彈先出，產業基本面不佳

## 名詞解釋

| 名詞 | 說明 |
|------|------|
| KD黃金交叉 | 技術指標中，K線由下往上穿越D線，視為買進訊號 |
| ABC修正波 | 艾略特波浪理論中的修正型態，由A浪下跌、B浪反彈、C浪再跌組成，完成後常迎來新一波上漲 |
| 集團作帳 | 年底前關係企業透過交叉持股拉抬旗下子公司股價，美化財報的行為 |
| ETF分割 | 將一股拆分為多股（如一分七），降低每單位價格以吸引更多投資人 |
| 淨值比（PBR） | 股價與每股淨值的比率，低於1表示股價低於公司帳面價值 |
| 空盤手 | 市場主力或大型法人透過操作指數期貨壓低大盤的手法 |
| 處置股 | 因股價異常波動被證交所實施處置措施的個股，交易受到限制 |
| ASIC | Application-Specific Integrated Circuit，客製化特殊應用積體電路 |
