## 市場觀察

### 輝達（NVDA）財報前瞻

#### 股價技術面

- 上週兩度觸及季線均打出長下影線反彈，季線為輝達最強支撐保護傘
- 上週五收盤價190美元，本益比約45倍（靜態），預期本益比僅28倍
- 法人平均目標價240美元

#### 基本面預估

| 季度 | 營收預估 | 營收年增 | 獲利年增 | EPS預估 |
|------|----------|----------|----------|---------|
| Q3（本季公布） | 549億美元 | +56% | +66% | ~1.25 |
| Q4 | 601億美元 | +56% | 六成以上 | ~1.42 |

#### 三種情境對台股影響

| 情境 | 機率 | 對台股影響 |
|------|------|------------|
| 優於預期 | 最大 | 台股直攻28,500點甚至挑戰新高 |
| 符合預期 | 中等 | 維持27,000-28,100點區間整理 |
| 低於預期 | 極低 | 回測27,000點附近，下行空間僅約500點 |

#### 大魔（大摩/摩根士丹利）觀點

- 稱輝達即將進入「史上最強一季」財報
- 財報公布後股價即將出現「大逆轉」（向上）
- GB300及明年的路線圖為新成長動能

### 美國市場風險評估

#### 資金面問題

- 銀行準備金降至3兆以下，資金趨緊信號
- **解方一**：聯準會準備重新購債（QE），紐約聯儲主席威廉斯11/7提到「可能很快開始」，時間點可能在明年Q1
- **解方二**：美國政府開門後財政部7,000多億資金釋出，具有降息效果
- **解方三**：川普豁免多項農產品關稅（咖啡等），CPI壓力不大

#### AI泡沫討論

- CoreWeave（輝達投資的AI新創）面臨困境：年營收50億但負債141億，CDS超過500（接近違約）
- 但此為個案，AI建設投資來自四大雲端業者（非散戶），結構與網路泡沫/次貸危機不同
- 美國AI股重點標的：AMD與Google最強，波克夏開始買Google
- 輝達與台積電雖拉回但守住季線之上

### 費半與台股連動

- 6月以來費半（紅色線）與台股（黃色線）走勢幾乎同步
- 費半只要上漲，台股必定跟漲（主因為台積電連動）
- 結論：費半沒問題，台股就沒問題

## 產業分析

### 一、記憶體全面盤點

#### 供需格局

- **供給端**：三大原廠（SK海力士、三星、美光）產能持續轉向HBM高階產品，DRAM/NAND Flash產能雙降
- **需求端**：PC/手機記憶體容量自然增加（程式越來越大）；AI大廠狂掃HBM，價格彈性極低（不計代價搶購）
- **關鍵差異**：AI大廠價格彈性低（必須買），PC/手機廠價格彈性高（漲價就不買或延遲出貨）
- **NAND Flash交期**：明年產能已被訂光，目前訂購要排到2027年，供需缺口從預估70-80%擴大到100%

## 策略總結

1. **輝達財報為本週最大催化劑**：預期本益比僅28倍，市場共識偏優於預期，台股有機會挑戰28,500點
2. **記憶體**：DRAM/NAND Flash供需缺口擴大，越漲本益比越低（類航海王邏輯）；首選南亞科（DDR5領頭羊）、華邦電（多元產品線+擴產空間）、力積電（代工價格落後反應3-4個月）
3. **硬碟為隱藏版題材**：敏意（3260）、普安（2495）底部剛起漲，Seagate已漲近兩倍但台灣硬碟概念股尚未跟上
4. **AI概念低檔股**：世芯等明年1-3月為營收空窗期，可縫低分批布局；崇明電為唯一未漲的水冷機櫃股
5. **法說會看門道**：重點看毛利率方向、訂單能見度長度、新產品/新市場切入；IET-KY與晴看為正面案例

## 名詞解釋

| 名詞 | 說明 |
|------|------|
| 價格彈性 | 經濟學概念，衡量需求量對價格變動的敏感程度。彈性低表示即使漲價需求也不減少 |
| HBM（高頻寬記憶體） | High Bandwidth Memory，AI晶片專用的高效能記憶體，由多層DRAM堆疊而成 |
| DDR5 | 第五代雙倍資料傳輸率記憶體，較DDR4速度更快、功耗更低 |
| NAND Flash | 非揮發性快閃記憶體，用於SSD、手機儲存等 |
| NOR Flash | 非揮發性記憶體，主要用於儲存程式碼，讀取速度快 |
| CDS（信用違約交換） | Credit Default Swap，衡量公司違約風險的指標，數值越高違約風險越大 |
| CoreWeave | 輝達投資的AI雲端新創公司，專注於GPU雲端運算 |
| GB300 | 輝達下一代AI伺服器平台 |
| QE（量化寬鬆） | 央行透過購買債券向市場注入資金的貨幣政策工具 |
| TIM1散熱材料 | Thermal Interface Material，夾在晶片與均熱片之間的散熱介面材料，技術門檻最高 |
| TGV導電膏 | Through Glass Via，玻璃基板的導電通孔技術，為下一代先進封裝材料 |
| 矽光值（Silicon Photonics） | 以矽為基礎的光電整合技術，用於高速資料傳輸 |
