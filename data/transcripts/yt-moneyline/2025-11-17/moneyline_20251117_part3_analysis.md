## 市場觀察

### 11月ETF除息潮

- 明天（11/18）將有三四十檔ETF進行除息，包括台股十多檔
- **高股息ETF**：今年表現相對弱勢，配息持續縮水
- **市值型/科技型ETF**：今年表現非常亮眼，但近期遇到亂流修正
- 投資人面臨抉擇：高股息賺了很多要不要賣？市值型跌下來要不要換？

### 聯準會會議後市場衝擊

#### 10月29日聯準會後的影響

- **市場高點**：大部分市場高點出現在10/29（聯準會會議當天）
- **鮑威爾關鍵發言**：「12月降息並不是板上釘釘的」-- 直擊市場靶心
- 12月降息機率已降至五成以下
- 明年全年最多降兩碼，上半年最多一碼，與市場原先預期落差極大

#### 被忽略的利多

- **12/1結束縮表**：不再回收資金，等於把水龍頭上的鎖拿掉，對資金市場正面
- **鮑威爾罕見產業評論**：
  1. 「降不降息不會影響資料中心投資」
  2. 「AI與網路泡沫不一樣，現在的公司是有獲利的」
- 波克夏開始買進Google，代表對雲端公司並未看壞

### 加密貨幣暴跌衝擊

- 10月10日加密貨幣出現大規模清算，規模超過100億美元
- 高槓桿合約操作導致許多投資人受傷
- 加密貨幣佔避險基金/金融機構比重僅5%，衝擊有限
- 但作為風險性資產，已成為股市重要信心指標
- 近期暴跌有「擠泡沫」效果，反而更健康

### 美國盤後表現

- 錄影時間下午四點二十分，那斯達克期貨漲幅擴大至+1%
- AI與費半走勢偏多
- 本週三台積電結算、週四輝達財報、週五鴻海科技日，為密集催化劑

- 擔心者：盡量分散，不重壓單一產品

#### 冠洲觀點：別只盯科技股

- 股價領先基本面，產業風向尚未完全明確但端倪已現

## 技術面分析

### 傳產族群技術面共通特徵

- 大部分傳產股處於「底部區」，波段整理幅度大但底型越來越明確
- 量能普遍偏低（資金不在此處），一旦放量則為轉折訊號
- 股價領先基本面：產業風向尚未完全明確，但股價已開始築底

### 航運股技術面

- 裕民：連前波高點的一半都還沒回去，量能極低但底部形態明確
- 長榮、陽明：低檔整理，若旺季帶動營收改善可能有底部反彈

### 台塑化（6505）技術面

- 莫名其妙的急拉，但油價尚未配合
- 屬於低檔反覆整理型態，需油價或政策面配合才能確認底部翻轉

## 策略總結

1. **ETF資產配置**：股票型佔五成以上，黃金避險、債券收息、保留現金子彈；積極者繼續持有科技型，保守者部分轉定期定額
2. **加密貨幣**：暴跌為擠泡沫過程，反而更健康，但佔比控制在5%以內
3. **聯準會**：12月降息機率降低但非大利空，結束縮表為被忽略的利多
4. **傳產低檔股浮現**：航運（散裝優於貨櫃）、鋼鐵鋼構、石化、網通、電力為年底至明年潛力方向
5. **烏克蘭/中東重建**：總規模6,500億美元以上，台灣企業已參與重建展，鋼構/機電/網通為直接受惠族群
6. **本週操作重點**：
   - 週三台積電結算
   - 週四輝達財報（最重要）
   - 週五鴻海科技日
   - 記憶體/PCB/光通訊族群輪動快，拉回買進、急漲不追

## 名詞解釋

| 名詞 | 說明 |
|------|------|
| SCFI（上海貨櫃運價指數） | Shanghai Containerized Freight Index，反映貨櫃航運市場運價水準 |
| BDI（波羅的海乾散貨指數） | Baltic Dry Index，衡量散裝航運市場運費的指標 |
| 縮表（Quantitative Tightening） | 央行減少資產負債表規模（賣出或到期不再投資債券），收回市場資金 |
| 反傾銷 | 針對以低於正常價值出口的商品加徵關稅的貿易保護措施 |
| PV（太陽能） | Photovoltaic，太陽能光伏發電 |
| 鋼構 | 鋼結構建築，以鋼材為主要結構材料的建築方式 |
| 低軌衛星 | Low Earth Orbit衛星，軌道高度約160-2,000公里，用於通訊、導航等 |
| ETF除息 | ETF將累積的股息/利息分配給投資人，除息日股價會相應調降 |
| 非投資等級債 | 信用評等較低（BB+以下）的債券，收益率較高但違約風險也較高 |
| 波克夏（Berkshire Hathaway） | 巴菲特旗下投資公司，以價值投資聞名 |
