## 🌍 市場總體觀察

### 美國經濟與政策分析

#### 聯準會與經濟展望
- S&P 500 上週創五個月以來最大單週跌幅
- 鮑爾演說結論：美國經濟目前還不錯，短期不急於降息
- 錄影時（下午5點），美國期貨盤壓力持續擴大，NES 期指跌幅約1.3-1.4%
- 台積電 ADR 盤前跌幅不輕
- 美國十年期公債殖利率持續低迷（4.2-4.3%），反映經濟可能衰退

#### 川普2.0政策解析

**內政：廣基糧（內政改革）**
- 目前進行政府改革（馬斯克 DOGE 查帳），經濟與股市震盪是必要之痛
- 川普表示較少看股市，內政改革優先
- 已發現「吸血鬼」案例（360歲的人還在領社會福利金）

**外交：高築牆（關稅壁壘）**
- **川普1.0 vs 2.0的差異**:
  - 1.0：胡蘿蔔政策（邀請盟友一起圍堵中國），效果不佳
  - 2.0：棍子政策（你不對中國課關稅，我就對你課關稅），威脅成分高
- 墨西哥、加拿大正考慮配合對中國課關稅
- 加拿大對美國有高額貿易盈餘（每年1,000-2,000億美元），對中國是貿易赤字，配合美國較有利

**三大產業政策方向**:

1. **非紅船海運計畫（造船業）**
   - 對持有中國製造船舶比例超過25%的航商課高額停泊費
   - 範圍擴大至營運中、計畫交付、訂購中的船舶
   - 要求盟友跟進，否則課關稅
   - 中國目前占全球新貨櫃船訂單約70%

2. **鋼鋁關稅（3月12日實施）**
   - 25%關稅如期生效，沒有豁免期
   - 與2018年不同：這次是要製造業回歸美國，不可能全面豁免
   - 目標：基礎工業原物料留在國內

3. **擴大原油開採**
   - 去年底日產量1,350萬桶，今年底預估1,390萬桶
   - 油價可能下跌，利好航空業

### 1. MAGA 概念股（讓美國再次偉大）

#### 貨櫃航運三雄

**非紅船海運計畫影響分析**:

| 航商 | 營運中國船比例 | 訂購中國船比例 | 影響程度 |
|------|--------------|--------------|---------|
| 馬士基 | 11% | 94.5% | 高 |
| 地中海航運 | 8% | 68.9% | 高 |
| 達飛 | 21% | 64.4% | 高 |
| 中國海運 | 51% | 100% | 極高（幾乎被排除） |
| **長榮 (2603)** | **低** | **0%** | **受惠（轉單效應）** |
| **陽明 (2609)** | **低（<25%）** | **23%** | **影響小** |
| **萬海 (2615)** | **低** | **低** | **影響小** |

**長榮海運 (2603)**
- 美國航線占比40-50%，全球運能排名第七
- 泛太平洋航線為前五大
- 4月份美國航線傳出將漲價
- 去年 EPS 預估較高，今年可能小幅下滑
- 配息預估30-38元，殖利率仍高
- 淨值299.9元，股淨比偏低
- **操作建議**: 創高不追，拉回量縮可考慮逢低布局，緩步墊高走勢

**陽明海運 (2609)**
- 全球運能排第九，美國航線國內排第一（長榮第二）
- 去年 EPS 約20元，今年預估17元（小幅下滑）
- 配息預估6-8元，殖利率約10%
- 淨值912.8元，低於淨值
- **操作建議**: 創高不追，拉回逢低布局

#### 航空股

**華航 (2610)**
- 受惠油價下跌
- 剛站上月線，像是起漲點
- 去年 EPS 約2元，今年有機會成長
- 全球缺機潮持續至2028年（空巴、波音產能不足）
- 2025年全球旅客數預估達52億人（年增7%）
- 新機陸續交機、短約轉長約對航空有利
- **操作建議**: 法人持續買超，創近期最長連漲天數，短底味道

**長榮航 (2618)**
- 獲利較佳，股價已回到季線
- 投信連續買超第一名
- **操作建議**: 投信持續買，跟著資金走

**星宇航空**
- 配息6.01元，股價站上來
- 手握季線，獲利較高
- **操作建議**: 股本較小，仙琴指標，短線有些過熱需注意

#### 鋼鐵股

**大成鋼 (2027)**
- 美國最大的鋁圈板與不鏽鋼通路商
- 鋁圈板占比約60%
- 2018年德州鋁工廠年底從1.3萬噸擴增至3.1萬噸，自製率提高
- 自製後毛利率將再度提高
- **歷史對照**:
  - 2018年（川普1.0鋼鋁關稅）：EPS 從1元多跳至5.8元
  - 2020-2021年（反傾銷稅）：EPS 5.76→6.23元
  - 2025年再次發生關稅效應
- 2月營收87.79億（18個月新高）
- 鋁價生產商向日本買家提出第二季漲價14%
- 去年 EPS 約1元多，今年預估3元多，明年可能跳至6元以上
- **操作建議**: 暴量區出現後未跌破，為換手整理；接近10日線可布局；中長期看突破前高

**中鋼 (2002)**
- 外資今日買超第一名（35,000多張）
- 投信買超第二名（11,000多張）
- 持續創波段高點
- 資金才剛進來，投信漸倉階段
- **操作建議**: 接近10日線可布局，走大波段格局

#### 成熟製程

### 2. PCB 族群

#### 產業總覽
- 2024年 Q4 台商 PCB 全球產值115億美元（年增20.8%）
- 全年產值868億美元（年增6.1%）
- 2025年預估產業成長至850億美元（年增4.6%）
- 增長主要集中在高階廠商（如台光電），後段廠商增長有限

#### 關鍵個股分析

**台光電 (2383)**
- PCB 龍頭，股價突破600元
- 法說會重點：「2025年是下一波基因基效、卓越成長的開始」
- 高階 HDI 占比70%，類載板材料占比90%
- 高盛目標價800多元
- M8以上等級材料2024-2027年年複合成長率130%
- 馬來西亞廠 Q3 量產，月產能增加60-75萬張
- 大園廠增資80億元擴建計畫
- 產能全滿，接到滿但不能滿
- **操作建議**: 唯一缺點是貴（600多元），但每次拉回都是買點；投信持續買超

**富喬 (1815)**
- 股價僅32-35元，低基期
- 大客戶為台光電，供應電子級材料
- Low DK1 已量產，Low DK2 通過客戶（台光電）認證
- Low DK2 用於 M8 以上高階材料
- 下半年 Low DK2 可能從8萬張倍增至20萬張
- 泰國廠準備擴產
- 去年業績不好（便宜的原因），但今年開始要賺錢了
- **操作建議**: 前波漲停板後回到漲停板低點，為買點；下檔空間有限

**高技 (5439)**
- 營收連續創新高
- 大客戶為台光電與智邦
- 今年最看好 M8 材料，雙位數成長
- 車用通訊開始用 M7/M8
- 今年配息增加3倍至11元
- 800G 良率提升，AI 占比今年目標11%以上
- 股價已從107.5元漲至153.5元
- **操作建議**: 不要追高，風高準備獲利了結；若修正至135.5元可再介入

**博智 (8155)**
- 二月營收創新高（年增68.8%）
- 大股東為仁寶、嚴華
- 伺服器板表現佳（占比約80%）
- IPC（工業電腦）板下半年有望因邊緣 AI 開案而回升
- IC 載板切入（給穎威等）
- 已發行 CB 10.5億 + 現增5億，共募資15.5億準備擴廠
- 投信持續買超（累計4,703張）
- 公司發言體系非常保守
- **操作建議**: 比高技更值得選擇，挑戰前波高點；不到20倍本益比

### 3. 電子紙產業

**元太 (8069)**
- 櫃買最大權值股
- 上週法說會方向正面
- 彩色電子紙技術成熟，需求強勁
- 發展方向：電子書閱讀器→電子標籤→電子廣告看板（大尺寸）
- 大尺寸彩色電子紙為今年推動重點，尺寸越大營收與毛利越好
- 電子標籤在歐美市場普及加速（技術成熟、成本下降）
- 去年營收321億（年增8%），EPS 7.75元
- 今年有機會挑戰 EPS 10元
- 累積至二月營收年增3%，二月營收年增14%
- 資本支出50-60億投入大尺寸電子紙研發與生產
- 歷史本益比約30倍
- **操作建議**: 上週突破，氣勢強勢；拉回整理區間可觀察

**振曜 (6143)**
- 電子紙 ODM 廠商，專做電子書閱讀器
- 與樂天 Kobo 合作，閱讀器銷量翻倍增長
- 切入博智（同一集團）合作電子看板
- 今年營收預估年增35%，毛利率22%（改善中）
- 累積至二月營收年增約9%（弱於元太）
- 不到20倍本益比
- **操作建議**: 拉回可留意，與元太走勢相近

### 4. BPU（備援電源）概念

**順達 (3211)**
- 3月5日法說會，展望正面
- BPU 應用範圍擴大：AI 伺服器、機器人、路由器網路
- CSP 廠商持續建造資料中心，BPU 需求持續
- 去年 EPS 約23-25元，今年市場看法樂觀，挑戰4個股本
- 二月營收年增15%
- **操作建議**: 突破下降壓力線，基本面正面

**APC（達方）**
- CSP 廠商持續拉貨 AI 伺服器
- 累積二月營收成長中
- **操作建議**: 與順達同步觀察

## 📋 投資策略總結

### 核心策略
1. **MAGA 概念股為主軸**: 跟著川普政策走（鋼鐵、航運、航空、成熟製程）
2. **PCB 族群精選**: 產業大好年但增長集中在高階廠商（台光電、富喬、博智）
3. **電子紙產業長線布局**: 元太為領頭羊，關注大尺寸彩色電子紙發展
4. **BPU 不只是 AI**: 備援電源應用擴及機器人、網路設備，需求持續
5. **航運股攻守兼備**: 殖利率高、股淨比低、政策題材加持

### 操作注意事項
- 美國股市仍在修正，費半影響台積電連鎖效應
- 關稅政策一日數變，不確定性極高
- 創高不追為原則，拉回量縮逢低布局
- 10日線為短線操作關鍵支撐

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **MAGA (Make America Great Again)** | 讓美國再次偉大，川普的核心政策口號，延伸為受惠美國政策的概念股 |
| **非紅船海運計畫** | 美國計畫對使用中國製造船舶的航商課徵高額港口費用，推動造船業回歸 |
| **PCB (Printed Circuit Board)** | 印刷電路板，電子產品的核心基板 |
| **Low DK** | 低介電常數材料，用於高頻高速電路板，M8以上等級的關鍵材料 |
| **HDI (High Density Interconnect)** | 高密度互連技術，PCB的高階製程 |
| **M8** | PCB 材料等級分類，M8以上為高階低介電材料，年複合成長率130% |
| **BPU (Battery Power Unit)** | 備援電源單元，用於伺服器、機器人等設備的不斷電系統 |
| **CSP (Cloud Service Provider)** | 雲端服務供應商，如 AWS、Google Cloud、Microsoft Azure |
| **ODM (Original Design Manufacturer)** | 原始設計製造商，為品牌客戶設計並製造產品 |
| **電子紙 (E-paper/E-ink)** | 模擬紙張顯示效果的電子顯示技術，省電且護眼 |
| **CB (Convertible Bond)** | 可轉換公司債，可在特定條件下轉換為股票 |
| **股淨比** | 股價除以每股淨值，低於1表示股價低於帳面價值 |
