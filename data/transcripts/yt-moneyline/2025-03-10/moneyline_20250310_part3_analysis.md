### 2. 股票分割題材

#### 分割邏輯與效果

**為什麼要分割？**
- 降低股價門檻，增加流動性
- 流動性增加→波動性增加→有利股價表現
- 三大理論支持：流動性理論、信號理論（公司看好未來才分割）、心理定價理論

**S&P 500 分割統計數據**:

| 期間 | 分割股報酬率 | S&P 500 報酬率 | 差異 |
|------|------------|---------------|------|
| 分割前後3個月 | 7%+ | 2% | 分割股優 |
| 分割前後6個月 | 優於大盤 | - | 分割股優 |
| 分割前後12個月 | 優於大盤 | - | 分割股優 |

**台股分割歷史案例**:
- Apple 2020年分割：分割前後股價上漲
- 綠界科技：宣布分割後股價下跌→分割完成後上漲，流動性增加穩定成長
- 康霈上次分割（1拆2）：分割前無動作→分割後5日、20日、60日漲幅均非常亮眼（歷史案例中表現最佳）

**台股分割上漲機率**:
- 過去6檔案例中，分割前5日上漲機率約80%
- 分割後上漲機率約60%（6檔中4檔上漲）

#### 分割概念股

**0050（元大台灣50 ETF）**
- 已計畫分割
- **特殊性**: ETF 有申購贖回機制，籌碼會變化（不同於一般股票）
- 分割對股價影響可能不大
- **關鍵**: 看台積電（占比約五成）會不會漲，而非分割本身

**康霈 (6919)** - 二度分割
- 上次分割後表現為歷史案例中最佳
- 年底可能進行分割
- 目前股價正盪，約四折來到淨現值估算的位置
- 在手現金約88億，足以支撐研發營運
- **操作建議**: 等待分割確認後動作；風險調整後淨現值約1,260億，目前市值約1,300億，下檔空間有限

**材料-KY (4763)**
- 做矽酸鋯（給瓷磚廠商的材料）
- 全球做這類材料的廠商很少
- 去年 Q4 至今年上半年持續擴產
- 去年現金配發率60%以上
- 殖利率約4%
- 今年 EPS 有機會挑戰百元
- 股價約570元，本益比不到20倍，偏價值型投資
- **操作建議**: 拉回靠近短期均線可留意

2. **新藥股操作心法**: 解盲前卡位（不等解盲後），距離解盲越近溢價越高

- 美國夏令時間生效，開盤改為台灣晚上9:30

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **AB-BNCT** | 加速器硼中子捕獲治療（Accelerator-Based Boron Neutron Capture Therapy），新型癌症放射治療技術 |
| **ATP** | 三磷酸腺苷（Adenosine Triphosphate），細胞的主要能量分子 |
| **MDR (Medical Device Regulation)** | 歐盟醫療器材法規，較舊規範更嚴格，取得認證可獲轉單效應 |
| **股票分割** | 將一股拆成多股（如1拆2），股價等比例降低但總市值不變，目的是增加流動性 |
| **淨現值 (NPV)** | 將未來現金流折現至現在的價值，用於評估新藥公司長期價值 |
| **費半指數** | 費城半導體指數，美國半導體產業的領先指標 |
| **夏令時間** | 美國日光節約時間，每年3月第二個週日開始，美股開盤提前1小時至台灣晚上9:30 |
| **信號理論 (Signaling Theory)** | 公司願意分割股票，暗示管理層對未來前景有信心 |
| **ETF 申購贖回機制** | ETF 特有的籌碼變動機制，與一般股票分割不同 |
| **解盲** | 新藥臨床試驗結束後揭曉實驗結果，決定藥物是否有效 |
| **矽酸鋯** | 一種工業陶瓷原料，用於瓷磚製造，材料-KY的主力產品 |
