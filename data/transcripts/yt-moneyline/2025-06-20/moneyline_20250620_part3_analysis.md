## 🌍 市場總體觀察

### Tesla Robotaxi 即將上路 -- 自駕車新紀元

#### 重大事件
- **日期**: 6月22日（本週末）
- **地點**: 美國德克薩斯州
- **內容**: Tesla 自家自駕計程車 Robotaxi 率先上路營運
- **外觀**: 類似 Model Y 的流線型造型，引擎蓋、車門、車尾均有 Robotaxi 標誌

#### Tesla 自駕技術突破
- **自駕介入里程數**: 從過去卡在2,300英里大幅提升至45,000英里（約700公里）
  - 意義：自駕車可跑700公里（約台北到高雄來回一圈）才需人工介入
  - 新硬體版本帶來的技術飛躍
- **核心競爭優勢 -- 不需要雷達**:
  - 對比 Waymo（目前美國自駕技術最成熟的公司）：每台車需加裝大量雷達，成本從3-4萬美元飆升至近30萬美元（約1,000萬台幣）
  - Tesla：不需加裝任何雷達，出廠即可自駕，每台成本約100萬台幣
  - 成本差距10倍，這是 Tesla 最大的殺手鐧

#### 商業模式顛覆
- **第一階段**: Tesla 自有車隊營運 Robotaxi
- **第二階段**: 所有 Tesla 車主的車在閒置時可自動成為計程車（共享經濟）
- **第三階段**: 其他車廠（福特、賓士、BMW）被迫採用 Tesla 自駕軟體
  - 因為同樣100萬買車，Tesla 車可以當計程車賺錢，其他車不行
  - 最終 Tesla 從「賣車公司」轉型為「賣軟體的科技公司」
- **終極願景**: 未來計程車業可能消失，所有車都是自駕車，出行成本極低

#### 全球自駕車市場規模
- **美國**: 2025年快速增長，年化增長率約96%
- **中國**: 同步快速增長，為全球第二大市場
- **10年展望**: 市場規模1變2、2變4、4變8，爆炸式成長

#### Tesla 股價歷史規律
- **過去四年**: 每年6-7月 Tesla 都會舉辦重要活動（電池日、AI日、機器人日）
- **6月上漲機率**: 80%
- **7月上漲機率**: 100%（過去四年皆上漲）
- **平均漲幅**: 每年至少一成以上

#### Tesla 銷售現況
- **歐洲**: 品牌討論度因馬斯克爭議大幅下滑，但最近因馬斯克離開政壇開始回溫
- **美國**: 銷量持續下滑（品牌爭議影響）
- **中國**: 已超越美國成為 Tesla 最大銷售市場（黃金交叉）
- **未來**: 若 Robotaxi 成功，中國市場的自駕車競爭對手（即使再捲）都可能被碾壓

### 遺產繼承法律實務

#### 案例：頂客族配偶的遺產困境
- **情境**: 丈夫過世，妻子以為可以直接使用丈夫的銀行帳戶
- **三大法律盲點**:

##### 盲點一：人過世後權利能力終止
- 過世後，該人名字不能再使用
- 所有以其名義的資產變成「遺產」，由全體繼承人共有

##### 盲點二：配偶不等於唯一繼承人
- 頂客族（無子女）容易誤認配偶是唯一繼承人
- 實際上：配偶的父母、兄弟姐妹都是法定繼承人
- 除非配偶的父母與兄弟姐妹都不在，配偶才是唯一繼承人

##### 盲點三：夫妻關係不等於可以自由動用對方資產
- 即使是配偶，未經全體繼承人同意，不能動用遺產
- 違法動用可能構成：偽造文書、詐欺銀行、侵占

#### 正確流程
1. 先繳遺產稅
2. 取得完稅證明
3. 全體繼承人同意
4. 才能動用遺產

#### 緊急措施
- **3萬以內**: 單一繼承人可申請提領，但需切結書（保證已獲其他繼承人同意）
- **20萬以內**: 需全體繼承人同意

#### 三大解決方案

##### 1. 預立遺囑 + 指定遺囑執行人
- 最重要的解決方案
- 指定配偶為遺囑執行人，可不需其他繼承人同意即可處理遺產
- 完稅證明後即可動用，不需他人簽字

##### 2. 保險規劃
- 保險金不屬於遺產，配偶可直接向保險公司請領
- 可用於支付遺產稅、房貸、生活費等緊急需求

##### 3. 預留財務規劃
- 夫妻各自預留部分現金
- 避免所有資金集中在一人名下
- 減輕臨時的財務壓力

#### 常見問題釋疑

| 問題 | 回答 |
|------|------|
| 配偶重病時可以用提款卡預領嗎？ | 若事前有授權可以，但必須用在對方身上，需保留收據 |
| 可以轉帳到自己戶頭嗎？ | 必須說明原因，否則可能被視為侵占，需退回遺產 |
| 網路轉帳可以嗎？ | 不行，電腦紀錄清楚，過世後轉帳一定會被追查 |
| 過世前提領大筆現金避稅可以嗎？ | 國稅局會追查過世前兩年的大筆異常提領，千萬不要逃漏稅 |
| 遺產會被充公嗎？ | 不會，只要依法繼承，遺產不會自動被充公 |

## 📋 投資策略總結

### 法律資產保護核心觀點
1. **預立遺囑是最重要的事**: 不分年齡、不分婚姻狀態，每個人都應預立遺囑
2. **指定遺囑執行人**: 避免遺產被凍結，配偶可以在合法架構下迅速處理
3. **保險是第二道防線**: 保險金不屬於遺產，可作為緊急資金來源
4. **頂客族風險最高**: 無子女者更需注意繼承人範圍擴大至配偶父母及兄弟姐妹
5. **婚前協議不丟臉**: 講清楚財務分配比事後爭產好得多

### Tesla 概念股投資策略
1. **6月底至7月是布局黃金期**: 過去四年7月100%上漲
2. **選股優先順序**: 低本益比（建準電機）> 營收爆發（昶圓科技）> 連接器供應鏈（宏致、貿聯）
3. **Tesla 不是車廠，是科技公司**: Robotaxi 成功意味著從賣車轉型為賣軟體，估值邏輯完全改變
4. **不追高**: 等拉回整理、量縮、前低不破再介入

### 下週操作注意事項
1. **21,800點為大盤多空關鍵**: 跌破將進入明顯回檔
2. **外資期貨空單45,000口**: 若搭配現貨賣超擴大需提高警覺
3. **6/22 Tesla Robotaxi 上路**: 週一概念股可能有反應
4. **中東戰爭**: 週末密切關注，若升溫則航運股與軍工股受益，科技股承壓
