## 🌍 市場總體觀察

### 穩定幣立法重大進展

#### 美國穩定幣監管法案（GENIUS 法案）
- **進度**: 美國參議院已通過，眾議院若通過，最快8月川普即可簽署
- **內容**: 規範穩定幣發行機構（銀行、金融科技公司、大型零售商均可發行）
- **準備金要求**: 每發行1枚穩定幣，須持有等值美元資產（美元或短期美國國債，93天內到期）做擔保
- **市場現況**: USDT（泰達幣）與 USDC（Circle）合計占市場90%

#### 香港穩定幣條例
- **進度**: 以香港作為探頭堡，穩定幣條例預計8月正式生效
- **中國策略**: 通過香港率先立法，搶占穩定幣市場

#### Circle（USDC 發行商）股價表現
- **上市**: 6月5日正式在那斯達克掛牌
- **股價**: 從64美元短短半個月漲至200美元

### 穩定幣對美債市場的影響 -- 兩大迷思破解

#### 迷思一：穩定幣能創造貨幣？
- **市場說法**: 一塊美元當兩塊用，等同QE
- **事實**: 穩定幣並未創造新貨幣
  - 資金來源是從銀行存款或貨幣市場基金轉出
  - 例：1,000億美元從貨幣市場基金 → 購買穩定幣 → 穩定幣公司再買美國國債
  - 本質只是資金搬家，並非新增流動性

#### 迷思二：穩定幣會推動美債大牛市？
- **市場說法**: 穩定幣大量購買美債，將推升債券價格
- **事實**: 穩定幣購買的是極短天期國庫券（93天內到期），非長天期美國國債
  - 短天期債券本來就不缺買家
  - 長天期美國國債（10年、20年、30年）的困境不會因此解決
  - 上上週日本30年期國債標售結果極差，即為長天期無人買的例證
- **結論**: 台灣投資人不宜因穩定幣利多就衝進去買長天期美債ETF（如元大美債20年ETF）

### 美國國債的三大風險

#### 1. 聯準會不降息
- 鮑爾堅持觀望，認為下半年關稅將傳導至通膨
- 川普持續施壓要求降息，但聯準會不為所動
- 長天期利率居高不下

#### 2. 財政持續惡化
- 美國國債已達36.5兆美元（10年前18兆，20年前9兆），每10年翻倍
- 減稅法案 → 財政減項
- 馬斯克離開DOGE → 裁員省錢計畫擱淺
- 國防開支從8,000億增至1兆美元
- 以伊戰爭額外軍費支出
- 「只有減項，沒有加項」，唯一的加項是關稅

#### 3. 信用評等下調
- 三大信評機構全數調降美國評等
- 中國持續減持美國國債
- 上個月加拿大單月減持500多億美元（報復性減持）
- 買家越來越少

### 美國借貸成本問題
- 美國借錢是以10年期公債殖利率（約4.5%）為基準再加碼
- 房貸利率約6.5%、信用卡利率約8.5%甚至更高
- 高利率抑制消費意願、影響美國製造回流（企業借貸成本高）

### 房產贈與子女的三種方案（蘇律師）

#### 案例背景
- 父母有房產想給女兒，擔心離婚後女婿分走房產
- 三種方式各有優缺點

#### 方案一：直接贈與房產

**優點**:
- **排除女婿分產**: 贈與屬「無償取得」，非婚後共同財產，離婚後女婿完全分不到
- **贈與稅較省**: 以公告現值計算（非市價）
  - 範例：市價2,500萬的房子，公告價約740萬，扣掉每年免稅額244萬，贈與稅基僅500萬，稅額約50萬
- **不會有房地合一稅**: 因為不是買賣行為

**缺點**:
- **未來出售時房地合一稅極重**: 女兒取得成本以公告價（740萬）計算，若以3,000萬賣出，課稅基礎高達2,260萬
- **適合對象**: 不急、一次給清、女兒不打算轉賣的父母

#### 方案二：分年贈與現金，女兒再向父母購買

**優點**:
- **未來房地合一稅較低**: 女兒以實際買賣價格（如2,540萬）取得，未來賣3,000萬時課稅基礎僅460萬
- **資金來源合法**: 每年夫妻各244萬免稅額，合計488萬，約五年可完成
- **可向國稅局申報**: 每年贈與有紀錄，合法合規

**缺點**:
- **房價增值部分可能算婚後財產**: 購買後的增值可能被視為婚後投資獲利，離婚時女婿有權分配
- **資金需專款專用**: 父母贈與的現金不能挪做他用，否則國稅局可能質疑
- **適合對象**: 有時間規劃、希望降低未來稅負的父母

#### 方案三：遺囑繼承（推薦）

**優點**:
- **免房地合一稅**: 若房子是2016年（民國104年）12月31日前取得（舊制），以繼承方式取得後出售免課房地合一稅
- **土地增值稅洗掉**: 繼承時以當時公告價為新成本，「洗掉」過去的增值部分
- **無償取得不列入婚後財產**: 離婚完全不用分
- **避免生前被處分**: 遺囑方式可防止女兒受騙將房產提前過戶給女婿

**缺點**:
- 需要等到父母過世才能取得
- 遺囑需合法製作（建議公證），避免文字錯誤

**適合對象**: 持有10年以上舊房子、不急著移轉的父母

#### 常見 Q&A

| 問題 | 回答 |
|------|------|
| 女兒收到贈與後賣舊換新，新房算婚後財產嗎？ | 等價平移不算，但買小換大時需補差額的部分會算婚後財產 |
| 子女貸款買房，父母每年贈現金還貸款，離婚可分嗎？ | 可分，但需扣除贈與部分（贈與不分，漲價部分可能要分） |
| 父母借錢給女兒買房，離婚可分嗎？ | 可分（扣除借款成本後的獲利部分） |
| 婚前協議可否避免分產？ | 可以，建議簽署婚前協議講清楚財務分配 |
| 房子已登記在女兒名下，能做預告登記嗎？ | 可以，只要女兒同意即可做預告登記，防止被騙過戶 |

### 0050 分割後操作策略

#### 外資動向解讀
- **分割前**: 外資大量買超（在指數約18,000-20,000點區間）
- **分割後**: 外資連續賣出（分割登錄日6/10後指數走高，外資獲利了結）
- **結論**: 外資不是「割韭菜」，是正常的獲利了結操作；不要因為分割後價格從180元變40元就覺得「便宜」而追買

#### 操作建議
- **定期定額存股**: 不管位置，每月固定投入
- **波段操作**: 等大盤月線支撐區（約20,000-20,500點）再介入，上方21,800-22,500間獲利
- **大額單筆投入**: 等待月線大幅跌破後的恐慌低點，如出現長黑帶量才是歐印時機

## 📈 技術面分析與操作策略

### 台幣升值與台股的歷史關係

#### 明漢的歷史數據研究
- **核心結論**: 台幣升值 → 台股上漲（千古不變）
  - 台幣升值期間，外資資金流入，推升股市
  - 台幣貶值期間，股市不但不漲反而下跌
- **匯損不會打敗股市**: 歷史上沒有一次匯損能戰勝股市漲幅
  - 2017年、2020年台幣升值期間，整體企業獲利確實因匯損下滑2%
  - 但同期股市仍大幅上漲

#### 升值期間的板塊分化
- **上游半導體（高毛利）**: 獲利受匯損影響僅0.3%，股價漲幅27%
- **下游零組件（低毛利）**: 獲利受匯損影響達7.6%，股價漲幅不到5%
- **結論**: 高毛利族群是台幣升值期間的王者

#### 推薦方向：高毛利 + 外資買超

##### 台達電 (2308)
- **優勢**: 產品線往半導體方向移動，獲利持續走高
- **外資動向**: 近期持續買超，呈現緩慢墊高走勢
- **操作建議**: 外資大買後若上不去可能調節回壓，黑K棒+外資小賣時反而是介入點
- **目標價**: 緩步墊高，不設急漲目標
- **停損點**: 跌破短期均線支撐

##### 全網 (MoTC相關)
- **優勢**: 軟體公司，毛利率極高（軟體賣出後幾乎無成本），獲利持續上攻
- **外資動向**: 持續買超
- **股價特性**: 黏稠但穩健，大跌機率不高，整理後有轉強機會
- **目標價**: 整理完畢後看新高
- **停損點**: 跌破近期整理區間低點

##### 信邦 (3023) / 打心彩料
- **優勢**: 產品線往半導體移動，獲利持續走高
- **風險**: 短線漲幅已大，外資大量買超後股價位置偏高
- **操作建議**: 踩煞車，等外資轉賣超拉回量縮後再介入
- **目標價**: 長線故事持續，不是短線標的
- **停損點**: 跌破短期均線

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **穩定幣（Stablecoin）** | 與法定貨幣（如美元）1:1掛鉤的加密貨幣，作為虛擬世界與傳統金融的橋樑 |
| **USDT（泰達幣）** | 由 Tether 公司發行的穩定幣，目前市占率最高 |
| **USDC** | 由 Circle 公司發行的穩定幣，已在那斯達克上市 |
| **GENIUS 法案** | 美國參議院通過的穩定幣監管法案，要求1:1美元資產擔保 |
| **國庫券（T-Bill）** | 美國政府發行的短天期債券（通常1年以下），風險極低 |
| **貨幣市場基金** | 投資短天期債券與貨幣工具的基金，類似高利活存 |
| **長天期美債** | 10年、20年、30年期美國國債，對利率與通膨敏感 |
| **0050 分割** | 元大台灣50 ETF 進行股份分割，面額不變但股數增加、每股價格等比例降低 |
| **高毛利族群** | 毛利率較高的產業（如半導體、軟體），較能抵禦匯損衝擊 |
| **匯損** | 因外幣匯率變動造成的帳面損失，台幣升值時出口企業面臨匯損 |
| **贈與稅** | 財產無償移轉時課徵的稅款，以公告現值而非市價計算，每人每年免稅額244萬元 |
| **房地合一稅** | 出售不動產時，以實際成交價減去取得成本後的獲利課稅，稅率依持有時間而定 |
| **公告現值** | 政府公告的土地與房屋價值，通常低於市價，用於計算贈與稅、遺產稅等 |
| **預告登記** | 在不動產上設定的保護措施，防止所有權人擅自移轉或設定抵押 |
| **婚後財產（剩餘財產分配）** | 婚後雙方各自取得的財產，離婚時差額較少者可向另一方請求分配，但繼承或贈與取得者不列入 |
