## 💼 產業分析與投資建議

### 主題一：AI 眼鏡（AR 智慧眼鏡）

**產業概況**:
- CES 展中 AI 眼鏡成為新亮點，各大廠紛紛投入
- 取代手機部分功能：即時翻譯、AI 問答、眼球追蹤
- 將 VR 的功能輕量化至眼鏡形態
- Micro LED 產值預計四年內超過 11 倍成長
- Meta 已公布 AI 眼鏡搭配極限系路製程

**受惠個股分析**:

| 股票代號 | 股票名稱 | 產業定位 | 收盤價 | 分析重點 | 評級 |
|---------|---------|---------|--------|---------|------|
| 創新板 | 錼創 | Micro LED 量產 | - | 全球唯一可量產 Micro LED 晶片，巨量移轉技術領先，獲利模式類 IP 堆疊式 | 🟢 |
| - | 達曼 | 透明 PI / 數位影像 | 58.8 | 台灣最大 PM 廠，已與 Meta AI 眼鏡合作，眼球追蹤技術，底部剛突破出量 | 🟢 |
| - | 佳凌 | 光學鏡頭 | ~57 | 鏡頭供應商，今年出貨機種倍增，本益比僅 10 倍，年線附近均線剛翻揚 | 🟢 |
| - | 新普 | 電池 / BPU | - | AI 眼鏡需電池 + BPU 雙題材，底型態打完有機會挑戰前高 | 🟢 |

**操作建議**:
- AI 眼鏡屬於「新題材 + 底部型態」的最佳組合，股價尚未充分反映
- 與機器人、自駕車等已漲一年的題材不同，反應幅度相對較小
- 達曼突破盤整區出量為買進訊號，佳凌年線附近可布局

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| CES | Consumer Electronics Show，消費電子展，每年 1 月在美國拉斯維加斯舉行 |
| GTC | GPU Technology Conference，NVIDIA 年度技術大會，通常在 3 月舉行 |
| BPU | Battery Protection Unit，電池保護單元，伺服器備用電池關鍵元件 |
| BBU | Battery Backup Unit，備用電池模組，資料中心不斷電系統核心 |
| Micro LED | 微型發光二極體，次世代顯示技術，適用於 AR 眼鏡等小型裝置 |
| 巨量移轉 | Micro LED 製程關鍵技術，將大量微型 LED 晶片精準轉移至基板 |
| 三角形收斂 | 技術分析型態，股價高點下降、低點上升形成三角形，突破方向決定趨勢 |
| 乖離率 | 股價與均線的偏離程度，過大時容易出現回檔修正 |
| GB300 | NVIDIA 下一代 AI 伺服器架構，預計搭載 BPU 為標準配備 |
| 諾弗圖法案 | 美國針對華為壟斷的法案，將訂單釋放給非華為供應商 |
