## 市場總體觀察

### 日本央行升息深度解讀

**升息四大重點**:
1. 明年圈鬥（日圓）恐怕還會大幅調行，現在是升息時機
2. 為實現 2% 通膨目標，利率不得不往上調
3. 即使升息，金融環境目前還是很寬鬆
4. 經濟慢慢復甦有眉目

**中性利率**: 日央表示約在 1%-2.5% 之間，目前 0.75% 仍有很大升息空間

**為何日圓反而貶值**:
- 市場解讀為鴿派升息，預期半年後才會再升一次
- 套利交易資金沒有立即回補日圓的壓力
- 類似「利多出盡」效應：期待時已漲完，實現時反跌

### 2026 年全球資金大趨勢

#### 美國必須美元貶值的三大原因

1. **38 兆美元天量國債**: 美元貶值等於實質債務減輕
2. **AI 基礎建設投資需求**: 借錢成本需降低，必須大幅降息
3. **長期高利率副作用**: 經濟出現疲態，老百姓苦不堪言。有分析指出若無 AI 投資，美國經濟成長率為負

#### 聯準會預期操作路徑

| 階段 | 措施 | 說明 |
|------|------|------|
| 已執行 | 連續降息三次 | 利率降至 3.5%-3.75% |
| 本月起 | 停止 QT | 結束縮表 |
| 進行中 | APP（買短債） | 每月對銀行端注入 400 億資金 |
| 未來可能 | 真正 QE（買長債） | 換了新聯準會主席後可能實施，會改變資產價格 |

> **熊老師關鍵區分**: APP（買短債）不會改變資產價格；真正 QE（買長債）才會推升債券、MBS、股票等所有資產價格。

#### 日本必須升息的原因

1. **CPI 連續 45 個月超過 2%**: 通膨不是暫時的，已持續三年多
2. **薪資物價螺旋性上升**: 與兩年前聯準會升息的主因相同
3. **停止 YCC 政策**: 不再無限量印鈔買 10 年期債券壓低利率
4. **粗步賣出日股 ETF**: 央行逐步退出對股市的支撐
5. **環步升息至中性利率**: 預計半年升一次（0.75→1.0→1.25→1.5...）

#### 美元霸權動搖的風險

- **聯準會獨立性受質疑**: 若聯準會服從政治目的（川普要求降息），市場將不信任美國貨幣政策
- **1970 年代博恩斯教訓**: 當時聯準會主席博恩斯服從尼克森降息要求，從 5% 降至 3.5%，引發超大通膨延續 5.6 年，最後靠保羅沃爾克將利率升至 20% 才壓下
- **高通膨可能捲土重來**: 美國經濟還不錯卻持續降息，只為政治目的，可能重蹈覆轍

### 對台灣市場的影響

**正面效應**:
- 美元貶值 → 亞洲新興市場貨幣升值 → 外資大舉流入（可能買個五百、一千億）
- 黃金、比特幣作為美元替代品將走強
- 大宗商品以美元計價，美元貶值時商品價格上漲
- 日圓套利交易誘因降低，全球流動性風險下降

**隱含風險**:
- 日元升值將衝擊日本外銷產業（Uniqlo、Sony、Toyota）
- 日本財政利息支出將被大幅推升
- 美國若過度降息可能引發通膨捲土重來

## 產業分析與投資建議

### 一、鴻海（2317）- 趁外資放假打底

**基本面**:
- 11 月營收年增 25.5%，為過去 11 月新高、全年度歷史次高
- 業績完全沒問題，跌的原因是外資 11 月起的大賣
- 美國政府創世紀計畫（AI 國家級資產）為長期支撐

**籌碼面**:
- 借券餘額最近都是低點標示，外資沒有借來賣
- 借券賣出沒有明顯恢復，下跌機率不高

**技術面**:
- 今日出現向上多方缺口，止跌訊號
- 外資前面賣很多，但股價僅回到特定支撐位，未跌到前低

**操作建議**:

| 項目 | 內容 |
|------|------|
| **進場價** | 222 元以下都是買點 |
| **策略** | 趁外資放假期間內資推升打底，等外資 1 月回來推動上漲 |
| **目標** | 布計老師演講時觀眾預期 300-400 元，「連睡著都會笑」 |
| **風險** | 若 AI 泡沫疑慮擴大，需重新評估 |

### 二、台積電（2330）- 用時間換空間

**基本面**:
- 2 奈米領先三星、背英特爾，技術面無人能追
- 法人預估明年 EPS 約 78-80 元，後年挑戰 100 元
- 本益比 20 倍 = 股價 1,600 元；25 倍 = 2,000 元；後年賺百元 = 2,500 元

**技術面**:
- 跌破季線三天未站回，但 1,400 元位置不跌破就不必擔心走空
- 季線開始要扣高，即將走平，在季線上下屬正常波動
- 定期定額買盤（成股族）為長期支撐力量

**操作建議**:

| 項目 | 內容 |
|------|------|
| **長線進場** | 現價抱得住就長線佈局，一定有好回報 |
| **短線進場** | 1 月 1 日前接近 1,400 或季線附近為買點 |
| **最大支撐** | 1,390 元（判斷不太會到） |
| **策略** | 趁外資進出量變少時買入，等 1/15 法說會催化 |
| **注意** | 紅包行情期間台積電表現可能不如中小型股過癮 |

### 三、記憶體族群 - 基本面無虞，首選顆粒廠

**美光財報亮點**:
- 預估 Q4 營收 187 億（市場僅估 170 多億）
- EPS 漲幅驚人，達 8.4 元（市場估約 4 元多）
- 毛利率變態高達 67%-68%
- 缺貨將延續到 2026 全年

**筆電漲價效應**:
- 戴爾已開第一槍漲三成
- 華碩一台好像要漲三千以上
- 接下來可能快速三萬（電腦均價）
- 結構性缺貨現象，嚴重影響下游

**操作策略**:

| 優先順序 | 股票 | 理由 |
|----------|------|------|
| **首選** | 南亞科（2408）| 下週解除處置放出，美光關係緊密；前高在眼前，開盤可能直接過 |
| **首選** | 華邦電（2344）| 已過高走樓梯式上漲；週一可能被關處置，資金轉移效應 |
| **觀察** | 群聯（8299）| 本益比不高，底部時間比頭部長，139 元一定過 |
| **暫緩** | 模組廠（威剛等）| 低價庫存用完後新進貨成本變貴，毛利受限；先做顆粒漲一大段後再回頭看模組 |
| **跟班** | 力積電、旺宏 | 獲利能力與顆粒廠差距大，非首選 |

**記憶體關鍵判斷**:
- 問題絕對不在基本面，而是籌碼與市場追價意願
- 本益比尚未落到時輩（8 倍以下），都還安全
- 「翹翹板效應」：南亞科被處置時資金流向華邦電，反之亦然

## 法律專題：遺囑修改注意事項

### 案例概要
大地主爸爸寫了第一份遺囑（大兒子分較多），後改為第二份遺囑（均分），但第一份遺囑日期被多次塗改，導致兄弟對簿公堂。

### 關鍵法律要點

1. **遺囑以最新日期為準**: 兩份遺囑相互抵觸時，以時間較晚者為準
2. **塗改必須補簽名**: 法律規定修改處需標明位置、增減字數，並重新簽名
3. **自書遺囑三要件**: 自出遺囑全文、記明年月日、親自簽名
4. **日期格式**: 千萬不要寫「中華民國」混用西元年，避免爭議
5. **重要內容建議重寫**: 避免塗改爭議，重寫比修改更安全
6. **可錄影存證**: 證明意識清楚、自願簽名、無人逼迫
7. **不動產遺囑建議公證**: 具有更高公信力，辦過戶時不會被質疑
8. **公證遺囑 vs 自書遺囑**: 效力相同，都以時間為準（非公證較大）

## 名詞解釋

| 名詞 | 說明 |
|------|------|
| **YCC（殖利率曲線控制）** | 日本央行過去的政策，透過無限量買入債券將長期利率壓在接近零的水準 |
| **QE（量化寬鬆）** | 央行購買長期債券向市場注入資金，會推升資產價格 |
| **APP（資產購買計畫）** | 央行購買短期債券，注入流動性但不直接改變資產價格 |
| **QT（量化緊縮）** | 央行縮減資產負債表，減少市場流動性 |
| **CDS（信用違約交換）** | 債券的「保險」，CDS 價格升高代表市場擔憂該公司違約風險增加 |
| **中性利率** | 既不刺激也不抑制經濟成長的利率水準，日央估計為 1%-2.5% |
| **套利交易逆轉** | 當日圓升息導致借日圓的成本增加，套利交易者被迫回補日圓部位 |
| **處置股** | 因股價異常波動被證交所列入處置的股票，交易受到限制 |
| **自書遺囑** | 由立遺囑人親筆書寫全文、記明日期並簽名的遺囑形式 |
