## 📊 技術面教學精華

### 破底翻三情境操作口訣

```
情境一：低檔出量 → 三日不破低 → 設低點停損 → 風險有限希望無窮
情境二：巨量長黑 → 三日內過高 → 換手成功 → 拉回找買點（勝率90%）
情境三：終極戰爆量 → 一步二看三準備 → 守低檔收盤價 → 賺魚的身體
```

### 二刀流選股法

```
日線四要件：X線打到 + 量縮1/4~1/5 + 留下影線紅K + KD在50以下
周線三要件：右肩帶量 + 長紅突破 + 回測成功
結合：日周線同時符合 = 高勝率轉強訊號
```

### 財報前力股篩選

```
四大條件：主流族群 + 營收雙增（季增年增>18%） + 毛利率雙升 + 線型準備突破
關鍵：提前用公開資料分析，不追已噴出個股
```
