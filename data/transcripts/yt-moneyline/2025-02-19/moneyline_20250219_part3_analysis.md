## 📈 美股風險分析 - 停滯性通膨警告

### 諾貝爾經濟學獎得主警告

**發言人**: Joseph Stiglitz（2001年諾貝爾經濟學獎得主）

**核心觀點**: 美國正成為一個很可怕的投資區域，可能引發停滯性通膨

#### 四大危險因素

| 風險 | 說明 |
|------|------|
| 1. 關稅政策不確定性 | 川普政策反覆無常，一下要徵一下不徵 |
| 2. 法規與企業保障 | 大量解僱政府員工、取消合約、DOGE部門裁減開支 |
| 3. 通膨風險 | 關稅推升物價，GDP中政府支出減少 |
| 4. 貿易報復 | 加拿大等國反擊25%關稅，貿易壁壘升高 |

#### DOGE效應（政府支出減少）
- GDP構成：民間支出 + 企業投資 + 政府支出 + 進出口
- 政府支出大幅減少 → GDP可能下掉
- 大量解僱聯邦員工
- 取消政府合約 → 供應商損失慘重

#### 停滯性通膨定義
- **經濟停滯**: GDP成長放緩或衰退
- **通膨升高**: 物價持續上漲
- **最難解決**: 降息會加劇通膨，升息會加劇衰退
- **美國上次**: 很久未遇到停滯性通膨

### 美國消費者信用風險

#### 信用卡嚴重逾期率
- 達到11.35%，為2010年以來新高
- 循環預約（循環利息）年增幅度不正常

#### 車貸嚴重逾期率
- 持續往上增加
- 汽車銷售下滑拖累零售銷售數據

#### 學貸
- 疫情後政府補助學貸，暫不公布
- 2025年Q1開始公布，可能大幅攀升

#### 關鍵訊號
- 信用卡違約與車貸爆掉 → 牽扯金融機構與零售銷售市場
- 零售銷售意外大幅減少
- 第一季GDP表現可能不佳

### 巴菲特觀點
- 股市持續創新高，但巴菲特一直在賣股
- 13F報告顯示持續減碼
- 認為股價已偏離合理價格
- 不代表一定是空頭，但越來越需要謹慎

### 投資建議
- **短期**: 多頭仍在，S&P 500不破5,923可做多
- **中期**: 注意高檔磨頂訊號（創高間隔拉長）
- **風險控管**: 高檔適度調節，考慮拉回較大的商品或已相對低位的內股
- **對策**: 不局限美股，選擇相對低位的內股或大宗商品

## 📚 名詞解釋

### 經濟術語

**停滯性通膨 (Stagflation)**
- 定義：經濟成長停滯同時通膨升高的現象
- 特徵：高失業率 + 高物價 + 低經濟成長
- 難解：降息 → 通膨更嚴重；升息 → 經濟更衰退
- 歷史：1970年代美國曾經歷嚴重停滯性通膨

**GDP (國內生產毛額)**
- 定義：一國在特定時期內所有最終商品與服務的市場價值
- 組成：民間支出 + 企業投資 + 政府支出 + 淨出口
- 意義：衡量經濟成長的主要指標

**對等關稅 (Reciprocal Tariffs)**
- 定義：根據對方國家對本國課徵的關稅稅率，課徵相同比率的關稅
- 川普政策：宣布但尚未完全執行，反覆不定
- 影響：推升物價、引發貿易報復

**DOGE (Department of Government Efficiency)**
- 定義：馬斯克主導的政府效率部門
- 目標：精簡政府開支、減少浪費
- 爭議：大量解僱聯邦員工、取消政府合約

### 技術分析術語

**KD指標過熱區**
- 定義：KD值在80以上的區域
- 意義：短線漲多，上漲勝率開始下降
- 操作：資金需分批佈局，不宜全壓

**日KD交叉向下**
- 定義：K值由上向下穿越D值
- 意義：短期轉弱訊號
- 應用：在此訊號出現前維持多方持股

**三角形收斂**
- 定義：股價高低點逐漸收窄形成三角形
- 突破方向：出量那一天即為未來趨勢
- 量能觀察：收斂期間量縮為正常，突破時需帶量

### 財報術語

**三率三升**
- 定義：毛利率、營業利益率、稅後淨利率三者同步上升
- 意義：公司經營效率全面改善
- 應用：優質成長股的重要指標

**Low DK (低介電常數)**
- 定義：波銅板材料的電氣特性參數
- 用途：減少高頻信號傳輸中的耗損與延遲
- 世代：Low DK → Low DK2 → Low DK3（越新越好）
- 重要性：AI高速運算的關鍵材料

**13F報告**
- 定義：美國SEC規定管理超過1億美元資產的機構投資者每季度申報的持股報告
- 代表人物：巴菲特（波克夏海瑟威）
- 觀察重點：大咖增減碼方向
