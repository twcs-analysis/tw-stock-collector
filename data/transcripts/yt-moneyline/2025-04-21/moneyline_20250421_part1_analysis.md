## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| 垃圾時間 | NBA比賽中，領先方已大幅領先，雙方不再全力攻擊的時段。比喻目前台股主力股不動、僅中小型股有表現的盤面 |
| 微笑曲線 | 分批投入策略中，從高點往下買到低點再往上的過程形成微笑形狀，平均成本低於高點 |
| 對等關稅 | 川普政府對各國課徵的報復性關稅，90天緩衝期內各國需與美國談判 |
| 關稅缺口 | 4月7日因關稅恐慌而跳空下跌形成的技術性缺口，是否回補為多空關鍵指標 |
| DDR5 | 第五代雙倍資料速率記憶體，AI應用提升帶動需求增長與漲價趨勢 |
| AP8 | 台積電先進製程廠區編號，位於新竹科學園區 |
| 急單 vs 長單 | 急單指短期搶貨的一次性訂單；長單指持續性的長期訂單 |
| 美元指數 | 衡量美元對一籃子主要貨幣匯率的指標，98.29為三年新低 |
