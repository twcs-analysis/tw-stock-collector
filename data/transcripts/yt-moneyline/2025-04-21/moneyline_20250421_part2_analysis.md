## 🌍 市場總體觀察

### 美中關稅最新發展

#### 美國策略升級
- 外媒報導美國對中國的關稅（100%、200%）只是「起手式」
- 最新策略：拉攏各國限制對中國貿易交易，換取關稅優惠
- 白宮特別設置緊急工作小組處理供應鏈斷鏈危機（準備美中全面脫鉤）

#### 中國回應
- 稱美國此舉為「國際經濟霸凌」，堅決採取反制措施
- 雙方都不想談判：美國認為中國過去承諾未履行，中國認為條款全是懲罰性質

#### 中國歷年承諾未履行清單
- 2001年加入WTO的入世承諾未遵守
- 2016年承諾全面開放市場（含匯率開放）未做到
- 2015年答應南海島礁不軍事化，實際已軍事化
- 2018年答應川普管制芬太尼，未管制
- 2020年第一階段貿易協議（禁止侵害智慧財產權、開放市場、對美採購2,000億美元）未履行

### 川普政策核心邏輯

1. **改善美國雙赤字**（貿易赤字 + 財政赤字）
2. **嚴查洗產地**: 中國產品透過第三國轉口至美國
3. **各自獨立不護換**: 關稅、投資、管制一碼歸一碼
4. **終極目標**: 重組國際經濟與安全秩序、削弱中國實力
5. **四管齊下**: 軍事圍堵、外交孤立、科技封鎖、經濟脫鉤

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| 洗產地 | 中國產品先運至第三國（如越南），貼上該國標籤後出口至美國，規避關稅的行為 |
| 雙赤字 | 指美國同時存在的貿易赤字（進口大於出口）與財政赤字（政府支出大於收入） |
| 第一階段貿易協議 | 2020年美中簽署的協議，中國承諾禁止侵害智慧財產權、開放市場、對美採購2,000億美元商品 |
| SOC | Security Operation Center，資安戰略中心，提供7x24全天候監控，即時偵測回應駭客攻擊 |
| SEMI E187 | 國際半導體設備資安標準，要求設備通過資安驗證方可採購 |
| 廣場協議 | 1985年五國在紐約廣場飯店簽署的協議，要求日圓大幅升值，導致日本泡沫經濟 |
| T1級供應商 | 直接供貨給品牌原廠（如波音、空巴）的第一層供應商，門檻最高 |
| C919 | 中國自製大型客機，但關鍵零組件（引擎等）仍依賴美歐供應商 |
