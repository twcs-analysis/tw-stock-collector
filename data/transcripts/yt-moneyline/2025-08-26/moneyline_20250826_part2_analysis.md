### ADX指標教學 — 量大人氣股進出場判斷

#### ADX原理

- **全名**：平均動向指數（Average Directional Index）
- **功能**：衡量趨勢強度，**不分多空方向**
- **數值**：大漲或大跌時ADX都會上升
- **位置**：通常在DMI指標內找到

#### 進場訊號

- **ADX從低檔突破20**：趨勢轉強，為進場時機
- **搭配+DI/-DI**：+DI在上方為做多確認

#### 出場訊號

- **ADX高檔回落**：趨勢減弱
- **+DI與-DI死亡交叉**：考慮獲利了結

#### 個股ADX檢視

| 個股 | ADX位置 | 多空方向 | 現在追高？ | 操作建議 |
|------|---------|----------|------------|----------|
| **神達** | ~60（高） | 偏多 | 是追高 | 等黑棒高點突破再進場，不建議放空 |
| **嘉士達** | ~30-40（不高） | 偏多 | 不算追高 | ADX尚低，追入風險較小，等黑棒高點突破 |
| **真頂** | ~70（極高） | 偏多 | 是追高 | 有燈就爆，追入須手腳快 |
| **金居** | 高但往下彎 | 偏多 | 是追高 | ADX往下彎但偏多，觀察後續變化 |
| **東元** | 高 | 偏多 | 是追高 | 不建議現在追，等黑棒高點突破 |
| **中光電** | 往下彎 | 偏多 | 是追高 | ADX往下彎，續航力可能減弱，需留意 |

#### 操作原則總結

1. **追高型**（ADX高）：等最後一根黑K棒高點被突破再進場
2. **非追高型**（ADX低）：可積極進場
3. **不放空**：只要+DI仍在-DI上方，不建議放空
4. **ADX下彎**：趨勢可能暫停，續航力減弱

## 📋 投資策略總結

### 短線策略

1. **外資態度偏中性**：現期合計賣超200多億，下半週台股大漲機率降低。中小型股輪動為主。
2. **ADX指標運用**：對於量大人氣股，用ADX判斷是否追高。ADX高者等黑棒突破再追，ADX低者可積極進場。
3. **分盤風險**：康配等分盤股短線避開，等分盤後半段再找機會。

### 中線策略

1. **矽光子**：9月台積電OIP論壇 + 半導體展為催化劑，矽光子族群可提前佈局。

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **ADX（平均動向指數）** | Average Directional Index，衡量趨勢強度的技術指標，不分多空方向。數值越高代表趨勢越強。通常以20為分水嶺 |
| **+DI / -DI** | 正向/負向動向指標，+DI在-DI上方為多方，反之為空方。搭配ADX使用判斷趨勢方向 |
| **P/C Ratio** | Put/Call Ratio，賣權與買權的比值。大於100代表市場偏多 |
| **分盤交易** | 證交所對漲跌幅過大的股票實施的交易限制措施，限制每5分鐘撮合一次 |
| **ABF載板** | Ajinomoto Build-up Film，味之素增層膜載板，用於高階IC封裝 |
| **Scale Across** | 輝達新技術，將不同地點的資料中心串聯，實現跨區域算力調配 |
| **OIP** | Open Innovation Platform，台積電開放創新平台，整合IC設計、EDA、封裝等生態系 |
| **矽光子** | Silicon Photonics，以矽基材料實現光電整合的技術，可大幅提升資料傳輸速度 |
| **CSP** | Cloud Service Provider，雲端服務供應商（如AWS、Google、微軟等） |
| **黑棒高點** | 技術分析中最後一根下跌K棒的最高價，被突破時為進場訊號 |
| **土洋對作** | 外資與投信買賣方向相反的現象 |
| **乖離率** | 股價偏離均線的百分比，過大時有回調壓力 |
