### 四、合約負債選股法（慶龍分析）

#### 核心概念

- **合約負債** = 客戶預付的訂金/預收工程款/預收備料款
- 列於資產負債表的**流動負債**科目
- 未來將以商品與服務形式實現，反映在**未來營收**
- 流動合約負債大約反映在**兩季後的營收**
- 為**財報領先指標**

#### 選股條件

1. 今年Q2合約負債較去年Q2增加金額佔股本比例 > 80%
2. 今年Q2合約負債總額佔股本比例 > 140%
3. 近四季EPS計算之本益比 < 20倍
4. 排除近四季EPS虧損及櫃外股票

#### 精選五檔

| 股票 | 合約負債增加佔股本比 | 合約負債總佔股本比 | 本益比 |
|------|---------------------|-------------------|--------|
| 寬宏藝術（6596） | 371% | 499% | 17.4倍 |
| 華漢（1414） | 221% | 1,198% | 14.2倍 |
| 三洋時間（營造） | — | — | 47.3倍（偏高） |
| 得唱（營造） | — | — | 7.7倍 |
| （第五檔本益比超過20倍已剔除） | — | — | — |

#### 驗證案例

- **漢唐（2404）**：Q1合約負債303億，佔股本1,598%，5月時股價約500元，半年後股價翻倍至1,065元

## 📋 投資策略總結

### 短線策略

1. **輝達財報前**：觀望為主，不宜追高。關注毛利率是否回升至76%以上，及第三季展望是否達520億美元。
2. **拉回找買點**：利用財報前的震盪拉回，在台積電、鴻海等核心標的找進場機會。
3. **健康輪動**：昨天大型股強、今天櫃買強，輪動健康有利於行情延續。

### 中線策略

1. **合約負債選股**：透過財報中合約負債的變化，提前佈局未來營收成長股。
2. **機器人主題**：輝達Thor平台合作夥伴為中長線趨勢，研華、一詮、廣明等值得持續追蹤。
3. **漲價循環**：景碩等高階載板/通孔受惠於漲價大循環，為長線佈局標的。

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **KD黃金交叉** | K線由下往上穿越D線，為技術面買進訊號 |
| **合約負債** | 企業已收取客戶預付款項但尚未提供對應商品或服務的負債科目，可視為未來營收的領先指標 |
| **GB300** | 輝達下一代AI伺服器平台，功率需求大幅提升 |
| **Rubin系列** | 輝達下世代AI晶片架構，包含CPU/GPU等6款新產品 |
| **Thor** | 輝達推出的新一代機器人大腦平台，算力為前一代Orin的7.5倍 |
| **VLM/VAM** | 視覺語言模型/視覺動作模型，讓機器人具備看到即思考的能力 |
| **TFLOPS** | 每秒浮點運算次數（兆次），衡量處理器運算能力的單位 |
| **矽光子** | 以光訊號取代電訊號的半導體技術，用於提升資料傳輸速度 |
| **背鑽機** | 用於多層PCB的後鑽孔製程，去除多層堆疊產生的雜訊干擾 |
| **CCL** | Copper Clad Laminate，銅箔基板，為PCB的關鍵材料 |
| **ASP** | Average Selling Price，平均售價 |
| **流動負債** | 一年內需清償或實現的負債項目 |
