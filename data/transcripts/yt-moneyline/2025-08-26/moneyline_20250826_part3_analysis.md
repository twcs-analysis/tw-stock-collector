## 💼 產業分析與投資建議

### 一、勞保與勞退理財規劃（慶龍分析）

#### 勞保三大陷阱

| 陷阱 | 說明 |
|------|------|
| **忘記申請**（時效問題） | 勞保所有給付有5年追溯期限，過期即喪失權利 |
| **單身/無子女**（無受扶養遺屬） | 繳一輩子的勞保，身故後全數充公（無繼承人） |
| **職場轉換中斷** | 勞保中斷期間發生意外，無法獲得傷病或死亡補助 |

#### 勞保 vs 勞退比較

| 項目 | 勞保 | 勞退 |
|------|------|------|
| 性質 | 基金制（共同帳戶） | 個人專戶 |
| 破產風險 | 有（高齡化少子化） | 無（你的就是你的） |
| 領取方式 | 活到老領到老 | 累積金額 ÷ 平均餘命 |
| 法定請領年齡 | 64歲（可提早5年至59歲） | 60歲 |
| 提早領 | 每提早1年減4%，提早5年打8折 | — |
| 提撥 | 勞工20%、雇主70%、政府10% | 雇主強制提撥薪資6% |

#### 月薪三萬的退休金試算

| 方案 | 提撥比例 | 65歲退休金 | 每月可領 | 所得替代率 |
|------|----------|------------|----------|------------|
| **僅雇主提撥** | 6% | 427萬元 | 21,649元 | 43.12% |
| **雇主+自提** | 6%+6%=12% | 854萬元 | 43,298元 | 86% |
| **差額** | — | **+427萬元** | **+21,649元** | — |

#### 試算假設條件

- 個人工資：30,000元
- 退休金投資報酬率：5.69%（過去10年勞退平均）
- 個人工資成長率：2%
- 工作年資：40年
- 預估平均餘命：23年

#### 自提6%的三大優勢

1. **節稅效果**：自提金額可列為年度所得扣除額（如月提9,000元，年省96,000元稅基）
2. **低風險**：政府委託專業機構操作，長期報酬穩定
3. **長期累積**：複利效應下，40年可累積可觀退休金

> **結論**：自提6%為退休金核心策略。若有餘力，搭配0050等ETF投資可進一步提升總報酬。

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **勞保** | 勞工保險，採基金制，全體勞工共同繳納，活到老領到老。法定請領年齡64歲，可提早5年（59歲），但每提早1年減4% |
| **勞退** | 勞工退休金，個人專戶制。雇主強制提撥薪資6%，勞工可自願加提最多6%。60歲可開始領取 |
| **所得替代率** | 退休後每月可領金額佔退休前薪資的比例，一般建議達70%以上 |
| **平均餘命** | 統計上某年齡群體預期還能存活的年數。目前台灣國人平均餘命約80歲（男77歲、女84歲） |
| **九條好漢** | 節目中選出的9檔AI核心持股，以投信持股200張以上且營收表現佳為條件篩選 |
| **探針卡** | Probe Card，用於晶圓測試的關鍵設備，將測試訊號傳送至晶片進行電性測試 |
| **RTX 50** | NVIDIA最新一代消費級顯示卡系列，帶動PC電源供應器需求 |
| **CPO** | Co-Packaged Optics，共封裝光學，將光收發模組與交換器晶片共同封裝的技術 |
| **小旺矽** | 旺矽的小型期貨合約，讓散戶以較少資金參與千金股的漲跌 |
