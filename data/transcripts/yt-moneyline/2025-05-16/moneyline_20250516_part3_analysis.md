## 🌍 市場總體觀察

### 台幣匯率深度分析

#### 台幣升值現況
- **近期走勢**: 連續三天再度升值，又逼近30元關卡
- **上週低點**: 一度觸及29.59元
- **央行動態**: 天天掛外匯交易室美元賣單，試圖控制升值速度
- **在岸 vs 離岸**: 央行僅能控制在岸市場（台北外匯中心），離岸市場（NDF）曾出現28.9~29元，甚至傳出26元多的報價（為錯帳）

#### 台幣升值的驅動因素
1. **國際趨勢**: 美元走弱，非美貨幣全面升值
2. **台灣特殊壓力**: 美國認為台灣貨幣被低估，可能成為貿易談判條件
3. **對等關稅與半導體關稅**: 均尚未公布，匯率可能是談判籌碼
4. **歷史經驗**: 2016~2018年台幣升值持續約兩年，本次才升兩個月

#### 台幣升值影響評估
- **正面**: 熱錢進場推升台股、購買力提升、進口原料成本降低
- **負面**: 電子業出口匯損、金融業美元資產帳面縮水
- **建議**: 緩升有利、急升有害

### 全球匯率與投資幣別策略

#### 今年全球匯率變化
- **美元**: 全面走弱（與去年完全相反）
- **台幣**: 今年升值幅度達3.78%以上
- **主要升值時間點**: 集中在4月及5月

#### 基金幣別選擇 — 核心觀念

**關鍵原則**: 計價幣別 ≠ 投資幣別
- 用台幣買美元計價基金 → 贖回時強制換回台幣，匯率風險跑不掉
- 用美元買美元計價基金 → 贖回時拿回美元，可自行選擇換匯時機

**今年實證（各市場基金）**:

| 市場 | 美元計價報酬 | 台幣計價報酬 | 差距 |
|------|------------|------------|------|
| 新興市場 | 24% | 15% | -9% |
| 拉丁美洲 | 類似差距 | 類似差距 | ~10% |
| 中國 | 88%（三個月） | 大幅縮水 | 差距極大 |
| 日本 | 最佳 | 大幅縮水 | ~10% |

**不同幣別比較（同一檔基金）**:
- 美元計價 > 歐元計價 > 台幣計價（報酬差距約10%）
- 原因：不是計價幣別強弱，而是實際投資地區貨幣對美元的關係

#### 幣別選擇實戰建議

1. **長期投資（3~5年以上）**: 買投資地區的當地貨幣
   - 投資美國 → 用美元
   - 投資日本 → 用日元
   - 投資澳洲 → 用澳幣
   - 原因：長期匯率無法預測，避免匯差風險

2. **短期操作（數月~1年）**: 買弱勢貨幣計價
   - 目前美元走弱 → 短線仍選美元計價
   - 原因：弱勢貨幣買入後換算回來較有利

3. **特殊情況**: 避免冷門貨幣（如東南亞貨幣），除非你投資該地區

4. **核心原則**: 投資境外商品一律直接用外幣進出，避免台幣進出被匯差吃掉

## 💼 產業分析與投資建議

### 低估值潛力股挖掘

#### 選股邏輯
- **條件**: 低股價淨值比、低本益比、有獲利、現金比率高、負債少
- **概念**: 「引火蟲」型態 — 暗夜中慢慢發光的股票（非跑車型爆衝）
- **風水輪流轉**: 過去兩年表現差的族群，未來可能輪到

#### 個股推薦

**1. 瑞軒（2489）**
- **特色**: 低股價淨值比、有獲利、現金比率高、負債少
- **籌碼**: 外資連續賣四天（每天約2萬張），但股價跌不下去
- **除息日**: 5月22日（下週四），殖利率約7~8%，配1元
- **策略**: 股價低檔，除息後容易填息，有填息效益保護
- **風險**: 籌碼面偏空，但技術面撐住

**2. 翰宇博（6560）**
- **特色**: 低股價淨值比、有獲利
- **4月營收**: 年成長58%
- **走勢**: 已漲回4月2日低點位置
- **結論**: 具備防禦條件（低估值 + 營收成長）

**3. 精鼎（6486）**
- **營收**: 1~4月每個月都年成長40%以上
- **客戶**: 產品提供給應用材料 → 鴻海子公司 → 台積電
- **連結**: 與三大公司（應用材料、鴻海、台積電）都相關
- **潛力**: 若台積電美國擴廠，精鼎將大幅受惠
- **注意**: 股本較小，波動可能較大

**4. 台塑（1301）— 風水輪流轉概念**
- **現況**: 前兩年表現極差
- **優勢**: 做原料較容易出口、在美國有兩個廠（不受關稅影響）、和汙泥鏈提拆
- **條件**: 低估值，若石化景氣回升將大幅受益

**5. 華新（1605）— 台幣升值概念**
- **受惠邏輯**: 主要供應台灣及大陸市場，與美國無直接關係
- **台幣升值影響**: 進口材料因台幣升值變便宜 → 毛利率提升
- **注意**: 目前處於小虧損狀態，未寫本益比
- **條件**: 若轉虧為盈，加上股價淨值比低，有大幅翻身空間

**6. 台肥（1722）**
- **竹金收錄**: 目前約25億，未來預估可達45億
- **股本**: 約9億
- **潛力EPS**: 竹金收錄45億 ÷ 股本 ≈ 4~5元
- **估值**: 目前股價淨值比低
- **賣點**: 新竹、南港等地房屋建案收入

### 資產股 — 台幣升值概念

#### 士電（1503）籌碼分析

- 部分為「士林概念股」（輝達總部傳言）

### 短期策略（1-2週）

1. **台幣升值概念**: 資產股（士電、台活、新紡）、內需股仍有動能
2. **航運股**: 萬海、長榮大戶持股高，但追高風險大，盤中回檔找買點
3. **低估值防禦股**: 瑞軒（5/22除息填息）、翰宇博（營收成長58%）
4. **電腦展前布局**: AI相關族群未提前拉高，展場題材有發酵空間

### 中期策略（1-3個月）

1. **基金幣別**: 投資境外一律用外幣進出，美元計價仍為首選
2. **台幣升值長期趨勢**: 若持續升值兩年（參照2016~2018年），內需/資產股長期受惠
3. **風水輪流轉**: 台塑、華新等低估值傳產股，石化景氣回升時有翻身機會
4. **精鼎（6486）**: 與台積電、應用材料、鴻海三大客戶連結，擴廠受惠

### 風險評估

| 風險因素 | 影響程度 | 說明 |
|---------|---------|------|
| 離岸台幣狙擊 | 高 | 央行管不到NDF市場，若離岸急升將迫使在岸跟進 |
| 對等關稅公布 | 高 | 尚未公布，可能衝擊出口企業 |
| 半導體關稅 | 高 | 若公布將直接影響台積電與供應鏈 |
| 航運股追高被套 | 中高 | 隔日沖賣壓 + 談判期僅90天，實質獲利有限 |
| 低估值股流動性 | 中 | 部分小型股成交量不足，進出不易 |

## 📚 名詞解釋

- **NDF（無本金交割遠期外匯）**: 離岸市場的台幣遠期合約，央行無法直接干預
- **在岸/離岸市場**: 在岸指台北外匯中心的官方交易；離岸指國際市場的交易，價格可能與在岸有差異
- **計價幣別**: 基金淨值報價所使用的貨幣，不等於實際投資的貨幣
- **IFRS 17**: 國際財務報導準則第17號，改變保險業收入認列、負債衡量與匯率處理方式
- **股價淨值比（P/B Ratio）**: 股價除以每股淨值，低於1代表股價低於公司帳面價值
- **殖利率**: 每股股利除以股價，衡量投資報酬率的指標
- **填息**: 除息後股價回到除息前的水準，代表投資人真正獲得股利收益
- **真空狀態**: 籌碼面上賣壓極少，股價上漲時幾乎沒有阻力的狀態
- **竹金收錄（租金收入）**: 公司持有不動產所收取的租金收入
- **對等關稅**: 美國對貿易夥伴課徵與該國對美課稅相同稅率的關稅政策
