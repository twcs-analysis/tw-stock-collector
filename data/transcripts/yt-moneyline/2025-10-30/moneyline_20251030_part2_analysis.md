## 📊 市場總體觀察

### 台股走勢
- **電源雙雄賣壓**: 台達電與光寶科法說會後遭外資賣超，光寶科一度逼近跌停
- **外資動態**: 外資今日賣超前五名含光寶科，第七名為台達電；但買超第一名為聯電（四萬七千多張）
- **千金股壓力**: 多檔千金股（金像電、創意、台達電）出現利多出盡的下跌走勢
- **櫃買指數**: 跌破月均線，中小型股表現疲弱

### 法說會效應
- **利多出盡現象**: 近期多家公司公布財報後，股價反應為「開高走低」或「利多出盡」
- **被動元件**: 華新科、國巨業績極佳，但股價反應冷淡
- **光寶科**: 外資看空報告加上發行120億可轉換公司債，雙重利空壓力

#### EPS預估

| 機構 | 今年EPS | 明年EPS | 後年EPS |
|------|---------|---------|---------|
| 高盛 | 64.6元 | 75.8元 | - |
| 大和 | - | - | 90.2元 |
| 瑞銀 | - | 73.5元 | 91.2元 |

- **目標價推算**: 以明年EPS 73.5元 x 20倍 = 1,470-1,500元；後年EPS 91.2元 x 20倍 = 1,800元

#### 毛利率維持高檔的關鍵 - 降本雙王牌

1. **光罩互進技術突破**: 台積電在光罩對位、材料控制、互進缺陷控制方面大幅領先三星，7奈米時代即打敗競爭對手
2. **設備成本控制**: 2奈米與1.4奈米製程不需購買4億美金的高端EUV曝光機，改用原有1-2億美金的設備即可，訂了30台
3. **競爭者無力追趕**: 三星良率仍低，Intel努力多年未見成效，日本Rapidus尚未接到訂單

#### 2奈米產能預估
- 2025年: 2-3萬片
- 2026年: 9萬片
- 2027年: 15.5萬片
- 科化市: 31.6萬片 → 最終120萬片以上

#### AI基礎建設訂單
- 數據中心訂單: 今年15GW → 2034年82GW
- 每GW建設投資約500億
- 10年平均每年3,350億市場規模
- 台積電每GW訂單約3-15億

#### 台積電共好股

| 股票 | 說明 |
|------|------|
| 日月光（3711） | 後段封裝外包持續增加，接單從19億成長至明年48億 |

| 欣興（3037） | 載板龍頭，BT載板與ABU載板漲幅9%與24% |

#### 台積電操作策略
- **買進方式**: 不設特定價位，看到就買，但務必設停損
- **停損設定**: 依個人風險承受度設定，萬一不對立即執行
- **思維轉換**: 台積電為世界級企業，估值不能用傳統標準衡量

## 📈 技術面分析與操作策略

### 台達電技術面
- 季線自起漲以來從未跌破 → 季線為多空生命線
- 若跌破季線可減碼，等低點再接回
- 目前為長多回檔，產業面沒有改變

### 光寶科技術面
- 跳空缺口為多方關鍵防線
- 缺口不補 → 整理後仍有機會向上
- 明日觀察能否量縮企穩

### 千金股警訊
- 金像電: 2,030元創新高後回落，上方壓力沉重
- 創意: 同樣高價股反應完畢
- 提醒: 本益比拉高後，一旦風吹草動跌幅會更大

### 記憶體族群操作
- 外資在記憶體股進出頻繁（今買明賣）
- 旺宏: 純主力操作，非基本面驅動
- 建議: 記憶體族群波動大，不適合穩健型投資人

## 📋 投資策略總結

### 短期（1-2週）
- 財報公布期間，利多出盡風險高，漲多股宜先獲利了結
- 電源雙雄（台達電、光寶科）為長多回檔，觀察關鍵支撐是否守住
- 千金股短線壓力大，不宜追高

### 中期（1-3月）
- 台積電為唯一值得大波段操作的標的，毛利率與獲利持續上修
- 台達電為財報三率三升中最具潛力者，回檔即布局機會
- 載板族群（南電、欣興）受惠AI封裝需求缺口，中線看好

### 風險評估
- 櫃買指數跌破月線，中小型股弱勢格局確立
- 高價千金股利多出盡風險持續
- 外資操作記憶體族群大進大出，散戶容易被割韭菜
- 台積電雖基本面強勁，仍需設停損管控風險

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| 三率三升 | 毛利率、營業利率、EPS三項指標均較前期成長 |
| 可轉換公司債（CB） | 公司發行的債券，持有人可在特定條件下將債券轉換為公司股票 |
| 季線 | 60日移動平均線，常被視為中期多空分界線 |
| EUV（極紫外光） | 極紫外光微影技術，用於先進製程晶片製造的關鍵設備 |
| DUV（深紫外光） | 深紫外光微影技術，為EUV之前的主流曝光技術 |
| 光罩（Photomask） | 晶片製造中用於將電路圖案轉印到晶圓上的模板 |
| ABF載板 | 味之素堆積膜載板，高階IC封裝使用的關鍵基板 |
| BT載板 | 雙馬來醯亞胺三嗪樹脂載板，用於記憶體等中階封裝 |
| 利多出盡 | 利好消息公布後，股價反而下跌的現象，通常因市場已提前反應 |
| 拉積盤 | 主力或法人集中買進台積電等權值股拉抬指數的操作方式 |
