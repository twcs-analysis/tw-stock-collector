## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| 年線 | 240日移動平均線，代表長期趨勢方向，跌破通常視為長期空頭訊號 |
| 本益比（PE） | 股價除以每股盈餘（EPS），衡量股票估值高低的指標 |
| 閃電崩盤 | 短時間內指數或個股劇烈下跌的現象，通常伴隨恐慌性賣壓 |
| 殖利率 | 每股配息除以股價，衡量持有股票的現金收益率 |
| 避險貨幣 | 在市場動盪時，投資人傾向持有的穩定貨幣（如日元、瑞郎） |
| 系統性風險 | 影響整體市場的風險，非個別股票可規避 |
| 下影線 | K線圖中實體下方的線段，代表盤中曾大幅下跌但被拉回 |
