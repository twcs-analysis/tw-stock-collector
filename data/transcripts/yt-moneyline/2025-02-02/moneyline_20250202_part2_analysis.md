## 🌍 市場總體觀察

### 二月份市場展望

#### 兩大主軸
1. **DeepSeek衝擊**: 二月上半月可能持續發酵，下半月若衝擊過去，利空股反彈轉利多
2. **關稅戰升級**: 川普已對加拿大、墨西哥加徵25%關稅，對中國加10%，後續可能擴大到歐盟、晶片、藥品、半導體

#### 資金面觀察
- 年前融資大幅下降、主力縮手 → 開紅盤後三大勢力回流
  1. **法人佈局股**: 年前已卡位或新方向佈局
  2. **主力歸隊**: 年前量能縮小，年後回流
  3. **融資回流**: 無法抱太多天，成本太高，為大盤助力

### 美股觀察

#### 費半指數
- 多頭氣勢被打斷：1月22日一度突破盤整區間（5,525點），但DeepSeek事件後跳空大跌
- 跌至4,776點（接近12月20日低點），若守住為假跌破 → 後續反彈
- 上週五因川普關稅消息收長上影線，賣壓較大
- **關鍵**: 費半不能再破底，否則排擠效應擴大

#### 美國經濟數據
- **PCE物價指數**: 年增率從2.4%升至2.6%，通膨壓力向上
- **就業數據**: 本週五公布，最佳情境維持4.1%左右不變
- 聯準會降息機率持續降低

### 一、柏傑老師：二月份五大選股邏輯

#### 邏輯一：短線避開但跌深後變買點

**台積電 (2330)**
- **技術面**: 明天合理跌至月線（破與不破之間），季線為極端買點
- **鐵板支撐**: 1,000元（今年支撐底線）
- **操作**: 月線反彈可觀察；若跌至季線（約跌6%），直接進場
- **買點區間**: 1,050元（月線）、1,000元（季線/鐵板）

**鴻海 (2317)** - 墨西哥概念避開但觀察
- 籌碼面不佳（年前外資未買、投信賣超）
- 觀察是否直接跌破前低 → 若守住則打出底部
- 建議等月線走平後站上再進場

**緯創 (3231)** - 相對強勢
- 有缺口支撐，回補缺口後仍有機會上漲
- 優先觀察緯創（優於緯穎）

**緯穎 (6669)** - 弱勢避開
- 封關前仍在創低 → 弱勢股
- 可能面臨2,000元保衛戰
- 短線三天不破低再進場

**CPO概念股**
- 封關前最強族群，短線避開但基本面未變
- **技術面**: 若開在月線為買點（大趨勢未變，訂單仍在）

#### 邏輯二：矽智財自主研發與軟體股

**世芯-KY (3661)**

- 技術面：10日線與20日線未跌破即偏多
- 高點有機會再過

**力旺 (3529)**
- 突破後回測，5日線未破
- 高點3,695元突破後將再創高

**M31 (6643)** -- 低檔等待
- 跌深尚未見進貨訊號
- 站上680元才代表小底完成轉強

**智原 (3035)** -- 低檔觀察
- 跌破前低後反彈，假跌破現象
- 等量能出來拉中長紅確認底部成形

**宏碁資訊 (6811)**
- 先前漲過一波後回測半年線

#### 邏輯三：低軌衛星與網通

**昇達科 (3491)**
- 美國啟動星鏈計畫，年前外資與投信同步買入
- 技術面：恩字型網上攻，拉回守住長紅低點即無問題
- **週線已漫步太空**，上方無壓力

**華通 (2313)**
- 位置較低，有機會打出W底
- 站上頸線後挑戰前高

**啟碁 (6285)** -- 首選
- 今年有新產品通過認證即將量產
- 年線測試兩次，有量出來代表換手完成
- 半年底部幾乎成形
- **本益比不貴**（約8~10倍，相對AI股便宜許多）

**中磊 (5388)**
- 過頸線且站穩在年線之上
- 股性較牛皮，拉中長紅當天不追，等兩天壓回再進場

#### 邏輯四：高殖利率概念股 -- 營建股

**核心邏輯**:
- 房地產被打房降溫，但去年建商獲利極高
- 央行12月已放完打房措施，上半年不會再有大動作
- 股價從去年8月一路跌，已充分反映利空
- 二月法說會 → 年報公佈 → 配息配多少 → 高殖利率吸引資金

**永信建 (5508)**
- 去年前三季EPS 14.6元，殖利率約10%
- 從322元跌至124元（大幅修正）
- 三五天內不再破底即可佈局小波段

**華友聯 (1436)**
- 去年前三季EPS 8.3元，配發率近七成，殖利率約10%
- 南部營建，台積電設廠帶動房市

**皇翔 (2545)**
- 殖利率10%
- 股價比永信建與華友聯強勢
- 有機會挑戰前高

**中長線觀點**: 中南部營建股可能是長線買點（台積電等大廠進駐帶動）

#### 邏輯五：消費吃喝玩樂股

**長榮航 (2618) / 華航 (2610)**
- 過年期間持續賺錢，航空股基本面最清楚
- 法人年前持續買進
- 預估今年EPS：華航約9元、長榮航快18元
- 本益比12~13倍仍有空間
- **最有機會領先站上百元**（目前90幾元）

### 二、世紀老師：法說股與BBU概念

#### IC設計法說股

**聯發科 (2454)** -- 2月7日法說
- 全球第五大IC設計公司
- 天璣9000系列手機晶片（AI功能）
- 走向客製化ASIC晶片（與輝達合作GBC個人AI超級電腦）
- 技術面：月線以上、三角收斂格局
- **判斷**: 打不到季線，月線附近可進場拼法說

**瑞昱 (2379)** -- 2月5日法說
- 網通晶片與車載晶片為主力
- WiFi 7為未來重點（裝置與雲端、雲與雲互聯）
- 技術面：打出底型後往上攻，下方有空間
- **策略**: 封底後法說加持可能轉強

#### BBU概念股

**新盛力 (4931)**
- 鋰電子模組代工99%
- GB300伺服器採用新一代M8材料的BBU廠商
- 去年全年EPS約2.5元，BBU中算績優生
- 技術面：三角收斂整理，量能逐步增穩
- **策略**: 月線站穩不測底即可佈局

**新能高 (3287)**
- 鋰電池廠，雙題材（BBU + AI智慧眼鏡）
- 多頭排列且最強勢，確認單也不低
- 技術面：一路過關斬將，量能格局佳
- **策略**: 利空測試不跌即多頭延續

#### 吃喝玩樂股

**雄獅旅遊 (2731)**
- 台灣第一品牌旅遊，去年底重開東區旗艦店
- 轉型：旅遊+餐飲服務+數位智能
- 去年前三季EPS 7.5元，訂單能見度達7~8月
- 技術面：3個月築底，量能蒸溫，站穩季線以上

**晶華飯店 (2707)**
- 飯店股股王，全方位佈局
- 金泉風旅（礁溪溫泉）+ 太魯閣晶英（花蓮，重新營業）
- 未來兩年新增5,050間房、海外開6家飯店
- 12月住房率達九成
- 去年前三季EPS 7.39元
- 技術面：站穩季線，短天期均線扭轉

### 三、記者（旗展）：DeepSeek與關稅影響

#### DeepSeek產業衝擊
- 最大恐怖：帶入速度快、不用錢、手機即可運行
- **硬體股利空**: 市場質疑是否需要這麼多硬體投資
- **軟體股利多**: 低成本AI推廣有利應用端發展
- 輝達從小年夜前高點140跌至120（-15%），缺口尚未補回

#### 關稅全面衝擊
- 已確定：加拿大、墨西哥25%，中國10%
- 即將到來：歐盟、能源（原油天然氣）、金屬（銅鐵礦物）、藥品、半導體
- 各國可能互相報復 → 惡性循環

#### 美債分析
- 十年期美債殖利率可能在4.5%~4.8%區間整理
- 美國在舉債上限（3月中前不能再發太多債） → 短期支撐債價
- 建議：長債切換成短債（2年期約4.2%，與長債利差不大但風險較小）

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **BBU (Battery Backup Unit)** | 電池備援單元，用於伺服器的不斷電系統，GB300伺服器標準配備 |
| **ASIC** | 客製化特殊應用積體電路，針對特定應用設計的晶片 |
| **WiFi 7** | 最新一代無線網路標準，提供更快速度與更低延遲 |
| **IC設計 (Fabless)** | 無晶圓廠的半導體設計公司，只設計晶片不製造 |
| **法說會** | 法人說明會，上市公司向投資機構說明營運狀況與展望 |
| **PCE物價指數** | 個人消費支出物價指數，美國聯準會偏好的通膨指標 |
| **假跌破** | 股價短暫跌破支撐後迅速反彈，為洗盤訊號而非真正破位 |
| **三角收斂** | 技術分析型態，股價高低點逐漸收窄，醞釀方向選擇 |
| **殖利率** | 現金股利除以股價，衡量股票現金報酬率 |
