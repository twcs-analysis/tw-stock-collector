## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| ASIC | Application-Specific Integrated Circuit，客製化專用晶片，針對特定用途設計 |
| TPU | Tensor Processing Unit，Google自研的AI專用處理器 |
| TR系列 | Amazon自研的AI晶片（Trainium），TR2/TR3/TR4為不同世代 |
| QD快接頭 | Quick Disconnect，水冷散熱系統的快速接頭模組 |
| 券資比 | 融券餘額除以融資餘額的比率，券資比高代表軋空動能大 |
| 格日沖 | 當日買進隔日賣出的短線交易策略 |
| 貼息 | ETF除息後股價未能回補到除息前水準，持有者實際虧損 |
| 本益比 | 股價除以每股盈餘(EPS)，衡量股票是否昂貴的常用指標 |
| Rubin架構 | NVIDIA下一代GPU架構（接替Blackwell），預計2026年推出 |
| 五日線法則 | 以五日均線作為短線操作的支撐參考，跌破三天內需收回否則出場 |
