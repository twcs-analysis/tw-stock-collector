## 💼 產業分析與投資建議

### 一、關稅議題與市場解讀

#### 菁龍觀點：關稅幾趴都不用怕

**歷史數據論證**：
1. **融資維持率觸底後台股必漲**：過去10年只要融資維持率殺到波浪新低，後續1個月、3個月、1年後台股都是上漲的
2. **今年4月9日融資維持率降至118%**，比金融海嘯還低
3. **明年4月預估**：以過去10年平均漲幅21.33%計算，台股即便保守也在21,000點以上

**2025年 vs 2020年疫情年對比**：

| 指標 | 2025年（關稅年） | 2020年（疫情年） |
|------|-----------------|-----------------|
| 股災後反攻天數 | 72天 | 72天 |
| 漲幅 | 35.61% | 40%+ |
| 融資增幅 | 僅3%（57億） | 37% |
| 籌碼乾淨程度 | 有史以來最乾淨 | 次乾淨 |
| 底部反攻站回年線時間 | 2個月 | 2個月 |

**三個確定的事情**：
1. 大盤低點17,306點不會再回來
2. 第三季（最快8月）可能看到外資空單密轉多單
3. 大盤季線從下彎拉到翻揚，代表股市不怕跌

**新台幣升值分析**：
- 過去13年台幣升值時間與股市表現正相關
- 今年台幣從33元急升至28元附近（3個月升值13%）
- 過去10年只要台幣在4個月內急速升值超過8%，後續都會帶來台幣回貶的趨勢
- 台幣升值當年台股必漲

**年線預估**：
- 台北股市年線在22,200點
- 2020年疫情年從年線11,000點漲了6,000多點
- 本次若抓保守的2,000點漲幅，目標至少24,200點以上

1. **淘汰弱勢成分股**: 不像0050被迫照單全收（如中鋼、台塑等拖累績效的股票）
2. **擴大選股池**: 從前50大市值擴展到前150大市值，從第51-150名中挑選強勢股
3. **台積電比重上限控管**: 設定上限（如30%），避免過度集中

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| 融資維持率 | 融資餘額與擔保品市值的比率，低於130%會被追繳保證金，觸底後通常代表市場已過度恐慌 |
| 天花板價格 | 股票在歷史高點或重要壓力位形成的價格天花板，突破需要大量能配合 |
| 多方缺口 | 股價跳空上漲留下的缺口，代表多方力道強勁；若被封閉（回補）則需觀察支撐 |
| 月MACD | 以月線為單位計算的MACD指標，綠棒翻紅代表中長期趨勢轉多 |
| 年線扣底 | 年線（240日均線）開始走平或向上翻揚，代表長期趨勢轉多 |
| 主動型ETF | 由基金經理人主動選股與調整權重的ETF，相對於被動追蹤指數的傳統ETF |
| 物理AI | 黃仁勳強調的概念，指AI從虛擬世界走向實體化應用（如機器人） |
| BBU (Battery Backup Unit) | 電池備援單元，用於伺服器的不斷電系統 |
