#### 外資空單的真相

**核心觀點：外資空單與台幣升值同步發生**

三件事同時發生：
1. 台幣從32.5元急升至28元附近
2. 外資開始大舉買進台股現貨
3. 期貨空單同步增加（避險需求，非看空）

**關鍵提醒**：
- 期貨空單方向經常與現貨相反（避險操作）
- 不可單看空單數量就判斷外資看空
- 應搭配現貨買賣超與台幣走勢綜合判斷

#### 台幣與空單四宮格推演

| 情境 | 台幣 | 空單 | 大盤走勢 | 操作策略 |
|------|------|------|---------|---------|

| **右上** | 回貶（破30元） | 減少 | 外資真心做多（現貨+期貨同方向） | 強勢做多 |

- 代表外資真心愛台灣，部位從中性轉為偏多

**關鍵轉折點**：
- 台幣若回到31.5-31.7元（年線位置），代表升值趨勢結束

## 📈 技術面分析與操作策略

### DMI指標選股法（中哥教學）

**核心概念**：
- **正DI（+DI）**: 上升方向指標，代表多方力道
- **負DI（-DI）**: 下降方向指標，代表空方力道
- **黃金交叉**: 正DI由下往上穿越負DI = 買進訊號
- **歸離**: 正DI與負DI的差距，差距大代表追價風險高

**操作原則**：
1. 正DI在負DI上方 = 偏多，持有
2. 負DI在正DI上方 = 偏空，觀望
3. 兩線接近即將交叉 = 準備進場
4. 歸離過大 = 不宜追價
5. 搭配法人籌碼+基本面（營收成長）篩選

### 外資期貨籌碼觀察法

**判讀方式**：
- 將過去10天外資空單水位取均值
- 目前均值：52,000口
- 今日實際：44,000口
- 低於均值 = 偏多（紅色）
- 高於均值 = 偏空（綠色）

**結合其他指標**：
- Put/Call Ratio < 80 = 市場恐慌過度（通常為短線低點）
- 選擇權自營商+外資同方向 = 趨勢確認
- 十日均線走勢 = 中期方向

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| DMI指標 | Directional Movement Index，趨向指標系統，由正DI、負DI和ADX組成，用於判斷趨勢方向 |
| 正DI (+DI) | Plus Directional Indicator，上升方向指標，數值越高代表多方力道越強 |
| 負DI (-DI) | Minus Directional Indicator，下降方向指標，數值越高代表空方力道越強 |
| 歸離 | 正DI與負DI之間的差距，差距越大代表趨勢越明確但追價風險越高 |
| Put/Call Ratio | 賣權成交量除以買權成交量，低於80代表市場偏恐慌，通常為短線低點 |
| 格日沖 | 當日買進隔日賣出的極短線操作，外資常用於賺取短線價差 |
| 行為金融學 | 結合心理學與金融學的研究領域，分析投資人非理性行為 |
| 定期定額 | 每月固定金額投資特定標的，透過時間分散風險的投資策略 |
| 避險操作 | 同時持有現貨多單與期貨空單，降低整體部位風險 |
| 十日均線 | 過去10個交易日的收盤價平均值，常作為短線多空分界 |
