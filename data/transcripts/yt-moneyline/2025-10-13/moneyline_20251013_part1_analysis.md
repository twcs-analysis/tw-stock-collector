## 💼 產業分析與投資建議

### 一、中美稀土戰事件深度分析

#### 事件時序回顧

| 日期 | 事件 |
|------|------|
| 9/8 | 美國戰略金屬公司與巴基斯坦政府簽署 5 億美元稀土投資協議 |
| 9/9 | 川普與習近平通話 2 小時，確定 APEC 川習會、TikTok 交易 |
| 10/9 | 中國國務院公布第 61 號文（稀土物項出口管制，**12/1 實施**）與第 62 號文（稀土技術出口管制，**立即實施**） |
| 10/10 | 川普宣布 **11/1** 起對中國進口商品加徵 100% 關稅、關鍵軟體列出口管制 |
| 10/12 | 中國官方聲明「出口管制不等於禁止出口」（態度放軟） |
| 10/12 | 川普在社群平台發文安撫：「不要擔心中國，一切都會好起來」 |

#### 俊文老師分析：「擦槍走火的烏龍」

**核心觀點**: 此次中美衝突可能只是信息溝通的誤會，本質上是談判籌碼的交換。

1. **時間差問題**: 中國稀土管制訂於 12/1 才實施，距離 APEC 峰會（11 月底）約一個月。實施時間設在談判之後，明顯是「先抬價再打折」的談判策略，而非實質敵意行動。
2. **TikTok 讓步**: 中國在 TikTok 交易中大幅讓步（90% 美國持有、交出演算法），突破過去紅線，顯示習近平主動想見川普。
3. **WTO 前科**: 中國在稀土出口限制方面曾多次違反 WTO 第 11.3 條款承諾，2021 年被日本、歐盟、美國聯合控告且敗訴。
4. **川普誤判**: 川普可能誤以為實施日是 11/1（有敵意），實際是 12/1（談判籌碼），導致過度反應加徵 100% 關稅。

**稀土去中國化進程**:
- 目前中國稀土開採量佔全球約 70%，加工產量約 90%
- 非中國比重從 2020 年約 20-25%，預計 2030 年可達 50%
- 日本經驗：大金空調減少 90% 稀土用量、辛運半導體回收技術可達 90-95%
- 整體去中國化原本需 10 年，現加速至約 7 年

#### 挺好分析：籌碼交換與長期脫鉤

**核心觀點**: 談判本質為雙方短期利益交換，長期持續脫鉤。

1. **中國稀土優勢**: 加工領域佔 90%、永磁釹鐵硼佔 90% 市佔
2. **美方脫鉤進度**: 重點不在取得稀土礦（全球各國都有），而是建立完整精煉能力
3. **Polymarket 民調**: 63% 的人不相信美國最終會對中國加徵 100% 關稅，主流預期最終稅率 20-40%
4. **大豆問題**: 2025 年中國進口美國大豆為零，對美國農業州（共和黨票倉）影響極大；川普本屆難以再用財政刺激補貼農民（資本撙節政策目標明確）
5. **月底前展望**: 稀土禁令和 100% 關稅很可能都不會實際發生，雙方會在月底前撤銷或作為談判交換

**高盛統計的川普貿易戰模式（11 階段循環）**:
1. 川普發出含糊貼文暗示關稅
2. 市場開始走跌
3. 突然宣布高額關稅（通常 > 50%），市場巨烈下跌
4. 恐慌性拋售，籌碼洗出
5. 抄底買盤出現，假反彈
6. 反彈後再創低
7. 聰明錢第二波進場
8. 川普加碼或擴大關稅
9. 對手國發聲明
10. 川普週末貼文安撫「正在尋求解決方案」
11. 財政部長出面安撫 -> 2-4 週後簽訂新貿易協議 -> 重複循環

**市場為何跌不下去的三層邏輯**:
1. **政治事件金融化**: 投資人對波動耐受度提高，利空不夠大就撐得住氣
2. **不確定性可分配化**: 不確定性不再全是風險，也是機會（如 AI 受川普親自推動中東訂單）
3. **市場信念的反身性**: 利多利空本身不重要，市場「覺得」是利多還是利空才重要（類凱因斯選美理論）

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **稀土（Rare Earth）** | 17 種化學元素的統稱，廣泛用於電子產品、永磁鐵、國防武器等。中國掌控全球約 70% 開採量與 90% 加工產量 |
| **WTO 第 11.3 條款** | 世界貿易組織規定，成員國不得隨意禁止出口或實施配額限制（除非獲得例外允許） |
| **APEC（亞太經濟合作會議）** | 亞太地區 21 個經濟體的經濟合作組織，每年舉行領袖峰會 |
| **TikTok 交易** | 美國要求 TikTok 出售美國業務，最終中方同意 90% 由美方持有並交出演算法 |
| **騰弱指標** | 衡量市場漲跌家數強弱的技術指標，與大盤背離時顯示漲勢過度集中 |
| **國安基金** | 台灣「國家金融安定基金」，總額度 5,000 億元，在重大系統性風險時進場護盤 |
| **凱因斯選美理論** | 凱因斯提出的投資理論：投資不是選你認為最好的，而是選大家認為最好的 |
| **Polymarket** | 基於區塊鏈的預測市場平台，用戶可對政治、經濟事件下注預測 |
| **反身性（Reflexivity）** | 索羅斯提出的概念，市場參與者的預期會反過來影響市場本身，形成自我強化循環 |
| **川習會** | 指美國總統川普與中國國家主席習近平的雙邊會晤 |
