## 🌍 市場總體觀察

### 台股市況分析

#### 大盤表現
- **加權指數**: 持續多頭格局，距離歷史新高僅一步之遙
- **多頭氣氛**: 紅海持續延伸，多檔個股創歷史新天價
- **台積電 (2330)**: 收盤價穩守在1,100元以上區間，拉回就是買點

#### 台積電技術外洩事件
- **事件概要**: 日經亞洲獨家報導，台積電發生2奈米先進製程技術外洩事件
- **涉案人員**: 3名被告（2名現職工程師勾結1名離職前工程師），以國家安全法遭羈押
- **外洩方式**: 涉案人員利用手機拍照方式，竊取2奈米晶片製程機密線圖
- **洩密對象**: 疑似流向日本東京威力科創（TEL），是否進一步流向中國大陸仍待調查
- **股價影響**: 台積電當日股價未受明顯衝擊，技術領先幅度（領先對手3-5年）讓洩密影響有限
- **管理啟示**: 暴露出台積電內部管理存在漏洞，高層級人員仍可攜帶手機進入產線拍照

#### 台積電操作建議
- **策略**: 拉回就是買
- **支撐位**: 前一波平台整理區約1,100元附近
- **理由**: 國際投資評論認為台積電目前相對便宜，2奈米技術全球獨霸

### 美股與聯準會動向

#### 降息預期升溫
- **觸發因素**: 美國7月非農就業數據僅7.3萬人，遠低於預期；5月與6月數據也大幅下修
- **聯準會官員發言**: 克里夫蘭聯準銀行總裁戴力表示「降息時間點正逐漸逼近」，今年可能降息兩次或以上
- **9月降息機率**: 已攀升至90%以上
- **10月再降息機率**: 約60%
- **昨日美股**: 三大指數創下5月27日以來單日最大漲幅

#### 降息對台股的歷史經驗
- 非農就業數字低於預期後，台股一個月報酬率平均表現亮眼
- **去年8月經驗**: 股災後一個月漲幅10.8%，兩個月漲幅13.65%
- **重要觀察**: 股市漲在前面，真正降息後漲幅反而縮小
- **小結論**: 預期降息時漲幅最大，真正降息後反而漲幅放緩

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **CCL（銅箔基板）** | Copper Clad Laminate，PCB的關鍵上游材料，由銅箔+樹脂+玻纖布組成 |
| **HDI板** | High Density Interconnect，高密度連接板，用於智慧型手機、伺服器等高階產品 |
| **CoMoS** | 未來次世代封裝技術概念，用PCB直接取代ABF基板，降低成本 |
| **ASIC** | Application-Specific Integrated Circuit，特定應用積體電路，四大CSP自行設計的AI晶片 |
| **GV200/GV300** | NVIDIA新一代GPU加速器平台，GV300為下半年推出的升級版 |
| **非農就業數據** | 美國每月公布的非農業部門新增就業人數，是聯準會制定貨幣政策的重要參考指標 |
| **UV減黏膠** | 用紫外光照射可解除黏性的半導體保護膠，用於晶圓製程中保護電路 |
| **本益比重估** | 市場重新評價個股合理本益比倍數，通常因業務轉型或獲利結構改變而發生 |
| **扣抵值** | 技術分析中均線未來的比較基準，用於判斷均線未來走向 |
| **OPEC增產** | 石油輸出國組織增加原油產量，導致油價下跌 |
