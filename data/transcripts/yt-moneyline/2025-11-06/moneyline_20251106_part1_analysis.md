## 技術面分析

### 大盤技術指標
- **騰弱指標**: 出現明顯背離，指數上漲但下跌家數遠大於上漲家數，預告高檔將拉回
- **K線型態**: 高檔出現罕見的連續5支上影線（高原下處），預示快速拉回
- **上影線**: 從來沒看過在高檔出現連續5支上影線的紀錄
- **成交量**: 自某天起再也沒有出現歷史大量，代表行情進入較長區間整理

### 國安基金統計學操作模型（郭老師）

#### 7次拉回統計
- 自17,360點起漲以來，共7次拉回
- 每次回檔約900~1,230點
- 本次從28,854跌至27,373，跌1,181點，符合歷史回檔幅度
- 支撐計算：28,854 - 1,230 = 27,324點

#### 操作原則
- **買點**: 靠近27,324點以上都是買點
- **賣點**: 接近28,854高點附近
- **結構判斷**: 本次結構與過去不同（高檔5支上影線+下跌家數遠大於上漲家數），短期不會過高
- **區間預測**: 未來一週，高不過28,554、低不破27,324，區間震盪

## 策略總結

### 短線操作策略
1. **區間操作為王**: 大盤進入27,324~28,554區間震盪，低買高賣
2. **國安基金在場**: 拉回就是買，跟著國安基金買權值股、權重股、產業龍頭指標股
3. **台積電不走空+國安基金未退場 = 不做空、不恐慌**
4. **11/12鴻海法說會**: 關鍵催化劑，關注毛利率能否超越6.23%甚至接近6.5~7%

### 選股方向
- 跌深反彈的權值股（台積電、鴻海、廣達）
- 被動元件回檔到支撐的個股（國巨、華新科）
- 小型MSCI新增股（尚未啟動的加能、一騰KY等）
- 記憶體族群看南亞科為指標

### 風險提示
- 外資持續賣超，期貨空單高達32,000口
- 短線不會過前高28,854
- AI泡沫論持續發酵，外資不斷提醒估值過高
- PCB多家公司發債，可能壓抑短期股價

## 名詞解釋

| 名詞 | 解釋 |
|------|------|
| MSCI季度調整 | 摩根士丹利資本國際指數每季進行成分股增減，影響被動式基金資金流向 |
| 騰弱指標 | 藉由計算每日市場漲跌家數的差值，反映整體市場行情的強弱變化，預判趨勢方向 |
| 國安基金 | 國家金融安定基金，政府護盤工具，總額5,000億（擬擴大至1兆），歷史上最多使用1,227億 |
| GB200/GB300 | 輝達（NVIDIA）新一代AI伺服器GPU產品，GB200已出貨，GB300開始量產 |
| Rubin | 輝達下一代AI晶片架構，預計明年下半年量產 |
| AI RAN | 將AI技術深度整合到無線接取網路，預估未來3G市場可達2,000億美元 |
| CSP | 雲端服務供應商（Cloud Service Provider），如AWS、Azure、GCP等 |
| 上影線 | K線圖中，最高價與收盤價（或開盤價較高者）之間的線段，代表上方賣壓 |
| 發債 | 公司發行公司債或可轉換公司債籌資，可能因套利者賣老股買新股而壓抑股價 |
