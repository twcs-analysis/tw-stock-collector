## 技術面分析

### 區間震盪操作要訣（郭老師核心教學）

#### 操作觀念
1. **長期套牢股票**: 這波解套有賺一定要資金退出，換股操作
2. **高出低進**: 若不換股，買的價位一定要比原始套牢價低
3. **指數上漲盡壓**: 壓力不追買；利空拉回一定趕接
4. **保持靈活**: 輪動速度快，找相對位階低的股票，畫出每檔區間空間
5. **半倉操作**: 長幅已大的股票，一半錢買即可，盤隨時變盤
6. **散射（選擇權）保護**: 留另一半部位用選擇權避險

#### KD+MACD 選股法
- **買進訊號**: KD 20以下向上黃金交叉 + MACD負翻正
- **案例**: 精層科(6191)在105.5元出現訊號，後漲至130多元
- **停損點設定**:
  - 底部：用最長期移動平均線（股價下方、低點上方最長線的那條）
  - 隨股價上漲：逐步從65日線 → 22日線 → 10日線 → 5日線縮短

#### 第五階段行情特徵
- 11月是每年漲最兇的月份
- 12月是平均漲最多的月份
- 高漲要拉回的股票（做頭股）：要捨得賣
- 反轉向上的股票（多方走勢）：買進訊號轉多就要買
- 區間震盪：KD 20以下黃金交叉 + MACD負翻正都可以買

## 名詞解釋

| 名詞 | 解釋 |
|------|------|
| 第二支腳 | 股價在底部區域形成雙底型態時的第二個低點，通常是更安全的買點 |
| 0.618反彈 | 黃金分割率反彈，股價從低點反彈至前波跌幅的61.8%位置 |
| 三角收斂 | 股價在逐步縮小的高低點範圍內整理，最終將選擇方向突破 |
| KD黃金交叉 | KD指標中K值由下往上穿越D值，視為買進訊號，尤其在20以下出現更為有效 |
| MACD負翻正 | MACD柱狀體從負值翻為正值，代表由賣方市場轉為買方市場 |
| 騰弱指標 | 計算每日漲跌家數差值，反映市場整體強弱，當指數漲但下跌家數多於上漲家數時為背離警訊 |
| 博通（Broadcom） | 全球網通晶片龍頭，近期發表800G AI以太網路晶片，與輝達競爭 |
| 矽光子 | 利用矽基材料傳輸光訊號的技術，台積電積極發展，為高速傳輸關鍵技術 |
| W底（雙底） | 技術分析中的底部反轉型態，外型像英文字母W，代表底部確認 |
| 區間震盪 | 股價在固定的上下界限之間來回波動，適合高出低進操作 |
