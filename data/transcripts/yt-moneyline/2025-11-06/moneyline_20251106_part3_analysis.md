## 市場觀察

### 台經院GDP預測上修

#### 2025年GDP預估
- **台經院最新預測**: 5.94%（國內智庫最高預測）
- **院長補充**: 有機會挑戰6%
- **前三季實際數據**:
  - Q1：5.45%
  - Q2：8.01%
  - Q3：7.64%（遠超預期）
- **對美順差**: 從去年649億美元，今年可能上看1,100~1,200億美元
- **主要驅動力**: AI與半導體供應鏈貢獻度極強

#### 2026年展望
- **台經院預測**: 約2.6%（不到3%）
- **國內外機構**: 普遍預測落在3%左右
- **變數**: 若AI持續強勁，有機會慢慢往3%靠近
- **今年基期高，明年成長放緩屬正常**

### 傳產業面臨多重困境

#### 石化產業（最悲觀）
- **EIA預測布蘭特原油價格**:
  - 去年：約80美元
  - 今年：滑落至62.9美元
  - 明年：進一步降至52美元
- 預測機構普遍認為2028年前亞洲石化產業公過於求
- 明年還要面對對等關稅 + 碳費徵收
- **結論**: 相對不利的佈局方向

#### 傳產轉機觀察
- **台塑化等台塑集團**: 壞了多年，股價在低檔，可能有年底集團作帳
- **不追高**: 在整理時低接，等待集團作帳行情
- **服務業**: 殖利率不到2%，長期低檔

### 服務業趨勢

#### 明年重點趨勢
1. **零售業**: 進入高度數位化，全通路線上線下無縫接軌，打造智慧零售
2. **銀行業**: AI技術導入，數位轉型更進一步
3. **家族辦公室**: 二代接班比例提高，高資產人士服務需求增加
4. **亞洲資產管理中心**: 政府持續推動，創造台灣特色

#### 不動產業
- **辦公室市場**: 台北市核心商業區供給從今年5.7萬坪增至明年9.7萬坪
- **市場轉變**: 從房東市場轉向租客市場
- **營造業**: 樂觀（公共工程明年預算6,704億，年增6.1%）
- **不動產業**: 偏悲觀，除非政策大幅鬆綁，否則持續盤整

## 策略總結

### 三大投資主軸

1. **AI半導體持續強勁**: GDP 5.94%背後最大推手，台積電供應鏈持續受惠
2. **赴美佈局概念股**: 半導體設備/耗材、AI伺服器代工、先進封裝
3. **Switch 2供應鏈**: 穩定出貨至少未來5個月，關注有基本面支撐的個股

### 短線操作建議
- **大盤**: 區間震盪27,324~28,554，低買高賣
- **國安基金持股**: 台積電、鴻海、廣達等持有至退場
- **Switch 2**: 旺宏投機，原相較有基本面支撐
- **傳產**: 台塑集團低接等年底作帳，不追高
- **不動產**: 營造業優於不動產業

### 風險提示
- 明年GDP可能降至2.6%，不到3%
- 美中談判不確定性高，邊打邊談成常態
- 石化產業持續悲觀至2028年
- AI泡沫論：CSP用股權換大單，資金瘋狂程度隱含風險
- 晶片關稅細則可能影響上中下游電子產業成本

## 名詞解釋

| 名詞 | 解釋 |
|------|------|
| GDP（國內生產毛額） | 衡量一國經濟規模的主要指標，台經院預測2025年台灣GDP成長率5.94% |
| 對等關稅 | 川普政府對貿易逆差國加徵的等額關稅，目前台灣處於20%加徵暫時性階段 |
| 232條款 | 美國以國家安全為由對進口商品加徵關稅的法律依據，可能用於晶片關稅 |
| 碳費 | 台灣即將開徵的碳排放費用，對高碳排產業（鋼鐵、石化、水泥、紡織）衝擊大 |
| DLSS | 輝達Deep Learning Super Sampling技術，用AI提升遊戲畫質同時降低處理器負擔 |
| 光線追蹤 | 模擬光線在3D場景中的反射折射效果，使遊戲畫面更逼真 |
| LPDDR5X | 最新低功耗雙倍資料速率記憶體規格，Switch 2採用12GB |
| 向下相容 | 新設備可以使用舊設備的遊戲卡帶或軟體，Switch 2可玩一代遊戲 |
| 主權AI | 各國為確保AI自主性而投資建設的國家級AI基礎設施 |
| 家族辦公室 | 為高資產家族提供的專業投資與財富管理服務機構 |
| CoWoS | 台積電先進封裝技術（Chip-on-Wafer-on-Substrate），用於AI晶片封裝 |
| SoIC | 台積電系統整合晶片（System on Integrated Chips）3D堆疊封裝技術 |
