## 💼 產業分析與投資建議

### 一、台積電（2330）第二季行情展望

#### 季線分析（佩政重要觀點）

**核心判斷: 台股第二季防守盤**

- **台積電季線已下彎**: 過去一年，台積電法說會後三個月股價上漲機率100%，但本次季線下彎改變了這個慣性
- **1月16日法說會收盤價**: 1,105元
- **季線壓力**: 約1,070元附近
- **關鍵觀察**: 4月16日前，台積電能否拉回到1月16日法說會收盤價（1,105元）以上
  - 若無法突破 → 改變過去一年外資操作慣性，確認防守盤
  - 若能突破 → 仍維持多頭格局

#### 歷史比較
- **2022年第一季**: 同樣出現台積電秒填息但大盤季線下彎的情況，之後跌破年線，直到第四季才翻轉
- **現況**: 台積電連八度秒填息，但大盤季線下彎，與2022年情境相似
- **結論**: 三個月內台股難以攻上24,000點，以防守為主

#### 台積電秒填息觀察
- 過去只要台積電秒填息＋大盤季線上揚 → 一個月內大盤創新高
- **本次不同**: 秒填息但大盤季線下彎 → 拉積盤力道有限

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **P/C Ratio** | Put/Call Ratio，賣權與買權的比值，低於100偏空，高於100偏多 |
| **道瓊運輸指數（DJTA）** | 追蹤美國20檔運輸業股票的指數，道氏理論認為其領先大盤 |
| **以盤代跌** | 股價不再大幅下跌，而是進入橫盤整理，為正面訊號 |
| **拉積盤** | 法說會後或除息後，法人拉抬股價的行為 |
| **ATX 3.0** | 新一代電源供應器規格，支援大瓦數（千瓦以上）輸出 |
| **MSAB** | 高密度多層板（Multi-layer Substrate Any-layer Build-up），進階PCB技術 |
| **UBB副板** | 伺服器中的子板（Universal Baseboard），承載關鍵元件 |
| **非農就業數據** | 美國每月公布的就業報告，為重要經濟指標 |
| **做帳行情** | 季底或年底時，法人（尤其投信）拉抬持股以美化績效的行為 |
