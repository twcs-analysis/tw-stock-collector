## 🌍 市場總體觀察

### 全球地緣政治格局

#### 美中關係與關稅談判
- **馬德里第四次會談**: 美中雙方正在進行新一輪談判
- **TikTok時間線**: 9月17日為最後期限，須出售或面臨制裁
- **核心議題**: 雙方報復性關稅是否延長或達成新協議
- **預判**: 本輪協議難以達成確切稅率，很可能再度延長
- **美方目的**: 加速中國洗產地、轉向第三國轉運的圍堵

#### 中國對外擴張策略
- **出口創新高**: 雖對美國、墨西哥出口減少，但對奈及利亞、越南、泰國、埃及、印度、德國等雙位數增長
- **一帶一路投資再創歷史新高**: 上半年在非洲投資達400億美元，成長最多地區已從東南亞轉向非洲
- **跨境支付**: 人民幣佔國際比例僅4%，但跨境數位支付從18年的15%上升至50%
- **PPI負2%**: 向外輸出通縮，壓低全球生產成本
- **結論**: 美中如同棋局，中國重視長期佈局，川普僅剩一任四年

#### 全球執政黨危機
- **日本**: 石破茂上任一年即下台，自民黨內部派系幾乎全數解散（安倍派、茂物派、暗天派、二階派等），10月將選出新首相
- **法國**: 兩年多已換五任總理，財政改革無法達成，長天期國債殖利率顯著飆升
- **英國**: 工黨遭受極大壓力，經濟不佳但通膨上升
- **阿根廷**: 右派總統米萊在地方選舉大敗，國債殖利率從9%飆升至13%
- **南韓**: 執政黨同樣面臨挫敗
- **結論**: 川普關稅戰讓各國執政黨遭殃，但美國股市反而受益

#### 美中將持下的影響
- 對美國：各國投資承諾（投資額保證）是利多
- 對其他國家：執政黨遭重創，但不影響資金流向美國
- 拉丁美洲下半年至明年為大選年，川普希望形成美洲供應鏈
- 委內瑞拉：美軍艦集結外海，呼應毒品戰爭，軍事壓力升高

### 美股估值與回調預判

#### 泡沫程度評估
- **本次特點**: 漲幅集中在少數股票，但本益比並未到泡沫程度
  - 輝達佔S&P 500權重 7.6%
  - 微軟 6.9%，蘋果 6.5%
  - 但前三大本益比僅 30~40倍（微軟32倍、蘋果30倍、Alphabet 22倍）
- **與1999年對比**: 1999年微軟市佔僅 2.8%、2.5%，但當時本益比更高
- **結論**: 感覺泡沫大是因為權重集中，而非個股估值離譜

#### 回調週期觀察
- 美國GDP與台灣EPS每3-4年有一次修正回歸
  - 2018年：跌幅約13%
  - 2015-2016年：跌幅接近13%
  - 2011-2012年歐債危機：跌幅12%
  - 2020年：疫情修正
- 上次修正為2020年，循環角度2025年出現適度回調並不意外
- **不是崩盤**: 泡沫程度不及1999年，更可能是恐懼情緒驅動的中期回調

#### VIX恐慌指數觀察
- 低於40為偏恐懼水位
- 過去觸發點：2025/4月關稅戰、2024/7-8月日圓套利平倉、2023/7-10月中期回調、2022年庫存回調
- **目前**: 約50-60，等待恐懼情緒像樣發酵後再做左側交易

### 降息後市場展望

#### 降息理由是關鍵
- **好理由**: 通膨逐步達標、關稅為一次性反應 → 利多
- **壞理由**: 勞動力市場惡化 → 搭配獲利下修，利空
- **取決於聯準會聲明釋放的態度與措辭**

#### 降息利多是否出盡
- 華爾街部分觀點認為降息利多已充分反映
- **反駁**: 取決於降息理由，若為正面理由則仍有上漲空間

### 三、台指期籌碼分析

#### 外資期貨動態
- 現貨連續買超10天以上
- 期貨空單從換倉時的35,000口降至不到20,000口（幾乎對半砍）
- 空單水位為長期以來罕見低位
- **歷史規律**: 台股大漲時外資皆為淨多單
  - 若淨空單翻為淨多單，將是偏向長多的重要訊號

#### 選擇權觀察
- 9月10日後外資從賣出賣權轉為買進賣權
- 原本雙層保護（賣出買權+賣出賣權收時間價值），現只剩單層
- 買進賣權部位仍大於買進買權 → 偏多結算有利

#### 結算展望（週三台指期）
- 只要在**25,000點以上結算**即為多方大獲全勝
- 本合約多方從23,661點起算，已贏1,000多點
- 週五美股也結算（開盤即結算），開盤後走勢可能與盤前不同

#### MSCI調整觀察
- MSCI在8月26日約23,050點調整完成
- 歷史規律：調整後若突破短期壓力，後續有軋空行情
  - 8月底突破後一路軋空上漲
  - 5月底同樣模式
  - 2月底無法突破則一路下跌
- **結論**: 頭過身就過，MSCI換手後為季度防禦點

#### 三種情境分析
1. **情境一（最可能）**: 25,000點守住 → 繼續一高比一高，權值股帶動，台積電挑戰新高
2. **情境二（次可能）**: 高檔盤整 → 24,500~25,000點區間震盪，正常配置不追高
3. **情境三（機率最低）**: 跌破月線 → 往24,500點以下，等到有長下影線再進場

### 中期（第四季展望）
- 外資期貨若從淨空翻淨多，為長多確認訊號
- 第四季作帳行情可期，集團股為布局重點
- 美股估值偏高但非泡沫，3-4年週期性回調可能出現但非崩盤
- 全球資金仍偏向美國，降息循環有利新興市場

### 資產配置
- **核心**: 台積電 + 台灣權值ETF
- **衛星**: 全球軍工太空、黃金、歐洲ETF
- **避險**: 短債ETF或主動型債券ETF

### 風險提示
1. **美中談判破裂風險**: TikTok時限到期可能升溫

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **IEEPA** | 國際經濟緊急權力法（International Emergency Economic Powers Act），川普用以課徵對等關稅的法律依據，目前面臨最高法院可能推翻的風險 |
| **洗產地/轉運** | 中國商品經由第三國（如越南、泰國）轉運至美國，規避直接關稅 |
| **一帶一路** | 中國主導的跨國基礎建設投資計畫，近年重點從東南亞轉向非洲 |
| **VIX恐慌指數** | 衡量市場預期波動率的指標，低於40為偏恐懼，通常是左側交易者進場的參考 |
| **淨多單/淨空單** | 外資在期貨市場的多單減空單淨額，正數為淨多單（看多），負數為淨空單（看空） |
| **MSCI調整** | 明晟指數定期調整成分股與權重，調整日前後往往造成資金大幅進出 |
| **左側交易** | 在股價尚未止跌確認前提前布局，與右側交易（確認止跌後買進）相對 |
| **軋空** | 空方被迫回補空單，推動股價進一步上漲的現象 |
| **買進賣權** | 買入看跌選擇權，支付權利金取得在到期日以約定價格賣出的權利，通常用於避險或看空 |
