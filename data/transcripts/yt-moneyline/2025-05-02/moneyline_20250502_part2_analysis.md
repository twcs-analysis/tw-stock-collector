## 🌍 市場總體觀察

### 美債議題深度分析

#### 六月美債到期潮
- **規模**: 6.5兆美元美債即將到期
- **結論**: 美債不會倒，但壓力巨大
- **邏輯**: 持有長天期美債等於看空股市（只有經濟大衰退、聯準會被迫救市、利率大降時長債才賺錢）

#### 美債殖利率結構
| 天期 | 殖利率 | 市場意涵 |
|------|--------|---------|
| 2年期 | 3.7% | 需求大、價格好、流動性佳 |
| 10年期 | 4.2% | 需求相對低、反映通膨風險 |
| 20年期 | 更高 | 台灣投資人主流持有，風險最大 |

**關鍵觀點**: 短債好發（各國搶買），長債難發（買家減少），但台灣投資人偏好20年長債，風險最大

#### 官股銀行動向
- **重要訊號**: 過去20天，八大公股銀行前十大賣超ETF中，有四檔為美債ETF
- **意涵**: 官股銀行嘴巴不說，但用行動拋售美債部位
- **解讀**: 機構投資人對長天期美債信心下降

### 世界經貿秩序重塑

#### 舊秩序（拜登以前）
```
美國消費 → 發美債 → 買亞洲商品 → 亞洲賺美元 → 亞洲買美債 → 美元回流
```
- 美國負責消費，亞洲負責製造
- 亞洲出口賺美元，美元再買美債回流美國
- 美國外債持續膨脹（信用卡已到36.2兆，接近40兆上限）

#### 新秩序（川普推動）
- **核心**: 不再只靠消費，美國也要製造
- **目標**: 將財政赤字從GDP的6.9%降至3%
- **手段**:
  1. 加徵關稅增加國庫收入
  2. 美國製造帶回就業
  3. 壓低利率降低美債利息支出
  4. 減稅法案（國慶日前通過）

#### 對亞洲的衝擊

**資金循環被打斷**:
1. 亞洲出口到美國減少 → 外匯收入減少
2. 各國外匯儲備成長放緩
3. 買美債需求下降 → 美債價格不好 → 殖利率居高
4. 台灣：出口商賺的美元減少 → 央行發行等值台幣減少 → 本土資金行情也不在

**貝森特（財政部長）關鍵發言**:
> 「華爾街的時代結束，主街的時代來臨」

- **華爾街時代**: 金融市場繁榮，頂層4%靠股票致富
- **主街時代**: 實體經濟繁榮，中產階級有穩定工作養家（類似1950年代美國夢）
- **意涵**: 資本市場報酬可能被壓縮，實體經濟將獲得更多資源

### 三殺與套利交易平倉

#### 美元三殺持續
- **美元**: 走弱（今年以來美元貶值約7.6%）
- **美債**: 長債價格不佳
- **美股**: AI七雄以外普遍疲弱

#### 全球套利交易平倉（比2024年8月更大規模）
- **2024年8月**: 日元套利交易平倉
- **2025年**: 日元、歐元、台幣全面升值 → 全球規模的套利交易平倉
- **邏輯**: 過去借低利率貨幣買美元資產的人，現在全部被迫反向操作

**曾老師建議**: 美元資產過多的投資人，應進行避險（去槓桿），三殺可能還會繼續

### 台幣匯率深度分析

#### 台幣 vs 美元走勢分離
- **正常關係**: 美元貶值 → 台幣升值（同步）
- **3月起分離**: 美元持續貶值7.6%，台幣反而因外資持續賣超而貶值
- **本週修正**: 三天內台幣快速升值，從差距8個百分點收斂到不到1個百分點
- **結論**: 今天的急升是合理的修正，週一不太會有更大的升幅，會慢慢穩住

#### 美債不會倒的理由

1. **投標倍數仍高**: 4月份（含對等關稅宣布後），10年期美債投標倍數從2.3升至2.6，代表需求仍旺
2. **認購者身分**: 不是散戶認購，是各國政府授權的退休基金在認購
3. **聯準會後盾**: 2020年疫情時短短時間買入3.7兆美債，還有1.5兆子彈在手
4. **無限QE能力**: 2020年直接宣布無上限量化寬鬆，要多少有多少

### 美國經濟數據解讀

#### Q1 GDP 負成長（-0.3%）
- **結論**: 假議題，非真正衰退

**GDP四大馬車拆解**:
| 項目 | Q1表現 | 說明 |
|------|--------|------|
| 個人消費支出 | +1.8% | 正常成長，未衰退 |
| 民間投資 | +21.9% | 大幅成長（搶進口設備） |
| 政府支出 | 負成長 | 受馬斯克DOGE裁員影響 |
| 進出口 | -41%（進口大增） | **GDP負值主因** |

- **真相**: 因關稅恐慌提前拉貨，進口大增41%，進口是GDP減項，導致帳面衰退
- **Q2展望**: 亞特蘭大聯準會GDP模型從2.4%下調至1.1%，經濟確實有隱憂

#### 就業市場風險
- **裁員人數**: 2-4月持續增加，與過去幾季明顯不同
- **今晚非農就業**: 市場預估失業率4.2%（持平）
  - **4.2%**: 正面（利多），可能解讀為降息機會
  - **4.3%**: 還可接受
  - **4.4%以上**: 美股會有非常大的壓力

#### 通膨觀察
- **PCE（個人消費支出物價指數）**: 3月公布2.3%（比前值下降），核心2.6%（從3%降至2.6%）
- **短期**: 通膨沒有明顯升溫跡象
- **長期風險**: 密西根大學預期通膨一年期跳至6.5%（42年新高），五年期也明顯跳升
- **停滯性通膨**: 短期可能性不高，但長期不能排除

#### 降息預測
- **聯準會觀察工具（CME FedWatch）**:
  - 5月7日：不降息（但選擇權布局顯示大幅波動預期）
  - 6月：降息預期明顯增加
  - 全年：市場預期約四碼
- **孟漢觀點**: 預估兩到三碼（比市場更保守）
  - 前提1：通膨能否繼續往2%靠攏
  - 前提2：鮑爾能否頂住川普壓力（預計可以頂住到明年五月卸任）

### 資產配置建議

#### 經濟衰退機率
- **國際賭盤**: 目前約60%衰退機率
- **3月前**: 僅20%
- **配置邏輯**: 機率接近一半一半，不應全部押股市

#### 孟漢的配置建議

**核心原則**:
1. **最差情況準備**: 永遠準備4/9對等關稅再來一次
2. **現金部位**: 至少保留兩到三成現金
3. **長短均衡**: 長線看多也買一些，短線避險也配一些

**美債ETF操作**:
- **不會倒**: 但長天期美債獲利空間有限
- **匯率風險**: 台幣繼續升值會侵蝕報酬
- **短債較佳**: 兩年期殖利率3.7%，流動性佳，風險低

#### 量能問題
- **現況**: 3,300億元，有補量但仍不足

- **歷史經驗**: 每次台股崩跌超過兩成後，外資一定最後一個回來
  1. 下跌時外資率先賣出
  2. 底部時外資繼續賣、內資承接
  3. 反彈時外資持續站賣方
  4. 來到均線後外資開始小買但又很快轉賣
  5. 真正多頭：外資連續買超 + 站上均線 + 均線翻揚

- **短線**: 外資初步買超可參考

## 📚 名詞解釋

### 美債相關

**投標倍數 (Bid-to-Cover Ratio)**
- 定義：美債標售時，投標金額 ÷ 發行金額
- 範例：發行1萬億，投標2.6萬億，倍數為2.6倍
- 意涵：倍數越高代表需求越旺，市場信心越強

**殖利率倒掛 (Yield Curve Inversion)**
- 定義：短天期殖利率高於長天期殖利率
- 現況：2年期3.7% vs 10年期4.2%（正常，但差距不大）
- 意涵：若倒掛加深，通常預示經濟衰退

**量化寬鬆 (QE, Quantitative Easing)**
- 定義：央行大量購買政府債券以向市場注入流動性
- 2020年：聯準會宣布無限QE，買入3.7兆美債
- 子彈：目前手上還有約1.5兆可動用

### 經濟指標

**PCE（個人消費支出物價指數）**
- 定義：聯準會最重視的通膨指標
- 目標：2%
- 最新：整體2.3%，核心2.6%
- 趨勢：緩步下降但仍高於目標

**亞特蘭大聯準會GDP模型 (GDPNow)**
- 定義：即時追蹤的GDP預測模型，每月更新
- 特色：比傳統季度資料更及時
- 最新：Q2預測從2.4%下調至1.1%

**密西根大學消費者信心指數**
- 定義：調查消費者對未來經濟的信心
- 重要分項：預期通膨（一年期和五年期）
- 最新：一年期預期通膨6.5%（42年新高）

**非農就業 (Non-Farm Payrolls)**
- 定義：美國每月公布的就業人數變化
- 重要性：聯準會決策的關鍵參考指標
- 觀察重點：就業人數變化 + 失業率

### 貿易與匯率

**財政赤字 (Fiscal Deficit)**
- 定義：政府支出超過收入的差額
- 拜登時期：占GDP 6.9%
- 川普目標：降至GDP 3%

**貿易順差 (Trade Surplus)**
- 定義：出口金額大於進口金額
- 台灣對美：約700億美元順差
- 影響：順差越大，美國越可能施壓匯率升值

**主街 vs 華爾街 (Main Street vs Wall Street)**
- 華爾街：代表金融市場、資本市場
- 主街：代表實體經濟、一般民眾的生活
- 川普政策：從華爾街轉向主街（製造業回流、創造就業）
