## 💼 產業分析與投資建議

### 一、BBU（電池備援模組）產業鏈

**繪子老師分析** - BBU產業複製龍頭擴散模式

#### 產業邏輯
- AI資料中心用電需求持續攀升，BBU需求隨之增加
- 產業發展模式：龍頭先行 → 訂單滿載 → 二線三線接棒
- 兩大供應體系：
  1. **直供體系**: AES-KY直接供貨給CSP大廠
  2. **電源體系**: 透過光寶科、台達電配合電源供應器出貨

#### 重點個股

**1. AES-KY（6781）- BBU龍頭**
- **角色**: BBU直供龍頭，客戶涵蓋亞馬遜、Meta、Google
- **BBU營收佔比**: 2023年約30% → 2024年約50% → 2025年預估接近70%
- **獲利趨勢**: 持續創高，2026年仍將大幅成長
- **股價區間**: 已從420元漲至1,275元
- **操作建議**: 已處高位，作為產業觀察指標

**2. 新勝利（3236）- BBU二線接棒**
- **股價**: 約65-70元區間
- **去年EPS**: 2.5元（上半年）
- **今年前兩月EPS**: 已達1.03元（已賺去年半年份的錢）
- **BBU佔比**: 2024年不到20% → 2025年預估往50%
- **客戶擴展**: 已打入光寶科BBU → 再打入台達電BBU
- **技術面**: 突破盤整區，逆大盤走強，低點持續墊高
- **支撐位**: 均線密集處有強支撐
- **操作建議**: 拉回找買點，短線衝高注意成交量，中線可持有
- **目標價**: 未明確提及，但以成長性而言仍有空間
- **停損點**: 跌破均線密集支撐區

**3. 加百裕（3323）- BBU三線潛力股**
- **股價**: 約40多元（低價位階）
- **去年獲利**: 虧損
- **轉折點**: 年底開始轉虧為盈，已打入光寶科BBU
- **進展**: 小量出貨中，預計Q3開始放量
- **發展階段**: 類似新勝利更早期階段
- **額外利多**: 神寶家族、鴻海家族今年自己做AI伺服器也會搭配BBU
- **操作建議**: 低價潛力股，適合長線布局

### 二、AI軟體應用族群（AI代理 / 物理AI）

**繪子老師分析** - NVIDIA GTC大會後的AI應用新方向

#### 產業邏輯
- 黃仁勳GTC大會點名：AI發展重點從「雲端AI」轉向「AI代理」再到「物理AI」
- AI代理涵蓋企業端到個人端，市場規模遠大於AI伺服器
- 國際趨勢：Google以321億美元收購Wiz（網路安全公司），看重AI應用落地
- 美股AI應用相關股票昨晚全面轉強

#### 重點個股

**4. 華金（未明確代號）- AI影像與自然語言服務**
- **股價**: 已連續四根漲停
- **市值**: 僅30-40億元
- **題材**: AI影像辨識、自然語言服務
- **短線操作**: 連續噴出後乖離率過大，短線不追，等拉回靠近均線再說
- **長線展望**: AI代理趨勢下仍有前景

**5. 零壹（3029）- AI代理概念**

- **題材**: 機器人（台灣金評獎）、智慧電腦人（已打入醫院體系）、日本AI合作、行政院AI導入
- **技術面**: 打底完成，突破後回測未破底
- **操作建議**: 短線可注意拉回買點，長線投資價值浮現

**6. 麥達特（未明確代號）- 基因/碳盤查概念**

- **市值**: 相對更低
- **操作建議**: 反彈空間較大，可留意

**7. 凌群（2453）- AI代理/國防/低軌衛星**

- **獲利**: 今年可能有接近翻倍成長
- **技術面**: 翻上所有均線，短線轉強
- **量能**: 成交量較少
- **操作建議**: 低市值高潛力，可留意

**8. 凌羿（2929）- AI軟體龍頭（市值最大）**
- **技術面**: 短線表現相對弱
- **操作建議**: 靠近低點附近可留意，等待轉強訊號

### 三、三大外資論壇結論（錢線獨家）

**建序分析** - 上週美林、摩根士丹利、高盛三大論壇重點

#### 核心結論：不需太悲觀，第二季東風起

**論壇重點整理**:

1. **關稅影響有限**
   - 台灣以ICT/半導體為主，直接出口美國比例不高
   - 台積電賣晶片給蘋果，蘋果再出口，關稅影響主要在蘋果端
   - 台灣企業早已全球化分散供應鏈

2. **在地化趨勢**
   - 美系外資認為台積電赴美投資「相當合理」
   - 亞系外資對此較有疑慮

3. **大摩報告亮點**
   - **京鼎科（3583）**: 過去八年零一收、年複合成長率28%，維持2025年EPS 36元，目標價608元
   - **嘉斌**: 今年EPS預估約20元（大摩報告），2026年將交出亮眼財報

4. **高盛聚焦CPO矽光子**
   - 特別帶客人參訪**聯亞（3081）**與**全新（2455）**
   - **聯亞**: CPO今年營收佔比約八成，高盛目標價680多元（現價350元左右）
   - **全新**: 今年營收佔比持續上調，高盛目標價120-130元

5. **投信總司令張錫觀點**
   - 第二季看好：4/2關稅後 → 財報季 → 股東會 → 強制回補 → 發股息

#### 第二季多頭五大理由
1. 壽險公司在找高殖利率股票
2. 政府基金有1,000多億待撥款
3. 4月2日關稅不確定性消除後量能有望回升
4. 川普百日落在4月底，政策變數趨於明朗
5. **錢藏在市** - 台灣債券ETF規模全亞洲第一（2024年成長1兆元），資金隨時可回流股市

## 📋 投資策略總結

### 慶龍的兩招心法

**第一招：股票與現金配置**
| 投資人類型 | 股票比重 | 現金比重 |
|-----------|---------|---------|
| 積極型 | 80% | 20% |
| 保守型 | 60% | 40% |
| 慶龍本人 | 70% | 30% |

- **核心原則**: 任何時刻都不應清空股票
- **原因**: 報復性反彈來得又快又急，2020年3月、2022年10月均是如此

**第二招：好公司越跌越美麗**
- **信念**: 好公司的獲利逐年成長（今年 > 去年 > 前年）
- **好公司定義**: 台股權值股如台積電、鴻海、廣達等均符合
- **實戰案例**: 2022年跌破年線時宣布買入十張台積電
  - 2022/4月買在579、561、531
  - 2022/5月買在560
  - 2022/7月買在471、441

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **BBU** | Battery Backup Unit，電池備援模組，用於AI資料中心提供不斷電保護 |
| **AI代理（AI Agent）** | 能夠自主執行任務的AI軟體，從企業端到個人端均有應用 |
| **物理AI** | NVIDIA提出的概念，將AI應用於真實物理世界（如自駕車、機器人） |
| **對等關稅** | 川普政府4/2起實施的貿易政策，對各國課徵與該國對美關稅相當的稅率 |
| **年線** | 240日移動平均線，被視為多空分界的重要指標 |
| **CPO（矽光子）** | Co-Packaged Optics，將光學元件與晶片封裝在一起的技術 |
| **PB（本益比）** | Price-to-Book Ratio，股價淨值比，衡量股票估值的指標 |
| **派對交易（Pair Trade）** | 同時做多A股票做空B股票的配對交易策略 |
| **CSP** | Cloud Service Provider，雲端服務供應商（如AWS、Azure、GCP） |
