## 🌍 市場總體觀察

### Grok 3：馬斯克地表最強AI模型

#### 基本規格
- **發表時間**: 2025年2月上旬
- **訓練規模**: 從10萬GPU增加到20萬GPU
- **上線兩天下載量**: 突破2,027萬次
- **2月23日新增**: 語音模型（10種預設模式，目前僅英文）
- **語音任務完成率**: 89%
- **複雜問題處理能力**: 提升3倍

#### 語音模型的革命性意義
1. **更自然直觀的互動**: 從文字輸入進化到語音對話，不需要「文字思考」
2. **效率提升**: 長篇描述不需打字，解放雙手
3. **多工處理**: 邊做其他事邊使用AI（開車、做飯、看盤）
4. **無障礙性**: 對視力不佳或手部不便者是一大福音
5. **趣味性**: 10種預設模式，可設定輕鬆、幽默等對話風格

#### Grok 3 vs ChatGPT 語音模式比較
| 項目 | Grok 3 | ChatGPT |
|------|--------|---------|
| **架構** | 端對端語音文字混合模型 | 文字與語音為兩個架構 |
| **延遲** | 120毫秒以下 | 約500毫秒 |
| **資訊來源** | 基於X平台，較即時真實 | 一般網路資料 |
| **整合方向** | 特斯拉自駕車 + Optimus機器人 | 通用聊天應用 |

#### 產業影響
- AI從文字走向語音，將大幅改變生活形態
- 整合至自駕車：不僅自動駕駛，還能用語音進行深度互動
- 整合至機器人：機器人真正成為「隨身助理」
- AI學習特性：一個機器人學會，同品牌全部都能學會（擴散速度極快）

## 💼 產業分析與投資建議

### 一、族群輪動策略 - 不漲股操作法（來賓：其真）

#### 核心邏輯
- 盤勢震盪時，強勢族群中的龍頭股已大漲
- 尋找「同族群、基本面更好、但尚未上漲」的個股
- 比較指標股的獲利能力與本益比，找出被低估者

#### 操作心法
1. **選擇熱門題材**: 不夠熱門的股票會躺平不動
2. **觀察指標股先行**: 先有一兩隻指標股衝高
3. **基本面良好**: 獲利佳、虧轉盈、營收爆發
4. **與指標股對標**: 獲利能力比指標股好、本益比更低即可布局
5. **前面先有量**: 代表有人開始進駐，後續攻擊力道較大

#### 強勢股操作技巧
- 股票拉漲停後橫盤整理，5日線靠近10日線時為最佳布局點（第一次靠近勝率最高）
- 主力推升股價過程中需要整理洗盤，洗掉獲利了結者後再發動第二波攻擊

### 六、台積電深度分析（來賓：慶龍）

#### 最壞情境沙盤推演

**挑戰一：川普關稅威脅**
- 若課徵25%或100%關稅，等同川普「拿石頭砸自己的腳」
- 台積電先進製程全球市佔率92%，美國沒有替代品
- 不合理的關稅最終由美國消費者買單

**挑戰二：拜登補助可能被推翻**
- 拜登承諾：66億美元直接補助 + 51億美元貸款
- 台積電可申請最高25%投資稅收抵免（資本支出651億美金）
- **最壞損失**: 228億美金（約7,200億台幣）
- 相當於2024年獲利（1.1兆）的66%
- 但會分5-10年認列，每年衝擊有限

**挑戰三：赴美設廠困難**
1. **人才短缺**: 亞利桑那州找不到有經驗的建廠工人（上一座工廠是10年前）
2. **勞工問題**: 工會、薪資、勞資拉扯
3. **成本高昂**: 制定1.8萬條規則花了3,500萬美金；硫酸在美國生產價格高5倍，改從台灣海運到洛杉磯再卡車運到鳳凰城（7小時）仍較便宜
4. **行政效率低**: 任何產線改變都需重新申請，曠日費時

#### 台積電長期展望

**2025年EPS預估**:
- 預估EPS: 55.95元
- 三種情境估值:

| 本益比 | 目標價 |
|--------|--------|
| 20倍 | 1,100元 |
| 18倍 | 990元 |
| 16倍 | 880元 |

**2029年展望**:
- 董事長魏哲家：未來5年營收年複合成長20%
- 2024年營收2.8兆 x 1.2^5 = 突破7兆
- 預估EPS: 101元
- 若給20倍本益比：目標價2,200元
- 現金股利預估：46元/年

#### 赴美設廠規劃
- **第一座**: 2025年下半年量產（4奈米製程，亞利桑那州鳳凰城）
- **第二座**: 2028年投產（最先進奈米製程）
- **第三座**: 更先進製程（時間未定）
- **建議**: 台積電應承諾加快設廠速度，以換取川普善意

#### 操作策略
- 18倍本益比（990元）有機會看到
- 16倍本益比（880元）可遇不可求
- 最新技術會持續留在台灣，赴美廠以成熟製程為主

## 📈 技術面分析與操作策略

### 外資操作解讀（來賓：會智老師）

#### 外資賣超前幾名
1. **鴻海**: 賣超3萬多張，跌破所有均線
2. **台積電**: 賣超22,000多張，跌破重要技術支撐
3. **0050/0056 ETF**: 連ETF都賣

#### 外資心態分析
- 短線擔心國際股市震盪 + NVIDIA財報不如預期
- 空單雖加碼至約35,000口，但離前高4萬多口仍有距離
- 基本上是短線避險心態，非極度看空
- 把近期回補的空單又建回一些，但未超越前高

### 個股技術面

#### 鴻海
- 跌破所有均線中最後一道防線
- 前次DeepSeek利空也曾大跌，但後來填補缺口甚至過前高才回落
- **判斷**: 這次低點會有支撐

#### 廣達
- 直接跌破半年線
- 今日有小缺口，短線可能有反彈回測機會
- 出量區域若拉回到該處，不用過度悲觀

#### 華新科 (3059)
- **股價**: 49.1元，連續兩天漲
- 底部型態確認，出量突破
- 所有均線非常靠近（中長線乖離小），累積籌碼獲利了結壓力不大
- **操作建議**: 拉回買，不追高，收盤紅K收在二分之一以上算強勢

#### 性邦（推測為線束/感測器廠）
- **產品**: 線束，應用於開關器、訊號傳輸、電池充電、BMS管理系統
- **客戶**: 美國人形機器人廠商（BJ、AA等），已拿下四家中三家
- 也供應ASML光刻機百分之八十選擇線束
- 設備組裝也有涉入
- **操作建議**: 可留意

#### 亞光（推測為鏡頭/視覺相關）
- 視覺感測是自駕車與機器人最重要的環節
- 車子至少需要8顆以上鏡頭，機器人亦然
- **判斷**: 長線多頭，走階梯式上漲後回測
- **股價**: 約203元
- **操作建議**: 靠近上升趨勢線附近布局較漂亮；基本面強勁不太拉回

#### 新能高
- **題材**: AI眼鏡電池 + BPU的BMS技術
- **市值**: 僅60億元，相對較低
- **操作建議**: 優先留意

#### 達邁
- **題材**: PI膜（聚醯亞胺膜），結合子公司成為眼睛追蹤功能
- **操作建議**: 與新能高同為AI眼鏡指標股
