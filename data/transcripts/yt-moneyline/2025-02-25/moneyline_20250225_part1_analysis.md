### 三、傳產族群分析（來賓：其真推薦）

#### 運動產業 - 自強（推測為鈺齊/百和類型）
- **股價**: 約162.5元
- **今年預估EPS**: 約13元（去年8元，大幅成長）
- **本益比**: 約12倍

- **操作建議**: 本益比有上修空間，獲利進入強力成長期

#### 運動產業 - 預期（推測為豐泰類型）

  - 戶外品牌大廠，客戶涵蓋On Running等瑞士專業跑鞋品牌

  - 終結掛牌（子公司上市）題材
- **技術面**: 均線上升速度快，短線乖離過大時會拉回，等均線靠近時布局

#### 波麗（推測為碳纖維/複合材料廠）

  - 全球最大碳纖維冰上曲棍球廠商

- **技術面**: 高檔整理，等待均線靠近後突破創新高

## 📈 技術面分析與操作策略

### 大盤技術面
- 月線（23,285附近）已跌破，短線偏空
- 櫃買指數回測五日均線，相對強勢
- 台指期夜盤持續下跌，短線仍有壓力

### 傳產避風港策略（來賓：其真）

**短線操作**: 航運股（BDI運價指數本月漲36%，本週漲24%，加上重建題材）

**中長期操作**: 鋼鐵股
- 川普美國製造政策帶動基礎建設需求
- 大量廠商赴美擴廠蓋廠，帶動鋼鐵需求

### DeepSeek技術解析（來賓：居博）

#### 技術原理
- DeepSeek使用兩次監督式微調 + 兩次強化學習
- 核心概念：用較少運算資源訓練出精準權重
- Meta（臉書）技術長評估：有創新但非破壞性創新
- 可能使用「知識蒸餾」技術（用教師模型訓練學生模型，縮小模型規模）

#### 產業影響
- 確實降低了AI訓練成本，但幅度可能沒有媒體宣傳那麼誇張
- 中國AI實力不可小看
- 2025年AI投資大方向已確定，不會改變
- **關鍵警告**: 2026年起大型雲端服務供應商可能開始檢討AI投資規模
- AI應用擴散速度取決於「AI幻覺」（一本正經胡說八道）問題能否改善

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **BDI (Baltic Dry Index)** | 波羅的海乾散貨指數，反映全球散裝航運市場運費水準 |
| **DeepSeek** | 中國AI公司開發的大型語言模型，以較低成本達到與GPT相當的效能 |
| **知識蒸餾 (Knowledge Distillation)** | AI技術，用已訓練好的大型「教師模型」來訓練較小的「學生模型」，降低運算需求 |
| **強化學習 (Reinforcement Learning)** | 讓模型自行嘗試錯誤，答對加分答錯扣分的訓練方式 |
| **監督式微調 (Supervised Fine-Tuning)** | 用有標註答案的資料來調整模型權重，提升精準度 |
| **類神經網路 (ANN)** | 模仿生物神經網路結構的數學模型，用於計算事件發生的機率 |
| **權重 (Weight)** | 類神經網路中的參數，決定訊號傳遞的放大倍數 |
| **GB200/GB300** | NVIDIA新一代AI伺服器平台，需要更多電源與散熱元件 |
| **BPU** | 高毛利產品線，佔比提升可帶動整體獲利成長 |
