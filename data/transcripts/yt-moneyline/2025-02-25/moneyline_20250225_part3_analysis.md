## 🌍 市場總體觀察

### 人形機器人產業深度剖析

#### 產業時程預估
- **2025年**: 人形機器人量產元年（工廠應用為主）
- **工廠應用**: 未來5-10年逐步導入
- **居家機器人**: 複雜度更高，需要更長時間
- **2040年預測**: 全球人形機器人數量可能達100億台（超過80億人口）
  - 居博認為此數字可能誇大，但方向正確
  - 每個家庭可能不只一台機器人

#### 人形機器人智慧化等級（Level 0-5）

| 等級 | 名稱 | 機器人能力 | 人類角色 |
|------|------|-----------|---------|
| Level 0 | 無自主性 | 結構驅動，重複動作 | 完全操控 |
| Level 1 | 輔助控制 | 簡單關節驅動 | 遙控與操作 |
| Level 2 | 部分自主 | 演算法驅動，執行規劃好的軌跡 | 運算規劃、行為設計 |
| Level 3 | 條件自主 | 感測控制、定位導航、環境感知 | 設計任務 |
| Level 4 | 高度自主 | 任務推理、知識圖譜、理解語文 | 觀察者 |
| Level 5 | 完全自主 | 自主決策行動、執行複雜任務 | 僅監督 |

- 目前自駕車與高階機器人（如小米機器狗）大約在Level 2
- 人形機器人要達到居家應用至少需Level 3-4

#### FIG AI 家居機器人展示
- 展示兩個機器人自主整理超市購回的食物
- 機器人能辨識從未見過的物品（蔬菜、水果、蛋、咖啡豆等）
- 自動判斷放冰箱、水果欄、抽屜等正確位置
- 拿蛋不會捏破（力道控制精準）
- 動作流暢協調

#### 核心技術：VLA（視覺語言動作模型）
- **視覺語言模型（VLM）**: 將大語言模型 + 視覺編碼結合，讓AI具有「看」的能力
- **訓練方式**:
  1. **對比學習**: 大量餵入圖片資料（貓、狗等），讓AI學會辨識
  2. **零樣本學習**: 給予標籤（毛茸茸、四隻腳、喵喵叫），讓AI推理未見過的物體
- **雙系統架構（Helix展示）**:
  - System 1: 快速反應的視覺運動系統（工廠級，重複性高、速度快）
  - System 2: 大規模互聯網預訓練視覺語言模型（思考能力）
  - 兩系統協作讓動作更協調流暢

### 人形機器人三大核心技術

#### 1. 處理器（大腦）
- 決策學習（知識圖譜、AI推理）
- 人機互動（自然語言處理、語言理解）
- 多重互動（機器人與機器人之間的群組溝通）

#### 2. 感測器（皮膚/感官）
- 影像感測（眼睛）
- 聽覺感測（耳朵）
- 嗅覺感測/電子鼻（尚未普及，手機也還沒有此功能）
- 觸覺感測（機械皮膚）
- 震動感測、慣性感測、溫度感測、壓力感測、高度感測

#### 3. 致動器（肌肉/骨骼）
- 自主導航、肢體移動
- 協調控制
- 搬運重物
- 臉部表情控制

### 特斯拉Optimus進展
- **2021年8月**: 概念圖發表
- **2022年**: 原型機亮相
- **2023年3月**: 第一代Optimus
- **2023年12月**: 第二代Optimus
- **2025年**: 預計在特斯拉工廠開始執行簡單工作

#### 特斯拉自駕晶片（Hardware 3.0/4.0）
- 使用ARM Cortex A72處理器（4核心，2.2GHz）
- GPU用ARM Mali G7E
- **核心**: 特斯拉自行設計的NPU（神經處理器），2.1GHz，73 TOPS（TeraFlops浮點運算）
- Hardware 4.0已量產，5.0正在設計中
- 自駕車與機器人共用同一個大腦架構

#### 成本結構
- **大腦（FSD晶片）**: 僅佔3.8%
- **手部**: 約9,500美元，佔比最高17.2%（靈活度最難）
- **最大成本來源**: 機械元件（馬達、感測器、減速器）
- 人形機器人最難的不是大腦，而是機械元件

#### 勞退請領條件
- **年滿60歲**即可開始請領
- **年資超過15年**: 可選月退或一次領
- **年資不滿15年**: 只能選擇一次領
- 未滿60歲喪失工作能力可提早請領
- 帳戶不會消失，受益人死亡仍可由遺族請領

#### 試算範例
- **假設條件**: 月薪5萬、年資35年、提撥率6%（僅雇主）、報酬率3%、月退領19年
- **一次領**: 約223萬
- **月退**: 每月12,829元
- **若自提6%**: 月退約24,000元（翻倍）
- 所得替代率約25%（僅雇主提撥）；加自提可達50%

#### 查詢方式
- 進入勞保局E化服務系統
- 選擇「個人」登入
- 可用自然人憑證、虛擬勞保憑證、行動自然人憑證、金融電子憑證、**行動電話認證**（最方便）
- 注意：使用行動電話認證時須**關閉WiFi**，改用手機行動網路
- 可查詢所有工作紀錄、雇主提撥明細、帳戶累計金額

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **VLA (Vision-Language-Action Model)** | 視覺語言動作模型，結合視覺辨識、語言理解與動作執行的AI模型 |
| **VLM (Vision-Language Model)** | 視覺語言模型，讓AI具有「看」的能力的多模態系統 |
| **對比學習 (Contrastive Learning)** | 透過大量圖片比對訓練AI辨識能力的學習方式 |
| **零樣本學習 (Zero-shot Learning)** | 透過語意標籤讓AI推理從未見過的物體的學習方式 |
| **電子鼻 (Electronic Nose)** | 嗅覺感測器，可偵測氣體濃度（如一氧化碳），目前尚未整合至手機 |
| **TOPS (Tera Operations Per Second)** | 每秒萬億次運算，衡量AI晶片運算能力的單位 |
| **Optimus** | 特斯拉人形機器人，已發展至第二代 |
| **諧波減速器** | 人形機器人關節中的關鍵零組件，將高速低扭矩轉為低速高扭矩 |
| **滾珠螺桿** | 將旋轉運動轉換為直線運動的精密機械元件，為機器人關節核心零組件 |
| **FIG AI** | 與Meta合作的人形機器人公司，專注家居機器人開發 |
| **GTC (GPU Technology Conference)** | NVIDIA年度GPU技術大會，為AI產業最重要的展覽之一 |
| **勞退新制** | 2004年開始實施的勞工退休金制度，雇主每月提撥至少6%至個人帳戶 |
| **所得替代率** | 退休後每月可領金額佔退休前薪資的比例 |
