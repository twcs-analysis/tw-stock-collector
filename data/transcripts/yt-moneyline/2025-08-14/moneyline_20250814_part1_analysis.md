## 📈 技術面分析

### 大盤技術分析

#### 波浪理論觀點（柯哥老師）
- 台股挑戰歷史高點24,416（差約10點）
- 已出現5,500-6,000億以上的爆量訊號
- **預估**: 8月中旬至9月底之前會出現頭部訊號
- **修正幅度**: 做頭後至少2,000-4,000點修正
- **重要**: 做頭不等於翻空（需跌破高點20%才是翻空）

#### 國安基金退場預測
- 預估10月6日至10月14日之間召開會議
- 推估約10月11日前後一天
- 在正式宣布退場前（約1個月前），大盤已會形成頭部
- **結論**: 國安基金在場期間持續做多，但須留意頭部訊號

#### 爆量訊號解讀
- 歷史上5,500-6,000億量能出現，通常是頭部或底部訊號
- 2024年7月11日、2025年4月9日皆出現過
- 爆量後尚未出現翻空K線，仍可做多
- 但個股已有10-20%開始做頭

### 個股做頭警訊辨識

**必須賣出的三種型態**:
1. **M頭**: 大盤創高但個股未能跟進創新高，形成雙頭
2. **三重頂**: 大盤創高但個股出現三個高點都無法突破（威力最大）
3. **頭肩頂**: 量能有高點，第三個高點無法過第二個高點（速度最快）

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **13F報告** | 美國SEC要求管理資產超過1億美元的投資機構每季申報的持股報告 |
| **CPI** | 消費者物價指數，衡量通膨的重要指標 |
| **CSP** | Cloud Service Provider，雲端服務提供商（亞馬遜、微軟、Google、Meta） |
| **國安基金** | 國家金融安定基金，政府護盤工具，進出場時機影響市場信心 |
| **上升軌道** | 股價沿著趨勢線持續走高的技術型態，跌破軌道下緣為賣出訊號 |
| **月線（20MA）** | 20日移動平均線，中期趨勢判斷依據 |
| **M頭/三重頂/頭肩頂** | 三種經典的頭部反轉技術型態 |
| **爆量訊號** | 成交量異常放大，可能代表趨勢即將反轉 |
| **做頭** | 股價在高檔形成頂部型態，預示即將拉回修正 |
| **ETF權重再平衡** | 定期調整ETF成分股權重回到目標比例，達到賣高買低效果 |
