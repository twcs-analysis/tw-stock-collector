## 產業分析與投資建議

### 議題一：緯穎（3231）目標價八千元？

**背景**: 外資一家接一家調高緯穎目標價，從當前四千多元看到八千元

**分析重點**:
- 目前股價約四千多元，距離八千元目標價尚有一倍空間
- 節目早在9月30日時從三字頭就開始推薦緯穎，至今已到四字頭
- **母公司緯創（3231）**: 股價距離前高15%尚未突破，有挑戰前高的機會
- 緯創下檔支撐約在135元，往下空間有限
- 緯創本益比僅22倍（以過去一年EPS計算），若以未來一年更高EPS估算，六千元以上可期

**操作建議**:
- 緯穎：拉回到紅黑K棒一半位置可上車
- 緯創：可作為買不起緯穎的替代標的
- 緯穎有可能超越信驊成為股王

**風險提示**: 新華本益比偏高，緯穎與新華可能形成比價效應

### 議題二：台積電（2330）開高走低的解讀

**背景**: 台積電公布11月營收創新高，但市場反應平淡，今日開高走低

**分析重點（俊嚴觀點）**:
- **量能不足**: 台積電五日均量3.3萬張，但所需攻擊量水準為每日3.7萬張，缺乏攻擊量
- **整理屬正常**: 法說會後創新高再拉回整理，過去通常需要2週到半個月
- **買點區間**: 1,390~1,420元之間為合理買點區間
- **目標價**: 合理估值為1,600~1,630元，若公開漲價計劃或明年貢獻明朗，有機會更高
- **上升軌道**: 月線圖顯示台積電處於非常整齊的上升軌道中

**外資動態分析**:
- 5月份外資大量匯入（4月股災1,730點後第一個月份），一路拉抬
- 10月份外資賣超近1,000億，但淨匯入仍為正向
- **關鍵指標**: 台幣若維持在30.6以下（弱勢），外資暫無大動作
- 台幣一旦聚貶結束，外資十早都會回來買

**背景**: 上週連跌五天後，昨天跳空缺口大漲5.8%，站回所有均線

**分析（明漢觀點）**:
- 化解了上週做頭疑慮，NASDAQ指數也同步化解
- AI泡沫論退散：雲端業者財報亮眼，AI需求實質存在
- **OpenAI市佔率**: 生成式AI聊天機器人市場佔60%，微軟14%，Google 13%
- OpenAI仍持續虧損，但使用人數達7億，計劃2027年IPO
- AI晶片市場年增34%，GPU仍是最大宗，ASIC（客製化晶片）也快速增長

### 美科技ETF投資策略

**ETF選擇邏輯**:
- 選擇資訊科技比重超過兩成的ETF表現較好
- **推薦標的**: 00980B（資訊科技比例相對較高）
- 受益人數隨比例增高而明顯增長

**操作策略**:
- 月線為重要支撐，每次回到月線附近都有買盤承接
- 衝高不追，拉回到月線甚至跌破月線才是好買點
- 等待聯準會動向更明確後，科技族群將更加強勢

**支撐因素**:
1. 美國政府關門期間科技族群表現相對較好
2. 降息趨勢下科技族群為首選（2019~2024年降息後一年前三名產業）
3. 非必需性消費也受惠（特斯拉、網購等）

## 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **QLC SSD** | 四層式儲存單元固態硬碟，每個儲存單元可存放4位元資料，容量大但速度較慢 |
| **HBM** | 高頻寬記憶體（High Bandwidth Memory），AI加速器專用記憶體，價格高昂 |
| **NAND Flash** | 非揮發性快閃記憶體，用於SSD、手機儲存等，目前嚴重缺貨 |
| **PCIE6** | 第六代高速匯流排介面，傳輸速率為PCIE5的兩倍 |
| **月天量/次天量** | 技術分析概念，月K線出現近年最大成交量後，若後續出現第二大量且股價站上，代表底型確認完成 |
| **攻擊量** | 個股或指數突破壓力所需的最低成交量門檻 |
| **AIDAPTAPP+** | 群聯推出的AI解決方案，讓PC端可直接運行AI應用 |
| **OpenAI** | 全球最大生成式AI公司，ChatGPT開發商，計劃2027年IPO |
| **ETF 00980B** | 台灣掛牌的美國科技類ETF，資訊科技比重較高 |
