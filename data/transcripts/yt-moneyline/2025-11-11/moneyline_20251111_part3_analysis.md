## 產業分析與投資建議

### 議題一：年底報喜行情 — 抱緊處理到農曆年

**明漢觀點**:

#### 美股基本面支撐強勁
- 美股財報季已到尾聲，超過八成公司優於預期（過去平均約六成多接近七成）
- 整體獲利年增15%，非常亮眼
- **主要貢獻**: 通訊與科技兩大產業接近九成優於預期
- S&P 500第三季EPS年增率大幅走高

**美股七雄結構變化**:
- 過去幾乎一枝獨秀，但因基期偏高，七雄成長力道慢慢降低
- 其他公司慢慢跟上，但科技七雄仍是表現最好的

#### 降息趨勢與股市多頭

**關鍵對比：去年vs今年**:
- 今年走勢與去年極度相似
- 去年：8月非農就業不如預期 → 降息預期升溫 → 年底三次降息 → 12月偏鷹派暴跌
- 今年：相同路徑，10月降息，12月降息機率從100%跌到六成多
- **去年12月教訓**: 降息後聯準會暗示暫停，股市大跌後進入長時間整理（非空頭）
- **重要觀察**: 月線為多頭分界，跌破月線回來 = 多頭；跌破季線 = 格局結束

**降息機率追蹤**:
- 10月降息時12月降息機率100% → 現跌至六成多
- 若持續往七成、八成回升 → 資金行情來臨
- 若持續下修 → 股市反彈空間受限

**CPI為下一個關鍵**:
- 目前核心CPI約3%
- 只要沒有暴衝，降息預期往上修正，股市繼續多頭
- 本週政府關門可能延遲數據公布

#### 報喜行情選股策略

**年底做夢行情的邏輯**:
1. **12月全球行情**: 公司編列隔年預算，研究員估值，性善者多→明年故事樂觀→本益比下降→股價易漲
2. **2月紅包行情**: 台灣獨有，每年2月特別強
3. **資金流**: 每年12月全球股票基金流入量特別大（過去10年統計）
4. **今年10月資金**: 已經大量流入美國ETF，月走月高

#### 營收獲利創新高選股法

**三條件篩選法**:
1. 營收創歷史新高
2. 本業獲利創歷史新高
3. 最終獲利創歷史新高

**重點**: 盡量選三個條件都符合的，優於兩個條件，優於一個條件。避免靠業外收入創高的公司。

**範例**: 創見（2451）雖獲利創高，但有3億多匯兌收益，扣除後本業未創新高

#### 個股推薦

**台達電（6669）**:
- 營收創歷史新高 + 獲利創歷史新高
- 雖有雜音但基本面扎實
- 股價對就對，莊家錯比你因為他覺得有問題

**創蓬（散熱/機殼相關）**:
- 獲利創高 + 營收創高
- 金屬衝壓製程
- 呈現整理走勢，為很好的佈局點位

**宜鼎（5765）**:
- 三個條件都創新高
- 記憶體相關，基本面比創見還好
- 持續往上走不需做最高動作
- 長線拉回都可以持續關注

**致茂（2360）**:
- 顧家（營收）沒有創見強但基本面更好
- 會選擇致茂而非創見
- 價格更具投資價值

### 議題二：美國政府關門分析

**夢到觀點**:

#### 關門進展
- 今天為第41天
- **即將結束原因**: 民主黨在平價醫療法（歐巴馬健保）延長議題上立場鬆綁
- **流程**: 參議院同意 → 眾議院同意 → 川普簽字 → 臨時撥款（僅到明年1月30日）
- **撥款到期後**: 重新進入預算審議流程，有可能再度關門

#### 歷史對照
- 1976年以來的政府關門多集中在9~12月
- **反覆關門先例**: 1977年（10/31結束→11/30再度關門）、1995年也類似
- 不排除短期解除後再度關門的可能

#### 關門期間股市表現（歷史統計）

**S&P 500指數統計**:
- 關門初期（前5天）：股市通常下跌
- 關門中期：開始慢慢回升
- 關門40天後：股市多已回正
- **關門後一年報酬**: 幾乎都是正報酬（僅1997年與2018年例外）

**結論**: 政府關門對股市衝擊僅為短期，中長期無負面影響

#### 關門對經濟的衝擊

**美國國會預算辦公室估算**:
- 關門6週（約42天）：Q4 GDP減少約1.5個百分點
- 關門4週：衝擊較小但仍顯著
- **長尾效應**: 即使關門結束，Q1~Q4的GDP影響仍為負值
  - 約150億美元的經濟活動無法恢復
  - 政府僱員失業的消費信心衝擊持續存在
  - 聯邦旅遊業受影響

#### 消費者信心的隱憂

**核心觀點**:
- 美國GDP約七成以上與消費有關
- 最近消費者信心指數（密西根大學與經濟資商局）持續下滑
- **歷史規律**: 每次經濟衰退前，消費者信心都是先行指標，都是往下掉
- Q2 GDP看似強勁，但主要靠進口貢獻（提前拉貨效應），消費實質偏弱
- 若消費者信心持續下滑，明年經濟表現可能被拖累
- **但目前**: 尚無明顯衰退跡象

## 技術面分析

### 美股技術面（明漢觀點）

**NASDAQ指數**:
- 月線為多頭重要支撐
- 每次跌破月線都是買點（只要能回站）
- 若跌破季線 = 格局結束

**降息暫停的整理模式**:
- 去年偏鷹派後：整理約一個月
- 本次若降息暫停：預期也是整理而非走空
- 川普關稅是去年整理後的額外利空（與降息無關）

### 台積電股利與估值

**股利增加的估值影響**:
- 法說會時法人將今年EPS從60元上修至64元（高出市場預期4元）
- 4元 x 25倍本益比 = 股價應上漲約100元
- 但目前股價回到法說會當時水準（約1,420~1,440元）
- **股利非高殖利率概念，而是成長股利**：反映獲利持續創高、賺太多必須配給股東

## 策略總結

### 操作策略

1. **報喜行情佈局**: 12月年底做夢行情 + 2月紅包行情，抱緊到農曆年
2. **選股邏輯**: 營收 + 本業獲利 + 最終獲利「三創新高」為首選
3. **台積電**: 股利增加為正面催化劑，外資偏好股利，短線有望反應
4. **降息觀察**: 12月降息機率為關鍵，若回升則資金行情再起
5. **政府關門**: 即將結束但可能反覆，對股市衝擊短期且有限

### 風險管理
- 降息若暫停，股市進入整理而非崩盤，但短線衝高不宜追
- 消費者信心持續下滑為明年最大隱憂
- 政府關門臨時撥款僅到1月30日，屆時可能再度關門
- CPI若暴衝將打擊降息預期

## 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **報喜行情** | 年底因企業公布樂觀展望、法人編列隔年預算而帶動的股市上漲行情 |
| **紅包行情** | 台灣農曆年前後獨有的股市上漲現象，通常出現在2月 |
| **偏鷹派** | 聯準會傾向維持高利率或放緩降息的態度 |
| **CPI** | 消費者物價指數，衡量通膨的重要指標 |
| **臨時撥款** | 美國政府關門後通過的短期資金法案，僅供維持一段時間的政府運作 |
| **平價醫療法** | 又稱歐巴馬健保（Affordable Care Act），美國全民健保政策 |
| **S&P 500** | 標準普爾500指數，追蹤美國500家大型上市公司的股市指數 |
| **密西根大學消費者信心指數** | 美國密西根大學每月發布的消費者信心調查，為重要經濟先行指標 |
| **本益比（P/E）** | 股價除以每股盈餘，衡量股票估值的常用指標 |
| **成長股利** | 非因高殖利率吸引投資人，而是因為公司獲利大幅成長，被動增加股利配發 |
