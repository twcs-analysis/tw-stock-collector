### 加密貨幣與區塊鏈

#### 美國加密貨幣三大法案（本週參議院審議）

**法案一：穩定幣法案**
- 發行穩定幣必須購買美元相關儲備，每月揭露
- 境外不合規者不能發行
- 目的：擴大數位美元影響力與支付優勢

**法案二：監管邊界法案**
- 界定SEC（證管會）與CFTC（商品交易委員會）的管轄範圍
- 放鬆監管，有利海外平台進入美國市場
- 目的：實現「全球加密金融中心」目標

**法案三：反CBDC法案**
- 禁止央行發行數位貨幣
- 只允許銀行或私人企業發行
- 目的：維護自由市場，與中國數位人民幣形成差異化

#### 三大法案綜合影響
1. **鞏固美元與美債**: 數位經濟站穩後，全球資金流入支撐美元
2. **與中國競爭**: 完全相反的監管路線，吸引國際資金
3. **資產鏈上化**: 股票、商品、房產等未來可在鏈上交易
4. **比特幣受惠**: 區塊鏈資金量增加，數位黃金地位更加鞏固

#### 比特幣市場現況
- **上市公司持有量**: 今年大幅增加，價值創新高
- **活躍地址數下降**: 散戶交易減少，但機構持有增加
- **比特幣ETF**: 資金持續淨流入，近資產創新高
- **結論**: 從散戶主導轉向機構主導，波動變緩但趨勢穩健上升

#### 相關ETF

2. **00983A (中信創新基金)**: 含加密貨幣、AI應用，10元上市已漲至約10.8元

### 個股技術面教學

#### KD指標 + 籌碼配合判讀

**判讀方法**:
1. 均線斜率：上升偏多、下降偏空
2. 成交量：5日均量上方為主角，下方為配角
3. DMI指標：紅線在綠線上方偏多，交叉反轉為出場訊號

**實例分析**:
- **紅海 (2311)**: Q1 EPS 3元、累積營收成長90%，但股期量低、DMI多空難判，基本面好但技術面尚未啟動
- **南亞科 (2408)**: 從低點爆量上漲，DMI綠色超越紅色為出場訊號；Q2營收年增46%，本淨比0.82
- **揚明 (8215)**: Q1 EPS連減7%、營收連減12%，均線往下，偏空股票
- **中興電 (1513)**: 除息後DMI指標受干擾，需2-3週恢復參考價值
- **台新金 (2887)**: 均線網上彎，連漲多天，但Q1 EPS連減、營收僅增5%，主要看合併後H2效應

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **中實戶** | 單季成交1至5億元的投資人，全台約23,000人 |
| **400張大戶** | 持有單一個股超過400張的大股東或法人 |
| **CPO** | 共封裝光學（Co-Packaged Optics），下一代光通訊技術 |

| **CBDC** | 央行數位貨幣（Central Bank Digital Currency） |
| **KD指標** | 隨機指標，衡量股價相對於一定期間內高低點的位置 |
| **DMI** | 趨勢方向指標（Directional Movement Index），判斷多空方向 |
| **Put/Call Ratio** | 賣權/買權比率，高於100代表偏多 |
| **未平倉量** | 股票期貨尚未結清的合約數量，越大代表未來波動越大 |
| **定時定額** | 每月固定金額定期買入，利用時間平均成本 |
| **FedWatch** | CME聯準會利率觀察工具，反映市場對升降息的預期機率 |
| **股期** | 個股期貨，以個別股票為標的的期貨合約 |
