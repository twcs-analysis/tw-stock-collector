- **當日表現**: 最高攻上1,158元，逼近歷史新高1,160元

- **目標價**: 持續創新高，無明確上限
- **停損點**: 短線以5日線為參考

### 二、連接器產業

#### 貿聯-KY (3665)
- **產業地位**: 特斯拉電源管理線束獨家供應商，AI主動式電纜供應商
- **客戶擴展**: 四大雲端服務商（AWS、Meta等）全部包進去，下半年量產
- **估值**: 明年本益比不到20倍，以明年本益比計算目標價有千元潛力
- **當日股價**: 885元（高檔拉回第4天）
- **股性分析**: 上漲後整理約3-4天，整體呈上升軌道
- **操作建議**: 底部出量後籌碼穩定，整理時為偏多買點
- **目標價**: 以明年20倍本益比計算，千元以上
- **停損點**: 高檔暴量或達明年20倍本益比時注意整理風險

### 三、PCB（印刷電路板）族群

#### PCB產業總覽
- **當日表現**: 至少6檔漲停，成交量前兩名皆為PCB族群
- **核心判斷**: 與AI相關的PCB族群屬於「正熱」，非AI相關的PCB有過熱疑慮
- **產業背景**:
  - 2022年疫情後低階/中階CCL供過於求，持續至今
  - 2023年AI帶動高階CCL需求強勁成長
  - 高階波纖布（Low DK）缺貨，日東紡2026年擴產至5倍
  - 今年主要缺貨：Low CTE波纖布

#### 副橋 (6244)
- **產業題材**: M8等級CCL已通過認證，今年出貨比約20%，Q4提升至50%
- **籌碼面**: 投信前幾天買了3,000多張，成本約36-37元
- **當日表現**: 漲停
- **操作建議**: 漲停後注意隔日沖風險，空手等拉回至頸線（40元附近）再布局
- **目標價**: 隨下半年業績持續增長，中線看好
- **停損點**: 頸線40元跌破或投信成本36-37元跌破

#### 台燿 (6274)
- **產業題材**: 全球僅三間可大量生產Low CTE波纖布的廠商之一
- **擴產計劃**: 今年擴建8條Low DK產線
- **操作建議**: Low CTE缺貨受惠標的，可持續留意

#### 建鼎 (3044)
- **產業題材**: CCL材料供應鏈
- **操作建議**: 與副橋、台燿同屬正熱PCB族群

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **CCL** | 銅箔基板（Copper Clad Laminate），PCB的核心原材料 |
| **Low DK/Low DF** | 低介電常數/低介電損耗，高頻高速訊號傳輸所需的材料特性 |
| **Low CTE** | 低熱膨脹係數，用於BTH/HBM載板材料 |
| **波纖布** | 玻璃纖維布，CCL的三大成分之一，高階產品由日東紡主導 |
| **Q Glass** | 石英玻璃纖維布，DK值最低的材料，可替代傳統波纖布 |
| **HVLP** | 超低輪廓銅箔（Hyper Very Low Profile），等級越高表面越光滑 |
| **PTFE** | 聚四氟乙烯（鐵氟龍），介電特性最好的材料 |
| **BPU** | 基板處理單元，GPU模組相關 |
| **CPO** | 共封裝光學（Co-Packaged Optics），下一代光通訊技術 |
| **FSD** | 完全自動駕駛（Full Self-Driving），特斯拉自駕系統 |
| **台指期結算** | 台灣期貨指數每月第三個週三結算 |
| **主動式ETF** | 由基金經理人主動選股的ETF，非被動追蹤指數 |
