## 📊 市場總體觀察

### 台股走勢

- **法人動態解讀**：外資與投信站在賣方，代表對輝達財報態度謹慎，外資有去高證（降低部位）傾向
- **外資買超前十名**：群創、華邦電、欣興電子、台新金、永豐金、南亞科、漢翔，全部為「未接比較低」的個股
- **外資賣超重點**：
  - 欣興（買）vs 景碩（賣）：景碩對漲價態度較保守，外資轉向欣興與南電
  - 嘉澤（2374）：機器人漲幅最大的龍頭，外資趁高賣出9,500張獲利了結，盤中仍創新高但收黑K
  - 東元（1504）：投信與外資同步獲利了結，紅海併購後漲幅大
- **投信買超特色**：
  - 中信金、真頂、精元電、南亞、光寶科、致茂、台巨、神基
  - 投信開始轉向電子股，以往偏重金融通路股
  - 櫃買市場投信更積極：行勝利（高壓電源供應器）、成田、中光電（軍工國防）、台特化（先進製程特化）

### 美股影響

- **聯準會降息分析**：
  - 鮑爾上週改口提及「寬鬆」與「調整」，但內容細看後發現只是「門縫」
  - 6-7月美國通膨率仍高達2.7%，比4月上升0.4%
  - 8月關稅大部分才開始上路，物價上漲壓力尚未完全反映
  - 美國就業能力下降、職缺開放下降、勞動參與率下降
  - 鮑爾認為美國經濟進入「脆弱的高原期」
- **降息前景**：
  - 9月預防性降息一碼的機率高
  - 但此後何時再降息不確定
  - 中性利率水準會高於2010年（0.25%），不會進入循環性降息
  - 市場進入「選股不選市」的格局

### 國際市場動態

- **美國製造政策**：台積電被迫增加美國投資，但技術領先是最大籌碼
- **台積電兩奈米產能**：
  - 年底可達4.5萬至5萬片
  - 明年上看超過10萬片
  - 加計美國廠，2028年可達20萬片
  - 美國廠佔比要提升至整體30%
- **全球晶片法案競賽**：歐盟、美國、韓國、日本、中國都提供半導體補助方案

## 📈 技術面分析與操作策略

### 聯準會降息與資金行情

1. **預防性降息**：9月降一碼後，11月/12月觀望，非循環性降息
2. **中性利率**：高於2010年水準，美國不會回到零利率時代
3. **選股不選市**：大盤橫盤但個股創高不斷，基本面選股回測月線買進，技術面選強勢股不破軌道線持有

### 台積電操作策略

- **定義**：目前為「南風」非「北風」，不用太過恐懼
- **過高操作**：過歷史高且無雙背離 → 做多
- **出場訊號**：出現巨量長黑 + 隔天開低走低 → 出場
- **量縮策略**：越漲量越少 → 保留現金，不再加碼
- **群魔亂舞警訊**：若只漲低價右下角個股（無業績股），代表末升段亂舞，需配場減碼

### 個股操作原則

- **基本面選股**：回測月線時風險選擇低買進（如PCB族群）
- **技術面選股**：強勢股不破軌道線就持有，破了善設停損
- **大量區間低點**：作為停損參考
- **創高個股**：觀察投信是否持續買超，籌碼優勢為必要條件

## 📋 投資策略總結

1. **先進製程是必買方向**：蝕刻金屬用量成長2.6倍，中砂（1560）為首選，台積電訂單佔八成
2. **軍工國防+AI雙題材**：行勝利（新勝利）本益比最低，具備UPS+軍工+機器人三重概念
3. **CPO矽光子**：波羅威為龍頭，10-11月技術突破揭曉
4. **廠務工程受惠建廠潮**：漢唐為核心，聖暉/帆宣/洋基為比價標的
5. **9月佈局方向**：法人買超+籌碼優勢+題材加持的個股
6. **風險管理**：過高不追、巨量長黑出場、群魔亂舞減碼

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| 預防性降息 | 在經濟尚未明顯衰退前，為預防風險而提前降息的措施 |
| 脆弱的高原期 | 經濟成長動能趨緩，就業與消費同步降溫，處於高檔但脆弱的狀態 |
| 中性利率 | 既不刺激也不抑制經濟成長的均衡利率水準 |
| 蝕刻金屬 | 半導體製程中用於蝕刻圖案的金屬材料，先進製程用量大增 |
| 廠務工程 | 半導體工廠的無塵室、機電系統等基礎設施工程 |
| UPS（不斷電系統） | Uninterruptible Power Supply，確保供電不中斷的電力設備 |
| FOMC | Federal Open Market Committee，聯邦公開市場委員會 |
| 晶片法案 | 各國為確保半導體供應鏈安全而推出的補助與激勵法案 |
| 群魔亂舞 | 市場末升段特徵，無業績的低價股輪番漲停，為出場警訊 |
| 去高證 | 降低持股部位，減少曝險 |
