## 📊 市場總體觀察

### 台股走勢

- **收盤表現**：台股開高走高收高，收在24,500點之上，收盤價創歷史新高
- **盤中高點**：距離歷史最高點（24,551）僅差不到10點
- **上漲幅度**：大漲244點
- **成交量**：4,600億元，未達5,000億，量價出現背離疑慮
- **關鍵觀察**：股價已到新高價位，但成交量尚未跟上，需留意是否出現「量價背離」
- **三大法人動態**：
  - 外資：連續兩天賣超台股
  - 投信：連續兩天賣超台股
  - 自營商：大買110億元，成為推升指數主力
- **風險警示**：自營商買超多為一日行情，部分為權證避險買盤，隔日可能賣出

### 美股影響

- **輝達財報**：今晚盤後公布，為台股明日走勢的關鍵催化劑
- **市場預期**：輝達本業營收穩健成長（非爆發性成長），H24有回補利潤，可能戰勝分析師預期
- **重點觀察**：GB300是否在下一季出貨，將決定輝達的財測展望
- **蘋果新機**：確定9月9日亮相，但今年拉貨量為歷年最低，蘋果概念股短期期待不宜過高

### 國際市場動態

- **美國白宮**：商務部長驚爆內幕，可直接打電話給台積電總裁魏哲家，威脅若不來美投資將收回補助

## 📈 技術面分析與操作策略

### 大盤技術面

1. **歷史高點挑戰**：前高24,551點為關鍵關卡
2. **量價背離**：收盤創新高但成交量僅4,600億，未創新高量
3. **KD指標**：在指標50附近做正交叉，暗示24,551應會突破
4. **雙背離警訊**：若過高時量不配合（雙背離），應在賣方
5. **操作策略**：
   - 過24,551且量能配合 → 做多
   - 過高後出現巨量長黑 → 隔天開低走低立刻出場
   - 量越大價越高但量越少 → 保留戒心

### 台積電技術面

- **關鍵價位**：1,200元為心理關卡
- **觀點**：台積電為大型高價股，三個條件（大型、高價、非低價接）都不符合當前盤面特徵
- **判斷**：台積電不一定漲得比小型股或其衛星股更多
- **操作建議**：看大做小，以台積電走勢為指標，操作其供應鏈小型股

### 個股操作原則

- **強勢股**：未跌破十日均線前持有，跌破即設停損
- **突破股**：缺口不回補即持有，回補則出場
- **分盤交易股**：不好操作現貨，可透過股期參與，但注意未沖銷比例限制

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| CPO（共同封裝光學） | Co-Packaged Optics，將光學元件與晶片整合封裝，提升資料傳輸效率 |
| 矽光子 | Silicon Photonics，利用矽基材料傳輸光訊號的技術 |
| ABF 載板 | Ajinomoto Build-up Film，味之素堆積膜基板，用於高階晶片封裝 |
| BT 載板 | Bismaleimide-Triazine，雙馬來醯亞胺三嗪樹脂基板，用於IC封裝 |
| 分盤交易 | 證交所對異常波動股票採取的交易限制措施，每5分鐘撮合一次 |
| 股期未沖銷比例 | 個股期貨未平倉量佔流通股本的比例，超過15%將被限制 |
| 減速機 | 馬達輸出高速旋轉後，透過減速機降低轉速、提高扭力的精密傳動裝置 |
| 量價背離 | 股價創新高但成交量未同步放大，暗示上漲動能不足 |
| 雙背離 | 價格創新高但量能和技術指標同時未創新高 |
| 主動式 ETF | 由基金經理人主動選股操作的ETF，相對於被動追蹤指數的傳統ETF |
| 看大做小 | 以大盤方向為參考，實際操作中小型個股以獲取更高報酬 |
