## 📈 技術面分析與操作策略

### 黃金分割率三種修正

扣老師以黃金分割率將多頭反轉後的修正分為三種：

| 修正類型 | 回檔幅度 | 後續走勢 | 對應台積電價位 |
|----------|----------|----------|---------------|
| 強勢整理 | 0.382 以內（超強勢 0.191 以內） | 修正結束後回到上漲趨勢 | 台積電維持 1,200 元以上 |
| 中級整理 | 0.5 以內 | 50% 機會重新回到上漲趨勢 | 台積電跌至 1,100 附近 |
| 弱勢整理 | 0.618 以上 | 不易回到上漲趨勢，轉為空頭 | 台積電跌破 1,000 元 |

**目前判斷**: 台積電未翻空、鴻海未翻空，大盤處於「強勢整理」第一階段。

### 操作策略
1. **短線反彈靠近 25,100～25,410 區間上緣站賣方**
2. **下跌過程中碰到重大利空，可強短操作但上來仍要賣**
3. **底部翻多訊號出現前，屬於「急跌重挫搶短」格局**
4. **空頭做頭股票任何反彈靠近第二高點都要站賣去換股**
5. **上升軌道股票沿五日、十日均線持續做多，帶量衝高找賣點、拉回量縮找買點**

### 多頭股與空頭股辨識
- **多頭股特徵**: 底部越墊越高、MACD 收斂往上、帶量衝高→量縮拉回→再衝高
- **空頭做頭特徵**: 指數過高四五次但個股無法超越前波高點，融資偏高，溫水煮青蛙
- **換股策略**: 從空頭股中撤出資金，轉進上升軌道或底部翻多股票

## 📋 投資策略總結

### 短期（1-2 週）
- 大盤等幅滿足壓力已到（25,520），今日高點 25,410 後爆量拉回，短線宜降低持股
- 反彈靠近 25,100 以上宜站賣方，短線搶反彈需設停損
- 台積電 1,200～1,285 元區間操作，鴻海 197～215 元區間操作
- 空頭做頭股票（如台肥 1802）任何反彈都是出場機會

### 中期（1-3 個月）
- 多頭反轉進入強勢整理階段，尚未進入中級或弱勢修正
- 關鍵觀察：台積電是否跌破 1,200 元（進入中級修正）或 1,000 元（確認空頭）
- 被動元件（國巨 2327、上銀 2049）底部翻多，中線布局時機
- 做頭股票與翻空股票數量會隨指數每次過高而增加

### 風險評估
- **高度風險**: 多頭反轉做頭訊號已出現兩個（巨量長黑、利多後開高走低全面拉回）
- **中度風險**: 國安基金預計 10 月退場，退場前後常伴隨較大波動
- **低度風險**: 台積電、鴻海未翻空，強勢整理格局下修正幅度有限

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| 黃金分割率 | 以 0.382、0.5、0.618 等比率計算股價回檔幅度的技術分析工具 |
| 等幅測量 | 以前波整理區間的幅度，預測突破後的等距漲幅目標 |
| 籌碼沈澱 | 股票經過量縮整理後，浮額被清洗，籌碼集中至主力手中 |
| MACD 收斂 | 移動平均收斂背離指標從低檔開始收窄，通常為轉多訊號 |
| 做頭 | 股價在高檔形成頭部型態，通常伴隨爆量與開高走低 |
| 溫水煮青蛙 | 股價緩慢下跌，投資人不知不覺中深度套牢 |
| 融資斷頭 | 融資買進的股票跌幅超過維持率（約 22%），券商強制賣出 |
| 翻桌點 | 股價從底部開始翻多的關鍵轉折點 |
| 本益比（P/E） | 股價除以每股盈餘，衡量股票估值高低的指標 |
