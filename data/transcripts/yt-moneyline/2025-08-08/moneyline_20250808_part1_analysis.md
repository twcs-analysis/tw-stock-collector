## 🌍 市場總體觀察

### 台股市況分析

#### 大盤表現
- **收盤**: 逼近歷史新高，距離不到400點
- **台積電 (2330)**: 盤後公佈7月營收3,231.1億元，月增22.5%、年增25.8%，史上第二高
- **累計營收**: 1至7月累計創下史上最佳紀錄
- **第三季展望**: 以7月營收3,231.6億乘以3個月，已超過財測高標9,570億元
- **量能觀察**: 量能相對前波偏低，但代表籌碼已充分清洗，有利於真突破

#### 法人動向
- **外資期貨空單**: 大減，套利部位離開，回到正常空單水位
- **外資**: 先前5.5萬口空單已大幅崩減
- **融資**: 距離高水位仍有700億加碼空間
- **投信**: 近期從大型股開始擴散，類股輪動已在八月份展開

#### 台幣匯率
- 台幣緩慢貶值，毛損效應已回點
- 第三季匯兌有機會回沖利益，對OTC中小型股有利

### 關稅與國際情勢

#### 半導體關稅
- 半導體關稅出爐但市場反應冷淡，「利空不跌」
- 目前開出28%尚未攤完，但市場覺得沒什麼
- 中國關稅尚未出來，台灣232調查結果也未出
- 中國談判延至11月，其他國家8月前大致底定

#### 美國經濟觀察
- 目前就業與通膨數據尚可，但9月後需觀察關稅推升消費者壓力
- **降息預期**: 9月降息機率超過9成，年底前可能降2-3次
- **費半 (SOX)**: 高檔盤整一個月，未回測均線也未跌破警戒線，5,000點為關鍵支撐

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **真突破** | 股價突破盤整區後不回補缺口，代表多頭強勢確認 |
| **本益比 (P/E)** | 股價除以每股盈餘，衡量股票估值的指標 |
| **費半指數 (SOX)** | 費城半導體指數，衡量全球半導體產業景氣的關鍵指標 |
| **籌碼清洗** | 股價在盤整期間將短線浮額洗出，有利後續上漲 |
| **融資水位** | 投資人以融資方式買進股票的總金額，距高水位越遠代表加碼空間越大 |
| **矽智財 (SIP)** | 半導體設計服務公司，為客戶提供IC設計方案 |
| **232調查** | 美國依據貿易擴張法232條款進行的國家安全調查，可能導致額外關稅 |
