## 🌍 市場總體觀察

### 一、美國超級財報季總結

#### AI財報三部曲 — 全面正向
- **第一部曲**: 台積電（前端製造）— 表現最強
- **第二部曲**: 四大雲端業者（微軟、Google、亞馬遜、Meta）— AI業務全面成長
- **第三部曲**: NVIDIA — 尚未公佈（月底），但前兩部曲已確認趨勢
- **投資邏輯**: 台積電財報好 → 後面供應鏈照理講不會太差 → 安全的策略是確認台積電後再買後端

#### 四大雲端業者財報比較

| 公司 | 財報表現 | 營收展望 | 資本支出 | 股價反應 |
|------|---------|---------|---------|---------|
| **Google** | 優於預期 | 正向 | 大幅上調 | 上漲 |
| **微軟** | 優於預期 | 正向 | 上調（前次持平，本次追加） | 上漲 |
| **Meta** | 優於預期 | 正向 | 上調 | 上漲 |
| **亞馬遜** | 優於預期 | **略遜預期**（成長僅17-18% vs. 其他30%+） | 上調 | **下跌** |

#### 資本支出持續上調 — AI無虞可擊
- **上次法說（4月）**: 四家中三家上調，微軟維持平
- **本次法說（7月）**: **四家全部上調**，微軟也趕緊跟進
- **核心結論**: AI資本支出持續網上，代表整個AI趨勢仍在加速，沒有放緩跡象
- **對台股意義**: 資本支出 = 買NVIDIA晶片 = 台積電營收 → 供應鏈持續受惠

### 二、手機族群分化 — 蘋果 vs. 安卓

#### 蘋果 (AAPL) 財報
- **表現**: 優於預期，包含展望都是正向
- **全年預估**: 上修（與聯發科的下修形成對比）
- **市場意外**: 原本預期蘋果會跟安卓一樣差，結果完全相反

#### 聯發科 (2454) 法說會
- **財報**: 不錯
- **展望**: 略遜預期，全年對比上次法說下修
- **股價**: 正面反應（天三胖），但屬短線情緒

#### 投資策略 — 往左靠攏
- **最安全區域**: AI + 蘋果供應鏈
- **次安全區域**: AI相關但非蘋果
- **風險區域**: 安卓陣營
- **高風險區域**: 工業、車用電子
- **結論**: 下半年手機選股盡量選蘋果陣營，安卓盡量減碼

### 三、降息對台股的統計學影響

#### 美元/美債與亞股的負相關性
- **統計結論**: 美元走弱 + 美債殖利率下降 → 亞洲股市上漲
- **台灣特色**: 台股對**美債殖利率**敏感度為亞洲最高（深色比例最大）
- **韓國特色**: 韓股主要對**美元指數**敏感

#### 去年（2024年）降息經驗回顧

| 時間 | 事件 | 市場反應 |
|------|------|---------|
| 2024年8月初 | 7月就業數據差 → 降息預期爆增 | 股市先崩後漲 |
| 2024年9月中 | 首次降息2碼 | 股市持續走高 |
| 2024年11月 | 再降1碼 | 股市持續走高 |
| 2024年12月 | 降息但偏鷹派（暗示不再降） | 美股崩盤 |

- **本次對照**: 時間走勢與去年完全對準（8月就業數據差 → 9月預期降息）
- **重要觀察**: 不只看是否降息，更要看**會後聲明**是否偏鷹派
- **風險情境**: 若降息後聯準會暗示不再繼續降 → 股市反轉向下

#### 降息預期的可靠度觀察
- 距離FOMC會議（9月中）約一個月
- **專家觀察**: 過了8月中旬，若降息預期仍維持8成以上 → 降息幾乎確定
- **歷史經驗**: 最後一個月內降息預期大幅翻轉的案例也曾發生過

## 💼 產業分析與投資建議

#### 基本面
- 今年獲利成長8成（vs. 台積電3成）
- 一分錢一分貨，高本益比有高成長支撐
- 股價已漲至約1,090元

- 今天爆大量 → 需要時間整理
- **關鍵觀察**: 均線（尤其是月線）不破 → 下一波行情起點

#### 操作建議
- **不追高**，等量能縮減後均線不破再介入
- 短線漲多，但趨勢未結束
- **停損點**: 月線跌破

## 📊 關稅對台灣各產業衝擊評估

### 冠州的完整產業影響分析

#### 總體經濟影響
- **出口數據**: 7月前拉極單推升出口，8/7關稅實施後出口呈斷崖式下滑
- **GDP影響**: 上半年5.48-7.96%（強勁），第三季急降至3%以下，第四季更低
- **全年GDP預估**: 約3%左右（上下半年明顯分化）

#### 對等關稅影響（目前28%，仍在談判）

| 產業 | 輸美比重 | 關稅影響程度 | 轉嫁能力 | 備註 |
|------|---------|------------|---------|------|
| **成衣/鞋/紡織** | ~30% | 高 | 低 | 越南東南亞關稅也不低，難避開 |
| **汽車零組件** | 較高 | 中高 | **高** | 台灣零組件在全球有議價力，可轉嫁 |
| **自行車** | ~4% | 中 | 中 | 巨大(9921)、美利達受影響 |
| **鋼鐵** | - | 低 | - | 25%關稅已實施，但需求未回溫 |

#### 232調查（半導體關稅）影響

| 產業 | 直接影響 | 間接影響 | 風險等級 |
|------|---------|---------|---------|
| **晶圓代工** | 100%關稅（但可能零關稅） | 赴美投資成本增加 | 中（看白紙黑字） |
| **IC設計** | 影響較小 | 終端產品需求可能下滑 | 低 |
| **PCB** | 直接輸美僅1% | 終端產品（AI伺服器、PC）間接影響 | 低中 |
| **PC/NB** | 高（輸美20-80%） | 漲價10%可能導致銷量降10% | **高** |
| **AI伺服器** | 組裝可能零關稅 | 零組件進口可能課稅 | 中 |

#### 核心結論
- **只要232調查最終平均超過15%** → 對台灣整體資訊產業造成顯著衝擊
- PC/NB的價格彈性約1.2倍（漲價10% → 需求降10%），影響最為直接
- IC設計因產品嵌入晶片中，若晶片不單獨課稅，受影響較小

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **AI財報三部曲** | 指AI產業鏈財報依序公佈的順序：台積電（製造）→ 四大雲端（需求端）→ NVIDIA（設計端） |
| **資本支出 (CapEx)** | 企業用於購買設備、建設等長期資產的支出，雲端業者資本支出主要用於購買AI晶片與建設資料中心 |
| **價格彈性** | 需求量對價格變動的敏感度，彈性1.2表示價格漲10%，需求量將下降12% |
| **會後聲明** | 聯準會FOMC會議後發布的政策聲明，其中的措辭變化（鷹派/鴿派）對市場影響重大 |
| **鷹派/鴿派** | 鷹派主張升息或維持高利率以抗通膨；鴿派主張降息以刺激經濟 |
| **往左靠攏** | 指投資組合應偏向AI+蘋果供應鏈（最安全區域），遠離安卓、車用、工業等風險區域 |
| **拉極單** | 企業在關稅實施前大量預先下單以規避關稅成本，導致短期出口數據膨脹 |
| **處置股** | 因股價連續異常波動被證交所列為處置股票，交易需預繳款項且限制信用交易 |
