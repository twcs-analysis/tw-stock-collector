## 市場總體觀察

### 記憶體族群 -- 強勢族群的投資邏輯

#### 明漢觀點：記憶體與被動元件是「強勢族群」
- **定義**: 記憶體與被動元件在大盤跌千點時仍相對抗跌，屬於「鍋蓋壓著」的強勢族群
- **南亞科跌停分析**: 即使跌停，南亞科股價仍未跌回11月初的28,500點起跌水位，「這根本就沒跌」
- **操作邏輯區分**:
  - **長線投資**: 買AI族群中基本面好但跌深的股票（上集策略）
  - **短線操作**: 等指數壓力鍋蓋拿掉後，強勢族群會率先噴出，適合搶短

#### 被動元件與消費性電子的連動

**核心觀點**: 被動元件的上漲並非純AI驅動，而是消費性電子復甦帶動

- 9月開始起漲的電子非AI族群，主要受蘋果iPhone銷售帶動
- 消費性電子好轉才是主要驅動力，AI只是錦上添花
- **關鍵**: 最終所有消費性電子股都會一起下來

#### 記憶體報價 -- 唯一的王道指標

**報價為王**: 不管買記憶體、被動元件或任何消費性電子股，最終都要看記憶體報價

- **每日報價**: 記憶體每天報價三次，隨時可查（免費網站）
- **當前狀況**: DDR4與DDR5報價均持續上漲，每天上漲0.幾到0.9%，近日又拉高
- **風險訊號**: DDR4若見高點反轉，即使DDR5還在漲也沒用，股價會一起下來

**歷史借鑑 -- 2020年疫情周期**:
- 當年DDR3先見高點反轉，DDR4仍在創高
- 但南亞科股價跟隨DDR3先行反轉，後來DDR4也跟著下來
- **教訓**: 舊世代報價見頂 = 全面反轉訊號，不要相信新世代還在漲的說法

#### 韓國廠商 -- 領先指標

**重大警訊**: 三星與海力士股價在11月3日已見高點，未再創新高

- 韓國是全球記憶體產量最大的國家，韓廠股價具領先指標意義
- 上一次記憶體周期中，韓廠高點比台廠早約一個月
- 韓廠高點後，台廠即使繼續創高，最終也會跟著反轉下來
- **結論**: 韓廠已不創高，是否只是受全球股市拖累還是真正見頂，需密切觀察

#### 記憶體五大族群輪動順序（歷史經驗）
1. **製造**（南亞科）-- 最早見高點（波動大、刺激但風險也大）
2. **通路**（智商）-- 約晚10幾天
3. **封測**（南茂等）-- 更晚
4. **IC設計** -- 更晚
5. **模組** -- 最後見高，持續創高時間最長、相對安全

**操作啟示**: 追求刺激買南亞科，追求安全買模組/封測等較後段的標的

#### 記憶體操作總結
- **報價持續上漲 + 指數穩定 = 記憶體會噴出**
- **韓廠已不創高 = 不適合抱長單，只能賺價差**
- **不管誰出來講基本面多好都不要管，報價一往下切記一定要跑**
- **不要看基本面**: 2021年南茂等公司營收獲利創高時股價已先行反轉，看基本面會套牢

## 產業分析與個股研判

### PCB產業 -- 明年3A趨勢與密碼解析

#### PCB三大成長動力（3A趨勢）

**A1 -- ASIC客製化晶片資本支出**:
- 明年CSP（雲端服務商）資本支出增加40%
- 未來10年複合成長率高達27%（約3-4年翻倍）

**A2 -- ASIC晶片明年高度成長**:
- Google、Meta、微軟等巨頭自研晶片需要高階PCB
- ASIC晶片成長率31%以上

**A3 -- AI伺服器升級周期**:
- 輝達GPU每年升級一次（明年Rubin系列）
- Rubin晶片需用到30層PCB門坎（現行約20層）
- **關鍵密碼**: Google ASIC架構的PCB需達44層
- **選股密碼**: 找Google供應鏈相關的PCB廠

#### PCB四大正向循環
1. **量**: AI伺服器PCB用量比通用型提升50倍
2. **質**: 規格升級周期從2-3年縮短至1.5年
3. **產業景氣**: 自有的正向循環（需求強 -> 備料 -> 缺貨 -> 搶貨 -> 更缺）
4. **搶**: 2026年增標股需解決兩大瓶頸

#### 兩大瓶頸與戰略物資

**瓶頸一：銅箔（Copper Foil）缺量**
- 高品質PCB需用到「低粗糙度」銅箔，減少電阻與訊號干擾
- 波仙布（剝銅板相關）已漲一波
- 高階銅箔需達Q部等級（1-10英部的低粗糙度）
- AI PCB良率偏低（5-6成），做兩片壞一片，銅箔用料大增

**瓶頸二：鑽針（Drilling）**
- 傳統PCB：一根鑽針可鑽3,000孔
- AI高階PCB（Q部等級）：一根鑽針只能鑽100孔（僅1/30）
- 傳統PCB只需1根鑽針，AI PCB需3根（長短不一）
- **計算**: 3根 x 30倍 = 需要90倍的鑽針用量

## 操作策略總結

### 記憶體策略
1. **短線**: 報價上漲+指數穩定時可搶短，但韓廠不創高代表不適合抱長單
2. **風險管理**: 每天看報價（一天三次），DDR4報價反轉立刻出場
3. **輪動順序**: 製造最先反轉最危險，模組/封測較安全
4. **不看基本面**: 股價領先基本面1-2季，獲利創高時股價可能已先行反轉

### 被動元件策略
- 與記憶體連動，看記憶體報價操作
- 強勢族群在指數壓力解除後會率先噴出
- 長線投資建議買AI跌深股，被動元件適合短線操作

### PCB策略
1. **核心持股**: 金像電（Google供應鏈密碼）、金居（銅箔戰略物資）
2. **特殊標的**: 尖點（唯一鑽針廠，戰略物資）
3. **注意事項**: 波仙布（剝銅板）明年轉Q部等級，台灣廠商受惠有限，有高先處理
4. **操作節奏**: 正常拉回都是買點，季線附近可積極布局

### 鍾老師總結提醒
1. 觀察聯準會態度是否改變（從每位理事談話中追蹤）
2. 輝達股價是否轉強（全村的希望）
3. AI基礎建設相關股票不能再弱（上鏈數、拉甲股、CoreWeave等）
4. 三大法人動態：今日核心賣超一千億，不能持續這樣賣
5. 融資必須大幅減少才會止跌

## 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **DDR4/DDR5** | 第四代/第五代雙倍數據傳輸速率記憶體規格 |
| **DRAM報價** | 記憶體晶片的市場交易價格，每日更新多次 |
| **HVLP銅箔** | 高速低損耗（High Speed Very Low Profile）銅箔，AI PCB必備材料 |
| **Q部等級** | 銅箔的超低粗糙度等級（1-10英部），為最高規格 |
| **鑽針** | PCB製程中用於鑽孔的工具，AI高階PCB需大量精密鑽孔 |
| **模組鑽針** | 尖點開發的新型長短不一鑽針，一次可取代三根傳統鑽針 |
| **CSP** | 雲端服務供應商（Cloud Service Provider），如AWS、Azure、GCP |
| **ASIC** | 特定應用積體電路，科技巨頭自研的客製化晶片 |
| **CB/可轉債** | 可轉換公司債，公司發行用於籌資擴產 |
| **本淨比** | 股價/每股淨值，衡量股票相對資產價值是否合理 |
