## 🌍 市場總體觀察

### 原物料價格動態
- **CRB商品指數**: 近期創高，代表整體商品價格回升
- **銅價**: 近一個月漲近8%，是原物料中最強勢的品項
- **鋼鐵**: 美國熱壓鋼價大漲，大陸、韓國鋼價也跟漲，中鋼4月/Q2報價可能跟漲
- **鐵礦砂**: 報價走揚，成本推動效應將帶動鋼鐵報價上升
- **石化/塑化**: 油價走勢仍弱，庫存積壓，下游買氣觀望，**是原物料中最弱的族群**
- **水泥**: 價格持續走低，基本面尚未好轉

### 原物料上漲的真正原因
- **最大利多是「位階低」**: 這些族群去年腰斬，今年終於反彈
- 全球格局相同：美國科技股在休息，台灣電子股也在休息，大家都在找低位階標的
- **題材先領先基本面**: 俄烏停戰、加薩走廊重建等想像空間帶動

### 航運產業分析
- **散裝航運**: 原物料運送主要靠散裝，BDI指數上漲帶動
- **貨櫃航運**: 成品運輸為主，SCFI連六跌（本週跌9.3%），與原物料行情脫鉤
- **結論**: 搶運潮應以**散裝族群優於貨櫃**

## 💼 產業分析與投資建議

### 一、鋼鐵族群

#### 基本面分析
- 川普對全世界進口鋼鐵課25%無差別關稅
- 美國鋼價大漲，連動全球鋼價走揚
- **但獲利面仍弱**: 部分公司甚至還不賺錢

#### 個股觀察

| 股票 | 分析 | 注意事項 |
|------|------|---------|
| 中鋼 (2002) | 整體龍頭，4月報價可能調漲 | 投信持續買超，外資賣不下去後被迫回補 |
| 豐興 (2015) | 16族群（原物料供應商），銅價漲受惠大 | 同價轉強時16族群比15族群受惠更多 |
| 世紀鋼 | 中小型鋼鐵股 | 籌碼面投信持續買超，可關注 |
| 大成鋼 (2027) | 不鏽鋼，在美國有據點，有獨立利基 | 近期最強，但不鏽鋼整體基本面並沒那麼強 |

#### 重要觀念：15族群 vs 16族群
- **15族群**: 重電工程（直接用鋼鐵的），基本面較好
- **16族群**: 原物料供應商（賣鋼鐵銅等給15的），銅價/鋼價漲時受惠更多
- **本次行情**: 16族群先動，走在前段

### 二、銅相關族群

#### 華新 (1605)
- 16族群代表，投信持續買超
- 漲多後短暫整理屬正常
- 趨勢仍向上

#### 大亞 (1609)
- 中小型銅/電線電纜
- 前段大型股漲多，最近中小型開始落後補漲

### 三、石化/塑化（最弱族群）

- 油價走勢弱，庫存積壓
- 去年已經腰斬
- **雖也在漲但續航力存疑**: 基本面是所有原物料中最弱的
- **操作建議**: 若要退場，優先從基本面較弱的石化股退出

### 四、散裝航運

#### 裕民 (2606)
- 內外資同買
- **散裝特色**: 有很多船是每天租賃變化（非長約），BDI短線大漲時動得快
- 拉回量縮後有機會再走一個波段

#### 慧洋-KY (2637) / 新興 (2605)
- 船隊最大 + 獲利較穩定
- 進入短暫整理，整理過後應有再轉強機會

### 五、原物料族群的風險提醒

#### 輝達財報翹翹板效應
- **若GB200出貨不如預期**: 原物料Party繼續，資金不回流電子
- **若黃仁勳說出貨很好**: 資金直接往AI衝出去，原物料族群暫時休息
- **退場優先序**: 基本面較弱的先退（石化 > 水泥 > 鋼鐵 > 銅）

### 六、櫃買指數強勢與中小型股機會

#### 櫃買指數技術面
- 連續三天站穩所有均線
- **空頭慣性改變**: 低點不再創新低，確認回升格局
- 拉動力量：跌深股反彈 + 積體電路（群聯等）

#### 半導體特化/設備股

| 股票 | 分析 | 操作建議 |
|------|------|---------|
| 環球晶 (6488) | 跌深反彈代表，矽晶圓/三代半導體題材 | 反彈中，但套牢賣壓仍大 |
| 中美晶 (5483) | 比環球晶慢一步，三代半導體題材 | 搶反彈一定先補環球晶，中美晶可跟進 |
| 台特化 | 特用化學龍頭，投信幾乎手買 | 可能形成三角形整理，封閉缺口後看下半年 |
| 新印材（新同學） | 半導體特化，掛牌時間剛好過年後 | 有反彈跡象 |
| 文曄 (3036) | 三代半導體 | 跌深超跌，台積電若重回上升軌道，設備股將更強 |

#### 成熟製程/記憶體
- 台積電短期不動，但成熟製程低位階
- 今日長紅棒代表**新資金進場**的訊號
- **低價半導體**: 位置不高，可搭上底部逐漸轉強

### 七、小型股新機會

#### 歐萊德席 (5314)
- 持有四季半導體約7%股權
- 併入鋪大公司後Q4營收上升
- 有PU/運動鞋概念（切到主流）
- 去年題材不反應，今年開始反應，符合「今年才發動」邏輯

#### ETF投資
- 高股息ETF（精選高息類）帶動弱勢股同步回升
- 綠能股、電動車、重電概念都跟著回升
- 中國科技股ETF：中國AI武軍股站上季線創新高

## 📈 技術面分析與操作策略

### 下週觀察重點
- **中期均線是否能補漲**: 台積電的大盤若能帶動，格局會更好
- **波段買點 vs 當沖賣點對決**: 目前波段買點勝出，每次當沖留下的上影線隔天都被紅棒推過去
- **機械股/美國概念股**: 能否繼續擴大範圍

### 操作策略
1. **原物料**: 銅 > 鋼鐵 > 散裝 > 石化（依基本面強弱排序）
2. **輝達財報後注意資金流向**: 好 = 電子回流、原物料休息；不如預期 = 原物料繼續
3. **退場排序**: 從基本面最弱的先退
4. **櫃買中小型股**: 空頭慣性已改變，可積極找波段轉強標的
5. **半導體設備/特化**: 跌深超跌，Q2台積電回升時將有更大行情

## 📋 投資策略總結

### 原物料族群操作心法
- **現在強勢時不用急著分辨誰真誰假**: 都可以跟著漲
- **進入整理時要區分**: 留基本面好的，退基本面弱的
- **關鍵觀察**: 銅價變化（最具指標性）、輝達財報後資金動向

### 下週關鍵時間表
- **週三**: 輝達財報公布（美國時間）
- **週四**: 台股反應日（需提前下好離手）
- **週五**: 台股休市（2/28和平紀念日）

### 風險因子
1. 輝達財報若利多 → 資金回流AI，原物料暫時休息
2. 4月2日對等關稅 → 第二季開始的系統性風險
3. 石化/水泥基本面未改善，價格仍在走低

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **CRB商品指數** | 追蹤一籃子原物料商品價格的綜合指數，為全球原物料價格走勢的重要參考 |
| **BDI指數** | 波羅的海乾散貨指數，反映國際散裝航運運費走勢 |
| **SCFI指數** | 上海出口集裝箱運價指數，反映貨櫃航運運費走勢 |
| **15族群** | 重電工程族群（使用原物料做工程建設的公司） |
| **16族群** | 原物料供應商族群（賣鋼鐵、銅等材料給15族群的公司） |
| **成熟製程** | 非先進製程的半導體生產，如28nm以上，用於消費性電子等產品 |
| **三代半導體** | 以碳化矽(SiC)、氮化鎵(GaN)為代表的新型半導體材料 |
| **翹翹板效應** | AI與傳產/原物料資金互相消長的現象 |
| **PU（聚氨酯）** | 一種高分子材料，廣泛用於運動鞋、汽車零件等 |
| **精選高息ETF** | 以高股息殖利率股票為成分的ETF，吸引追求穩定現金流的投資人 |
