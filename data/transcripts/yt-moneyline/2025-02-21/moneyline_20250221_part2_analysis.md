## 🌍 市場總體觀察

### 川普就任一個月全球總盤點

#### 全球股市市值創新高
- **川普就任前**: 全球股市總市值 118兆美元
- **就任一個月後**: 125兆美元，**創歷史新高**
- 多國股市創新高：美國標普500、英國富時100、德國股市、澳洲指數
- 黃金也創新高：2,954.9美元

#### 各國股市分化表現

**創新高/大漲的市場**:
- 美股（標普500持續新高，但那斯達克原地踏步）
- 歐洲（英國、德國）
- 俄羅斯（受惠美俄和談利多）
- 香港恆生指數（AI概念、阿里巴巴、騰訊帶動，創近年新高）
- 韓國（三星、記憶體、半導體概念）

**大跌/受害的市場**:
- 印度（對等關稅預期衝擊，從高點持續下跌）
- 泰國、菲律賓（東南亞國家股市全面下跌）
- 原因：這些國家關稅不對等，是對等關稅的主要受害者

### 關稅的「暴風雨前的寧靜」

#### 為什麼大家還不怕？
- **尚未真正課稅**: 從川普說要課關稅到現在，實際上一毛都沒課
- **沒有經驗**: 過去二三十年全球化趨勢下，大家沒經歷過加關稅
- 比喻：美國汽車關稅目前僅2.5%，若調高到25%，衝擊巨大

#### 4月2日：真正的衝擊日
- **對等關稅品項**: 汽車、半導體、藥品全部課25%關稅
- **最新加入**: 木材也要加稅（加州大火後重建需求 + 木材關稅 = 房屋通膨）
- **川普的野心**: 若對等關稅成功，美國老百姓不用繳所得稅
  - 美國人去年繳了**1.8兆美元**所得稅
  - 美國全年財政部總稅收**4.9兆美元**
  - 目標：用關稅收入取代個人所得稅

#### 後遺症將在第二季展開
- 4月2日是第二季開始
- 對物價、利率都會有深遠影響
- 目前是「暴風雨前的寧靜」，台風延後但台風終究會來

### 地緣政治劇變

#### 俄烏戰爭
- 川普直接與普丁通電話談判，**排除烏克蘭與歐盟**
- 可能方案：烏克蘭接受現有領土現狀、永遠不加入北約、美國開發烏克蘭資源
- 美歐關係急轉直下：副總統乃至指手畫腳歐洲內政
- **結論**: 川普政府以美國利益至上，沒有盟友觀念

#### 美中關係
- 川普表示「很快可能與中國達成協議」
- 原本說要對中國課60~68%關稅，後來只課18%，且未再追加
- 顯示川普外交策略：先恐嚇再談判

#### 聯準會動向
- 公布會議紀要提到**可能放緩或暫停QT**
- 因為美國債務上限問題，財政部可能沒錢還債
- 暫停QT = 停止收錢 = 等於放錢，**對股市是利多**

#### 日元升值風險
- 日元突破150關卡
- 原因：日本Q4 GDP不錯、CPI達3.2%、春鬥加薪預期
- 日本央行可能升息到1%
- **風險**: 若日元持續升值，可能引發Carry Trade逆轉賣壓

### 台積電議題

#### Intel合作傳聞
- 傳出台積電可能入股Intel分割出的新公司（僅20%）
- **曾老師看法**: 20%太虛，100%才合理
- **風險**: 技術外流（光刻化學品配方等機密）、改造成本高
- **建議**: 不要急著買台積電，等到談判確定或川普去新廠剪綵再買

## 💼 產業分析與投資建議

### 風水輪流轉策略

#### 核心邏輯
- 高基期股可能接下來休息（AI、矽光子、機器人）
- 低基期股開始上漲（原物料、面板、工業電腦、重電）
- **全球都在玩這套**: 不只台股，連國際股市都是風水輪流轉
- **投資重點**: 先重「安全與價值」，再講「報酬率」

### 跌深反彈 vs 波段轉強（柏傑老師教學）

#### 兩種「馬確變鳳凰」的差異

**第一種：跌深反彈股**
- 特徵：股價大跌後首次反彈，均線仍向下
- 壓力：季線、半年線、年線依序形成反壓
- **操作**: 到重要均線（尤其年線）要調節，不能追
- **關鍵**: 等均線走平需要時間，不急

**第二種：波段轉強股**
- 特徵：已經打底完成（回測前低不破），均線走平
- 突破時：均線從壓力變支撐
- **操作**: 突破時應該要追進！
- **關鍵**: 這是後半段循環，有機會轉回升

## 📈 技術面分析與操作策略

### 櫃買指數（OTC）技術突破
- 連續三天站穩所有均線
- 空頭慣性已被打破：低點不再創新低，高點開始突破前高
- **確認回升格局**: 多頭循環啟動
- 櫃買指數拉動力量：跌深股反彈 + 積體電路（群聯等帶動）

### 關鍵操作原則
1. **跌深反彈股**: 年線以上或爆量高點附近 → 調節（不是殺掉）
2. **波段轉強股**: 突破重要均線且量增 → 追進
3. **重電/原物料**: 爆量後不跌破 = 中長期資金，可持有
4. **下週輝達財報**: 若拉回是買點，不是賣點

### 下週操作要點
- 週四（2/27）輝達財報公布後，台股週五休市（2/28和平紀念日）
- 需在週四提前下好離手
- 若輝達財報利多 → AI資金回流，原物料族群可能短暫休息（但不會大跌）
- 若輝達財報不如預期 → 原物料/低基期繼續Party

## 📋 投資策略總結

### 核心觀點
1. **關稅真正衝擊在4/2**: 目前是暴風雨前的寧靜，Q2要特別小心
2. **風水輪流轉已確認**: 高基期休息、低基期翻身，全球皆然
3. **兩種翻身股操作不同**: 跌深反彈到年線調節，波段轉強可追進
4. **輝達財報是翹翹板**: 好 = AI回流；不如預期 = 低基期繼續漲

### 風險提醒
- 4月2日對等關稅是比輝達財報更重要的事件
- 日元升值可能引發國際資金動盪
- 台積電Intel合作案：技術外流風險，短線不宜重押

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **對等關稅** | 川普政策：美國對各國課徵與該國對美國相同稅率的關稅，目標是消除貿易不公平 |
| **QT（量化緊縮）** | 聯準會縮減資產負債表，到期債券不再購買，等於從市場收回資金 |
| **Carry Trade** | 借低利率貨幣投資高利率資產的交易策略，日元是常見的借貸貨幣 |
| **春鬥** | 日本每年春天的勞資薪資談判，影響通膨預期與央行政策 |
| **債務上限** | 美國國會設定的政府可舉債總額上限，到頂時政府面臨關門風險 |
| **DOGE（政府效率部）** | 馬斯克主導的美國政府效率改革組織，清查浪費與詐領 |
| **跌深反彈** | 股價大跌後的技術性反彈，遇到重要均線仍有壓力 |
| **波段轉強** | 股價打底完成後突破均線轉為多頭的訊號 |
| **馬確變鳳凰** | 形容長期低迷的股票突然翻身大漲的投資現象 |
| **風水輪流轉** | 不同類股/市場輪流表現的現象，高基期休息讓低基期補漲 |
