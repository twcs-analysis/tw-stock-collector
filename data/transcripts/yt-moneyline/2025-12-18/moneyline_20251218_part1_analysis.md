## 技術面分析與操作策略

### 美光財報解讀（明哲分析）

**財報亮點**：
- Q1（快計年度26年Q1）營收136.43億美元（預估129.5億），大幅優於預期
- 毛利率56.8%（預估51.6%），甚至超越台積電的60%毛利率
- 非GAAP EPS 4.7美元（預估3.95）
- **下季財測更亮眼**：營收187億（預估143.8億）、毛利率68%（預估55.7%）、EPS 8.42美元（預估4.7億）

**供需面關鍵**：
1. 2026年HBM供應量與客戶已達成協議全部售罄，價格與銷量均鎖定
2. 美光目前只能滿足關鍵客戶50%~66%的需求
3. 史上首次出現帶有強制性條款的多年期供貨合約
4. 資本支出上調至180~200億美元用於HBM與先進製程

**缺貨原因三大核心**：
1. HBM與DDR5需求暴增，排擠一般DRAM（含NAND Flash）供給
2. 供給端保守投資與產能重新分配
3. 庫存偏低與通路拉貨/恐慌性備貨

**研調機構預測**：
- 集邦科技：明年全年結構性漲價
- Counter Point：DDR5 Q1再漲30%、Q2再漲20%
- 昂典：DDR4缺口估計缺一年甚至到2027年
- 大摩：DDR4 16Gb短缺最嚴重，Q1合約價再漲10%

**記憶體金字塔**：頂端是AI伺服器 > 消費性電子（手機、PC將面臨漲價壓力）

### 台股期貨結構分析（律恆分析）

**期貨換倉觀察**：
- 1月合約換倉價：27,753點
- 外資大台空單僅29,000口，且今天再回補5,000多口，空單減少中
- 連續兩個月長上影線合約，歷史上這種情況盤整4~5個月後會突破

**關鍵判斷**：
- 1月合約若能吞掉前兩個月上影線，走出大長紅，類似2024年初走勢
- 空方壓力區：28,300~28,500、台積電1,500元以上
- 本週五為美股三巫日+台灣富時調整，量能會放大

**聖誕老人行情**：
- 定義：12月最後五個交易日 + 1月前兩個交易日
- 2023年底與2024年底都沒有出現聖誕老人行情，但隔年台股都創高
- 律恆預期今年應該會出現，因為已經折磨夠久

### 2026年投資方向（律恆建議）

1. **主動式ETF**：今年表現優於被動式ETF，明年可持續關注（如0981、0982、0983）
2. **貴金屬**：黃金正二年漲135%、白銀原型漲100%，明年趨勢持續
3. **科技**：美中台為核心，日韓為補充（韓國今年漲7成，落後補漲）
4. **軍工/太空衛星**：全球政策持續支持，趨勢延續2~3年

## 名詞解釋

| 名詞 | 解釋 |
|------|------|
| 三巫日 | 美股每季第三個週五，股指期貨、股指選擇權、個股選擇權同時到期結算的日子 |
| 費波南西轉折 | 以費波南西數列（1,1,2,3,5,8,13,21...）天數作為變盤轉折的技術分析方法 |
| HBM | High Bandwidth Memory，高頻寬記憶體，AI伺服器核心零組件 |
| DDR5 | 第五代雙倍資料速率記憶體，目前最新主流規格 |
| 季線 | 60日移動平均線，被視為中期多空分水嶺 |
| 結構性漲價 | 非短期供需失衡造成的漲價，而是產業結構改變帶來的長期趨勢性漲價 |
| 主動式ETF | 由基金經理人主動選股操作的ETF，區別於追蹤指數的被動式ETF |
| 聖誕老人行情 | Santa Claus Rally，指12月最後5個交易日加1月前2個交易日通常出現的上漲行情 |
| 換倉 | 期貨合約到期前，將部位從即將到期的近月合約轉移到下一個月合約 |
