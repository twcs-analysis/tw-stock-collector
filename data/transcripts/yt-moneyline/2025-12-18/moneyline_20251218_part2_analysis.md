## 產業分析與投資建議

### 一、2026年台股大預測——建大哥技術面推估

**年度高低點預測**（月線等距測量法）：

| 項目 | 點位 |
|------|------|
| 2026年低點 | 24,416點 |
| 2026年高點 | 32,720點 |
| 年度振幅 | 8,304點 |

**計算邏輯**：
- 低點24,416至今年高點28,568，差距4,152點
- 以等距測量法：28,568 + 4,152 = 32,720（明年高點）
- 因此全年高低差距：32,720 - 24,416 = 8,304點

### 三、三天內大漲的技術面依據

建大哥提出三大理由：

1. **季線與月線扣底低檔**：
   - 月線正在扣最低檔，季線持續上揚
   - 下週一（12/22）起扣底到最低點，每天線向上45點
   - 月線百分之百一定走上升，不可能翻跌（除非一天跌3,000點）

2. **官股連續大買**：
   - 八大官股每天買超80億、120億不等，連續買超
   - 國安基金護盤一定買權值股

3. **費波南西21天多方轉折**：
   - 11月21日（26,395低點）算起，到12月19日剛好是第21天
   - 21天為費波南西數列的多方轉折點

- 到壓力先賣，「站賣蹲買」原則

## 技術面分析與操作策略

### 台股大盤技術面

**區間判斷**：
- 下檔支撐：26,395（11/21低點）
- 上檔壓力：28,568（今年高點）
- 目前處於三角形收斂末端，即將表態方向

**扣底分析**：
- 月線扣底最低檔，未來每天向上45點
- 季線扣底低檔（約24,500點），距離現在27,000多點有2,000多點差距
- 兩條均線百分之百向上，形成多方支撐走勢

**操作建議**：
- 三天內（12/19~12/23）必有一天大漲300~500點
- 大漲時一定是權值股帶動
- 到壓力區站賣蹲買，碰到力空大跌後一定要趕買

### 明年台股曲線預測（建大哥）

- **年底**：在27,000~28,000附近整理
- **第一季**：往上創高，有機會挑戰30,000~35,000
- **之後**：上上下下盤整，大曲線整理
- **全年走勢**：前高後低，第一季為全年最佳表現期

## 名詞解釋

| 名詞 | 解釋 |
|------|------|
| 等距測量法 | 技術分析中，以前一波漲跌幅度等距推估下一波高低點的方法 |
| 扣底 | 均線計算時，最舊的一筆資料被「扣除」並替換為最新資料，扣底低檔意味均線容易上揚 |
| 站賣蹲買 | 股價到壓力區站著賣出，跌到支撐區蹲下買進的操作策略 |
| KD指標 | 隨機指標，K值低於20為超賣區，高於80為超買區 |
| MACD柱狀體 | 衡量趨勢動能的指標，負值收斂代表空方力量減弱，可能翻多 |
| 連七凍 | 央行連續七次維持利率不變 |
| 重貼現率 | 央行對金融機構的融通利率，為台灣基準利率指標 |
| W底 | 又稱雙重底，股價兩次觸底後反彈的底部型態，確認翻多訊號 |
| 基期效應 | 因前期比較基礎不同造成成長率變化的現象，基期低則成長率容易看起來較高 |
