## 產業分析與投資建議

### 一、聯發科（2454）—— Google TPU + 低軌衛星雙題材

**題材一：Google TPU ASIC**
- 聯發科為Google TPU使用的ASIC晶片供應商，主要兩款產品：
  - **B7E**：原本從1萬片增至2萬片，2027年預計達15萬片（七倍成長）
  - **B8E**：鎖定更先進製程，接棒B7E
- 主要客戶為Anthropic（Google TPU的客戶，開發Claude AI）
- 2026年Q1風險試產，通過認證後直接量產
- 台積電先進製程產能中，聯發科配額從1萬片倍增至2萬片

**題材二：低軌衛星通訊**
- 聯發科11月公告與歐洲太空機構、OneWeb/Airbus合作
- 完成全球首例符合3GPP R19規範的5G NR NTN（非地面網路）連線
- **透明轉發器技術**：降低衛星複雜度、提升NTN效率、支持R19手機直連
- 與SpaceX手機直連衛星概念相關，為未來重要商機

**題材三：AI工具生態**
- Gemini搜尋引擎活躍用戶6.5億人
- 結合Notebook功能可深度搜尋、製作簡報、生成封面圖
- AI不會泡沫，產業持續向上發展

**技術面分析**：

- 短時間漲較快進入整理，但並未轉弱

## 全球央行與匯率分析（御恆）

### 歐洲央行（ECB）

**觀察重點**：
1. 中性利率及停止降息終點的辯論
2. 對未來一年長期路徑的論述——是否表示「政策處於良好位置」
3. 新經濟預測報告——明年通膨遇估是否穩定維持2%
4. 德國財政刺激預期是否帶動經濟成長展望上調

**歐元走勢**：
- 目前利率2.15%，通膨約2%，利率與通膨接近持平
- 部分委員已開始討論2027年可能升息
- 若歐洲維持利率不變而美國降息，資金將從美國流向歐洲
- 歐元/美元大頸線約1.1，突破1.2後進入真正強勢區，目標1.23以上
- 明年歐元升值機會大

### 日本央行（BOJ）

**明天決議重點**：
- 市場已完全反映升息預期，關鍵在「鴿派升息」還是「鷹派升息」
- 目前利率0.5%，若再升就是30年來最高利率水準
- 日本政府財政負擔會加重（大量國債），但首相為安倍繼承者，偏寬鬆財政
- 中期利率預估範圍：1.0%~2.5%，若上調即為鷹派訊號

**日圓走勢**：
- 即便今年有升息，大部分時間仍在高位區間（貶值區）
- 160左右為貶值極端區，140以下為升值區
- 鴿派升息：日圓繼續在高位區間盤整偏貶
- 鷹派升息/正常化加速：日圓快速升值，可能引發全球套利交易平倉

**套利交易影響**：
- 大量投機性資金借日圓買其他資產
- 日圓急升時，這些資金會被迫平倉，影響美債與美股

### 美元

- 美元指數挑戰100後回落，強勢期可能已過
- 假突破後下跌，可能開始走較長下行波段
- 結構性偏空為正常趨勢（各國重整軍備、財政刺激導致貨幣購買力下降）
- 聯準會獨立性降低，不管誰當主席都可能受政治影響
- 下一任主席候選人：Hassett（較不獨立）vs. Waller（較獨立，華爾街支持）

### 美債

- 美國10年期公債殖利率正常化目標約3%
- 2年期與10年期利差目前約0.5%
- 短率往下走，長率可能盤整（受通膨與美元信用影響）

### 投資建議——債券ETF

- 被動式債券ETF今年表現不佳
- 建議考慮**主動式債券ETF**（0981、0982、0983等）
  - 可搭配非投資等級債提高殖利率
  - 存續期間可靈活調配
  - 信用等級可多元配置

### 貴金屬

- 今年黃金、白銀大漲的原因：
  1. 美國降息循環
  2. 各國搶購關鍵礦物（AI伺服器原料）
  3. 美國給的價格較高，全球白銀往美國集中
  4. 美元弱勢
- 御恆認為趨勢正確，明年仍有機會

## 名詞解釋

| 名詞 | 解釋 |
|------|------|
| ASIC | Application-Specific Integrated Circuit，特定應用積體電路，為特定用途客製化設計的晶片 |
| Google TPU | Tensor Processing Unit，Google自行設計的AI加速晶片 |
| NTN | Non-Terrestrial Network，非地面網路，指衛星通訊網路 |
| 3GPP R19 | 第三代合作夥伴計劃第19版標準，定義5G/6G通訊規範 |
| 透明轉發器 | 衛星上僅做訊號放大與頻段轉換，不做訊號解調處理的轉發裝置 |
| 手機直連 | Direct-to-Cell，手機無需基地台即可透過衛星進行通訊的技術 |
| ABF載板 | Ajinomoto Build-up Film，味之素堆積膜基板，高階IC封裝用的關鍵基板 |
| CCL | Copper Clad Laminate，銅箔基板，PCB的核心原材料 |
| 鴿派升息 | 升息幅度或速度較市場預期溫和，暗示未來可能放緩或暫停 |
| 鷹派升息 | 升息態度強硬，暗示未來可能繼續加速升息 |
| 套利交易 | Carry Trade，借入低利率貨幣（如日圓）投資高利率資產以賺取利差 |
| 風險試產 | Risk Production，在未完成全部認證前先行小量試產，以加速上市時程 |
| SpaceX IPO | SpaceX可能成為史上最大IPO案，帶動低軌衛星相關概念股 |
