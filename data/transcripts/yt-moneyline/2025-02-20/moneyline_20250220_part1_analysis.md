## 📈 技術面分析與操作策略

### 大盤技術面判斷

**柯老師定調**: 「利空鈍化，先整後彈」

1. **KD指標**: 短線指標已來到超買區，隨時拉回修正
2. **MACD指標**: 中線指標維持多方市場
3. **綜合判斷**: 短線拉回，中線仍多，操作採「賣七多三」策略
4. **區間操作**: 上有關稅變數壓力，下有勞動基金3,250億資金護盤

### 操作原則

#### 「賣七多三」策略
- **賣七**: 到壓力區不追買，選擇站在賣方
- **多三**: 支撐區拉回逢低承接，維持三成部位
- **依據**: 統計30年數據，高點時政府賣出，大跌時政府買進

#### 選股三原則
1. **上升軌道股**: 選擇做多（沿五日均線操作）
2. **區間整理突破股**: 突破轉強後做多
3. **下降趨勢股**: 避開，必賺指數賠價差

#### 右下角股操作心法
- 第一根長紅後三天內是最佳買點
- 碰到五日均線拉回即為低風險買點
- 量縮拉回是安全的，爆大量要小心反轉
- 低點越來越高、高點越來越高的格局不變則持有

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **利空鈍化** | 利空消息持續出現但市場反應逐漸減弱，股價不再大幅下跌 |
| **先整後彈** | 技術面先經歷一段整理（震盪）期間後再向上反彈 |
| **賣七多三** | 在高檔震盪區間，七成部位做賣出、三成部位做買進的操作策略 |
| **右下角** | 指股價位於低位階、股價淨值比低的個股 |
| **KD指標** | 隨機震盪指標，用於判斷短線超買超賣 |
| **MACD** | 趨勢追蹤動量指標，用於判斷中線多空方向 |
| **夏普值（Sharpe Ratio）** | 衡量每承受一單位風險所獲得的超額報酬，數值越高越好 |
| **動能因子** | 根據股票過去一段時間的漲跌表現篩選「強者恆強」的個股 |
| **平準機制** | ETF為維持配息穩定所設立的機制，避免新申購資金稀釋原有配息 |
| **五日均線** | 過去五個交易日收盤價的平均值，短線操作重要參考 |
