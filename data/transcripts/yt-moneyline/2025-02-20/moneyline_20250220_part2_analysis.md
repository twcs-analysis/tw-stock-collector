## 🌍 市場總體觀察

### 籌碼面深度分析

#### 外資期貨空單
- 空單已降至24,000口以下，接近歷史低點
- **警訊**: 融資與外資期貨空單同步偏低，對大盤推升反而不利
- 兩萬口以下已太偏低，行情推動缺乏動能
- 需觀察後續是否回升至四萬口以上才有多頭行情

#### 投信賣超
- 連續大量賣超（昨日50億、今日64億），維持史上第三大賣超水準
- 原因：漲價贖回，高股息ETF需配發現金
- 屬於「趨勢性賣法」，非看空市場

#### 政府基金動態
- **統計30年數據**: 每次高點政府都賣，每次大跌政府都買
- 今日跌116點，政府小量買進；若明天跌300點，政府可能大量買進70-80億
- 操作建議：跟著政府步調走

### 操作策略定調

#### 「賣七多三」策略詳解
- KD指標已在超買區 → 短線隨時拉回修正
- MACD維持多方 → 中線格局不變
- 碰到壓力區 → 賣七（站在賣方）
- 回到支撐區 → 多三（逢低承接三成部位）

## 💼 產業分析與投資建議

### 一、重電族群深度分析

#### 華城 (1519) - 重電龍頭
- 今日漲停板
- **定位**: 重電族群的「大哥」，率先表態走多
- **操作**: 不追漲停，等拉回碰五日均線再買進，風險極低
- **指標意義**: 華城維持多方，等同台積電對大盤的指標地位
- **類比**: 如同高鐵一旦開動就不會停，有站停靠但持續前進

#### 大亞 (1609) - 重電黑馬
- 今日帶量長紅
- **操作**: 第一根長紅後三天內（預計週一或週二）若量縮拉回，即為最佳買點
- **訊號**: 最先漲停的股票，短線上會最強

#### 中心電 (1611) - 落後補漲
- 股價位置最低
- **定位**: 未先漲停的股票，屬於因位階低而落後補漲型
- **優勢**: 大型龍頭先漲完後，資金會流向位階較低的標的

#### 重電操作心法
1. 第一天長紅後三天內若量縮拉回，碰五日均線即買進
2. 低量起漲的股票較安全；爆大量越滾越大時反轉風險高
3. 五日均線不破則持有
4. 股價與五日均線乖離太大時不追買

### 二、上升軌道股 vs 下降趨勢股

#### 上升軌道股（做多）
- 特色：產業熱門、成交量大、EPS好
- 操作：沿軌道低點買進，壓回找支撐

#### 區間整理突破股（做多）
- 有基本面支撐
- 突破轉強後的第一買點和第二買點都可進場
- 看到突破帶量即可做多

#### 下降趨勢股（避開）
- 每次反彈到壓力點就賣壓沉重
- 在2025年持有這種股票只會賺指數賠價差
- 建議換股操作，不要執著停損概念

### 三、柯老師精選五檔重點個股

#### 台積電 (2330) - 指標觀察
- 目前在利空消化階段
- 需觀察其強弱決定台股能否脫離「先整後彈」格局
- 區間操作為主

#### 緯創 (3231) - 上升軌道
- 營收持續成長，技術面呈上升軌道
- 操作：沿五日均線做多
- 到壓力點注意是否出現失敗訊號（拉回或翻空）

#### 長榮 (2603) - 高配息
- 去年賺70元，今年預估配39元（35-39元）
- 200元股價配39-40元，殖利率極高
- 2025年除權息行情不可能缺席

#### 陽明 (2609) - 高配息
- 去年賺21.25元，預估配21.5元
- 預估配發9元
- 60多元股價配9元，具投資價值

#### 金寶 (2312) - 底部翻多
- **技術面**: W底型態完成，突破後盤整8天再轉折上攻
- **基本面**:
  - 2023年EPS 0.5元
  - 2024年前三季 0.95元，全年預估1.3-1.5元
  - 1月營收年增36.13%
- **題材**: AI獨秀 + 美國生產（車用、電館）
- **操作**: 沿五日均線操作，不追高
- **目標**: 今年若EPS達2-3元，20多元股價具吸引力

## 📈 技術面分析與操作策略

### 三種線型判斷法

| 線型 | 特徵 | 操作策略 |
|------|------|---------|
| **上升軌道** | 低點越來越高、高點越來越高 | 做多，沿軌道低點買進 |
| **區間整理突破** | 底部整理後帶量突破 | 做多，突破點與回測點買進 |
| **下降趨勢** | 反彈到壓力就壓回 | 避開，換到前兩種股票操作 |

### 個股技術重點

1. **華城 (1519)**: 漲停板後等拉回碰五日均線買進
2. **緯創 (3231)**: 上升軌道，沿五日均線操作
3. **金寶 (2312)**: W底突破後盤整再上攻，標準底部翻多型態
4. **世芯KY (3661)**: 季線跌破需盡快站回，否則形成壓力
5. **創意 (3443)**: 在季線附近慢慢打底，季線走平翻揚後攻擊力轉強

## 📋 投資策略總結

### 操作架構
1. **跟著政府走**: 大跌買、大漲賣，嚴守「賣七多三」紀律
2. **選股優先序**: 先選上升軌道股，再選區間突破股，避開下降趨勢
3. **2025年操作關鍵**: 買對股比買對指數重要
4. **技術面翻多 + EPS有支撐** = 雙重確認的好標的

### 重點族群排序
1. **重電**: 華城、大亞為首選，中心電落後補漲
2. **AI伺服器**: 緯創為主軸
3. **高配息航運**: 長榮、陽明
4. **IC設計中低價**: 湖綠KY、綠綠、茂達
5. **底部翻多**: 金寶

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **賣七多三** | 在高檔震盪區間，七成時間做賣出、三成時間做買進的操作策略 |
| **W底型態** | 股價兩次測試低點後反彈形成的底部型態，突破頸線後確認翻多 |
| **上升軌道** | 股價沿著低點連線與高點連線形成的通道持續上漲的趨勢 |
| **黃金交叉** | 短期均線由下往上穿越長期均線，為技術面做多訊號 |
| **Beta值** | 衡量個股相對大盤波動程度的指標，大於1代表波動比大盤大 |
| **Alpha值** | 個股相對大盤的超額報酬率 |
| **本益比（P/E）** | 股價 / 每股盈餘，衡量股票估值高低的指標 |
| **殖利率** | 每股股利 / 股價，衡量現金回報率 |
| **季線** | 60日移動平均線，中期趨勢判斷指標 |
| **五日均線** | 5日移動平均線，短線操作重要支撐/壓力參考 |
