## 📊 市場總體觀察

### 各國關稅與股市反應

| 國家 | 關稅稅率 | 股市反應 | 備註 |
|------|----------|----------|------|
| 日本 | 25%（比 4 月多 1%） | 漲 0.3%+0.3%（連兩日上漲） | 談判反而更差，不談的結果更好 |
| 韓國 | 25%（不變） | 昨漲 1.8%、今漲 0.6% | 新總統民族主義行情帶動 |
| 越南 | 10.2%（從 46% 大降） | 股市大漲，胡志明指數創波段新高 | 幫忙打擊洗產地 + 全面開放美國商品 |
| 台灣 | 尚未公布（市場預估 15%~20%） | 今日開低走高收紅 | 今晚或明晨公布 |

### 關鍵發現：談判不一定比不談好

- **日本**：積極談判，從 24% 反而升到 25%，比不談還差
- **韓國**：政局混亂未派人談，維持 25% 不變，反而省事
- **越南**：全面開放美國商品 + 打擊洗產地 → 獲得最低稅率 10.2%
- **結論**：川普看的是「誠意」而非談判過程，日本說了但沒做到讓川普不滿

### 川普最新聲明（節目錄製時）

1. **關稅大限**：8 月 1 日不會再延了，已出數字要求各國再來談
2. **未來幾天**：還會再寄 15~20 封信（對更多國家/商品課稅）
3. **銅關稅**：明確提出 50%，目的是逼廠商把銅帶回美國生產
4. **藥品關稅**：最高兩位數，但給業者 1~1.5 年調整時間
5. **晶片關稅**：仍在討論中，時間與稅率尚未確定

### 美股對關稅反應

- **納斯達克**：雖有晶片關稅疑慮，費半仍往上衝
- **銅價期貨**：川普宣布課銅 50% 時，銅價瞬間噴出創歷史新高
- **整體邏輯**：市場已進入「反正川普會說、先買再說」的慣性

## 💼 產業分析與投資建議

### 一、銅價關稅 50% — 他口交易機會分析

#### 銅概念股

| 項目 | 分析 |
|------|------|
| 銅價走勢 | 宣布 50% 關稅後瞬間創歷史新高，仍在高檔震盪 |
| 美國國內銅 | 價格更貴（海外運來要被課稅），已在美國的銅庫存價值提升 |
| LME 倫敦銅 | 若全球經濟不佳，海外銅價反而可能因需求下滑而承壓 |
| 台灣銅概念股 | 開高走低居多（華新、華榮等），題材偏短多 |
| 操作建議 | 短多長空思維：有低價庫存的短期可賣高價，但未來成本上升會抵銷利潤 |

**紀展分析**：
- 超過 50% 的銅關稅能否落實尚不確定
- 推動銅價上漲的主因是美國國內供需失衡，非全球需求大增
- 他口交易（銅、藥品、晶片）目前看起來都相對保守，沒有明顯踏空機會

#### 藥品關稅

| 項目 | 分析 |
|------|------|
| 稅率 | 最高兩位數（可能 25%~50%） |
| 緩衝期 | 1~1.5 年 |
| 影響 | 有時間調整，不會造成短期劇烈波動 |
| 操作建議 | 藥品股大漲困難，因緩衝期太長 |

#### 晶片關稅

| 項目 | 分析 |
|------|------|
| 現況 | 仍在討論中，手機、筆電等消費性產品若課稅影響美國人負擔 |
| 費半反應 | 不跌反漲，市場不擔心 |
| 操作建議 | 費半仍強勢，目前無拉回時點 |

### 二、關稅下的國際政治博弈

#### 川普的工具箱（王健全副院長整理）

| 法律工具 | 條款 | 特性 | 時間 |
|----------|------|------|------|
| IEEPA | 1977 國際緊急經濟權力法 | 川普目前用的主要法源，原為動結資產用途，非關稅 | 不需國會批准 |
| 122 條 | 國際收支平衡條款 | 可課最高 15%、最長 150 天 | 不需調查 |
| 201 條款 | 貿易法保護特定產業 | 需經 ITC 調查，可保護 4 年 | 時間較長 |
| 301 條款 | 不公平貿易行為 | USTR 調查 6~9 個月 | 最常見 |
| 232 條款 | 國家安全（鋼鐵、半導體、藥品） | 不需國會批准 | 25%~50% |
| 338 條款 | 報復性關稅 | 上限 50%，100 年未使用 | 歷史工具 |

#### 各國因應策略

| 國家 | 策略 | 效果 |
|------|------|------|
| 日本 | 態度強硬（選舉考量），但答應的採購未兌現 | 反而被加稅 |
| 韓國 | 政局混亂未談 | 維持不變，反而不差 |
| 越南 | 全面開放進口 + 打擊洗產地 | 獲最低稅率 |
| 歐盟 | 會員國意見分歧 + 仍需美國軍事協助 | 從 16% 升至 20% |
| 加拿大 | 態度強硬（課數位稅） | 美國一度停止談判 |
| 中國 | 表面強硬但實際合作（從 100%+ 降至 30%） | 比預期好 |

### 三、台灣的戰略建議（王健全副院長）

| 面向 | 具體建議 |
|------|----------|
| 戰術面 | 對美投資（台積電設廠）、軍購、能源採購、台幣升值表態 |
| 戰略面 | 半導體民間與政府唱黑白臉，有秩序萬一；作為美國去中國化的策略夥伴，換取傳統產業低關稅 |
| 產業面 | 主權基金協助傳統產業轉型（22% 傳產員工將很辛苦） |
| 關稅預估 | 與日韓差距不大，若低於 25% 則相對有利 |

## 📈 技術面分析與操作策略

### 日股技術面（NIKKEI 225）

- 關稅 25% 公布後仍在高檔整理，未跌破
- 日幣在 139~149 區間盤整，尚未跌破

### 韓股技術面（KOSPI）

- 底部過高格局，新總統行情推動
- 即使關稅 25% 不變，仍持續上漲
- 市場預期 8/1 可能降至 20%，屆時再漲一波

### 越南股市（胡志明指數）

- 從被課 46% 的低點一路反彈
- 目前持續創波段新高
- 已無踏空機會，先前低點買入者已獲利

### 銅價技術面

- 宣布 50% 後瞬間創歷史新高
- 目前在歷史高點附近震盪
- 若後續稅率確認更高，可能再衝；若經濟下滑，海外銅價承壓

### 操作核心策略

1. **舒方老師**：等均線黃金交叉向上再進場（保守策略）
2. **至少保留 30% 現金部位**
3. **留意 7/17 後法說會密集期**：買第三季展望好的個股
4. **關稅 + 半導體關稅尚未定案**：不宜滿倉操作

## 📋 投資策略總結

### 關稅因應三大策略

| 策略 | 代表產業/標的 | 邏輯 |
|------|--------------|------|
| 避險策略 | 支付服務（麥達特 6172）、內需綠電（中興電 1513） | 不出口美國、無匯損問題 |
| 進攻策略 | 台積電（2330）、先進製程（中砂 1560） | 高毛利、在美設廠零關稅、產業在浪頭 |
| 迴避策略 | 工具機（上銀 2049）、傳統產業 | 輸美比重高、匯率+關稅雙重打擊 |

### 今晚關稅公布後的情境推演

| 情境 | 稅率 | 預期反應 | 操作建議 |
|------|------|----------|----------|
| 最佳情境 | 15%~18% | 利多大漲，比照越南模式 | 可積極布局，但仍注意 8/1 才是最終期限 |
| 基準情境 | 20%~25% | 利多偏中性，日韓模式 | 保守布局，觀察後續談判空間 |
| 最差情境 | 25% 以上 | 利空，市場反感情緒 | 減碼觀望，等均線訊號再進場 |

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| 對等關稅 | 川普政府針對各國對美貿易順差實施的對應性關稅，以 IEEPA 為法源 |
| IEEPA | 國際緊急經濟權力法（1977 年），原為動結資產用途，川普創先例用於課關稅 |
| 301 條款 | 美國貿易法中針對不公平貿易行為的調查與制裁條款 |
| 232 條款 | 基於國家安全理由對特定商品課稅（鋼鐵、鋁、半導體等） |
| 洗產地 | 將中國商品經由第三國（如越南）轉口出口至美國，規避關稅 |
| 他口交易 | 因特定事件或題材產生的短期交易機會 |
| 貨幣戰 | 若關稅無法改善貿易逆差，下一步可能逼迫他國貨幣升值 |
| 主權基金 | 由國家設立的投資基金，可用於協助產業轉型、穩定經濟 |
| 胡志明指數 | 越南股市主要指數，反映越南整體股市表現 |
| KOSPI | 韓國綜合股價指數，韓國股市主要指標 |
| LME 銅 | 倫敦金屬交易所的銅期貨價格，全球銅價基準 |
