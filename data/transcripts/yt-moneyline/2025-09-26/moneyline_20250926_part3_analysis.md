## 📊 市場總體觀察

### 政策面動態

#### 基本工資調漲
- 基本月薪調高至29,500元
- 時薪調高至196元
- 反映通膨壓力，勞工薪資持續調整

#### 月薪五萬免繳稅政策
- 總統宣布月薪五萬以下明年可免繳所得稅
- **重要條件限制**：
  - 必須是「單身租屋族」才完全適用
  - 需包含免稅額、標準扣除額、薪資特別扣除額等加總
  - 單身租屋族：年收入62.6萬元以下免稅（月均約5.2萬元）
  - 若非租屋族，扣除項目減少，月薪5萬仍可能需繳稅
- 財政部補充：並非所有月薪5萬者都免稅，需視個人條件而定

### 股利所得與稅務策略

#### 小資族利多
- 股利所得可採合併計稅，享8.5%抵減稅額
- 年收入62.6萬以下的單身租屋族，股利所得合併後仍可免稅
- 抵減上限可完全抵消應繳稅額

#### 高所得者注意
- 所得稅率30%以上者，股利合併計稅反而不利
- 股利所得超過94萬元者需特別注意
- **分離課稅策略**: 高所得者應選擇28%分離課稅，避免被推高至40%以上稅率
- **範例**: 月薪40萬的醫生，若股利合併計稅會以最高稅率課徵，改用分離課稅（28%）可大幅節稅

#### 高股利族節稅方法

1. **分離課稅**: 股利單獨以28%稅率計算，適合所得稅率30%以上者
2. **投資海外基金/KY股**: 境外所得適用最低稅負制，可降低稅負
3. **除息前賣出**: 避免當年度股利所得，但需有後續買回策略
4. **成立投資公司**: 持股不賣，公司可列報各項費用抵減，適合大股東與長期持有者
5. **股息傳承信託**: 將股票信託10年，股利直接分配給子女，本金自己保留控制權

#### 股票虧損與股利稅務
- **重要觀念**: 股票投資虧損不能與股利所得互抵
- 股利屬於薪資性收入，依法需課稅
- 股票未實現損失不被認列為虧損
- 即使帳面大幅虧損，股利仍需繳稅

## 💼 產業分析與投資建議

### 一、第四季集團股輪動 —— 抓住新主流

#### 投資邏輯
- 第四季歷來是美股與台股最會漲的一季
- 第四季行情通常預告明年上半年的新主流
- 從集團股內部輪動可看出未來趨勢方向

#### 個股推薦

**1. 鴻海（2317）—— 第四季仍有機會**
- 今日長黑K棒，但十日均線位置為重要支撐
- 若前高成為支撐、完成換手，第四季目標可看210元以上
- 230元區間仍有突破型態的可能

**2. 光寶科（2301）—— 台達電攻千元的跟漲者**
- 台達電準備攻千元，電源大革命題材仍在
- 光寶科為鴻海集團旗下電源供應器重要廠商
- 若守住前面整理平台、大盤反攻，光寶集團有機會跟漲

**3. 仁寶（2324）—— 集團中相對低價**
- 價格較低，適合資金有限的投資人
- 仁寶集團中直接看仁寶本身即可
- 其他集團成員（如光寶科）價格已從低價漲到百元以上

**4. 國巨（2327）—— 被動元件龍頭**
- 被動元件檔數不多，資金集中效果好
- 若週二、週三出現紅棒，被動元件族群將再掀一波行情

### 短期策略（1-2週）
- 下週有反彈機會，但需觀察美股穩定度
- 記憶體為下週最重要的焦點，華邦電、南亞科若止跌為買點
- 被動元件（國巨）若出紅棒可帶動一波行情
- BBU與散熱股帶頭反攻的機率高

### 中期策略（1-3個月）
- 第四季集團股輪動為主軸
- 鴻海集團（光寶科、仁寶、以諾）
- 國巨集團（被動元件）
- 台塑集團（南亞、南電）

- 極端概念新題材（能緯、東元）值得追蹤

### 稅務策略建議
- 小資族：善用股利合併計稅的8.5%抵減稅額
- 中等收入者：注意股利所得是否推高稅率級距
- 高所得者：應選擇28%分離課稅
- 大股東：考慮成立投資公司或股息傳承信託
- 所有投資人：記住股票虧損不能抵減股利所得稅

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **特留份** | 民法規定繼承人可保留的最低遺產份額，即使遺囑指定他人也不能完全剝奪 |
| **遺囑** | 被繼承人生前以書面方式表達財產分配意願的法律文件 |
| **股息傳承信託** | 將股票交付信託，股利分配給受益人（子女），本金控制權保留給委託人 |
| **分離課稅** | 股利所得不與其他所得合併，單獨以28%稅率課稅的方式 |
| **合併計稅** | 股利所得併入綜合所得稅計算，可享8.5%抵減稅額（上限8萬元） |
| **KY股** | 在台灣上市但註冊地在海外的公司，股利屬境外所得，適用最低稅負制 |
| **月K線帶大量** | 月線級別出現放量，通常代表中長期趨勢轉折的訊號 |
| **解禁** | 處置股票恢復正常交易，不再受分盤交易限制 |
| **232調查** | 美國貿易法第232條調查，以國家安全為由評估進口商品是否威脅國內產業 |
