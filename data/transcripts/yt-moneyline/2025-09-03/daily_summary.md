## 📈 技術面分析總整理

### 大盤操作策略分層

| 大盤狀態 | 操作策略 |
|---------|---------|
| **目前——中短線修正** | 擇強埋進，選比大盤強的個股，5日均線操作 |
| 仍有創高可能 | 技術面突破買進，均線突破、中繼站買點 |
| 修正一段時間後 | 重質選擇，價值投資、合理本益比 |
| 全面轉空 | 等確認底型，選台灣50成分股 |

### 個股操作原則

#### 強勢股

1. 沿5日或10日均線操作
2. 回測前波大量區低點為「中繼站買法」
3. 停損：收盤跌破設定均線即出場

#### 長多轉落股

1. 收盤跌破大量區間低點 → 退出
2. 上漲軌道線（十日線/月線）跌破 → 減碼
3. 資券同減而價落 → 警戒主力出貨

#### 處置股

1. 利用股票期貨做替代交易或避險
2. 觀察期貨成交量判斷人氣
3. 出關後觀察法人動態決定方向

### 選股方向

- **選小不選大** → 中小型股優於大型股
- **選內不選外** → 內資主導個股優於外資主導
- **正規軍勝蹭題材** → 區分實質業務與題材投機
- **觀察期貨量** → 期貨量維持高檔代表仍有人氣

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **VEU** | Validated End-User，已驗證最終用戶，美國商務部對特定出口管制的豁免機制 |
| **收斂三角形** | 技術分析型態，高點逐漸降低、低點逐漸升高，預示即將變盤 |
| **處置股** | 因股價波動異常或成交量過大，被交易所列入分盤交易的股票 |
| **注意股** | 股價波動達警示標準的股票，為處置股前一階段，尚無交易限制 |
| **分盤交易** | 非即時撮合，每5或20分鐘集合競價撮合一次 |
| **股票期貨** | 以個股為標的之期貨合約，一口=2張，保證金13.5%-20% |
| **功率半導體** | 專門處理電力轉換與控制的半導體元件 |
| **MOSFET** | 金屬氧化物半導體場效電晶體，低功率開關應用 |
| **IGBT** | 絕緣柵雙極電晶體，高功率應用如電動車 |
| **碳化矽 (SiC)** | 第三代半導體材料，耐高溫高壓 |
| **氮化鎵 (GaN)** | 第三代半導體材料，高頻高效率 |
| **中繼站買法** | 回測前波最大成交量區間低點時買進的操作策略 |
| **資券同減而價落** | 融資融券同步減少且股價下跌，暗示主力出貨 |
| **季線（生命線）** | 60日均線，中期趨勢判斷的關鍵線 |
| **DMI（趨向指標）** | 判斷趨勢方向與強度的技術指標 |
| **KD交叉向上** | K線由下往上穿越D線，短線買進訊號 |
| **穩定幣** | 與法定貨幣掛鉤的加密貨幣，價格波動小 |
| **智能合約** | 區塊鏈上自動執行的程式碼合約 |
| **WFI** | 川普家族支持的世界自由代幣 |
| **主動式ETF** | 由基金經理人主動選股的ETF，非被動追蹤指數 |
| **UPS** | Uninterruptible Power Supply，不斷電系統 |
| **BBU** | Battery Backup Unit，電池備援單元 |
| **BMS** | Battery Management System，電池管理系統 |
