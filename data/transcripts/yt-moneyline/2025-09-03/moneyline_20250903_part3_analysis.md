## 🌍 市場總體觀察

### 處置股現象觀察

- 近三週成交量越來越活躍，導致多檔個股因過度激情遭列處置股
- 目前約**二十多檔**個股被列為處置股（分盤交易五分鐘、十分鐘、十五分鐘撮合等）
- 觀察重點：二十多檔中**僅四檔下跌**，其他被列入處置股後仍持續上漲
- 市場流傳：「關了不要緊，關過才是大哥」——暗示處置後仍有行情

### 加密貨幣市場重大事件

- **川普家族穩定幣 WFI（世界自由代幣）** 於9月1日正式上線交易
- 由川普三個兒子推動，川普擔任名譽董事長
- 初始發行量高達**250億顆**，遠超市場預期的3,000萬至50億顆
- 開盤從0.2美元衝至0.478美元，隨後大幅回落，盤中約0.23美元
- 前兩輪投資者成本約0.05至0.15美元，已有獲利了結賣壓
- 川普家族持有超過**80%代幣**，帳面價值逾**65億美元**

### 比特幣市場觀察

- 比特幣創新高後正在修正中，8月曾突破12萬美元
- 機構投資人持續累積籌碼，**美國比特幣相關ETF基金規模近1,500億美元**
- 已接近美國黃金相關ETF與基金規模的1,800億美元
- 各國開始將比特幣納入戰略儲備（美國已開始）
- 4月低點約75,000美元，一路上漲至12萬美元，目前屬於創新高後的健康拉回

## 💼 產業分析與投資建議

### 一、處置股操作策略（林政文老師）

#### 處置股交易規則

| 項目 | 第一次處置 | 第二次處置（30天內再犯） |
|------|-----------|---------------------|
| 撮合間隔 | 5分鐘一次 | 20分鐘一次 |
| 處置天數 | 10天 | 12天 |
| 其他限制 | 預收款券、暫停信用交易 | 同上，限制更嚴 |

#### 處置股的流動性風險

1. **買賣價差擴大** → 不利進出
2. **成交量大幅下降** → 流動性枯竭
3. **交易成本增加** → 無法使用融資融券
4. **波動加劇** → 流動性不足導致價格非正常節奏波動

#### 股票期貨做為替代管道

- 處置股的資金會轉移至**股票期貨**市場
- 股票期貨優勢：
  1. **價格發現功能** → 觀察期貨量能可預判現貨走勢
  2. **槓桿效率** → 保證金僅需13.5%-20%（對比融資四成）
  3. **交易成本低** → 手續費及相關費用遠低於現貨
  4. **多空雙向交易** → 放空不需借券，隨時可做
  5. **不受處置限制** → 即時撮合，不受分盤交易影響
- 缺點：每月第三個週三需**結算**，持有需注意到期日

#### 實戰案例：台波避險操作

- **情境**: 8月19日持有台波現貨10張，股價36元，已知將被處置10天
- **策略**: 放空5口股票期貨（1口=2張）對沖
- **結果**: 現貨下跌虧損6.65萬元，期貨避險收入6.65萬元，**完全對沖**
- **優勢**: 不論處置期間股價漲跌，透過期貨完全規避風險

### 二、加密貨幣投資分析（大波/齊展老師）

#### 比特幣 (BTC)

- **目前定位**: 加密貨幣的「台積電」，市值最大、機構投資人最多
- **投資特性**: 機構買了不太會賣，籌碼長期鎖定
- **美國BTC ETF**: 資產規模近**1,500億美元**，接近黃金ETF的**1,800億美元**
- **戰略儲備趨勢**: 美國已將比特幣列為戰略儲備，其他國家有望跟進
- **技術面**: 4月低點75,000美元→12萬美元，目前為創新高後拉回，屬健康修正
- **投資建議**: 價格已高，不宜期待過大漲幅；透過受監管管道投資（如台灣合規交易所或美國ETF）

#### 以太幣 (ETH)

- **目前定位**: 市值第二大加密貨幣
- **特點**: 波動比比特幣更劇烈，因市值較小、投資人較少
- **走勢**: 從1,400美元漲至接近5,000美元，漲幅巨大
- **核心價值**: 智能合約應用生態，穩定幣題材帶來實體消耗需求
- **風險**: 若穩定幣題材消退，修正幅度可能較大（漲幅太多、獲利回吐壓力大）
- **投資建議**: 就算回到2,000-3,000美元仍屬正常修正，多頭格局未變

#### 加密貨幣投資原則

1. **選市值前五大** → 長期投資僅選主流幣（比特幣、以太幣等）
2. **避開小幣** → 川普幣等小型加密貨幣風險極高
3. **注意流動性** → 小幣可能隨時崩盤
4. **選擇受監管管道** → 台灣合法交易所或美國ETF
5. **小幣能漲一天十天一個月，但不一定活過一年** → 除非專業短線操作，否則不碰

- **三角形收斂**: 持續收斂中，即將變盤
- **月線**: 連三天跌破，差約60點，突破即轉多

- **KD指標**: 修正中，等待交叉向上
- **季線**: 扣低期間，接近季線不宜殺低

### 股票期貨技術指標應用

- **觀察期貨成交量**: 拉出5日均量線，當期貨量維持在均量之上代表仍有人氣
- **期貨量萎縮訊號**: 期貨成交量跌破5日均量時，代表行情可能走完
- **DMI指標（趨向指標）**: 紅色線（+DI）在綠色線（-DI）上方為多方趨勢；紅綠線發散為趨勢啟動訊號
- **案例——金居**: 現貨被處置後量縮，但期貨量上升，代表資金轉移至期貨；現貨出關後期貨量可能回落

## 📋 投資策略總結

### 短期策略（1-2週）

- **大盤判斷**: 三角形收斂末端，即將變盤，需量能配合
- **處置股操作**: 利用股票期貨做避險或替代交易管道
- **出關個股**: 聯茂優於台波（法人動態較正面）；聯亞基本面佳可留意
- **加密貨幣**: 比特幣修正中不急追，等待拉回穩定後再布局
- **業績股**: 下週營收公布為關鍵，業績股必須帶量領軍

### 中期策略（1-3個月）

- **比特幣**: 機構持續累積，各國戰略儲備趨勢支撐長期多頭
- **以太幣**: 穩定幣題材為核心驅動力，題材不滅則多頭不變
- **股票期貨應用**: 持有強勢股但擔心處置風險時，善用期貨避險
- **軍工國防**: 下週國防展為催化劑，觀察題材能否延續

### 風險評估

- **處置股風險**: 流動性驟降、交易成本增加、價格波動異常
- **加密貨幣風險**: 小幣壽命不確定、海外交易所無監管保障、川普幣投機性極高
- **大盤風險**: 量能持續萎縮、月線連三天失守、三角形收斂後方向未明
- **匯率風險**: 台幣走貶對出口有利但對進口與海外投資計價有影響

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **處置股** | 因股價波動異常或成交量過大，被交易所列入分盤交易的股票，撮合間隔延長為5-20分鐘 |
| **注意股** | 股價波動或成交量達到警示標準的股票，尚無交易限制，為處置股的前一階段 |
| **股票期貨** | 以個別股票為標的物的期貨合約，一口代表2張（2,000股），保證金約13.5%-20% |
| **分盤交易** | 處置股的交易方式，非即時撮合，而是每5分鐘或20分鐘集合競價撮合一次 |
| **預收款券** | 處置股交易限制之一，買進時需預先繳交全額款項（非T+2交割） |
| **WFI（世界自由代幣）** | 川普家族支持的穩定幣/加密貨幣，由世界自由金融公司發行 |
| **穩定幣** | 與法定貨幣（如美元）掛鉤的加密貨幣，價格波動小，用於加密市場交易媒介 |
| **智能合約** | 在區塊鏈上自動執行的程式碼合約，以太坊為主要平台 |
| **ETF（指數股票型基金）** | 在交易所上市交易的基金，可追蹤特定指數或資產（如比特幣ETF） |
| **DMI（趨向指標）** | Directional Movement Index，判斷趨勢方向與強度的技術指標 |
| **三角形收斂** | 技術分析型態，高點逐漸降低、低點逐漸升高，預示即將變盤 |
| **KD交叉向上** | KD指標中K線由下往上穿越D線，為短線買進訊號 |
