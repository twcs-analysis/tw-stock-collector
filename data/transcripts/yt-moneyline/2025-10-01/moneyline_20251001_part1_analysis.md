## 📊 市場總體觀察

### 台股走勢

- **大盤表現**：台北股市今日再度挑戰歷史新高，大漲160.2點，收盤29,082點
- **五日均線**：前天跌破，今天迅速站回，顯示多方力道仍強
- **成交量**：約4,657億元，與昨日持平
- **三大法人動態**：
  - **外資**：持續買超
  - **投信**：整個9月份賣超，但9月30日（季底最後一天）轉賣為買，10月1日繼續買超，為重要轉折訊號
  - 可能拉出本土法人投信的多頭行情
- **股王信驊（5274）**：盤中再創歷史新高，一度漲至5,465元
- **台積電（2330）**：盤中差5元再創歷史新高

### 美股影響

- **美國政府關門**：台北時間10月1日中午12點正式宣布暫時停擺，共和黨與民主黨談不攏
- **影響範圍**：航空交管繼續運作但不發薪水、鐵路不中斷、國家公園部分開放、護照簽證持續辦理
- **經濟數據蓋牌**：政府停擺期間重要經濟數據全部不公布
- **美國期貨盤**：下跌約0.7%-1.1%，但跌幅持續收斂
- **台指期夜盤**：受到牽連下跌

### 國際市場動態

- **聯準會降息預期**：FedWatch最新顯示10月29日降息一碼機率達94.6%，12月持續降息，年底前兩次降息無問題
- **黃金**：持續創歷史新高，接近3,900美元/盎司
- **美國政府關門對降息影響**：市場認為關門反而增加降息理由，政府停擺導致經濟風險增加，聯準會可能提前行動
- **美股指標股**：輝達（NVIDIA）平台整理突破、美光（Micron）創歷史新高附近、Robinhood散戶交易活躍代表多頭氣氛仍在

### 個股技術面重點

- **台積電（2330）**：十日均線為操作參考，跌破出場
- **緯創（3231）**：均線糾結發散型態，140.5元為短線停損

### 操作策略

- **大盤定位**：「史高震」——持續創歷史新高但震盪幅度加大
- **選股方向**：資券同增而價強、法人買而價強
- **風險控管**：設停損點、爆大量低點為出場參考、不追高
- **資金配置**：避險資金流向黃金，債券壓力較大

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| 史高震 | 指數持續創歷史新高但震盪幅度加大的盤勢型態 |
| 資券同增而價強 | 融資與融券同步增加但股價仍強勢上漲，暗示主力與業內資金進場 |
| 週線乖離率 | 股價偏離週均線的幅度，過大代表短線超漲容易回測 |
| 雙背離 | 股價創新高但技術指標未過高，且成交量萎縮，為頭部警訊 |
| 十日均線停利法 | 以十日均線為動態停利點，收盤跌破即出場，保護獲利 |
| FedWatch | CME聯準會觀察工具，反映市場對聯準會利率決策的預期機率 |
| CPO（Co-Packaged Optics） | 共同封裝光學技術，將光模組與交換晶片封裝在一起 |
| PSPI（感光型聚醯亞胺） | 半導體先進封裝製程中的關鍵材料，用於圖案化和絕緣層 |
| HBM | 高頻寬記憶體（High Bandwidth Memory），AI晶片關鍵元件 |
| 太弱留強 | 將比大盤弱的個股換掉，保留或買進比大盤強的個股 |
