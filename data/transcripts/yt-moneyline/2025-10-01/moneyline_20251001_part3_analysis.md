## 「持續買進」作者由股轉債分析

### 事件背景

美國暢銷書「持續買進」（Just Keep Buying）作者，長期投資百分之百股票作為退休金，最近將退休帳戶調整為80%股票+20%美國中期公債。

### 作者看到的風險

| 風險因素 | 說明 |
|----------|------|
| AI題材過熱 | 部分機構花2-3億美元請AI人才，效果不如預期就停止 |
| 股價營收比過高 | 很多企業市值極高但營收追不上，20年營收也賺不回市值 |
| 歷史對照 | 上次股價營收比過高出現在2021年11月（接近7兆美元），隨後美國升息股市大跌 |
| 本次狀況 | NVIDIA市值突破4.5兆美元，部分個股估值過高 |

### 作者的資產配置調整

| 帳戶類型 | 調整前 | 調整後 | 原因 |
|----------|--------|--------|------|
| 退休帳戶 | 100%股票 | 80%股票+20%中期公債 | 認為估值過高，需降低風險 |
| 經濟帳戶 | 股票為主 | 保守投資公債+市政債 | 近期想買房，需穩健資產 |

### 專家觀點

| 觀點 | 說明 |
|------|------|
| 合理性 | 適時調整資產配置是合理行為，不同人生階段需求不同 |
| 年輕人 | 可維持較高股票比重（股八債二） |
| 接近退休 | 應增加穩健資產比重 |
| 有現金需求 | 如買房、結婚等，資金不應放在高波動商品 |
| 參考建議 | 股六債四（較保守）或股八債二（較積極） |

### 美國就業風險

| 項目 | 內容 |
|------|------|
| 非農就業人口 | 調整後每月增幅已降至7萬多，3個月均值更低 |
| 6月數據 | 已出現負值 |

| 政府關門後 | 可能進一步大規模裁員，就業數據恐持續惡化 |
| 影響判斷 | 短期經濟數據可能不好，但目前尚未惡化，降息前仍可樂觀 |

## 名詞解釋

| 名詞 | 說明 |
|------|------|
| 股期（股票期貨） | 以個別股票為標的的期貨合約，可觀察法人對個股的多空態度 |
| KD黃金交叉 | K值由下往上穿越D值，為技術分析中的買進訊號 |
| 不含散單 | 排除散戶小額交易後的法人籌碼指標，低於100為偏空，高於100為偏多 |
| 雙背離 | 股價與技術指標走勢相反，如股價創高但指標未創高，為轉弱警訊 |
| Just Keep Buying | 美國暢銷理財書籍，主張長期持續買進股票累積財富 |
| 股價營收比（P/S Ratio） | 公司市值除以年營收，衡量估值是否過高的指標 |
| 政府關門（Government Shutdown） | 美國國會未通過撥款法案導致政府部分機構暫停運作 |
| 騰落指標 | 上漲家數減去下跌家數的累積值，反映市場廣度健康程度 |
| 安可（Encore） | 演唱會結束後觀眾要求加演，此處比喻大盤在高檔持續創高 |
| 選擇權賣權（Put） | 賦予持有者在到期日前以約定價格賣出標的物的權利，用於避險或做空 |
