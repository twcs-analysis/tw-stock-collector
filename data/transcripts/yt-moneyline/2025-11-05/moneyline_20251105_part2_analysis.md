## 市場總體觀察

### 11月投信換股潮 -- 主夢行情開始

#### 為什麼11月投信頻繁換股？

**被動式換股（制度規定）**:
- MSCI、復旦指數、加權指數、特選ETF指數，固定在5、8、11月進行季度或半年度成份股調整
- 投信法人須在公告生效日前調整持股
- 11月21日前需送件主管機關
- 被動式ETF須追蹤指數成份變動

**主動式換股（基效壓力）**:
- 基金經理人年底績效結算在即
- 績效好的基金明年規模更大（定期定額資金會轉向績效佳的基金）
- 為明年績效鋪路：先行布局明年主流股
- 實現獲利：必須實際賣出才能分配績效
- 年底作帳行情：集團半年報與年報的平均價格決定明年可借款額度

#### 11月換股時間軸

| 時間點 | 事件 |
|--------|------|
| 10月21日-25日 | ETF指數公司送件申請調整 |
| 10月底-11月初 | 指數公司公告調整名單 |
| 11月中旬 | MSCI調整 |
| 11月底 | 新成份股正式生效 |
| 12月底 | 年底作帳行情 |

## 第三季財報分析：四大選股邏輯

### 子東的財報選股法

**核心觀點**: 單看EPS太粗糙，需搭配四大條件才能找出真正黑馬

#### 條件一：效果的現金題 -- EPS創新高

- 第三季EPS大過於第二季
- 排除第二季虧損、第三季虧損較少的假改善
- 確認獲利是真實成長

**統計結果**: 第三季EPS創新高共13檔，營收創新高約20檔

#### 條件二：存貨周轉率盤升

- 商品越賣越好的指標
- 第三季多數公司存貨周轉率僅微幅上升
- 原因：第二季因關稅問題緊急拉貨，基期已高
- 周轉率維持10%以上已算不錯
- 庫存水位下降 + 周轉率上升 = 有漲價潛力

#### 條件三：外資逆勢買超

- 大方向外資在賣超台股
- 但有些公司外資偏偏在買
- 正統外資不會一天大買、隔天大買
- 真正布局是鋸齒狀買法（整體趨勢不停歇）
- 代表外資看到特定公司的長期價值

#### 條件四：股價淨值比偏低

- 台股上市股價淨值比已接近3倍（接近2000年泡沫水準）
- 選股價淨值比偏低的，具防守性

### 財報選股結果

#### 台達電 (2308)

**財報亮點**:
- EPS像坐雲霄飛車：去年Q4 2元 → 今年Q1 3元 → Q2 5元 → Q3 7.16元
- 季季創新高，爆發性極強
- 有分析報告預估2027年HVDC爆發後，年EPS可達29元
- Q3 7.16元 × 4 = 接近28元，已接近預估值

**操作建議**:
- 千元保衛戰有機會守住
- 投信買盤近期稍微減弱但仍在
- 目標價: 市場已有看法上修趨勢

#### 崇越 (5765) 與台特化

**基本面**:
- 外資連續四個月站在買方
- 正統外資鋸齒狀買法
- 從今年Q4到2027年進入一奈米世代
- 獨門獨市公司，沒有競爭對手

**崇越技術面**:
- 中長線架構，每次拉回修正到月線就是買點
- 服務台積電的先進設備供應商

**台特化技術面**:
- 用週線或月線觀察較準確
- 獨門獨市公司股價整理期可達半年
- 適合長線投資

**操作建議**:
- 月線附近逢低分批布局
- 不用追高
- 長線趨勢跟隨台積電正成長

#### 致遠 - 交換器/網通

**基本面**:
- 前兩年清庫存階段
- 外資6-7月大量布局，建倉成本約200元
- 第三季EPS創新高
- 目前價位與外資成本差不多

**技術面**:
- 目前偏空
- 需確認200元以下外資是否重新建倉

**操作建議**:

- 否則再觀望

#### 保瑞 - 生技CDMO

**基本面**:

**操作建議**:

#### 連電 - 半導體電子

**基本面**:

- 上游降價 = 連電毛利有效提升

- 車用電子佔比較高
- 台積電Q3提到車用電子附近，連電為相關供應鏈

**籌碼面**:

#### 同經電 - CMOS（國巨集團）

**基本面**:

- 第三季EPS有上來（約2.028元）

**操作建議**:
- 中長線法人有在積極布局
- 股價偏低具防守性

#### 牧德 - PCB檢測設備龍頭

**基本面**:
- 存貨周轉率由0.58升至0.95（與去年同期比）
- 存貨快速遞減，公司庫存降低
- 周轉率上升 + 庫存降低 = 商品搶手，有漲價潛力

**技術面**:

- 周轉率數據與股價起漲時間吻合

**操作建議**:
- 關注存貨周轉率趨勢
- 設備龍頭地位穩固

#### 台鴻 - PCB軟板/PTFE

**基本面**:
- PTFE（鐵氟龍）材質，介電損耗更小、更便宜
- 應用於低軌衛星、網通（不需高層數板的場景）

**籌碼面**:

**技術面**:

- 今天拉回後形態未被破壞

**操作建議**:
- 等待圓弧右半邊成形
- 園氣恢復後可能再上攻

## 千金股比價效應

### 玉堂的比價邏輯

**核心觀點**: 千金股數量創歷史新高（27-28檔），高價股一檔帶著一檔上，投資人買不起千金股可尋找同族群中位置偏低的個股

**比價邏輯**:
1. 千金股代表市場給予高度評等
2. 同產業中有競爭力的公司，價格相對低
3. 多頭時期比價效應更顯著
4. 股王股后之爭推動整體族群向上

### 散熱族群比價

**簡述千金三傑**: 建準、奇鋐、雙鴻

- 建準早就是前金股（前一波衝到2,000元）
- 奇鋐衝上來
- 雙鴻過去一個多月從600-700元衝上千金

#### 精確 (3008) - 散熱/電動車

**基本面**:
- 過去做電動車零件與散熱
- 轉投資散熱領域，開始出貨水冷板、浸沒式相關零組件
- AI伺服器訂單11月底開始出貨
- 營收佔比目前不高，但明年將逐步增加
- 本業電動車業績也不錯

**技術面**:
- 昨天直接一根漲停
- 今天爆大量（過去長期無量）
- 昨天多方缺口今天回補一點後仍收紅
- 早盤開高拉高，盤中受大盤壓力但整體強勁
- 籌碼換手乾淨（不是高檔爆量）

**操作建議**:
- 股價僅60幾元，相對千金散熱股便宜
- 量能延續是關鍵
- 有量就有希望

#### 建準 (2421) - 散熱風扇

**基本面**:
- 伺服器風扇為主力
- 也有液冷散熱產品（水冷模組、CDU冷卻液分配）
- 營收表現不錯
- 已剩樣給台灣大型客戶

**技術面**:
- 10月開始有後期之勢
- 外資買了非常長的一段時間
- 昨天開高走低暴量黑K是警訊
- 今天跌破昨天低點
- 形態上不能說轉空，但昨天黑K壓力未化解

**操作建議**:
- 操作上稍微再等一等
- 需克服昨天黑K高點後才有機會再上攻
- 短線操作留意反彈壓力

## 技術面分析與操作策略

### 族群輪動策略
- 電子股成交比重過高時，資金會轉往非電族群
- 11月份非電族群（軍工、大亞、華融、亞電、統一超等）開始表現
- PCB與記憶體仍為投信主力布局方向

### 千金股操作建議
- 不敢追千金股者，可在同族群中找相對低位的個股
- 比價效應在多頭時期更加顯著
- 風險較低（位置低）、空間可期（族群帶動）

### 第三季財報選股重點
- 11月15日前財報全部公布
- 11月20日NVIDIA財報為重要時間節點
- 選擇業績成長、存貨周轉率上升、外資逆勢買超、估值偏低的標的

---

## 投資策略總結

1. **11月為主夢行情起點**: 投信換股潮 + 年底作帳 + 集團護盤，資金將流入明年主流股
2. **PCB仍是主戰場**: 投信主動式基金大量買進PCB族群，精層科、大量、金居為代表
3. **第三季財報四維選股**: EPS創新高 + 存貨周轉率上升 + 外資逆勢買 + 低股價淨值比
4. **千金股比價效應**: 同族群中找相對低位標的（精確、良維、雍智等）
5. **時間為盟友**: 獨門獨市公司（崇越、台特化）用時間換空間，月線逢低布局

|------|------|
| **MSCI調整** | 摩根士丹利資本國際指數的成份股調整，每年2月、5月、8月、11月進行季度檢視 |
| **主夢行情** | 投信為明年績效提前布局主流股的行情，通常從11月開始啟動 |
| **年底作帳** | 集團或基金年底前拉抬旗下持股以美化淨值或財報的行為 |
| **存貨周轉率** | 衡量公司存貨銷售效率的指標，越高代表商品銷售越快 |
| **股價淨值比（P/B）** | 股價除以每股淨值，反映市場對公司資產的評價，越低代表越便宜 |
| **鋸齒狀買法** | 外資布局策略，不連續大買而是一天買、一天休息，總趨勢不停歇 |
| **ETF成份股調整** | 指數型基金定期檢視並調整追蹤指數的成份股名單 |
| **PTFE** | 聚四氟乙烯（鐵氟龍），介電損耗更小的PCB板材料，應用於低軌衛星與網通 |
| **碗形底** | 技術分析型態，股價緩慢築底後上升，為多方蓄勢訊號 |
