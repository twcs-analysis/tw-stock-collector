## 多頭延長賽分析

**核心觀點**: 台股目前像MLB世界大賽第七場延長賽，多頭尚未結束

**研判依據**:
- 年初預測高點從25,000、26,000到現在28,000，不斷被突破
- 今天下殺留下影線，多頭氣勢未結束
- 不能斷定此處轉空
- 個股輪動速度極快，一天漲隔天跌

**選股三大面向**:
1. **技術面**: 選擇底部區或剛突破整理區間的個股，下檔空間有限、上檔可以期待
2. **族群輪動**: 在熱門族群中找漲幅落後、會做輪動的個股
3. **籌碼面**: 法人有站在買方的、特定買盤進場的

## 美國政府關門與國際分析

### 祺戰的美國政府關門分析

**現況**:
- 美國政府關門已進入第35天，創史上最長記錄
- 4,000多萬靠食品券過活的民眾面臨斷炊
- 航管人員缺數千人，部分航班可能關閉
- 最樂觀看法：11月8日（週六）有機會重啟

**兩黨分歧**:
- **共和黨**: 先恢復政府運作，延長原有撥款，再談長期策略
- **民主黨**: 要求擴大或延長健保補貼方案，不接受短期補救

**妥協方案浮現**:
- 四位兩黨議員組成小組
- 提出延長補貼兩年但設置補貼上限的折衷方案
- 有望成為突破口

**市場影響**:
- 若週六達成共識重啟政府，為短線利多
- 但政府重啟後，淤積的經濟數據將公開
- 失業率若從預期的4.3-4.4%升至4.8%，將衝擊市場

### 美股技術面

- S&P 500歷史高點在上週三
- 企業財報公布後（加大資本支出）仍漲不上去
- 月線尚未碰到，不必覺得要崩
- 10月10日川普宣布對中國加徵關稅時的低點為重要支撐

### 美債

- 最高來到4.12%，目前4.078%附近
- 高點持續降低的趨勢未改變
- 殖利率往下 = 債券價格持續反彈
- 若政府重啟後加大發債，對美債短期不利

### 黃金

- 兩週前因川習會面傳言，一天跌5%跌破4,000美元
- 目前在4,000美元附近震盪
- 月線慢慢走平
- 關鍵觀察：能否站上月線往上走
- 若月線下彎且跌破，下行空間將擴大

## 技術面分析與操作策略

### 大盤技術面
- 五日均線、十日均線已破，月線守住
- KD短線賣出訊號出現（K值降至59）
- 價跌量增為正常現象

- 若日KD重新交叉向上再進場為保守策略

### 操作策略
1. **短線操作**: 選擇守住月線、比大盤強的個股
2. **中線布局**: 好股票遇到利空拉回時，逢低分批承接
3. **停損紀律**: 個股跌破十日均線或起漲點即出場
4. **時間節點**: 11月20日前避開財報可能有問題的標的（NVIDIA財報11月20日公布）

## 投資策略總結

1. **大盤研判**: 多頭延長賽進行中，短線震盪但中線未轉空，月線為多空分界
2. **記憶體走獨立行情**: 不跟美股連動，長價效應想像空間大，以十日均線為操作依據
3. **千金股拉回非末日**: 台積電、台達電等拉回是好股票出現便宜價的機會
4. **非電族群輪動**: 電子股成交比重過高時，軍工、資產股等非電族群有輪動機會
5. **底部突破股優先**: 選擇相對低檔、剛突破整理區間的個股，風險較低

## 名詞解釋

| 名詞 | 說明 |
|------|------|
| **13F報告** | 美國SEC要求管理資產超過1億美元的機構投資者每季度提交的持股報告，可窺見大型基金的投資方向 |
| **熔斷機制** | 股市跌幅達到一定比例時自動暫停交易的機制，韓國今天一度觸發 |
| **KD指標** | 隨機指標，K值與D值交叉向下為短線賣出訊號，交叉向上為買入訊號 |
| **波浪理論** | 技術分析方法，多頭波浪各波不重疊，若起漲點被跌破則轉為空頭波浪 |
| **碗形底** | 技術分析型態，股價緩慢築底後上升，形似碗的形狀，為多方蓄勢型態 |
| **PUE** | Power Usage Effectiveness，電能使用效率，資料中心的用電效率指標，越接近1越好 |
| **HVDC** | High Voltage Direct Current，高壓直流電，新一代資料中心配電技術 |
| **矽光子** | Silicon Photonics，利用矽基材料製造光學元件的技術，用於高速光通訊 |
