3. **權證**
   - 注意行使比例、到期日、造市狀況及流動性

#### 散熱產業演進
- **氣冷** -> **液冷（水冷）**: 已成為AI伺服器標配

#### 個股深入分析

##### 奇鋐（3017）- 散熱四大天王之首
- **前三季EPS**: 32元（去年全年21元）
- **營收成長**: 年營收雙位數成長
- **技術面**: 從1,580元回檔，走勢強勁
- **關鍵支撐**: 季線（169元附近）為核心價位
- **成長動能**:
  1. GB300機櫃量能增加帶動水冷需求
  2. ASIC伺服器也開始採用水冷（不僅GPU伺服器）
  3. 路邊系列（Rubin）新散熱模組參與機會
- **操作建議**: 長線列入明年觀察名單，必須關注
- **目標價/停損**: 季線為重要支撐，跌破需警覺

##### 富世達 - 奇鋐子公司
- **地位**: 奇鋐子公司，明年第三代Vera Rubin平台水冷需求增加
- **成長動能**: 亞馬遜ASIC產品導入水冷方案、水冷接頭需求增加
- **前三季EPS**: 約20元（去年全年7元）
- **獲利能力**: 毛利率尚不夠高
- **技術面**: 走勢超強，比奇鋐更強
- **評價**: 從現在評價看稍高，但奇鋐相對便宜
- **操作建議**: 不是第一考量，但訂單能見度看到2027年

##### 雙鴻（3324）
- **成長動能**: GB300出貨放量、第四季營收表現佳、明年Q1不會太淡
- **法說會說法**: 隨著冷板、分歧管需求持續增加
- **客戶**: 微軟、甲骨文等傳統客戶外，亞馬遜也開始加入
- **前三季表現**: 去年全年僅賺1元，今年獲利改善中
- **技術面**: 走勢與奇鋐類似，近期偏弱
- **明年展望**: 水冷比重持續擴大，獲利持續改善
- **操作建議**: 目前K線偏黑，等收紅K時切入；時間點理論上明年業績持續成長

##### 建準——液冷蓋板新題材
- **獨特技術**: 液冷蓋板（Lid）——封裝時直接將散熱結構嵌入晶片
- **傳統方式**: 水冷板外掛在晶片外面
- **進化方向**: 液冷蓋板封裝時一起放進去，散熱效能顯著提高
- **TDP（散熱設計功率）**: 目前約2,000W，蓋板技術可大幅提升
- **時間表**: 預計明年下半年AI GPU客戶開始採用
- **外資展望**: EPS看到2027年，獲利可挑戰三位數
- **操作建議**: 長線角度看，目前本益比偏高；關注明年下半年蓋板技術量產進度

- **操作策略**: 三階段操作不能搞錯

## 策略總結

### 嘉明核心策略
1. **散熱產業三大催化劑**:
   - GB300機櫃水冷需求增加
   - ASIC伺服器導入水冷
   - Rubin平台新散熱模組
2. **選股優先順序**: 奇鋐（整套做、評價合理）> 富世達（子公司連動）> 雙鴻（等收紅）> 建準（長線蓋板題材）
3. **蓋板技術**: 2026年下半年可能是轉折點，提前佈局建準
4. **關注時點**: 明年度業績是否持續成長，以基本面支撐股價

### 名哲核心策略
1. **千金股養成**: 高毛利率 + 真實獲利 + 產業龍頭/獨佔
2. **小資族三大介入管道**: 零股、小股期、權證
3. **洪鏡**: 抽不到別急著追，等回檔整理再留意
4. **被動元件**: 漲價是事實但別期待超級循環

### 進老師收盤策略
1. **翻多確認**: 趨勢已反轉，大盤在季線與前高之間震盪
2. **台積電為本波指標**: 能否率領AI族群翻多挑戰新高
3. **三階段操作**: 護盤股都輪過一遍 -> 換題材股 -> 最後換業績股

## 名詞解釋

| 名詞 | 解釋 |
|------|------|
| 液冷散熱 | 使用液體（通常為冷卻水或特殊冷卻液）來帶走晶片運算產生的熱量，效率遠高於傳統氣冷 |
| 水冷板 | 貼附在晶片表面的金屬板，內部有流道讓冷卻液流過，帶走熱量 |
| 液冷分配單元（CDU） | Coolant Distribution Unit，冷卻液分配裝置，負責將冷卻液分配至各伺服器 |
| 水冷快接頭 | 液冷管路的快速連接接頭，方便維護更換 |
| 液冷蓋板（Lid） | 將散熱結構嵌入晶片封裝中的技術，比外掛水冷板效率更高 |
| TDP | Thermal Design Power，散熱設計功率，表示處理器最大散熱需求 |
| GB300 | NVIDIA下一代AI伺服器平台，全面採用液冷散熱 |
| Vera Rubin | NVIDIA預計推出的第三代AI伺服器平台架構 |
| 小股期 | 小型股票期貨，每口100股（一般期貨為2,000股），適合小資族參與高價股 |
| 零股交易 | 以不足一張（1,000股）的股數進行交易，適合小額投資 |
| 權證 | 由券商發行的衍生性金融商品，以小額資金參與股票漲跌，具有槓桿效果 |
| ATC | Active Temperature Control，主動式溫控系統，洪鏡的核心技術 |
| SLT | System Level Test，系統級測試，用於驗證整個系統的功能與性能 |
| 競拍 | 新股上市前的價格競標，投資人出價得標後以該價格取得新股 |
| BBU | Battery Backup Unit，備用電池單元，用於伺服器不斷電系統 |
| CSP | Cloud Service Provider，雲端服務供應商（Google、Amazon、Meta等） |
