## 策略總結

### 三階段操作法（柯老師核心策略）

**第一階段：買國安基金護盤股**
- 政府護盤時期，優先買進國安基金重倉的權值股
- 代表標的：台積電、廣達、鴻海、國巨、緯創等
- 邏輯：護盤拉升一定先拉這些大型股

**第二階段：換到低位階低基期、產業熱門題材股**
- 當第一階段標的漲到壓力區不動時，換到低基期題材股
- 代表標的：重電概念股（華城、士電、中興電、亞力）、被動元件低價股

**第三階段：換到業績營收成長股**
- 反彈到高檔壓力區時，買進業績營收確定成長的股票
- 代表標的：設備股、半導體供應鏈中EPS持續成長者

### 進老師操作建議
- **記憶體**: 先觀望，看群聯、威剛、創見能否帶頭
- **AI伺服器**: 區間操作，低買高賣
- **被動元件與矽光子**: 長線低基期布局
- **PCB**: 指標股經緯電過高即可跟進同族群

### 嘉明操作建議
- **AI伺服器四大天王**: 鴻海、廣達、緯創、緯穎
- **Google概念股**: 鴻海、廣達為核心
- **電源供應**: 台達電、光寶科為正宗焦點（需輝達認證）
- **長線關注**: AI伺服器需求至2030年持續成長

## 名詞解釋

| 名詞 | 解釋 |
|------|------|
| KD指標 | 隨機指標，由K值與D值組成，用於判斷超買超賣。KD在20以下為超賣區，80以上為超買區。黃金交叉指K值由下往上穿越D值，為買進訊號 |
| MACD | 指數平滑異同移動平均線，由快線（DIF）、慢線（MACD）及柱狀體組成。零軸以上為多頭格局，柱狀體收斂代表跌勢趨緩 |
| 月線 | 20日移動平均線，為中期趨勢的重要參考。站上月線代表中期多頭確認 |
| 季線 | 60日移動平均線，為中長期趨勢判斷依據 |
| 口紅吃三黑 | 一根大紅K棒吞噬前面三根黑K棒，為強烈的多方反轉訊號 |
| CSP廠商 | Cloud Service Provider，雲端服務供應商，如Google、Amazon、Meta等，是AI伺服器的主要採購方 |
| ASIC | Application-Specific Integrated Circuit，特殊應用積體電路。相對於GPU的通用算力，ASIC為特定用途設計的晶片 |
| Gemini Street | Google推出的革命性AI模型，具備推理、分析與「讀懂空氣」的能力 |
| GB300 | NVIDIA下一代AI伺服器平台，預計全面採用液冷散熱 |
| 國安基金 | 國家金融安定基金，在台股大跌時進場護盤的政府基金 |
| U形反彈 | 股價緩慢築底後逐步回升的走勢型態 |
| V形反轉 | 股價快速下跌後迅速回升的走勢型態，力道最強 |
