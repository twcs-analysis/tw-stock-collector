## 💼 產業分析與投資建議

### 一、台積電三大柱（台積電、鴻海、台光電）

- **表現**: 盤中跌破月線，但尾盤走高收紅K

- **操作建議**: 跌就算跌破月線也不要離場，站在買方
- **關鍵支撐**: 月線附近，跌3%即可考慮進場
- **目標價**: 持續看多，短線低接
- **停損點**: 無明確設定，中長期持有

#### 鴻海 (2317)
- **表現**: 從200元以上跌破月線，收盤約200元
- **利多催化**: 9月5日將公布8月營收，第三季因雲端業務將強勁成長
- **操作建議**: 200元以下短線可買，波段走勢需看輝達表現
- **目標價**: 短線反彈至月線（200元上方）
- **停損點**: 視輝達走勢而定

#### 台光電 (6274)

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| 九月魔咒 | 統計上美股九月為全年跌幅最大月份，源自交易員假期歸來重新調倉、家庭開學資金需求、機構季度結算等因素 |
| ABC拉回 | 技術分析中的三波段修正型態，A波下跌、B波反彈、C波再跌，為正常多頭中的修正 |
| 空盤工具 | 指在大盤下跌時反而穩住的權值股（如台積電），主力利用其控制指數，使大盤不至於暴跌 |
| MSCI調整 | 摩根士丹利資本國際指數定期調整成分股權重，影響外資被動式資金流向 |
| 換倉價 | 期貨合約換月時的開盤價格，為多空判斷的重要參考價位 |
| 黃金交叉 | 短期均線由下往上穿越長期均線，為技術面的多頭訊號 |
| 比價效應 | 同產業中龍頭股大漲後，資金轉向同題材但漲幅落後的個股尋找補漲機會 |
| TOPS（算力） | 每秒兆次運算（Tera Operations Per Second），衡量AI晶片運算能力的單位 |
