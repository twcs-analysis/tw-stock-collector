## 📈 技術面分析與操作策略

### 大盤技術面

- **五日均線**：短線多空分界，今日守住
- **量能變化**：從 5,000 多億縮至 4,600 多億，量縮拉回屬正常
- **研判**：連三天創高後首日休息，五日線守住則多頭格局不變

### 個股操作原則

1. **強勢股守五日線或十日線**：不破則多頭不變
2. **同族群比價**：價格低 + 位階低 = 「雙低」最強
3. **量是價的先行指標**：突破前需要量能表態確認
4. **乖離率過大時**：以近期低點或月均線為出場參考
5. **漲價概念股區分**：需求帶動者可做長，成本帶動者只做短

### 日圓匯率操作（期戰老師）

- 台幣對日圓已來到 0.2037 甜甜價（兩個多月新低）
- **建議**：不急著換，可安步當車，日圓可能還會再貶
- **風險**：若高市早苗成為日本首相延續安倍經濟學，做空日圓的「渡邊太太」可能捲土重來
- **技術面**：日圓若跌破 150 關卡屬超過警戒，目前已至 152.64

## 📚 名詞解釋

| 術語 | 說明 |
|------|------|
| 蓋牌 | 通路商暫停報價，不願以低價出售庫存，預期後續價格上漲 |
| 雙低 | 同族群中「價格低 + 位階低」的選股策略，短線上最受青睞 |
| 被動型基金 | 追蹤指數的 ETF 或基金，因匯率波動需操作期貨避險 |
| 五日均線 | 短線多空分界線，強勢股回測五日線不破為續漲訊號 |
| 鋸齒狀買法 | 外資不連續買進而是買兩天賣一天的佈局方式，累積回首仍為淨買超 |
| 弧形底 | 技術面底部型態，呈現圓弧狀的底部結構，量能漸增確認 |
| 乖離率 | 股價偏離均線的程度，過大時有回測均線壓力 |
| 安倍經濟學 | 前日本首相安倍晉三推行的三箭政策：寬鬆貨幣、擴張財政、結構改革 |
| 渡邊太太 | 日本散戶投資人的代稱，以借入低利日圓投資海外高息資產聞名 |
| 集團作帳 | 集團旗下關係企業在季底或年底透過交易拉抬股價的行為 |
