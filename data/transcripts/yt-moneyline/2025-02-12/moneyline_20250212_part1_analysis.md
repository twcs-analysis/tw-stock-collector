### 景氣循環與大盤多空判斷（巨年分析）

#### 核心結論
- **台灣目前處於第16次景氣循環的擴張期**
- 過去15次景氣循環，平均擴張期為30個月
- 以目前進度估算，仍有約17個月的擴張期可走

#### 歷史案例對照

1. **2007年次貸風暴（第12次循環）**
   - 擴張期遇次貸危機 → 僅3個月震盪後反攻
   - 直到2008年3月景氣高峰後才進入收縮期
   - 2008年9月雷曼兄弟破產 → 才是真正危機

2. **2011年歐債危機（第13次循環）**
   - 擴張期間遇歐債危機 → 震盪長格局，未形成空頭
   - 台股從谷底一路上漲至景氣高峰

3. **2018年中美貿易戰（第15次循環）**
   - 台灣處於擴張期 → 僅1個月下殺、3個月築底後反攻突破前高
   - COVID-19疫情（2020年）→ 同樣3個月反應後繼續上漲

#### 關鍵觀察
- **大盤指數往往領先景氣谷底3-8個月先見低點**
- 擴張期遇利空 → 頂多3個月震盪
- 收縮期遇利空 → 才是真正危機
- **結論: 川普關稅戰在擴張期背景下，屬於短期震盪，不代表空頭危機**

#### 權值股F4觀察
- **台積電 (2330)**: 季線上方，強勢整理
- **聯發科 (2454)**: 季線上方，持續創高，外資集中加碼
- **鴻海 (2317)**: 季線下方，弱勢格局，外資持續提款
- **廣達 (2382)**: 季線下方，缺口尚未回補，弱勢

#### 判斷基準
- 台積電 + 聯發科處於季線上方 → 大盤不會垮
- 外資從鴻海、廣達提款 → 資金集中轉入聯發科

## 📋 投資策略總結

### 短線操作原則
1. **不追高**: 大盤無明確趨勢，高位階個股震盪劇烈
2. **當沖量大**: 價格波動極端，嚴設停利停損
3. **資金分流**: 電子降溫 → 傳產（塑化、航運）轉強

### 中期觀察
1. **景氣擴張期未結束**: 關稅衝擊屬短期震盪（3個月內）
2. **權值股分化**: 聯發科強、鴻海弱 → 選強汰弱
3. **歐洲AI題材**: 法國星際之門可望帶動邊緣運算相關台廠

- **2/13凌晨3:30**: 川普可能簽署對等關稅行政命令

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **對等關稅** | 川普政策：若他國對美國課稅高於美國對該國課稅，則美國將調高至相同水準 |
| **景氣循環** | 國發會定義的經濟週期，包含擴張期（谷底→高峰）與收縮期（高峰→谷底） |
| **券資比** | 融券餘額/融資餘額的比率，超過25%以上視為高券資比（軋空可能性升高） |
| **雙背離** | KD指標與成交量均未隨價格創新高，代表上漲動能衰竭 |
| **MSCI調升** | 明晟指數將台灣權重調高，理論上吸引被動資金流入 |
| **星際之門 (Stargate)** | 美國/法國大規模AI基礎建設投資計畫 |
| **邊緣運算 (Edge Computing)** | 在靠近資料源端進行運算處理，降低延遲與駭客攻擊風險 |
| **以靜制動** | 台積電面對關稅不確定性的策略：不先行表態，等對方出牌再回應 |
