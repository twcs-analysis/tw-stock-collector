## 技術面總結

### 大盤技術面
- **KD**: 正式黃金交叉（第二天確認），偏多訊號
- **月線**: 距月線約130點，尚未站上
- **5日均線**: 短線多空分界，正乖離過大時勿追高
- **操作策略**: 月線之下可買、月線之上不追高；等回測月線時加碼；鋸齒狀操作

### 反彈判斷
- **第一隻腳已站穩**: 不會破底
- **第二隻腳**: 有機會比第一隻腳高
- **量能**: 5,200億尚不足以支撐大幅反彈，但反彈初期不需過度在意量

## 策略總結

### 多頭操作策略
1. **月線之下偏多操作，月線之上不追高**
2. **鋸齒狀操作**: 反彈拉高時獲利了結，回測時再買
3. **日KD交叉向下或5日均線跌破兩天**: 轉為保守
4. **選股方向**: 中小型個股本波較活潑，不一定只能買台積電

### 風險控管
- 所有個股設定均線停損（5日/10日/月/季線依個股特性）
- 週線正乖離過大時不追高
- 年線下彎的個股不追高
- 注意PCB等「半電子」族群被資金排擠的風險

## 名詞解釋

| 名詞 | 說明 |
|------|------|
| **TPU（Tensor Processing Unit）** | Google自主研發的張量處理器，屬於ASIC架構，與GPU不同，專為AI推論與訓練優化 |
| **CPO（Co-Packaged Optics）** | 共同封裝光學，將光學元件與交換器晶片封裝在一起，提升傳輸速度 |
| **矽光子** | 利用矽基材料製造光學元件的技術，是實現高速光通訊的關鍵 |
| **ASIC** | 特殊應用積體電路，針對特定用途設計的晶片，如Google TPU |
| **KD黃金交叉** | 短期K值由下向上穿越D值，為技術面偏多訊號 |
| **正乖離** | 股價高於均線的幅度，過大時代表短線漲多有回測壓力 |
| **頭肩底** | 技術分析型態，由左肩、底部、右肩組成，完成後通常向上突破 |
| **鋸齒狀操作** | 在震盪行情中，漲高賣、跌低買的來回操作方式 |
| **ETF一拆七** | 將一股拆為七股，降低每股價格與投資門檻，總資產不變 |
| **景氣循環股** | 獲利與景氣高度連動的股票，通常買在高本益比（谷底）、賣在低本益比（高峰）|
