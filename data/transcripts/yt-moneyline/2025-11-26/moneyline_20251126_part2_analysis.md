## 市場總體觀察

### 投信法人年底作帳行情啟動

#### 投信買超的深層意義
- **11月底投信大買的三大原因**:
  1. **績效壓力**: 基金績效是經理人的成績單，績效不好位子可能換人
  2. **吸引新客戶**: 績效越漂亮，越容易留住舊客戶、吸引新客戶
  3. **檯面下代操部位結算**: 投信基金分為檯面上（公開報表）與檯面下（代操部位），代操部位須獲利了結才能分紅，因此影響到檯面上持股操作

#### 作帳行情的運作邏輯
- **時間窗口**: 11月中旬 ~ 12月底
- **操作特徵**: 拉抬帳面持股價位以提升績效
- **中長部位觀察**: 若重倉部位到現在都沒賣，就一定是拉到至少12月上旬
- **強勢股偏好**: 投信偏好買已經在漲的強勢股（強者恆強邏輯）

#### 作帳 vs 作夢行情比較

| 項目 | 作帳行情 | 作夢（主夢）行情 |
|------|---------|----------------|
| **買的理由** | 讓現有績效好看 | 市場買未來性、講故事 |
| **驅動者** | 投信法人 + 公司派 | 市場資金 + 法人籌碼 |
| **標的特徵** | 強勢股、法人重倉股 | 有想像空間但尚無獲利驗證的股票 |
| **時間窗口** | 11月中 ~ 12月底 | 11月中 ~ 明年3月（財報空窗期）|
| **選股邏輯** | 拉相對比大盤強的個股 | 包裝出未來有夢的股票 |
| **風險** | 重倉部位可能提前結算 | 六天漲幅超26%恐被公布財報 |

### 公司派年底拉抬股價的動機
- **明年股東會**: 股價影響公司評價，好股價才能拍拍手
- **信貸評估**: 銀行以六到八個月均價評估公司信貸條件
- **CB轉換公司債**: 轉換價以股價平均價格計算
- **股票質押**: 股價高低影響貸款條件

#### 強茂 (2481) - 轉單效益 + 漲價題材

**基本面分析**:
- **安世半導體轉單效應**: 安世半導體（Nexperia）被禁後，一年的訂單已轉給強茂
- **獨家優勢**: 台灣唯一具備自有封裝與測試能力的整流二極體廠商
- **漲價效益**: 封裝與測試產業目前處於漲價趨勢
- **TPU概念**: 功率元件應用於TPU運算及800V DC等領域
- **獲利成長**: Q4淡季不淡，依舊成長2%；獲利率從3.1%提升至4.8%（成長逾四成）

**籌碼面**:
- 投信持續買超，最新一日買至近期最高水位
- 外資未買，但投信積極加碼
- 買盤空間仍大（過去投信持股不多）

**技術面**: 大盤有破季線，強茂沒破；大盤未站上所有均線，強茂也未站上 -- 但結構相對抗跌

**操作建議**: 季線位置可佈局，具備轉單效應 + 漲價效益 + ASIC/TPU概念三重題材

### 三、作夢行情概念

#### 作夢行情的運作原理
- **時間窗口**: 11月中旬 ~ 明年3月底
- **核心邏輯**: Q3財報公布後（11/15~11/20），到明年3月底公布Q4財報前，為財報空窗期
- **有夢最美**: 沒有財報可以打臉，市場可以盡情想像
- **標的特徵**: 現在看不到EPS，但未來可能有大成長性

#### 主要作夢族群
1. **AI伺服器**: 多層次印刷電路板、封裝、先進封裝
2. **ASIC/TPU**: Google TPU概念（如聯發科到明年Q4才量產）
3. **先進製程**: 台積電資本支出增加500億
4. **軍工國防**: 想像美國400億美元軍售案的空間

#### 軋空行情預告
- 明年1月起將銜接軋空行情
- 沒有基本面的個股被放空後，空方回補形成軋空
- 超過1.23倍券資比以上的個股為重點觀察對象
- 軋空行情預計延續至3月份

### 四、高接封策（高階封測）產業深度分析

#### 產業底氣
- 台股股價前十名中，高階封測佔三檔: 以為（因為）、忘記（旺矽）、精策（精測）
- 三檔財報皆美: 業績高成長、毛利率最低42%最高56%、單季EPS整齊度高
- 股價相對大盤強勢，具創高動能

#### ASIC時代推動封測需求

| 概念 | 說明 |
|------|------|
| **訓練（Training）** | 用GPU，如同教小孩走路 |
| **推論（Inference）** | 用ASIC/TPU，如同讓AI講話講得好 |
| **先進封裝** | CoWoS、SiP、3D封裝，測試難度高 |
| **奈米製程** | 越做越小，測試精密度要求越高 |

#### 封測全方位解決方案（一條龍供應最有價值）

| 測試階段 | 名稱 | 說明 | 相關公司 |
|---------|------|------|---------|
| 前段（晶圓測試） | CP Test（探針卡） | 上網下測，測晶圓片上的晶片 | 精測、旺矽、薄瑞 |
| 中段（封裝後測試） | FT/FTA（功能測試） | 下網上測，封裝完後測試 | 以為（因微）-- 最高價、技術層次最高 |
| 後段（系統級測試） | SLT（System Level Test） | 耐熱、高壓電等動態測試 | 薄瑞、芝貿 |

#### 重點個股分析

##### 薄瑞/博瑞 (3581) - 親民價位的封測設備股

**基本面**:
- 半導體封測設備與液晶專業製造商
- 產品涵蓋: 自行研發設備 + 代理

**技術面（週線）**:
- **一年多的頭肩底型態**: 左肩 --> 頭部 --> 右肩（目前位置）

**技術面（日線）**:
- 全面多頭排列
- 曾破月線後站回，站回月線即為強勢格局
- 季線從未跌破

**操作建議**: 價位親民，週線大底右肩帶量，等盤整後出量即有機會突破；月線為停損參考

### 五、聯準會降息沙盤推演

#### 最新降息機率
- **12月降息機率**: 82.9%~85%（當日盤中一度到85%）
- **推升因素**: 美國9月零售銷售 + 生產者物價指數（PPI）雙雙低於預期

#### 關鍵數據時程
- **12月5日**: 公布9月PCE（個人消費支出物價指數），為12月利率決議前最後一次通膨數據
- **GDP**: 預期Q3年率4%以上（數據好反而可能降低降息理由）

#### 聯準會內部分歧
- **12人投票權**: 4人贊成降息、5人目前不贊成、3人不表態
- **關鍵人物**: 威廉斯（紐約聯儲主席，有投票權，支持降息）、馬力・達利（鮑爾的朋友，支持降息但無投票權）

#### 兩種降息情境

| 情境 | 鴿派暫停 | 鷹派降息 |
|------|---------|---------|
| **12月動作** | 不降息 | 降息 |
| **後續訊號** | 暗示明年還會降息 | 暗示明年暫停或減緩降息 |
| **態度** | 偏鴿（留有後續武器） | 偏鷹（先發給你，但後續沒了）|
| **對股市影響** | 短空長多（不降但有預期） | 短多長空（降了但沒有後續資金題材）|
| **對美元影響** | 美元可能短升 | 美元可能再往上走 |

#### 美股技術面
- S&P 500上週曾跌破10月低點，但拉出長下影線（可能假跌破）
- 連漲數日後回到月線上方，但月線下彎，需要時間確認
- **摩根士丹利目標**: 一年後S&P 500看到7,800點（+18%~20%）

#### 類股輪動新趨勢
- 美股可能從科技股主導轉向更平衡的市場
- 非必需消費品、金融、工業類股開始走強
- Magnificent 7（科技七雄）近期表現相對弱勢

#### 美元走勢
- 9月降息後美元指數觸底（90.21），反彈至100.395（近5個月新高）
- 短線支撐在月均線附近
- 即使12月降息，美元不一定會走弱（因市場早已預期）

#### 黃金走勢
- 底部慢慢墊高（從4,000逐步上移）
- 近期未再創新高，處於修正期
- **最佳情境**: 鷹派降息 --> 股市修正 --> 避險需求推動黃金上漲
- **操作建議**: 目前不需急賣黃金，拉回仍可分批佈局

## 策略總結

### 年底雙行情操作要點

1. **作帳行情（11月中~12月底）**: 跟著投信買超方向操作，鎖定重倉股與強勢股
2. **作夢行情（11月中~明年3月）**: 鎖定財報空窗期、有想像空間的中小型個股
3. **軋空行情（明年1~3月）**: 預告式提醒，觀察券資比偏高的個股
4. **高階封測產業**: 長期趨勢明確（AI推論需求 + 先進封裝），短線可找月線拉回買點
5. **降息題材**: 不論12月降或不降，2026年降息趨勢不變，留意資金輪動方向

### 風險控管
- 投信重倉股可能提前結算（檯面下代操需求）
- 6天漲幅超26%的個股可能被要求公布財報
- 週轉率過高的個股可能被分盤交易
- 作夢股務必設定嚴格停損

## 名詞解釋

| 名詞 | 說明 |
|------|------|
| **作帳行情** | 年底法人為美化績效報表而拉抬持股價位的市場現象，通常出現在11月中至12月底 |
| **作夢/主夢行情** | 市場在財報空窗期（Q3財報公布後至Q4財報公布前）對個股未來成長性的想像與炒作 |
| **軋空行情** | 融券賣出者被迫回補，推升股價的行情，通常出現在1~3月 |
| **檯面下代操** | 投信基金除公開報表的操作外，私下為特定客戶進行的資產代操管理 |
| **CP Test** | 晶圓探針測試（Circuit Probing），在晶圓切割前以探針卡測試每顆晶片的功能 |
| **FTA/FT** | 功能測試/最終測試（Final Test），封裝完成後進行的功能性驗證 |
| **SLT** | 系統級測試（System Level Test），模擬實際使用環境的動態測試 |
| **探針卡** | 半導體測試中用於接觸晶圓表面進行電性測試的精密元件 |
| **鴿派暫停** | 央行維持利率不變，但暗示後續會降息的態度 |
| **鷹派降息** | 央行降息，但暗示後續可能暫停或減緩降息步伐 |
| **PCE（個人消費支出物價指數）** | 聯準會最重視的通膨指標，比CPI更能反映消費者實際支出變化 |
| **券資比** | 融券餘額除以融資餘額，比率越高代表放空力道越大，軋空潛力越高 |
