## 🌍 市場總體觀察

### 半導體關稅（232 條款）最新動態

#### 國發會四大關注重點

行政院國發會針對本週即將公布的 232 條款半導體關稅，提出四大關注焦點：

1. **實施範圍**: 232 條款半導體關稅涵蓋哪些品項？筆電、伺服器、主機等是否列入課稅範圍？
2. **課稅方式**: 具體稅率與課稅機制為何？
3. **豁免條件**: 目前尚無白紙黑字確認台積電獲得豁免，其他廠商條件不明
4. **執行細節**: 若擴大至中端商品（筆電、伺服器、主機），目前政府 930 億元紓困方案恐不足，需再擴編

#### 盡老師對 232 條款的解讀

- **國家安全框架**: 232 條款以國家安全為由課徵關稅，若出口品項不涉及國家安全，稅率不會太高
- **美國進口成本考量**: 大幅課稅會增加美國自身進口成本，形成制衡力量
- **關稅的「和平外交」用途**: 川普善用關稅作為外交籌碼，不僅用於貿易平衡，更用於促成多項國際和平協議

### 晶片關稅：保護台積電的高牆

盡老師提出逆向思維 — **100% 晶片關稅實質上是保護台積電的高牆**：

**三大晶圓代工在美投資現況比較**：

| 公司 | 投資規模 | 製程目標 | 現況 |
|------|----------|----------|------|
| **Intel** | 號稱 1,000 億美元 | A28/A18 製程 | CEO 涉嫌違規出售違禁品予中國（被罰 1.4 億美元），俄亥俄廠延至 2030-2033 年量產 |
| **三星** | 400 億美元（含韓國補助） | 4nm/2nm | 德州廠延至明年或以後量產，與特斯拉傳合作 |
| **台積電** | 1,650 億美元 | 4nm/3nm/2nm/1.6nm | 亞利桑那六座晶圓廠＋兩座封測廠＋安迪廠，持續擴廠中 |

**關鍵推論**：
- 在 100% 晶片關稅的「高牆」內，只有台積電在不斷擴廠
- Intel 和三星都在延後量產，短期無法構成競爭
- 台積電已在美國投資，可獲得豁免；未在美國投資的（如聯電、中芯）將被課稅
- **結論**: 晶片關稅 = 保護已在美國投資的半導體廠 = 利多台積電

**台積電白宮待遇**：
- 魏哲家總裁是極少數進過白宮的企業家
- 盡老師以古語形容：「官拜一品、賜穿黃馬掛」— 最高規格禮遇
- 越早投資表態誠意越好，如同英國最早讓步獲得最佳條件

#### 戰略意義

盡老師指出，從鋼鐵鋁、汽車零組件、晶片、藥品、造船到稀土，這些全部指向**備戰準備** — 確保戰時所有戰略物資掌握在美國本土。全球化已經結束，去全球化是目前進行式。

**關鍵優勢**：
- 資產規模約 200 億元，比被動式 ETF 小，因此能靈活布局小型股
- **全透明揭露**: 每日收盤後在官網公布實際投資組合，可追蹤經理人買賣
- 不追蹤指數，經理人有完全操作彈性

#### 追蹤主動式 ETF 的方法

1. 每日收盤後（約 16:30）上各基金官網查看持股
2. 比對兩天數據，即可推算當日買賣標的
3. 經理人通常開單點會連買 3-5 天，強力看好可達 6 天以上
4. 追蹤績效最好的經理人（如 00981 陳川雅）

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **232 條款** | 美國《1962年貿易擴展法》第232條，允許總統以國家安全為由對進口品課徵關稅 |
| **主動式 ETF** | 由基金經理人主動選股的 ETF，不追蹤特定指數，每日揭露完整持股 |
| **被動式 ETF** | 追蹤特定指數的 ETF（如 0050、0056），持股固定按指數成分調整 |
| **ITAR 認證** | 美國國際武器交易條例認證，取得後方可供貨美國國防部 |
| **OCP 展** | Open Compute Project 開放式架構展，由 Meta 發起的資料中心開放標準展覽 |
| **板式交換器** | 用於液冷散熱系統中交換熱能的設備，CDU 的核心零件 |
| **開源（Open Source）** | 開放原始碼策略，AI 模型免費開放使用，對比封閉收費模式 |
| **矽光（Silicon Photonics）** | 利用矽基材料製作光電元件的技術，用於高速光通訊 |
| **FSD（Full Self-Driving）** | 完全自動駕駛系統 |
| **ASIC 服務** | 客製化特殊應用積體電路設計服務 |
