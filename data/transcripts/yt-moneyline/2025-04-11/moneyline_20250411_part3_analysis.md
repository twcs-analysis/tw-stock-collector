## 🌍 市場總體觀察

### 全球經濟衰退風險

#### 摩根大通最新報告
- **經濟衰退機率**: 高達60%
- **中美互不相讓**: 美國145% vs 中國125%，貿易壁壘可能拖累全球經濟
- **關稅戰 + 金融戰 = 雪上加霜**

#### 1930年斯姆特-霍利關稅法案的歷史教訓

| 比較項目 | 1930年胡佛 | 2025年川普 |
|---------|-----------|-----------|
| 法案/政策 | 斯姆特-霍利關稅法案 | 對等關稅政策 |
| 時間 | 1930年6月17日 | 2025年4月 |
| 目的 | 保護國內企業、復甦經濟 | 同上 |
| 稅率變化 | 13% → 19.8% | 2.3% → 20-30%（平均） |
| 結果 | 進出口降幅超過50% | 待觀察 |
| 失業率 | 7.8% → 25.1% | 目前約3.8% |
| 後果 | 引發美國經濟大蕭條 | 停滯性通膨風險 |

- **關鍵警告**: 目前美國平均關稅稅率（20-30%）已達到1930年大蕭條時期的水準
- **若不全面停止**: 3個月到半年後，停滯性通膨（Stagflation）很可能發生

#### 中美貿易影響
- **中美貿易額**: 約5,800億美元
- **太平洋上貨船**: 許多已停止運輸
- **若貿易額砍半**: 影響極為巨大
- **聖誕節危機**: 美國今年聖誕節可能買不到中國製的裝飾品（全球只有中國在做）

#### 通膨與消費數據
- **通膨預期**: 從4.3%上升至4.9%
- **消費信心**: 三月已降至5.7%的低水準
- **iPhone影響**: 加徵145%關稅後，iPhone要賣到4,500美元以上，無人購買
- **結論**: 消費持續萎縮，經濟衰退風險上升

#### 聯準會困境
- **降息預期劇烈波動**:
  - 上週五：預估今年降3碼
  - 週一：變成5碼
  - 週二：4碼
  - 昨天早上4碼，下午3碼
- **核心問題**: 通膨上升 → 可能不降反升息
- **聯準會官員表態**: 更重視通膨而非經濟，CPI下降不代表會降息
- **最壞情境**: 停滯性通膨 → 利率往上 → 經濟往下 → 無法降息甚至升息

## 💼 產業分析與投資建議

### 商品避險策略

#### 一、美債部位（減碼/避險）

- **問題**: 殖利率持續往上 → 美債價格持續往下
- **案例**: 00687B（美債ETF），五天內從32元跌至28元
- **風險**: 原本期待降息 → 價格上漲的邏輯已被打破
- **停滯性通膨情境**: 利率往上、經濟往下 → 聯準會無法降息還要升息

**操作建議**:
- 慢慢觀察通膨數據，若持續走高 + 降息預期消失 → 開始調節
- **避險工具**: 00689B（美債反一），可用等量部位對沖美債曝險
- 美債反一可短期持有（目前波動大，非不動盤面，適合避險操作）

#### 二、日元（看多操作）

- **邏輯**: 經濟衰退 + carry trade平倉 → 日元升值
- **觸發條件**: 科技股高檔反轉、經濟衰退股價下跌 → 資金回流日元
- **操作工具**: 00706（元大日元ETF），跟隨日元升值方向走
- **操作方式**: 做一段行情（波動大時），真正出現趨勢反轉時出場

#### 三、黃金（全球唯一避險商品）

- **最新價位**: 3,220美元以上，持續創歷史新高
- **邏輯**: 全球不穩定 → 資金擠兌 → 換成黃金
- **操作工具**: 可選1倍或2倍槓桿的黃金ETF
- **操作建議**: 即便看多黃金，也不要追高
  - 長多行情中必有整理（長多整、長多整的循環）
  - 等整理回檔時再買進
  - 追高風險大

#### 四、原油（反向操作）

- **現況**: 油價與銅價因經濟衰退預期大幅下跌
- **邏輯**: 預期經濟衰退 → 能源需求下降 → 油價下跌
- **操作工具**: 00673R（原油反一ETF）
- **操作建議**: 等油價反彈上漲時，再做反向（做空）
  - 因為長期趨勢是往下
  - 不要在油價已經跌很多時才追反向

### 套牢股操作心法

#### 「存股不出」的迷思

- **近10年才流行**: 因為有台積電、有ETF（0050），大多頭格局深信不出
- **陷阱**: 回頭看30年，當時被存的股票很多已消失
- **巴菲特也不是永遠不賣**:
  - 他的現金水位是有進有出的
  - 2000年網路泡沫前拉高現金
  - 2020-2023年逐漸拉高現金部位
  - 「如果我不打算持有三十年，一天都不想持有」是演說方式，不是每檔都抱三十年

#### 數學上的不對稱性

- **跌50%需要漲100%才能回本**:
  - 200元跌到100元 = 跌50%
  - 100元要漲回200元 = 需漲100%
- **反面思考**: 如果在90%跌幅時賣出:
  - 100元跌到10元 = 跌90%
  - 10元漲到20元 = 漲100%（但只回到20元）
  - 若有賣出，只需要小幅反彈就能全部回來

#### 波段操作的優勢
- **每次賺20%，四次就一倍**: 100 × 1.2^4 = 207
- **一年四季度**: 只要找到兩個季度的20%，兩年就有兩倍
- **結論**: 不要執著於一檔股票不賣，用波段操作可以更快回本

#### 面對系統性風險的方法
1. **持股比例**: 有100萬資金只買10萬
2. **利用引伸性商品**: 期貨、ETF直接反應行情（不怕流動性問題）
3. **分散投資**: 半導體有風險就配航運，航運有風險就配石油
4. **負相關商品**: 利用反向ETF對沖

## 📈 技術面分析與操作策略

### 下週觀盤重點（鄭華老師）

#### 五大觀察指標

1. **融資變化**:
   - 最好：維持在增減50億以下
   - 邏輯：一邊有加（好股票如鴻海）一邊要減（沒流動性的股票）
   - 大增大減都不好
   - 實際上已在發生「從沒流動性的股票轉到好股票」的換手

2. **美股開低能否拉上來**:
   - 若美股下跌後台股開低→拉上來 = 慣性延續（週五模式）
   - 若開低→收更低 = 打底尚未結束，趕快出掉

3. **長假前高點 21,139點**:
   - 越靠近越好，但短線突破很難
   - 這是反彈的天花板觀察點

4. **國安基金概念股能否擴散**:
   - 目前集中在鴻海、台積電
   - 需擴散至中小型股（量能放大）
   - 健康的盤面 = 國安基金概念股擴散

5. **觀察標的**:
   - 聯發科是否過高（代表AI信心）
   - 長榮等航運能否成為新族群
   - 貨櫃三雄會之後走漲（看營收/運價趨勢）

## 📚 名詞解釋

- **斯姆特-霍利關稅法案（Smoot-Hawley Tariff Act）**: 1930年美國通過的高關稅法案，被普遍認為是加劇經濟大蕭條的重要原因
- **停滯性通膨（Stagflation）**: 經濟成長停滯（或衰退）同時通膨上升的經濟狀態，傳統貨幣政策難以同時應對
- **00687B**: 國泰20年期以上美國公債ETF，追蹤長天期美國國債表現
- **00689B（美債反一）**: 反向追蹤美國長天期公債的ETF，美債下跌時上漲
- **00706（元大日元ETF）**: 追蹤日元兌台幣匯率的ETF，日元升值時上漲
- **00673R（原油反一）**: 反向追蹤原油價格的ETF，油價下跌時上漲
- **巴菲特現金水位**: 波克夏海瑟威持有的現金與短期投資部位，巴菲特會根據市場估值調整現金比重
- **存股不出**: 買進股票後長期持有不賣出的投資策略，依賴股息收入與長期增值
- **引伸性商品**: 衍生性金融商品（如期貨、選擇權、ETF），能直接反應標的資產價格變動
- **SCFI（上海集運指數）**: Shanghai Containerized Freight Index，反映上海出口貨櫃運價的指標
- **QE（量化寬鬆）**: 央行透過購買國債等方式向市場注入大量流動性的非常規貨幣政策
