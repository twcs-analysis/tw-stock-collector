## 💼 產業分析與投資建議

### 一、輝達H20禁令影響評估（屬方分析）

#### 影響程度解讀
- **中國營收占比**: 輝達中國業務營收已從2020年的20%以上，降至2025年僅12%-13%
- **55億美元認列**: 包含H20晶片打消、違約費用及銷售費用，屬一次性損失
- **會計保守原則**: 輝達依據會計保守原則在第二季財報提前認列損失
- **可回沖機會**: 若未來政策鬆綁，此損失可回沖
- **舊聞不是新聞**: 中國先前已自行規定企業不准購買H20（因不符效能規定），加上深思（DeepSeek）崛起

#### 對台灣供應鏈影響
- **台積電影響有限**: H20是H100效能的五分之一，對台積電營收影響遠低於帳面數字
- **台灣訂單不受影響**: 該拿的訂單已拿到，違約費用由輝達自行承擔
- **GB200/GV200訂單飽滿**: 高階產品供不應求，低階H20影響可控

#### 輝達後續觀察
- 輝達可能推出降規版本（如H10）重新申請出口許可
- 五千億美元的美國投資計畫與H20禁令是兩碼事
- 今晚觀察輝達與超微在美股的實際反應

### 二、艾斯摩爾（ASML）財報解讀

#### 訂單下滑原因
- **關稅不確定性**: 歐洲（20%關稅）、日本（24%關稅）客戶暫停設備訂單
- **中國無法出貨**: 美國禁止艾斯摩爾賣EUV設備給中國
- **訂單停滯**: 客戶因關稅談判未定而暫緩設備採購
- **不代表台積電**: 台積電已確定投資擴產計畫，不受此影響

#### 對半導體景氣判斷
- 代表先進製程設備需求暫時受壓
- 關稅造成歐洲、日本投資設備暫停
- 非景氣亮紅燈，而是政策干擾造成的訂單遞延

## 📈 技術面分析與操作策略

### 大盤技術分析

#### 兩萬點關卡壓力
- 距離兩萬點僅一步之遙卻被拉回，顯示該關卡壓力重大
- 昨天100多檔漲停但成交量僅2,000多億，量價不合理
- 中小型股帶領反彈無法突破，需要大型股代領才能真正突破

#### 黃金右腳期待
- 第一隻腳已完成（上週三低點）
- 市場期待黃金右腳出現
- 美股反彈也在打類似的雙底型態
- 美股相對強勢，月線未跌破

### 三大操作策略教學（瞬間分析）

#### 策略一：相對強勢操作法
- **定義**: 大盤還在修正整理，個股領先打雙底或突破
- **條件**: 大盤在年線以下，個股月線以上，呈多頭排列
- **特徵**: 大盤下跌時個股量能增加（低檔承接訊號）
- **示範**: 哲固（跌幅僅10%，遠低於大盤19.5%）
  - 4月7-9日量能連三天遞增（3,800→3,900→8,000+張）
  - 安全監控概念，3月營收EPS 0.93元，月增25.5%
  - 中線大底突破格局
  - **操作**: 不追高，拉回跳空缺口時留意買點
- **示範**: 永信（藥廠）
  - 大盤跌19.5%，永信僅跌7.5%
  - 第一天即爆7,500張大量
  - 台灣少數在美國設廠的藥廠（北卡羅萊納州）
  - 3月營收8.13億元，年增51%，創4年新高
  - 大底突破格局
  - **操作**: 不追高，拉回時留意

#### 策略二：大乖離操作法
- **定義**: 股價與季線乖離達30%以上
- **搭配指標**: KD指標低檔背離（價量背離+KD背離=雙背離）
- **示範**: 新能高
  - 4月9日乖離季線約30%
  - KD指標出現背離（股價創新低但KD未創新低）
  - **操作**: 跌深反彈性質，反彈至月線/缺口附近先拔檔
  - 等待第二隻腳（需高於第一隻腳）再進場
  - 季線反彈約25%時考慮減碼

#### 策略三：好股落難操作法
- **定義**: 原本線型漂亮多頭排列，因系統性風險被無差別殺跌
- **特徵**: 從多頭排列跌至季線甚至半年線位置
- **示範**: 可成
  - 4月2日收盤時仍為多頭排列
  - 系統性風險三天殺跌至季線176附近
  - 3月營收月增數、年增皆不錯
  - **操作**: 不追高，低檔附近震盪後上攻機會存在

## 📋 投資策略總結

### 短期策略（1-2週）
1. **兩萬點關卡需大型股代領**: 中小型股無法帶動突破，需台積電等權值股領軍
2. **明天台積電法說會為關鍵**: 法說會結果將決定短線方向
3. **注意分盤交易風險**: 華紅資、安庫等強勢小型股可能被列為分盤交易
4. **強勢股下半週注意衝高拉回**: 週末前部分強勢股可能出現獲利了結

### 中期策略（1-3個月）
1. **等待黃金右腳**: 第一隻腳已完成，第二隻腳需高於第一隻腳才算成功
2. **三大操作法**: 相對強勢股、大乖離反彈、好股落難為三種進場策略
3. **大型股為多頭關鍵**: 出升段與主升段一定靠大型股帶動

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| H20晶片 | 輝達針對中國市場設計的降規版AI晶片，效能約為H100的五分之一，此次被美國政府要求出口中國需許可 |
| 黃金右腳 | 雙底（W底）型態中的第二個低點，若高於第一個低點則型態成立，代表底部確認 |
| 乖離率 | 股價偏離某條均線的幅度百分比，乖離過大時有回歸均線的傾向 |
| KD背離 | 股價創新低但KD指標未同步創新低，暗示下跌動能減弱，可能反轉 |
| 分盤交易 | 證交所對波動過大或異常交易的股票實施的管制措施，改為每五分鐘集合競價一次 |
| 大量距離 | 近期成交量最大那根K棒的低點，可作為短線支撐參考 |
| 系統性風險 | 影響整體市場的風險（如關稅戰、疫情），非個別公司因素 |
| 會計保守原則 | 當資產有減損風險時，會計上需提前認列損失，反映最保守的估值 |
