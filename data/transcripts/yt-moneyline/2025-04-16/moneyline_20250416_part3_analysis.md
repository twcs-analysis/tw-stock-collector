## 🌍 市場總體觀察

### 美債市場震盪

#### 美債拋售潮原因分析（瞬間分析）

市場猜測美債大跌的四大原因：

1. **中美債券對抗**: 中國可能聯手盟友拋售美國公債（亞洲盤、歐洲盤持續出現賣壓）
2. **基差交易平倉**: 對沖基金利用公債現貨與期貨的價差進行槓桿套利（200-1000倍），市場波動加劇時被迫平倉
3. **關稅通膨帶來賣壓**: 長天期債券（10年、20年、30年）因通膨預期而遭拋售
4. **日幣升值帶動去槓桿**: 過去借低利日幣買美債套利的資金，因日幣升值而被迫反向操作

#### 美國財政部長回應
- 定調為「去槓桿造成的短期現象」
- 強調財政部有工具可避免失控 -- 回購機制
- 聯準會官員也表示必要時可用政策穩定市場

#### 美國十年期公債殖利率走勢
- 4月4日降至3.86%（接近去年降息時低點），市場避險
- 之後急彈至接近4.6%（拋售潮）
- 目前回到4.3-4.4%附近
- **判斷**: 若不再重破4.6%，可視為暫時利空鈍化、趨向回穩
- 長天期（20年、30年）波動更大

#### 美債操作建議
- **領息型投資人**: 不需要賣，固定收息繼續持有
- **賺價差型投資人**: 若擔憂可趁反彈減碼一些，但不必全賣
- **考慮進場者**: 若認為美國不會倒債，現階段可分批買入
- **風險**: 兩週內的波動不應過度反應，長期債券投資本就需要耐心

### 美元與台幣走勢

#### 美元指數
- 美元指數持續走弱，跌破降息時低點150.157
- 目前約99附近，偏弱格局
- 非美貨幣表現強勢

#### 美元兌台幣
- 延著季線往上穿破往下的規律
- 最近台幣持續升值，但近兩天暫停
- **操作建議**:
  - 若定存美元（0.7%）已持有，繼續持有觀察
  - 若破三個趨勢，考慮換回台幣
  - 若看好美元前景，可在此位置分批買入（分10份，先買第一份）

#### 比特幣觀察
- 趨勢上高點越來越低、低點持續破底，8萬不一定守得住
- 但在7.6萬附近有兩個觸底反彈的跡象
- **判斷**: 7.6萬比8萬更為關鍵支撐

### 聯準會與利率政策

#### 包爾（鮑威爾）主席動態
- 明天（4/17）將發表談話
- 美國財政部長透露正在面試新任聯準會主席人選（包爾任期至明年5月）
- 多位聯準會官員紛紛表態：若關稅衝擊大則可能提前降息

#### 降息前景分析
- **降息前提**: 美國經濟確實不好（非單純通膨）
- **GDP預測**: 亞特蘭大聯儲GDPNow模型顯示第一季可能負成長（衰退-3.7%後彈升但仍為負）
- **零售銷售**: 今晚公布，若數據好則衰退幅度可望收斂
- **搶購效應**: 關稅前的囤貨消費可能短暫推升零售數據，但4月可能回落

#### 聯準會官員立場分化
- 部分官員開始表態願意降息（可能在爭取下任主席提名）
- 若關稅衝擊不大 → 通膨壓力 → 降息時間延後
- 若關稅衝擊很大 → 經濟衰退 → 降息提前且幅度加大

## 💼 產業分析與投資建議

### 一、台積電法說會受惠股（瞬間分析）

#### 漢唐 (2404) - 無塵室工程大廠
- **地位**: 台積電無塵室工程合作夥伴
- **美國布局**: 已在美國與台積電正式合作
- **美光擴廠**: 今年另一大客戶
- **在手訂單**: 700億元，創歷史新高（每年營收約50億，可吃好幾年）
- **亞利桑那擴廠**: 統包廠建廠工程交給漢唐
- **去年EPS**: 32.94元，年增32%
- **技術面**:
  - 日線打底突破，站上季線
  - 今天稍微震盪但屬封閉缺口
  - 投信持續買進，外資今天第一天轉買
- **操作建議**: 若能站穩季線或景線，對半導體設備族群加分

#### 崇越 (5765) - 隱藏版設備廠

- **達拉斯辦事處**: 去年設立美國辦事處
- **業務範圍**:
  - 建廠工程（類似漢唐）

- **營收**:
  - 1月營收創歷史新高

### 四、美債危機分析

#### 百年零息美債傳聞
- 央行總裁表示：若美國真推百年零息美債，等同於倒債
- 分析：需債權人同意，且百年到期仍會還本金
- 與直接賴帳不同，但仍有重大風險

#### 美債ETF操作
- 投資等級債與非投資等級債因美國公債下跌而同步受壓
- 原因：美國公債是所有債券的基準，公債價格下跌（殖利率上升）會拖累所有債券

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| 基差交易 | 利用期貨與現貨之間的價差進行套利的交易策略，通常搭配高倍槓桿，市場劇烈波動時可能被迫平倉 |
| 去槓桿 | 投資人減少借貸部位、降低槓桿比率的過程，通常伴隨資產拋售 |
| 百年零息債 | 傳聞中美國考慮發行的100年期零利息公債，被央行總裁評為等同倒債 |
| AM市場 | 售後維修市場（Aftermarket），指原廠以外的汽車零件維修替換市場 |
| GDPNow | 亞特蘭大聯儲開發的即時GDP預測模型，根據最新經濟數據即時更新預測值 |
| 飛天車（eVTOL） | 電動垂直起降飛行器，形態類似大型無人機，可搭載乘客的空中交通工具 |
| 費半（費城半導體指數） | 追蹤全球主要半導體公司的股價指數，為半導體產業景氣的領先指標 |
| 盤跌格局 | 股價反覆打底後破底、反彈後又碰壓的下降通道走勢，代表弱勢未改 |
| 處置股 | 因異常交易被證交所列入注意的股票，可能限制交易方式（如變更為分盤交易） |
| 碳纖維輕量化 | 使用碳纖維複合材料取代金屬，大幅降低重量，廣泛應用於航太、飛天車等高端製造 |
