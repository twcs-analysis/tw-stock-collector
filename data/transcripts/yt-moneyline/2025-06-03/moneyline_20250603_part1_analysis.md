## 💼 產業分析與投資建議

### 一、台積電（2330）股東會解析

**八字總結：新的不多，底氣十足**

**股東會三大關鍵議題**:

1. **AI需求超強**
   - 魏哲家保證「AI長長久久」
   - 5~10年需求「非常好」
   - 不只資料中心，邊緣端（PC、手機、汽車、物聯網）需求持續擴散
   - 人形機器人訂單「非常強勁」

2. **先進製程進度**
   - 2奈米製程今年下半年量產，完全沒有延遲
   - 更先進製程明年下半年量產
   - 先進製程營收佔比將持續提升，目標70%~80%

3. **關稅與匯率影響**
   - 關稅：買方（進口方）問題，對台積電影響為間接而非直接
   - 即使關稅15%~20%，客戶下單完全沒有影響
   - 今年營收成長20%目標不變，營業利潤有機會再創歷史新高
   - 配息政策：每季不低於前季，每年不低於前年

4. **技術外流疑慮**
   - 不會去中東設廠
   - 海外設廠技術外流風險極低（每代製程驗證需半年至一年，加上工程師訓練又需一年）
   - 美國廠（美積電）技術根留台灣

5. **綠電投資**
   - 持續投資綠電，提升國際客戶認同度

**台積電操作建議**:
| 項目 | 內容 |
|------|------|
| 操作策略 | 分批買進，中長線操作 |
| 買進時機 | 拉回至均線匯集區域、缺口支撐平台附近 |
| 短線操作 | 過前高、量能放大時可短線出一部分，保留基本持股 |
| 停損位置 | 跌破缺口支撐平台 |
| 注意事項 | 不要用極短線眼光操作台積電，短線價差不容易做 |

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **Put/Call Ratio** | 賣權與買權比率，數值越高代表看多情緒越濃 |
| **Beta值** | 衡量個股相對大盤波動程度的指標，小於1代表波動低於大盤 |
| **四象限分析** | 用期貨多空與現貨多空組成的四個象限判斷法人態度 |
| **均線匯集** | 多條移動平均線在同一區域交會，通常為重要支撐或壓力 |
| **缺口平台** | 股價跳空後形成的價格空白區域，常為支撐或壓力 |
| **獨門獨市** | 指公司在特定領域擁有獨特技術或市場地位，競爭者少 |
| **鬆齊底** | 技術分析中的底部型態，底部逐漸墊高 |
| **經緣表面改質** | 半導體製程中對晶圓表面進行處理的技術 |
| **鑽石碟** | 化學機械研磨（CMP）製程中使用的鑽石修整器 |
| **AOI** | 自動光學檢測（Automated Optical Inspection），用於品質檢驗 |
