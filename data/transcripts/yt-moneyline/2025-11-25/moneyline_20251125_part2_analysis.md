## 市場總體觀察

### 聯準會降息動態

#### 12月降息機率劇變
- **本週上半週**: 降息機率僅約30-40%
- **最新數據（11/25）**: 降息機率飆升至80.9%
- **關鍵人物**: 舊金山聯準會主席戴利（Daly）——鮑爾的「跟班」首度搶先表態支持降息
- **政治因素**: 川普偏好降息，鮑爾任期至2026年5月，下一任由川普決定
- **市場解讀**: 若降息一碼，約有7,000億美元流入股市；若2026年再降三碼，約2.1兆美元資金動能

#### 降息對市場的影響
- 降息 → 資金寬鬆 → 股市利多
- 不降息 → 表示經濟好 → 不降也不壞
- **關鍵變數**: 12月10日聯準會會議前仍有兩週變化期

### 外資態度轉變

#### 期貨部位
- 外資期貨空單**連三降**，降到三萬口以下
- 相較過去動輒四五萬口空單，本次空單規模不大
- **解讀**: 外資認為大盤只是假摔，不會真正大跌

#### 選擇權部位
- 昨天（上週四）外資一度在選擇權翻空（六月以來首次）
- 但**最近迅速翻回做多**
- 今天外資選擇權做多約24億，期貨做多9億，現貨63億
- **三項合計**: 約143億偏多部位

#### 外資態度判斷標準
- **觀察指標**: 期貨+選擇權+現貨，連續三天都紅 → 外資真的回來了

### 三、假摔股辨識法

#### 假摔定義
- 股價下跌但**20日線仍在50日線上方**（多方排列未破壞）
- 即使股價破線，只要均線不死亡交叉 → 算假摔
- 要復活的訊號：**KD在低檔出現黃金交叉**

#### 假摔股實戰分析

**已復活（雙指標共振）**:

| 股票 | 均線狀態 | KD狀態 | 判斷 |
|------|---------|--------|------|
| 台積電 (2330) | 多方排列 | 低檔黃金交叉（K>D）| 假摔復活中，但20日線下彎須注意 |
| 聯電 | 多方排列 | 已黃金交叉 | 假摔已復活，連漲2-3天 |

**台光電**: 前波死亡交叉後又重新穿上 → KD黃金交叉 → 真正轉強
**健策 / 其洪**: 多方排列，KD快要黃金交叉

**尚待觀察**:

| 股票 | 均線狀態 | KD狀態 | 判斷 |
|------|---------|--------|------|
| 華邦電 | 多方但靠近 | 死亡交叉中 | 假摔但尚未復活 |

**相對弱勢**: 智邦、川湖、旺矽 → 不像以前全部右上方，注意個股分化

## 策略總結

1. **外資態度**: 期貨空單連三降、選擇權翻多 → 偏多轉向中，但需連續三天紅確認
2. **降息預期**: 從40%飆升至80%，12月降息機率大增，但仍有變數
3. **操作方向**:
   - 投信偷買股：跟投信成本差不多的（南電、電影、大量、台灣五行等）
   - 主動式ETF共識股：台積電、其洪、璟向電、復盛達、智邦
4. **假摔股策略**: 20MA>50MA + KD黃金交叉 = 假摔復活訊號
   - 已復活：台積電、聯電、台光電
   - 待觀察：華邦電、鴻海
5. **風險提醒**: 三大資產同步多方排列罕見，可能有一方需修正

## 名詞解釋

| 名詞 | 說明 |
|------|------|
| 主動式ETF | 由基金經理主動選股操作的ETF，與被動追蹤指數的ETF不同，目標是打敗大盤 |
| FedWatch | CME聯邦基金期貨隱含的降息機率工具，市場共識的即時反映 |
| 投信偷買股 | 投信在大盤下跌期間悄悄加碼的個股，通常代表機構看好的標的 |
| 股期 | 個股期貨，可用來觀察法人對特定個股的多空態度 |
| 死亡交叉 | 短期均線（20日）向下穿越長期均線（50日），代表空方力量增強 |
| 黃金交叉 | 短期均線向上穿越長期均線，或KD中K值上穿D值，代表多方力量回升 |
| PCE（個人消費支出）| 美國聯準會最重視的通膨指標，晚間即將公布10月份數據 |
| 聖誕行情（Santa Rally）| 歷史上12月美股上漲機率最高的季節性效應 |
