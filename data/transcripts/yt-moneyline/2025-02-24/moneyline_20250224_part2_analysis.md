## 💼 產業分析與投資建議

### 一、半導體供應鏈 — 新股效應與耗材重估

#### 新股掛牌：穎能科技（2/26上櫃）
- **產品**: 半導體封裝製程中氣泡解決方案
- **參考承銷價**: 1,250元
- **興櫃收盤價**: 1,720元
- **EPS**: 2023年賺25元，去年前三季30元
- **毛利率**: 60-65%（設備業中算高毛利）
- **估值**: 以去年約40元EPS計，本益比約40倍
- **定位**: 專業氣泡解決方案大廠，用氣動與熱能消除製程氣泡、橋曲問題

#### 產業重點觀察：設備股 vs 耗材股

**設備股高峰期已過**
- 從去年下半年開始，設備股不太漲了
- 股價大概率已反映整個擴廠效益
- 未來可能進入高原期，本益比會下修
- 案例：弘塑（3131）從高點跌掉超過30-40%

**耗材股（特化/特氣）成為今年重頭戲**
- 隨先進製程用量等比級數增加
- 二奈米與三奈米差最多的地方：曝光次數增加 → 清洗、蝕刻全部增加
- 特化與特氣用量將等比級數跳增
- **戰略意義**: 2023年6月日本官方基金收購JSR（全球最大光阻劑廠），公有化 → 關鍵材料成為戰略物資
- JSR本益比150-200倍，顯示特化特氣享有極高估值

#### 三檔半導體耗材股精選（基本面+籌碼+技術面三重確認）

**昇陽半導體 (8028)** — 再生晶圓龍頭
- **產品**: 再生晶圓（國內龍頭）
- **今年底月產能**: 提升至80萬片
- **利多**: 晶圓補化、矽晶存在晶圓需求
- **去年EPS**: 2.65元
- **今年EPS預估**: 5.5-6元（倍增成長）
- **籌碼**: 投信在買
- **技術面**: 近期直接拉升，短期不宜追，等拉回
- **操作建議**: 短期已拉升過快，等整理後再進場

**台特化 (4766)** — 台積電特化供應商
- **產品**: 細一碗（二奈米大量使用）、無水氟化氫（今年開始貢獻營收）
- **客戶**: 台積電占營收約70%，中美晶為大股東
- **去年EPS**: 2.72元
- **年增率**: 42%大增
- **毛利率**: 潛進六成
- **今年展望**: 倍數成長有機會（用量隨二奈米量產大增）
- **籌碼**: 近兩天投信開始買
- **技術面**: 大漲一波後拉回整理，等月線扣底翻揚（約1-2週後）
- **缺口支撐**: 220元附近
- **操作建議**: 本益比較高但成長性極強，可分批布局長期投資，不宜重壓
- **市值對比**: 即將超越弘塑（貴板排30名左右），帶動OTC上漲

**吸引材 (6891)** — 台積電光阻材料
- **產品**: 紫外線光材料開發、低溫聚醯亞胺表面改質劑（二奈米專用）、洗滌劑、底部反射塗層
- **客戶**: 台積電占營收約70%
- **EPS**: 前年3.9元 → 去年前三季6.39元 → 全年約8元
- **成長性**: 不到4元跳到8元，今年持續高成長
- **本益比**: 較高（特化特氣本益比普遍偏高）
- **市值**: 約630億，接近新普（約700億，貴買第10大）
- **操作建議**: 高檔橫盤整理中，市值超越新普後將帶動OTC指數

#### 設備股 vs 耗材股投資邏輯

| 比較項目 | 設備股（如弘塑） | 耗材股（如台特化） |
|---------|----------------|----------------|
| **趨勢** | 高峰期已過，走弱 | 今年重頭戲，成長中 |
| **市值** | 下滑中 | 上升中，即將超越設備股 |
| **本益比** | 開始下修 | 享受高成長溢價 |
| **操作策略** | 利用反彈減碼 | 拉回時站在買方 |
| **驅動力** | 擴廠告一段落 | 二奈米量產用量大增 |

### 三、美超微（SMCI）供應鏈 — 起死回生

#### 美超微現況
- **明日重大事件**: 必須繳出遲交財報，否則面臨納斯達克下市
- **股價**: 一個月內從25元漲至66.4元（翻倍）
- **市場判斷**: 股價已先反映，分析師預期能繳出財報
- **財務指引**: CEO指出2026財年預估營收400億美元（vs 分析師預估292億）
- **成長動力**: 新數據中心30%將採用直接液冷技術

#### 美超微核心技術：直接液冷（DLC）
- SuperCluster連接10萬顆NVIDIA GPU
- 液冷技術可減少40%能源消耗、空間減80%
- 支持溫水冷卻，可將AI系統熱量重新利用
- 搭載NVIDIA GB200 GPU伺服器
- 創辦人梁見後（Charles Liang）為台灣人（台北科大畢業）

## 🌐 總體經濟分析（中經院PMI）

### PMI數據解讀

#### 台灣製造業PMI（1月）
- **PMI**: 48.7%（跌破50榮枯線，結束連續2個月擴張）
- **原因**: 農曆天數減少 + 川普關稅不確定性 + 庫存調整
- **未來六個月展望**: 仍大於50%（相對樂觀）
  - 中國補貼政策
  - 消費端需求（烏俄結束、洛杉磯大火重建）

#### 各產業PMI表現
| 產業 | 1月表現 | 說明 |
|------|--------|------|
| **生技醫療** | 成長最多 | 流感推升藥品需求 |
| **食品紡織** | 持平 | - |
| **電力機械設備** | 持平偏好 | AI、半導體、重電設備、機器人自動化帶動 |
| **交通工具** | 衰退最大 | 需求不強，台灣多為OEM |
| **化學生技** | 成長顯著 | 流感藥品需求 |

#### NMI（非製造業）
- 仍在50以上但微降
- **表現好**: 住宿餐飲（剛性需求）、營建工程（半導體工程）
- **表現差**: 零售（百貨、量販）、金融保險（川普政策波動）
- **空運好、海運差**: 出國觀光熱 vs 烏俄戰爭影響

#### 核心擔憂
1. **訂單短單化**: 新增訂單下滑，客戶庫存不敢拉貨
2. **主要經濟體成長放緩**: 美國今年預估1.8-1.9%（去年2.5%）、中國可能降至4.6-4.7%
3. **美國失業率**: 看似偏低，但可能是未來衰退的領先指標
4. **中國房地產**: 地方政府債務問題，短期無法解決

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **PMI** | 採購經理人指數，50以上代表擴張，50以下代表緊縮 |
| **NMI** | 非製造業指數，反映服務業景氣 |
| **特化** | 特殊化學品，半導體製程關鍵材料（如光阻劑、蝕刻液） |
| **特氣** | 特殊氣體，半導體製程使用的高純度氣體 |
| **DTC** | Direct To Consumer，品牌直接面對消費者的銷售模式 |
| **JSR** | 日本合成橡膠公司，全球最大光阻劑廠，2023年被日本官方基金收購 |
| **DLC** | Direct Liquid Cooling，直接液冷技術 |
| **Sidecar** | 邊車式液冷方案，在機櫃背門內建獨立液冷循環 |
| **分歧管** | 液冷系統中分配冷卻液的管路元件 |
| **硬銲** | 高溫銲接技術，接合強度高於軟銲，用於液冷管路 |
| **MSCI** | 摩根士丹利資本國際指數，被納入可吸引被動資金 |
| **Ariot模組** | NVIDIA的Grace CPU + Blackwell GPU整合模組 |
