## 🌍 市場總體觀察

### 川普貿易政策全面解析

#### 關稅政策進展
| 對象 | 措施 | 現狀 |
|------|------|------|
| 加拿大/墨西哥 | 20%關稅 | 延後一個月，作為談判籌碼 |
| 中國 | 額外加徵10%關稅 | 持續中 |
| 台灣半導體 | 曾提100%，後改25% | 4月2日揭曉 |
| 鋼鐵鋁 | 25%關稅 | 台灣為美國第五大鋼鐵出口國 |
| 對等關稅 | 出口國關稅+加值營業稅 | 台灣加值營業稅僅5%，衝擊較小 |

#### 台積電與美國三大方案
1. **一條龍赴美**: 晶圓廠+封測全部投資美國 → 對台灣影響有限，但需注意人才外流
2. **英特爾子公司+台積電技術入股**: 短期影響小，但長期技術可能外洩 → 對台積電不利
3. **合資企業（二三奈米）**: 變數最多，台積電可能成為全球性晶圓代工廠，但美國希望英特爾主導

#### 台灣關稅稅率
| 產品類別 | 平均關稅 |
|---------|---------|
| 農產品 | 9.33% |
| 工業產品 | 1.48% |
| 全部產品 | 1.76% |
| **說明** | 因加入WTO資訊科技協定（ITA），IT產品稅率極低 |

#### 台灣對美貿易順差
- **金額**: 739億美元（美國第六大順差國）
- **增幅**: 從13-14%增至24-25%（主要因AI科技產品出口）
- **順差排名**: 中國3,000億 > 墨西哥 > 越南 > 日本 > 德國 > **台灣**

### DeepSeek影響分析（中經院觀點）

#### 正面效果
1. **鯰魚效應**: 刺激OpenAI等加速創新
2. **降低成本**: 開源模式讓AI訓練成本、設備成本降低 → 加速應用滲透
3. **AI三波機會論**:
   - 第一波：NVIDIA、微軟、Apple等平台商（基礎建設）
   - 第二波：更多競爭者入場（DeepSeek、OpenAI開源競爭），降低成本 → 破圈應用
   - 第三波：帶動各行各業，長期生產力提升

#### 實際評估
- DeepSeek訓練成本號稱500萬美元，但背後基礎建設成本仍很高
- 核心晶片使用量可能1,000-2,000顆（但大量在其他處「偷跑」）
- 結論：有幫助但沒有想像中那麼顛覆

## 💼 產業分析與投資建議

### 阿里巴巴概念股 — 蘋果中國AI合作

#### 產業背景
- **蘋果選擇阿里巴巴**作為中國AI大模型合作夥伴（非DeepSeek）
- 中文AI功能模型已送交中國批准
- 阿里巴巴未來三年AI基礎設施投入將超過過去10年總和
- 阿里巴巴今年股價漲70%，旗下布局完整：
  - **機器人**: 阿里雲爾斯系統打入優必選（香港掛牌，今年漲50-60%）
  - **自駕**: 與NVIDIA合作無人駕駛車載軟體
  - **收購**: 收購人型機器人開發商「新動技元」

#### 個股分析

**英業達 (2356)** — 阿里巴巴伺服器代工
- **定位**: 阿里巴巴伺服器四大代工廠中最主要
- **IP領域**: 切入矽智財（SK晶片設計、量產、客製化）
- **營收**: 去年Q4創歷史新高
- **展望**: 大陸雲端客戶訂單持續；下半年可能有GB300出貨
- **技術面**: 位置點偏低，底部有跡象
- **操作建議**: 位置低，後面可觀察是否築底上來
- **來賓**: 育堂

**南子電 (8121)** — 持有滬電股份
- **間接利多**: 持有滬電（中國大陸掛牌，做AI伺服器PCB板，股價歷史新高）股份
- **滬電持股成本**: 不到5元，現價約40多元（翻近10倍）
- **潛在處分利益**: 高達百億元（約5個股本）
- **自身業務**: 切入AI高速運算PCB板，今年營收占比可能從個位數提升至20%
- **技術面**: 橫盤整理三週，等放量突破
- **操作建議**: 量出來配合紅K上攻即為切入時機，否則等待
- **來賓**: 育堂

**威田/威廷 (3535)** — 工業機器人/機器視覺
- **產品**: 機器視覺技術（機器人最關鍵技術）
- **客戶**: 中國大陸客戶（間接阿里巴巴關聯）
- **集團**: 佳世達集團（與羅昇合作機器手臂）
- **Q3毛利率**: 創歷史新高，約40%
- **應用**: 半導體後段檢測設備、大數據印上專案、工廠自動化
- **技術面**: 上週才開始放量，過前波黑K高點+過紫線壓力，屬落後補漲
- **對比**: 同族群工業電腦股幾乎全翻倍，威田剛啟動
- **操作建議**: 大底過紫線突破，放量明確，跟工業電腦族群做補漲
- **來賓**: 育堂

**智原 (3035)** — ASIC/AI晶片設計
- **產品**: ASIC晶片設計服務
- **展望**: 今年營收有機會年增18%
- **中國布局**: ST業務深耕中國，中國自家設計晶片開放代工需求增加
- **DeepSeek效應**: 加速AI應用導入
- **法說會**: 看法兩極（毛利率可能下滑 vs 營收成長強勁）
- **股價**: 245元（今日開低走高）
- **技術面**: 去年跌了一整年（459 → 底部），今年已出現築底翻升，投信積極站在買方
- **操作建議**: 跌深股，底部已確認，反彈到年線位置都不會過分
- **來賓**: 育堂

## 🌐 中經院政策建議 — 台灣因應策略

### 王健全副院長建議

#### 半導體產業（恩威並施策略）
1. **短期**: 赴美投資（不得不做），但保留後手
2. **六大後手**: 旅行經濟安全、雙向投資、美國軟體人才引進台灣
3. **施壓管道**: 透過NVIDIA、蘋果、超微等大客戶對川普施壓
4. **資本市場連結**: 推動台灣企業赴美雙掛牌（如長春化學、漢唐、群聯）

#### 傳統產業
- **必須二次升級轉型**: 面對中國低價傾銷、日幣貶值、海外設廠壓力
- **政策組合**: 租稅優惠 + 人才配套 + 協助轉型

#### 服務業
- **產業化**: 服務業必須與產業結合
- **成立主權基金**: 台灣是全球少數沒有主權基金的經濟體
  - 現有5,500億外匯存底，拿300億美元與民間合作
  - 投資AI、機器人、購併技術

#### 對美關係
- **爭取關稅優惠**: 帶100家廠商投資美國，創造就業換取關稅通道
- **提升產業結構**: 高科技隨著AI整合擴散、傳產科技化、服務業產業化

## 📋 投資策略總結

### 三大核心主軸
1. **半導體特化/特氣取代設備股**: 二奈米量產是最大催化劑
2. **美超微供應鏈復活**: 高力、承民電、軍力、緯創受惠
3. **阿里巴巴+蘋果中國AI**: 英業達、南子電、智原間接受惠

### 川普關稅結論
- **台灣科技業**: 因ITA協定，關稅影響有限；台積電可轉嫁
- **傳統產業**: 衝擊較大，特別是農產品、鋼鐵
- **整體評估**: 短多長空，2025年減稅利多，2026年關稅後座力顯現
- **台灣GDP**: 可能從3.2%降至2.3-2.4%

### 美股今晚展望
- 錄影時美股期貨已開高
- 台股今日表現優於預期（上週五美股大跌後未崩盤）
- 櫃買翻紅，多頭健康輪動

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **對等關稅** | 美國要求貿易夥伴的關稅+加值營業稅與美國對等 |
| **ITA** | 資訊科技協定（Information Technology Agreement），WTO框架下IT產品零關稅或低關稅 |
| **DTC** | Direct To Consumer，品牌直接銷售消費者模式 |
| **DeepSeek** | 中國AI大模型公司，以低成本訓練引發全球關注 |
| **鯰魚效應** | 引入競爭者刺激原有市場參與者加速創新 |
| **主權基金** | 國家級投資基金，利用外匯存底進行策略性投資 |
| **ASIC** | 特定應用積體電路，針對特定用途客製化設計的晶片 |
| **滬電股份** | 中國大陸PCB板上市公司，主做AI伺服器加速器板 |
| **優必選** | 中國人型機器人公司，香港掛牌 |
| **停滯性通膨** | 經濟成長停滯但通膨仍高的困境 |
