## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| 法說會 | 法人說明會，上市公司向法人機構說明營運狀況與展望 |
| 本益比（P/E Ratio）| 股價除以每股盈餘，衡量股票估值水準 |
| 灰犀牛理論 | 指高機率且影響巨大的潛在風險，但常被忽視的威脅 |
| VIX恐慌指數 | 芝加哥選擇權交易所波動率指數，反映市場恐慌程度 |
| 換手 | 股票持有者從一方轉移到另一方，通常指籌碼從弱手轉到強手 |
| DDR5 | 第五代雙倍資料速率記憶體，AI伺服器主要使用規格 |
| 主動式ETF | 由基金經理人主動選股管理的ETF，代碼尾碼為A |
| 平衡型ETF | 同時投資股票與債券的ETF，代碼尾碼為T |
