### 三、2025年操作策略（柯老師核心觀點）

#### 長線投資觀念
1. **M型化加劇**: 全球產業M型分化，龍頭企業持續壟斷
2. **強者恆強**: 2025年必須做強於大盤的股票
3. **台積電是標配**: 2025~2026年不做台積電是最傻的選擇

#### 操作模式
- **強於大盤的股票**（如台積電）: 趨勢型上漲，大利多時短線站賣方，利空拉回支撐一定要敢買
- **符合大盤的個股**: 階梯式上漲，高賣低買區間操作
- **趨勢未變前**: 高點不過23,743，低點不過22,050，低進高出

#### 台積電技術面
- **上升軌道支撐**: 1,060元
- **季線支撐**: 1,060元附近（上揚中）
- **前波轉折點**: 1,050元
- **整數關卡**: 1,050元
- **操作**: 利多衝高短線調節部分，拉回支撐必買

#### 光明產業 vs 暗淡產業

**光明產業**（趨勢操作）:
- 半導體/AI高效能運算
- AI資訊通訊供應鏈
- 金融產業
- 高股息股票

**暗淡產業**（跌深反彈操作，勿追高）:
- 低附加價值/技術含量低的傳產股
- 舊產業（台塑、南亞、南亞科）→ 等W底第二隻腳
- 營建業（打房政策延續）
- 中國概念股（關稅戰+出口競爭力下降）

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **CPO (Co-Packaged Optics)** | 共同封裝光學，將光學元件與電子晶片整合封裝，提升資料傳輸效率與降低功耗 |
| **矽光子 (Silicon Photonics)** | 利用矽晶圓製程生產光電元件的技術，用於高速資料傳輸 |
| **ADR** | 美國存託憑證，台積電在美國掛牌交易的憑證 |
| **BATMMAAN** | 2025年美股新七巨頭：Broadcom、Apple、Tesla、Microsoft、Meta、Amazon、NVIDIA |
| **預防性降息** | 在經濟尚未衰退時，央行預先降息以防止經濟下行 |
| **分盤交易** | 證交所針對特定股票實施的交易限制，每5分鐘撮合一次，增加交易風險 |
| **M型化** | 社會或產業呈現兩極分化，中間層萎縮的現象 |
