- **台積電ADR盤前**: 一度大漲7%，後縮至5%

### 大盤趨勢研判（柯老師深度分析）

#### 區間震盪格局確認
- 過去4個月（10月~1月），大盤維持壓力與支撐來回震盪
- **壓力區**: 23,743~23,943點
- **支撐區**: 22,050~22,580點
- **操作原則**: 趨勢未變前，高賣低買

#### 官股動態解讀
- **1月7日高點**: 官股單日賣超112億（近期最大），隔天續賣 → 行情下來
- **1月13日低點**: 跌523點後，官股買超122億（2024年9月4日以來最大）→ 確認底部
- **結論**: 跟著政府（官股）腳步走不會吃虧

#### 台積電領先大盤
- 台積電今天重回1,000億成交量級別
- 台積電過高代表大盤過23,743的前兆
- 台積電突破1,160元 → 大盤才會重新挑戰前高

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **官股（國安基金/政府基金）** | 政府控制的金融機構買賣動向，常被視為政策態度指標 |
| **W底（雙重底）** | 股價形成兩個低點的底部型態，第二隻腳確認後較安全 |
| **KD指標** | 隨機指標，20以下為超賣區，向上交叉為買進訊號 |
| **MACD收斂** | MACD柱狀體由最大負值開始縮小，暗示賣壓減緩、即將翻多 |
| **轉單效應** | 因地緣政治或關稅政策，訂單從某國轉移至其他國家供應商 |
| **PB（Price-to-Book）** | 股價淨值比，股價低於淨值時PB<1，通常被認為低估 |
| **主動型ETF** | 由基金經理主動管理的ETF，結合共同基金的彈性與ETF的交易便利性 |
