## 📊 油金債匯操作策略（遇堂分析）

### 黃金
- **現況**: 期貨收盤稍微過前高，但現貨未過高
- **觀察重點**: 若過高後收黑，通常代表一波較大修正
- **基本面**: 全球央行儲備佔比已達20%（超過歐元16%，僅次美元46%）
- **籌碼面**: Q1黃金流入美國（Comex庫存堆高），Q2已逆轉回流歐洲（DOGE檢查結束）
- **操作建議**: 視為利多出貨訊號，非搶進時機；手上有黃金正二或期貨者可考慮調節

### 原油
- **觀察指標**: 台灣的元大S&P原油正二（00672L）出現大量K棒，過去每次大量K皆為趨勢翻轉點
- **基本面**: 安培夫預估Q2-Q3均衡油價66美元，目前已超過均衡價，極度被高估
- **供給面**: OPEC+增產、美國增產、俄羅斯增產 → 供過於求
- **操作建議**: 大量K高點若無法再過，翻轉下跌機率高；手上有正二者找停利時間點

### 美元
- **技術面**: 跌破前低後出現紅K，若形成破底翻形態則可能反彈至月線
- **基本面**: Q2貿易逆差可能縮小（黃金回流歐洲影響進出口數據）
- **觀察重點**: FOMC利率決議（週四凌晨）、點陣圖變化

### 美債（10年期公債殖利率）
- **現況**: 3.6%-4.8%區間盤整近兩年，目前約4.5%附近
- **結構**: 殖利率曲線仍為熊陡（短端較低、長端較高）
- **標售狀況**: 逐漸好轉，投標需求增加
- **降息前景**: 市場預期9月、10月降息，但長端不見得跟著降很多

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **CPO (Co-Packaged Optics)** | 光電共封裝，將光學元件與交換器晶片封裝在一起，大幅提升資料傳輸效率 |
| **TH6** | 博通推出的最新交換器晶片，支援102.4Tbps傳輸速度，可連動十萬顆GPU |
| **PD (Photodetector)** | 光偵測器，將光訊號轉換為電訊號的關鍵零組件 |
| **CWDM/CWDFB雷射** | 連續波長可調雷射，用於矽光模組中的光源 |
| **AOC (Active Optical Cable)** | 主動光纜，使用光纖傳輸的高速連接線 |
| **四巫日** | 美股每季第三個週五，股票指數期貨、股票指數選擇權、個股期貨、個股選擇權同時到期結算 |
| **台指期結算** | 台灣期貨交易所每月第三個週三進行當月合約結算 |
| **荷莫茲海峽** | 位於波斯灣出口，全球約20%原油經此運輸 |
| **Comex** | 紐約商品交易所，全球最大的黃金期貨交易市場 |
| **DOGE** | 馬斯克領導的政府效率部門，曾計劃檢查美國黃金庫存 |
