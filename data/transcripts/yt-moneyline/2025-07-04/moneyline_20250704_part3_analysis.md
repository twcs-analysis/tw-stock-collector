## 🌍 市場總體觀察

### 台幣升值對投資組合的全面衝擊

#### 受影響資產類別
| 資產類別 | 影響程度 | 說明 |
|---------|---------|------|
| 美元保單 | 高 | 匯損直接反映在帳面價值 |
| 美股ETF | 中至高 | 美元計價，台幣升值吃掉漲幅 |
| 美債ETF | 極高 | 價格不漲 + 台幣升值 = 雙重虧損 |
| 台股ETF | 低 | 台幣計價，無直接匯率影響 |
| 高股息ETF | 低 | 影響在成分股的匯損，非ETF本身 |
| 日圓資產 | 極高 | 日圓對台幣創歷史新低 |

#### 最慘的投資者
- **槓桿買美債者**: 用美債質押再加倍買同類債券，台幣升值導致爆倉風險
- **案例**: 買微軟、蘋果債券後質押加倍，以前台幣在30-32區間認為安全，現在28.7直接打破假設

### 台幣歷史區間與投資判斷

#### 過去20年台幣匯率區間
- **區間**: 27至34-35之間波動
- **當前位置**: 28-29（接近區間下緣）
- **波傑觀點**: 台幣再跌空間有限，現在開始定期定額買進美元計價ETF是合理策略
- **27元附近**: 應勇敢加碼（歷史區間下緣）

## 📋 投資策略總結

### 台幣升值下的資產配置四原則
1. **核心配置**: 台股ETF（0050或主動式）— 完全不受匯率影響
2. **穩定收益**: 高股息ETF（00919、00878）— 影響極低
3. **攻擊部位**: 美股AI/科技ETF — 選漲幅大於匯損的標的
4. **暫停加碼**: 美債ETF — 等台幣升值告一段落再考慮

### 法人籌碼布局結論
- **外資**: 持股低但6月積極買進 = 建倉任養，下半年有機會發動
- **投信**: 5%以下持股 + 6月連續買超 = 看好產業趨勢
- **首選標的**: 大量(3167)、成明電(6205)、達新材 — 產業趨勢明確 + 法人雙買

### 短線操作建議
- **下週一關鍵**: 對等關稅公布後的市場反應
- **不追高**: 等拉回利空測試後再進場
- **觀察央行**: 若對外資炒匯提出管制措施，市場將有新變數

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **任養（認養）** | 法人（外資或投信）在持股比重偏低時，有計畫地連續買進某檔個股，逐步建立部位的過程 |
| **T+2 / T+1** | 股票交割制度。T+2為交易後兩個營業日交割，若改為T+1可縮短外資炒匯套利空間 |
| **CCD檢測機** | 利用CCD（電荷耦合元件）將光轉換成電訊號的檢測設備，用於PCB和半導體品質檢測 |
| **FOPLP** | Fan-Out Panel Level Packaging，扇出型面板級封裝技術，是先進封裝的重要方向 |
| **CPO** | Co-Packaged Optics，共同封裝光學技術，將光學元件與晶片封裝在一起以提升傳輸速度 |
| **GB200 / GB300** | NVIDIA的AI伺服器產品代號，GB300為GB200的升級版，預計2025年8月開始出貨 |
| **Sikah** | NVIDIA AI伺服器的水冷散熱模組系列 |
| **主動式ETF** | 由基金經理人主動選股操作的ETF，不完全追蹤指數，希望打敗大盤表現 |
| **定期定額** | 固定時間投入固定金額的投資方式，透過平均成本法降低擇時風險 |
