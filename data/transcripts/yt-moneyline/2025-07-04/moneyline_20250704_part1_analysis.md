## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **自然避險** | 企業不使用衍生性金融商品，而是透過營運本身的外幣收支自動對沖匯率風險的方式。例如月底匯率若回到原點，則該月無匯損 |
| **本益比天花板** | 指標股（如台積電）的本益比水準會壓制同產業其他個股的估值上限 |
| **期貨空單對沖** | 外資在現貨市場買進的同時，於期貨市場放空等量部位，形成無風險套利組合 |
| **匯率套利** | 外資利用台幣升值趨勢，將資金匯入台灣買進股票，同時放空期貨對沖，待台幣升值後獲利了結匯出 |
| **大而美法案** | 美國眾議院通過的「One Big Beautiful Bill」，包含減稅、擴大國防支出、債務上限調高等財政寬鬆政策 |
