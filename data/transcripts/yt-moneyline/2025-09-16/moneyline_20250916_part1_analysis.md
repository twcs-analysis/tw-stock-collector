## 📈 技術面分析與操作策略

### 降息三大劇本與台股走勢

#### 劇本一：符合預期（今年降3碼、明年降2-3碼，共5-6碼）
- 預防式降息，通膨降溫後的溫和降息循環
- 4月走反彈資金行情，後續接基本面行情，一路延續到明年
- AI供應鏈持續上攻，**最樂觀情境**
- **歷史參考**: 預防式降息後3個月漲15%、6個月漲10%、1年漲43%

#### 劇本二：高於預期（川普期望的大幅降息）
- 一次降兩碼以上，市場懷疑經濟衰退
- 美股面臨修正壓力，半年內波動加大
- 台股基本面行情可能落空

#### 劇本三：低於預期
- 資金行情面臨考驗，台股修正壓力出現

#### 關稅影響
- 實質有效關稅稅率僅9%，遠低於國際貨幣基金與世界貿易組織預期的20%
- 關稅衝擊「雷聲大雨點小」

### 三大權值股操作策略

#### 聯發科（2454）— 降息最大受益者
- 歷史數據：降息後3個月平均漲50%，半年持續擴大，1年翻倍甚至達160%
- 第三季（9月）為聯發科歷史上最強接棒期
- 與台積電合作2奈米晶片設計完成，明年量產
- **操作建議**: 五日線附近出現紅棒突破即進場；空手者五日線拉回有買盤就直接進場
- **目標價**: 前高之上，降息循環1年內有翻倍潛力
- **停損點**: 跌破五日線且無買盤支撐

#### 台積電（2330）
- 秒天席第19度，三天內觀察能否持續創新高
- **操作建議**: 三天內未創新高，等月線扣底回靠月線再買；月線上升趨勢不變
- **停損點**: 跌破月線

#### 鴻海（2317）
- 上週五曾創新高，週一至今未過高
- **操作建議**: 明天（週三）未過高就等月線，月線上升中靠近即可佈局
- **停損點**: 跌破月線

### 投資組合管理——核心持股 vs 衛星持股

#### 現金比重管理
- 鏡龍老師目前持股76%、現金24%（年初現金30%，4月低點加碼後降至24%）
- 4月低點動用375萬加碼：鴻海128.5元買進、金原電子74.7元買進、群力166元買進、台耀133元買進
- 保持至少10-20%現金比例，跌時才有籌碼

#### 汰弱留強原則
- 弱的先賣、強的留下甚至加碼
- 漲到目標價的衛星持股可獲利了結，拉高現金比重

#### 核心 vs 衛星配比
- 可採5:5、7:3或3:7，視個人風險承受度而定
- **核心持股**: 長期持有不輕易賣出（如台積電、鴻海、台耀等）
- **衛星持股**: 逢低加碼、逢高減碼，彈性操作

## 📋 投資策略總結

### 短期（1-2週）
- 降息一碼幾乎確定，利多已反映部分，短線可能震盪
- 聯發科為降息最大受益者，五日線附近積極佈局
- 台積電與鴻海觀察三天能否創新高，未過高則等月線
- 記憶體族群南亞科突破後勿追，等拉回再進場
- PCB族群終止連黑，金居、堅端拉回可佈局

### 中期（1-3個月）
- 預防式降息後3個月台股平均漲15%，AI基本面行情可期
- 軍工國防展週四登場，無人機概念中低本益比股（融程電、原相、義隆電）值得中期佈局
- 聯發科在降息循環中歷史表現最佳，中期看翻倍
- 維持核心持股+衛星持股策略，現金比重保持20-30%

### 風險評估
- **最大風險**: 聯準會降息幅度超出預期（一次降兩碼以上），引發經濟衰退恐慌
- **次要風險**: 川普持續施壓聯準會獨立性，政策不確定性升高
- **關稅風險**: 目前看來實質影響有限，但仍需持續觀察
- **操作風險**: 台股創歷史新高後若無法持續攻堅，短線震盪加大

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **秒天席** | 指開盤即創歷史新高，形容股價強勢突破天際 |
| **預防式降息** | 在經濟尚未衰退前，為預防景氣下滑而提前降息，通常為溫和降息 |
| **救市式降息** | 經濟已確認衰退後的緊急降息，通常一次降兩碼以上 |
| **核心持股** | 長期持有的主力部位，不輕易因短線波動而賣出 |
| **衛星持股** | 可彈性操作的部位，逢高減碼、逢低加碼以管理現金比重 |
| **GCS** | Ground Control Station，地面控制站，用於操控無人機的控制設備 |
| **IP65** | 國際防護等級，65代表防塵與防水噴射，軍用級認證標準 |
| **OTS/OMP** | 光學運動感測/光學動態感測，用於無人機與機器人的追蹤導航技術 |
| **CME FedWatch** | 芝加哥商品交易所聯準會觀察工具，用於預測聯準會利率決策機率 |
| **汰弱留強** | 賣出表現弱的股票，保留表現強的股票，投資大師共同的操作原則 |
