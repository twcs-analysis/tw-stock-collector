### 超級央行週分析（聽號）

#### 本週央行會議時程
- **週四清晨**: 美國聯準會（FOMC）利率決議
- **週四下午**: 台灣央行理監事會議
- **日本央行**: 提前一天（週三）

#### 美國聯準會的兩難

**市場預期 vs 聯準會立場**:
- 市場降息預期已拉到三碼（75個基點）
- 鮑威爾前次表態：經濟無太大隱憂，不應把降息預期拉得太快
- 就業數據表現不差（非農、職位空缺數均正常）
- 通膨穩定下滑中

**不確定性因素**:
1. **小型企業不確定性指數**: 短期內高速衝高（來自關稅引起的通膨預期上行）
2. **企業軟著陸問題**: 過去幾個季度財報都討論軟著陸，本季度卻無人提及
3. **美國政策不確定性指數**: 已創歷史新高（川普政策持續衝擊市場）

**聽號個人判斷**:
- 市場過度被嚇到，聯準會應會在未來幾週把市場預期拉回
- 經濟數據不支持緊急降息
- 即便最終降息三碼，債券上漲空間也有限（已充分反應）
- **聯準會最終可能會說服市場，而非市場迫使聯準會降息**

#### 台灣央行的兩難

**升息的可能理由**:
1. **食品通膨上行**:
   - 水果通膨（颱風影響）
   - 禽流感導致蛋價上漲（產地價從32-33元飆到39元）
   - 早餐店漲價潮（已漲未降回）
2. **電價調整壓力**:
   - 3月底經濟部將召開電價審議委員會
   - 台電預算被刪減，需反映到民間電價
   - 半導體佔台灣用電近五成，本次可能對半導體調漲電價
   - 民生用電330度以下（約1,500萬戶）也可能調整
3. **CPI變化**:
   - 2月CPI降至1.58%（因去年2月春節基期高達3.08%）
   - 3月可能因食品通膨往上彎

**聽號判斷**: 升息半碼的空間存在，但壓力可能延續到下次會議

#### 日本央行的兩難

**核心問題**: 全球央行降息，日本卻面臨內生性通膨壓力

**通膨失控現象**:
- 日本米價相對2024年元月暴漲七成（完全失控）
- 加工食品上漲一成六
- 調味料上漲一成七
- 肉類上漲兩成三
- 糖果漲一成九
- 牛奶漲一成三
- 麵包漲五成三

**民意反彈**:
- 石破茂支持率從六成下滑至四成
- 通膨改善了經濟數據，但民間購買力未提升
- 「通縮不行，通膨也沒讓市場購買力提升多少」

#### 中國人行的困境

**唯一明確方向**: 解決通縮問題
- 2月CPI、PPI全部年減（標準通縮）
- 核心CPI也年減（服務價格、工資都在跌）
- 汽車製造業PPI年減3.8%（新能源車越賣越便宜）
- 企業新增中長期貸款創歷史新低

**結論**: 中國人行是所有央行中最確定會繼續寬鬆的

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **Edge AI（邊緣AI）** | 不需連接雲端，在本地設備（如個人電腦）上運行AI推理的技術，具備低延遲、隱私保護的優點 |
| **AI DIP TIP+** | 群聯推出的軟硬整合方案，採用NVIDIA ATX GPU，讓企業以更低成本導入AI |
| **量子運算** | 利用量子力學原理進行運算的技術，一次可處理多件事，運算速度為傳統電腦的數倍甚至數百萬倍 |
| **矽IP** | Silicon Intellectual Property，半導體設計的基礎元件模組，可讓量子位元狀態更穩定 |
| **均溫板（Vapor Chamber）** | 高效散熱元件，利用相變化原理均勻散熱，平均單價高於傳統散熱方案5-10倍 |
| **Mateau TIM** | 散熱金屬材料，用於伺服器市場，已通過NVIDIA認證 |
| **電價審議委員會** | 經濟部下設的委員會，負責審議台灣電價調整方案 |
| **內生性通膨** | 由國內經濟因素（如工資上漲、原物料成本）自然產生的通膨，非外部輸入 |
| **通縮** | 物價持續下跌，企業獲利縮減，消費者延遲消費的惡性循環 |
