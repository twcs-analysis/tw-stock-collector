#### 三檔被打入全額交割股（今日跌停）
1. **台養（紅家軍）** - 美股禁止（股價低於5元），一開盤跳空跌停鎖死

3. **抗控** - 美股禁止（低於3元），之前已是全額交割，繼續分盤交易

#### 全額交割股的徵兆與應對
- **警訊**: 連續虧損、股價一直下滑是最明顯徵兆
- **流程**: 股價低於10元 → 取消信用交易 → 低於5元 → 打入全額交割
- **台養**: 過去三年連續虧損，大股東鑑漢已處分過半股份，紅家軍色彩漸淡
- **另一房**: 過去三年大虧，三年累計虧損10元以上
- **操作建議**: 被打入全額交割基本上先出為主，不要「不賣就沒賠」的心態
- **提醒**: 即使不是全額交割，持續虧損的公司也要小心操作

#### 重要結構觀察
- **主跌重心**: 電子股（本波最弱勢）
- **上漲重心**: 傳產股（從1月13日低點開始反彈）
- **類股輪動特徵**: 通常經過一次大跌後，資金會從電子換到傳產
- **騰落指標**: 大盤破底但騰落指標未破底 → 表面看漲的股票多，實際是傳產在撐
- **騰落指標已跌破2024年8月股災低點** → 代表非常多個股（尤其電子）已跌破股災低點
- **操作難度**: 從2024年11月開始，已連續四五個月操作難度極高

#### 櫃買指數（OTC）更嚴峻
- 騰落指標已跌破股災低點，中小型股跌幅更大
- 跡線（下降壓力線）一度突破但失敗，形成假突破
- 跡線、半年線、年線有空頭排列跡象
- OTC繼續下跌對中小型股殺傷力很大

## 💼 黃金與貴金屬分析（遇很）

### 黃金

#### 價格現況
- 上週五突破每盎司3,000美元歷史新高（最高3,004.94美元）
- 新債券巨頭岡拉克預測：下一個目標為4,000美元

#### 黃金上漲驅動力（四個因素）
1. **央行結算需求** - 已告一段落（美國已囤大量黃金現貨）
2. **美國經濟衰退預期** - 持續發酵中
3. **美元弱勢** - 衰退預期 → 聯準會降息 → 美元走弱
4. **戰爭/避險需求** - 歐洲備戰，地緣政治不確定

#### 技術面分析
- 一倍等幅距離：從2,850到2,950（約100美元），往上翻到3,050
- 若到3,050可能獲利了結
- 若未到3,050就提前下跌 → 留意假突破拉回（2:1形態）
- **關鍵**: 觀察本週經濟數據（FOMC、GDP、就業）對黃金動能的影響

#### 操作工具
- 正向ETF: 00674R（元大S&P黃金）、00635U
- 反向ETF: 00708L
- 微型黃金期貨
- **性質**: 短線波動為主，不宜長抱

### 白銀

#### 特性
- 黃金的替代品，有工業需求（與經濟相關）
- 避險需求低於黃金（央行存黃金不存白銀）
- 經濟好時漲幅比黃金快
- 目前高點尚未突破（黃金已過高但白銀未過）

#### 交易機會
- 若本週經濟數據顯示美國經濟沒那麼快衰退
- → 黃金動能消失、拉回
- → 白銀不跟跌或跌幅更小
- → 白銀走「落後補漲」行情
- **工具**: 00738U（元大道瓊白銀）

### 銅

#### 特性
- 工業金屬（非避險），與中國經濟/陸港股走勢高度相關
- 電動車電池大量使用銅
- 目前正在挑戰2024年9-10月高點

#### 交易方向
- 觀察中國經濟復甦力道與陸港股多頭是否延續
- **工具**: 00763U（街口道瓊銅）

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **全額交割股** | 股價低於5元或財務狀況不佳的股票，買進時須先繳足全額款項，交易限制多 |
| **騰落指標** | 統計市場中上漲與下跌股票家數的差異，用以觀察市場內部強弱 |
| **2:1形態** | 技術分析中的假突破型態：過前高後微幅創高即跌回，壓力反彈不過再往下走 |
| **一倍等幅** | 技術分析測量方法，以前一波漲幅等距離推算下一波可能的目標價位 |
| **成熟製程** | 半導體製程中28nm以上的較舊技術，與先進製程（7nm以下）相對 |
| **結算需求** | 黃金期貨到期時，買方要求實物交割而非現金結算，推動現貨需求 |
