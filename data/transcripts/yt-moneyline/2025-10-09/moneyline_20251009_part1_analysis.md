## 📈 技術面分析與操作策略

### 大盤技術面
- 連假四天上漲 540 點，短線漲幅已大，負乖離比較大
- 下禮拜進入營收與財報季，好壞消息都會影響
- 盤面雖然大盤上漲，但部分 ODM 股已開高走低
- 許多缺乏業績支撐的題材股已開始下跌

### 個股操作策略
1. **短線操作者**：台積電不用急，等拉回，法說會前三個交易日觀察
2. **選股邏輯**：找低本益比、低位階、業績尚未反映的個股
3. **電子成交比重**若降溫，資金可能輪動至傳產（散裝貨運、塑化）
4. **記憶體操作**：跟著報價走，價格持續高檔不墜就有機會
5. **風險控管**：高本益比、高位階且無業績支撐的個股應提高警覺

## 📋 投資策略總結

### 短期（1-2 週）
- 台積電法說會前整理機率高，五日線為短線強弱關鍵
- 連假後首日注意獲利了結賣壓
- 記憶體族群持續關注報價動態，拉回可布局
- PCB、被動元件等低位階族群有補漲空間

### 中期（1-3 月）
- 第四季歷史上為台股上漲機率最高、平均漲幅最大的季度
- 記憶體超級大循環若持續，相關個股仍有表現空間
- Tesla 平價版量產帶動供應鏈訂單成長
- 散裝貨運第四季旺季效應可期

### 風險評估
- 美國政府關門危機持續
- 美中半導體 232 條款調查結果不確定
- 地緣政治衝突（俄烏、中東）影響原物料
- 台積電 ADR 盤前已先行反應，國內股價可能面臨整理
- 營收與財報季來臨，業績不如預期個股恐遭修正

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| DDR4/DDR5 | 雙倍資料率第四代/第五代同步動態隨機存取記憶體，用於電腦主記憶體 |
| NAND Flash | 非揮發性快閃記憶體，用於 SSD、手機儲存等 |
| Robo Taxi | 無人駕駛計程車，Tesla 規劃中的自動駕駛叫車服務 |
| FSD | Full Self-Driving，Tesla 全自動駕駛軟體套件 |
| 蓋盤 | 記憶體廠商暫停公布報價，通常暗示價格將大幅上漲 |
| BDI 指數 | 波羅的海乾散貨運指數，反映全球散裝貨運市場景氣 |
| 232 條款 | 美國貿易法第 232 條，針對進口產品是否威脅國家安全進行調查 |
| ADR | 美國存託憑證，台積電在美國上市交易的憑證 |
| 五日線 | 五日移動平均線，短線強弱分界指標 |
