## 🌍 市場總體觀察

### 超完美風暴 — 川普主導經濟衰退？

#### 野村證券報告核心觀點
- 川普正在策劃讓美國經濟進入衰退
- 透過關稅戰讓經濟減速 → 通膨趨緩 → 聯準會被迫降息
- 美元貶值有利於推行下階段經濟方案
- **一箭三雕**: 逼迫降息 + 減輕國債利息 + 美元貶值促進製造業

#### 華爾街已開始佈局「衰退交易」
- 美元正在走弱
- 黃金等避險資產持續上漲
- 銀行股與中小型股跌幅最重（對衰退最敏感）
- 科技股下跌與關稅無直接關係，主要受AI需求質疑影響

### 川普「讓美國偉大」的財政平衡大計

#### 增加收入方面
1. **對等關稅（4月2日生效）**: 對全世界課徵，包含加拿大、墨西哥同步
   - 點名印度稅率太高
   - 點名韓國稅率是美國4倍（針對三星）
   - 為美國財政帶來大量收入
2. **吸引外國投資**: 上任六週已帶來1.7兆美元新投資
   - 台積電1,000億美元
   - 蘋果從墨西哥搬回
   - 新機資門等
3. **出售金卡（移民）**: 500萬美元（約1.6億台幣）可獲美國公民身分
   - 若10萬人購買即約5,000億美元，可緩解國債
   - 美國一直是最難移民的國家，此舉打破傳統

#### 減少支出方面
1. **馬斯克DOGE效率部門**: 削減欺詐性支出（如超過100歲仍領社保的幽靈帳戶）
2. **結束俄烏戰爭**: 軍費可大幅節省
3. **減少北約支出**: 美國佔北約軍費約60%以上，要求歐洲自行承擔
4. **降低國債利息**: 美國年利息支出3,600億美元，降息1%即省3,600億
   - 比國防預算8,000多億的節省效率更高

#### 減稅承諾（先花錢再省錢的矛盾）
- 所有美國人減稅（企業、富人、窮人）
- 小費收入也減稅
- 提供公信家庭緊急救濟與即時就業

### 全球經濟格局大轉變

#### 美國：從消費大國轉型
- 過去幾十年「雙赤字」模式（外貿赤字 + 財政赤字）
- 川普要打破這個模式：不要貿易赤字、也要平衡預算
- 全球經濟運行模式將被根本改變

#### 德國：財政擴張新方向
- 新總理上任，修憲開放國防預算不受赤字比例限制
- 投資5,000億歐元改善基礎建設
- 從「財政模範生」轉向財政擴張
- 德國10年期公債殖利率3天內從2.35%跳升至2.85%（+50bp）
  - 創兩德統一以來最大跌幅
- 歐洲央行（ECB）未來可能停止降息

#### 歐美利率分歧
- 美國：可能被迫降息（經濟衰退壓力）
- 歐洲：可能停止降息（財政擴張 → 通膨壓力）
- 結果：歐元走強、美元走弱
- 資金從美國流向歐洲與亞洲

### 台積電赴美投資影響

#### 投資規模
- 1,000億美元投資，六座先進製程晶圓廠
- 40%先進製程產能將在美國
- 張忠謀強調：最先進技術仍在台灣先研發，再移至美國

#### 對投資人的影響
- **短期內不會有美積電**（獨立上市）
- 但六座廠全部蓋完後就難說了（5~10年後風險）
- 沒有補貼，生產成本大幅提高
- **重要提醒**: 以後看台積電不要只看毛利率，要看**營業利率**
  - 毛利率約57% → 預計降至52%
  - 美國成本增加很多在營業費用（人員薪資、土地、水電）
  - 營業利率比毛利率更能反映真實成本壓力
- 張忠謀承諾長期維持53%毛利率 → 成本轉嫁給客戶與供應鏈（設備、耗材）

### AI科技股下跌深層原因

#### 不是關稅問題，是AI需求信心動搖
- 中國大模型持續價格破壞：阿里巴巴通義千問QWQ推出
  - 訓練數據僅DeepSeek的1/20
  - 成本極低，免費開源
- OpenAI GPT-4.5被嫌又貴又不好用
- 10幾個大模型互殺，最終可能只剩1~2個
- 被淘汰者之前投入的巨額資本無法回收 → 股價付出代價
- AI獲利模式被受挑戰

## 💼 產業分析與投資建議

### 網友五大問

#### 第一問：台積電（2330）
- **結論**: 1,000元以下仍是地板
- 除非兩件事發生：美股走弱 或 AI需求突然消失
- 高點回來已跌約20%
- **定時定額策略**:
  - 若認為美股不會崩 → 現在多買一點（接近地板）
  - 若擔心經濟衰退 → 維持原有定時定額節奏，跌越多買越多

#### 第二問：00757（統一FANG+ ETF）
- 美國七大科技股中已有三檔進入技術面空頭定義
  - 特斯拉、輝達、會打（Meta）跌幅最大
  - 蘋果、Google跌幅最小（AI成分較低）
- **AI越多的越慘**
- 半年線買進第一批（1/3~1/4資金）
- 年線（約90元）買至一半
- 若年線又大跌可歐印
- **分批定時定額是最好策略**

#### 第三問：亞光（3009）— 機器人概念股
- 機器人概念股正在「團滅」
- 原因：漲太多、本益比太高
- 上銀（2049）財報不如預期，影響整個族群
- 亞光、上銀、台達電（大銀微）、全球傳動均跌破月線與季線
- **短線正盪時間要拉長**
- 長期機器人趨勢未變，等正盪打底後再介入
- 有機器人部位應趁反彈先跑一點

#### 第四問：鴻海（2317）— 紅海
- 2月營收創同期新高（年增動輒5成以上），廣達也超過5成年增
- **但外資不買就漲不動**
- 借券賣出高峰在2月3日後已趨緩
- 內資已先撐住（不會破底），但要等外資買進才能突破
- **觀察重點**: 外資連續買兩天以上，就是底部確認訊號
- 廣達比鴻海稍強，同樣邏輯

#### 第五問：鋼鐵人 vs 航海王 vs 散裝王

**貨櫃航運**:
- SCFI連續8週下跌，接近成本價
- 川普關稅搶運潮未出現
- 僅剩高殖利率題材，行情可能在3~5月或7~8月

**鋼鐵**:
- **大成鋼**: 美國製造題材，買就買大成鋼
- **雲鎗（豐興）**: 俄烏重建題材，在土耳其有廠，重建最快從土耳其搬東西過去
  - 25元以上未跌破就做多
  - 不幸補完缺口，反彈至27~28元反彈要買
- 鋼鐵除重建外，需求面關鍵在大陸房地產立場
- 中鋼盤價要連續三個月往上漲才是確認訊號

**散裝航運**:
- BDI指數年底以來大漲約7%
- **裕民**: 一半散貨船 + 一半合約船，BDI漲時先買它
- **四維航**: 近陽（低價股），3塊多漲到23元，最有投機性
- **慧洋**: 幾乎都是合約船，波動較小

## 📋 投資策略總結

### 總經策略
1. **關稅利空在4月2日前會充分反映**，低點可能提前出現
2. **美國經濟是否衰退為核心觀察** — CPI < 4%、失業率 < 4.5%即可
3. **全球資金大風吹** — 從美國流向歐洲、港股、亞洲
4. **德國財政擴張** — 歐洲利率上升、美國利率下降的分歧格局

### 操作建議
- **台積電**: 定時定額，跌越多買越多
- **00757**: 分批往下接，年線是重要買點
- **機器人概念股**: 趁反彈先減碼，等打底完成
- **鴻海/廣達**: 等外資回頭，目前內資撐住不破底
- **傳產（鋼鐵、散裝）**: 有基本面支撐可佈局
- **看台積電未來要看營業利率**，不要只看毛利率

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **衰退交易（Recession Trade）** | 華爾街在預期經濟衰退時的佈局策略，包括買黃金、賣銀行股等 |
| **一箭三雕** | 川普透過經濟衰退同時達成：降息、降國債利息、美元貶值三個目標 |
| **雙赤字** | 美國同時存在外貿赤字（進口大於出口）與財政赤字（支出大於收入） |
| **DOGE** | 馬斯克主導的政府效率部門，負責削減聯邦政府浪費性支出 |
| **金卡（Golden Card）** | 川普推出的500萬美元移民方案，直接獲得美國公民身分 |
| **對等關稅** | 美國對各國徵收與該國對美國相同稅率的進口關稅 |
| **營業利率（營益率）** | 營業利益除以營收，比毛利率更能反映公司含管銷費用後的真實獲利能力 |
| **DeepSeek** | 中國AI公司，推出低成本高效能的大語言模型，衝擊美國AI股估值 |
| **通義千問QWQ** | 阿里巴巴推出的AI大模型，訓練成本僅DeepSeek的1/20 |
| **SCFI** | 上海出口貨櫃運價指數 |
| **BDI** | 波羅的海乾散貨運價指數 |
