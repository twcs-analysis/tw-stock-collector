## 🌍 市場總體觀察

### 台股市況分析

#### 大盤表現
- **收盤點位**: 22,576點
- **週跌幅**: -477點
- **連續兩週累計跌幅**: -1,100多點
- **成交量**: 約3,500億元左右（量能萎縮）
- **年線位置**: 約22,210點（距收盤僅三四百點）

#### 法人動向
- **外資**: 連續9天賣超，累計近2,989億元（快3,000億元）
- **外資期貨空單**: 維持在4萬多口，未進一步增加
- **內資**: 積極承接，使台股跌幅遠小於外資賣壓力道
- **重要觀察**: 外資賣3,000億僅跌1,000點，過去類似賣壓會跌3,000點，顯示內資撐盤力道強

#### 盤面特徵
- 電子股全面躺平
- BBU概念股前一天最強，今天幾乎全回吐
- 機器人概念股也沒電
- 資金流入記憶體與鋼鐵族群
- 金控族群也受到賣壓
- 電子成交比僅64%，未回到70%

### 美股影響

#### 美股四大指數持續下跌
- **那斯達克**: 近10交易日跌1,623點，跌幅8%
- **費城半導體指數**: 跌幅15.5%，已跨入熊市定義
- 費半回測去年8月股災低點
- 費半已跌破過去四個月來的低點，有轉空疑慮

#### AI與科技股壓力
- 資金從AI硬體股撤出
- CPO、半導體設備、主裝等族群資金外流
- 國際資金短線大量流向香港股市（阿里巴巴、騰訊等中國科技股）
- DeepSeek衝擊使高估值AI股面臨價格重估
- 博通財報雖好，台股相關CPO概念股仍無反應

#### 關稅戰影響
- 川普對加拿大、墨西哥關稅反覆（一下課徵、一下暫緩）
- 4月2日對等關稅為最大利空時間點
- 市場反映不確定性持續升高
- 俄烏和談可能下週碰面，也是變數之一

## 📈 技術面分析

### 大盤技術面

#### 短期格局
- **支撐位**: 年線22,210點附近
- **壓力位**: 23,500點（盤整區高點）
- 禮拜二低點目前守住，暫時是震盪整理格局
- 年線是最後防線，跌破前不會兵敗如山倒
- 但美股、費半若持續破底，年線終將失守

#### 結論
- **三月底前沒有向上的大行情**
- 指數就是震盪整理，個股表現格局
- 台股相較美股有抗跌性，關鍵在內資撐盤
- 資金從AI撤出，轉進右下角轉機股（記憶體、圓目料）

### 台積電技術面
- 1,000元是目前地板，但有可能下移
- 台積電年線約950元
- 若台積電在950~1,000元之間震盪，大盤可能在22,000~22,500年線附近盤整

### 期貨觀察（醫痕分析）

#### 台指期三月合約
- 空方領先，二月合約漲幅已被三月吞噬
- 出現吞噬型態
- 兩個可能：
  1. **偏多情境**: 結算前收長下影線 → 反彈至23,500點
  2. **偏空情境**: 實體黑K → 四月合約還會破底

#### 美股期貨
- 上次四大契約結算在12月22日，之後空方一路佔優
- 美國結算在3月第三個禮拜五，空方可能壓到結算位置
- 台股仍有風險

#### 操作策略（整盪盤）
- 假突破 → 第二天黑K吞噬下來 → 警訊 → 反彈過不了前高 → 第二個警訊 → 做空
- 假跌破 → 出現紅吞噬 → 進場做多 → 翻一倍背離就走
- 底部不要期待爆量，量縮慢慢爬高才是健康訊號
- 現貨看錯可以用期貨避險鎖住虧損
- 期貨看錯不能熬單，直接砍掉

## 📋 投資策略總結

### 資金配置建議
1. **高殖利率股**: 佔總資金25%~33%（波計老師建議）
2. **非電族群（鋼鐵、散裝、機械、重電）**: 電子成交比<70%時操作
3. **電子股暫避**: 等美股修正到位、外資回頭再介入
4. **期貨操作**: 震盪盤做反市場（假突破做空、假跌破做多），只做短線

### 時間節點
- **4月2日前**: 關稅最大利空反映完畢，低點可能在此之前出現
- **三月底前**: 無向上大行情，震盪整理
- **觀察指標**: CPI不穿4%、失業率不穿4.5% → 經濟未衰退

### 操作原則
- 非電族群：電子成交比回到70%以上就退場
- 台股底部確認訊號：量縮慢慢添高（不是爆量反彈）
- 最先反彈的會是目前最弱勢的（半導體、電子權值股）
- 但那是最後才要買的，目前先佈局非電

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **對等關稅** | 川普政府預計4月2日實施，美國對各國徵收與對方對美國相同稅率的關稅 |
| **年線** | 240日移動平均線，通常被視為多空分界的重要技術指標 |
| **吞噬型態** | K線型態之一，後一根K線完全包住前一根，代表趨勢可能反轉 |
| **假突破/假跌破** | 價格短暫突破（或跌破）關鍵位置後又回到原區間，常是反向操作訊號 |
| **電子成交比** | 電子類股成交金額佔全市場比例，70%以上代表電子股主導盤面 |
| **SCFI** | 上海出口貨櫃運價指數，反映貨櫃航運市場行情 |
| **BDI** | 波羅的海乾散貨運價指數，反映散裝航運市場行情 |
| **殖利率** | 現金股利除以股價的比率，越高代表每投入一元可獲得越多股利 |
| **四行倉庫** | 比喻最後防線，此處指年線是台股多頭最後的支撐 |
| **二比一翻轉** | 期貨操作技巧，在假突破或假跌破出現後做反向操作的策略 |
