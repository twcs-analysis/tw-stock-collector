## 2. 市場總體觀察

### 2026 年全年展望（明哲分析）
- **第一季**：仍有高點可期，過完年回來三月份還有機會往上衝
- **第二季**：需要選股換股操作
- **第三季**：若出現年度低點，可開始逢低佈局好個股
- **第四季**：有機會再到高點
- **全年最高點**：大概率出現在第一季，因景氣角度來看，二、三、四季將逐季向下修正

### 關鍵觀點
- 即使全年高點在第一季，後面仍有操作空間 -- 重點是「買進點位」與「賣出點位」的價差
- 震盪回撤時挑好個股佈局，反而有機會抓到價差空間
- 若春節期間國際股市出現明顯回檔，反而是更好的進場機會

### 三月份季節性選股策略（明哲分析）

#### 篩選條件
1. 掛牌 10 年以上（經歷多輪景氣循環）
2. 三月份歷史上漲機率 > 70%
3. 平均上漲幅度 > 5%
4. 成交量在千張以上（確保流動性）
5. 去年前三季 EPS > 0（非虧損股）

#### 停損策略要點
- 停損不要超過該股歷史平均上漲幅度
- 例如：某股平均上漲 10%，停損就設 10% 以內
- 賺錢時不要急著全部出場，可用移動停利策略

## 4. 技術面分析與操作策略

### 高技（PCB 類股）-- 三月份重點觀察
- **歷史三月份上漲機率**：80%
- **平均上漲幅度**：10.1%
- **去年前三季 EPS**：9.52%
- **技術面**：週線圖顯示在 300-350 區間整理約 4-5 個月，目前在區間下緣
- **產業特性**：利基型高門檻 PCB，受消費性電子景氣循環影響較小
- **操作建議**：在區間相對下緣位置卡位，停損較好設定

### 操作策略框架
| 策略 | 說明 |
|------|------|
| 期望值計算 | 上漲機率 x 平均漲幅 = 期望報酬（如 80% x 10% = 8%） |
| 停損設定 | 不超過平均上漲幅度 |
| 獲利保護 | 使用移動停利，不急著全部出場 |
| 進場時機 | 若春節期間國際股市回檔，開紅盤後逢低佈局 |

## 7. 名詞解釋

| 名詞 | 說明 |
|------|------|
| 水星逆行（水逆） | 占星學概念，水星看似逆行的天文現象期間，傳統上認為溝通、交通、科技容易出問題 |
| 木星進獅子座 | 2026 年的占星大事件，木星進入獅子座帶來擴張、自信的能量 |
| 季節性選股 | 根據歷史統計，某些個股在特定月份有較高的上漲機率，據此進行選股策略 |
| 移動停利 | 隨著股價上漲，逐步調高停利點的策略，確保獲利不回吐 |
| 期望值 | 上漲機率乘以平均漲幅，用來評估投資的預期報酬 |
| 利基型 PCB | 針對特定客戶需求製作的特殊印刷電路板，受一般消費性電子景氣循環影響較小 |
| 五窮六絕 | 台股俗語，指五月、六月通常為電子股淡季，股市表現較弱 |
