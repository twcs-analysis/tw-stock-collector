## 2. 市場總體觀察

### AI 依然是 2026 年投資主旋律
- 「一代新人換舊人」-- 不是全新的 AI 股票，而是在 AI 趨勢中相對更受惠的標的
- 跟 AI 相關的股票都已經浮出水面，關鍵是找到「接下來趨勢中比較受惠」的個股
- IC 設計成為 2026 年 AI 投資亮點

### 信華（股王）觀察
- 台北股市有機會誕生第一檔萬元股票
- 信華做伺服器電源管理晶片（Power Management IC），代表 AI 需求強勁
- 股王效應將帶動 IC 設計族群的比價效應
- 股王與股后差距太大，短期內難有第二檔萬元股

### CPO（共同封裝光學）元年啟動
- 矽光子機板龍頭預估機櫃間連接的光學訂單將翻倍
- CPO 在 2028-2029 年將迎來爆發性成長
- 從「本夢比」轉向實質出貨獲利，有機會有「基之台」（估值修復）
- 符合黃仁勳談到的「光互聯」趨勢 -- 因晶片封裝越來越大，需用光線傳輸提升速度

### NVIDIA Blackwell Ruby 新架構
- 相較 GB 系列，主要變動：800V DC 電源 + 全液冷散熱
- 「一代新人換舊人」體現：過去所有散熱方案都受惠，現在必須有液冷技術才能受惠
- 800V DC 電源供應也成為新的門檻

- 近年獲利不佳導致股價在相對低檔，具備價差空間

## 4. 技術面分析與操作策略

### 高技（延續中集分析）
- 週線圖 300-350 區間整理 4-5 個月
- 目前在區間相對下緣
- 在下緣卡位，停損好設定
- 期望值：80% 機率 x 10% 漲幅 = 8%
- 停損不超過 10%

## 7. 名詞解釋

| 名詞 | 說明 |
|------|------|
| ASIC | Application-Specific Integrated Circuit，特定應用積體電路，為特定客戶或用途設計的晶片 |
| CPO | Co-Packaged Optics，共同封裝光學，將光學元件與交換晶片封裝在一起，大幅提升資料傳輸速度 |
| 矽光子 | Silicon Photonics，利用矽材料製作光學元件的技術，用於高速資料傳輸 |
| Blackwell Ruby | NVIDIA 新一代 GPU 架構，採用 800V DC 電源與全液冷散熱設計 |
| 800V DC | 800 伏特直流電源系統，新一代伺服器電源規格，效率更高 |
| 全液冷散熱 | 使用液體循環帶走晶片熱量的散熱方式，散熱效率遠高於傳統風冷 |
| CPU Socket | CPU 安裝在主機板上的連接器插座 |
| 光互聯 | 使用光線（而非傳統銅線）進行晶片間或機櫃間的資料傳輸 |
| BDI | Baltic Dry Index，波羅的海乾散貨指數，反映散裝貨運市場運價 |
| 海岬型船 | Capesize，最大型的乾散貨船，主要運送鐵礦砂與煤炭 |
| 殖利率 | 股息除以股價的比率，衡量股息投資報酬的指標 |
| 移動停利 | 隨股價上漲而逐步提高停利價格的策略，保護已實現的獲利 |
| Power Management IC | 電源管理晶片，負責電壓轉換、電源分配等功能 |
| 基之台 | 估值修復，指從本夢比回歸到基本面估值的過程 |
