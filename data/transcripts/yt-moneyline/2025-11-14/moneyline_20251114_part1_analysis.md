## 技術面分析

### 大盤技術面
- **月線**: 正式跌破，為警訊
- **關鍵支撐**: 約26,470點（前低），必須守住
- **若跌破前低**: 連續兩天六千億大量將全部套牢，恐引發「殺戮戰場」
- **多頭判斷**: 月K線本月高點已比上月高，但若跌破上月低點（約26,000）則翻空
- **量價關係**: 連兩天六千億大量黑K，半數量能被套住

### 櫃買指數
- **比大盤更弱**: 10-11月量能全被集中市場吸走
- **風險**: 可能被大盤下跌拖累回測更低區域
- **結構問題**: 成分股AI含量少（中美晶、環球晶等非AI股為主）

### 費半技術面
- **形態**: 類似頭肩頂，已出現三分之二的結構
- **風險**: 若跌破頸線，整個頭部完成，NASDAQ跌破概率極高
- **台股連動**: 美股若破底，台股會加速反應

## 策略總結

### 操作建議

1. **指數操作**: 短線偏空，不要太樂觀，期貨結算前（下週三）可能還有壓力
2. **台積電、紅海**: 甜甜價還沒到，不要急著買，等外資賣壓減緩
3. **高價股**: 下週起可能成為市場焦點，做夢行情與一線升機的指標
4. **時間判斷**: 短則一週（到期貨結算），長則兩週（外資結帳到月底）
5. **反彈後布局**: 等中小型股的資金從大型股流入，做夢行情可期

### 風險提示
- 外資連賣11天且空單水位高，短線多方不利
- 若融資開始減少，代表四方力量全部在賣，盤勢將更加嚴峻
- 台美關稅談判結果（月底前公布），零關稅為最佳情境，若非零則衝擊電子產業

## 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **頭肩頂** | 技術分析形態，由左肩、頭部、右肩構成，為反轉信號，跌破頸線確認空頭 |
| **月線** | 20日移動平均線，為中期多空分界重要指標 |
| **台指期結算** | 每月第三個週三為台指期貨結算日，結算前常有法人調整部位的壓力 |
| **借券賣出** | 法人借入股票後賣出（放空），若借券增加代表看空力道增強 |
| **本益比（P/E）** | 股價除以每股盈餘，數值越低代表越便宜（相對估值） |
| **做夢行情** | 財報公布完畢後的空窗期（約11月中至隔年1月），因無財報檢驗，題材股容易被炒作 |
| **外資結帳** | 外資法人年度績效結算，通常在11月底完成，期間會大量調節持股 |
