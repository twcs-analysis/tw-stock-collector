## 產業分析與投資建議

### 一、台積電 (2330) 兩奈米製程完勝分析

#### 產業背景
育康老師深入解析三星發布全球首款兩奈米晶片手機處理器 Exynos 2600，但實測結果顯示台積電仍然完勝：

**兩奈米製程三大廠比較**：

| 項目 | 台積電 N2 | Intel 18A | 三星 SF2 |
|------|----------|-----------|----------|
| 電晶體密度（百萬/平方毫米） | 313 | 238 | 231 |
| 良率表現 | 領先 | 停止測試 | 需將晶片獨立分離 |
| 背面供電 | A16 導入 | 18A 最早導入但良率差 | 2027年才導入 |
| 大規模量產時程 | 最早 | 幾乎無產品 | 有限 |

#### 背面供電技術（BSPDN）的關鍵意義
- 傳統架構：電源層在上方，經過訊號層到電晶體，多走一段無效路徑
- 背面供電：電源從背面直接進入電晶體，訊號從正面直接出去
- **節能效果**: 電壓降從7~8%降至2~3%，節省約5%功耗
- **商業意義**: AI工廠年電費若為1億美元，僅此一項就省500萬美元
- **客戶反應**: NVIDIA 已將 A16 產能全部包下，原因就是背面供電省電

#### 投資建議
- **台積電 (2330)**
  - 目標價: 法說會前持續看漲，樂觀看資本支出達485億美元
  - 操作策略: 盤中拉回即可買進，1月15日法說前為多頭行情
  - 本益比仍低，不論是新曆年或農曆年封關，都可投資布局

## 名詞解釋

| 名詞 | 說明 |
|------|------|
| **N2/A16** | 台積電兩奈米製程代號，A16為導入背面供電的版本 |
| **背面供電（BSPDN）** | 將電源層移至晶片背面，縮短電力傳輸路徑，降低功耗約5% |
| **SF2** | 三星兩奈米製程代號（Samsung Foundry 2nm） |
| **GAA（閘極全環）** | 先進電晶體結構，取代FinFET，三家廠商均採用 |
| **CB（可轉換公司債）** | 企業發行的債券，持有者可依約定價格轉換為公司股票 |
| **HVDC** | 高壓直流電源，AI資料中心電源架構的核心技術 |
| **BBU** | 備用電池單元（Backup Battery Unit），取代傳統UPS |
| **CPO** | 共同封裝光學（Co-Packaged Optics），光電共封裝技術 |
| **電源櫃** | AI伺服器獨立的電源供應機櫃，從機架內建式轉為獨立模組 |
| **主動式 ETF** | 由基金經理人主動選股操作的ETF，非追蹤指數的被動式 |
