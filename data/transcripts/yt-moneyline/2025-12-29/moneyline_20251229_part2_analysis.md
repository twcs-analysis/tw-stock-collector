## 市場總體觀察

### 2026年關鍵字：「缺」

進老師開宗明義指出，2026年AI產業的核心關鍵字就是「缺」（短缺）。從半導體先進製程、記憶體、先進封裝測試到PCB材料、電力設備，全線供不應求，形成系統性缺貨格局。

### 記憶體產業缺貨實況

#### 四大科技巨頭搶貨白熱化

1. **Google 採購主管被解雇** - 因未能搶到足夠的 HBM 庫存而被開除
2. **微軟高層與 SK 海力士會談破裂** - 微軟高層親赴談判要求更多 HBM 配額，SK海力士拒絕條件，微軟高層憤而離席
3. **科技巨頭採購團隊進駐原廠** - 直接派駐在三星、SK海力士、美光工廠，盯著貨源、不限價格、不限數量
4. **全球新設專職** - 各大科技公司新增「全球記憶體/HBM商品經理」或「全球採購經理」專職

#### 記憶體供需數據
- **SK海力士內部文件**: 記憶體可能到2028年才能供需平衡
- **通路商創見**: 10月份起就拿不到貨，中小品牌已買不到貨
- **東京秋葉原**: 硬碟也開始斷貨
- **美光**: 已退出消費品牌，全力專注AI記憶體
- **DDR5利潤率**: 2026年可能超越HBM（說明DDR5缺貨程度之嚴重）
- **DDR4產能**: 完全開不出來（所有產能都轉去HBM與DDR5）

### 半導體全線缺貨分析

#### 先進製程缺
- 5奈米以下極度短缺，主因AI晶片需求
- 三星與Intel的兩奈米無法實用
- 有效產能全集中在台積電
- 台積電日夜擴廠、加速擴廠，仍追不上需求暴增

#### 設備也缺
- 台積電擴廠受限於設備供應不足
- 半導體設備供應鏈也產能不足
- 「整條缺」：要擴廠→沒設備→設備廠產能也不夠

#### 先進封裝缺
- CoWoS先進封裝產能不足
- 台積電與致越光拚命擴CoWoS
- 三星也在做，但跑去日本設研發中心、進度太慢
- Intel的先進製程都顧不了，更難顧先進封裝

#### 先進測試缺
- AI晶片單價高、測試需求暴增
- HBM晶片測試時間遠高於一般記憶體
- 系統級測試（SLT）成為必備需求
- 京元電連續擴產，日月光也在擴產

#### 高階PCB/銅箔基板缺
- AI伺服器銅箔基板層數高（20~30層以上甚至40~50層）
- 操作難度高，需要雷射鑽孔、肩點等高端技術
- 材料需升級（銅箔、玻纖布都需升級）
- 認證需要時間，擴廠跟不上需求

#### 電力設備缺
- AI伺服器耗電量為傳統伺服器的3~5倍
- 超大型資料中心全面擴建
- 單一AI訓練耗能約百萬家庭用電量
- 核電、燃料電池需求暴增
- 散熱需求暴增
- 節能技術（金敗供電降壓）成為主流

## 產業分析與投資建議

### 一、記憶體族群

#### 南亞科 (2408)
- **題材**: DDR5與低功耗LPDDR需求暴增，獲利能力提升
- **技術面**: 創新高後回檔空間有限（從188元僅回到175元），平台突破
- **操作策略**: 以5日線做積極操作，10日線做穩健操作，不破即持有
- **停損點**: 5日線（積極）/ 10日線（穩健）

#### 華邦電 (2344)
- **題材**: 擴產投資351.5億元資本支出，看3~5年基礎需求
- **技術面**: 創新高後黏在高檔不拉回，75元不破即續抱
- **操作策略**: 75元以上持續創新高可能性高
- **停損點**: 75元

#### 力積電 (6770)
- **題材**: 第四季爆發開始上漲，每半/美光找它代工（自身產能不夠）
- **技術面**: 38~39元缺口支撐穩固，整理後有機會再創高
- **操作策略**: 缺口不破即持有
- **停損點**: 38元

#### 群聯 (8299)
- **題材**: 威剛創高後輪動標的，距前高1,390元（今日1,340元）
- **技術面**: 歷史前高容易過（高股息ETF不再調節壓力消除）
- **操作策略**: 站在買方，5日線與10日線不破即持有
- **預期**: 過前高後看萬里無雲
- **停損點**: 10日線

### 二、PCB族群

#### 復甲
- **題材**: 台光電供應商，挑戰百元大關
- **技術面**: 98.8元逼近百元，90~95元支撐強勁
- **操作策略**: 拉回到90~95元區間買進，創新高容易有短線調節
- **停損點**: 90元

#### 德紅
- **題材**: M8升M9材質（波纖布→執行部），台灣獨家
- **漲幅**: 年內漲幅超過700%
- **技術面**: 直接過百元大關頭也不回
- **操作策略**: 波段持有以10日線操作，短線用5日線；創新高不追，拉回再買
- **停損點**: 10日線（波段）/ 5日線（短線）

#### 建勇
- **題材**: 母公司為日東紡（全球最大高級AI玻纖布製造商），明年AI比重拉到七成
- **籌碼**: 接近五成在日東紡手上
- **技術面**: 剛創新高，量不大
- **操作策略**: 沒有爆量之前都可以追，明天若量不大仍可進場
- **停損點**: 前波低點

### 三、封測設備族群

#### 以為（鷹為 / 6515）
- **題材**: 全球第一大測試座供應商，客戶87%做ASPC/SSK/GPU/CPU
- **股價**: 2,775元（盤中一度觸及3,000元）
- **關鍵數據**:
  - 測試座需求成長5~10倍
  - 87%用在5奈米以下先進製程
  - 推出3,500瓦測試解決方案（從2,000瓦升級）
  - 進入1.6T高速傳輸時代需雙邊探測（光電同測）
- **操作策略**: 長線發展方向肯定還會漲，但短線3,000元有壓
- **停損點**: 長線持有不設嚴格停損

#### 精測 (6510)
- **題材**: 從PCB跨入探針卡製作，高頻高密度大電流測試技術突破
- **合作**: 與日本彈簧大廠有花科技相互投資
- **訂單**:
  - SpaceX 10年長約（2017年簽約）
  - 傳聞接到 Blackwell 與 TPU 測試訂單
  - 傳聞特斯拉 AI5 自研晶片（透過創意合作）
  - 透過聯發科切入 TPU 供應鏈
- **技術優勢**: PCB精密度達業界最高，提供一站式服務
- **法說樂觀展望**: 緊急啟用新廠，桃園評審三廠也要派上用場
- **操作策略**: 先操作精測與鷹為，待旺矽第一季展望修正後再操作旺矽
- **停損點**: 前波低點

#### 新日光（薪日光 / 興櫃）
- **題材**: AOI（自動光學檢測）結合AI視覺判讀
- **創辦人**: 林昏喜博士（前台積電資深副總經理）
- **技術**:
  - AI視覺判讀通過美國FDA 510K核準（醫療廢牙檢測）
  - 半導體先進製程AOI檢測
  - 深度學習自動化智能解決方案
- **上市進度**: 10~11月通過證交所審議，預計數月內掛牌上市
- **股價**: 盤中一度觸及800元
- **操作策略**: 不硬追高，拉回慢慢以零股布局
- **停損點**: 興櫃股流動性低，零股分批操作

### 四、2026年風險與黑天鵝分析

#### 大摩（Morgan Stanley）三大黑天鵝

1. **生產力繁榮（正面黑天鵝）**
   - AI帶動生產力提升但失業率不降
   - 通膨下行但經濟成長
   - 可能造成股市快速上漲後泡沫擔憂又快速下跌，雙向波動加劇

2. **股債關係翻轉**
   - 今年股債雙漲（降息環境），明年可能回到股債蹺蹺板
   - 若新任聯準會主席偏鷹派（如瓦許），可能停止降息甚至縮表
   - 瓦許35歲就當理事，對QE非常反感

3. **原物料與能源暴漲**
   - 美元貶值→資金流入通膨避險→原物料暴漲
   - 同時經濟回暖推升需求

#### 德意志銀行（Deutsche Bank）風險清單

| 風險項目 | 發生機率評估 | 說明 |
|---------|------------|------|
| 生產力帶動的繁榮 | 可能 | AI經濟下通膨控制、生產力提升 |
| 標普上漲17% | 中偏高 | 美股多頭年平均漲15~20% |
| 聯準會激進降息助力軟著陸 | 低 | 川普聯準會主席人選一直拖 |
| 貿易休戰與關稅減免 | 中偏高 | 關稅實際收入低於預期，雷聲大雨點小 |
| 歐洲改革成功 | 低 | 地緣風險不太會消退 |
| 聯準會被迫重啟升息 | 2026年低/2027年可能 | 若油價暴漲帶動通膨回升 |
| AI泡沫破裂 | 低 | 基本面仍實，降息週期中不易破裂 |
| 主權債務危機 | 低 | 違約機會低，但印鈔擋債務可能 |
| 歐洲政治經濟危機共振 | 中 | 認同此風險 |

#### 2026年資金流向觀察重點

1. **美元走勢**
   - 目前在100附近，若破底則弱勢確認→資金流入亞洲
   - 若守住100反彈→風險資產資金可能撤退
   - 關鍵：新任聯準會主席是誰（若瓦許上任，美元可能反彈）

2. **長期利率**
   - 若利率曲線正常化（長率走升），股優於債
   - 銀行股受惠（長短利差擴大）
   - 經濟仍向好

3. **日圓走勢**
   - 已回到2024年8月台股跌停的水平附近
   - 日本央行若升息→套利交易平倉→風險資產資金退潮
   - 日本財政（安倍經濟學寬鬆）與央行（升息）矛盾

4. **油價走勢**（最關鍵警示指標）
   - 若油價快速往上→通膨起來→聯準會轉鷹→泡沫提早
   - 歷史參照：2007年油價暴漲 → 2008年崩盤
   - 油價穩定偏弱 = 明年無事；油價序漲 = 2027年有事

## 技術面分析與操作策略

### 記憶體族群技術面
- **輪動結構**: 南亞科、華邦電先創高→休息→威剛、群聯接力創高
- **核心邏輯**: 外資怎麼賣都賣不下來，投信怎麼賣也賣不下來
- **美光**: 也創歷史新高，確認全球記憶體多頭格局
- **操作原則**: 沒有出現明顯敗象前，波段持有不放手

### PCB族群技術面
- **台波與南響**: 有傳統產品拖累，攻擊力較弱
- **優先順序**: 德紅 > 建勇 > 復甲
- **共同特徵**: 拉回不深、量縮整理後再攻

### 封測設備技術面
- **操作順序**: 精測、鷹為先操作 → 旺矽等第一季修正後再介入
- **三檔聯動性大**: 一漲三漲，波段操作

## 投資策略總結

### 缺貨受惠三大主軸

| 主軸 | 缺貨品項 | 核心標的 | 操作優先度 |
|------|---------|---------|-----------|
| 記憶體 | HBM、DDR5、DDR4 | 南亞科、華邦電、群聯、力積電 | 最高 |
| 先進封測 | CoWoS封裝、高階測試 | 精測、鷹為（以為）、旺矽 | 高 |
| 高階PCB | 銅箔基板、玻纖布 | 德紅、建勇、復甲 | 高 |

### 風險管理
- 2026年操作難度比2025年更高（雙向波動加劇）
- 重點觀察：聯準會新主席人選、美元走勢、油價走勢、日圓動向
- 1月第一週或第二週即可能公布聯準會主席人選，為明年第一個關鍵變數

## 名詞解釋

| 名詞 | 說明 |
|------|------|
| **HBM** | 高頻寬記憶體（High Bandwidth Memory），AI晶片必備的記憶體，目前全球嚴重短缺 |
| **DDR5** | 第五代雙倍資料率記憶體，AI伺服器與企業級SSD的標準配備 |
| **CoWoS** | 台積電先進封裝技術（Chip on Wafer on Substrate），將多顆晶片整合在一起 |
| **SLT** | 系統級測試（System Level Test），AI晶片必備的測試環節 |
| **ABF載板** | Ajinomoto Build-up Film 載板，高階IC封裝基板 |
| **探針卡** | 晶圓測試時用於接觸晶片的測試工具，高階探針卡技術門檻極高 |
| **AOI** | 自動光學檢測（Automated Optical Inspection），用機器視覺進行品質檢測 |
| **套利交易（Carry Trade）** | 借入低利率貨幣（如日圓）投資高利率資產的交易策略 |
| **QE** | 量化寬鬆（Quantitative Easing），央行購買債券注入流動性 |
| **主權債務危機** | 國家政府債務過高導致的信用危機或違約風險 |
