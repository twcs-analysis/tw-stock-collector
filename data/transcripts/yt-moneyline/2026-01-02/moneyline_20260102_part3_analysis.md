## 📈 技術面分析與操作策略

### 傳產族群展望

#### 一、機器人
- **協作型機器人**: CAGR 30%（優於人型機器人的16~17%）
- **量更大**: 廣泛用於工廠與特殊領域
- **觀察**: 關稅落地後工具機族群有望回升

#### 二、特化（半導體材料）
- **特性**: 與設備不同，設備是建廠時需要，特化是有生產就需要
- **驅動力**: 台積電持續擴大國內供應鏈採購比率
- **需求**: 先進製程放量 → 特化需求持續增加

#### 三、重電
- **邏輯**: 有算力就有國力，但沒電力就沒算力
- **台灣重電**: 海外市場（特別是美國）業績成長顯著
- **代表個股**: 華城（海外市場明顯成長）
- **全球趨勢**: 不只台灣缺電，美國更缺

#### 四、金融
- **防禦特性**: 市場震盪時的避風港
- **高殖利率**: 金融指數封關時已創新高
- **獲利創高**: 大型金控2025年獲利幾乎都創新高
- **估值偏低**: 相較電子股，金融股股價仍偏低
- **壽險新制**: IFRS 17讓壽險追逐高股息股

#### 五、生技
- **催化劑**: 再生醫療法落地
- **關鍵條款**: 完成臨床二期+驗證安全性後，可申請5年暫時許可證（不需三期驗證）
- **適用條件**: 疾病為危及生命或嚴重失能
- **第一輪受惠**: 仲人、國璽、長聖

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **砷化鎵（GaAs）** | 化合物半導體材料，用於製作PA（功率放大器），高頻傳輸效率佳 |
| **磷化銦（InP）** | 化合物半導體材料，用於製作光通訊雷射探測器，電轉光的關鍵材料 |
| **PA（Power Amplifier）** | 功率放大器，手機/Wi-Fi/衛星通訊中負責放大訊號的元件 |
| **EML（Electro-absorption Modulated Laser）** | 電吸收調變雷射，用於資料中心間長距離光通訊 |
| **VCSEL** | 垂直共振腔面射型雷射，用於短距離傳輸（如手機刷臉） |
| **OCS（Optical Circuit Switch）** | 光學電路交換器，Google自研技術現開放外部供應商 |
| **協作型機器人** | 可與人類安全共同工作的機器人，CAGR 30%高於人型機器人 |
| **再生醫療法** | 台灣新立法框架，允許完成二期臨床試驗後取得5年暫時許可證銷售 |
| **IFRS 17** | 國際財務報導準則第17號，壽險業新會計制度，影響投資收益認列方式 |
| **GB200/GB300** | 輝達Blackwell世代AI晶片平台，GB300為升級版 |
