### 月線天量選股法（核心教學）

#### 操作步驟
1. 找出五年內月線級別天量的月份
2. 標記該月的高低點
3. **突破天量高點** + 帶12個月均量 → **長線底部完成**
4. **上攻過程** 需夾帶60個月（5年）均量 → **主升段持續**
5. 每日只需盯成交量是否維持均量水準

#### 量能觀察公式
- 每日所需量 = 月均量 ÷ 20個交易日
- 鴻海：105萬張 ÷ 20 = 每日5.25萬張
- 華通：38萬張 ÷ 20 = 每日約1.9萬張

## 📚 名詞解釋

| 名詞 | 解釋 |
|-----|------|
| **CPO（Co-Packaged Optics）** | 共封裝光學，將光學元件與GPU緊密封裝在同一基板上，縮短傳輸距離並降低能耗 |
| **矽光子（Silicon Photonics）** | 利用矽基材料製造光學元件的技術，是AI資料中心高速傳輸的關鍵 |
| **月線天量法** | 技術分析方法，透過觀察月K線五年內最大成交量位置，判斷法人籌碼集中區與長線支撐壓力 |
| **本益比（P/E Ratio）** | 股價除以每股盈餘，衡量估值高低。大盤平均約22-23倍 |
| **VIX恐慌指數** | 反映市場對未來30天恐慌預期，低於20安穩，高於30恐慌 |
| **BPU（Battery Power Unit）** | 備用電源模組，AI伺服器機櫃關鍵備援設備 |
| **ODM直供** | 原始設計製造商跳過品牌廠，直接對接終端客戶的商業模式 |
| **CSP（Cloud Service Provider）** | 雲端服務供應商，指Google、Amazon、Microsoft、Meta四大巨頭 |
| **AI泡沫** | AI企業估值遠超實際獲利，科技巨頭間互相投資形成內循環 |
| **穩定幣（Stablecoin）** | 與法定貨幣1:1掛鉤的加密貨幣，發行量越大對美國公債買盤越多 |
| **深層政府（Deep State）** | 聯邦機構中不執行總統政策的官僚體系 |
| **川普綠卡（Trump Gold Card）** | 每張500萬美元的投資移民方案，目標發售100萬張 |
| **CFD（差價合約）** | 不持有實際資產，純做價差交易的衍生性商品，可多空雙向操作 |
| **MACD** | 移動平均收斂擴散指標，判斷股價趨勢方向的技術指標 |
| **Put/Call Ratio** | 賣權與買權成交量比值，下降代表市場偏空 |
| **左側交易** | 在股價尚未確認底部前提前買進的策略 |
| **80 PLUS Ruby** | 電源供應器最高效能認證，轉換效率達96.5%以上 |
| **FAU（Fiber Array Unit）** | 光纖真列，用於資料中心光纖連接 |
| **Scale-out / Scale-up** | Scale-out為跨機房互連；Scale-up為提升單一伺服器效能 |
