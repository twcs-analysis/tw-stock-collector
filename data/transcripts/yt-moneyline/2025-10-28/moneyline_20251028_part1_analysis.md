### 五、AI伺服器組裝股 - 月線天量觀察法

#### 月線天量選股方法（郡顏教學）
- **五年內月線天量高點** → 法人籌碼集中的價格區間
- **突破天量高點** → 需帶12個月均量 → 長線底部完成
- **跌破天量低點** → 法人籌碼棄守
- **上攻過程** → 需夾帶60個月（5年）均量
- **每日觀察** → 成交量是否維持60個月均量水準

#### 三大組裝股分析

| 股票代號 | 公司名稱 | 股價 | 外資目標價 | 月線天量觀察價位 | 當前狀態 |
|---------|---------|------|-----------|----------------|---------|
| 2317 | 鴻海 | ~250元 | 高盛喊400元 | 157.5元（已穩過） | 長線底部完成，主升段展現，300元為下一壓力，過300元有機會挑戰400元 |
| 2382 | 廣達 | 304元 | 外資目標價400-425元 | 已穩站上 | 長線底部完成，主升段展現 |
| 3231 | 緯創 | ~161.5元附近 | 外資目標價210元 | 161.5元（本月突破中） | 需持續觀察月成交量是否維持5年均量水準 |

**鴻海操作重點**:
- 每日觀察預估成交量是否達5.25萬張（60個月均量÷20個交易日）
- 今日成交量7.2萬張，量能充足，主升段未結束
- 過300元且夾帶5年均量 → 300元變長線底部 → 再談400元目標

**緯創操作重點**:
- 每月觀察成交量是否維持5年均量水準
- 突破161.5元後，若量能持續 → 不會是壓力，持續往上
- 量縮人氣退 → 終極無力

## 📚 名詞解釋

| 名詞 | 解釋 |
|-----|------|
| **CPO（Co-Packaged Optics）** | 共封裝光學，將光學元件與GPU緊密封裝在同一基板上，縮短傳輸距離並降低能耗 |
| **矽光子（Silicon Photonics）** | 利用矽基材料製造光學元件的技術，是AI資料中心高速傳輸的關鍵技術 |
| **GTC DC大會** | NVIDIA舉辦的GPU技術大會（資料中心版），發布最新AI產品與技術路線圖 |
| **月線天量** | 月K線級別中五年內最大成交量的月份，代表法人籌碼集中的價格區間 |
| **FAU（Fiber Array Unit）** | 光纖真列，波若威的核心產品，用於資料中心光纖連接 |
| **ELAS（External Laser Source）** | 外部雷射光源，CPO技術中的關鍵零組件，核聖科技主力產品 |
| **CFD（Contract for Difference）** | 差價合約，一種衍生性金融商品，買賣雙方交換標的資產的價差，不涉及實際資產轉移 |
| **騰落指標** | 統計上漲與下跌家數的比例，用於判斷多頭行情的廣度與健康程度 |
| **IP授權** | 智慧財產權授權，將技術設計以授權方式提供給其他公司使用 |
| **Scale-out / Scale-up** | Scale-out為跨建築/機房的資料中心互連；Scale-up為提升單一伺服器或GPU的運算效能 |
