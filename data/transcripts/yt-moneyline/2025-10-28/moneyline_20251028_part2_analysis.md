### 月線天量法延伸應用（蘋果概念股）

#### 華通（2313）操作要點
- 月天量觀察位已突破
- 每日預估量需維持2萬張以上
- 量能衰退 → 警覺；跌至關鍵價位且量衰退 → 出場

#### 量能觀察公式
- **鴻海**: 月均量105萬張 ÷ 20日 = 每日5.25萬張

## 📚 名詞解釋

| 名詞 | 解釋 |
|-----|------|
| **BPU（Battery Power Unit）** | 備用電源模組，AI伺服器機櫃中的關鍵電源備援設備，確保停電時資料不遺失 |
| **ODM直供（Direct Model）** | 原始設計製造商跳過品牌廠，直接對接系統整合商或終端客戶的商業模式 |
| **80 PLUS Ruby** | 電源供應器效能認證等級，要求轉換效率達96.5%以上，為最高等級之一 |
| **Alow 10/11/12** | AI伺服器的不同整合層級，數字越大越接近完整資料中心規模 |
| **GB200/GB300/VR200** | NVIDIA不同世代的AI伺服器平台，VR200為下一世代產品 |
| **CSP（Cloud Service Provider）** | 雲端服務供應商，指Google、Amazon、Microsoft、Meta四大巨頭 |
| **月線天量法** | 技術分析方法，透過觀察月K線五年內最大成交量的位置，判斷法人籌碼集中區與長線支撐壓力 |
| **KW（千瓦）** | 電源供應器的功率單位，AI伺服器從5.5KW升級至12-18KW甚至3.3KW |
