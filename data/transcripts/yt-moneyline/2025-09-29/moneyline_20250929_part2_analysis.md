## 📊 市場總體觀察

### 十月份歷史統計

- **上漲機率**: 過去約30年統計，十月份上漲機率為58%（高於五五波）
- **平均漲跌幅**: 約跌1.6%（意味著漲的次數多但跌的時候跌幅大）
- **核心結論**: 「贏了面子，輸了裡子」—上漲機率高，但平均漲跌為負
- **策略意涵**: 若十月份出現明顯回檔，反而是佈局第四季的良機

### 第四季選股條件（名哲統計模型）

名哲以四大條件篩選歷史上第四季最會漲的個股：

| 條件 | 內容 |
|------|------|
| **1. 掛牌年限** | 上市超過10年以上（樣本數夠大） |
| **2. 上漲機率** | 過往第四季上漲機率大於70% |
| **3. 平均漲幅** | 掛牌以來第四季平均上漲幅度大於5% |
| **4. 營收成長** | 前8個月營收較去年同期成長（非衰退公司） |

另外附加條件：成交量大於1,000張，確保有足夠流動性。

## 💼 產業分析與投資建議

### 一、半導體上游（先進製程材料）

#### 產業趨勢
- 台積電持續擴建先進製程廠房，需要在地化供應鏈
- 不論建在美國、日本或台灣，都優先尋找當地供應商
- 半導體材料單價遠高於面板材料，帶動毛利率提升

#### 篩選結果（半導體類）

| 個股 | 第四季上漲機率 | 平均漲幅 | 前8月營收成長 |
|------|-------------|---------|-------------|
| **弘塑 (3131)** | 78.6% | **19.2%（最大）** | 成長 |
| **漢唐 (2404)** | 77.8% | 零板（穩定漲） | 四成以上 |
| **達興材料 (5765)** | 79% | 零板（穩定漲） | 四成以上 |
| **世界先進 (5347)** | 70.4% | 零板（穩定漲） | 成長 |

#### 推薦個股

**1. 達興材料 (5765)** -- 半導體特化材料轉型股

- **公司背景**: 原以面板新型感光性化學材料為主，近年積極轉型半導體材料
- **半導體營收佔比**:
  - 2024年Q1：僅6.7%
  - 2025年Q2：已達16.1%（大幅成長）
  - 2025年全年預估：達20%
  - Q3財報出來後數字將持續走高
- **毛利率趨勢**: 從35.2%成長至40.73%，往四成邁進（半導體材料單價較高推升）
- **新產品**: 目前有半導體材料產品在量產中，下半年再新增2-3項產品多量產
- **新廠產能**: 中港新廠產能上限9條新產線
- **EPS預估**: 今年約7元，年增率約20%；明年有機會挑戰一個股本（10元）
- **同業比較**: 新英材料、南保樹脂、台特化等特化股本益比都偏高，市場看的是成長動能
- **技術面**: 股價長多後回檔整理，大量築底位置明確
  - 支撐位：季線/月線附近
  - 觀察點：10月上旬結束前月均線能否翻揚
- **操作建議**: 月均線之上可佈局，等待月均線翻揚確認攻擊訊號
- **目標價**: 挑戰前波高點
- **停損點**: 大量築底區下緣

### 二、AI伺服器族群（機殼/散熱）

**2. 勤誠 (8210)** -- AI伺服器機殼供應商

- **產品**: 伺服器機殼（含散熱），主要供應GB300機殼
- **客戶**: 輝達（NVIDIA）、美系一線大廠
- **競爭地位**: 主要供應商（非第二供應鏈）
- **新產品**: 降噪機櫃，上半年已小量出貨，預期下半年放量延續至明年
- **CSP投資趨勢**: 業者擔心的不是過度投資，而是「沒有投資結果在產業競爭中落敗」
- **EPS預估**: 今年約20元，明年達31元（高速成長）
- **本益比**: 目前股價約660元，以明年EPS 30元計算約22倍，不算特別高
- **第四季上漲機率**: 前8月營收成長四成以上
- **技術面**: 股價走勢「有趨勢但沒有動能」
  - 趨勢方向：往上
  - 動能：偏弱（量能不足）
- **操作策略**（二擇一）:
  1. **趨勢交易**: 在上升趨勢下緣尋求買點
  2. **動能交易**: 等出現明顯增量搭配攻擊紅K棒，代表動能轉強再進場追買
- **目標價**: 以明年3個股本（約930元）為參考估值區間
- **停損點**: 上升趨勢線跌破

### 三、傳產 -- 航空股（第四季連假旅遊概念）

#### 產業背景
- 第四季連假密集（中秋、雙十、年底），刺激出國旅遊需求
- 補發現金（政府消費振興）+ 台幣維持強勢 → 旅遊需求增加
- 航空燃油價格：7-8月約86美元，今年全年預估約83美元，Q2約81美元（去年95元），對航空業有利

**3. 華航 (2610)** -- 航空龍頭

- **第四季上漲機率**: 78.1%
- **平均上漲幅度**: 統計數據中最大
- **特殊題材**: 鳳凰城（亞利桑那州）有直飛航班，因台積電設廠帶動商務客需求
- **機型**: 使用空巴機型，亞洲首家直飛
- **技術面**: 股價在低檔區間整理
  - 過去幾年低點約20元，目前價格與歷史低點差距不大
  - 長線位於低檔區
- **操作建議**: 長線低檔佈局，可拉長持有時間
- **目標價**: 突破區間整理上緣
- **停損點**: 20元歷史低點
- **補充**: 長榮航各項條件也符合（僅前8月營收微幅負成長），股性較華航活潑

### 四、電子其他（集團股/作帳概念）

**4. 宏大電 -- 集團作帳概念股**

- **背景**: 雖基本面非頂尖，但歷史統計第四季上漲機率高
- **可能題材**: AI眼鏡概念、集團年底作帳
- **技術面**: 8月中噴出後開始休息，目前處於下跌修正階段
  - 漲的時候不給上車機會
  - 跌的時候也沒有反彈空間
- **操作建議**: 等待橫向整理訊號出現（約需2週），出現橫盤後可留意攻擊點
- **目標價**: 前波噴出高點
- **停損點**: 橫盤整理區下緣

## 📋 投資策略總結

### 統計選股核心邏輯
1. **相信數學**: 以30年以上的歷史數據為基礎，排除主觀判斷
2. **機率優勢**: 選擇第四季上漲機率超過70%的個股，提高勝率
3. **搭配成長**: 前8個月營收正成長，確認公司非衰退狀態
4. **技術確認**: 統計面符合後，再以技術面決定進出場時機

### 各族群佈局優先順序

| 優先度 | 族群 | 代表個股 | 理由 |
|-------|------|---------|------|
| **最高** | 半導體材料 | 達興材料 (5765) | 轉型題材+毛利率提升+台積電在地化供應鏈 |
| **高** | AI伺服器機殼 | 勤誠 (8210) | CSP資本支出持續擴大，GB300主要供應商 |
| **中** | 航空 | 華航 (2610) | 長線低檔+連假旅遊+燃油成本有利 |
| **觀望** | 集團作帳 | 宏大電 | 需等待技術面確認 |

### 風險評估
- **統計風險**: 十月份上漲機率58%但平均漲跌為負（跌大於漲）
- **個股風險**: 部分個股短線漲多需消化，切勿追高
- **時機風險**: 十月上旬為營收公布期，數據不如預期恐造成賣壓

## 📚 名詞解釋

| 名詞 | 說明 |
|-----|------|
| **特化材料** | 特殊用途化學材料，如半導體製程用感光材料，技術門檻高、單價高 |
| **在地化供應鏈** | 台積電在設廠地點優先採用當地供應商的策略，降低物流成本與供應風險 |
| **毛利率** | （營收-營業成本）÷ 營收，反映公司產品的附加價值 |
| **合約負債** | 公司已收取客戶預付款但尚未交付產品的金額，為營收領先指標 |
| **CSP** | Cloud Service Provider（雲端服務供應商），如AWS、Azure、GCP、Meta |
| **GB300** | NVIDIA下一代AI伺服器平台，需要大量機殼、散熱與電源模組 |
| **集團作帳** | 年底時集團公司透過內部交易或業績調整，美化年度財報的行為 |
| **金銀比** | 黃金價格除以白銀價格的比值，用於判斷貴金屬間的相對價值 |
| **空巴** | Airbus（空中巴士），歐洲飛機製造商 |
| **機殼** | 伺服器外殼結構，含散熱設計，AI伺服器因高功耗對機殼要求更高 |
