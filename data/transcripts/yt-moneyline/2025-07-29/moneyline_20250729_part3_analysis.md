## 📊 市場總體觀察

### 併購（M&A）成為助漲神器
- 近期多檔個股因併購題材股價大漲
- 併購直接帶入營收、客戶與資源，是最暴力的營收提升方式
- 併購行情通常分兩波：第一波消息面推升，第二波營收實際貢獻時再次推升
- 典型案例：志同 (3553) 2023年併購軟體廠後，營收季季成長，6月起至今股價漲65%

### 傳產鋼鐵股異動
- 鋼鐵族群近期開始資金流入
- 中國官方發出紅頭文件要求鋼鐵業「反內捲」（7/15）
- 中國鐵礦砂港口庫存年增率下降 → 鐵礦砂價格上漲 → 熱壓鋼報價上漲
- 7/15中國「崗路上不江水電工程」開工（發電量為三峽三倍，投資金額五倍）

### 盤後重大消息
- **鴻海 (2317) + 東元 (1504)**: 同時宣布7/30暫停交易（重大訊息待公布）

#### 志同 (3553) - 併購典範
- **併購標的**: 2023年以44.5億元併購AIP
- **營收貢獻**: AIP每年營收37.49億元
- **效果**: 併購後營收季季成長，股價從102元漲至今（漲幅65%+）
- **啟示**: 併購對的公司 → 營收進來 → 市場認同 → 股價持續創高

#### 金層科 / 精層科 - PCB併購受惠股
- 以84億元併購日本PCB，每年營收貢獻132億元（超值）
- **營收表現**: 六月營收年增53.8%，上半年累積年增55%
- 今年以來股價漲95%
- **收盤價**: 120.5元
- **操作策略**: 沿五日線操作，外資持續分批買入，雙法人加持
- **停損點**: 五日均線跌破（約3%跌幅為警訊）

#### 偉訓 (3039) - 併購跨入消費性/車用電子
- 併購AIP切入消費性及車用電子
- **營收**: 七月份營收併入，預期大幅增長
- **技術面**: 仍在五日線之上，多頭趨勢未改
- **操作策略**: 等營收數字公布後再評估續航力

#### 洪輝 (宏輝 (1120)) - 併購FDK取得稀土資源 ★新發掘★
- **大股東**: 第一大股東華新科技、第二大股東光寶科
- **併購標的**: 今年Q1公開收購日本FDK（富士通旗下子公司）45%股權
- **FDK核心業務**: 電池、電源模組、能源儲存系統
- **FDK年營收**: 649億日元（約130億台幣）
- **併購金額**: 44.4億台幣

**三大投資亮點**:

1. **營收暴增**: 原本年營收約20億，併購後增加58.5億（45%持股按比例），年增率望達242%
2. **鎳氫電池全球市佔第一**: FDK的鎳氫電池全球市佔第一，安全性高於鋰電池（不起火），可用於電動車
3. **稀土資源概念**: FDK早在2001年在內蒙古包頭（中國最大稀土產區）設立子公司，持有包頭富士電池化學90.4%股權。間接掌握稀土關鍵材料供應鏈

**稀土題材加持**:
- 美國唯一商業化稀土生產公司MP Materials：7月拿到美國國安部訂單，又與蘋果簽供應協議，月漲幅超過90%
- 稀土為戰略資源，AI、軍事設備、電動車、尖端科技皆需要

**光寶科連結**: 光寶科Q3開始出BPU，FDK有電池技術 → 協同效應

- **收盤價**: 約37~38元（連漲兩根漲停板後）
- **技術面**: 昨天量2,500張，今天量8,000張，隔日沖已在今日被洗掉
- **操作策略**: 短線連漲兩根漲停板後勿追，等正常休息後在月線（37.5元）附近布局
- **目標價**: 參考金層科併購後漲幅模式，等營收實際貢獻後評估（中線看好）
- **停損點**: 月線（37.5元）跌破

## 📈 技術面分析與操作策略

### 併購股操作法則
1. **第一波（消息面）**: 宣布後先漲一波，短線獲利了結
2. **整理期**: 等股價正常休息回到合理價位
3. **第二波（基本面）**: 營收實際併入後，基本面改善推動第二波漲勢
4. 操作核心：不追第一波高點，等第二波營收驗證

### 鋼鐵股操作法則
1. 短線看三個月應沒問題（反內捲政策+基建需求）
2. 長線需觀察關稅戰對消費需求的衝擊
3. 美蓋股（大成鋼）受關稅影響最小，優先布局
4. 中鋼/中鴻以底部為多空分界，反彈到月線/年線為第一壓力

### 大盤操作策略
- 關稅公布前：區間整理，不追高不殺低
- 不安定籌碼已經過換手，有利不確定因素消除後向上
- 美國科技股仍強，AI應用持續擴大
- 重點觀察：PCB上游、BPU、關稅抵禦力強的個股

## 📋 投資策略總結

### 核心策略
1. **併購股找第二波行情**: 不追已漲的第一波，等營收實質貢獻再布局（洪輝為新發掘標的）
2. **鋼鐵傳產短多**: 中國反內捲+基建需求，短線三個月正向看待
3. **美蓋股避險**: 大成鋼為關稅環境下最佳傳產避風港
4. **關稅底定後方向明確**: 指標股（金居、AES、新勝利）若突破前高，將帶動族群上攻

### 佈局優先順序
1. **第一順位**: BPU族群（AES、新勝力）— 新題材+起漲段
2. **第二順位**: 併購新標的（洪輝）— 等拉回再布局
3. **第三順位**: 美蓋鋼鐵（大成鋼）— 關稅避險+價格上行
4. **第四順位**: PCB族群（新興、台光電）— 中線偏多但短線追高風險

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **併購（M&A）** | 合併與收購，透過收購其他公司快速擴大營收與市場版圖 |
| **稀土** | 17種稀有金屬元素的統稱，為AI晶片、電動車、軍事設備關鍵原材料 |
| **FDK** | 富士通旗下電池子公司，鎳氫電池全球市佔第一 |
| **鎳氫電池** | 以鎳和氫為主要材料的充電電池，安全性高於鋰電池（不起火） |
| **反內捲** | 中國官方政策用語，限制產業惡性價格競爭，維護市場秩序 |
| **美蓋股** | 在美國設有生產基地的台灣企業，可規避美國進口關稅 |
| **熱壓鋼/熱軋鋼** | 高溫軋延成型的鋼材，為鋼鐵產業主要產品之一 |
| **黃金交叉** | 短期均線由下向上穿越長期均線，為技術面多方訊號 |
| **公開收購** | 在公開市場以特定價格收購目標公司股權的併購方式 |
