## 💼 產業分析與投資建議

### 策略一：關稅若不如預期（拉回買點）

#### 台積電 (2330)
- **收盤價**: 約1,125元（盤中最低）
- **投資邏輯**: 2奈米良率持續提升，訂案數量比前代更多，美國廠加速進行，爆發力將超越3奈米
- **技術面**: 今日一度跌破十日均線，但未碰月線即收上影線，籌碼面非常安定
- **操作策略**: 靠近月線附近為絕佳買點；1,160元兩度碰到未過，第三次有望突破
- **目標價**: 突破1,160元後不再是停損價，而是目標價帶
- **停損點**: 月線跌破且三天未站回

#### 崇越 (5765) - 先進製程耗材
- **收盤價**: 343元
- **投資邏輯**: 全球先進製程耗材領導廠，2奈米用量更高要求更高，明年獲利大幅成長
- **技術面**: 一底比一底高，階段式往上，出量拉回量縮，法人完全掌控
- **操作策略**: 關稅若有不如預期，往月線附近走為絕佳買點
- **目標價**: 持續看多，不預設立場
- **停損點**: 月線跌破

#### 貿聯-KY (3665) - AIE系獨家供應商
- **投資邏輯**: 為AIE系（ASIC晶片）獨家供應商，800G準備量產，GB300 ASIC將上來，下一代路線圖範圍擴大
- **技術面**: 曾創高後拉回，今日公布亮眼數字（Q2 EPS 8.88元），翻上所有均線形成初升段
- **操作策略**: 短線初升段後有上圍整理，突破前高非常容易
- **目標價**: 挑戰前高
- **停損點**: 初升段低點

#### 葵花子（推測為葵品 (4163)）- 生技新藥

- **操作策略**: 分割後買一張門檻降低（原需140萬），藏波段股票
- **目標價**: 持續看多（還原後創高）
- **停損點**: 分割後觀察月線支撐

#### 康霈 (6919) - 生技新藥（推測）

### 台積電供應鏈（七成分析）

#### Tesla轉單三星事件
- Tesla宣布下一代車用晶片交給三星代工（165億美元，2025年7月至2033年12月）
- **年化影響**: 每年約20億美元，佔台積電年營收千億美元的極小部分
- **結論**: 對台積電影響不大，車用市場讓出無妨
- **反面觀點**: Tesla每年出貨200萬台車用晶片 vs AI訓練5千萬台伺服器需求（由NVIDIA/AMD供應，仍在台積電）

## 📋 投資策略總結

### 核心策略
1. **關稅拉回 = 買點**: 多位專家一致認為，不論關稅結果如何，AI族群拉回都是布局良機
2. **三條件選股**: 訂單看好（基本面）+ 多頭形態（技術面）+ 投資價值浮現（估值面）
3. **九條好漢觀察法**: 若某天九檔全部下跌，台股才真正危險
4. **外資心態未轉空**: 期現貨合計仍偏多，只是做多金額減少

### 風險管理
- 週五（8/1）對等關稅正式公布為最大變數
- 週四（7/31）聯準會利率決策動見觀瞻
- 選擇權週五結算需特別留意
- 台幣匯率波動影響外資進出

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **對等關稅** | 美國對各國課徵的對等報復性關稅，台灣稅率尚未公布 |
| **DMI指標** | 趨勢方向指標（Directional Movement Index），正DI在負DI之上為多方，反之為空方 |
| **第一人買** | 多空累積能量分數指標，紅色線在綠色線之上代表多方 |
| **Put/Call Ratio** | 賣權/買權成交量比值，數值越高代表市場越偏空方 |
| **HVOP** | 高壓有機銅箔（High Voltage Organic PCB），AI伺服器關鍵材料 |
| **AIE系 / ASIC** | 客製化AI加速晶片，與NVIDIA GPU互補的另一AI算力路線 |
| **BPU** | 備用電源裝置（Backup Power Unit），AI資料中心關鍵供電設備 |
| **九條好漢** | 林忠以營收年增28%+投信持股200檔以上篩選出的九檔台股多頭指標股 |
