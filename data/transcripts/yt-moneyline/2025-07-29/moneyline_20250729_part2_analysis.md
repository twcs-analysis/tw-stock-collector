## 📊 市場總體觀察

### AI進化論：BPU成為新焦點
- AI伺服器進化路線持續延伸，BPU（備用電源裝置）為新一波成長動能
- 各大雲端媒體（Google、Meta等）陸續導入BPU
- PCB族群材料升級（非單純升級，而是多了新東西），基本面有實質重大改變
- 八月份BBU/BPU族群有機會複製PCB七月的漲幅表現

### PCB族群最新動態
- **外資今日買超第一名**: 新興 (3527)
- **投信今日買超**: 新興 (3527) + 定穎 (3037)
- **外資+投信聯手買超僅兩檔**: 新興、定穎，皆為PCB
- **ABF載板**: 可能即將漲價，最上游CCL漲價導致產能排擠，整串受惠

## 💼 產業分析與投資建議

### 一、BPU電源供應族群

#### AES (6781) - BPU獲利王
- **收盤價**: 約1,200元
- **投資邏輯**: BPU族群中的獲利王，連續兩天漲停板，形態已完成
- **技術面**: 連續兩天漲停後形態明確向上，將挑戰前高1,175元（1月高點）
- **催化劑**: 之前市場預估僅反映GB200上的BPU，加上GB300後，再加上歐廠BPU滲透率持續提高，等於要反映兩個新增題材
- **目標價**: 突破1,175元後看更高，新題材加入讓估值天花板上移
- **停損點**: 1,100元（回測前波漲停支撐）

#### 順達 (3211) - BPU穩健標的
- **收盤價**: 305元
- **投資邏輯**: IT比重較高（消費性電子/PC），股性較不活潑，但BPU業務仍倍數成長
- **技術面**: 慢慢墊高，出量未破底，買盤持續進場
- **優勢**: 有穩定的股息提產
- **操作策略**: 整理時布局，不追高
- **目標價**: 依BPU貢獻度上調
- **停損點**: 大量低點

#### 新勝利 (推測為新盛力 (4931)) - BPU接Meta訂單
- **收盤價**: 115.5元
- **投資邏輯**: 直接接Meta訂單，Meta資料中心預計4,000個位置，HVDC架構下每位置配6台BPU = 24,000台，每台4,000~6,000元
- **估值推算**: 法人已將Google明年數字直接估到10元EPS，以目前115元計算，本益比有大幅提升空間
- **技術面**: 不斷創高，拉回五日均線即被承接
- **操作策略**: 上半年Q2有虧損但市場看的是下半年到明年，慢慢會往明年本益比靠攏
- **目標價**: 明年EPS 10元 x 本益比20倍 = 200元
- **停損點**: 五日均線或十日均線跌破

### 二、PCB族群

#### 新興 (3527) - PCB龍頭之一
- **投資邏輯**: 外資+投信聯手買超，今日外資買超1,000多張
- **技術面**: 長線空轉多已確認，但短線突破年線後正乖離偏大，可能短暫整理
- **操作策略**: 短線整理後中線偏多看待
- **目標價**: 中線上方仍有空間
- **停損點**: 年線跌破

#### 台光電 (2383) - PCB材料王
- **投資邏輯**: N8 Pro材料核心受惠者，未來800G交換器材料升級，供需緊張
- **營收表現**: 六月營收年增58%，上半年累積年增55%
- **馬來西亞擴產**: 持續擴充產能
- **技術面**: 週KD高檔但代表市場信心持續加溫，不宜反手做空
- **操作策略**: 沿月線或五週線操作，不追高但也不放空
- **目標價**: 持續看多，不預設天花板
- **停損點**: 五週線（月線）跌破

#### ABF載板漲價題材
- CCL（銅箔基板）上游漲價，產能排擠
- ABF載板有望跟進漲價
- 相關標的：新興、景碩、南電等

### 三、八月飆股統計分析（嘉明）

#### 研究方法
- 統計過去10年（2015~2024），8月份上漲次數達8成以上的個股
- 計算平均漲幅/標準差比值（風險調整後報酬），數值越大越好
- 篩選出波動小、穩定上漲的個股

#### 重點個股深度分析

**冒訊（強固型電腦）**
- **產品**: 軍用電腦、強固型商用電腦（國防用佔九成以上）
- **六月營收**: 3.16億元，年增30%以上（首度年增30%+）
- **上半年累積營收**: 年增約3.8%，但六月出現轉折訊號
- **估值**: 預估今年EPS約10元，目前本益比約13倍
- **關稅抵禦力**: 產品結構以商用/軍工為主，消費性佔比極低，受關稅影響小
- **操作策略**: 本益比10~13倍區間，可依評價布局
- **目標價**: EPS 10元 x 本益比13倍 = 130元
- **停損點**: 季線跌破

**台光電 (2383) - 八月必看**
- 營收每年7~8月開出為季節效應高峰
- 週KD高檔不宜反手做空
- 操作：沿月線做多

**是和（合晶清洗設備）**
- **投資邏輯**: 台積電2奈米量產推進，清洗需求大幅增加（製程越先進清洗難度越高）
- **營收**: 六月年增7~8%，上半年年增11%
- **獲利**: Q1 EPS 2.13元，去年全年6元，今年有機會超過
- **股價**: 約150元，本益比不高
- **操作策略**: 150元為下檔支撐，區間操作
- **停損點**: 150元跌破

**信昌（BMC晶片）**
- **投資邏輯**: 做BMC（基板管理控制器）晶片，只要有伺服器就需要BMC
- **營收**: 5~6月年增50%，上半年度年增80%
- **獲利**: 去年EPS 6.8元，今年Q1 EPS 2.3元，預估全年一個股本（10元+）
- **估值**: 市場歷史本益比50~100倍，目前偏低估
- **技術面**: 修正完畢來到季線位置有支撐，KD低檔開始往上
- **操作策略**: 季線支撐處布局，等待修正結束後向上
- **目標價**: EPS 10元 x 本益比50倍 = 500元（下限），100倍 = 1,000元（上限）
- **停損點**: 季線跌破

### 四、選擇權教學與避險策略（林忠）

#### 選擇權週五結算新制
- 2025年6月27日起，台灣選擇權新增週五結算
- 過去僅週三結算，現在週三+週五雙結算
- 目的：促進成交量，與國際股市接軌

#### 外資選擇權操作解讀
- 外資今日選擇權仍偏多（買Call）
- 外資組合策略：期貨做空 + 選擇權做多（避險/停損停利）
- **結算日風險**: 外資若有大量賣權部位，結算日可能積極壓低指數
- **反向操作**: 外資若有大量買權賣出部位，結算日可能拉高指數

#### 選擇權報酬率實例
- **5/13做多案例**: 大盤從21,330漲2.1%，買Call報酬率134%（775→1,040）
- **4/2做空案例**: 清明節關稅衝擊大盤跌9%，買Put報酬率1,921%（115→2,095）
- **巴菲特策略**: 長期持股搭配賣出買權收取權利金（巴菲特曾在可口可樂賺750萬美元）

#### 賣方策略實績
- 林忠本人4/28起做選擇權賣方（當沖為主）
- 三個月972口交易，淨收益約15萬元
- 本金150萬，年化報酬約40%
- 賣方策略：收取時間價值，適合盤整行情

#### 週五結算操作建議
- 選擇快到期（存續一週）的選擇權，權利金最便宜，看對報酬率最高
- 注意區分TXY（第三個週五結算）vs TXU（第四個週五結算）
- 重大事件前布局：FED利率（週四）、台積電法說（季度）、蘋果/輝達財報（週五凌晨）
- **不要盲目買進**: 波動率過高時買方易賠錢
- **時間價值衰退**: 做買方須特別留意

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **BPU** | 備用電源裝置（Backup Power Unit），AI資料中心不斷電設備 |
| **BBU** | 電池備援裝置（Battery Backup Unit），與BPU概念相近 |
| **BMC** | 基板管理控制器（Baseboard Management Controller），伺服器必備監控晶片 |
| **ABF載板** | 味之素堆積膜載板，高階IC封裝必備材料 |
| **CCL** | 銅箔基板（Copper Clad Laminate），PCB上游關鍵材料 |
| **N8 Pro** | 下一代高階PCB材料規格，800G交換器使用 |
| **HVDC** | 高壓直流供電架構，AI資料中心新一代供電標準 |
| **週五選擇權結算** | 2025年6月27日起新增，與原有週三結算並行，接軌國際 |
| **賣方策略** | 選擇權賣方收取時間價值權利金，適合盤整行情，需較多資金 |
| **風險調整後報酬** | 平均漲幅除以標準差，衡量每承受一單位波動可獲得的報酬 |
