#### 大盤表現
- **收盤點位**: 24,236點
- **漲跌幅**: 下跌283點

- **技術面**: 回測短均線支撐，月線、五日線、十日線仍有守住

#### 法人動向
- **外資**: 賣超96億（連續多天賣超）

- **台積電尾盤壓低**: 最後一盤壓跌十多塊，收在1,160元，跌幅2.5%，影響大盤超過250點
- **台積電跌破月線**: 技術面出現壓力訊號

### 美股影響

#### NVIDIA（輝達）財報解讀

**財報數據**
- **第二季營收**: 符合預期，年增表現亮眼
- **資料中心營收**: 411億美元（年增56%），但連續兩季低於市場預估的412億
- **GPU運算業績**: 338億美元（季減1%）
- **網路業務**: 73億美元（年增翻倍）
- **遊戲業績**: 營收年增成長不錯
- **EPS**: 1.05美元（優於預估的1.01美元）✅

**市場擔憂**
1. **資料中心營收連續兩季不如市場預期** - 華爾街要求太高
2. **第三季財測不夠驚豔** - 不包含中國任何出貨
3. **中國市場業務停滯** - H20晶片出口受限，外交問題是最大隱憂
4. **庫存增加** - 路透報導H200庫存與年存都超過30%

**分析師觀點**
- **高盛報告**: 市場對輝達期待太高，短期股價有壓力
- **路透報告**: 擔心第二季庫存增加問題
- **財務長回應**: H100、H200第二季賣得非常好，庫存增加可能因H20中國卡關及新產品備貨

**投資建議**
- 輝達相關概念股短期有壓力，先避開等回測後再買
- 不是基本面不好，而是利多已反映，需要時間消化
- 台積電依然穩健，焦點應放在設備與後材

### 國際市場動態

- **美股期貨盤**: 盤後一度下挫，但電子盤已經拉回
- **台指期夜盤**: 呈現上漲跡象

## 📈 技術面分析與操作策略

### 大盤技術面

1. **上升軌道**: 從4月開始形成上升軌道，只要不跌破即可安心
2. **關鍵支撐**: 24,000點（略低於月線），不跌破上升趨勢完整
3. **今日量縮拉回**: 雖為長黑K線，但量縮，非主力出貨訊號
4. **富台指結算影響**: 明天結算結束後可望恢復正常

### 顧總高檔警訊

1. **高檔爆量**: 8月在24,300以上出現3次5,000億以上大量
2. **高檔爆量代表70%將反轉向下**
3. **溫水煮青蛙**: 做頭股票會越來越多，但翻多股票可繼續做
4. **國安基金退場時程**: 10月6日至14日，在此之前仍可偏多操作

### 操作策略

- **做頭股票**: 出現空頭吞噬、墓碑線、跳空缺口等翻空K線的，堅決賣出
- **翻多股票**: 繼續做多，嚴守五日均線（短線）、月線（中線）
- **買進時機**: 拉回支撐買，不追高
- **停損原則**: 跌破五日均線短線出場，跌破月線中線出場

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| 富台指結算 | 富時台灣指數期貨的月度結算，通常在月底前最後兩個交易日，結算前可能出現壓低或拉高的異常波動 |
| 矽光子（CPO） | Co-Packaged Optics，將光學元件整合到晶片封裝中，用於資料中心高速傳輸，降低功耗並提升傳輸速率 |
| 溫水煮青蛙 | 高檔區間整理，量能逐漸萎縮，人氣慢慢退散，股價緩慢下跌，投資人不知不覺中套牢 |
| 注意股票 | 證交所對股價波動過大的股票發出警示，連續多日被列注意可能進入處置（分盤交易） |
| 處置股票 | 被證交所列為異常交易的股票，改為5分鐘或20分鐘撮合一次，降低流動性以抑制投機 |
| 國安基金 | 國家金融安定基金，在股市大跌時進場護盤，其退場時間通常代表政府認為市場已回穩 |
