### 注意股票操作策略

#### 注意股票的意義
- **最常觸發條件**: 最近6個營業日累積漲跌超過20%
- **其他條件**: 30天100%、60天100%、周轉率過高、成交量異常
- **處置規則**: 漲幅過大連3天→5分鐘一盤；周轉率/成交量因素連5天或10天中6天→處置
- **首次處置**: 5分鐘一盤；再次處置：20分鐘一盤

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| 季底作帳 | 每季最後一個月（3/6/9/12月），法人（尤其投信）為美化績效而拉抬持股的行為 |
| 三重頂 | 技術分析型態，股價三次觸及同一高點區域無法突破，確認後可能大幅下跌 |
| 頭肩頂 | 技術分析型態，中間高點高於兩側肩部，是典型的頭部反轉訊號 |
| M頭（雙重頂） | 股價兩次觸及同一高點無法突破，形似英文字母M，為反轉訊號 |
| 分盤交易 | 被處置股票改為每5分鐘或20分鐘撮合一次，降低流動性 |
| 貴買市場 | 即「櫃買市場」（OTC），上櫃股票交易的市場 |
| N趴（N波） | 股價呈現N字型的波動走勢，在區間內上下來回操作 |
| BDI指數 | 波羅的海乾散貨指數，反映全球散裝航運運價，是航運業景氣的領先指標 |
