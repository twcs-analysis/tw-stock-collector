## 🌍 市場總體觀察

### 國際政經分析

#### 川普對等關稅深度解讀

**表面動作 vs 實際目的**:
- **表面**: 對等關稅，各國稅率要與美國對等
- **實際**: 以關稅為工具交換各國核心利益
- **川普策略**: 先威脅 → 看對方表現 → 有給利益就豁免

**各國因應範例**:
| 國家 | 因應方式 | 結果 |
|------|---------|------|
| 日本 | 擴大對美投資（軟銀等） | 關係改善 |
| 印度 | 改善貿易狀況、購買美國武器（原本買俄羅斯） | 川普接待中 |
| 巴拿馬 | 退出一帶一路 | 達到川普要的 |
| 加拿大/墨西哥 | 邊境派1萬名武裝警察 | 暫緩一個月 |
| 台灣 | 擴大對美投資與採購（能源、武器、飛機） | 積極回應中 |

**台灣可能的回應措施**:
- 石油、天然氣從中東轉移到美國採購
- 客運飛機多買波音、少買空巴
- 武器（雷神、洛克希德馬丁）必須買美國
- AI與半導體加深合作

**關鍵事件**: 川普與普丁通電話後致電烏克蘭總統澤倫斯基，談論烏克蘭資源開發 → 戰爭停火可能性

#### 對等關稅的真正影響

**與川普第一任期的差異**:
- **第一任**: 僅對中國課關稅 → 廠商可轉移到越南、墨西哥 → 通膨未起
- **第二任**: 全面對等關稅 → 所有國家都課 → 無處轉移 → 成本真的會起來

**美國15大貿易夥伴**: 川普針對進口貨物比率較美國低的國家，要求對等甚至更高
- 台灣去年對美貿易順差7,739億美元，成長率最高
- 主要來源：半導體與通訊產品
- 因此被川普特別點名

## 💼 產業分析與投資建議

### 跌深股操作完整攻略

#### 跌深的兩種類型

**第一種：產業走空的跌深**
- 特徵：不只一檔，是一群（如鋼鐵、塑化、面板）
- 跌到深部見底，長期無感
- 代表：台塑（1301）- 跌到60元以下

**第二種：長多拉回的跌深**
- 特徵：股價長一段後回來
- 雖然跌得深，但會反彈上來
- 代表：穿鼻（創意等AI類）- 800漲到1,400後回到850

**操作差異**:
- 長多拉回：可搶反彈（如穿鼻，AI產業沒問題）
- 產業走空：第一次反彈視為「反彈逃命」（如台塑，季線跌破前都是逃命波）

#### 跌深股會反彈的條件

1. **有題材**: 如25停戰重建、原物料重建需求
2. **出現承接量**: 跌深後突然出量，代表有人在地板接走
3. **範例**: 上銀（上品） - 一直跌後突然出量，然後量能反彈

#### 跌深股反彈的四步驟

```
跌深 → 反彈 → 回測前低不破 → 再反彈 → 打出底型 → 回升
```

- 跌可能跌兩年
- 反彈約一個月
- 回測約一個月
- 底部打約一個月
- 完成底部形態至少需4-6個月

#### 跌深股技術面完成訊號

- 必須突破季線、半年線、年線（改變長線慣性）
- 技術面完成半年以上大底，才是真正長線翻多訊號

### 景氣循環股操作

**核心觀念**: 看報價，不看營收

**鋼鐵股觀察指標**:
1. 鐵礦砂價格變化
2. 中鋼每月/每季盤價調整方向
3. 寶鋼報價
4. 越南河靜鋼鐵報價

**不銹鋼**: 看國際鎳鋼價格變化
**銅**: 看銅鋼現貨報價

**操作原則**: 報價真的開始回升 → 股票底部見底 → 最差時本益比300-500倍甚至虧損 → 報價轉折時算出半年後、一年後獲利 → 本益比降到5-10倍 → 開始買進

### 跌深焦點股解套策略

#### 中鋼（2002）
- **今日位置**: 來到年線
- **今日量能**: 爆出近兩年最大量
- **走勢**: 從27-28元底部漲到33元附近
- **解套策略**:
  - 突破半年線/季線時先賣一趟
  - 爆大量時第一次都是賣點
  - 拉回年線與半年線中間再買回來
  - 等打出底部形態再加碼

#### 中鴻 / 大成鋼
- **操作**: 與中鋼相同邏輯
- **歷史案例**: 大成鋼2020年7月至8月，底部出量突破後 → 回測均線 → 原物料報價走多 → 股價主升段
- **重點**: 突破季線/半年線/年線先賣 → 回測再買回 → 突破底部型態加碼

#### 允強
- **特點**: 鋼鐵中反彈最強，連漲兩根漲停
- **原因**: 在印尼興建油廠，今年開始量產，將成全球第二大不銹鋼鋼管廠
- **地理優勢**: 接近烏克蘭重建區域
- **操作**: 年線附近先賣一趟，回補今天缺口時再買回

#### 營建股
- **特點**: 被政策打壓跌深，因高殖利率反彈
- **走勢**: 反彈到年線附近，又來到前高/季線
- **操作**: 先賣一趟 → 等回測季線/月線支撐 → 下一次買點

## 📈 技術面分析與操作策略

### 跌深股操作SOP

**減碼時機**:
- 反彈到季線上
- 反彈到半年線
- 反彈到年線
- 爆大量（第一次都是賣）

**加碼時機**:
- 拉回到年線與半年線中間
- 回測前低不破
- 打出底部型態突破季線時

**範例操作**（假設持有10張）:
1. 到年線：減碼5張
2. 拉回前低：買回3-5張
3. 打出底型突破：加碼5張
4. 結果：成本越來越低、股票越來越多

### 跌深股解套的關鍵

| 步驟 | 說明 | 時間估計 |
|------|------|---------|
| 跌深 | 產業走空或長多拉回 | 可能1-2年 |
| 第一波反彈 | 有題材或出量 | 約1個月 |
| 回測前低 | 確認底部 | 約1個月 |
| 打底型態 | W底或頭肩底 | 約1-3個月 |
| 突破回升 | 長線翻多 | 需半年以上底部 |

## 📚 名詞解釋

### 政經術語

**MAGA (Make America Great Again)**
- 川普的核心政策口號與計畫
- 包含：放鬆監管、幫企業做生意、回流製造業

**對等關稅 (Reciprocal Tariff)**
- 以各國對美國的關稅稅率為基準，美國以相同或更高稅率回應
- 還包括非關稅手段（補貼等）的調查
- 預計4月2日開始實施

**CPI (Consumer Price Index)**
- 消費者物價指數，衡量通膨的重要指標
- 美國1月CPI月增0.5%、年增3%，超出市場預期

**PPI (Producer Price Index)**
- 生產者物價指數
- 美國PPI年增3%，雖高於預期但部分物價（藥品等）暗示通膨壓力可能不如想像嚴重

### 產業術語

**CSP (Cloud Service Provider)**
- 雲端服務供應商
- 包含Google、Amazon、Microsoft、Meta等

**ASIC (Application-Specific Integrated Circuit)**
- 特定應用積體電路
- 各大CSP自研晶片（如Google TPU），非NVIDIA通用型GPU

**TPU (Tensor Processing Unit)**
- Google自研AI晶片，已到第六代
- 在推論（SEC/Inference）領域市占率70%

**GB72**
- NVIDIA最新AI伺服器機櫃型號
- 原估2025年出貨5萬台，現降至2-2.5萬台

**邊緣運算 (Edge Computing)**
- 將運算從雲端移至終端裝置
- 降低延遲、降低成本
- 代表應用：AIPC、AI手機、AI眼鏡

### 股市操作術語

**反彈逃命波**
- 產業走空的股票，在下跌趨勢中出現的短期反彈
- 特徵：未改變下跌慣性，反彈到季線即結束
- 操作：第一次反彈不要以為翻多，先賣再說

**破底翻 (Bottom Reversal)**
- 股價跌破前低後反轉向上
- 條件：需有題材、需出量、籌碼乾淨

**景氣循環股 (Cyclical Stock)**
- 業績隨景氣循環波動的股票
- 代表：鋼鐵、塑化、面板、航運
- 操作：看報價不看營收

**W底 (Double Bottom)**
- 跌深 → 反彈 → 回測前低不破 → 再反彈
- 形成W字型底部型態
- 確認：需半年以上才算有效底部
