## 🌍 市場總體觀察

### 對等關稅最新進展

#### 越南率先達成協議
- **協議內容**: 美國產品進入越南市場零關稅，越南商品出口美國從原定46%降至20%（減半）
- **越南股市**: 一舉攻上三年以來新高
- **蘋果影響**: 蘋果曾宣布除iPhone外，大部分產品將從越南進口，關稅從5%跳升至20%，成本壓力增加
- **7月9日大限**: 台灣對等關稅即將公布

#### 蘋果供應鏈回流困境
- **中國依賴度**: iPhone供應鏈仍有50%以上在中國（高峰曾達60~70%）
- **回流成本**: 全面移回美國，每支iPhone成本恐高達3,500美元
- **時間與金錢**: 蘋果花三年投入300億美金，僅能移回約10%供應鏈
- **預期策略**: 蘋果將採「一拖代辯」策略，部分轉移至印度，難以全面回美

### 台灣半導體產業全景

#### 今年產業表現（1~5月）
- **電腦電子產品及光學製品**: 年增 45.09%（AI伺服器貢獻）
- **積體電路**: 年增 31.17%
- **傳產衰退**: 紡織、汽車零件、基本金屬、化學原材料全數下滑
- **結論**: 產業表現呈現極端兩極化，半導體一枝獨秀，傳產面臨中國產能過剩、關稅壓力、匯率風險

#### 全球半導體銷售預測
- **全球**: 去年成長19%，今年趨緩至11.2%
- **台灣**: 去年成長22.4%（規模5.31兆），今年預估成長19.2%（規模6.33兆，再創歷史新高）
- **台灣趨緩幅度**: 小於全球，連續兩年呈現「黃金交叉」格局
- **台灣半導體占GDP**: 附加價值部分可達近16%

#### 台積電全球地位
- **全球晶圓代工市占率**: 67.6%（Q1 2025）
- **三星市占率**: 7.7%（差距高達59.9個百分點）

- **今年營收成長**: 預估24~26%
- **2奈米**: 今年下半年量產，客戶下單踴躍，效益將優於3奈米

## 📈 技術面分析與操作策略

### AI軟體股操作通則

1. **低量卡位法**: 在股價盤整、量縮至極低時先行佈局
2. **出量確認法**: 當月均量或季均量突破前波大量線時，確認攻擊發起
3. **防守停損法**: 盤整區間下緣跌破即停損，風險有限
4. **不追高原則**: 軟體股多為小型股，流動性差，追高容易套牢

### 國哥最終操作策略總結

| 策略要點 | 具體做法 |
|---------|---------|
| 短線操作 | 重視籌碼與技術面 |
| 長線操作 | 重視產業成長與趨勢 |
| 面對政策變數 | 區間應對，利多壓力站賣方，利空低接佈局 |
| 核心標的 | 低位接翻多 + 營收成長 = 防守反攻核心 |
| 大盤觀察 | 就看台積電，台積漲指數就漲 |
| 護盤階段 | 21,700~23,058 趨勢未改變前，高出低進來回操作 |

1. **持股檔數**: 從5檔降至3檔，保留現金因應
2. **島狀反轉風險**: 明日不可出現123點以上跳空開低

4. **軟體股流動性**: 小型股量能不足時需特別注意出場難度
5. **關稅變數**: 7月9日對等關稅公布，短期可能衝擊但市場已提前消化

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| 對等關稅 | 美國針對貿易逆差國家課徵的報復性關稅，稅率依各國對美貿易順差程度而定 |
| 232條款 | 美國《貿易擴展法》第232條，授權總統以國家安全為由對特定進口商品課徵關稅，無時間限制 |
| USMCA | 美墨加協定（United States-Mexico-Canada Agreement），取代原NAFTA的北美自由貿易協定 |
| DDR4/DDR5 | 第四代/第五代雙倍資料速率同步動態隨機存取記憶體，DDR5為最新規格 |
| 黃金交叉 | 技術分析術語，短天期均線由下往上穿越長天期均線，為多頭訊號；此處指台灣半導體成長率連續兩年超越全球平均 |
| 非主管全時員工 | 每週工作時數達法定標準（約35~40小時）的非管理職正式員工，用於計算真實平均薪資 |
| 二代健保補充費 | 台灣全民健保針對股利、利息等額外所得課徵的補充保費，股利超過一定金額需繳納 |
| Palantir (PLTR) | 美國AI大數據分析軟體公司，近兩年股價漲超10倍，為AI軟體股代表 |
| ServiceNow (NOW) | 美國企業級AI驅動軟體平台，股價達1,000美金，為SaaS龍頭之一 |
