## 📋 投資策略總結

### 短期策略（1-2週）

1. **台灣模式題材**：創意（3443）、聖暉（5765）、弘塑（3131）、亞翔受惠美國擴廠
2. **AMD利多效應**：日月光（3711）、京元電（2449）、南電（8046）封測供應鏈受惠
3. **PCB漲價持續**：金居（8358）、副橋（6206）、中科（4989）法說後突破
4. **超級財報週**：美國科技七雄財報公布，關注業績是否超預期

### 中期策略（1-3個月）

1. **AI伺服器出貨旺季**：Q4為GB300+Meta伺服器出貨期，廣達、緯創、英業達受惠
2. **創意電子明年爆發**：三家客戶量產帶來授權金收入，AI營收占比大幅提升
3. **AMD生態系擴大**：MI450晶片+OpenAI合作，台積電與封測廠長期受惠
4. **散熱股分化**：台達電穩健型首選，奇鋐等投信調節後再進場

### 風險評估

- **美國政府關門延長風險**：若超過2018年川普時期的35天，可能影響信心
- **估值偏高**：部分科技股股價已反映明年業績，追高風險增加
- **創意電子AI占比仍低**：目前僅15%，明年才有大幅提升
- **投信調節壓力**：奇鋐、日月光、京元電等近期遭投信賣超，短線需等籌碼沉澱
- **AMD認股權門檻高**：股價需達600美元方能行使，仍有不確定性

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| 台灣模式 | 將台灣竹科半導體產業鏈經驗複製到美國的關稅談判方案 |
| RCA計畫 | 1976年工研院派19人赴美國RCA學習半導體技術，奠定台灣半導體產業基礎 |
| 232條款 | 美國貿易法中針對國家安全的條款，可對特定產品（含半導體）加徵關稅 |
| 認股權證（Warrants） | 持有者有權在特定條件下以約定價格購買股票的權利 |
| 合約負債 | 公司已收取客戶預付款但尚未完成交付的金額，為未來營收的領先指標 |
| 授權金（Royalty） | IC設計公司的智慧財產權使用費，客戶量產時按片收取 |
| SoIC | 台積電3D堆疊封裝技術（System on Integrated Chips） |
| MI450 | AMD下一代AI GPU晶片，預計2026年部署 |
| GB300 | NVIDIA下一代AI伺服器平台 |
| ABF載板 | 高階IC封裝基板（Ajinomoto Build-up Film），為AI晶片必要材料 |
| CSP業者 | 雲端服務供應商（Cloud Service Provider），如AWS、Google Cloud、Azure |
| MCM | 多晶片模組（Multi-Chip Module），將多顆晶片封裝在一起的技術 |
| CPO | 共同封裝光學（Co-Packaged Optics），將光學元件與晶片封裝的技術 |
| 地甲瓦（GW） | 十億瓦特，衡量資料中心電力規模的單位 |
| SEC | 美國證券交易委員會（Securities and Exchange Commission） |
