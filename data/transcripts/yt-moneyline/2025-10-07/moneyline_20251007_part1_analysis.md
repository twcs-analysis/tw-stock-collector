### 中期策略（1-3個月）

2. **台灣模式題材**：創意（3443）、聖暉（5765）、弘塑受惠美國擴廠

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| MLCC | 積層陶瓷電容（Multi-Layer Ceramic Capacitor），被動元件核心產品，用於電路濾波、去耦 |
| 鉭質電容 | 使用鉭金屬的電容器，耐高溫、穩定性高，適用於軍工航太與AI伺服器 |
| 固態電容 | 使用固態電解質取代電解液的電容，不會爆漿，耐高溫 |
| 導線架 | IC封裝中連接晶片與外部電路的金屬框架 |
| CoWoS | 台積電先進封裝技術（Chip on Wafer on Substrate），整合多晶片於同一基板 |
| M8/M9 | PCB銅箔基板（CCL）的層數規格，M9為AI伺服器高階版材主流 |
| ABF | Ajinomoto Build-up Film，味之素堆積膜，高階IC載板關鍵材料 |
| 本益比（PE） | 股價除以每股盈餘（EPS），衡量股票估值的指標 |
| 列處置 | 證交所對股價異常波動股票實施的分盤交易措施 |
| 主動式ETF | 由基金經理人主動選股、可每日調整持股的ETF，區別於追蹤指數的被動式ETF |
| DDR5 | 第五代雙倍資料速率記憶體，目前AI伺服器主流規格 |
| SSD | 固態硬碟（Solid State Drive），使用快閃記憶體的儲存裝置 |
