## 🌍 市場總體觀察

### 化工股暴漲暴跌解析

#### 事件背景
- **昨日化工股大漲**: 因日本旭化成（PSPR材料）傳出先進封裝關鍵材料告急
- **今日化工股崩跌**: 永光等個股開盤幾乎漲停 → 盤中幾乎跌停（單日振幅近20%）
- **關鍵判斷**: 台灣化學公司（如永光做的是BT、ABF材料）與PSPR（光罩用材料）不同，**沒有轉單效應**
- **正確解讀**: 日本旭化成PSPR告急 → 代表AI算力需求快速成長 → 利多的是AI供應鏈（非化工股）

#### 玻纖布（波纖布）缺貨才是真題材
- **30瓦斯（三零瓦斯）**: 波纖布延長交期 → 與PCB產業直接相關
- **銅箔基板（CCL）**: 上游原料（波纖布、聯合片）缺貨 → 中游銅箔基板受惠
- **邏輯鏈**: 上游缺料 → 中游漲價 → 下游PCB受惠

### 全球債券市場壓力

#### 日本40年期公債殖利率創歷史新高
- **歷史新高**: 3.695%（上週）
- **對比**: 2016年接近零利率 → 現在接近4%
- **問題**: 投資人持有2016年購入的公債，帳面虧損巨大

#### 日本減少發長債的影響
- **做法**: 減少發行超長期（40年期）公債，改發短期債
- **連鎖效應**:
  - 日本公債殖利率下降（利多日債）
  - 美國30年期公債殖利率也跟著下滑（大半點6的跌幅）
  - 日幣走強（因不需賣日債買美債）
  - 美債短期獲得喘息空間
- **深層邏輯**: 日本過去需賣日債→換美元→買美債；現在減少發日債→減少賣壓→間接穩住美債

### 美國穩定幣法案與比特幣

#### 穩定幣對美債的潛在支撐
- **邏輯**: 發行美元穩定幣需要等額儲備（美國公債或等同現金的資產）
- **現況**: USDT已超過千億規模，儲備中大量持有美國公債
- **影響**: 穩定幣法案若通過 → 未來更多穩定幣發行 → 更多美債買盤

#### 比特幣走勢
- **最新高點**: 約111,000美元（再次創新高）
- **格局**: 偏向震盪上行
- **推動力**: 川普旗下企業投資加密貨幣 + 穩定幣法案推進

## 📚 名詞解釋

- **PSPR**: 感光性聚醯亞胺（Photosensitive Polyimide Resin），用於先進封裝的光罩材料，由日本旭化成供應
- **BT / ABF**: PCB基板材料（BT樹脂/ABF載板），台灣化工廠主要生產的材料，與PSPR不同
- **聯合片（Prepreg）**: 銅箔基板的中間層材料，由玻纖布浸漬樹脂而成，目前缺貨最嚴重
- **Low DK / Low CT**: 低介電常數/低介電損耗的高階材料規格，用於高頻高速訊號傳輸
- **M8等級材料**: 高階伺服器專用銅箔基板材料等級
- **穩定幣（Stablecoin）**: 與法定貨幣（如美元）掛鉤的加密貨幣，需要等額儲備資產支撐
- **殖利率倒掛**: 長期債券殖利率低於短期的異常現象，通常暗示經濟衰退風險
- **T50反一**: 台灣50反向一倍ETF，用於做空台股大盤
- **去美元化（De-dollarization）**: 各國央行減少美元外匯儲備，轉向其他貨幣或資產的趨勢
- **廣場協議**: 1985年美日英法德五國簽署的協議，迫使美元大幅貶值
