### 2. 個股期貨操作三步驟（予很教學）

**AMD操作模型**：

| 步驟 | 說明 | 操作 |
|------|------|------|
| 步驟一：吸籌/洗盤 | 盤整區間上下洗，觀察主力動作 | 只觀察不進場 |
| 步驟二：操縱（假跌破/假突破） | 假跌破後急拉回 | 識別流動性掠取，確認結構轉換 |
| 步驟三：派發 | 真正方向啟動 | FVG位置進場 |

**進場三要素**：
1. **等待流動性掠取**：觀察下影線出現（主力進場訊號）
2. **確認結構轉換**：出現更高的高點（HH），不急追
3. **FVG回測進場**：回測50%-61.8%黃金切割率位置，找下影線進場

**目標設定**：盤整區高低點距離往上一倍

**台股大盤應用**：4月低點盤整區往上一倍，目標指向三萬點

### 4. 降息循環與資金行情（冠州分析）

**核心論述**：目前屬於「預防式降息」而非「衰退式降息」，對股市最有利。

#### 預防式 vs 衰退式降息比較

| 類型 | 特徵 | 歷史案例 | 股市表現 |
|------|------|----------|----------|
| 預防式 | 經濟未衰退，有風險時預防性降息 | 1995、1998、2019年 | 股市表現優異 |
| 衰退式 | 經濟已衰退或即將衰退 | 2001網路泡沫、2008金融海嘯、2020疫情 | 股市崩跌 |

**目前狀況**：
- 已降息兩到三次，資金行情環境已建立
- 鮑威爾暗示12月可能不降息（愛降不降），反而對股市更好
- 12月降息機率不到七成，維持不變機率達三成
- 預估利率從4%降至3%需到2027年，速度緩慢（一季降一碼）

**結論**：愛降不降比一直降對股市更好（一直降=經濟出問題），Q4至明年Q1走資金行情機率極高。

#### 聯準會最新動態

- 宣布暫停縮表（停止抽回資金），資金活水保持寬鬆
- 下一任主席態度為中期觀察重點（鮑威爾任期至明年5月）

## 技術面分析與操作策略

### 美股期貨觀察法

- **換倉點法則**：每季換倉時的價位為多空分界，只要換倉點未被跌破，多方格局不變
- **目前12月合約**：整理一個月後站上，多方偏多
- **觀察重點**：若回測換倉區25,000-25,500後買方重新進場，更加確認多方

### 大盤目標推估

- **AMD模型應用**：4月盤整區高低點距離往上一倍
- **台股目標**：三萬點有機會（從月線角度分析）

### 個股進出場SOP

1. 確認週K趨勢方向（目標是否已到）
2. 切入日K找FVG回測位置
3. 等待假跌破+下影線確認
4. 進場後設定停損（下影線下方）與停利（等幅上方或1:5風報比）

## 名詞解釋

| 名詞 | 說明 |
|------|------|
| FVG | Fair Value Gap，公允價值缺口，價格快速移動後留下的空白區域，常作為回測進場點 |
| 黃金切割率 | 斐波那契回撤比例（38.2%/50%/61.8%），用於預測回測深度 |
| 流動性掠取 | Liquidity Sweep，主力刻意突破關鍵價位觸發停損單後反轉，收集籌碼 |
| 結構轉換 | 趨勢從下降轉為上升（或反之），以更高高點/更低低點確認 |
| 換倉點 | 期貨合約到期換月時的價位，作為多空分界參考 |
| 預防式降息 | 經濟尚未衰退時的預防性降息，歷史上對股市有利 |
| 衰退式降息 | 經濟已進入或即將衰退時的降息，通常伴隨股市下跌 |
| 縮表 | 央行縮減資產負債表規模，即抽回市場流動性 |
| DDR4/DDR5 | 第四/五代雙倍資料傳輸率記憶體標準 |
| HBM | 高頻寬記憶體（High Bandwidth Memory），AI晶片必備 |
