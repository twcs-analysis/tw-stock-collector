## 市場總體觀察

### 台股

- **盤勢表現**：11月第一個交易日，台股開高走跌，尾盤因台積電神龍擺尾，指數由黑翻紅，上漲101點，收在28,334點
- **成交量**：5,786億元，較上週五小幅增加27億，量能充沛
- **結構特點**：權值股除台積電外多數休息，資金轉進PCB族群（連續第二天大漲）及記憶體族群
- **距三萬點**：差約1,666點
- **盤中提示**：差一點有機會突破上週四歷史新高

### 三大法人動態

- **外資**：現貨持續賣超，再賣84.4億元；期貨空單一口氣增加4,944口，目前空單水位約27,880口
- **外資空單**：尚未到30,000口警戒線，但單日大增需警惕
- **現貨賣、期貨空單增加、台幣貶值**：三重壓力需列入警戒

## 技術面分析與操作策略

### 大盤策略

1. **多頭格局維持**：只要10日均線不破、量能維持5,000億以上且不暴量（不超過6,500億），多頭格局不變
2. **選股重於選市**：KD高檔鈍化+騰落指標偏弱，操作難度提高，需精選強勢族群
3. **外資空單觀察**：若連續數日再增4-5千口，需提高警戒

### 個股操作模型

- **權值股**：台積電整理為主，等基本面催化；鴻海拉回找10日均線買點
- **PCB族群**：台光電為精神領袖，長線持有；景碩先行（BT漲價），南電後續（ABF漲價）
- **記憶體**：南亞科站上年線後觀察能否續強，若利多不漲需減碼

## 名詞解釋

| 名詞 | 說明 |
|------|------|
| PCB | 印刷電路板（Printed Circuit Board），電子產品的基礎載體 |
| ABF載板 | 味之素堆疊薄膜載板，用於高階CPU/GPU封裝 |
| BT載板 | 雙馬來醯亞胺三嗪樹脂載板，用於記憶體等封裝 |
| M8/M9 | 台光電高速銅箔基板材料等級，M9為新一代更高速材料 |
| IC載板 | 積體電路封裝載板，連接晶片與PCB的關鍵中介層 |
| MSCI | 明晟指數，全球最具影響力的股票指數編製公司 |
| KD指標 | 隨機指標，用於判斷超買超賣，80以上為過熱 |
| 騰落指標 | 上漲家數與下跌家數之差，反映市場廣度 |
