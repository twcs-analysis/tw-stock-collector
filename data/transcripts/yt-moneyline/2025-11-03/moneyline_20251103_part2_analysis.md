## 產業分析與投資建議

### 1. 台積電漲價與先進製程演進

**核心邏輯**：台積電先進製程產能極度吃緊，連續四年漲價計劃（5-10%/年），策略性定價以兼顧客戶成長。

#### 台積電製程領先分析

| 時間節點 | 台積電 | Intel | 三星 |
|----------|--------|-------|------|
| 2011年 | FinFET導入 | 同步導入 | 2013年才導入（落後2年） |
| 2018年 | 7nm導入EUV | 繼續用DUV（開始落後） | 7nm也導入EUV |
| 2020年 | 3nm繼續用FinFET | - | 3nm導入GAA（但良率差） |
| 2025下半年 | 2nm導入GAA | 20A/18A導入GAA（不順） | 落後 |
| 2026年 | A16導入背面供電 | 18A計劃導入（未確定） | 2027年才導入 |
| 2029年 | A14P可能導入High-NA EUV | 已進第一台 | 今年下半年導入低台 |

**關鍵結論**：
- 台積電贏在良率，而非搶先導入最新設備
- High-NA EUV一台4億美元以上，台積電評估成本效益後選擇延後（預計2029年A14P）
- 台積電自研光罩薄膜，可提升良率並降低成本

#### 台積電（2330）

| 項目 | 內容 |
|------|------|
| 漲價計劃 | 先進製程每年漲5-10%，連續四年 |
| 產能狀況 | 極度吃緊，特斯拉排不到產能轉向三星 |
| 2nm進度 | 明年大量生產，3nm產能12-13萬片/月，2nm明年底達12-13萬片/月 |
| 操作建議 | 長線格局，季線為支撐，拉回季線附近可布局 |

### 2. 特用化學供應鏈（台積電2nm受惠股）

**核心邏輯**：2nm量產需要全新的監端材料，台積電除了設備還需化學品配合。墨克（德國化學大廠）在高雄楠梓投資5億歐元（170億台幣），12月落成，配合2nm量產時程。

| 核心產品 | 表面改質蝕刻劑、清洗劑，3nm及2nm製程材料 |

### 5. 四大雲端業者資本支出（冠州分析）

**核心邏輯**：四大雲端業者（Google、Meta、亞馬遜、微軟）2026年資本支出合計估超過5,000億美元，較今年3,300億增長超過50%，為歷年最高增速。

| 雲端業者 | 2025年估 | 2026年估 | 重點 |
|----------|----------|----------|------|
| Google | ~800-1,000億 | 破千億 | 雲收破千億，AI雲端營收年增強勁 |
| Meta | 720億（上調） | 估破千億 | 積極研發Llama AI，AI資料中心建設 |
| 亞馬遜 | 1,200-1,250億 | 1,288億+ | 自研ASIC晶片，雲端AI收入持續增長 |
| 微軟 | ~350億/季 | 持續增長 | Azure AI與OpenAI合作，Copilot整合 |
| **合計** | **~3,300億** | **>5,000億** | **YoY增長>50%，史上最高** |

**黃仁勳預測**：NVIDIA未來三年收入將達5,000億美元（含GB200/GB300/Rubin系統），從原訂2030年提前至2028年。

#### 泡沫疑慮回應

- 四大雲端業者資本支出只增不減，2026年AI投入確定性極高
- 從買家（雲端業者）到賣家（NVIDIA/AMD/博通），再到台灣供應鏈，邏輯完整
- 至少2026-2027年不用擔心泡沫，AI算力軍備競賽加速中

## 技術面分析與操作策略

### 台積電概念股操作邏輯

1. **特化雙雄**（新應材、台特化）：高檔橫盤後突破向上，大漲一段後盤整為多頭格局，長線直接買
2. **封測轉型**（京元電、欣銓）：測試毛利率遠高於封裝，轉型紅利尚未完全反映
3. **力成**：鴻黑K線一半低點為買點，積極布局

### AI伺服器供應鏈

- **散熱**（奇鋐、複士檔）：GB300散熱更重要，台積電休息時輪漲
- **伺服器**（緯穎）：沿10日線操作，本益比不到20倍

## 名詞解釋

| 名詞 | 說明 |
|------|------|
| FinFET | 鰭式場效電晶體，2011年起主流的電晶體架構 |
| GAA | 環繞式閘極電晶體（Gate-All-Around），2nm以下新架構 |
| 背面供電（BSPD） | 從晶片背面供電的新技術，可提升效能與功耗 |
| High-NA EUV | 高數值孔徑極紫外光微影設備，一台超過4億美元 |
| 光罩薄膜 | EUV光罩保護膜，可提高良率減少缺陷 |
| OSAT | 外包封裝測試廠（Outsourced Semiconductor Assembly and Test） |
| FORP | 面板級扇出型封裝（Fan-Out on Reconstituted Panel） |
| ALD | 原子層沉積（Atomic Layer Deposition），先進製程材料技術 |
| ASIC | 客製化特殊應用積體電路（Application-Specific Integrated Circuit） |
| 預燒測試 | 在高溫環境下測試晶片可靠度，篩除早期失效品 |
