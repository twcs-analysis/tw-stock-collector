## 📊 市場總體觀察

### 主題：那些等了一年的「委屈股」逆襲

鎮華提出核心觀察：股價往往領先業績一到兩年發動，導致部分個股在大平台整理超過一年。這些「委屈股」並非基本面不好，而是：

1. 股價太早反映未來預期（2-3 年前就開始漲）
2. 大型推薦者（黃仁勳、馬斯克）帶動提前炒作
3. 營收尚未跟上，導致本益比偏高
4. 市場資金轉向其他熱門題材

**關鍵轉折信號**: 當營收真正出來、國際同業股價持續創高時，大平台整理完畢就會走主升段。

## 🌍 商品市場分析（育恆深度報告）

### 一、黃金

#### 封關期間表現
- 封關前曾跳水（襪子衝擊 + 多殺多）
- 封關期間重新反彈至 5,084 美元/盎司
- 即便西方交易所主導期間（亞洲休市），空方也未能進一步打壓

#### 看多邏輯
1. **比特幣數位黃金屬性動搖** - 比特幣已偏向風險性資產（科技股先行指標），資金轉回實體黃金
2. **亞洲實體需求旺盛** - 印度、越南、中國、台灣實體黃金很難買到，需加價
3. **美國交易所庫存持續減少** - 黃金從美國流向亞洲（走實務交割提領）
4. **4 月黃金期貨結算** - 低通知日在 3 月底，多方仍有時間做網上攻擊
5. **跌幅一半已收復** - 從高點長黑下跌到最低點的 50% 已收復

#### 技術面判斷
- 5,000 美元是重要分水嶺，站穩後偏多方優勢
- 空頭機會已不多，但距前高仍有 10% 左右可便宜進場
- **建議**: 定期定額買黃金、黃金 ETF 的投資人可加碼

### 二、白銀

#### 封關期間風險
- 美國交易所大戶為空方，封關期間（亞洲休市）即出現長黑
- 但長黑後並未進一步破底 → 保證金擠壓的時間窗口已過

#### 關鍵數據
- 3 月歐萊爾（OI）換算約 2.7 億盎司
- 交易所庫存（已註冊 + 合格）約 3.6 億盎司 → 大於結算需求
- **庫存危機已紓解**，但庫存仍持續被提領（年前 3.98 億 → 持續減少）

#### 3 月合約轉倉
- 2/24 為最後調整日，2/27 為第一通知日
- 多單有序轉倉至 5 月合約 → 看多者繼續看多但不領庫存
- **結論**: 短線波動大，適合短線操作；中長期偏多

### 三、原油

#### 半年新高
- 封關期間原油從 50 多美元漲至 60 多美元，反映伊朗地緣政治風險
- 技術面小的頸線已向上翻揚完成

#### 三大推動因素
1. **伊朗衝突升溫** - 若荷莫茲海峽被封鎖，油價將大幅飆升
2. **美國增產速度慢** - 川普想大量輸出美油，但實際增產跟不上
3. **美國庫存低水位** - 對油價上漲較無抵抗力

#### 影響
- 若油價站穩 65 美元以上 → 上看 75 美元（+10 美元空間）
- 油價上漲 → 通膨反彈 → 聯準會下半年降息路徑受阻

### 四、美元

#### 目前狀態
- 美元指數在 96.7~100 區間整理
- 關稅違法後美元小跌但未破底（底部 96.22）
- 市場等待聯準會新主席 Waller 的聽證會（預計 3 月）

#### 未來走向
- 若 Waller 偏鴿派 → 美元走弱 → 黃金更強
- 若 Waller 偏鷹派 → 美元定存有利
- **提醒**: 美元定存需注意匯率波動風險，若美元貶值超過 3% 利息就會被吃掉

## 📈 技術面分析重點

### 大平台突破的判斷標準
1. **營收確認跟上** - 股價領先漲 1-2 年後，營收真正出來是啟動主升段的關鍵
2. **國際同業創高** - 日本三菱金屬、村田製作所等同業大漲是台股跟進的領先指標
3. **假跌破真築底** - 在大平台整理末期出現假跌破，反而確認做頭不成反成底
4. **被關警示不是壞事** - 關到最後籌碼反而沉澱，出來後爆發力更強

### 選股邏輯：新同學 vs 老同學
- **老同學**（聯亞、波羅威、光聖、華星光）: 漲三年了，已是市場主流
- **新同學**（去年 Q4 才開始漲）: 漲幅不到一輪，更有上漲空間
- **結論**: 要買就買「新同學」，因為漲幅較少、時間較短

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **大平台整理** | 股價在高檔橫向震盪超過半年至一年以上的技術形態，突破後通常有強勁主升段 |
| **假跌破** | 股價短暫跌破支撐後迅速收回，確認支撐有效，是多方強勢信號 |
| **三線糾結** | 短期（5日）、中期（10日/20日）、長期（60日）均線交纏在一起，預示即將出現方向選擇 |
| **關警示 / 分盤交易** | 證交所對異常交易個股實施處置措施，包括集中交易改為分盤撮合，抑制過度投機 |
| **CCL** | 銅箔基板（Copper Clad Laminate），PCB 的核心原材料 |
| **OI（Open Interest）** | 未平倉合約數，代表期貨市場中尚未結算的合約總量 |
| **實務交割** | 期貨合約到期時以實物交付（而非現金結算），黃金白銀大量實務交割會消耗庫存 |
| **荷莫茲海峽** | 波斯灣出口要道，全球約 20% 石油運輸經此，一旦封鎖將導致油價暴漲 |
| **FOPOP** | Fan-Out Panel-Level Packaging，扇出型面板級封裝技術，次世代先進封裝技術 |
| **Waller** | 克里斯多福・沃勒，美國聯準會理事，被視為可能的下一任聯準會主席人選 |
| **MAGA** | Make America Great Again，川普政治口號與支持者基本盤 |
