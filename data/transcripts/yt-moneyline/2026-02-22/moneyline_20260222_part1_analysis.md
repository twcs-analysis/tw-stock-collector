## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **IEEPA** | 國際緊急經濟權力法（International Emergency Economic Powers Act），川普用以課徵對等關稅的法律依據，已被最高法院判決違法 |
| **122 條款** | 1974 年貿易法第 122 條，允許總統對全球進口商品課徵最高 15% 關稅，期限 150 天，到期需國會批准延長 |
| **301 條款** | 針對外國政府不公平貿易行為的調查與課稅機制，需半年到一年審理期 |
| **232 條款** | 以國家安全為由對特定產業課稅（如鋼鋁關稅），需逐產業調查 |
| **338 條款** | 1930 年關稅法，針對「歧視美國貿易」的國家，最高可課 50% 報復性關稅 |
| **台指期結算** | 每月第三個週三為台指期貨結算日，結算前多空雙方交戰激烈，影響大盤走勢 |
| **正乖離** | 股價偏離移動平均線的幅度，正乖離過大代表短線漲幅過快，有回檔風險 |
| **矽光子** | 利用矽基材料製作光學元件的技術，用於高速光通訊，是 AI 資料中心核心技術 |
| **GTC** | NVIDIA GPU Technology Conference，輝達年度技術大會 |
| **Blackwell / Rubin** | 輝達下一代及再下一代 AI 晶片架構代號 |
