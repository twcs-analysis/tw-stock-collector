## 🌍 市場總體觀察

### OTC（櫃買）指數技術分析

#### 週量創歷史新高的意義

**關鍵數據**:
- 8月15日當週成交量：7,991 億元（接近 8,000 億），創歷史新高
- 前次高點：2024年3月8日 7,599 億元
- 連續兩週爆量

**歷史經驗法則**（盡老師）:

| 時間 | 成交量 | K棒顏色 | 後續走勢 |
|------|--------|---------|---------|
| 2024/3/8 | 7,599億 | 紅K棒 → 但後續漲不動 | 下跌（非攻擊量） |
| 2024/5/31 | 6,842億 | **紅K棒** | **上漲**（克服前高的攻擊量） |
| 2024/7/5 | 6,912億 | 紅K棒 | 隔週黑K → 8月股災 |
| 2024/7/12 | 7,031億 | **黑K棒** | 大跌（做頭確認） |
| **2025/8/15** | **7,991億** | **紅K棒** | **準備挑戰年線，後面絕對還有高點** |

**結論規則**:
- 爆量 + 紅K棒 → 不用擔心，至少還有一週可跑
- 爆量 + 黑K棒 → 請小心，可能是做頭訊號
- **本次**: 爆量紅K棒 + 準備突破 52 週均線（年線）= 攻擊量

#### OTC 年線扣抵分析
- 年線扣抵在高位，未來三週仍扣高 → 年線向下壓力大
- 短線可能漲得不會太快
- 但過完三週扣高期後，漲勢可能加速
- **結論**: 後面還有高點，但可能要過一個月漲勢才會加速

### 美中關係與半導體關稅

#### 烏俄停戰談判最新進展（提號/鐵號分析）

**八國聯軍進白宮**:
- 澤倫斯基親自飛到白宮談判
- 德國總理、法國總統馬克宏、義大利總理梅洛尼、英國首相施凱爾、芬蘭總統、北約秘書長、歐盟主席等八國領袖齊聚

**停戰協議核心議題**:
1. **領土交換**: 川普已明言一定會有領土交換，烏克蘭東南四州+克里米亞確認為俄國領土，但烏克蘭保留主權論述
2. **軍事援助**: 美方短期持續提供，後續由歐洲接手負擔
3. **北約加入**: 70% 烏克蘭民眾已不相信能加入，可能改以「類北約第五條」共同防禦
4. **停火監督**: 美國希望引發聯軍，俄國可能找白俄羅斯

**市場影響**:
- 停戰預期提高 → 俄羅斯恢復產能 → 油價持續向下 → 有利聯準會降息
- 川普策略：確保無通膨因素阻礙降息之路

#### 半導體關稅的兩層思考

**第一層（樂觀）**:
- 只要在美國設廠就能豁免？
- 蘋果投 6,000 億、輝達投 5,000 億、美光投 2,000 億
- 但蘋果年資本支出僅 100-110 億，6,000 億要投 30 年

**第二層（現實）**:
- 豁免範圍不確定：投資金額門檻？全資 vs 合資？
- 大廠（台積電、三星）已在美設廠 → 影響有限
- **真正受衝擊的是中芯國際、華虹等中國廠**：無美國廠，面臨 200-300% 關稅
- 台灣中小型半導體廠（合資、未設美國廠）→ 不確定性高

**結論**:
- 美中分裂持續，但有利在美設廠的台灣大廠
- 權值股（台積電、鴻海、紅海）已拿到「免死金牌」
- 股市回調時，優先選擇 AI 指標股布局

#### H20 管制放鬆的深層意義

- 川普釋放 H20 晶片管制放鬆訊號
- 輝達對中國營收占 13%（超維部分占 20%）
- IC 設計管制放鬆 → 先進製程代工是否也開放？
- 若台積電重新開放中國先進製程市場 → 想像空間極大
- **賣的都是降規版，但對營收貢獻仍然顯著**

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **CPO** | Co-Packaged Optics，共封裝光學，將光學元件與交換晶片封裝在一起的技術 |
| **矽光子** | Silicon Photonics，利用矽基材料實現光通訊的技術，為 CPO 核心 |
| **NBIM** | Norges Bank Investment Management，挪威主權基金，全球最大主權基金之一 |
| **FAL** | 光收發模組的一種架構，上詮通過台積電/輝達認證 |
| **隔日沖** | 外資或主力當日大買，隔天立即賣出獲利了結的操作手法 |
| **337 調查** | 美國國際貿易委員會（ITC）針對專利侵權進行的調查 |
| **扣抵/扣高** | 移動平均線計算時，新數據取代舊數據的過程；扣高時均線向下壓力大 |
| **年線（52 週均線）** | 52 週移動平均線，中長期趨勢判斷依據 |
| **H20** | 輝達針對中國市場推出的降規版 AI 晶片 |
| **13F 報告** | 美國 SEC 要求管理資產超過 1 億美元的投資機構每季申報的持股報告 |
