#### 重點推薦個股

**原相 (3227)** - AI機器視覺晶片龍頭
- **本益比**: 22.7倍（已公布Q4財報）
- **核心競爭力**: 全球滑鼠感測晶片龍頭，切入全場景位置追蹤、機器人、無人機
- **催化劑**: 與CINITY（因特爾、微軟、亞馬遜等為大股東）合作AI機器視覺
- **操作建議**: 拉回就是買點，本益比僅22倍，遠低於做「身體」的機器人股（50-70倍）

**百德 (4538)** - 機器人單元/鑽孔設備
- **本益比**: 28.4倍
- **核心競爭力**: 做機器人單元（Robot Cell），與德國Krones公司合作；鑽孔技術超強（半導體矽晶盤，1秒鑽1,500孔），5年前切入科磊

**台灣精銳 (4583)** - 行星式減速機
- **本益比**: 較高（股價895元）
- **核心競爭力**: 台灣第一大行星式減速機廠商，毛利率69.13%（業界最高），打進ASML、特斯拉組裝產線
- **催化劑**: 技術水準與德商威騰斯坦相當甚至超越日商，交期遠短於競爭對手
- **目標價**: 挑戰突破前高995元，有機會站上千元
- **操作建議**: 高貴不貴，拉回可佈局

**復田 (6909)** - 高效化馬達
- **本益比**: 較低
- **核心競爭力**: 大股東為中鋼，與特斯拉合作近20年，與馬自達合作電動車馬達，開發無人機動力馬達（已逐步出貨）及機器人多關節馬達

**上銀 (2049)** - 工具機龍頭

#### 股東人數變化（自2024/11/6川普當選以來）

- **投資等級債**: -16,000人（資金流出）
- **美國公債**: -26,000人（資金流出最多）

#### 非投資等級債 vs 投資等級債比較
| 項目 | 非投資等級債 | 投資等級債 | 美國公債 |
|------|------------|-----------|---------|
| 存續期間 | 2-3年（短天期） | 較長 | 最長 |
| 利率敏感度 | 低 | 高 | 最高 |
| 票面利率 | ~7% | ~5% | 最低 |
| 停止升息以來報酬 | 15.75% | 6.65% | 3.28% |
| 川普當選以來報酬 | 1.02% | 0.78% | 0.40% |

#### 推薦標的：00953B 群益優選非投等債
- **年化配息率**: 持續8%以上
- **特色**: 高票息 + 短天期
  - 僅篩選票面利率6%以上的債券
  - 排除CCC及以下評級（違約率從24.59%降至0.14%）
  - 存續期間僅2年左右，波動低
  - 用信用因子加權（非市值加權），降低違約風險
  - 發行人上限1%，產業上限10%
- **最新配息**: 0.07元（2/18配息），年化配息率8.1%
- **最後買進日**: 3月5日，3月6日除息，3月30日入帳
- **操作建議**:
  - 穩定高配息偏好：分批買進非投資等級債
  - 做價差偏好：逢跌買進投資等級債

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **HBM（High Bandwidth Memory）** | 高頻寬記憶體，AI晶片專用的堆疊記憶體技術，目前由SK海力士主導 |
| **Cube** | 華邦電開發的類似HBM的3D堆疊記憶體技術 |
| **行星式減速機** | 機器人關節核心零組件，將馬達高速旋轉減速為低速高扭力輸出 |
| **Robot Cell** | 機器人單元，整合多個機器人和設備的自動化生產單元 |
| **本益比（P/E Ratio）** | 股價除以每股盈餘，衡量股票估值的指標 |
| **非投資等級債** | 信用評等在BB以下的債券，風險較高但票息也較高，舊稱「高收益債」或「垃圾債」 |
| **存續期間（Duration）** | 債券價格對利率變動的敏感度指標，存續期間越短，利率敏感度越低 |
| **神龍擺尾** | 股票在尾盤突然大量拉升的走勢 |
| **00953B** | 群益優選非投資等級債券ETF |
