## 🌍 市場總體觀察

### 博通（Broadcom）帝國傳奇 - 打工皇帝陳福陽

#### 博通與輝達並列2025年頂尖投資標的

**背景**:
- 華爾街投資銀行 Bernstein 最新報告將輝達（NVIDIA）與博通（Broadcom）並列為2025年兩家頂尖股票
- 過去一段時間，輝達股價回測近一個月低點，同期博通股價上漲超過27%

**為什麼博通被看好**:
1. **AI營收爆發**: 單純以AI部門而言，營收年增率高達220%（vs 輝達整體約80%+）
2. **XPU自研晶片趨勢**: 四大雲端巨頭（Google、亞馬遜、微軟、Meta）不希望命運被輝達一家掌控，紛紛自研AI晶片
3. **網通領導地位**: WiFi6到WiFi7升級，博通為關鍵供應商
4. **與台積電深度合作**: CPO矽光子技術、先進製程合作

#### 陳福陽（Hock Tan）人物剖析

**背景經歷**:
- 1952年出生於馬來西亞檳城，華人背景
- 高中畢業獲獎學金進入麻省理工學院（MIT），取得碩士學位
- 進入陶氏化學，後獲哈佛MBA
- 進入通用汽車，遇到財務主管貴人，學會財務管理與節省成本
- **54歲**才進入半導體公司安華高（Avago）擔任執行長
- 2016年以小吃大，併購舊博通，保留「博通」品牌
- 打造市值30兆美元的博通帝國

**管理風格 - 鐵血經營**:
- 持股不到1%，但年薪高達1.6億美元（標普500最高薪CEO）
- 併購博通後立即裁員2,000人
- 承諾一年內毛利率提升至60%，結果真的從55%拉升至60%
- 不提供員工福利休閒設施，純粹以績效為導向

**前瞻性預言**:
- 五六年前在台積電三十周年論壇即預言：雲端服務商的影響力將貫穿整個科技產業
- 預言伺服器大廠最終會設計自己的晶片（現已一一驗證：Meta、Google、字節跳動皆自研晶片）
- 從B300之後，輝達提供GPU連結器，客戶自行做CPU（ASIC），這正是博通的強項

### 二、回測教學 - 瞬間老師獨家課程

#### 三種回測類型

**1. 回測移動平均線**
- 短線平均成本：5日線、10日線（月線）
- 中長線平均成本：季線、半年線、年線
- **關鍵判斷**: 比較個股回測的均線 vs 大盤回測的均線
  - 大盤測半年線，個股只測月線或5日線 = 相對強勢
  - 大盤測半年線，個股測年線 = 相對弱勢

**2. 回測頸線或趨勢線**
- 頸線：底部完成後突破的水平線，回測即為買點
- 趨勢線：將所有低點貫穿的上升趨勢線

**3. 回測大量和KD指標**
- 前波大量區為重要支撐
- KD最好在50以上
- 大量低點守住 + KD穩在50以上 = 持強買進

#### 回測成功案例

**達邁（3645）- 回測5日線成功**
- 1月13日低點62.8元，回測5日線63.5元
- 大盤在測半年線，達邁只測5日線 = 強勢
- 題材：四代矽基亞安薄膜，AI眼鏡概念
- 回測隔日拉出紅黑棒 = 測試成功

**升達科（3491）- 回測頸線成功**
- 1月13日低點357元
- 回測12月12日前高頸線362元位置（接近成功）
- 回測成功後隔日即拉出紅K
- **最佳買點**: 測試成功隔天開黑又留上影線時

**冰台 - 回測大量與KD指標成功**
- 1月13日低點39.35元
- 回測12月24日大量區37.7-42.2元成功
- KD指標在50向上
- 代理歐美日關鍵設備，跨食品與化工產業
- Q4營收月增79%、年增84%，創歷史新高
- 導入機械手臂、客製化飲料，轉機性十足
- **測試成功後連續拉出兩根漲停板**

#### 回測失敗案例

**啟碁（6285）- 回測年線失敗**
- 1月13日低點515元，已測年線
- 大盤在測半年線，啟碁已破年線 = 相對弱勢
- 中國客戶比較多，消息面偏負面
- 回測完後連續往下走
- **操作建議**: 反彈到5日線或10日線附近站在賣方，先跑一趟，換股操作

**紅海（暫音譯）- 回測頸線/前低失敗**
- 測1,380元前低與頸線1,400元位置
- 回測跌破，呈現續落
- 輝達下修B200/擴散規格訂單受影響
- 營收創歷史新高但利多不漲反跌
- 頸線為階梯式下降
- **操作建議**: 反彈站在賣方，不宜在此加碼

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| XPU | 泛指各種AI專用處理器（ASIC），非通用GPU |
| ASIC | 特定應用積體電路，為特定用途設計的晶片 |
| WiFi7 | 最新一代無線網路標準，速度與延遲大幅改善 |
| CoWoS S/L | 台積電先進封裝技術的不同版本（S=較小晶片，L=大型晶片） |
| 2B法則 | 股價突破前高後又快速跌回前高以下的假突破型態 |
| 頸線 | 底部型態（如頭肩底、W底）的突破關鍵水平線 |
| 趨勢線 | 連接多個低點（上升）或高點（下降）的直線 |
| 回測（Pullback） | 股價突破後拉回測試支撐的動作 |
| 打工皇帝 | 指持股極少但領取天價薪酬的職業經理人 |
| 標普500 | 美國最具代表性的500家大型上市公司指數 |
