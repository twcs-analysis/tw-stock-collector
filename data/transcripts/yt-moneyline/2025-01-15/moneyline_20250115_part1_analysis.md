## 💼 產業分析與投資建議

### 一、塑化族群（跌深反彈，不宜追高）

**代表個股**: 台塑（1301）

**技術面分析**:
- 破底後連續三根紅黑棒反彈
- 月線扣抵值仍比現在高，季線扣抵值也偏高
- 屬於「空頭市場跌深反彈」，不太可能單腳翻轉

**操作建議**:
- 短線操作者：以今日低點為停損，跌破即出場
- 長線投資者：需等待第二隻腳或第三隻腳牛轉向上再考慮做多
- 月線至季線區間為第一隻腳的壓力區
- **風險提示**: 中國大陸對原物料需求未明顯上來，通縮問題未解決；川普1月20日上任後大量開採政策可能壓抑油價

### 二、鋼鐵族群（題材面熱度高但基本面不支撐）

**代表個股**: 大成鋼（2027）、冶星

**題材面**:
- 美國洛杉磯大火帶來重建需求
- 川普基礎建設政策預期

**書方老師觀點**:
- 加州大火的重建題材不如加薩走廊或烏克蘭重建規模，且後兩者題材都未實現
- 美國房屋多為木造，鋼鐵需求有限
- 大成鋼雖在美國設廠，但過去川普時期加徵關稅，鋼鐵股也未因美國設廠而大幅受惠
- KD指標已鈍化到極致後開口向上，屬於跌深反彈
- 到月線附近即面臨均線糾結的壓力，仍會有第二隻腳或第三隻腳

**操作建議**: 短線反彈行情，不宜追高

### 三、AI VR/眼鏡概念股

**代表個股**: 宏達電（2498）

**現況分析**:
- CES展傳出輝達已申請AI眼鏡專利
- 宏達電為最早進入VR/AR的台廠
- 今日在大盤下跌中漲幅超過6%
- KD低檔黃金交叉

**書方老師觀點**:
- 目前所有研究報告都未顯示AI VR產品今年會大爆發成長
- Meta都還在虧錢，宏達電更難賺錢
- 每次出現大紅棒後續航力不足，缺乏連續性
- 年線扣抵仍偏高，整體呈大區間整理

**操作建議**: 除非Meta狀況好轉，否則宏達電在大區間整理的可能性較高

### 四、CPO矽光子概念股（年後圖圍重點之一）

**代表個股**:
- 上詮（3363）- 目標價被外資喊至600元
- 聯亞（3081）

**產業趨勢**:
- CPU矽光子是2025-2027年獲利與營收最爆發的產業
- 繼CoWoS之後最爆發的技術
- 全球大型晶片公司都在搶CPO技術

**書方老師觀點**:
- 上詮（3363）今日一開盤就鎖漲停，無量鎖到底（分盤交易）
- 外資給上詮目標價600元（現價257元），但有很多前提條件
- 2025年EPS僅1.3元，要到2027年才可能賺35-40元，本益比15-17倍
- 目前股價已被分盤交易，KD與量同步背離時不要追高
- 聯亞（3081）也是CPO概念股，已創高

**操作建議**: CPO產業確實看好，但個股追高風險大，宜等拉回再布局

### 五、半導體特用化學

**代表個股**: 台特化

**現況分析**:

- 未來將隨台積電（週五法說）波動加大

### 六、機器人概念股

## 📈 技術面分析與操作策略

### 大盤技術面判斷

**書方老師 - 複合式底型分析**:

1. **KD指標**: 已進入超賣區（19/33），屬於反向操作時機
2. **複合式底型特徵**:
   - 大家悲觀時不要過度悲觀（可能隨時反彈）
   - 大家樂觀時不要過度樂觀（可能隨時拉回）
3. **空方勢判定**: 只要股價未站上復律均線兩個營業日以上，空方勢持續
4. **重個股輕指數**: 複合底型期間以個股操作為主
5. **量能觀察**: 沒有量就沒有方向，但乖離率到達4%以上會有反彈契機

### 世事記老師 - 年後圖圍股策略

**三大圖圍方向**:

1. **矽光子/CPO**: 台積電法說會若提及先進製程中的CPO進展（下半年1.6吋光傳輸CPO，已與博通合作確認），將引爆相關個股

2. **剛冒出頭的新科技**:
   - AI眼鏡、機器人等具位置與籌碼優勢的概念股
   - 大部分人噴出時不敢買，但大部分人不重視時應買進一線股

3. **低位傳產股**:
   - 鋼鐵股位置都很低
   - 川普基礎建設 + 加州重建雙題材
   - 可當觀察指標，未必建倉

**操作心法**: 「買股不遭急，點位個股對了，到位再加」

**富財旗（暫音譯）**:

- 去年Q3單季終於轉虧為盈
- 底型有互織浮出感覺，慢慢做底部形態

#### 鋼鐵指標股

**海光（暫音譯）**:

**大成鋼（2027）**:

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| 複合式底型 | 股價在底部區域反覆震盪，形成多次低點的底部形態 |
| CPO（Co-Packaged Optics） | 共同封裝光學，將光學元件與電子晶片整合封裝的技術 |
| 矽光子 | 利用矽基材料製造光學元件的技術，用於高速光通訊 |
| COVA | 緊湊型通用光直引擎，台積電開發的CPO技術 |
| CoWoS | 台積電的先進封裝技術（Chip on Wafer on Substrate） |
| TSV（Through-Silicon Via） | 矽穿孔技術，用於3D堆疊封裝 |
| KD指標 | 隨機指標，用於判斷股票超買或超賣 |
| 空方勢 | 股價持續低於均線的空頭趨勢 |
| 乖離率 | 股價偏離移動平均線的程度 |
| 分盤交易 | 台灣證交所對波動過大個股實施的交易管制措施 |
