## 🌍 市場總體觀察

### 國際總經分析

#### 美國經濟數據
- **核心CPI**: 年增3.2%（預期3.3%），略低於預期
- **降息預期變化**: 從預期九月降息，回到六月降息預期
- **Fed理事華勒**: 主張今年降息三到四次
- **市場共識**: 今年可能僅降一次，甚至不降

#### 川普新政府財政挑戰

**財政部長貝森特（Bessent）「333計畫」**:
- 財政赤字縮減至GDP的3%以內
- 削減開支
- 減稅

**現實困境**:
- 美國固定開支（社保、醫療、國防）佔聯邦預算80%，難以削減
- 減稅 + 削減開支 = 矛盾（收入減少卻要減開支）
- 川普野心（格陵蘭、巴拿馬運河控制權、加拿大）都需要花錢
- **結論**: 增發美債是必然趨勢

**成立「外部稅務局」(ERS)**:
- 相對於IRS（國內稅務局），專門徵收國外關稅
- 表明關稅政策絕對會執行
- 關稅收入用來彌補國內減稅的財源缺口

#### 美債殖利率風險

**當前狀況**:
- 美國10年期公債殖利率約4.6%-4.7%
- 若突破5%，將對金融市場造成嚴重衝擊

**風險傳導機制**:
1. 增發美債 → 債券供給增加 → 價格下跌 → 殖利率上升
2. 殖利率上升 → 銀行壞帳增加 → 商業地產出問題
3. 企業與民眾對5%以上利率毫無準備
4. 投資人可能轉向穩定的債券收益，拋棄科技股

**前任政府遺留問題**:
- 葉倫時期為避免長債殖利率突破4.9%，改發大量短債
- 現在有3兆美元短債需要重新發行
- 貝森特上任後將面臨債務到期的棘手問題
- 若改發長債，10年期殖利率可能進一步攀升

#### 日本央行升息分析

**升息機率極高的原因**:
1. **美日利差已拉大**: 美債殖利率4.8%，日本僅0.25%，日本升一碼至0.5%合理
2. **川普態度**: 川普主張美元貶值、他國貨幣升值，不會反對日本升息
3. **通膨壓力**:
   - 日元貶值至150左右，進口成本高昂
   - 油價從66美元漲至82美元，以美元計價更痛苦
   - 今年第一季通膨數字將大幅跳升
4. **日本央行總裁植田已預告**: 若川普就任後無重大事件，將調整利率

**與2024年8月升息的差異**:
- 上次：日本升息 + 美國即將連續降息 → 利差快速收斂 → Carry Trade大量平倉 → 全球股災
- 這次：美國今年降息空間有限（可能僅一次或不降） → 利差收斂幅度小 → 平倉壓力較小
- **結論**: 會有震盪，但不會重演8月的全球性股災

### 投資市場結構性問題

#### 含台積電 vs 不含台積電的台股
- 台積電影響大盤接近30%權重
- **含台積電**: 大盤指數站上季線，表現不差
- **扣除台積電**: 指數破年線，表現疲弱
- 0050（含台積電）表現遠優於0056（高股息、不含台積電）
- **結論**: 台積電讓大家迷糊了，多數股票走空

#### 中國低價傾銷衝擊
- 成熟製程被中國大量低價傾銷
- 台灣第二線、面板等產業慘遭壓力
- 半導體設備股中，做不出先進製程的也受影響

#### ETF資金流向風險
- 2024年約有6,000億資金流入ETF
- 這些資金若鬆動或撤出，ETF成分股將面臨賣壓
- ETF的「骨牌效應」：買進時推升股價，撤出時拖累股價

## 💼 產業分析與投資建議

### 債券投資

#### 美債分析
- **直債 vs ETF**: 直債持有至到期可拿回本金+利息；ETF有價格波動風險
- **養老金/主權基金**: 買直債，放到到期日領息還本
- **散戶/投行**: 多買ETF，面臨價格波動壓力
- **殖利率展望**: 10年期殖利率出現初步高點，價格開始打底
- **建議**: 可以開始考慮進場，但不是因為日元避風港，而是殖利率出現見頂跡象

### 網友五大問

#### 1. 封關前操作策略
- 最後一批賣壓會在下禮拜一（T+2，禮拜三拿到錢）
- 若禮拜一川普未發表激進言論，賣壓將消退
- **預判**: 封關日與開紅盤日應為上漲，機率非常高
- **建議**: 原有持股若非太差，建議留著；若想買，禮拜一找有題材的強勢股

#### 2. 日本升息是否為壓垮台股的最後稻草
- 日本已從「偷襲珍珠港」教訓中學會，不會再次突襲
- 53位日本經濟學家中70%預測1/24日本央行會升息
- 日元已連續兩天大幅升值，市場已提前反應
- **結論**: 不會是壓垮台股的最後稻草，升息宣布後反而可能利空出盡

#### 3. 存台積電 vs 存鴻達電 (6592)
- **長線**: 存台積電絕對優於鴻達電，競爭力與產業地位不可比
- **短線**: 鴻達電題材（CES展AI眼鏡、與NVIDIA合作）使短線操作贏過台積電
- **技術面**: 鴻達電大量低點不跌破即為短線買點，50元不破、回測5日線可買
- **建議**: 不是「存」的概念，是短線操作

#### 4. 四寶（台塑、中鋼等）與原物料股
- **反彈原因**: 跌太深反彈 + 股價淨值比極低（台化僅0.5倍）
- **題材**: 年節補庫存、中國加電補貼政策
- **操作重點**: 觀察季線、半年線位置與成交量
  - 台塑：碰到季線若爆量應先賣
  - 中鋼：突破季線量才出來，目標價也是季線
- **歷史經驗**: 每次碰季線都站不久
- **建議**: 空手可在回測5日線時短線介入，套在季線以上的人應趁反彈先賣

#### 5. 觀光股
- **催化劑**: 中國文化旅遊部宣布恢復上海與福建旅客團赴台
- **上海團意義**: 人多且有錢，量體大於福建
- **風險**: 兩岸政治不確定性，可能隨時變卦
- **續航力排序**: 旅行社 > 飯店 > 航空
  - 飯店：春節訂房率不可能瞬間從五六成衝到九成滿房
  - 旅行社：出國人數增加，受益面較廣
  - 航空：獲利本就不差，但基期較高
- **建議**: 短線操作以旅行社為主

## 📈 技術面分析與操作策略

### 美國10年期公債殖利率
- 初步出現波段高點（4.7%附近）
- 價格開始打底
- 若殖利率不再創新高，代表利空不跌了

### 台塑 (1301) 技術面
- 碰到季線爆量 → 先賣
- 歷史經驗：季線有壓力，每次碰到都回落
- 長線底部成形需要季線走平翻揚

### 中鋼 (2002) 技術面
- 今天突破季線，量能才出來
- 比台塑稍好，但季線壓力同樣存在
- 目標價為季線位置

### 鴻達電 (6592) 技術面
- 大量低點不跌破為短線買點
- 50元不破、回測5日線可買
- 外資近期在買，跟著外資做

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| Carry Trade | 套利交易，借入低利率貨幣（如日元）投資高收益資產（如美股、美債） |
| 殖利率 | 債券的投資報酬率，與債券價格反向變動 |
| ERS (External Revenue Service) | 川普計劃成立的外部稅務局，專門徵收國外關稅 |
| IRS (Internal Revenue Service) | 美國國內稅務局（國稅局） |
| 333計畫 | 貝森特提出的財政目標：財政赤字降至GDP的3%、經濟成長3%、增產300萬桶石油 |
| 股價淨值比 (P/B) | 股價除以每股淨值，低於1代表股價低於公司帳面價值 |
| 直債 | 直接購買債券（非透過ETF），持有至到期可拿回本金與利息 |
| 骨牌效應 | 此處指ETF大量買進或賣出成分股時，對股價產生的連鎖反應 |
| T+2 | 股票交割制度，賣出後兩個營業日才能拿到款項 |
