## 📈 技術面分析與操作策略

### 台股三大觀察指標

#### 1. 大盤量能
- **歷史對照**: 2021年5月重挫後，量能一路縮、指數正常後走高
- **目前狀況**: 2024年8月重挫後，量能同樣一路縮
- **關鍵**: 要脫離在機模式（類似2021年盤整後下跌），上漲時必須量增
- **風險**: 若量價持續背離，第二季（約4月）要特別留意，時間週期與2021年雷同

#### 2. 外資空單
- **目前**: 降至2萬多口，屬於避險單
- **安全水位**: 2-3萬口 → 偏多
- **警戒水位**: 4-5萬口 → 開始留意空方力道
- **已明顯改善**: 從之前4萬口高峰快速下降

#### 3. 台積電走勢
- **對照2021年**: 2021年台積電在600~700元盤整後，過高即下跌（在機模式）
- **目前**: 8月底低點後已站回1,100元以上
- **關鍵**: 1,100元以上 → 脫離在機模式
- **風險**: 若1,100元站上後又跌破成為反壓 → 在機陰影回來
- **政治風險**: 川普點名台積電，消息面隨時可能衝擊

### 2月/3月合約展望
- 已盤整大半年，期待突破
- 2月結算若能收在高點 + 3月順勢往上 → 空間漲幅有機會更大
- 下週前三天若拉大空間至24,000附近 → 3月就有機會表態

## 💼 ETF投資策略

### 四大ETF類型分析

#### 1. 市值型ETF
- **特性**: 以大盤漲跌為基準
- **操作**: 台股不漲時買（買在高檔配息也不差）、大跌時積極加碼
- **適合**: 最簡單的操作邏輯
- **代表**: 0050、006208
- **新上市**: 009803（寶德信市值型人），2月18日上市

#### 2. 產業型ETF
- **特性**: 需對產業成長有信心（信仰型投資）
- **風險**: 產業趨勢與川普政策風險
- **現金流**: 通常不高，配息次數少
- **操作**: 緊盯川普動向與產業趨勢
- **代表**: 太空、科技股、比特幣相關ETF

#### 3. 高股息型ETF
- **特性**: 現金流需求、穩定配息
- **近期議題**: 若無加徵健保補充保費，可能被迫加息
- **觀察**: 選股重複性高的ETF，若無法加徵則收益可能縮水
- **代表**: 0056、00878等

#### 4. 債券型ETF
- **近期熱門**: 非投資等級債（高收益債）殖利率較高
- **注意**: 非國債有信用風險補償，殖利率高有其原因
- **操作**: 定期定額、息收為主、債券分散配置
- **聯準會動態**: 短期不會快速降息，以零息為主

### ETF配置建議

| 類型 | 保守型配置 | 積極型配置 |
|------|-----------|-----------|
| 市值型 + 產業型 | 40% | 50%+ |
| 收息型（高股息 + 債券） | 60% | 30~40% |
| 其中高股息 | 30% | 較少 |
| 其中債券 | 30% | 較少 |

### 聯準會與貨幣政策

#### 通膨現況
- **PCE / 核心PCE**: 連續2-3個月上漲，卡在2.8%（目標2%）
- **CPI結構**: 商品OK、房屋和服務月增仍往上
- **聯準會態度**: 已移除「對通膨有信心」字眼，暫不急於降息

#### 降息預期
- 最快第二季（需CPI大幅降低或非農明顯降溫至10萬以下）
- 短線美債殖利率維持4.5%左右
- **影響**: 降息延後 → 美元偏強 → 外資買盤不會快速回流台股

### 關稅對美股影響

#### 與2018年比較

| 面向 | 2018-2019（關稅1.0） | 2025（關稅2.0） |
|------|---------------------|----------------|
| 時間 | 上任第二年才課 | 上任第一年立即課 |
| 方式 | 分品項、分金額逐步加 | 全部商品一次課 |
| 對象 | 主要針對中國 | 墨加中全面，可能擴及台灣 |
| 規模 | 約3,700億美元（對中國） | 已達1.45兆美元（墨加中合計） |
| 美股影響 | 小跌幅3.5%~8.8%，大跌幅更重 | 預估類似，無可勝負上下一點 |

#### 關鍵差異
- 2018年背景是聯準會升息（ISM從高峰往下），景氣正在降溫
- 2025年背景是聯準會降息（ISM從低點往上），景氣正在復甦
- **信用利差**: 2018年擴大（景氣擔憂）、目前維持低檔下降（景氣穩健）
- **結論**: 關稅對股市只是短暫干擾，拉回都是逢低買進的機會

## 🌏 國際商品與匯率分析

### 美元指數
- **川普交易**: 當選前走強（預期課稅）→ 上任後走弱（利多實現）
- **區間**: 高點約110 → 目前回落至108以下
- **正常區間**: 105~107
- **美國財長**: 「樂見強勢美元」→ 川普是否真的要弱美元仍是問號
- **結論**: 美元已見高回落，短線偏弱

### 美國十年期國債殖利率
- **高點**: 約5%（川普上任前的恐懼高峰）
- **目前**: 回落至約4.4%
- **正常區間可能**: 4%~4.5%
- **關鍵**: 川普財長希望長端利率降低（與聯準會降短端利率是兩碼事）
- **影響**: 若長端殖利率下降 → 債券偏強 → 有利股市

### 日圓
- **央行態度**: 升息速度越來越快（0.1% → 0.25% → 計劃升至1%）
- **會議紀要**: 關注日圓貶值過快（約160附近）
- **走勢**: 已跌破150~160盤整區間（日圓走強）
- **下次會議**: 3月19日（與聯準會同步）
- **春鬥**: 3月薪資談判，結果好則更有升息底氣
- **對台股影響**: 日圓強 → 工具機族群有利（日本競爭對手成本上升）
- **對美股影響**: 機率不大引發大震盪（上次套利交易衝擊已過）

### 原油
- **區間**: 65~80美元（持續盤整）
- **基本面**: 供給略大於需求
- **川普政策矛盾**:
  - 要加大開採（增供給 → 壓油價）
  - 把移民趕走（減勞動力 → 影響開採）
  - 制裁伊朗（減供給 → 撐油價）
- **結論**: 無特殊事件下維持區間震盪，需站回80美元以上才有突破

### 農產品
- **走勢**: 2024年下半年已悄悄先動（玉米、黃豆、小麥）
- **漲幅**: 低點376.5 → 目前498（+20%）
- **驅動因素**:
  1. 中美貿易協商（中國是最大買家）
  2. 川普當選後農產品明顯轉強
  3. 天氣因素
- **觀察**: 是否醞釀通膨回升的先兆
