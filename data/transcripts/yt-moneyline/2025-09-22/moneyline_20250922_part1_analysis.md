### 美股/國際影響

#### 輝達入股Intel震撼分析
- **背景**: 輝達宣布入股Intel，市場擔心威脅台積電
- **對台積電影響**: 基本無影響
  - 輝達成功基於IC設計與製造分工，不會支持Intel的晶圓製造
  - 輝達自家GPU不會下單給Intel
  - 博通與輝達目前都放棄Intel 18A，轉向14A工藝（2029年才下線）
  - 短期晶片訂單仍給台積電
- **合作範圍**:
  - Intel為輝達定製x86 CPU（輝達原用ARM架構）
  - PC端整合輝達RTX GPU
  - 輝達NVLink快速連結Intel CPU與輝達GPU
- **對聯發科影響**: 較大，因ARPC相關業務受衝擊

#### 聯準會降息
- 上週四宣布降息一碼（25bp）
- 暗示年底前還有兩碼降息空間
- 市場預期：10月降至3.75-4%，12月降至3.5-3.75%
- 利率底部已確認，開始走向多頭降息循環

### 一、Intel成王之路 - 台積電供應鏈機會

#### 台積電成功之路回顧
- 1985年張忠謀創立，定調純晶圓代工模式
- 2011年率先導入FinFET
- 2017年鎖定HPC高速運算晶片

### 三、非投資等級債券ETF

#### 降息循環下的債券策略
- **歷史數據**: 降息循環後，非投等級債報酬率明顯高於美國公債與投資等級債
  - 2007-2011：非投等級債報酬6-8%，遠超投等債
  - 2019-2022：非投等級債接近8%，美國公債與投等債表現平平
- **降息後三年累計報酬**: 非投等級債可達34%（公債與投等債僅12-15%）
- **風險報酬比**: 非投等級債CP值1.3，台灣高股息僅0.15

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **FinFET** | 鰭式場效電晶體，台積電2011年率先導入的立體電晶體結構，大幅提升晶片效能與良率 |
| **GAA（Gate-All-Around）** | 閘極全環電晶體，下一代電晶體架構，台積電2025年兩奈米開始採用 |
| **EUV** | 極紫外光微影技術，先進製程的關鍵設備，台積電2018年領先導入 |
| **ARPC** | AI PC，整合人工智慧功能的個人電腦，需求帶動相關晶片與BIOS升級 |
| **NVLink** | 輝達的高速互連技術，用於GPU與CPU之間的快速資料傳輸 |
| **ISL（Inter-Satellite Link）** | 衛星間連結技術，低軌衛星之間的通訊連接 |
| **TT&C** | 遙測、追蹤與指揮站，衛星地面控制設備 |
| **墮落天使債** | 原為投資等級債但因公司營運惡化被降評為非投資等級的債券，常有超額報酬機會 |
| **非投資等級債** | 信用評等低於BBB-的債券（又稱高收益債），殖利率較高但風險也較高 |
| **存續期間** | 債券對利率變動的敏感度指標，存續期間越長，利率變動對價格影響越大 |
