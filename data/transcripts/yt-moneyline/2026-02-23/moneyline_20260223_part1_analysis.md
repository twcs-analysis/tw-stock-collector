## 💼 產業分析與投資建議

### 一、美國最高法院裁定 IEEPA 關稅違法

**事件摘要**：
- 美國聯邦最高法院以 6:3 裁定，川普使用《國際緊急經濟權力法》（IEEPA）課徵對等關稅違法
- 理由：IEEPA 法條僅提及「管制進口」，並未明文授權「課徵關稅」
- 川普隨即援引《貿易法》第 122 條，全面課徵 15% 關稅

**後續影響**：
- 122 條限制：最高稅率 15%、最長 150 天（需國會批准延長）
- 川普將加速推動 232 條（國家安全）及 301 條（不公平貿易）調查
- 已簽署的各國貿易協定繼續履行，不受判決影響

**對台灣影響**：
- 電子資訊產品約 76% 享有零關稅（232 豁免），影響極小
- 傳產業者：稅率維持 15%，相對影響較大
- 台灣擁有「最惠國待遇」，相對有利
- 中國維持 48% 高關稅，東南亞國家從 19%-46% 降至 15%，競爭格局改變

### 二、機器人產業 ── 2026 商用元年

**產業趨勢**：
- 2026 年定調為人型機器人「從實驗室跨入工廠商用」元年
- 國際研調機構預估，人型機器人市場年複合成長率近 40%
- 2030 年全球產值達 152 億美元
- 中國春晚機器人表演引發全球關注，AI 實體化趨勢加速

**推薦標的**：

| 股票 | 代號 | 定位 | 投資邏輯 |
|------|------|------|----------|
| 新代 | - | 機器人大腦/控制器 | 指標股，已創歷史新高，EPS 可賺兩個股本，毛利率高 |
| 盟立 | - | 系統組裝/關節 | 與新代組成「安心盟」聯盟，低價、位階不高，打完碗型底 |
| 全球傳動 | - | 微型滾珠螺桿 | 已接到兩岸客戶訂單（中國4家、台灣1家），今年將貢獻營收 |
| 光宇 | - | 電機/關節模組 | 鴻海集團子公司，送樣全球四大機器人廠，目標2030年搶5%市佔 |

**操作建議**：
- 新代已大漲一倍，不建議追高
- 盟立為低位階替代標的，均線已翻揚，可試機進場
- 光宇（廣宇）位於相對低檔，量縮整理完畢，逢低佈局
- 全球傳動：封關前測試月線後反彈，過前高 53.8 機率大

## 📈 技術面分析與操作策略

### 台積電
- **盤中最高**：1,935 元（再創新天價）
- **收盤**：留下上影線，略帶目碑線特徵
- **ADR 封關期間**：上漲 2.3%，但現貨僅漲 0.2%
- **策略**：方向未變，持續向上；想上車者可直接買進或透過市值型 ETF（如 00500）

### 記憶體族群
- **萬鴻**：突破百元，不追高，等十日線回檔買
- **華邦電**：漲停，但離前高仍有一段距離
- **南亞科**：離上方壓力較近，反彈力道弱
- **封測股**（台波、輔強）：經過中段整理，安全性較高
- **策略**：整體仍在中期整理階段，封測股操作性較佳

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| IEEPA | 國際緊急經濟權力法（International Emergency Economic Powers Act），美國總統宣布國家緊急狀態時可動用的經濟制裁工具 |
| 232 條款 | 美國貿易擴大法第 232 條，以國家安全為由課徵關稅 |
| 301 條款 | 美國貿易法第 301 條，針對不公平貿易行為課徵關稅 |
| 122 條款 | 1974 年貿易法第 122 條，總統可暫時課徵最高 15% 關稅，最長 150 天 |
| 乖離率 | 股價與移動平均線之間的偏離程度，乖離率過大時容易回檔修正 |
| 季線 | 60 日移動平均線，中期趨勢的重要參考指標 |
| 庫藏股 | 公司買回自家股票，可減少流通在外股數、提升每股盈餘 |
| 諧波減速機 | 機器人關節中的核心零組件，將高速馬達轉速降低並放大扭力 |
| 安心盟聯盟 | 新代科技與盟立組成的機器人製造聯盟，致力於台灣機器人供應鏈自主化 |
