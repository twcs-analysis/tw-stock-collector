## 🌍 市場總體觀察

### 關稅攤牌倒數

#### 當前局勢
- 美國總統川普宣布 8/1 為關稅最後期限，不再寬限
- 台灣代表團本週再赴美協商
- 日本、韓國均面臨 25% 關稅
- 台灣目標：爭取關稅率低於日韓的 25%

#### 8/1 關稅對市場影響
- 關稅公佈前：市場不敢大買，觀望氣氛濃
- 關稅公佈當下：多空決勝負
- **關鍵結論**: 若關稅沒有想像中慘，美元、原油、台股都可能反彈

### 日本大選深度解析

#### 選舉結果
- **自民黨聯盟慘敗**: 參議院席次大幅流失，自民黨與公明黨連一半席次都沒過
- **石破茂不肯下台**: 以「對美關稅談判責任在身」為由拒絕辭職
- **在野黨崛起**: 共產黨、立憲民主黨等在野聯盟席次顯著擴增

#### 敗選三大原因

**1. 通膨失控 -- 核心打擊**
- 日本通膨率 3.5%，為全亞洲已開發經濟體最高（台灣僅 1.5%）
- 米價較去年翻倍，引爆民怨
- 實質薪資連續 4 年收縮：名目薪資年增 1-3%，但物價漲幅更快
- **冰河期世代**（1980-90 年代進入職場者）：泡沫破滅 → 長期通縮 → 現在通膨侵蝕退休金
- 具體物價漲幅（2022-2025）:

| 項目 | 漲幅 |
|------|------|
| 東京迪士尼門票 | 9,400 → 10,900 日圓（+16%） |
| 麥當勞大麥克 | +73% |
| 大白王將 | +38% |
| 吉野家 | +17% |
| 壽司收市 | +5% |
| 衛生紙 | +2% |
| NTT 東日本（電信） | +400 日圓 |

**2. 反移民/反中情緒**
- 日本境外移民約 350-400 萬人
- 中國為日本最大海外移民來源（約 120 萬人）
- 中國留學生激增：從 7-8 萬增至 12-13 萬/年
- 外國人購買東京三區新建公寓比例：從 15% 升至 21%（每 5 人買房就有 1 個外國人）
- 年輕人投票 70% 投給在野黨

**3. 對美關稅談判不力**
- 石破茂對美態度強硬但未爭取到更好條件
- 稻米自給率 9% 打死不開放，得罪城市選民

#### 政策影響展望

**能源政策風險**:
- 在野黨反核能，要求立即轉型再生能源
- 若核電廠大幅關閉 → 電價調升 → 通膨加劇

**財政擴張壓力**:
- 在野黨主張增加公司稅、大幅減少消費稅
- 全面性現金普發（每人約 2 萬日圓）
- 所有措施都需要舉更多債 → 日本國債被拋售

**日本 30 年期公債殖利率**: 已挑戰 3.5%，速度極快

## 💼 產業分析與投資建議

### 一、投資商品展望

#### 日圓 (JPY)

**短線**: 偏弱，可能繼續貶值以救出口
- USD/JPY 在 140-150 區間整理
- 短線靠近 150 關口，8/1 前後可能表態方向

**中長期**: 偏向升息，貶值空間有限
- 日本面臨停滯性通膨，央行最終只能升息
- 日圓長期貶值趨勢的高點越來越低（已離 160 高點遠）
- 手上滿手日圓不用太悲觀

**操作建議**:
- 手持日圓者：不必急著在此階段特別悲觀
- 若有 200-300 萬台幣等值日圓：可考慮在東京購置不動產（五至七成貸款可行）
- 等待真正升息啟動再做大幅度調整

#### 美元指數 (DXY)

**短線**: 反彈起，有機會挑戰 100
- 美元指數近期在 100 下方整理
- 美國 Q2 GDP（7/30 公佈）預計不差
- 降息預期未大幅增加 → 支撐美元

**中期觀察**:
- 7 月底 FOMC 會議將釋放 9 月降息方向
- 若分歧很大，9 月不太容易降息
- 新任聯準會主席上任後「肯定會降」→ 美元長期偏弱
- **結論**: 短線偏強，不要太悲觀美元

#### 黃金

**走勢判斷**: 偏強，三角收斂後有機會向上突破
- 已回到月線與季線之上
- 三角收斂形態：上方平坦 → 向上突破機率較大
- 美元反彈中，黃金仍不弱 → 比原本想像的還強
- 7-8 月現貨溢價高於期貨 → 實體需求強勁

**操作建議**:
- 可做中場期投資觀察
- 等待三角收斂突破後順勢操作
- **目標**: 若突破則看新一波漲勢

#### 原油

**走勢判斷**: 64-65 美元為供需平衡區，有支撐
- IEA 報告：今年 60-65 美元大概就是供需平衡
- 下方 55 美元為極端情境（類似 COVID-19 級別的需求崩塌）
- 夏季用油旺季 + 美國經濟不差 → 有機會向上挑戰

**操作建議**:
- 64 美元不跌破 = 有轉機
- 台塑集團油化股已先行反映，可留意

#### 美國公債

**殖利率走勢**: 長短利差可能擴大（熊陡）
- 短債殖利率下行（穩定幣翻案、降息預期）
- 長債殖利率上行（通膨預期、美國政府信用問題）
- 4.5% 為上方壓力，4% 以下為相對較貴

**操作建議**:
- 手上已持有長債：只能領息持有，不必期待賺價差
- 不建議新增長債部位
- 並非降息就一定能賺錢，注意長短債分化

### 二、台積電匯損與避險策略

#### Q2 匯損狀況
- **表面上 Q2 沒有匯損** -- 但有特殊原因
- 平均匯價用 4-5-6 月的 31 元計算，6 月底才到 29 元
- 營收層面的匯損還沒反映在 Q2，**將反映在 Q3**

#### 其他企業匯損慘狀
| 企業 | Q2 匯損 | 備註 |
|------|---------|------|
| 中華郵政 | 虧損 293 億（外幣兌換損失 1,400 億） | 上半年 |
| 大立光 | 匯損 42 億 | Q2 美元獲利 31 元被匯損吃掉 3 個股本 |
| 壽險業 | 創開業以來最慘紀錄 | 5 月份數據 |

#### 台積電匯損避險三招
1. **借美元製舊**: 借美元負債抵銷美元資產貶值，成本約 7-8%（比傳統 NDF 的 10% 便宜）
2. **付款幣別改美元**: 要求供應商以美元計價，從源頭減少台幣兌換需求
3. **資本支出對沖**: 美國廠建設支出直接用美元，不匯回台灣

#### BVI 子公司架構
- 台積電成立以美元計價的 BVI 子公司
- 大部分美元資產轉移至子公司底下
- 美元市場價格波動不影響母公司台幣報表

#### 重要觀點
- Q3（7-9 月）若平均匯價維持 29 元，匯損才會真正反映
- 已開始反映匯損的公司 → 反而是好事（利空出盡）
- 沒反映的 → 要小心 Q3 壓力

### 三、台灣出口與半導體管制風險

#### 出口高基期
- 台灣上半年出口年增 25.9%（遠超韓國、新加坡、日本、中國）
- 明年要維持此成長率非常困難
- 台北基電一年期前瞻本益比已從 14 倍回到 18-20 倍

#### 半導體管制風險
- 台灣對馬來西亞出口運算晶片暴增（年增 94%），可能存在非法轉運
- 美方可能加強審查
- 台灣企業需主動表態合規

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **NDF** | 無本金交割遠期外匯（Non-Deliverable Forward），一種外匯避險工具 |
| **BVI** | 英屬維京群島（British Virgin Islands），常見的境外公司設立地 |
| **熊陡（Bear Steepening）** | 長期利率上升快於短期利率，通常反映通膨預期或信用風險上升 |
| **停滯性通膨（Stagflation）** | 經濟停滯但通膨持續上升的困境 |
| **冰河期世代** | 日本 1990 年代泡沫破滅後進入職場的世代，面臨就業困難與長期通縮 |
| **春鬥** | 日本每年春季的勞資薪資協商（春季鬥爭），決定年度加薪幅度 |
| **高基期效應** | 去年同期表現太好，導致今年即使實際表現不差，成長率也會下滑 |
| **前瞻本益比** | 使用未來預估 EPS 計算的本益比，反映市場對未來獲利的預期 |
| **二三二調查** | 美國貿易法第 232 條款調查，針對國安理由對特定進口品加徵關稅 |
