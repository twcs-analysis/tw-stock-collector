## 💼 產業分析與投資建議

### 一、PCB 產業鏈深度分析

#### 產業分類

**1. ABF 載板**
- 三雄：南電、欣興、景碩
- 用途：承載 CPU/GPU 等晶片
- 投信一致買超，仍有機會上漲

**2. AI PCB（伺服器板）**
- 分為三種板子：
  - **UBB 板（通用板）**: 通用型伺服器主板
  - **OAM 加速板**: 放置 GPU（如 8 顆 GPU 一板）
  - **交換器板**: 資料交換用
- 主要公司：金像電（龍頭）、高技、電影（轉型）
- **為何 AI PCB 這麼貴**: 高速傳輸、高散熱（GPU 功耗數百瓦至上千瓦）、多層次（14-50 層以上）、線寬線距 30 微米以下、特殊製程（MSAP）

**3. HDI 板**
- 主要做高密度互連板
- 華通、健鼎、新新等

**4. 銅箔基板（CCL）/材料**
- 龍頭：台光電（已破千元）、台燿、聯茂
- 玻璃纖維布：台玻、副橋、建中
- 銅箔：金居、龍科

**5. MSAP 製程說明**
- 傳統製程：減成法（先鍍銅再蝕刻）
- 新製程：改良式加成法（MSAP）-- 先鋪光阻再鍍銅
- AI PCB 必須用 MSAP 才能做到更細線距
- 不是想做就能做，技術門檻極高

#### AI PCB 推薦個股

- 伺服器 PCB 龍頭，AI 伺服器滲透率接近五成

- **目標價**: 持續看高，多頭未見出量訊號
- **停損點**: 跌破十日線且帶量

**2. 高技 (5439) -- 字幕供應鏈**

- 資本支出大增，未來 2-3 年成長無虞

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **ABF** | 味之素製膜（Ajinomoto Build-up Film），高階 IC 載板使用的關鍵材料 |
| **MSAP** | 改良式半加成法（Modified Semi-Additive Process），AI PCB 使用的先進製程 |
| **HDI** | 高密度互連板（High Density Interconnect），提升線路密度的 PCB 技術 |
| **CCL** | 銅箔基板（Copper Clad Laminate），PCB 的核心基材 |
| **PI 膜** | 聚醯亞胺膜（Polyimide Film），耐高溫材料，用於 AI 眼鏡、折疊手機等 |
| **OAM** | 開放式加速模組（Open Accelerator Module），GPU 加速卡使用的 PCB 板 |
| **UBB** | 通用基板（Universal Baseboard），伺服器通用主板 |
| **券資比** | 融券餘額占融資餘額的比例，越高代表做空比例越大，軋空潛力越大 |
| **景氣燈號** | 國發會每月公佈的景氣對策信號，紅燈為過熱、綠燈為穩定、藍燈為衰退 |
| **賣權莊家** | 期貨市場中賣出選擇權的大戶，代表收取權利金認為行情不會大跌 |
