### 一、AI 材料升級大戰 — CCL 供應鏈深度分析

**產業背景 — 為什麼 CCL 持續成長**：
- AI 伺服器傳輸速度持續提升，需要更高的電源完整性與訊號完整性
- 各大廠往高層數 PCB 發展：
  - GB200/GB300：維持 22 層
  - Vera Rubin 系列：24-26 層
  - AWS 自研晶片：26 層
  - Google TPU：14 層
  - Meta：38-40 層
- 更高層數 = CCL 用量持續增加

**2026 年 ASIC 放量**：
- Google 晶片 2025 年約 160 萬顆
- 2026 年 ASIC 晶片整體成長 60%
- ASIC 廠商直接跳過氣冷，全面採用水冷散熱

**CCL 核心組成**：
- **銅箔**：占 CCL 成本 45%
- **玻纖布**：占 CCL 成本 35%
- 兩者合計占 80%

#### 銅箔升級三大方向
1. **更低的粗糙度**
2. **更高的平整度**
3. **更高的可靠度**

**供需面**：
- 印尼銅礦場事故影響供給，銅價持續創高
- 能切入高階銅箔的廠商極少
- 日東紡也在持續擴產
- 銅箔供需平衡預計要到 2027 年才能緩解

#### 玻纖布升級
- 重點在「熱膨脹係數」越低越好
- Laminite 可與 Low Dk 持續缺貨
- 日東紡預估供需平衡要到 2027 年才會緩解

**材料等級升級路徑**：M6 → M7 → M8 → M9，對應 HPLB-3 → HPLB-4 → HPLB-5

### 二、多雲端網路服務 — 受惠股分析

**核心概念**：
亞馬遜 AWS 與 Google Cloud 建立多雲端網路（Multi-Cloud Network），中間透過高速交換器互聯，讓消費者可以跨雲端無縫使用服務。

**四大好處**：
1. **延遲與吞吐改善**：大模型訓練 + 即時推論效率提升
2. **跨雲端運算**：不需再花數天認證轉換，直接跨平台操作
3. **安全治理**：兩大雲端聯手加密策略控制，支援金融、政府等高安全需求
4. **成本與效率**：消費者可自由選擇最佳方案

### 三、日本升息與日圓走勢

**背景**：
- 聯準會 12 月降息機率近 90%
- 日本央行植田和男暗示可能升息
- 日本首相高市早苗引用近畿劇人台詞鼓勵投資

**日經指數分析**：
- 歷史高點 52,666 點，修正低點 48,200 點
- 目前被月線壓制，從先前「站月線上方一路往上」轉為承壓
- 東證指數表現優於日經（金融、工業、消費權重較高）

**日本 ETF 選擇差異**：
- **日經 225 ETF**（國泰/元大）：科技、半導體權重高，價格加權 → 高價股影響大
- **東證指數 ETF**（富邦）：金融、工業、消費權重高 → 目前相對較強
- **日本商社 ETF**：巴菲特五大商社占比約 65%，走勢與市值型不同

**日圓走勢判斷**：
- 目前仍在月均線上方偏弱整理
- 需跌破月線才確認日元反彈，需跌破季線才確認日圓大幅升值
- 單純靠日本升息的升值幅度不會太大（上次大幅升值還有關稅因素）
- 建議：不要積極加碼日元，升值幅度不一定大

**風險提示**：
- 川普可能本月或下月公布對日關稅政策
- 若法院裁定關稅違法 → 市場動盪 → 日元可能走跌
- 日本政府總負債比超過 250%，但央行持有 46% 國債（左手欠右手）

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| CCL | Copper Clad Laminate，銅箔基板，PCB 的核心材料 |
| 銅箔 | 附著在 CCL 表面的導電銅膜，用於 PCB 電路佈線 |

| HPLB | High Performance Low-loss Board，高效能低損耗基板材料等級 |
| M8/M9 | CCL 材料等級分類，數字越大代表越高階 |

| CPO | Co-Packaged Optics，共同封裝光學，矽光子技術的一種應用 |
| 東證指數 | TOPIX，東京證券交易所綜合指數，市值加權 |
| 鷹派升息 | 央行以抑制通膨為優先，採取較積極的升息政策 |
