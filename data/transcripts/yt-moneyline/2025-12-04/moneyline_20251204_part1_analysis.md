### 4. 矽光子 / 全光交換概念
**分析師：明則**

技術解析「全光交換」（OCS，Optical Circuit Switch）：
- 核心原理：光訊號直接反射/導向到輸出端口，避免光電轉換（OEO）
- 優勢：超低延遲、節能達 80%、支援 800G/1.6T/3.2T 高頻寬、成本效益佳
- Google TPU（B4/B5）與 Iron Wolf 已採用全光交換技術
- Marvell 收購 Celestro（光子互聯技術公司），深度綁定亞馬遜

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| BDI（波羅的海乾散貨指數）| 衡量全球散裝航運運價的指標，涵蓋不同船型的運費 |
| BCI（波羅的海海岬型船指數）| 專門衡量海岬型散裝船（主要運載鐵礦砂、煤炭）的運價指標 |
| OCS（全光交換）| Optical Circuit Switch，光學網路交換技術，光訊號直接反射導向而不經光電轉換 |
| OEO（光電光轉換）| 傳統光通訊需將光訊號轉成電訊號再轉回光訊號的過程 |
| MLCC（積層陶瓷電容）| 被動元件核心產品，AI 伺服器大量使用 |
| WDM（波分複用）| 不同波長的光線在同一條光纖中同時傳輸的技術 |
| 國安基金 | 政府為穩定股市設立的護盤基金，1 月 11 日將開會決定是否退場 |
