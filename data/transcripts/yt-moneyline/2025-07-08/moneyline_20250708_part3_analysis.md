## 💼 產業分析與投資建議

### 一、6月營收創高選股法

#### 營收創高但匯損嚴重的判別
- 收台幣的公司：匯損影響較大，但若仍能創新高更具說服力
- 收美金多且仍能創高者：如台光電、堅點，最為強勢
- 中砂客戶為台積電（收台幣居多），仍能創新高屬不易

#### AI關鍵零組件營收持續創高
- GB200/GB300出貨帶動：旗鴻、台光電、GDPR相關供應鏈
- 昨日新聞：口味已接到第一批GB300出貨訂單
- AI離組件需求持續強勁

### 二、冠傾選股：上櫃經典 - 台燿 (6274)

- **產品定位**: 銅箔基板（CCL），N8等級無鹵材料，應用於AI與800G專案
- **營收表現**: 6月營收創新高，Q2產能滿載（Q1僅85~90%）
- **擴廠進度**:
  - 泰國廠本季營收貢獻起漲，Q3~Q4持續放大
  - M9材料明年下半年量產
- **客戶突破**: 穿孔打入AWS供應鏈，下半年開始供應N8材料（因台光電供不應求）
- **高盛報告**:
  - M8等級以上材料2024年僅佔7%，預估2027年佔13%
  - 2027年M8+市場規模24.8億美元，年複合成長率102%
  - 台燿有望佔10~12%市場份額（台光電佔60~70%）
  - EPS預估：2025年13.76元 → 2027年25.69元
  - **目標價**: 290元（高盛，以本益比17倍計算）
- **技術面**: 創新高走勢，整理幾天拉上去，盤中上下波動劇烈
- **操作策略**: 安全型等低接，投資型以三年後EPS 25~26元計算，240元附近合理
- **停損點**: 跌破整理區間低點

### 三、冠傾選股：新櫃新貴 - 麥可（散熱股）

- **營收爆發**: 6月營收3.89億元，年增136%；2月僅1.57億，半年翻倍以上
- **產品線**: 三軸VC（三軸氣冷）、水冷技術
  - 水冷產線上半年建置完成
  - 超流體冷卻技術：可解決1,500瓦散熱需求
  - 使用介電液（不導電），即使沾到GPU也不會短路
  - 與Intel合作發展超流體冷卻技術
- **應用場景**: AI伺服器（GB300要求超過1,400瓦散熱）、AI PC、電競PC
- **對標公司**: 奇鋐（做同類產品，股價近800元）
- **股價**: 從71元漲至131元（前波高點）
- **注意事項**: 新櫃無漲跌幅限制，風險較高
- **即將上市**: 已通過上市審議，掛牌在即
- **操作策略**: 拉回佈局，因散熱股整體估值偏高，此檔為相對低價
- **停損點**: 跌破前波起漲低點

### 四、冠傾選股：上市高貴不貴 - 中砂 (1560)

- **本益比**: 僅4倍多（極低估）
- **三大事業部**:
  1. **ABU砂輪部門**: 傳統砂輪
  2. **鑽石碟部門（32%營收）**: 用於晶圓研磨

     - 3奈米鑽石碟立基大幅增加
     - 2奈米製程更可望全面採用
  3. **SPU再生晶圓部門（51%營收）**:

  - 需載體晶圓承撐（先進封裝必需）

- **研磨製程趨勢**: A16製程CNP研磨層數達77層（vs 5奈米僅30~40層），鑽石碟消耗量大增
- **股價表現**: 約304元，準備挑戰前波高點

| 情境 | 稅率 | 台股反應 | 操作策略 |

### 關稅下的受惠/受害分析

**受惠產業**:
- 台灣關稅若低於日韓25%：記憶體（南亞科、華邦電）有轉單效應
- 美國製造股：大成鋼、IDK-KY、神達（有美國廠）
- 內需概念股：不受關稅影響

**受害產業**:
- 泰國/馬來西亞關稅高（36%/25%）：封測（日月光）、車用PCB（敬鵬、泰鼎）
- ASE/車用PCB比例高者相對不利

### 除權息行情操作策略（重要提醒）

#### ETF配息前的拉抬與貼息風險

**現象描述**:
- 高股息ETF在除息前會大量買進成分股以領取股利
- 投信在除息前7天集中買進，將股價推到不正常高點
- 除息後投信轉向買其他股票，造成嚴重貼息

**案例一：保瑞**
- 除息前7天：投信買超14萬多張，股價漲17.8%
- 除息後：買超驟降至2,000多張，貼息跌近10%

**案例二：創見**
- 除息前：投信買超1.8萬多張，股價漲近一根漲停
- 除息後：立即貼息

**操作方法**:
1. 鎖定高股息ETF包牌的成分股（被多檔ETF同時持有）
2. 除息前搭投信順風車賺價差
3. **記得不要參加除息**（除息後貼息嚴重）
4. 等貼息回到投信成本附近再買回

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **CCL** | 銅箔基板（Copper Clad Laminate），PCB的核心原材料 |
| **N8材料** | 高階無鹵銅箔基板材料，應用於AI伺服器 |
| **M9材料** | 下一代更高階銅箔基板材料，台燿明年下半年量產 |
| **800G** | 800Gbps高速網路傳輸標準，AI伺服器互連使用 |
| **介電液** | 不導電的冷卻液體，用於浸沒式散熱，即使接觸電子元件也不會短路 |
| **超流體冷卻** | 利用特殊裝置加速介電液流動以提高散熱效率的技術 |
| **CNP研磨** | 化學機械研磨（Chemical Mechanical Polishing），晶圓製程中的關鍵步驟 |
| **載體晶圓** | 用於承撐極薄晶圓的支撐結構，先進封裝製程必需 |
| **再生晶圓** | 將使用過的晶圓經處理後重新使用，中砂為主要供應商 |
| **遠期外匯** | 銀行與客戶約定未來某一時間以特定匯率買賣外幣的契約 |
| **點陣圖** | 聯準會理監事各自對未來利率走向的投票圖示 |
| **貼息** | 股票除息後股價跌幅大於配息金額，投資人實際虧損的現象 |
| **包牌** | 同一檔股票被多檔高股息ETF同時納入成分股 |
