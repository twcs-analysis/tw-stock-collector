## 💼 產業分析與投資建議

### 一、PCB 族群深度分析

#### 台光電 (2383) - 千元俱樂部候選
- **股價**: 約963元，距千元僅咫尺之遙
- **6月營收**: 80.35億元（歷史新高）
- **擴產計畫**: 第三季馬來西亞廠擴產
- **關稅影響**: 馬來西亞關稅25%，與日韓相當，影響中性
- **操作策略**: 拉回就站在買方，等拉回再買進
- **目標價**: 1,000~1,080元（美銀/永豐投顧）
- **停損點**: 跌破短天期均線（5日/10日線）

#### 金像電 (2383)
- **外資目標價**: 400元
- **現況**: 突破300元後一週內即站穩，今日拉上319.5元
- **核心邏輯**: 台灣最單純的AI相關PCB標的
- **目標價**: 400元
- **停損點**: 跌破300元整數關卡

#### 金成科
- **轉型故事**: 從傳統MB/模組板PCB轉型為Google供應鏈
- **關鍵投資**: 子公司LensTaker切入自動駕駛/還工業領域
- **股價表現**: 從古災48元漲至98元，大型投信ETF提出後隔天拉漲停
- **本益比**: 偏低，因半導體含量尚低
- **注意事項**: 轉型中，需持續追蹤進展

#### 台巨 / 嘉聯益
- **警告**: 這兩家公司都虧損（EPS分別為-1.7元和-1.3元）
- **股價表現**: 6月下旬觸底後分別漲40%和50%
- **來賓建議**: 看看就好，一定有高手在做，不建議一般投資人參與

### 二、冠傾三檔推薦股

#### 推薦一：德律 (3030)
- **主業**: 自動光學檢測（AOI），85%用於PCB/SMP電路板檢測，15%半導體
- **本益比**: 僅17.5倍（因半導體含量較低而被低估）
- **毛利率**: 高達57.6~59.6%（與台積電水準相當）
- **轉機亮點**:
  - 切入NVIDIA智慧工廠生態系（機器人領域視覺AI）
  - 跨入半導體後段製程TSV/TGV檢測
  - 7個產品中2個（TR707Q、TR7590Q）已通過客戶驗證並開始出貨
  - 公司看好Q3 AI伺服器需求強勁，全年預計較大幅度成長
- **技術面**: 經長期整理後即將挑戰前高（192元附近），量能開始出來
- **目標價**: 挑戰前波高點192元，若半導體占比提升，本益比有望翻倍至35倍以上
- **停損點**: 跌破整理區間低點

#### 推薦二：堅點
- **主業**: 鑽針（鑽孔用），為PCB製程關鍵耗材
- **本益比**: 約30.49倍（高於台光電）
- **核心競爭力**:
  - 台灣唯一能鑽AI孔的鑽針公司
  - 杜摩鑽針：能達成孔位精度、孔壁品質、均勻平滑的高標準
  - 客製化背鑽針：從背後鑽的技術，精度需求更高
  - 全球僅3~4家公司能收費做AI鑽孔
- **關鍵催化劑**:
  - AI伺服器採用M8/M9材料，硬度更大，鑽針消耗量大增
  - 未來可能採用石英板（比玻璃還硬），折損率更高
  - AI板子30層以上，鑽下去消耗量極大
- **泰國廠**: 成為泰國第一家代鑽服務公司
- **量能觀察**: 每天2~3萬張以上為正常，低於1萬張代表熱度消退
- **董事申報**: 董事申報買進後股價未跌，具信心指標意義
- **目標價**: 持續看好，只要台光電股價仍高，堅點機會大（目前僅台光電1/20市值）
- **停損點**: 量低於1萬張且出現轉弱信號

#### 推薦三：車走向運（轉型股）
- **原本定位**: 電路板車用板（車用占60%以上），因中國內捲而被市場忽視
- **轉型方向**: 飛車用拉高至50~70%，車用降低
- **關鍵進展**:
  - 次伺服器板、高階網通板已出樣給廣達
  - 預期Q3開始驗證量產化，Q4開始量產GPU板
  - 泰國廠產能從10萬值擴張至50萬值
  - 多層板自成能力達50層，HDIA可做到32層
- **本益比**: 僅14~16倍
- **毛利率改善**: Q1僅9%（泰國廠初期成本高），目標回到Q2/Q3水準（24~27%）
- **參照標的**: 擎鴻也做GPU板，本益比40倍以上，股價100多元
- **目標價**: 若轉型成功且量產GPU板，本益比有望翻倍至30倍以上
- **停損點**: 拉回不應跌破52.8元（古災前低）

### 三、鴻海 (2317) 與電動車產業

#### 鴻海電動車現況
- **外資目標價**: 多家外資給予200~242元
  - 高盛: 242元（看好AI伺服器）
  - 大摩: 200元以上（維持Overweight）
- **本益比**: 現在僅10~12倍，處於8~15倍歷史區間中段偏低
- **台幣影響**: 財務長表示台幣每升值一塊，營收減少約3%，毛利率僅下降0.1%
- **合理評估**: EPS約14元，8倍=112元（底部），15倍=210元（高標）

#### 鴻海本益比操作法
| 本益比 | 股價 | 操作建議 |
|-------|------|---------|
| 8倍 | 112元 | 絕佳買點（4月大跌最低即此水準）|
| 10倍（三年線）| 138元 | 近三年平均，中長期買點 |
| 12.5倍（年線）| 175元 | 尚可買進 |
| 13.7倍 | 192元（今年最高）| 合理偏高 |
| 15倍 | 210元 | 賣出信號 |

- **現價位置**: 約150~159元，接近三年線（138元），本益比約10~12.5倍
- **目標價**: 175~200元（年線至外資目標價）
- **停損點**: 跌破三年線138元

#### 鴻海與日產合作評估
- **合作內容**: 日產傳出財務危機，可能找鴻海代工電動車
- **來賓結論**: 合作對鴻海股價「典火效果沒有」
  - 日產電動車在國際上無爆款車型
  - 鴻海自有品牌（納智捷N7）在台灣賣得不錯，但走不出台灣
  - 日本車廠不可能賣給鴻海（面子問題）
  - 僅為合作備忘錄層級，非收購
- **鴻海投資重點**: 應看AI伺服器（GB200/GB300），而非電動車

#### 特斯拉股價展望
- 馬斯克組建新政黨，短期為利空
- 但長期觀察：Robotaxi、AI聊天機器人Grok等仍有想像空間
- 企業家從政成功案例存在（如川普本人）
- 短期股價受壓，但不至於被制裁

#### 鴻海操作結論
- 現在買不怪，但可以再等更低一點
- 十倍以下本益比必須買
- 要等外資回補才有催化劑
- 操作區間：150元附近買進，175元附近賣出，來回做價差

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **AOI** | 自動光學檢測（Automated Optical Inspection），用於PCB和半導體的品質檢測 |
| **TSV/TGV** | 矽穿孔（Through Silicon Via）/玻璃穿孔（Through Glass Via），先進封裝技術 |
| **M8/M9材料** | AI伺服器使用的高階PCB基板材料，硬度更高，鑽針消耗更大 |
| **石英板** | 比玻璃還硬的基板材料，用於下一代AI伺服器，鑽孔難度極高 |
| **背鑽** | 從PCB背面鑽孔的技術，用於降低雜訊干擾、提高訊號完整性 |
| **GPU板** | 用於AI伺服器中GPU模組的高階電路板 |
| **杜摩鑽針** | 堅點的專利鑽針產品，針對AI電動車和先進製程的高精度鑽孔 |
| **代鑽服務** | 堅點利用鑽孔技術為PCB板貫穿電路板層間的接點提供服務 |
| **HDIA** | 高密度互連陣列（High Density Interconnect Array），多層板設計技術 |
| **本益比翻倍** | 當公司從傳統產業轉型至高成長領域時，市場願意給予更高的估值倍數 |
