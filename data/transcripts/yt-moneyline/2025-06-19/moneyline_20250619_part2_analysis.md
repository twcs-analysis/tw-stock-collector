## 📊 市場總體觀察

### 暑假行情與操作策略

#### 核心觀點：今年暑假概念股不一樣
- **匯率走強推升出國意願**: 台幣升值讓出國旅遊更划算
- **旅遊相關類股受惠**: 航空、旅行社等營收將逐月成長
- **營收節奏**: 6月 < 7月 < 8月（8月營收為高峰）
- **傳統暑假題材已進入反應階段**: 須掌握翻多走勢

### 柯老師操作心法（第四階段震盪策略）

#### 國安基金護盤期間操作原則
1. **從頭到尾做多**: 直到國安基金宣布退場
2. **買低賣高、買黑賣紅**: 拉回才買，急漲不追
3. **漲幅過大且位接壓力區的股票**: 容易出現翻高回檔修正
4. **不追買拉高的明星股**: 等回測到時均線或月線再買

#### 第五階段退場訊號
- **成交量爆大量**: 5,500~6,000億
- **兩週震盪出2,000點**: 快速劇烈波動
- **國安基金宣布退場**: 此為最終退場訊號
- **操作因應**: 看到訊號後從滿倉轉為半倉，再縮至兩成短線操作

#### 反彈結束訊號（目前均未出現）
1. 量價背離、壓力不見突破 ❌ 未出現
2. 指數創高時出現翻空K線 ❌ 未出現
3. 技術指標從高檔翻空修正 ❌ 未出現（僅長多拉回修正）
4. 國際利空導致美股台股同步修正 ❌ 以伊衝突一旦開打反為利多

#### 選股策略四大方向
1. **護盤概念股**: 拉回時分批低接佈局
2. **產業持續向上成長股**: AI、HPC、機器人需求長線看好
3. **財報穩定高配息股**: 穩定現金流 + 減緩避險
4. **位接低、財報反轉向上、K線低檔翻多股**: 逢低分批佈局

### 四、台積電深度分析（外資報告解讀）

- **投資風格**: 買進持有（Buy & Hold），不頻繁交易
- **歷史績效**: 2002年以來報酬率為標普500指數的6倍
- **核心觀點**: 台積電與輝達最有可能在2030年翻倍

#### 台積電翻倍邏輯
- **AI相關業務CAGR**: 45%（未來5年複合年增率）

- **翻倍門檻**: 每年只需維持15%增長即可（遠低於20%實際增速）
- **本益比**: 未來本益比約22.9倍，與標普500的22.5倍相當，不算貴
- **性價比**: 以成長性而言估值合理

#### 台積電七月法說會預期
- **美元財測上調**: 從原本25%成長調高至27%~29%
- **明年營收成長**: 約20%
- **資本支出**: 持平約400億美元（已是歷史新高水準）
- **成長動力**: 雲端AI半導體（四部曲）可望再成長30%~40%
- **Intel外包**: NOMA類CPU/GPU委外台積電，拿到二奈米製程
- **先進製程漲價**: 全球美元計價漲3%~15%，美國廠漲10%

#### 台積電操作建議
- **短線**: 空間不大，千元以下尋找低接機會

### 除息選股五大條件
1. **配息前已是獲利成長股**: Q1 EPS優於去年同期
2. **近期外資呈現買超**: 法人認同
3. **站上均線**: 技術面偏多
4. **MACD呈現多頭排列**: 非跌深反彈
5. **成交量配合**: 量能逐步放大

### 國泰金（2882）/ 富邦金（2881）被列注意股
- **原因**: 借券放出約6倍，高借券賣出比率
- **影響**: 空方動能增強訊號，法人利用借券壓盤套利
- **操作邏輯**: 先放空期貨再借券壓現貨，指數下跌套利
- **投資人應對**: 大到不能倒的金控，逢低支撐可再買，逢高壓力可減碼

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **CAGR** | 複合年增長率（Compound Annual Growth Rate），衡量投資在多年期間的平均年化成長率 |
| **MSCI** | 明晟指數，全球最具影響力的股票指數之一，納入成分股可吸引被動基金資金流入 |
| **ABF載板** | Ajinomoto Build-up Film，用於高階半導體封裝的關鍵基板材料，AI伺服器需求推動 |
| **CSP** | 雲端服務供應商（Cloud Service Provider），如Google、Meta、Amazon、Microsoft |
| **NVLink** | 輝達專有的高速互聯技術，用於GPU間高頻寬數據傳輸 |
| **ASIC** | 特殊應用積體電路，為客戶量身定制的晶片，如Google TPU、Amazon Trainium |
| **本益比（P/E）** | 股價除以每股盈餘，衡量股票估值的指標，數值越低代表越便宜 |
| **除息/除權** | 公司將盈餘以現金（除息）或股票（除權）方式分配給股東，股價會相應調整 |
| **填息** | 除息後股價回到除息前的水準，代表市場認同公司價值 |
| **借券賣出** | 投資人向券商借入股票後賣出，期望股價下跌後買回歸還，賺取價差 |
