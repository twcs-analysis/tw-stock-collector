## 📊 市場總體觀察

### 台灣央行利率決策

#### 會議結論
- **利率不變**: 重貼現率維持2.5%（連五凍）
- **GDP預估**: 全年維持3.05%
- **CPI下修**: 維持1.81%（通膨緩漲格局）
- **GDP前高後低**: Q1預計5.48%，下半年僅0.78%（不到1%）

#### 不降息原因
- **保留子彈**: 下半年風險較大，留更多降息空間因應未來狀況
- **匯率工具充足**: 央行認為不需動用利率來應對台幣升值
- **下半年變數**: 關稅不確定性 + 中東地緣風險
- **半導體關稅隱憂**: 引用232條款（同鋼鐵稅率條款），目前稅率未定（10%~20%或更高）

#### 通膨風險評估
- **CPI表面緩降**: 從1.89%下修至1.81%
- **隱憂**: 台灣能源進口依賴度達97%，油價上漲將直接衝擊CPI
- **歷史前例**: 過去台灣四次物價大幅上漲，全部因能源供給問題引起
- **下半年風險**: 能源危機 + 關稅影響 + 進口物價上漲，通膨可能反彈

### 油價深度分析

#### 當前油價結構
- **布蘭特原油**: 約76美元（近期從60多美元反彈）
- **供需基本面**: 供過於求（OPEC+國家不願減產，美國也增產）
- **正常情況**: 油價應維持在60~70美元區間

#### 以伊衝突對油價的影響

**短期供應衝擊已現**
- **遠近月價差轉負**: 近月期貨價格高於遠月（Backwardation），代表短期供應恐慌
- **OVX波動率上升**: 芝加哥原油波動率指數明顯攀升
- **一週已漲18%**: 地緣風險快速反映在油價上

**荷莫茲海峽封鎖分析**
- **每日運輸量**: 約1,600萬桶
- **佔中東出口**: 8成以上原油出口經此通過
- **佔全球供應**: 約20%
- **能繞過的國家**: 僅沙烏地阿拉伯（有油管通紅海）和阿聯酋（部分港口不經海峽）
- **無法繞過的國家**: 伊拉克、科威特、卡達、巴林等

#### 油價情境分析

| 情境 | 條件 | 油價預估 | 機率評估 |
|------|------|---------|---------|
| **情境一（最佳）** | 衝突快速結束，美國出兵速戰速決 | 60~70美元 | 較低 |
| **情境二（基準）** | 持久戰，伊朗不封鎖海峽 | 70美元以上，小幅上升 | 最高（分析師偏向） |
| **情境三（最差）** | 荷莫茲海峽被封鎖 | 100~130美元 | 需警戒 |

#### 歷史石油危機對照

**第一次石油危機（1973年）**
- 以色列與阿拉伯國家第四次戰爭
- OPEC禁運石油
- 油價從3美元漲至12美元（4倍）
- 全球GDP減少三分之一

**第二次石油危機（1978年）**
- 伊朗革命，中斷每日580萬桶出口
- 油價從18美元漲至41美元（約2.3倍）

**摩根大通預估**
- 供應每減少1%，短期油價上漲5~10%
- 荷莫茲海峽封鎖（減少20%供應）：油價可能翻倍至兩倍
- 油價每上漲10%：全球GDP下降約0.1%
- 若油價翻倍：全球GDP可能下降1~2%

## 💼 產業分析與投資建議

### AI眼鏡產業

#### 市場現況
- **Meta × 雷鵬（Ray-Ban）**: 2023年10月推出AI眼鏡，一年半賣出200萬副
- **Meta × Oakley**: 6月20日推出運動型AI眼鏡，售價360美元
- **Google重返市場**: 與Gentle Monster（韓國）、Warby Parker（美國）合作
- **小米**: 7月發表會預計推出AI眼鏡
- **Meta × Prada**: 進一步擴大時尚眼鏡版圖

#### 雷鵬歷史對照
- **捍衛戰士效應（1986年）**: 年銷從18萬副暴增至360萬副（20倍成長）
- **AI眼鏡時代**: 兩年累計200萬副，2026年目標年產能1,000萬台

#### 高盛中國市場預測
- **2025年出貨量**: 89.4萬台
- **2030年出貨量**: 700萬台
- **CAGR**: 56%（類比TWS真無線耳機2017~2023年64%的成長軌跡）
- **市場規模**: 從2,071萬美元成長至13.4億美元
- **平均售價趨勢**: 從306美元降至192美元（約台幣6,000元）

#### AI眼鏡核心功能
1. **娛樂用途**: 沉浸式虛擬螢幕、AR分割畫面
2. **隱私保護**: 與手機螢幕不同，只有配戴者看得到
3. **即時翻譯**: 語音翻譯 + 字幕疊加
4. **生活紀錄**: 第一人稱視角拍攝（鏡頭內建相機，錄影時有紅燈提示）
5. **AI語音助理**: 透過眼鏡直接對話取得資訊

#### AI眼鏡成本結構
- **無螢幕版（AI眼鏡）**: 系統單晶片佔35%（成本最高）、充電盒10~15%、結構件10~15%
- **有螢幕版（AR眼鏡）**: 顯示器佔比最重，其次為系統單晶片與光學模組

#### 受惠廠商建議

**題材型（股本小、波動大）**:

**揚明光（364X）**
- 關聯：AI眼鏡光學元件
- 特性：股價活潑，題材發動時漲幅大
- 操作：短線題材操作，注意流動性

**責名（674X）**
- 關聯：AI眼鏡相關供應鏈
- 特性：中小型股，營收佔比尚小
- 操作：題材型操作，留意成交量

**穩健型（大型股、長線佈局）**:

**鴻海（2317）**
- 關聯：AI眼鏡組裝與供應鏈整合
- 若產業爆發且營收佔比提升，將有實質貢獻
- 適合長線佈局

**注意事項**:
- 目前AI眼鏡佔各品牌商營收均小於5%
- 短線選股本小的標的做題材
- 長線待產業滲透率提升後再佈局大型股

## 📈 技術面分析與操作策略

### 油價技術面觀察

#### Backwardation結構
- 近月價格高於遠月 = 短期供應擔憂
- 差值越大代表市場越恐慌
- 目前已出現明顯Backwardation加深趨勢

#### OVX波動率
- 芝加哥原油期權波動率指數上升
- 與VIX類似，反映原油市場恐慌程度
- 目前明顯攀升，與油價上漲同步

### 節目最終操作建議（柯老師總結）

#### 六月下旬行情研判
1. **中線震盪整理**: 大盤進入整理階段
2. **量價配合觀察**: 注意成交量是否配合
3. **戰爭若開打**: 殺低爆大量就是買方動作
4. **國安基金護盤期間**: 長多不變

#### 操作紀律
- **利空低接是佈局最佳時機**
- **中東火藥庫一觸即發**: 緊盯以伊衝突後續變化
- **國際局勢升溫需警戒**: 操作保持理性
- **投資佈局嚴控風險**: 靈活因應
- **第四階段震盪**: 趨勢未改變前，低買高賣、買黑賣紅

## 📋 投資策略總結

### 夢到核心觀點
1. **央行按兵不動有深意**: 保留降息子彈應對下半年風險
2. **半導體關稅是最大隱憂**: 引用232條款，影響遠大於對等關稅
3. **油價情境三最危險**: 荷莫茲海峽封鎖將使油價突破100美元
4. **停滯性通膨風險加劇**: 若油價大漲，全球GDP與通膨都將受衝擊

### 明者核心觀點
1. **AI眼鏡產業起飛**: 2025~2030年CAGR達56%
2. **Meta + 雷鵬為先行者**: 2026年目標年產能1,000萬台
3. **選股策略**: 短線選小股本題材股，長線待大型股營收佔比提升
4. **平均售價下降有利滲透率**: 從306美元降至192美元

### 柯老師最終總結
1. **國安基金護盤 = 做多**: 直到退場訊號出現
2. **戰爭開打不用怕**: 殺低爆大量就是買點
3. **區間操作不變**: 低買高賣、嚴守紀律
4. **保持理性**: 投資佈局嚴控風險，靈活寬鬆

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **重貼現率** | 台灣央行的基準利率指標，銀行向央行融通資金的利率，影響整體市場利率水準 |
| **232條款** | 美國1962年貿易擴展法第232條，允許總統以「國家安全」為由對進口商品加徵關稅 |
| **Backwardation** | 期貨市場中近月價格高於遠月價格的結構，通常反映短期供應緊張 |
| **OVX** | 芝加哥選擇權交易所原油波動率指數，類似VIX，衡量原油期權市場的恐慌程度 |
| **OPEC+** | 石油輸出國組織及其盟友國，透過產量協調影響全球油價 |
| **TWS** | 真無線立體聲耳機（True Wireless Stereo），如Apple AirPods |
| **AR眼鏡** | 擴增實境眼鏡，可在現實場景中疊加數位資訊與影像 |
| **AI眼鏡** | 內建AI語音助理與相機的智慧眼鏡，但不一定有螢幕顯示功能 |
| **系統單晶片（SoC）** | 將處理器、記憶體、通訊模組等整合在單一晶片上的設計 |
| **荷莫茲海峽** | 連接波斯灣與阿拉伯海的狹窄水道，寬僅33公里，為全球最重要的石油運輸通道 |
| **Gentle Monster** | 韓國時尚眼鏡品牌，以設計感聞名，曾與BLACKPINK Jennie合作聯名 |
| **Oakley** | 美國運動眼鏡品牌，以高性能運動光學聞名，屬於Luxottica集團 |
