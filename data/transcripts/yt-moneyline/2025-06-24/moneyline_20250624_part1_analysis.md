## 💼 產業分析與投資建議

### 一、AI高速連接器：宏記（3605）

#### 基本面分析
- **本益比**: 15.4倍（僅馬聯的一半，馬聯約30倍）
- **四大CSP客戶**: 已打進三家供應鏈
- **產能計劃**: 上半年產能比去年倍增，年底再翻一倍
- **ASP提升**: 一般連接器10-20美元 → AI連接器50-65美元（4-5倍成長）
- **高速連接器**: 去年取得輝達認證，第三季開始出貨
- **美國製造**: 2020年併購美國公司「創世紀」，佈局網通與雲端
- **AEC（主動式以太網路電纜線）**: 2023年開始開發，明後年可望發酵
- **800G AECC**: 今年下半年開始出貨

#### 投資建議
- **操作策略**: 回到法說會前高點應無大問題（約69.4元附近）
- **目標價**: 69~70元（法說會前高點）
- **停損點**: 跌破近期整理平台低點（約55元以下）
- **風險提醒**: 前高附近有缺口需回補，短線整理後再介入

### 二、AI伺服器：神達（3706）

#### 基本面分析
- **本益比**: 16.6倍，低於同業緯創
- **三大客戶**: 甲骨文、帶有（Nvidia）、AWS
- **產業版圖**: 伺服器、車載、AI/SoT、軍工、航太
- **五月營收**: 年增1.2倍
- **資本支出**: 今年上看2億美元（去年一倍以上）
- **新竹廠**: 2025年3月開始導入新設備，強化高階伺服器製造
- **GB200出貨**: 配合美國夥伴開始出貨NVL系列

#### 投資建議
- **操作策略**: 目前回到大漲原點，合理買點（本益比15-16倍）
- **第一目標價**: 75元附近
- **長線目標**: 挑戰前高92.9元（有難度但可期）
- **停損點**: 跌破60元整理平台下緣
- **風險提醒**: 公布營收後拉上去又回來，短線震盪大

### 三、AI散熱：雙鴻（3324）

#### 基本面分析
- **本益比**: 28.5倍（凱基投顧估今年EPS 38元，實際本益比不到10倍）
- **主要客戶**: Meta、AWS、微軟等雲端巨頭
- **GB200水冷**: 已交付中；GB300第四季開始交付，單季價值增加50%
- **水冷營收占比**: 去年12% → 今年可望超過40% → 明年過半
- **泰國廠**: 第三季開始滿載
- **可轉債**: 轉換價734.4元，目前股價643元，尚有約100元空間
- **自動補液機器人**: 與冰川合作AI資料中心自動冷卻補液系統
- **毛利率**: 從2021年18.7%提升至27.4%

#### 投資建議
- **操作策略**: 700元壓力大，但CB轉換價734元是公司護股動力
- **目標價**: 734元（可轉債轉換價，公司有動力推升股價）
- **長線目標**: 挑戰前高964元
- **停損點**: 跌破600元支撐
- **風險提醒**: CB發行1.5萬張、轉換零張，大股東有強烈推升動機

## 📋 債券投資策略（林忠分析）

### 聯準會降息展望
- **Fed副主席鮑曼**: 若通膨無惡化，7月可降息
- **FedWatch**: 7月降息機率僅兩成，9月降息機率從五成多升至六成四
- **2025年預估**: 9月與12月各降一碼，共降兩碼
- **長期利率路徑**: 降息趨勢未變，只是快慢問題

### 美國經濟數據
- **CPI**: 預期2.5%，實際公布2.4%，通膨持續下降
- **就業**: 非農就業仍穩定，失業率維持低檔
- **鮑威爾態度**: 偏鷹派，顧慮下半年關稅可能推升CPI

### 債券操作建議

#### 持有者策略
- 以收息為目的，繼續持有
- ETF配息率維持5%~7%
- 匯率因素已反映（台幣升值約10%）
- 可定期定額投入，平均匯率波動

#### 空手者策略
- 現在買進勝過之前高點買入者
- 小額分批買進，殖利率6%以上仍具吸引力
- 掌握時間點：7月4日除息，7月3日前買入可享配息

#### 推薦標的：新光BBB投資級債ETF（00970B）
- **類型**: 20年以上BBB投資級債
- **最新配息**: 0.05元/單位
- **年化報酬**: 約6.8%
- **主要持債**: CVS健康照護、特許通訊、甲骨文、歐尼克天然氣、禮來藥廠
- **產業分散**: 非集中科技股，涵蓋醫療、通訊、能源、消費等
- **信評分布**: BBB等級佔49.88%

#### 歷史數據：降息週期債券表現
| 期間 | 20年以上報酬 | 7-10年報酬 | 3-5年報酬 |
|------|------------|-----------|----------|
| 2019/7~2020/2 降息週期 | 20.5% | - | - |

- **結論**: 降息週期買長天期債券（20年以上）報酬最佳
- **利率比較**: 20年以上6.48% > 7-10年5.92% > 3-5年4.86%

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **DDR5** | 第五代雙倍資料速率記憶體，AI伺服器主要採用的記憶體規格 |
| **AEC** | Active Electrical Cable，主動式以太網路電纜線，用於AI資料中心高速傳輸 |
| **AECC** | 主動式以太網路銅纜線（800G規格），高階資料中心傳輸介面 |
| **CSP** | Cloud Service Provider，雲端服務供應商（如AWS、Azure、GCP、Oracle） |
| **可轉債（CB）** | Convertible Bond，可轉換為公司股票的債券，轉換價為換股的基準價格 |
| **BBB投資級債** | 信用評等為BBB等級的投資級債券，風險適中但殖利率較高 |
| **FedWatch** | CME聯準會觀察工具，用於追蹤市場對聯準會利率決策的預期機率 |
| **GB200/GB300** | NVIDIA新一代AI加速卡，GB300預計第四季開始交付 |
| **ETF調倉** | ETF定期調整成分股權重，大量被動式買賣造成短線股價波動 |
