### 四、搶反彈策略（政華老師）

#### 反彈vs回升的區別

- **反彈**: 空方格局中的短暫上漲，每次反彈高點都比前次低
- **回升**: 反彈成功後不再破底，越過高點才算回升
- **關係**: 所有回升都是從反彈開始，反彈成功才會變回升

#### 反彈時間點預估
- **最快4月初**: 關稅議題藏下前先賣，出來後利空出盡買回
- **操作心態**: 搶到就跑，不要戀戰

#### 反彈三大原則

1. **價格失去平衡時（急跌超跌）**
   - 股票跌兩個月每天跌2%很弱，突然出現跌停板
   - 加速殺盤失去平衡時，就有反彈力道

2. **時間是敵人**
   - 股票長期不太動，突然開始慢慢漲
   - 這時候危險，可能拉回打第二隻腳（雙底）

3. **搶到先放口袋**
   - 搶到反彈的第一波先獲利了結
   - 若反彈變回升，再做第二段
   - 分兩次操作降低風險

#### 搶反彈選股四大方法

**方法一：找本週最強的股票**

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **殖利率** | 股利除以股價的比率，代表投資人持有股票一年可獲得的股利報酬率 |
| **除權息** | 公司發放股利時，股價會做相對應的調整（除權指配股票、除息指配現金） |
| **搶反彈** | 在下跌趨勢中，利用短暫的反彈波段快速進出獲利的操作方式 |
| **雙底（W底）** | 股價下跌後反彈再回測前低附近止跌的技術型態，又稱W底 |
| **對等關稅** | 川普政策，美國對各國課徵與該國對美國相同稅率的關稅 |
| **重建題材** | 指戰後重建帶動的基礎建設需求，受惠產業包括鋼鐵、散裝航運等 |
| **本益比（P/E Ratio）** | 股價除以每股盈餘，衡量股票估值高低的指標 |
| **年線/季線/月線** | 分別為240日、60日、20日移動平均線，用於判斷中長期趨勢 |
| **均線糾結** | 多條移動平均線在狹窄區間內交叉纏繞，通常預示即將出現方向性突破 |
