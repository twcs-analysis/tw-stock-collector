## 🌍 市場總體觀察

### 川普革命的三大核心目標（程中老師）

#### 1. 美軍必須強
- 美國本土軍事力量必須維持最強大
- 雖會縮減海外駐軍（歐洲、中東），但本土國防預算不會減少

#### 2. 美元必須用
- 全世界必須繼續使用美元結算
- 川普曾威脅金磚國家：若推出金磚幣，將課100%關稅
- 可能放鬆對俄羅斯制裁，讓其回到SWIFT系統，本質上就是讓俄羅斯回來使用美元

#### 3. 美債必須救
- **當前美債規模**: 36兆美元（2016年川普第一任時僅17兆）
- **國債利息**: 每年1.1兆美元（比馬斯克DOGE省的錢還多）
- **核心策略**: 讓長期國債殖利率下降 → 吸引資金買長債 → 減輕償債壓力
- **手段**: 經濟結構改革，可能容忍短期經濟衰退

#### 經濟結構改革的邏輯
- **拜登時期**: 大手花錢、財政支出增加、貨幣寬鬆、聯盟盟友
- **川普時期**: 反向操作 — 縮減政府支出（G下降）、鼓勵民間投資回流（I期望增加但需要時間）
- **結果**: 短期經濟衰退風險升高，但長期目標是減輕美債負擔

#### 賽局理論：貿易戰的反擊風險
- **加拿大新任總理卡尼**: 強硬回擊，稱關稅為「形同戰爭行為」
- **歐盟**: 態度趨於嚴厲，準備報復
- **中國**: 預期站在報復的一邊
- **風險**: 各國報復會精準打擊美國弱點，推升通膨，使聯準會陷入兩難
- **歷史借鑑**: 1930年關稅法案後各國報復，股市在反彈後再度崩盤，跌幅更大

### 消費者信心與耐久財

- **消費者信心指數**: 降至四年多來新低（4月2日尚未正式課關稅）
- **核心耐久財訂單**: 意外下滑（排除國防與交通的民生耐久財），顯示經濟正不如預期
- **停滯性通膨風險**: 物價上升 + 經濟衰退的最壞組合

## 💼 產業分析與投資建議

### 網友五大問（博姐老師 / 程中老師）

#### 第一問：台洋（太陽能）能否抄底？

**結論：反彈要減碼，不建議抄底**

| 項目 | 數據 |
|------|------|
| 近年EPS | 2020年虧0.42 → 2021年虧1.97 → 2022年虧2.0 → 2023年虧2.6 → 2024年虧4.5 |
| 營收趨勢 | 2022年最高4.8億 → 2024年僅16.7億（大幅下滑） |
| 負債比 | 從2020年55% → 2024年達79% |
| 董監持股 | 從2020年28.9% → 2024年僅12.2% |

- **昨日打開跌停**: 為主力自救手法（搭起來出），非真正止跌訊號
- **量價異常處置**: 4月14日前20分鐘一盤，流動性更差
- **建議**: 有持股者反彈要減碼，等營運好轉訊號再進場

#### 第二問：鴻海（2317）破底怎麼辦？

**結論：分批往下布局，以本益比為準**

| 項目 | 數據 |
|------|------|
| 法人預估今年EPS | 15元 |
| 法人預估明年EPS | 17元 |
| 過去本益比區間 | 8-15倍（正常8-12倍，多頭行情到15倍） |
| 甜蜜價位 | 本益比10倍以下（即150元以下） |

- **AI泡沫疑慮影響**: 輝達GTC利多出盡、阿里巴巴主席稱看見AI泡沫化跡象、高盛下修AI伺服器出貨
- **外資三月賣超**: 22萬張，持續不停
- **操作建議**: 從本益比10倍（150元）開始分批買到8倍（120元），持有一兩年可望獲利兩三成以上

#### 第三問：台積電（2330）要打到八字頭？

**結論：900元以下分批布局**

| 項目 | 數據 |
|------|------|
| 今年預估EPS | 約60元 |
| 過去本益比區間 | 14-24倍（最低時達10倍，僅限全球系統性風險） |
| 地板價 | 900元（15倍本益比） |
| 極端情境 | 840元（14倍本益比） |

- **目前面臨問題**: 關稅風險 + 英特爾投資疑慮
- **外資三月賣超**: 13.8萬張
- **操作建議**: 950元以下分批向下布局，定時定額不要停

#### 第四問：軍工股追高會不會套？

**結論：中長線沒問題，短線注意回檔**

- **大趨勢正確**: 川普推動各國自主國防，軍備競賽為長期趨勢
- **短線風險**: 預算需經立法院通過、招標等程序，需要時間
- **精選標的**:
  - 成田：本益比26.6倍，今年預估EPS約2元，不算很貴
  - 漢翔：本益比約20倍，預估EPS 7元
  - 寶一、千附實業：中小型股，當作人氣指標參考
  - **推薦**: 漢翔、雷虎或長空、航太（過去獲利較穩健）

#### 第五問：第一銅（銅概念股）為何破功？

**結論：銅概念不買第一銅，改看電線電纜股**

- **第一銅問題**: 做銅的加工，並非直接買賣銅，獲利效率不高，被短線客玩壞
- **銅價上漲受惠者**: 電線電纜股（原物料為銅，報價隨銅價上調）
- **推薦**: 大亞電纜 — 本益比最低，前兩月營收年增，相對價值優於第一銅

### 月K線趨勢分析（政華老師）

#### 核心觀念：價格風險來自以前的機會
- 過去三年漲最多的（AI股），現在修正風險最大
- 過去三年沒漲的，現在反而是機會

#### 加權指數月K線
- **3月首次收在前月低點下方**: 確認去年以來做頭的第一根轉折
- **不會像2022年跌8個月**: 因當時是升息循環開始+俄烏戰爭，現在是降息循環中
- **川普選前低點（約18,350）**: 為強力支撐區，傾向回測後即反彈

#### 台積電月K線
- **首次月K收在前月下方**: 可能修整一段時間
- **川普選前低點**: 為強力支撐，回到該位置（約900元）為好的進場點
- **操作**: 勾起來再買（等月K紅棒出現）

#### 鴻海月K線
- **首次收在前月下方**: 空方趨勢確認
- **翻多訊號**: 出現一根月K紅棒收比前月高
- **若訊號出現**: 未來3-4個季度可能都是上漲段

#### 過去沒漲的 = 現在的機會

| 標的 | 觀察重點 |
|------|---------|
| 南亞科 | 月K跌8根後首次收在前月上方，為翻多訊號 |
| 旺宏 | 稍弱但月均線乖離大，量縮至右下角，有機會反攻 |
| 映泰 | IC設計長期底部，AI三級也沒漲到，有反彈空間 |
| 四星科 | 軍工+工業電腦+邊緣AI，2月已先漲，拉回MACD零軸交叉為起漲點 |

#### 其他機會
- **印度股市**: 打出雙底後已回到多方格局
- **美債**: 美國態度要讓美債上漲（殖利率下降）
- **黃金**: 短線太強，關稅落地後若拉回可加碼

## 📈 技術面分析

### 月K線趨勢判讀法（政華老師）
- **空方趨勢定義**: 每月收盤都比上月低點還低
- **翻多訊號**: 出現一根月K棒收在上月低點上方
- **操作原則**: 多方趨勢中，每次回到上月低點附近都是買點

### 電價不調漲的影響
- **經濟部決議**: 本次電價不調整，台電虧損由經濟部撥補
- **對重電概念股**: 不會有太大影響（之前也沒漲）
- **對市場情緒**: 可能提供小型反彈火苗，但推升力道有限

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **SWIFT系統** | 全球銀行間金融電信系統，用於國際金融交易結算，被排除等同於被切斷國際貿易 |
| **停滯性通膨（Stagflation）** | 經濟停滯（成長趨緩或衰退）與通貨膨脹同時發生的現象 |
| **核心耐久財** | 排除國防及交通工具後的耐久財訂單，更能反映民間經濟實際需求 |
| **賽局理論** | 經濟學中分析博弈雙方策略互動的理論，用於解釋貿易戰中各國的報復行為 |
| **月K線** | 以月為單位的K線圖，適合判斷中長期趨勢方向 |
| **1930年關稅法案** | 又稱斯姆特-霍利關稅法案，大幅提高關稅後引發各國報復，加劇大蕭條 |
| **耐久財** | 可使用三年以上的消費財，如汽車、電腦、手機等 |
