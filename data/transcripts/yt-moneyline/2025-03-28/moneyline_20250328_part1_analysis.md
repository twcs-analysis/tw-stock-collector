## 🌍 市場總體觀察

### 台股市況分析

#### 大盤表現

- **成交量**: 3,246億元（量增但為下跌量）

- **上漲家數**: 僅200多檔
- **下跌家數**: 2,000多檔
- **櫃買跌幅**: 2.3%，比大盤更重

#### 台幣走勢
- **台幣貶破近十年新低**: 外資持續匯出，台幣面臨巨大貶值壓力
- **與美元指數背離**: 美元指數今年走跌，但台幣反而貶值，顯示有隱藏性利空
- **意義**: 外資持續撤出台灣市場的訊號

#### 法人動向
- **外資**: 現貨賣超336億元，三月累計賣超近4,000億元，今年賣超超過5,700億元
- **外資期貨**: 空單小招283口，總空單維持36,000多口
- **外資賣壓**: 持續不止，已接近去年全年賣超水準

#### 全球比較
- **台股今年跌幅全球最重**: 在美國、歐洲、日本、韓國等主要市場中，僅台股跌破今年低點與六個月低點
- **日本汽車股跌幅**: 因汽車關稅受衝擊，但跌幅仍不及台股
- **歐洲股市**: 仍在高檔區域

## 💼 產業分析與投資建議

### 一、台灣出口結構性風險（程中老師）

#### 核心觀點：台股弱勢的根本原因
1. **對美出口依賴過重**: 過去四年對美出口成長1.2倍，其中伺服器成長6.4倍、半導體大幅增長
2. **不怕對等關稅，怕特定行業關稅**: WTO協定下半導體與伺服器為零關稅，真正風險在於川普對汽車→晶片→藥品等逐一課稅
3. **台積電赴美投資的雙面影響**:
   - 美國廠產能不算台灣出口，台灣GDP受損
   - 民間投資（I）外移，經濟成長動能減弱
   - 在美生產成本大增，EPS恐受壓

#### 戴維斯雙殺（Davis Double Kill）效應
- **第一殺 — 殺估值（本益比下修）**: AI泡沫疑慮升溫，科技股本益比從20倍可能下修至15倍
- **第二殺 — 殺EPS**: 若需求不如預期、美國生產成本高昂，企業獲利將下修
- **範例**: 台積電若EPS維持50元但本益比從20倍降至15倍，合理股價從1,000元降至750元；若EPS再降至40元，股價可能僅600元
- **結論**: 戴維斯雙殺正在美股科技七雄發生，台積電等台灣權值股亦面臨同樣風險

#### 落底訊號尚未出現
- 散戶大規模停損尚未發生
- 融資減少速度太慢，未見單日50-90億大幅減少
- 需等待「融資快速減少 + 量價配合」才有V型反彈機會

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **戴維斯雙殺（Davis Double Kill）** | 股價同時受到本益比下修（殺估值）與EPS下修（殺獲利）的雙重打擊，導致股價大幅下跌 |
| **對等關稅** | 川普政策，要求對美國課多少關稅，美國就對該國課多少關稅 |
| **灰犀牛** | 比喻高機率且影響巨大的威脅，雖然明顯可見但常被忽視 |
| **融資斷頭** | 融資買進的股票因股價下跌，維持率不足而被券商強制賣出 |
| **借券賣出** | 向券商借入股票後賣出，屬於做空操作 |
| **GDP組成（C+I+G+X）** | C=民間消費、I=民間投資、G=政府支出、X=淨出口 |
