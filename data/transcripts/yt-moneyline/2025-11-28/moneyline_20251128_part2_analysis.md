### 聯準會降息與總經分析

#### 降息機率變化
- 一週前: 30多%
- 本日: 突破85%
- **判斷**: 即使真正降息，對股市刺激力道有限（已反映在股價）
- 不降息也不致大跌（市場會期待1月降息）

#### 降息真正原因：救美國財政部
1. **美國國債危機**: 國債達38兆美元，每100天增加1兆
2. **SLR放寬**: 補充槓桿率從5%降至3%，釋放銀行購買國債空間
3. **預估效果**: 銀行可多買5兆美元國債
4. **本質**: 放水不是救股市，是救財政部（以債養債）

#### AI基礎建設資金排擠
- 財政部發債 vs AI基建發債，爭搶市場流動性
- 聯準會須結束QT（量化緊縮），甚至考慮降息

#### 修正風險警示
1. **放水未必進股市**: 流動性目標是國債市場
2. **美國融資餘額創歷史新高**: 1.18兆美元（今年7月僅1兆）
3. **日本黑天鵝**: 12月18日日本央行會議，若升息將引發日圓套利交易回轉
   - 40年期國債殖利率飆至3.6%
   - 10年期國債殖利率1.82%
   - 高市早政府擴大財政預算至21兆日圓，引發債市恐慌
   - 類似2024年中日圓套利交易逆轉的衝擊
4. **七大科技巨頭分化**:
   - 漲: Google（Alphabet）+20%、蘋果
   - 跌: NVIDIA、特斯拉、微軟、Meta

### 違約交割警訊

#### 現象
- 台股反彈漲千點，但頻繁出現違約交割
- 主因: 當沖客追漲鎖不到漲停時無法出場

- 兩天後交割日無法交割

#### 案例: 南亞科(2408)
- 類似走勢：看好追高後反轉大跌，當沖做多者被套

## 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **CCL** | 銅箔基板（Copper Clad Laminate），PCB的核心原材料，漲價直接影響PCB成本與售價 |
| **DDR4/DDR5** | 雙倍速率同步動態隨機存取記憶體的第四/五代，DDR5為最新規格 |
| **HBM** | 高頻寬記憶體（High Bandwidth Memory），AI伺服器專用高效能記憶體 |
| **格蘭碧八大法則** | 利用股價與移動平均線的關係判斷買賣時機的經典技術分析方法 |
| **KD指標** | 隨機指標（Stochastic Oscillator），用於判斷超買超賣及交叉訊號 |
| **黃金交叉** | 短期均線由下往上穿越長期均線，為技術面看多訊號 |
| **SLR** | 補充槓桿率（Supplementary Leverage Ratio），巴塞爾協議規定銀行一級資本與總曝險的比率 |
| **QT** | 量化緊縮（Quantitative Tightening），央行縮減資產負債表的貨幣政策 |
| **日圓套利交易** | 借入低利率日圓投資高收益資產的策略，日本升息會導致此交易大規模逆轉 |
| **違約交割** | 投資人在T+2日無法完成股款交割，屬嚴重違規行為 |
| **集團作帳** | 大集團旗下法人在季末或年底買進自家股票以美化績效 |
| **乖離率** | 股價偏離移動平均線的程度，過大時容易出現修正 |
