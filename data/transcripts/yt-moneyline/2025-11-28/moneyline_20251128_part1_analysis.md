### 二、Google vs NVIDIA（灰達）競爭格局

#### GPU vs TPU 本質差異
- **GPU（NVIDIA）**: 通用型處理器，如「萬用瑞士刀」
  - 從遊戲圖形處理 → 比特幣挖礦 → AI訓練，用途廣泛
  - CUDA平台是護城河，工程師從學生時代就學習
  - 市占率曾達90%以上
- **TPU（Google）**: 專用型ASIC，如「手術刀」
  - Google自2016年起自主研發，已迭代至第七代
  - 專門為Google Gemini大模型訓練與推理設計
  - 能耗較低、效能出色
  - 開始對外銷售，Anthropic與Meta也考慮採購

#### 對NVIDIA的衝擊
1. **市場份額減少**: 從90%可能逐漸降至60%甚至50%
2. **毛利率壓力**: 目前73%高毛利率將面臨下調壓力
3. **其他巨頭跟進**: 亞馬遜、Meta、微軟也在開發自有晶片
4. **市值修正風險**: 短期可能從5兆美元回到4兆美元
5. **OpenAI困境**: Gemini威脅OpenAI地位，OpenAI融資困難，匯豐預估未來五年現金流為負

#### 歷史類比
- **Netscape vs IE**: OpenAI像Netscape，Google像微軟的IE，靠生態系統優勢取代
- **大賣空Michael Burry**: 認為當前AI投資存在巨大泡沫，NVIDIA像2000年的Cisco
- **Google CEO皮查伊**: 坦承AI投資存在泡沫風險

#### 台股受惠標的
- Google概念股將成為12月主流
- 聯發科、創意等IC設計股受惠於TPU趨勢

### 三、幫子女買房的稅務規劃（俗律師專題）

#### 核心法律觀念
- 未成年人（未滿18歲）購買的財產，法律上視為父母贈與
- 贈與稅舉證責任倒置：由父母證明「非贈與」

#### 免稅額運用策略
- **每人每年贈與免稅額**: 244萬元（2025年度）
- **父母雙方兩年度**: 約976萬元
- **結婚加碼**: 每人額外100萬元
- **短期（1-2年）**: 結婚時可達1,176萬元免稅
- **不足部分**: 搭配銀行貸款，資金來源清楚即可

#### 資金證明三要點
1. 來源清楚（不可用現金贈與）
2. 資金流向單純（不可混用、進進出出）
3. 轉帳名細完整對應

#### 房產移轉方式比較
| 方式 | 贈與稅 | 土地增值稅 | 房地合一稅 | 遺產稅 |
|------|--------|-----------|-----------|--------|
| 贈與現金買房 | 超過免稅額需繳 | 無 | 無（子女未來賣出時有） | 無 |
| 贈與自有房 | 依公告現值 | 有 | 無（但子女賣出時有，成本低稅重） | 無 |
| 買賣自有房給子女 | 無（需資金證明） | 有 | 父母可能有 | 無 |
| **繼承（最推薦）** | **無** | **無** | **無（賣出時有，但成本可拉高）** | **有遺產稅** |

#### 結論
- **最佳方式**: 繼承房產（僅有遺產稅，且取得時間可拉長至父母取得日）
- **次佳方式**: 分年贈與現金 + 銀行貸款

## 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **BBU** | 備用電池單元（Battery Backup Unit），用於伺服器不斷電系統，確保資料中心斷電時仍能運作 |
| **TPU** | 張量處理器（Tensor Processing Unit），Google自主研發的AI專用晶片，針對AI訓練與推理優化 |
| **ASIC** | 特定應用積體電路（Application-Specific Integrated Circuit），為特定用途設計的專用晶片 |
| **CUDA** | NVIDIA開發的平行運算平台，AI開發者廣泛使用的生態系統 |
| **NDAA認證** | 美國國防授權法案認證，通過此認證的產品可供美國軍方採購 |
| **聚合交易** | 台股盤後定價交易機制，可觀察法人或大戶布局方向 |
| **MSCI調整** | 摩根士丹利資本國際指數的成分股定期調整，通常伴隨大量交易 |
| **SLR** | 補充槓桿率（Supplementary Leverage Ratio），銀行資本充足率指標 |
| **不對稱戰力** | 以低成本武器（如無人機、飛彈）對抗高成本傳統軍事力量的戰略概念 |
| **贈與稅免稅額** | 每人每年可免稅贈與的金額上限，2025年為244萬元 |
| **房地合一稅** | 房屋及土地交易所得合併課稅制度，以實際交易價格計算所得 |
| **預告登記** | 在不動產登記簿上預先登記權利變動，防止不動產被非法移轉 |
