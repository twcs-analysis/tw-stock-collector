## 💼 產業分析與投資建議

### 一、PCB 族群 - 處置潮下的強勢輪動

**基本面分析**:
- PCB 族群漲價趨勢確立，但目前僅漲一次
- 需連續漲兩到三次才能確認波段行情
- 外資針對 PCB 前段市值個股持續站賣方

**籌碼面**:
- 內資主力、大戶、業內在主導行情
- 外資偏賣，僅台耀等少數個股外資在買
- 處置股高達29檔，形成「搞小圈」現象

**技術面觀察重點**:
- 飆股不被處置就不叫飆股，處置後籌碼反而鎖碼更緊
- 放量不跌 = 安全；大量長黑 + 隔天開低 = 趕快跑
- 目前無任何 PCB 個股出現爆量翻轉訊號

### 三、飆股小時候養成計畫 - 海華密技

**選股四大條件**:

1. **第一根紅K很重要**
   - 每天觀察漲幅前100名 + 成交量前100名（約150檔）
   - 找到低檔出現第一根紅K的個股
   - 列入觀察名單，量縮時切入
   - 案例：征頂（PCB股）低檔第一根紅K後翻倍

2. **籌碼面篩選**
   - 外資連續買超（不是一天，要連續三天以上）
   - 投信比現在受主動型 ETF 干擾，穩定度較差
   - 大戶持股比例突然大幅增加為重要訊號
   - 案例：波羅威大戶持股從16%一週增至32%

3. **基本面 - 算不出獲利的反而最會漲**
   - 已知獲利 = 合理股價已反映
   - 無法估算獲利 = 想像空間無限
   - 案例：安國併購前山科技後，IP題材無法估算

4. **技術面 - 三個月內漲幅不到三成**
   - 橫盤三個月內，漲幅不到30%
   - 出現長紅K時可進場
   - 若已漲超過30%，已是中鷹股，應放棄

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| 處置股 | 因股價異常波動被證交所列入注意後進一步處置，改為分盤撮合交易（如20分鐘撮合一次），限制交易頻率 |
| 融資餘額 | 投資人向券商借錢買股票的總金額，反映散戶槓桿程度 |
| 鎖碼 | 籌碼被主力或大戶鎖定不賣出，造成市場流通籌碼減少 |
| 第一根紅K | 個股在底部盤整後出現的第一根實體紅K線，通常為起漲訊號 |
| 0050調整 | 元大台灣50 ETF每季調整成分股，被納入的股票通常有被動買盤推升 |
| 傑克遜霍爾（Jackson Hole） | 美國聯準會每年8月底舉行的全球央行年會，為貨幣政策重要風向球 |
| 232調查 | 美國依據《貿易擴展法》第232條對特定進口商品進行國安調查，可能導致加徵關稅 |
