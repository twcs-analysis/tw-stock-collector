### 五、當沖操作密技 - 海華教學

#### 做多當沖條件
1. 不要追AI類股（突然拉漲停難追）
2. 前一天外資賣超但股價不跌 = 有機會
3. 大戶籌碼偏多
4. 前一日成交量最好偏小（量縮後放量漲再買）
5. AI券商無差別5%買進訊號可跟

#### 做多當沖標的觀察

| 個股 | 適合度 | 說明 |
|------|--------|------|
| 漢翔 | 暫不適合 | 今日爆大量，不符合量縮條件，等量縮回5日線再做 |
| 波羅威 | 暫不適合 | 連續漲太多，等量縮到5日線再做 |
| 系統電 | 適合觀察 | 量已縮小，盤整整理中，大戶持股增加5%，BBU概念 |
| 南電 | 等待 | 連續漲停兩天後今日拉回，壓回5日線量縮後有機會再上 |
| 廣宇 | 等待拉回 | 修正四天黑K，第一次跌破通常假跌破，量縮後長紅3%以上追買 |

#### 做空當沖條件
1. 前一天上漲爆量（隔天有人出貨）
2. 外資買超的（假外資/借券外資隔天會賣）
3. 鎖漲停比率高的（隔天開高走低機率大）
4. 大戶籌碼賣量大於買量
5. 在開盤價上方一點去空（勝率較高）

#### 做空當沖標的

| 個股 | 適合度 | 說明 |
|------|--------|------|
| 南子電 | 適合 | 漲過頭、本業沒賺錢、大戶連續賣三週、今日對稱壓力區 |
| 宏達電 | 適合觀察 | EPS不夠高、對稱壓力區、大戶減持、今日放量 |
| 聲揚半 | 適合觀察 | 類似條件，到對稱壓力 |
| 環宇 | 再等兩天 | 五天後可能被處置，處置前一天可空 |

**處置股空法**:
- 被處置的股票大戶都會賣
- 在第四天（處置前一天）若股價又漲，可以去空
- 處置開始後通常會有賣壓

## 📈 技術面分析與操作策略

### 台積電（2330）技術面

- 本月漲幅零趴，純粹政治面干擾（232調查、晶片關稅）
- 1,200元是暫時性高點，非中長期高點
- 需等美股（那斯達克、費半）創高，台積電才會跟著突破
- 外資不買就是暫時性高點

### 鴻海（2317）技術面

- 200元為關鍵位置
- 收穩200元與均線位置，就會跟著台積電再攻
- 外資借券賣出未增加 = 做空力道不強
- 只要借券賣出不增加，鴻海就跌不下去
- **目標價**: 站穩200元後有高點
- **停損點**: 跌破月線

| 承名電 | 約130元 | 約8.5-9元 | 約15倍 | 最便宜，挪威主權基金持股 |

**承名電（CME）特別分析**:
- META GP300/GP457 供應鏈
- 前三季營收可能脫谷，Q4因GP300出貨大成長（營收年增五成）
- 挪威主權基金為公司派外最大單一股東
- 法人預估明年EPS 8.5元以上
- **目標價**: 對標JPPC的本益比（18倍），合理價約153-162元
- **停損點**: 跌破整理區間底部

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| 季底作帳 | 投信基金經理人在每季末（3/6/9/12月底）前拉抬持股，美化基金績效報告 |
| 貴買買 | 指投信在較高價位持續買進的行為，通常暗示看好後續 |
| 借券賣出 | 向券商或法人借入股票後賣出，為做空機制之一 |
| 假外資 | 以外資身份進行短線交易的資金，非真正的國際長線資金 |
| 可轉債（CB） | 可轉換公司債，持有人可在特定條件下將債券轉換為公司股票 |
| BBU（電池備援單元） | Battery Backup Unit，伺服器不斷電系統的電池模組，AI伺服器重要零組件 |
| GP300/GP457 | META的AI伺服器代號，為廣達、承名電等台廠重要訂單來源 |
| 挪威主權基金 | 全球最大主權財富基金（規模超過1.7兆美元），其持股動向為重要參考指標 |
