## 🌍 市場總體觀察

### 台股盤勢概況
- 台經院觀點：AI在接下來的應用仍會成為市場焦點
- 部分個股已動過一輪且回檔（老AI股調整中）

### DeepSeek對市場的深層影響

#### 情緒定價 vs 理性分析
- 影響股價的最大因素是「情緒溢價」而非理性分析
- DeepSeek帶來的最大衝擊：**價格破壞**
  - 過去AI追求規格、性能、更多晶片
  - DeepSeek從頭到尾強調「我可以用更低的規格接近對手」
  - 市場擔心：過去需要的散熱、高規格零件可能「都不用了」
- 但未來不排除出現第三家、第四家類似公司（印度、日本、韓國都可能）

- **操作策略**: 若2月18日出現利空（課百分之百關稅），股價碰到1,000元附近就是好機會

## 📈 技術面分析與操作策略

### 均線操作法則（正華 + 菁英共識）
- **核心**: 均線是多空分界線
- **多頭定義**: 均線上揚且股價在均線上方
- **空頭定義**: 均線失守（收盤跌破均線超過3天）
- **選股**: 均線上方的個股才值得操作

### 老AI股處理原則
| 類型 | 股票 | 建議 |
|------|------|------|
| **緯創/廣達** | 低毛利組裝廠 | 等週線長紅棒再搶反彈（右側交易） |
| **CPO族群** | 上詮/聯亞 | 等出關換手成功後再進場 |
| **BPU族群** | AES | 均線不破可持有，破3天出場 |
| **設備股** | 萬日/弘塑 | 均線已破，暫不操作 |

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **情緒溢價** | 市場參與者因情緒（恐懼或貪婪）導致股價偏離基本面合理價格 |
| **左側交易** | 在股價下跌過程中越跌越買，試圖抄底（風險較高） |
| **右側交易** | 等股價確認反彈趨勢後才進場，追求安全性 |
| **出關（限空令解除）** | 券商限空令到期，融券可重新放空，通常伴隨較大賣壓 |
| **BPU** | 背板電源（Backplane Power Unit），AI伺服器電源供應系統 |
| **CPO** | 共同封裝光學（Co-Packaged Optics），高速資料傳輸技術 |
| **矽光子** | 利用矽晶圓製造光學元件的技術，應用於高速通訊 |
| **CoWoS** | 台積電先進封裝技術，AI晶片關鍵製程 |
| **碳費** | 政府對碳排放徵收的費用，預計影響鋼鐵、水泥等建材成本 |
| **商用不動產** | 非住宅用途的不動產，包括辦公大樓、廠房、物流倉儲等 |
| **工業地產** | 供工業使用的土地與建物，包括工業用地、廠房、廠辦等 |
