## 💼 產業分析與投資建議

### 一、主動基金重倉股分析

#### 1. 新日興 (3376) - 可折疊手機鉸鏈
- **產業地位**: 蘋果折疊手機/iPad鉸鏈第一供應商
- **近期表現**: 昨日大跌時仍收紅（2024年8月5日股災時也歷史性收紅）
- **營運亮點**:
  - 可轉債20億元用於原料擴產
  - 越南廠第二季開始量產
  - 蘋果折疊iPad Air、AirPods耳機均採用其鉸鏈
  - 目前鉸鏈占營收僅10%（三星部分），蘋果加入後將大幅成長
- **法人估值**: 若交出100萬台iPad折疊鉸鏈，可貢獻營收30億元（OPM約1.5%）
  - iPad年銷5,000萬台，若10%採折疊 = 500萬台
  - 去年EPS約7.8元，加上新業務可達14.5元
- **股價**: 約215.5元
- **投信動態**: 主動式買入（買少量、非連續、有時多有時少）
- **技術面**: 打底接近完成，需站上230元確認
- **操作策略**: 跟著投信主動基金持續買就沒問題，站上230元後目標挑戰前高273元
- **推薦來賓**: 冠軍

#### 2. 創惟 (6104) - USB IC設計
- **產業催化劑**: 原象十位去（Vision Pro 2）準備出貨
- **關鍵地位**: Vision Pro 2的USB IC獨家供應商
  - 上一代佔比50%
  - 新一代做兩顆下部IC（量由1顆增至2顆）
  - 法人估計出貨價至少提升1.5倍
- **營運展望**: 去年第四季已有改善，法說會在即
- **推薦來賓**: 冠軍

### 三、美中科技戰與半導體影響（配正分析）

#### 拜登任期末期管制措施
- 2024年11月：要求台積電不得對中國客戶供應7奈米及以下先進AI晶片
- 實體清單擴增至140家
- 2025年1月：AI晶片三級管制（待川普拍板）

#### DeepSeek影響分析
- 宣稱開發成本560-600萬美元（遠低於美國AI公司的數十億美元）
- 可能有少報嫌疑（偷藏5萬顆H100）
- **正面影響**: 加速邊緣運算AI滲透率
- **中性觀點**: 美國CSP大廠仍不會放棄高資本支出的雲端運算
- **結論**: 全球AI軍備競賽持續，台積電仍為核心

#### 2月18日關稅情境分析
- **情境一（較樂觀）**: 台積電因無可替代性，具備轉嫁能力
  - 75%美國客戶可能需承擔成本
  - 先進製程3奈米、2奈米無競爭對手
- **情境二（風險）**: 成熟製程無海外廠做彈性調配，較居劣勢
- **反托拉斯風險**: 美方可能以此議題要求台積電加強美國投資
- **台積電談判籌碼**: 先進製程不可替代性

#### 今年半導體景氣展望
- 全球半導體成長率從去年22%降至16-16.5%，但仍為正成長
- 營收將持續創新高（達6.17兆美元）
- 台積電先進製程+先進封裝（CoWoS）仍不可或缺
- 聯發科在邊緣運算為最大受益者

### 四、外資操作歷史經驗

#### 外資大賣後的台股表現
- 過去外資前10次大賣經驗：只要台股均線不是明顯向下，多頭格局未死，仍有機會挑戰前高
- 關鍵觀察：均線方向

#### 2月7日非農數據觀察

- 公布後市場先漲 -> 大型權值股（如鴻海、廣達）可能是逃命機會

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **主動型基金** | 由基金經理人主動選股操盤的基金，追求超越大盤的績效 |
| **被動型基金（ETF）** | 追蹤特定指數或策略的基金，不需主動選股 |
| **高股息ETF** | 以高殖利率股票為主要成分的ETF（如0056、00878等） |
| **可轉債（CB）** | 可轉換公司債，持有人可在特定條件下轉換為股票 |
| **鉸鏈** | 折疊裝置的關鍵零組件，決定折疊角度與耐用度 |
| **Vision Pro** | 蘋果推出的混合實境頭戴裝置 |
| **CoWoS** | 台積電先進封裝技術（Chip on Wafer on Substrate） |
| **CSP** | 雲端服務供應商（Cloud Service Provider），如Google、微軟、亞馬遜 |
| **實體清單** | 美國商務部列管的外國實體名單，被列入者受出口管制 |
| **GB200** | NVIDIA最新一代AI伺服器晶片/系統 |
| **非農就業數據** | 美國每月公布的非農業部門就業人口變動數據，為重要經濟指標 |
