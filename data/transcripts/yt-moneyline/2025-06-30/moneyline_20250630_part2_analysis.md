## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| ETF換股（成分調整） | ETF定期依照編製規則調整成分股，被剔除的個股會被大量賣出 |
| 棄息操作 | 外資在除息前賣出股票，避免參與除息後的所得稅負 |
| 填息 | 股票除息後股價回到除息前的價位，代表投資人實質獲得股利 |
| GIS | Gas Insulated Switchgear（氣體絕緣開關），高壓電力設備的核心組件 |
| BBU | Battery Backup Unit（備用電池單元），用於資料中心不斷電系統 |
| AI行動日 | 川普預定7月23日宣布的AI基礎建設加速政策 |
| ATE | Automatic Test Equipment（自動測試設備），半導體後段檢測設備 |
| N8銅箔基板 | 高速傳輸所需的先進銅箔基板材料，為AI伺服器PCB核心材料 |
| 西門子轉單 | 德國西門子電力設備缺貨，將訂單轉移至台灣廠商 |
