## 📊 市場總體觀察

### 穩定幣法案重大進展（七占分析）

#### 美國參議院通過穩定幣法案
- **事件**: 美國參議院通過川普支持的穩定幣監管法案（高度分裂的參議院質疑後仍通過）
- **後續流程**: 需經眾議院通過及總統簽署
- **財政部長貝森特預告**: 穩定幣市場10年後規模達3.7兆美元

#### 穩定幣運作原理
- **定義**: 與法定貨幣（如美元、日幣、英鎊）1:1掛鉤的加密貨幣
- **核心功能**: 解決加密貨幣與法幣之間的轉換問題（虛實之間的橋樑）
- **舉例**: 持有1顆比特幣（約10萬多美元）要換現金很困難，但可先換成等值穩定幣
- **日幣穩定幣**: 也存在，讓日本投資人不用擔心美元匯率波動
- **美國戰略意義**: 掌握穩定幣發行與監管 = 鞏固美元霸權
- **儲備要求**: 發行1元穩定幣需有等值美元資產（如美債）做儲備 = 增加美債買盤

#### 穩定幣市場版圖
- **USDT（泰達幣）**: 市佔約70%
- **USDC（Circle發行）**: 市佔約30%
- **川普相關**: 川普本人也有發行穩定幣（USD1）

#### 支付革命影響
- **大型零售商**: 亞馬遜、沃爾瑪考慮發行自己的穩定幣
- **衝擊信用卡**: Visa、Mastercard股價一度下跌5%
- **應用場景**:
  - 企業內部支付（如亞馬遜發行A幣，消費全在平台體系內流通）
  - 跨境匯款免手續費（直接轉帳，不需銀行）
  - 各平台穩定幣互通（MOMO幣、蝦皮幣等）
  - 省去信用卡手續費（1-3%）
- **台灣想像**: 若各大電商平台穩定幣互通，傳統信用卡與銀行匯款將受衝擊

#### Circle（USDC發行商）IPO
- **IPO價格**: 31美元（6月5日上市）
- **目前股價**: 接近150美元（漲近5倍）
- **巴菲特動態**: 週一全數清倉，獲利約5,000多萬美元
- **ARK女股神**: 也已獲利了結
- **評估**: 穩定幣非創新技術但有高應用性，巴菲特獲利了結合理但非過熱訊號
- **風險提醒**: Circle賺錢幅度有限（主要靠利息與綁定優惠），短線追高風險大

### 台幣強升深度分析（珠老師分析）

#### 台幣走勢數據
- **6月以來**: 台幣升值1.3%（美元指數僅跌0.9%）
- **一週表現**: 台幣升值1.43%，遠超其他亞幣
- **亞洲最強**: 超過人民幣、日圓、韓圜（韓圜甚至貶值）
- **遠期匯率**: 一年期遠期匯率貼水1.8元（暗示市場預期繼續升值至約27.7元）
- **離岸NDF市場**: 5月初曾出現26元多的價格（在岸還在30元時）；近期再次出現低於29元的價格

#### 台幣獨強三大原因

##### 1. 匯率操縱觀察名單（美方壓力）
- 美國財政部連續七次將台灣列入觀察名單
- 6月初將公布最新名單結果
- 台灣對美貿易順差去年超過700億美元
- 美國認為台幣被低估、央行在操縱匯率
- 央行被迫放手讓台幣升值以回應美方壓力

##### 2. 關稅談判提前反映
- **原始關稅**: 32%
- **川普底線**: 10%（英國已談到10%）
- **英國背景**: 英國與美國是鐵桿盟友，且對美「順差」都要10%
- **台灣困境**: 對美逆差700多億，不可能比英國低
- **市場傳聞**: 關稅協議可能在7月9日前提前公布
- **代價推測**: 加碼投資、加碼採購、匯率讓步
- **小道消息**: 已有人聽到好消息，外資提前進場佈局，台幣提前反映

##### 3. 套利資金（熱錢）
- 可能是上述原因的結果而非原因
- 外資聽到好消息後提前進場，推升台幣

#### 央行應對措施（四大手段）
1. **道義勸說**: 要求銀行外匯部、外商銀行、大型出口商節制美元拋售
2. **盤中干預**: 午盤後（尤其午盤結束後）透過外匯經紀商操作（避免直接出手被美方抓到）
3. **限制出口商結匯**: 每日結匯上限從2,000萬美元降至1,000萬美元（如台積電這種大廠影響甚大）
4. **開升走貶模式**: 連兩天走勢都是上午升值、下午央行動作壓回

#### 央行困境
- 美國盯上央行操作，以前自己出手現在改用外匯經紀商避嫌
- 大出口商跳腳：全世界都知道台幣要升，自然想趕快換台幣
- 若大廠帶頭拋售美元，小廠跟進將造成群聚效應（多殺多）

#### 台幣升值預測
- **外銀共識**: 28.8元附近（美國銀行、摩根等4-5家）
- **28元多幾乎不可避免**: 問題是到多少

### 央行理監事會前瞻（6/19）

#### 利率預測：連五凍
- **幾乎確定**: 維持利率不動
- **理由**:
  1. 過去升息幅度比別國少，降息空間也少
  2. 台灣利率在全球仍屬偏低
  3. 前五個月CPI平均超過2%（5月降至1.5%多，但關稅加徵後可能再升）
  4. 連續三年CPI超過2%
  5. 關稅影響尚未完全反映

#### 房市管控
- **信用管制**: 不太可能在此時鬆綁
- **可能時間**: 年底再視情況決定
- **理由**: 關稅問題最終影響尚不明朗

#### 記者會預期焦點
- 台幣升值走到多少？
- 關稅對通膨的影響？
- 央行立場：「我不是談判代表，不要問我關稅」

## 💼 美債市場深度分析（珠老師分析）

### 真正的問題

#### 1. 聯邦總負債持續攀升
- **最新數字**: 36.21兆美元（第一季）
- **川普上任後**: 較前一季（拜登末期）減少約30億美元（但長期趨勢仍向上）
- **利息支出佔GDP**: 高達3.025%（近90度角攀升）
- **去年利息**: 1.1兆美元
- **明年預估**: 若利率不降，利息將達1.5兆美元
- **問題根源**: 大量舊債到期需用更高利率續借

#### 2. 聯準會縮表持續
- **最高峰**: 9.1兆美元資產
- **目前**: 6.67兆美元（已縮表2兆多美元）
- **保守估計QE規模**: 至少5兆美元
- **影響**: 新債不斷發行，舊債被拋售，供需壓力增加

#### 3. 美債波動度驚人
- **近三年**: 美債波動度比美股還大
- **打破觀念**: 買債不等於安全（不會違約，但「價格」一點都不安全）

### 破解市場謠言

#### 謠言1：6月有6.5兆美元到期壓力
- **事實**: 6.5兆是整個上半年累計，非單月
- **5月已過高峰**: 約2.6兆已順利過關
- **6月**: 約1.6兆，壓力已漸小
- **結論**: 到期壓力最難過的一關已過，後續壓力遞減

#### 謠言2：8月舉債上限到期將違約
- **事實**: 自1917年以來，舉債上限已提高108次（平均每年約1次）
- **政治現實**: 即使民主黨討厭川普，這種重大事情還是得讓步
- **結論**: 百分之百會提高上限，美國不會違約

#### 謠言3：10年期殖利率破5%美股會崩盤
- **歷史驗證1**: 2023年10月破5%，美股僅小跌一點
- **歷史驗證2**: 更早期5.289%永遠高過5%，美股幾乎不動
- **結論**: 完全是謠言，歷史上從未因殖利率破5%而崩盤

### 投資人真正的痛點：匯率

#### 美債基金虧損原因
- **美元計價**: 各類債券ETF今年仍有正報酬（2-6%）
- **台幣計價**: 今年台幣升值9.9%，所有美元資產報酬被匯差吃掉
- **結論**: 美債無罪，問題在台幣升值

#### 債券投資建議

| 債券類型 | 今年表現 | 安全度 | 建議 |
|----------|----------|--------|------|
| 歐洲債券 | 較佳 | 中高 | 可考慮（歐元升值） |
| 新興市場債 | 佳 | 中 | 可考慮 |
| 金融債/投等債 | 佳 | 中高 | 穩健選擇 |
| 中國政策債 | 佳 | 中 | 可考慮 |
| 美國公債 | 差（匯損） | 高 | 需長期抗戰心態 |

- **各類排名**: 歐洲 > 新興市場 > 金融 > 投等 > 新興現金 > 中國政策 > ... 最差是美債

#### 降息預測
- **Fed Watch**: 今年仍有2次降息機會（9月、12月）
- **投行預估**: 保守看只降1次（12月）
- **矛盾**: 若買債為了領息，不降息反而更好；若為了資本利得，才需要降息
- **建議**: 目前以短天期債券為主，降低利率與匯率雙重風險

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **穩定幣（Stablecoin）** | 與法定貨幣（如美元）1:1掛鉤的加密貨幣，價值穩定 |
| **USDC** | Circle發行的美元穩定幣，市佔約30% |
| **USDT（泰達幣）** | Tether發行的穩定幣，市佔約70% |
| **USD1** | 川普相關團隊發行的穩定幣 |
| **NDF** | Non-Deliverable Forward，無本金交割遠期外匯，離岸市場工具 |
| **匯率操縱觀察名單** | 美國財政部半年公布一次，評估各國是否操縱匯率 |
| **舉債上限** | 美國國會對聯邦政府舉債總額的法定限制 |
| **縮表（QT）** | Quantitative Tightening，聯準會減少資產負債表規模 |
| **QE** | Quantitative Easing，量化寬鬆，聯準會買進債券釋放資金 |
| **殖利率** | 債券的收益率，與債券價格呈反向關係 |
| **連五凍** | 央行連續五次維持利率不變 |
| **CPI** | Consumer Price Index，消費者物價指數，衡量通膨指標 |
| **Fed Watch** | CME集團推出的聯準會利率預測工具，基於利率期貨價格推算 |
| **道義勸說** | 央行以非正式方式要求金融機構配合匯率政策 |
| **貼水/升水** | 遠期匯率低於/高於即期匯率，反映市場預期 |
| **信用管制** | 央行對房貸等特定信用的限制措施 |
