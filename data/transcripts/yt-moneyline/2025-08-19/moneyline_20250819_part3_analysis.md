## 📊 市場總體觀察

### 台積電二奈米定價策略
- **韓國媒體曝光**: 台積電二奈米晶片每片定價約 **3 萬美元**（約 100 萬台幣）
- **漲幅**: 比三奈米製程貴 50%-66%
- **策略**: 不打折、不議價，所有客戶同一價格
- **三奈米參考**: 蘋果晶片每片從 5,000 美元調高至 18,000 美元（十多年來漲 3.6 倍）
- **量產時間**: 預估明年（2026年）全面量產
- **高盛推估**: 二奈米接近 3 萬但非滿 3 萬，留有議價空間但立場是「不折價」

### 晶片價格演進（各製程跳升幅度）
| 製程跳升 | 單片價格漲幅 |
|---------|------------|
| 七奈米 → 五奈米 | +99.1% |
| 五奈米 → 三奈米 | +29% |
| 三奈米 → 二奈米 | +50~66% |

### 小晶片（Chiplet）趨勢
- **背景**: AI 晶片越切越大顆，12 吋晶圓只能切約 16 顆，良率極低（一顆壞掉就報廢）
- **解決方案**: 小晶片架構 -- 將晶片拆分為多個小模組再組合
  - 中間 AIO（資料進出）用六奈米（便宜）
  - 旁邊 Computing 用二奈米（算力核心）
  - 組合後整體 die size 不變，但良率大幅提升（可切 96 片）
- **影響**:
  - 良率爬升更快
  - 毛利率更高（越小越便宜的部分用便宜製程）
  - 五奈米以下 Chiplet 滲透率將持續提升
  - 二奈米使用 Chiplet 比例會更高

## 💼 產業分析與投資建議

### 一、台積電二奈米受惠概念股

**核心邏輯**: 二奈米高定價 + 小晶片趨勢 → 先進製程相關材料與設備受惠

#### 二奈米概念股（冠軍提及）
- **達興材料**: 近期強勢
- **台特化**: 近期強勢
- **新印材**: 近期強勢
- **巴比 CPO 族群**: 總科長溪、聯茂等
- **操作建議**: 持續關注，尚未過前高的有補漲空間

---

### 二、貴重金屬概念股（健序深度分析）

#### 1. 鎢（W）概念股 -- 台積電唯一合格的鎢供應商

**鎢的應用**:
- 半導體薄膜製程（六氟化鎢）
- 手機振盪器訊號穩定
- 飛彈陀螺儀定位（軍事用途）
- PCB 微鑽頭（鎢極硬，用於鑽通細孔）
- 砲彈、裝甲

**鎢價大漲原因**: 中美貿易對抗，中國禁止鎢出口，全球供應短缺

**全球鎢產量分布**:
| 國家/地區 | 佔比 |
|----------|------|
| 中國 | 80.2% |
| 台灣 | 3% |
| 其他（非中） | 16.8% |

**投資邏輯**:
- 台積電要求「責任礦產」（不使用壓榨人權的礦產）
- 台灣唯一合格供應商，在非中供應鏈中佔重要地位
- 中國禁止出口 → 非中供應商受惠
- 貴重金屬近兩年因地緣政治持續漲價

**相關個股**: 即將掛牌上市（創新板），從稀有金屬的鎢與鉬進行純化精煉，生產鎢酸與鉬酸鈣

#### 2. 銠（Rh）概念股 -- 光洋科

- **定位**: 台灣最大銠代理商
- **銠價格**: 一克約 1,000 元（100 克即 10 萬元），極其昂貴
- **用途**:
  - 白金族群金屬，硬度極高
  - 硬碟需求龐大（雷射是夫妻硬碟帶動）
  - 半導體相關
  - 被動元件（鉭質電容等）
- **供應鏈**: 金屬 → 靶材製造 → 薄膜製程 → 台積電、三星、AMD 等
- **近期事件**: 半導體部門計劃分割獨立
- **銠價走勢**: 持續創高（每盎司衝上 800 美元以上）

#### 循環經濟概念
- **責任金屬 + 循環利用**: 台積電要求金屬密閉循環（一片使用多次）
- **受惠族群**: 經營貴金屬回收再利用的公司

### 三、台灣人均 GDP 超越日本的啟示（慶龍）

#### 數據分析
- **2024 年台灣人均 GDP**: 33,980.3 美元（IMF 統計）
- **日本**: 32,850 美元
- **換算**: 台灣每人約 100.1 萬台幣；四口之家約 400 萬
- **中位數年所得**: 僅約 50 多萬（遠低於人均 GDP）
- **落差原因**: 半導體+電子資訊業員工（佔就業人口僅 7%）大幅拉高平均值

#### 88 節壓力調查
- 95% 受薪男性感覺生活壓力大
- 超過 40% 男性每月 70% 以上薪資用於家庭開支
- 12.2% 需全數上繳

#### 慶龍的投資哲學
1. **人不理財，財不理你**: 台灣教育缺乏理財教育
2. **問題不在收入太少，而在沒人教你讓錢長大**
3. **價值投資**: 投資好公司 + 用時間創造複利
4. **財富靠累積，不靠交易**: 一輩子找到一兩檔好股票，長期持有

- 一旦融資回到 3,000 億要提高警覺

## 📋 投資策略總結

### 短期（1-2 週）
- 台積電二奈米題材持續，小晶片趨勢帶動材料股（達興材料、台特化、新印材）
- 貴重金屬概念股受地緣政治推升，鎢價、銠價持續走高
- 融資未到 3,000 億前，行情仍健康

### 中期（1-3 個月）
- 台積電二奈米明年量產，相關供應鏈 Q4 起出貨將逐步反映
- 貴重金屬（鎢、銠）在中美對抗背景下持續緊缺，相關公司受惠
- 責任礦產 + 循環經濟趨勢下，台灣本土供應商地位提升

### 風險評估
- **二奈米風險**: 良率爬坡期可能不順，影響出貨節奏
- **貴重金屬風險**: 若中美關係緩和，禁令解除可能導致價格回落；庫存利益反轉為庫存損失
- **價值投資風險**: 需正確辨識「好公司」，否則長期持有虧損股反而損失更大
- **融資關鍵水位**: 3,000 億為警戒線

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **小晶片（Chiplet）** | 將大晶片拆分為多個功能模組再組合的架構，提升良率並降低成本 |
| **Die Size** | 晶片面積大小，越大良率越低 |
| **良率（Yield）** | 晶圓上合格晶片的比例，直接影響製造成本 |
| **六氟化鎢** | 鎢的化合物，用於半導體薄膜製程 |
| **銠（Rh）** | 白金族貴重金屬，硬度極高，用於硬碟、半導體靶材、被動元件 |
| **責任礦產** | 國際大廠要求的供應鏈規範，確保礦產來源不涉及人權壓榨 |
| **循環經濟** | 材料回收再利用的概念，台積電要求金屬密閉循環使用 |
| **人均 GDP** | 國內生產毛額除以人口數，反映平均經濟產出但不代表實際所得分配 |
| **中位數** | 所有數據排序後中間值，比平均值更能反映一般人實際狀況 |
| **融資餘額** | 投資人向券商借錢買股的總額，是衡量市場槓桿與散戶參與度的重要指標 |
