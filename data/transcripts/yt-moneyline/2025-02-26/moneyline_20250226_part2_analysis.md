### 三月份重要主題：作帳與結帳

#### 投信作帳（最重要）
- **為何投信作帳重要**: 投信有一條「電話線」連結業內主力，投信買什麼消息會傳出去
- **作帳特性**: 投信偏好中小型個股（快速列車）
  - 越會漲越喜歡追，「緊上天花板」拼績效
  - 業內主力配合拉抬：鎖漲停板、幫忙抬轎
- **操作策略**:
  - 追蹤投信**新布局**的個股（從1月開始買，持股比接近一成）
  - 趁盤中震盪、支撐未破（五日線/均線）時布局
  - 若投信**買轉賣**，立即出場（不管基本面有沒有破）
  - 投信賣出 → 業內主力跟著跳車 → 散戶最後殺（三波殺盤）

#### 結帳風險判斷
- 投信新布局（成本差不多、持股比未達一成）→ 不會被結帳
- 投信已獲利豐厚（持股比高）→ 可能提前結帳獲利了結
- **關鍵**: 觀察投信是否「買轉賣」，一旦轉賣即為出場訊號

#### 集團作帳
- 以**半年均價**為計算基礎（質押借款依據）
- 三月份集團作帳機率較低，六月/九月/十二月較明顯
- 集團（大股東）喜歡「區間車」洗盤，不像投信做高鐵快車
- 大股東常以投資公司身份出現在「假外資」買賣超中

#### 外資與自營商
- **外資**: 無月報壓力，不存在作帳問題，只有套利問題
- **自營商**: 幫老闆操作，短線看風向跑，以避險為主

## 📈 技術面分析與操作策略

### 投信作帳操作法
1. **篩選條件**: 投信從1月開始買 + 持股比接近一成 + 籌碼優勢
2. **進場**: 盤中震盪不破支撐時布局
3. **出場**: 投信「買轉賣」即出場，不等基本面破壞
4. **風險**: 投信賣 → 業內主力跳車 → 散戶被殺（三波殺盤）

### 特斯拉技術面觀察
- 今年跌幅達25%，短期有量可能止跌
- 呈現下降趨勢線格局
- 中國比亞迪自駕系統免費，特斯拉還要收費，競爭壓力加大
- 相關概念股（亞光等）需注意特斯拉走勢影響

### 避免踩雷：投信賣出個股
- **案例**: 忘記（6231）等個股已跌破半年線，投信持續賣出
- 投信「買轉賣」不要去搶反彈，等賣出一個底型後再介入也不遲

## 📋 投資策略總結

### 核心觀點
1. **三月作帳行情**: 以投信作帳為主（集團作帳六月後才明顯）
2. **投信新布局方向**: 運動類股、重建概念股（鋼鐵/航運）、AI相關（神準、台光電）
3. **停戰重建**: 長線題材，BDI低檔 + 報價未漲 = 風險有限空間大
4. **操作節奏**: 資金流向比每天都在變（電子vs傳產），靈活應對

### 風險控管
1. 投信「買轉賣」是最重要的出場訊號
2. 停戰概念股拉回可買，不追高
3. 記憶體股短線可做但不宜做長
4. 注意特斯拉走勢對相關供應鏈的影響

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **投信作帳** | 投信基金經理人在季末前拉抬持股以美化績效報表的行為 |
| **結帳** | 投信在季末前賣出持股獲利了結，鎖定已有報酬 |
| **籌碼優勢** | 投信 + 業內主力同時買進，1+1大於2的加乘效果 |
| **BDI指數** | 波羅的海乾散貨指數，反映全球散裝航運市場運價 |
| **BCI** | 波羅的海海岬型指數，反映大型散裝船運價 |
| **持股比** | 法人（投信/外資）持有某檔個股的比例 |
| **買轉賣** | 法人從連續買超轉為賣超的轉折點，重要出場訊號 |
| **假外資** | 以投資公司身份登記為外資的本土資金（大股東常用方式） |
| **半年均價** | 180天的平均股價，為大股東質押借款的計算基礎 |
