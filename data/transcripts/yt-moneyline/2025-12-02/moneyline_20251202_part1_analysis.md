## 💼 產業分析與投資建議

### 一、Google Gemini 3.0 光互連技術（ICA 光學架構）

繪子老師深入解析 Google 的 ICA 光學架構，包含兩大關鍵技術：

**1. OCS（光學電路交換器）**
- 核心元件：微機電鏡片（MEMS），每台收發器內含數千到數萬個微米級小鏡子
- 運作原理：光訊號經過準直器變成平行光，打到微鏡後反射至目標位置
- 關鍵優勢：全程光學反射，無需光電轉換（O-E-O 轉換）
- 對比傳統 NVIDIA 架構：傳統需反覆光轉電、電轉光，耗時、耗能、發熱

**2. Candy Torus（環狀拓撲架構）**
- 將 64 個 TPU 組成一個立方體，共 144 個小立方
- TPU v7 使用 48 台 OCS 互聯 9,216 顆 TPU
- 使用 13,824 條光纖連接
- 鏡子可在數秒內轉向，實現近乎即時的路由切換

**光互連帶來的優勢：**
- 功耗降低 45%
- 總運算成本降低 45%-55%
- 每個節點規模擴大 16-128 倍
- 訓練幾乎可以不間斷

### 二、三五族化合物半導體商機

嘉明大哥分析三五族（III-V）化合物半導體的多重成長動能：

**光通訊面向：**
- 雷射二極體相關元件需求增加
- 磷化銦（InP）為光收發模組關鍵基材
- 資料中心傳輸速度從 400G 升級至 800G，NVIDIA GB300 進入 1.6T

**WiFi 升級面向：**
- WiFi 多通道數增加（6 通道以上）
- 資料中心用 WiFi 裝置數量：2025 年約 15 億，2026 年預估 27 億
- 手機端將從矽基製程升級至三五族化合物

### 三、鴻海長公主賣股事件

**事件概要：**
- 郭曉玲（鴻海創辦人郭台銘長女）申報出脫 5,180 張鴻海股票
- 透過兩家投資公司全數出清，預估套現約 11 億元
- 從 12/4 開始至隔年 1/3，以一般交易形式進行

**分析觀點（慶龍）：**
- 實質面影響不大：5,180 張 vs 郭台銘持有 174 萬張，小巫見大巫
- 可能原因：(1) 家族年底財產配置調整 (2) 長公主另有事業打算
- 以 2025 年獲利計算，222 元已來到合理價上緣，賣出合情合理
- 鴻海 2025 年預估 EPS 14.18 元，合理價上緣約 220 元

**分析觀點（繪子）：**
- 張數僅 5,180 張，相對鴻海成交量影響極小
- 與鴻海基本面無太大關係
- 不需過度擔心

### 四、ETF 高股息比拼

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| OCS（Optical Circuit Switch） | 光學電路交換器，使用微機電鏡片進行全光路由切換 |
| MEMS | 微機電系統，此處指光開關中的微米級可旋轉鏡片 |
| Candy Torus | Google TPU 的環狀立體拓撲連接架構 |
| O-E-O 轉換 | 光-電-光轉換，傳統網路中光訊號需轉為電訊號再轉回光訊號 |
| TPU v7 | Google 第七代張量處理器 |
| III-V 族化合物 | 如砷化鎵（GaAs）、磷化銦（InP），用於光通訊與射頻元件 |
| 磷化銦（InP） | 光收發模組核心基材，用於雷射二極體 |
| 本益比（P/E） | 股價除以每股盈餘，衡量股票估值的指標 |
