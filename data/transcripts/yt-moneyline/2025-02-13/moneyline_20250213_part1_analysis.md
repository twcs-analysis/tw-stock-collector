### ETF投資策略

#### 0050費率大戰

**背景**
- 元大台灣50（0050）宣布在封關前降低管理費
- 0050管理費從千分之3.2降至千分之1以下（規模級距制）
- 富邦台50（006208）管理費為千分之1.5
- 0050費率降後比006208更便宜

**ETF總費用率比較重點**

| 項目 | 說明 |
|------|------|
| 經理費 | 基金管理費用 |
| 保管費 | 資產託管費用 |
| 交易成本 | 買賣股票的手續費與交易稅 |
| 會計列帳費用 | 其他管理成本 |
| 總費用率 | 以上四項加總，才是投資人真正付出的成本 |

**重要提醒**: 不能只看經理費和保管費，要看「總費用率」才是真正成本

**0050分割計畫**
- 計畫將1張分割成5張
- 降低單價，讓小資族更容易入手
- 對既有持股者無影響（張數變多，總價值不變）

#### 市值型 vs 高股息ETF

**市值型ETF比較**

| ETF | 費率特色 | 總費用率 | 去年表現 |
|-----|---------|---------|---------|
| 0050 | 降費後最低 | 約千分之2.5 | 台積電占比高，表現最佳 |
| 006208 | 富邦系列一直較低 | 約千分之2.5 | 與0050相近 |
| 原大ESG | - | 0.47% | 表現不錯 |
| 國泰ETF | 新發行 | 約千分之4 | 尚未滿兩年 |

**高股息ETF費用率**
- 普遍在千分之5到千分之8之間
- 比市值型費用率高
- 原因：多因子選股、換股頻率較高（如00919每次換近40檔）
- 換股頻率高 = 交易成本高 = 總費用率高

**美國趨勢參考**
- 美國最大ETF公司先鋒（Vanguard）大幅調降費率
- 平均降幅20%，已降到萬分之三
- 台灣未來可能跟進降費趨勢

**投資建議**
- 今年市值型ETF有機會勝出高股息
- 但去年市值型表現好是因為重壓台積電
- 短線台積電受壓力，選擇較分散的市值型ETF
- 以費率角度選ETF，要看總費用率而非只看經理費

## 📚 名詞解釋

### 投資術語

**破底翻**
- 定義：股價跌破前低支撐後，又快速反彈向上突破
- 意義：可能代表空方力竭，多方開始接手
- 應用：今日鋼鐵、塑化等傳產族群出現此現象

**殖利率 (Dividend Yield)**
- 定義：每股股息 ÷ 每股股價 × 100%
- 意義：衡量股息報酬率
- 標準：4%以上通常被視為高殖利率

**總費用率 (Total Expense Ratio)**
- 定義：ETF每年收取的所有費用占淨資產的比例
- 組成：經理費 + 保管費 + 交易成本 + 會計列帳費用
- 重要性：才是投資人真正付出的成本，非僅看經理費

**分割 (Stock Split / ETF Split)**
- 定義：將一張股票或ETF分割為多張，降低單價
- 特點：總價值不變，僅張數增加、單價降低
- 目的：降低投資門檻，吸引更多投資人

### 技術分析術語

**趨勢線 (Trend Line)**
- 定義：連接兩個以上低點或高點的直線
- 意義：判斷股價趨勢方向
- 應用：台積電上升趨勢線為重要支撐

**頸線 (Neckline)**
- 定義：頭肩底或雙底型態中的關鍵水平線
- 意義：突破頸線代表型態完成，趨勢可能反轉
- 應用：裕民突破頸線後以頸線為支撐

**均線糾結 (Moving Average Convergence)**
- 定義：多條均線在狹窄區間內交織纏繞
- 意義：即將選擇方向，可能出現大行情
- 應用：美亞均線糾結後等待帶量突破

**60日線 / 季線 (60-Day Moving Average)**
- 定義：過去60個交易日收盤價的平均值
- 意義：中期趨勢的重要參考
- 應用：台積電觸及60日線為重要支撐位

### 產業術語

**晶片法案 (CHIPS Act)**
- 定義：美國2022年通過的法案，補助半導體製造業在美設廠
- 規模：約520億美元補助
- 影響：Intel可能藉此取得補助

**2奈米製程 (2nm Process)**
- 定義：半導體最先進的製造技術之一
- 現況：台積電積極推進，預計近年量產
- 影響：相關設備與材料廠商將受惠

**資本支出 (Capital Expenditure / CapEx)**
- 定義：企業用於購買固定資產的支出
- 台積電狀況：持續擴大，美日德同步建廠
- 近期預估：將資本支出拉高至380~420億美元歷史新高
