## 💼 產業分析與個股建議

### 一、底部型態教學與實戰應用

#### W底（雙重底）買賣策略
- **第一買點**: 帶量突破頸線（W底高點連線）
- **第二買點**: 拉回頸線不破，再次確認
- **停損設定**: 突破紅棒的低點
- **關鍵原則**: 所有多頭右邊縮量，所有空頭左邊有量

#### M頭（雙重頂）辨識
- 左邊量大、右邊量小（主力已出貨）
- 跌破頸線 → 反彈再破頸線 → 確認頭部
- 三尊頭（頭肩頂）同理

#### 多重底操作法
- 最適合穩健投資人的底部型態
- 均線糾結 → 開口向上 → 帶量突破 = 標準標果訊號
- **實例**: 金居 (8358) 即為多重底突破

#### 中繼站概念（追高策略）
- 上漲過程中的爆大量長紅棒 = 中繼站
- 接近低點嘗試進場，停損距離不超過5%
- 以紅棒低點或跳空缺口低點為出場參考

#### 長黑K棒反轉策略（勝率九成）
- 下跌過程中出現距大量長黑K棒
- **條件**: 融資減少100億 + 三個營業日內過高（盤中即可）
- **勝率**: 高達九成
- **實例**: 4月股災當天出現長黑K棒，一天就過高，直接回升
- **注意**: 距大量黑K棒隔天若再破就不算

#### 月線長紅棒回測策略
- 月線出現長紅棒後，4-6個月內必然壓回
- 壓回若守住長紅棒低點且量縮 → 買進
- 以該低點為停損，距離不超過10%

### 三、高股息ETF新規範（金管會）

#### 新規三大原則
1. **實際配息率不得高於參考配息率**，且須說明差異
2. **收益平準金啟動標準與使用上限**須明確規範
3. **收益平準金分配優先順序**及使用金額須透明化

#### 配息來源四大管道
1. 成分股股息孳息（最正常來源）
2. 持有現金部位利息收入
3. 資本利得（換股產生）
4. 收益平準金（爭議最大來源）

#### 投資人注意事項
- **不必恐慌**: 未來不會看不到10%以上配息率，濫用平準金的僅是少數
- **資本利得可能很大**: 部分高配息率來自資本利得而非僅股息
- **多數基金公司合規經營**: 真正濫用收益平準金的為少數
- **配息不等於股息孳息**: 投資人須了解配息組成結構

### 四、主動式ETF崛起

#### 今年六檔主動式ETF表現
- 前四名中有三名為主動式ETF
- 均為六位數代碼（新掛牌），迴避了Q1台股低谷
- 近一個月表現多數優於大盤與元大台灣50

#### 主動式 vs 被動式差異
- **被動式**: 追蹤指數，持股固定，無法調整
- **主動式**: 量化模型篩選後，經理人可主動調整
- **特色差異**: 部分主動式ETF台積電比重明顯低於0050

#### 投資人選擇建議
- 不只看績效，要看投資風格與風險承受度
- 主動式ETF經理人會「做價」，投信進出解讀須與以往不同
- 可參考原本旗艦基金績效作為參考

## 📈 技術面分析與操作策略

### 底部辨識五大口訣（書方老師）

1. **底部不是散戶決定的** → 大股東、中實戶分批進場打出底型
2. **帶量式突破頸線** → 一定要帶量（四個字記住）
3. **資金切割進場** → 先進一部分，拉回守住再加碼
4. **假突破/真拉回** → 突破後拉回不守住就是假的，立即出場
5. **所有多頭右邊縮量** → 底部右邊量比左邊少才是健康

### 8月操作策略（子東）

1. **先求不輸，再求贏** → 8月行情不確定性高
2. **選股重於選時** → 篩選條件嚴格（存貨周轉 + 毛利率 + 歷史統計）
3. **關稅免疫股優先** → 營收來自台灣/無美國市場的公司
4. **低檔整理完畢的標的** → 7月整理、8月有機會啟動

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **增資發新股** | 公司發行新股票換取資源，會導致股本膨脹、稀釋現有股東權益 |
| **W底（雙重底）** | 股價形成兩個低點的底部型態，突破頸線確認反轉 |
| **M頭（雙重頂）** | 股價形成兩個高點的頭部型態，跌破頸線確認下跌 |
| **頸線** | 連接底部高點（或頭部低點）的水平線，為關鍵突破/跌破位 |
| **收益平準金** | ETF為公平分配股息給新舊投資人而設的機制 |
| **主動式ETF** | 由基金經理人主動選股的ETF，非完全追蹤指數 |
| **存貨周轉率** | 衡量公司銷售效率的指標，上升代表下游拉貨積極 |
| **複合底型** | 股價反覆上下形成的底部，操作困難度較高 |
| **中繼站** | 上漲過程中的暫時整理位置，可供中途上車 |
| **背增量** | 產能利用率超過100%，需擴充產能才能滿足需求 |
