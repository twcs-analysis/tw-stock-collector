#### GV200出貨量趨勢
- 緯創、鴻海、廣達三家組裝廠Q2出貨量大幅走高
- Q3/Q4高點持續往上，AI伺服器需求不斷增長

### 台股與國際比較
- 今年以來台股在全球主要市場中表現最弱
- 日本因達成關稅協議後股市大漲脫離盤整區間
- 已達成協議的國家股市普遍上漲5%以上，甚至創歷史新高

### 關稅情境分析（黃金48小時）
- **情境一**: 8/1前達成協議，關稅20%以下 → 台股大幅上漲（最佳情境）
- **情境二**: 未達成協議，繼續延期 → 台股持續盤整（中性）
- **情境三**: 談不成，課徵客制32%關稅 → 台股短線下跌但不會崩（非真正利空，因仍有談判空間）
- **情境四**: 達成協議但稅率偏高（如25%） → 真正利空（5-10年定案，無翻案機會）

### 一、台積電 (2330) - 關稅利空下的最佳買點

| 項目 | 內容 |
|------|------|
| **收盤價** | 1,158元（歷史新高） |
| **今年EPS預估** | 55元 |
| **明年EPS預估** | 63-65元（低標） |
| **合理估值** | 63元 x 22倍 = 1,386元；保守看1,260元 |
| **操作建議** | 不追高，等關稅利空下跌時為最佳買點 |
| **目標價** | 1,260-1,386元 |
| **停損點** | 若長紅棒買進，以該紅棒低點為停損（約1,100元附近） |

**分析重點**:
- 1,160元以上不宜追高，需等待市場恐慌性賣壓
- 關稅公布若引發下跌，將是台積電絕佳買點
- 台積電的漲跌與關稅相關，與公司基本面無直接關係

## 📈 技術面分析與操作策略

### 大盤技術面
- 昨日跌破5月10日以來所有均線，今日全數收復
- 量能3,324億元，市場人氣仍旺
- 短線受對等關稅消息面影響大

### 個股操作原則（書方老師策略）
1. **乖離率過大者不追高** → 以大量區間低點為停損
2. **帶量突破均線者** → 可短線跟進，以突破紅棒低點為停損
3. **利空出盡判斷** → 第二季財報差但股價不跌反漲，為利空出盡訊號
4. **PCB族群** → 不是所有PCB都能漲，要看是否切入AI伺服器高階PCB

### AI族群投資方向建議（明漢策略）
- **優先買進**: AI伺服器（左邊，需求最強）→ 紅海、廣達、緯創
- **觀望**: 邊緣AI / AI PC（等蘋果財報）→ 聯發科觀望
- **避開**: 車用IC / 工業IC（需求最弱）

### PCB族群操作建議
- 投信主導的中小型PCB股較可信賴（外資真假難辨）
- 關注**聯茂**與**新興**兩檔：整理過後投信持續買超
- CPO族群也開始有動作，可留意

### 紅海 (2317) 短評
- 目前本益比最低的組裝廠
- 空手者可考慮廣達（後續補漲空間較大）

## 📋 投資策略總結

### 核心觀點
1. **對等關稅8/1上路為最大變數**，但不論結果如何，台積電與AI族群中長線趨勢不變
2. **台股在全球表現最弱**，一旦關稅協議達成，補漲空間巨大
3. **資金狂熱指標創歷史第三高**（僅次於2000年科技泡沫、2023年疫後噴發），但過去經驗顯示狂熱期可維持半年至一年
4. **PCB族群分化**：高階AI伺服器PCB（金居、副橋）持續缺貨看漲，消費性PCB不可混為一談
5. **台塑四寶漲停為中美關係題材**，非基本面改善，操作須設停損

### 資金配置建議
- 保留三成現金部位，等待關稅利空完全出盡
- AI伺服器族群為核心持股方向
- 短線操作以技術面為主，KD指標交叉向上再進場
