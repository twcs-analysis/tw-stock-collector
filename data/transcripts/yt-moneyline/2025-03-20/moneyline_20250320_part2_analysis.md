## 📊 市場總體觀察

### 柯老師 - 波段翻多三大訊號

#### 確認底部的三個條件
1. **賣壓利竭量縮**: 必須看到賣不下去的現象（長黑後縮量），目前尚未完全出現
2. **大盤與台積電守穩年線並翻多**: 動態觀察年線攻防，目前仍反覆跌破
3. **政府積極護盤且擴大買超**: 已持續發生，買跌不買漲

#### 區間研判
- **波段區間**: 22,999 ~ 21,769
- **3月11日低點 21,769**: 經過多次利空測試，可能成為波段低點但尚未確認
- **3月27日**: 預估第二波高點出現後會拉回
- **關鍵觀察**: 官股是否持續賣出（反彈最後幾天會出現官股賣、外資轉不買的訊號）

### 2025年全球總經四大不確定性

1. **美國新政（關稅戰）**: 影響最大，可能造成新通膨或經濟趨緩
2. **貨幣政策分歧**: 川普政策與Fed政策不同步時，政策分歧擴大
3. **中國經濟長期供需失衡**: 拖累全球股市持續上漲
4. **地緣政治**: 增加市場波動，但通常影響短暫

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **董監改選** | 上市櫃公司每三年進行一次董事與監察人改選 |
| **最後過戶日** | 股東會前60天，持有股票者才具有投票權 |
| **設質比例** | 董監事將持股質押借款的比例，比例高者回補動機強 |
| **殖利率** | 現金股利除以股價的比率，代表投資收益率 |
| **官股** | 政府相關基金（國安基金、勞退、郵政儲金等）的操盤帳戶 |
| **頭肩底** | 技術分析型態，底部出現三個低點（左肩、頭、右肩），為反轉訊號 |
| **重貼現率** | 央行提供給銀行的短期融資利率，為央行政策利率指標 |
| **T+2** | 股票交割制度，成交後第二個營業日完成交割 |
