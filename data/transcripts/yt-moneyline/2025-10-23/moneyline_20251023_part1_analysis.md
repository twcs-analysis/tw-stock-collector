## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| MLCC | 積層陶瓷電容器，被動元件核心產品，AI伺服器大量使用 |
| MOSFET | 金屬氧化物半導體場效電晶體，功率半導體核心元件 |
| APEC | 亞太經濟合作會議，21個成員國元首出席 |
| 殖利率 | 債券的年化收益率，與債券價格呈反向關係 |
| 投等債 | 投資等級債券，信用評等較高、風險較低的債券 |
| 超級週期 | 指公司技術或產品重大突破，帶動未來數年持續營運成長 |
| 存續期間 | 債券平均回收期，越長對利率變動越敏感 |
| GB200/GB300 | NVIDIA高階AI伺服器產品，需大量被動元件 |
