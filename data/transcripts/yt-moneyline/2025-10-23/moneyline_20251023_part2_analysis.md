## 🌍 市場總體觀察

### 國安基金深度解析

#### 國安基金規模擴大
- **現行規模**: 5,000億元
  - 2,000億：以國庫持有股票做擔保，向金融機構借款
  - 3,000億：四大基金（政府勞退等）投資
- **修法提案**: 借款額度從2,000億提高至7,000億元
- **擴大後總規模**: 從5,000億擴大至約1兆元

#### 國安基金歷史護盤紀錄（25年統計）
| 次數 | 時間背景 | 使用金額 | 備註 |
|------|---------|---------|------|
| 第1次 | 2000年 | 542億 | 首次護盤 |
| 第2次 | 網路泡沫+伊拉克戰爭 | 1,227億 | 史上最高使用金額 |
| 第3次 | - | 16億 | - |
| 第4次 | - | 600億 | - |
| 第5次 | - | 424億 | - |
| 第6次 | - | 196億 | - |
| 第7次 | - | 7.56億 | 史上最少 |
| 第8次 | - | 545億 | 史上最久 |
| 前次公布 | - | 17億 | - |
| 本次（至10/9） | - | 122億 | 最新數據 |

#### 國安基金擴大的三大意義
1. **增強市場信心**: 政府在後面撐，投資人可以放心操作
2. **不願意輸**: 5,000億都用不到，擴大到1兆是宣示決心
3. **不會輸**: 歷史證明每次護盤都贏

#### 指數推估
- 若國安基金規模從5,000億擴大到1兆，考量股本膨脹
- 台股有超過30,000點的空間與變化

### 台股技術面深度分析

#### 量價背離警訊
- 從17,306點起漲，量價配合良好（價漲量增）
- 成交量從3,800億逐步放大至6,847億
- 但三次過高（挑戰28,000點）均未出現新高量
- **結論**: 量價背離，短線進入修正

#### KD與MACD指標
- **KD**: 80以上向下修正中，K<D呈下修狀態
- **MACD**: 柱狀體出現由正轉負的訊號
- **判斷**: 長多格局無疑，但短線處於空方修正形態

#### 波段修正統計（從17,306起漲以來六次修正）
- 第一次修正：最大跌幅1,230點
- 後續五次修正：均在900-1,000點內結束
- **結論**: 最大跌幅1,230點從未超越；900點以上即為買點

#### 大盤操作區間
- **高點壓力**: 28,000點整數關卡
- **低點支撐**: 26,754點（季線位置）
- **最悲觀下跌**: 從27,969跌至26,739（跌幅1,230點），今日收盤距最低793點

## 📈 技術面分析與操作策略

### 大盤操作法則

#### 國安基金護盤期間操作原則
1. **大跌趕買**: 國安基金不能買平盤以上，要與國安基金同步在大跌時買進
2. **明確順勢應對**: 上漲趨勢不變時，到壓力捨得賣，到支撐一定要買
3. **買權值股**: 低點反轉與突破高點壓力都靠權值股
4. **選股條件**: 築底完成、營收成長、產業熱門、題材翻多向上的股票

#### 操作紀律
- 高點壓力要捨得賣，學會避開拉回修正
- 修正到季線附近（26,754）要偏向做多
- 量價背離碰到壓力就調節
- 台積電未轉空、國安基金未退場前，利空大跌仍應勇敢站在買方

### 選股方向
- **集中電子股**: 約55%的股票連12,682點都沒過（集中在金融、傳產）
- **換股策略**: 向下軌道的股票碰到軌道上緣就換到多方股票
- **避開做頭股**: 指數過高但連前面兩三個高點都沒過的股票要趕快賣

## 📋 投資策略總結

### 短期策略（1-2週）
- 台股短線處於回檔修正中，KD高檔向下、MACD轉負
- 連假後關注APEC變數，大跌即為買點
- 權值股回到支撐位（月線/季線）分批進場
- 被動元件可能短暫整理後再走下一波

### 中期策略（1-3月）
- 國安基金規模若擴大至1兆，台股有望挑戰30,000點
- 大型權值股操作區間明確，做區間交易
- 台積電1,390-1,500、鴻海223-260、廣達281.5-322.5
- 跟著國安基金同步操作，不逆勢

### 風險評估
- 短線MACD轉負，回檔風險存在
- 量價背離，28,000點整數關卡壓力大
- 外資連續賣超，需觀察是否持續
- 台積電若跌破1,390元季線需謹慎

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| 國安基金 | 國家安定基金，由政府設立用於穩定股市的護盤資金 |
| 量價背離 | 股價創新高但成交量未同步創新高，顯示上漲動能不足 |
| 墓碑線 | K線型態之一，長上影線幾乎無實體，暗示可能做頭 |
| KD指標 | 隨機指標，K>80為超買、K<20為超賣 |
| MACD | 移動平均收斂發散指標，柱狀體正值為買方市場、負值為賣方市場 |
| 季線 | 60日移動平均線，中期趨勢的重要支撐/壓力參考 |
| 月線 | 20日移動平均線，短中期趨勢參考 |
| 區間操作 | 在明確的支撐與壓力之間做波段交易 |
