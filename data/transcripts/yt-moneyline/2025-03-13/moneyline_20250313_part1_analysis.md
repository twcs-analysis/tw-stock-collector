## 💼 產業分析與投資建議

### 一、台積電（2330）- 除息行情

**現況分析**:
- 股價跌破年線，收盤價跌至1,000元以下
- 下週即將進行除息（配息4.5元）
- 外資持續調節，籌碼偏空

**操作建議**:
- **長線/定期定額投資者**: 無需理會短期波動，持續持有即可
- **短線搶除息者**: 建議等週一再決定是否參加除息
  - 假日期間川普可能發表不利言論，導致週一跳空下跌
  - 賺股息可能賠價差，不划算
- **關鍵觀察**: 外資持續賣超，只要外資不停手，壓力就存在
- **停損點**: 無明確價位，視外資動向而定

### 二、記憶體族群 - 避風港轉多空亂鬥

#### 華邦電（2344）
- 連續兩天成交量排名上市第一
- 今日出現上下影線黑K棒，爆大量
- 一個月漲幅近30%
- **操作建議**: 關注紅K棒二分之一位置是否跌破，未跌破仍屬強勢整理
- **風險提示**: 爆大量黑K棒短線需留意震盪，但不一定是反轉

#### 南亞科（2408）
- 一個月漲幅達35%
- 外資報告中看法較保守，但股價漲幅反而最大
- 代表市場無差別追價
- **操作建議**: 以月線作為參考防守位置，跌破月線短線退場

#### 記憶體模組股 - 群聯（8299）
- 過去五年高殖利率表現穩定
- Netflix記憶體報價Q2有望反彈
- 近一個月漲幅相對較少（已先漲一段）
- 5日線今日有測試但未完全跌破，屬強勢整理
- **殖利率**: 以12元+13元=25元股息計算，約4%

#### 創見（2451）
- 已公布較高股息，殖利率達16.12%
- 底檔整理區約90元，下跌空間有限
- **風險**: 流動性偏低，成交量萎縮時操作需謹慎
- **觀察**: 若連續兩三天成交量低於千張，可能陷入長時間整理

#### DRAM精圓製造 - 南亞科 vs 華邦電
- **產業觀點**: 本波反彈以解套為主
- **南亞科**: 去年虧損1.64元，今年預估虧損縮小但尚未轉盈
  - 技術面強勢時月線可作為停損參考
  - 不建議急著追高
- **華邦電**: 自有CUB（客製化超高頻寬GT）為成長動能
  - 昨日漲停突破前波平台整理區
  - 關注年線套牢賣壓

### 三、潤泰新（9945）/ 潤泰全（9904）- 存股族失望

**事件**: 公布去年獲利百億以上，但派息不到兩成
- **潤泰新**: 今日跳空跌停並爆大量
- **潤泰全**: 同步跳空大跌
- **原因**: 去年Q4在券商帳上虧損，需以法定特別盈餘公積補虧損

**操作建議**:
- 持有者建議忍痛賣出
- 長線盈運狀況仍有問題
- 暫時避開為佳

### 四、簡老師的三種操作策略

#### 策略一：跌深反彈股（撿便宜）
- **適用標的**: 業績已公布但股價跌深的AI類股
  - 鑫準（2049）: 配息3.7元，殖利率不錯
  - 勤誠（8210）: 配息7.5元，殖利率3.28%
  - 聯群（5765）: 去年EPS 3.8元
  - 上詮（3363）: 配息2.4元，殖利率5.57%
- **操作方式**: 等年線附近整理後承接，年線有支撐就有空間

#### 策略二：短線衝一波強勢股
- **長榮航（2618）**: 法人持續買進，籌碼穩定，但前高壓力大，空間有限
  - 賺了就跑，過不了前高就賣
- **陽明（2609）**: 公布股利，殖利率高，今日衝高
  - 盤面較弱時上漲受限
- **廣宇（2328）**: 連拉兩根上漲，量能放大
  - 紅K棒不破則強勢整理
  - 乖離率偏大，短線操作為主

#### 策略三：中長線佈局股
- **金融股**: 基期低、業績不差、投信有在買
  - 國泰金控 - 股價較低
  - 兆豐金 - 長期穩定
- **原物料股**: 景氣循環低檔，未來需求增加
  - 台泥 - 龍頭股，長期右下角慢慢上攻
  - 中鋼 - 工序好轉，供給減少需求增加
  - **操作**: 分批慢慢買，不急著追高，定期定額模式

#### 整體持股比重建議
- **現金比重偏高**: 三成到四成持股即可
- 系統性風險不確定性大，關稅戰持續影響
- 美股不穩定，台股難有獨立強勢行情

### 五、二月營收分析 - PCB族群異軍突起

#### 營收創歷史新高統計
- 二月份年增公司共660家（因農曆新年影響，參考性低）
- **歷史新高**: 僅34家
- **最大亮點**: PCB族群佔4家（比例最高）
  - 半導體設備股3家
  - 軟體股3家

#### PCB四雄（皆為多層PCB）
1. **台光電（2383）**: 營收年增排名第一，做銅箔基板
2. **博智（8155）**: 存貨周轉率最快（1.53），毛利率15.82%
3. **高技（5439）**: 高層數佔比最高，盤中創高，但本益比近50倍
4. **金像電（2368）**: 量化評分最高（28.26），存貨在調整中

#### PCB產業前景
- 整體PCB市場年複合成長率僅4.8%
- **M8以上等級高層PCB**: 2024-2027年複合成長率達130%
- 兩大成長領域:
  1. **AI伺服器**: CCL潛在市場約121-151億美元，全球僅4家供應商（台光電、台燿、韓國斗山、日本Panasonic）
  2. **800G/1.6T交換器**: PCB部分2025年約4億，2027年可達12億（3倍增長）

#### 子東的量化選股法
- 將三個指標相乘做比較：**高層數佔比 x 存貨周轉率 x 毛利率**
  - 高技: 12.23
  - 台光電: 12.46
  - **金像電: 28.26**（最高）
  - **博智: 19.36**（第二）
- **結論**: 金像電與博智在量化指標上優於已大漲的高技與台光電，後發先至的比價空間較大

## 📋 投資策略總結

### 短線策略
1. **現金為王**: 持股比重三至四成，保持靈活
2. **搶短就跑**: 強勢股有賺就走，不貪心
3. **記憶體族群**: 分化開始，精圓製造以解套為主，模組股殖利率保護可趁回檔佈局
4. **除息行情**: 台積電建議等週一再決定

### 中長線策略
1. **金融股**: 定期定額佈局（國泰金、兆豐金）
2. **原物料股**: 景氣循環底部，分批慢買（台泥、中鋼）
3. **PCB族群**: 金像電、博智為量化選股優選，可等回檔佈局

### 風險管理
- 4月2日對等關稅政策是重要觀察點
- 外資連續賣超13天，資金持續外流
- 系統性風險尚未解除，不宜重壓

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **費半指數** | 費城半導體指數，追蹤美國上市半導體公司的股價指數，與台股科技股連動性高 |
| **年線** | 240日移動平均線，代表過去一年投資人的平均成本 |
| **除息** | 公司配發現金股利後，股價會扣除相對應的金額 |
| **多層PCB** | 8層以上的高密度印刷電路板，用於AI伺服器、高速交換器等高階應用 |
| **HDI板** | High Density Interconnect，高密度互連板，層數更多、線路更密集 |
| **銅箔基板（CCL）** | 製造PCB的核心材料，台光電、台燿為主要供應商 |
| **存貨周轉率** | 衡量庫存出貨效率的指標，數值越高代表出貨越順暢 |
| **殖利率** | 現金股利除以股價的比率，越高代表以目前價格投資可獲得越高的股息報酬 |
| **NAND Flash** | 快閃記憶體，用於SSD固態硬碟等儲存裝置 |
| **DRAM** | 動態隨機存取記憶體，用於電腦主記憶體等 |
