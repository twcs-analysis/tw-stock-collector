## 🌍 市場總體觀察

### 法人動態分析

#### 外資動向
- **現貨**: 連續13天賣超，累計提款4,100多億元
- **期貨空單**: 仍居高不下
- **特殊買超**: 今日積極買進鋼鐵股（大成鋼、中鋼、中鴻）

#### 投信動向
- **連續買超**: 9天買超，3月份以來天天站在買方
- **累計買超**: 437.5億元
- **三大買盤來源**:
  1. 護盤任務
  2. ETF被動式買盤（成分股調整）
  3. 主動式買盤（季末作帳行情）
- **重要訊號**: 台股3月修正4.73%（加權）、櫃買修正4.09%，但投信天天買超
  - 多數個股已低於投信成本 → 投信有動機拉抬做績效

### 投信作帳行情分析

#### 三大篩選條件
1. **3月份正在買方**: 買進賣出比例大於10（純粹看好而非多空分歧）
2. **與投信成本差距不大**: 最多不超過一根漲停板範圍
3. **主動式買盤為主**: 扣除ETF成分股的被動買盤，且預估今年獲利成長

#### 被動式 vs 主動式買盤

**被動式買盤特徵**:
- 來自ETF成分股調整（如0056每年6月和12月換股）
- 新增持股需在指數過渡期（約5天）內買到權重
- 被踢出的成分股會被連續賣出
- **案例**: 2024年12月23日0056調整
  - 長榮航（2618）: 連續5天買超，但外資同步賣出，股價不漲
  - 長榮（2603）: 同期間被動買進
  - 新復發（2454）: 同期間被動買進

**重要發現**: 3月份只有一個重要ETF有調整，其他ETF（如0056）3月不換股
→ 3月份投信買超較可能是主動式買盤（實質看好）

### 全球央行動態

#### 超級央行週（下週）
- **日本央行**: 升息可能性超過一半
- **美國聯準會**: 幾乎一面倒認為不會動（維持利率不變）
- **英國央行**: 去年8月以來已降息三次
- **瑞士央行**: 持續降息
- **關鍵**: 這些國家的貨幣政策會影響美元指數（六種貨幣組成）

#### 降息預期劇烈變化
- **一個月前（2月20日）**: 市場預期7月才降息一次
- **現在（3月13日）**: 預期提前至6月降息，全年可能降三次
  - 第一次: 6月
  - 第二次: 9月
  - 第三次: 12月
- **變化原因**:
  - CPI數據低於預期（不管總合或核心CPI都下降）
  - 個人消費指數（PCE）已開始下降
  - 通膨疑慮減緩

## 💼 產業分析與投資建議

### 一、投信作帳概念股

#### 台灣虎（5765）
- **投信成本**: 88.9元
- **今日收盤**: 88.8元（低於投信成本）
- **買進賣出比**: 無限大（只買不賣，53.8張買進、0張賣出）
- **預估今年EPS**: 7.8元
- **分析**: 有可能是主動式買盤，壓未來可能成為高股息ETF成分股
- **操作**: 股價走區間，在相對低檔找買點

#### 博爾威（3024）
- **投信成本**: 167元
- **今日收盤**: 165元（低於投信成本）
- **特性**: CPU概念股，與華星光（4979）等走勢類似
- **優勢**: 投信未出現套牢賣壓，反彈時賣壓最少
- **操作**: CPU股價若跌深反彈，博爾威最容易往上突破

#### 台特化（4766）
- **投信動態**: 幾乎天天買，張數不多但持續
- **技術面**: 離頸線有一點距離，以頸線為防守點
- **操作**: 未跌破頸線可持有

#### 世紀鋼（9958）
- **特性**: 近期強勢股，投信成本與現價差距不大
- **分析**: 投信尚未賺很多，有做績效的動機
- **操作**: 跟隨投信佈局，投信開始賣超時跟著調節

### 二、債券市場深度分析

#### 股債輪動現象
- 美股下跌 + 殖利率下降 = 資金從股市轉向債市避險
- 這是近期少見的股債同方向輪動

#### 殖利率曲線倒掛再現
- **一年前**: 短期利率5.39%，十年期4.15% → 典型倒掛（存短不存長）
- **一個月前**: 曲線趨於正常
- **現在**: 三個月期約4.3%，十年期約4.3% → 再度接近倒掛
- **含義**: 短線買短債有優勢，但降息預期增加後長債也有機會

#### 債券投資策略
- **短線操作（1-2個月）**: 買短債（殖利率曲線倒掛修正時獲利）
- **中長線佈局**: 買長債也OK
  - 升息不可能 → 最差不降息
  - 若降息 → 可賺價差
  - 利於不敗之地
- **絕對避開**: 非投資等級債（高收益債）
  - 與美股正相關（相關性0.8以上）
  - 美股下跌時非投等債同步下跌
  - 應當做「波動較小的股票」而非債券

#### 巴菲特的啟示
- 波克夏的3,000多億現金部位中，三分之二為短債（3個月至6個月）
- 驗證了殖利率曲線倒掛時買短債的策略

#### 近期報酬率比較
- **一年報酬**: 新興市場債表現最佳（因美元走弱）
- **一個月報酬**: 長債勝出（降息預期增加）
- **一週報酬**: 短債勝出（殖利率曲線再度倒掛的即時反應）

### 三、匯率市場分析

#### 美元指數走弱
- **3月跌幅**: 約3%
- **今年累計跌幅**: 約4%
- **關鍵位置**: 103點（美國大選日11月5日的水準），已接近跌破
- **若跌破103**: 下一個支撐在100整數關卡

#### 非美貨幣全面升值
- **歐元**: 3月大漲5%，去年以來降息6次但仍升值
- **英鎊**: 顯著升值
- **日圓**: 升值（日本央行升息預期）
- **唯獨台幣貶值**: 與美元指數脫鉤

#### 台幣特殊弱勢
- **異常現象**: 美元走弱但台幣未同步升值
- **原因**: 外資連續13天賣超，提款匯出導致台幣承壓
- **正常情況**: 過去一年台幣與美元指數同漲同跌
- **當前**: 美元下跌但台幣也在貶值，完全脫鉤

#### 歐元強勢原因
- **和平題材**: 俄烏戰爭可能結束
  - 歐洲通膨因天然氣價格飆升而居高
  - 停戰後通膨可望下降
  - 以色列問題也可能緩解
- **歐股表現**: 德國、英國股市持續創新高
- **資金流向**: 美股資金外流至歐股

#### 日圓強勢原因
- 日本央行為唯一升息的主要國家
- 通膨仍高（整體4%、核心2.5%）
- 經濟成長改善（去年0.18% → 今年預估1.18%）
- 下週升息可能性高

### 四、美國經濟衰退機率

#### 各機構預測
- **高盛**: 25%衰退機率
- **PIMCO**: 最高35%
- **屋底**: 35%
- **前財長**: 約50%
- **耶魯大學商學院院長**: 高機率

#### 朱老師觀點
- 實際衰退可能性不大
- 但經濟成長率會顯著下降
  - 去年GDP: 2.8%
  - 今年預估: 2.1%
  - 若關稅全面實施: 可能降至1.0%-1.5%
- 川普自己前後矛盾（前天說可能衰退，隔天說不可能）
- 華碩董事長與執行長態度：有AB方案應對，不需提前恐慌

## 📋 投資策略總結

### 投信作帳跟單策略
1. **篩選重點**: 買進賣出比大於10、成本差距在一根漲停板內、排除被動式買盤
2. **推薦標的**: 台灣虎、博爾威、台特化、世紀鋼
3. **操作**: 跟投信買，投信賣時跟著出
4. **時間窗口**: 距離季底約三週，投信有做績效壓力

### 債券投資策略
1. **短線（1-2個月）**: 買短債ETF
2. **中長線**: 買長債ETF也OK（降息預期增加）
3. **絕對避開**: 非投資等級債（與股市正相關，避險效果為零）
4. **立於不敗之地**: 升息不可能，最差不動，降息則額外獲利

### 匯率觀察
1. **美元偏弱**: 關注103關卡是否跌破
2. **台幣異常弱**: 外資賣超匯出為主因
3. **歐元、日圓強勢**: 和平題材與升息預期
4. **投資啟示**: 不能用台幣匯率判斷美元強弱（台幣非國際貨幣）

### 明日盤勢觀察重點
1. **Intel新CEO就任**: 盤後大漲10%，是否帶動半導體族群
2. **鴻海法說會**: 明日公布全年財報並召開法說，AI展望為關鍵

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **投信作帳** | 投信基金在季末前拉抬持股的行為，以美化基金績效報告 |
| **買進賣出比** | 投信買進張數與賣出張數的比例，越高代表看法越一致 |
| **被動式買盤** | 因ETF成分股調整而產生的機械式買賣，非基於看好 |
| **主動式買盤** | 基金經理人經過研究後，主動選擇看好的標的進場 |
| **指數過渡期** | ETF成分股調整生效後的5個交易日，用於將持股調整到位 |
| **殖利率曲線** | 以不同到期日的債券殖利率畫出的曲線 |
| **殖利率曲線倒掛** | 短期債券殖利率高於長期債券殖利率的異常現象，通常預示經濟放緩 |
| **FedWatch** | CME推出的工具，追蹤市場對聯準會利率決策的預期機率 |
| **非投資等級債** | 信用評等較低的債券（前稱高收益債），違約風險較高但殖利率也較高 |
| **PCE** | Personal Consumption Expenditures，個人消費支出價格指數，聯準會最關注的通膨指標 |
| **CPI** | Consumer Price Index，消費者物價指數，衡量一般消費者所購買商品和服務的價格變動 |
