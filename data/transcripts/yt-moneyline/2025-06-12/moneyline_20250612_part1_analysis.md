#### 中東局勢
- **CNN報導**: 美國開始撤離中東部分外交與軍事人員
- **國防部**: 批准美國軍人家屬自願離開中東
- **國務院**: 準備撤離駐伊拉克、巴林、科威特大使館非必要人員
- **CBS報導**: 伊朗可能對美國在伊拉克軍事基地進行報復
- **油價**: 昨日大漲5%，今日開高走低
- **黃金**: 微動但未呈現恐慌性大漲
- **專家研判**: 茶杯裡的風暴，伊朗急迫解除禁運碼，不會在此時結怨
- **伊朗軍力**: 全球排名第16，61萬部隊，每日石油產量330萬桶

### 權值股與類股輪動

#### 台積電 (2330)

- **影響**: 拖累大盤約120點
- **除息記錄**: 過去18次幾乎都秒填息，本次破例未填息

- **觀點**: 台積電千元以上波動很大，業績好、擴廠趨勢不會改變，但短線整理

#### OTC櫃買指數

- **與年線距離**: 負乖離率仍大，有補漲空間

### 四、美股CFD交易介紹

長新介紹在台灣買美股的三大管道比較：

| 項目 | 複委託 | 海外券商 | 美股CFD |
|------|--------|----------|---------|
| 資金安全 | 高（國內券商） | 低（資金匯出國外） | 高（國內期貨商） |
| 交易速度 | T+2 | 即時 | 即時（當日出入金） |
| 做空功能 | 不可 | 可 | 可 |
| 槓桿 | 無 | 無 | 1~10倍可選 |
| 盤前盤後 | 不可 | 可 | 可 |
| 交易成本 | 較高 | 較低 | 較低 |
| 監管機關 | 金管會 | 海外 | 金管會 |
| 可交易標的 | 美股個股 | 美股個股/ETF | 1,607檔美股+22檔ETF |

**美股CFD適合對象**:
1. 短線交易者（手續費低、可當沖）
2. 需要避險操作者（可做多做空雙向）
3. 盤前盤後交易者（財報公布後搶先卡位）
4. 小資族（保證金交易，少量資金即可參與）

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **貼息** | 除息後股價下跌，未能填回除息缺口 |
| **填息** | 除息後股價上漲回補至除息前水準 |
| **秒填息** | 除息當日即完成填息 |
| **CFD** | Contract for Difference，差價合約，一種金融衍生商品 |
| **複委託** | 透過國內券商委託買賣海外股票 |
| **景線** | 長紅K棒的低點位置，作為短線支撐 |
| **正乖離率** | 股價偏離均線的程度，過大表示超漲 |
| **OTC櫃買指數** | 衡量上櫃股票表現的指數，以中小型股為主 |
| **茶杯裡的風暴** | 比喻影響範圍有限、不會擴大的事件 |
