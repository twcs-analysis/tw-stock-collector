## 💼 產業分析與投資建議

### 一、蘋果 (AAPL) - 交兵代表，AI嚴重落後

#### WWDC 2025 大會觀察
- 本次WWDC全為軟體與作業系統更新
- **健康功能**: Apple Watch健身體驗、心率偵測、距離活動偵測等更完善
- **新概念**: 推出一款透明玻璃螢幕裝置（議題性質，非主力產品）
- **Siri升級**: 英文、中文及多國語言均已更新，但AI功能依然不足

#### AI落後的兩大根本原因

**1. 隱私問題**
- 蘋果堅持裝置端運算（on-device），限制了生成式AI與推理能力
- AI需要上雲端運算，但蘋果的隱私政策與雲端運算產生根本矛盾
- 結果：Siri無法有效升級，Apple Intelligence 遲遲無法商業化

**2. 資本支出嚴重不足**
| 公司 | 年度資本支出（約） |
|------|------------------|
| 亞馬遜 | 超過1,000億美元 |
| 微軟 | 860億~960億美元 |
| Google | 500億~700億美元 |
| **蘋果** | **僅100億美元（過去10年如一）** |

- **後果**: AI技術嚴重落後，Apple Intelligence無法推出有效功能
- **過去策略**: 靠庫藏股回購推升股價，但市場現在看的是營收成長爆發力與競爭力

#### 蘋果vs其他科技巨頭
- Google：雖然AI發展較Meta慢，但開發者大會後股價創高，因為進步空間大，搜尋引擎也加入AI功能
- Meta：AI獲利明顯進來
- 亞馬遜：AI獲利明顯進來
- **蘋果**: 股價因AI落後而一陣乏力

#### 蘋果未來唯一賣點 - 可折疊手機
- **時程**: 預計2026年推出
- **首年預估銷量**: 1,250萬至1,500萬台
- **技術門檻**: 可折疊手機需20萬次彎折測試（電腦僅3~5萬次），技術非常高
- **競爭對手**: 三星、華為已領先
- **結論**: 蘋果股價的賣點在可折疊手機，而非AI

### 二、記憶體DDR4/DDR5轉換潮 - 埃兵初期致勝

#### 美光帶頭，DDR5轉換加速
- **美光股價**: 近期極為強勢，屬於AI兵種中的「初期致勝」代表
- **DDR5滲透率**: 新平台推出後已達50%，速度比過往快很多
- **DDR4缺貨**: 設備全數轉移至DDR5生產線，DDR4供給急降
  - DDR4報價一個月漲50%，上一季漲40%
- **DDR5單價**: 約為DDR4的1.5至2倍

#### 新平台三大技術亮點

**1. 速度大躍進**
- DDR4：4,800 MHz
- DDR5：8,800 MHz（接近HBM等級）
- 傳統伺服器記憶體速度已追上HBM的水準

**2. CPU Pin數大增60%**
- 新平台CPU的Pin數（接腳數）較上一代增加60%以上
- Pin數增加 = 更多記憶體通道 = 傳輸速度更快
- 直接帶動連接器（嘉澤、紅海）的單價與需求

**3. 平台升級週期**
- 過去平台Pin數每代僅增加5%~10%
- 本次60%的增幅為歷史罕見，驅動整個生態系升級

#### 個股分析

**南亞科 (2408)** - DRAM製造
- **表現**: 因美光帶動有所表現
- **營收**: 已創2010年以來新高
- **風險**: 獲利率尚未明朗，庫存獲利難以估算
- **操作**: 觀察DDR價格持續上漲的趨勢

**威剛 (3260)** - 記憶體模組
- **定位**: 相對落後補漲，股價尚未大幅上漲
- **庫存優勢**: 持有大量低價DDR庫存，若報價持續上漲，庫存轉換利潤可觀
- **估值**: 目前約7元EPS水準
- **爆發邏輯**: DDR4漲50%、DDR5單價為DDR4的1.5~2倍，庫存利潤的爆發力驚人

**嘉澤 (3533)** - CPU連接器/Pin腳
- **外資看法**: 明年獲利上調至110%成長率
- **原因**: 新平台Pin數增加60%，連接器單價大幅提高
- **估值變化**: 原本90元EPS → 上調至110元
- **操作建議**: 股價相對未漲，屬落後補漲型，爆發性可能比已漲多的個股更高

**紅海 (6230)** - 連接器
- **定位**: 與嘉澤同為CPU Pin腳受惠股

**信驊 (5274)** - AI伺服器BMC晶片
- **特色**: 有AI概念，一漲就漲得很快但跌也快
- **對比嘉澤**: 信驊已漲多，嘉澤相對落後，後者獲利上調後爆發性更高

### 三、遊戲產業 - 新象 (3093)

#### 商業模式轉型
- **過去**: 線上遊戲為主（明星三缺一等），利潤低、競爭激烈
- **現在**: 轉向商用遊戲機台
  - 代表產品：浩劫山、狂野飆車、英雄、威亞極速等大型機台
  - VR體驗 + 實體遊戲機台 = 獲利空間大幅提升

#### 基本面
- **營收**: 年增28%，上半年表現亮眼，持續創新高
- **獲利**: 商用機台利潤率遠高於純線上遊戲
- **殖利率**: 穩定度高（約12~13%）
- **股價**: 約93元水準

#### 操作建議
- 非市場主流，但風險低
- 適合長期持有
- 博弈市場穩定度高

- 美元部位受台幣升值影響，匯損壓力大

## 📚 名詞解釋

| 名詞 | 解釋 |
|------|------|
| **DDR4/DDR5** | Double Data Rate第四代/第五代同步動態隨機存取記憶體，DDR5速度約為DDR4的2倍以上 |
| **HBM** | High Bandwidth Memory，高頻寬記憶體，用於AI加速器的高效能堆疊記憶體 |
| **Pin數** | CPU與主機板連接的接腳數量，Pin數越多傳輸通道越多、速度越快 |
| **DLSS** | Deep Learning Super Sampling，NVIDIA的深度學習超取樣技術，以較低解析度畫面透過AI升級為高解析度 |
| **光線追蹤** | Ray Tracing，模擬真實光線反射的渲染技術，使遊戲畫面更接近真實世界 |
| **LPDDR5X** | 低功耗DDR5加強版記憶體，用於行動裝置與遊戲主機 |
| **被動式ETF** | 追蹤指數成分股的ETF，成分股調整時必須強制買進或賣出 |
| **主動式ETF** | 由基金經理人主動選股的ETF，不受指數成分股限制，可靈活調整持股 |
| **借券賣出** | 向券商借入股票後賣出，期望股價下跌後買回歸還，賺取價差（做空操作） |
| **庫藏股** | 公司買回自家股票，減少流通在外股數以推升每股獲利與股價 |
| **可折疊手機** | 螢幕可彎折的智慧手機，目前以三星、華為領先，蘋果預計2026年加入 |
| **換手成功** | 股票從舊持有者轉到新買家手中，籌碼洗清後有利後續上漲 |
| **交兵/埃兵** | 軍事比喻用於股市：交兵指正在交戰（已漲多休息中）的主流股，埃兵指尚在佈署（低檔未啟動）的潛力股 |
| **吃豆腐** | 股市術語，指利用對手的操作來獲利，例如外資趁投信被動買進時反向賣出獲利 |
