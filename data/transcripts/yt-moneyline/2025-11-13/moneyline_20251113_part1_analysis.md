## 市場觀察

### 大盤概況
- 台股盤中試圖挑戰28,000點關卡，但尾盤因台積電壓回
- 時間已進入11月中旬，第四季已過一半，年底作帳行情全面啟動
- 集團股開始「大批開」，輪動明顯加速

### 集團作帳行情分析
節目指出三大集團成為第四季作帳主力：

1. **華新集團** — 最早啟動，第四季初即開始表現
2. **台塑集團** — 近日因南亞科帶動整個家族股飆漲
3. **國巨集團** — 被動元件龍頭，搭配台積電漲停帶動族群

### 記憶體報價觀察
- 集邦科技（TrendForce）約11點公布DDR4現貨報價
- DDR4 8GB仍呈現上漲，但漲幅明顯收斂，為近期最小漲幅
- 報價漲幅趨緩造成記憶體股盤中快速回檔
- 分析師認為屬於「震盪整理」而非產業反轉

### GDP與經濟展望
- 主計處透露今年GDP有機會上修至6%，為近幾年最佳
- 各季表現：Q1 5.45%、Q2 8.01%、Q3 5.8%
- 中經院預估明年GDP約2.55%，面臨高基期壓力
- 韓國國會議員質詢為何台灣成長率達韓國的五倍

## 技術面分析

### 選股條件（明日抱股過週末參考）
1. **股價站穩五日均線之上** — 強勢股的基本門檻
2. **短中期均線多頭排列** — 10日線、20日線、季線呈多頭
3. **KD指標大於50** — 確認在強勢區域
4. **近一週平均成交量 > 1,000張** — 確保流動性

### 記憶體股操作策略
- 強勢族群若未跌破五日線，可續抱
- 成本較高（近期才進場）者，建議明日（週五）適度調節
- 成本較低者，可給一到兩天觀察空間
- 隔日（週五）10:50~11:00注意TrendForce報價更新

### 軋空股觀察條件
1. 融券成本低於現股價格（空單被套）
2. 券資比偏高且融券張數具一定規模
3. 近期有強制回補需求更佳
- **潛在軋空標的**：欣興（PCB，券資比17%、張數夠大）
- **萬海**：多空尚未分出勝負，若航運股出現中長紅則軋空啟動
- **漢唐**：空單有賺錢，不算軋空

## 策略總結

1. **年底作帳行情是主軸**：聚焦華新、台塑、國巨三大集團，挑有主力、法人買進、多頭架構的個股跟隨
2. **記憶體震盪整理期**：報價漲幅收斂但未反轉，五日線為多空關鍵，勿過早出場也勿高檔追價
3. **抱股過週末選強不選弱**：符合四大技術條件（站五日線、均線多頭、KD>50、量>1000張）的個股可安心持有
4. **輪動加速期注意換股**：從記憶體擴散到機一體模組、通路、PCB、被動元件，跟著資金走
5. **注意明年經濟下行風險**：今年GDP基期極高，明年面臨中經院列出的九大風險

## 名詞解釋

| 名詞 | 說明 |
|------|------|
| 集團作帳 | 年底前大股東或集團主力拉抬旗下股票股價，美化年度績效的操作行為 |
| DDR4現貨報價 | 由TrendForce等研調機構公布的DDR4記憶體晶片現貨交易價格，影響記憶體股短期走勢 |
| 五日均線（5MA） | 過去五個交易日收盤價的平均值，短線多空判斷依據 |
| 軋空 | 當大量放空者被迫回補空單時，推升股價急漲的現象 |
| 券資比 | 融券餘額除以融資餘額的比率，數值越高代表放空比例越大，軋空潛力越高 |
| 強制回補 | 因股東會、除權息等事由，融券須於特定日前買回股票還券 |
| GDP上修 | 政府統計機構根據最新數據，將經濟成長率預測值往上調整 |
| 九大風險 | 中經院列舉的明年經濟潛在風險，包含地緣政治、AI泡沫、通膨、房市等 |
| 多頭排列 | 短期均線在上、中長期均線在下的排列方式，代表上漲趨勢 |
| 位階 | 股價相對於歷史高低點的位置，低位階代表相對便宜，上漲空間較大 |
