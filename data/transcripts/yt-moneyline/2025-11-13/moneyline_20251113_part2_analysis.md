## 技術面分析

### 投信強勢股技術特徵
- 投信買超的個股多為「近期才啟動」且「位階不高」者
- PCB族群呈現族群性買進，非單一個股
- 投信若開始調節，需留意是否有其他法人（外資、自營商）接手

### 個股技術觀察
- **光聖（6442）**：盤整多年後今日漲停，逼近千元大關，類似台光電當初拉上千元帶動整個PCB人氣
- **新興（3363）**：今日創高，黏著上升趨勢明確，外資目標價遠高於現價
- **公準（3178）**：昨日漲停今日盤中回檔留上影線，等缺口回補再進場

## 策略總結

1. **籌碼跟著法人走**：外資買傳產集團股避險、投信買PCB與強勢成長股，跟對法人方向
2. **Q3財報選股三條件**：轉機（虧轉盈）、成長（EPS+營收雙成長）、成交量足夠
3. **PCB族群是本波主軸之一**：從景碩電、新興擴散到欣興、健鼎、副橋，族群效應明確
4. **記憶體轉向通路補漲**：主流記憶體股需休息，通路股（平安8080）可能接棒
5. **輪動節奏加速**：每天不同族群輪漲（被動元件→建設→封測→PCB），靈活應對
6. **投信11月買到12月**：投信買進且位階不高的標的，可望持續至12月中

## 名詞解釋

| 名詞 | 說明 |
|------|------|
| 投信作帳 | 投信法人在季末或年底前買進持股拉抬淨值，美化基金績效 |
| 0050 | 元大台灣50 ETF，追蹤台灣市值前50大股票，外資常用作指數避險工具 |
| 虧轉盈 | 公司從虧損狀態轉為獲利，常成為股價轉機催化劑 |
| 季增率 | 本季與上一季相比的成長幅度，反映短期營運動能 |
| 年增率（YoY） | 與去年同期相比的成長幅度，排除季節性因素 |
| PCB（印刷電路板） | Printed Circuit Board，電子產品中連接各零組件的基板，AI伺服器需求帶動成長 |
| AIS伺服器 | AI Server，專為人工智慧運算設計的伺服器，為目前科技產業最大成長動能 |
| 本益比（P/E） | 股價除以每股盈餘，衡量股價相對獲利的估值指標 |
| 族群性買進 | 法人同時買進同一產業多檔個股，顯示看好整個產業趨勢而非單一公司 |
| 缺口回補 | 股價跳空上漲後回檔填補缺口，技術分析中常被視為進場時機 |
