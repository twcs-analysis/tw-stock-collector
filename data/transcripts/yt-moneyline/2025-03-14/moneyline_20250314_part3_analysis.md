## 🌍 市場總體觀察

### 台灣二月出口大爆發

#### 出口數據
- **月增**: +6.7%（較上月）
- **年增**: +31.5%（較去年同期）
- **評價**: 有機會寫下歷史以來最美好的第一季

#### 出口結構變化
- **對美出口占比**: 28.5%（20年來首度超越中國）
- **對中出口占比**: 28.4%（仍創歷史新高）
- **黃金交叉**: 美國出口占比首度超越中國，台灣出口越來越集中到美國

#### 帶動出口的兩大引擎
1. **資通訊產品**: 約七成出口到美國
2. **電子零組件**: 約六成出口到中國

#### 出口爆發的真正原因
- **關稅恐慌拉貨**: 各國廠商擔心4/2對等關稅實施，提前大量拉貨
- **中國拉貨帶動**: 中國出口商也搶在關稅前拉貨，間接拉動台灣電子零組件出口
- **傳統產業翻正**: 化學品、基本金屬等傳統產業從負成長全部轉為正成長
- **預警**: 這些漂亮數字背後是恐慌性拉貨，非真正需求成長

### 美國經濟政策不確定性指數

- **趨勢**: 從川普當選以來持續飆升
- **數值**: 1月 228 → 2月 401 → 3月 525
- **含義**: 全球對美國經濟政策的不確定性達到極高水準

### 關稅對通膨與經濟的預測

- **通膨**: S&P預測從3.31%上修（關稅推升物價）
- **經濟成長**: S&P預測下修（關稅抑制經濟）
- **結論**: 關稅確實會對全球經濟帶來負面衝擊

### 台灣經濟與全球連動性

- **2000年前**: 台灣與全球經濟相關係數僅0.29（台灣經濟獨立性強）
- **2000年後**: 加入WTO後相關係數高達0.8（高度連動）
- **含義**: 全球經濟下行，台灣無法獨善其身

## 💼 產業分析與投資建議

### 對等關稅對台灣的衝擊

#### 央行總裁的評估 vs 實際風險

##### 央行觀點（楊金龍）
- 使用經濟部國貿署數據，僅計算「積體電路」出口
- 積體電路出口占對美出口僅6.02%
- 結論：衝擊不大（曝險指數僅0.9）

##### 實際風險
- 台灣對美出口中，與晶片相關（含電腦、伺服器、汽車零件等）約占46%
- 兩種計算方式的落差極大
- **關鍵**: 川普若將「含晶片商品」也納入關稅範圍，衝擊將遠大於央行評估

#### 台灣對美順差持續擴大
- **2018年（第一任）**: 對美順差僅152億美元
- **2024年**: 對美順差高達739億美元（增加587億美元）
- **全球排名**: 增幅名列前茅
- **風險**: 川普若以順差為由課對等關稅，台灣很難避免

### 台灣2025年經濟成長展望

#### 基本情境（無關稅衝擊）
- **主計總處預估**: 3.14%
- **內需vs外需**: 去年靠內需（4.59%），今年靠外需（國外淨需求從負轉正至1.2）
- **保三無虞**: 若無關稅，保三沒問題

#### 風險情境（關稅實施）
- **出口受創**: 關稅一課，出口數據必然下修
- **連鎖反應**: 出口下修 → 經濟成長下修 → 保三恐有困難
- **明朗時間**: 至少要等到4月之後才能看清

## 📈 技術面分析 - 鄭華老師的相對論選股

### 核心概念：相對論

#### 三大原則
1. **別人反彈，我創高** → 強勢股，優先選擇
2. **別人下跌，我不跌** → 抗跌股，可以考慮
3. **別人拉回，我破底** → 弱勢股，必須迴避

### 大盤與OTC相對強弱

- **大盤**: 22,000-24,000點區間壓縮整理，中心點約22,000附近
- **OTC（櫃買指數）**: 相對強勢，今年做小型股效果比大型股好
- **結論**: 今年是個股行情，選對股票才有績效

### 族群輪動節奏（2025年初至今）

1. **1月上旬**: 機器人題材、新漢肥姐概念
2. **2月下旬**: 閃裝行運、鋼鐵重建題材
3. **3月上旬**: BBU創新高、散熱/水冷快接頭反彈
4. **持續強勢**: 機器人議題涵蓋最大漲幅

### 個股分析

#### 高力 (8996) - 相對論典範：別人反彈我創高
- **表現**: OTC指數僅反彈時，高力直接創新高
- **題材**: 事務機交換器板子，營收亮眼
- **判斷**: 標準的創新高模式，具備波段格局

#### 華邦電 (2344) - 記憶體
- **表現**: 昨天爆大量後今天量縮守住
- **判斷**: 下週一二若續創新高，可觀察是否有中長行情

#### 順達 (3211) - BBU
- **表現**: 雙底形態成形
- **題材**: 水冷快接頭概念

#### 通路股 - 關稅拉貨受惠族群

##### 貿聯-KY (3665)
- **營收**: 二月年增約103%
- **表現**: 公布營收後一週漲幅約40%
- **判斷**: 關稅拉貨帶動，先行者優勢

##### 安馳 (3528)
- **營收**: 二月年增約70%以上
- **題材**: IC通路商，另有網通外接器產品
- **表現**: 已有四根漲停

##### 紅衣鼓（鴻翊 7173）- 最具潛力通路股
- **營收**: 二月年增約70%以上
- **題材**: 標準通路商 + 算力中心轉投資（雙題材）
- **現狀**: 同族群中漲幅最小（僅約8%）
- **原因**: 去年市場將其歸類為算力中心概念股，忽略了本業是通路商
- **判斷**: 被低估的減到槍概念，營收出來 + 本業題材 + 算力中心雙引擎
- **操作建議**: 同族群中漲幅最小但營收一樣好，具補漲空間

#### 通路股投資邏輯
- **核心邏輯**: 廠商為避關稅寧可超額庫存，也不要被打到措手不及
- **通路商優勢**: 先拿貨再說，至於超額庫存是下半年的問題
- **選股標準**: 二月營收年增顯著的通路股都可留意

### 弱勢股警示：別人拉回我破底

#### 大立光 (3008)
- **現象**: 漲了四個月後做交代，長多拉回
- **風險**: 機器人鏡頭目前仍是概念居多
- **操作**: 可持有但絕不能追，跌破近期支撐全部出場

#### 微星 (2377)
- **現象**: 別人沒破底但微星破底，有補跌味道
- **原因**: 上漲時有機器人概念加持，這次回檔較深
- **判斷**: 別人拉回我破底，相對弱勢

#### 省頓（聲頓）
- **現象**: 上個月底就已先行跌破過年前低點
- **判斷**: 今天創新低是結果不是原因，該賣的時機早已過去
- **風險**: 可能形成長空格局

#### 鴻準 (2354)
- **現象**: 水冷族群中其他都沒破底，唯獨鴻準失守
- **走勢**: 比鸿海還弱勢
- **判斷**: 集團內資金已轉向廣宇，鴻準先不考慮
- **原則**: 同族群中有其他水冷與機殼股可買，不需選破底的

### 短線策略（下週操作重點）

2. **OTC更關鍵**: 204點位置失守就更強，能否收腳做雙底

4. **通路股**: 二月營收年增顯著者，持續追蹤

### 選股原則
1. **優先**: 別人反彈我創高的股票（如高力）
2. **次選**: 別人下跌我不跌的股票（如通路股）
3. **迴避**: 別人拉回我破底的股票（如微星、鴻準、省頓）

- **4/2關稅**: 對台灣衝擊可能遠大於央行評估
- **經濟保三**: 若關稅實施，保三恐有困難
- **個股**: 用相對論篩選，弱勢股果斷出場

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **對等關稅** | 川普預計4/2實施，依各國對美國的順差程度來決定課稅比例 |
| **海關編碼（HS Code）** | 國際統一商品分類標準，用於計算各類商品出口佔比 |
| **曝險指數** | 衡量一國受關稅衝擊的程度，關稅率 x 出口對美佔比 |
| **相對論選股** | 以個股與大盤或同族群的相對強弱來判斷買賣時機 |
| **黃金交叉** | 短期均線由下往上穿越長期均線，為買進訊號 |
| **美國經濟政策不確定性指數** | 衡量全球對美國經濟政策前景不明朗程度的指標 |
| **資通訊產品** | 包括手機、筆電、伺服器等資訊通訊類商品 |
| **WTO（世界貿易組織）** | 台灣2002年加入後，與全球經濟高度連動 |
| **算力中心** | AI運算基礎設施，結合伺服器、網通、散熱等硬體 |
| **減到槍** | 同族群中漲幅最小但基本面相似的股票，具備補漲潛力 |
