## 🌍 市場總體觀察

### Trumpcession（川普衰退）深度解析

#### 三位一體的衰退暗示
美國政府核心官員一致釋出經濟衰退訊號：

1. **川普本人**
   - 記者問是否會導致經濟衰退，回答「不排除」
   - 前兩天講完耐人尋味的話後，又開始粉飾太平

2. **財政部長貝森特（Bessent）**
   - 「沒有川普賣權（No Trump Put）」= 股市崩盤時川普不會救市
   - 「經濟要進入戒斷期」= 市場不要再依賴政府財政支出
   - 「只關注美債殖利率」= 目標讓10年期公債殖利率下降

3. **商務部長盧特尼克（Lutnick）**
   - 「關稅是美國有史以來最重要的政策」
   - 「即使陷入經濟衰退也絕對值得」
   - 最新發言：Q1、Q2經濟成長率低迷是「拜登的問題」，Q3開始才看到川普政策效果

#### 川普Put的深層含義

- **傳統Fed Put**: 聯準會在股市崩盤時降息救市，形同保險
- **川普Put**: 川普政府明確表示不會為下跌的股市提供保護
- **戒斷期**: 過去政府靠大量財政支出刺激經濟，現在要財政平衡，不再印鈔機救市

#### 美債殖利率策略
- **現狀**: 10年期美債殖利率約4.1-4.2%
- **目標**: 讓殖利率下降至3%甚至2%
- **效益**: 每降一個百分點，美國公債利息支出省4,000億美元
- **方法**: 讓市場認為經濟會衰退 → 資金湧入美債避險 → 殖利率下降
- **民間影響**: 美國30年房貸利率綁定10年期公債殖利率，殖利率下降可降低民間借貸成本

### 川普的如意算盤

#### 上半年劇本
1. 推行關稅政策，引發經濟摔退預期
2. 股市下跌，美債殖利率下降
3. 一切「甩鍋拜登」

#### 下半年劇本
1. 關稅上稍微讓步（第一次積招）
2. 減稅政策上路（有正當性）
3. 成立主權基金
4. 聯準會被迫大力降息
5. 股市V型反轉

#### 最大風險
- 如意算盤打不響：跑過頭的跌勢可能失控
- 下一次選舉在明年底，仍有充裕時間操作

### 外資投資銀行的態度

#### 經濟衰退機率不斷上修
- 從10% → 20% → 40%（高盛）
- 美國銀行：接近50%
- 各機構理由一致：關稅將造成負面衝擊

#### 華爾街的盤算
- 美股已漲兩三年，往上推的空間不如往下跌的空間
- 川普不再當「多頭總司令」，華爾街順勢做空
- 上面布空單 → 發布負面言論 → 投資人恐慌下跌 → 獲利
- 可能先做空半年，再做多半年

### 歷史教訓：1930年關稅大戰

- **胡佛總統**: 推出關稅法案，2萬件商品關稅拉高40-50%
- **口號**: 保護美國勞工（與川普如出一轍）
- **結果**: 加拿大率先反制 → 歐盟跟進 → 大蕭條持續3年
- **貿易影響**: 美國進出口衰退60%以上

## 💼 產業分析與投資建議

### 個股落底五大要件 - 玻接老師

#### 落底判斷標準
1. **量價與形態**: 底部要有底部該出現的量，價格要有慣性改變
2. **低檔爆量換手**: 有人停損、有人進場買，強迫換手
3. **連續3-5天不再創新低**: 形成短線低點的初步訊號
4. **K線出現長下影線**: 代表相對低檔有人承接，賣方賣錯
5. **底部形態需要時間**: W底、三重底、頭肩底等都需要時間醞釀

#### 確認底部的關鍵
- **站上頸線**: 底部形態完成的確認訊號
- **站上長期均線**: 年線或半年線站上才代表趨勢扭轉
- **大量高點站穩**: 出現大量後，股價必須站穩在大量高點以上

### 個股分析

#### 鸿海 (2317)
- **法說會成績**: Q4營收季增15%、年增15%，去年EPS 11.01元創17年新高
- **不利因素**: 全年毛利率及淨利率下滑，EPS略不如市場預期（原估12元）
- **技術面**: 前波第一支腳未跌破，178-163.5元區間兩次放量換手
- **關鍵價位**: 站上185元完成底部形態
- **操作建議**: 保守者等站上185元再買；積極者可小量布局，以163.5元為停損

#### 廣達 (2382)
- **技術面**: 兩次放量換手，頸線距離較近
- **優勢**: 比鸿海更接近完成底部形態
- **關鍵價位**: 站上271元完成底部
- **操作建議**: 若要賭反彈，廣達比鸿海更明確

#### 奇鋐 (3017)
- **技術面**: 低檔放量最明顯，已幾乎站上月線
- **優勢**: 站在月線之上，且站在季線位置
- **GTC題材**: 下週GTC大會前一天可能率先發動
- **關鍵價位**: 站上583元，需放量帶量中長紅
- **操作建議**: 三檔中最有可能領先打底完成

#### 弘塑 (3131) - 半導體設備
- **現狀**: 今日大量黑K破底
- **判斷**: 尚無形態、無連續不破底、無換手 → 全部不符合落底條件

#### 萬潤 (6187) - 半導體設備
- **現狀**: 有不破底但無形態，大量高點未站穩
- **判斷**: 目前也未符合落底條件

#### 辛耘 (3583) - 半導體設備
- **現狀**: 有出量，但仍差一個腳
- **判斷**: 比弘塑、萬潤好一點，但仍需等待

#### 潤泰新 (9945) / 潤泰全 (9904)
- **利空**: 配息率僅20%，鷹建比例高，被央行打房影響
- **判斷**: 連續空方趨勢，至少需一個月以上時間打底
- **操作**: 短線可能再創低，需等第二次大量換手

#### 富邦金 (2881)
- **利空**: 大盤無法出量，金融股形態轉差
- **判斷**: 外資最近在賣，需觀察外資態度
- **操作建議**: 87元以下再考慮進場

## 📈 技術面分析

### 黃金創歷史新高
- **現貨價格**: 接近2,999.55美元（錄影時間）
- **期貨價格**: 已突破3,000美元
- **意涵**: 避險需求強烈，印證市場對經濟衰退的擔憂

### 央行政策分析 - 夢到老師

#### 超級央行週預測

##### 聯準會（Fed）
- **預測**: 3月不會降息
- **理由**:
  - 2月CPI下降、核心CPI也下降，但單月數據不足以改變政策
  - 薪資與雇用成本仍高於疫情前水準
  - 鮑威爾持續強調「停看聽」
- **降息時機**: 市場預期下半年可能降息，空間約三碼

##### 日本央行（BOJ）
- **預測**: 3月不會升息
- **理由**: 春鬥（工會薪資談判）尚在進行，結果4-5月才出
- **物價**: CPI已達4%，接近30年高點4.3%
- **升息時機**: 若加薪幅度超過5-6%，可能5月或6月升息

##### 台灣央行
- **預測**: 3月不會升息，也不會有第八波打炒房
- **理由**:
  - 台灣CPI僅1.5%，核心CPI僅0.9%，遠低於2%門檻
  - 2025年經濟成長逐季下滑（Q1 3.46% → Q4 2.69%）
  - 4月關稅衝擊在即，央行需保留政策彈性
  - 前七波信用管制已有效（交易量萎縮）
- **電價影響**: 楊金龍總裁已表態電價調漲對CPI影響不大

### 台幣匯率展望

#### 上半年
- **趨勢**: 偏弱勢整理
- **區間**: 32.5-33元
- **原因**:
  - 外資持續賣超與資金流出
  - 台積電赴美投資帶走資金
  - 美元雖弱但台幣更弱（背離現象）

#### 下半年
- **趨勢**: 隨美台利差縮小而轉強
- **預估**: 有機會回到32元附近
- **催化劑**: 聯準會若下半年降息三碼，美台利差收窄

## 📋 投資策略總結

### 核心觀點
1. **Trumpcession是刻意操作**: 川普政府有意讓經濟先衰退再救市
2. **上半年偏空、下半年偏多**: 配合川普的政策節奏
3. **個股落底需要五大要件**: 量、價、形態、下影線、時間缺一不可

### 操作建議
1. **伺服器三雄排序**: 奇鋐 > 廣達 > 鸿海（以落底進度排列）
2. **半導體設備**: 全部尚未落底，暫勿進場
3. **金融股**: 等87元以下再看富邦金
4. **營建股**: 至少需要一個月打底，短線不宜進場

### 風險提示
- 華爾街可能先做空半年再做多半年
- 4/2對等關稅為最大不確定因素
- 美國消費70%靠前10%家庭，股市下跌直接衝擊消費

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| **Trump Put** | 比喻川普政府是否會在股市大跌時出手救市（如同賣權的保險功能） |
| **Fed Put** | 聯準會在股市崩盤時透過降息等手段救市的慣例 |
| **戒斷期** | 指市場需要脫離對政府財政支出刺激的依賴 |
| **10年期美債殖利率** | 美國30年房貸利率的參考基準，影響民間借貸成本 |
| **春鬥** | 日本工會每年春季進行的薪資談判，影響日央升息決策 |
| **連合（Rengo）** | 日本最大工會總聯合會，負責協調全國性薪資談判 |
| **頸線** | 底部形態（如W底、頭肩底）的確認突破線，突破即確認底部成立 |
| **W底** | 股價形成兩個低點的底部型態，突破頸線確認反轉 |
| **對等關稅** | 川普預計4/2實施的關稅政策，依各國對美順差程度課稅 |
| **下影線** | K線下方的影線，代表盤中低點被拉回，有承接力道 |
