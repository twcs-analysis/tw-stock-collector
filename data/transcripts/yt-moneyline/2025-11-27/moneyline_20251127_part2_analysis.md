## 市場總體觀察

### 外資動向詳解

#### 外資買超分析
- **連三日買超**: 外資態度明顯轉多
- **期貨空單**: 持續下降至28,000口以下
- **期限選連三紅**: 外資現貨+期貨+選擇權連續三天都偏多
- **買超標的**: 南亞（漲停，41,000張）、力積電、華邦電、中信金、連電、緯創等

#### 外資買超解讀（建成觀點）
- 買超個股不具強攻擊性代表性
- 華邦電、力積電等記憶體股可能為「黑頭髮外資」（境外中資假外資）
- **真正攻擊指標**: 看投信（歸買）買什麼更具參考價值
- 現貨買超多才是最重要的，期貨主要用於避險

#### 投信動向
- 投信買超: 復邦金、擁有風精、張營、群狀、華航、統一、旺宏、金寶、大同、台灣大
- 比較分散，但開始回補
- **歸買（投信主動型基金）買的更具攻擊性**:
  - 軍工中方電
  - 矽光子: 聯亞、華新光、華玉KY
  - 半導體設備相關

### 大盤技術面展望（海花觀點）

#### 否轉聖第二隻腳預判
- **預判**: 有可能出現第二隻腳回測
- **條件**: 量縮止穩 + 留長下影線或出現長紅K
- **關鍵支撐**: 26,400點（第一隻腳低點）
- **絕對不能破**: 26,400點，跌破則反轉失敗
- **第二隻腳右腳要高於左腳**: 回測止穩的位置要高於26,400點

#### 選股邏輯
- 到時候一定會有新的題材出現
- 新產品、新應用、新發展 = 未來新主流
- **大震盪後會出現新主流、新飆股**

## 產業分析與個股解讀

### 一、熱門股週末去留策略（海花分析）

#### 拉回最後買點（逢低佈局）

**1. 鴻海 (2317) - 首選減便宜標的**
- 每次大跌外資必賣，跌下來就是撿便宜機會
- 第三季EPS表現很好，蘋果、輝達、OpenAI所有最強AI公司要生產硬體全找鴻海
- **技術面**: 反彈偏弱，還沒站回季線，比台股大盤弱勢
- **甜甜價**: 若破底到203元附近為更甜買點
- **結論**: 拉回不要錯過，之前已多次上車機會

**2. 聯發科 (2454) - 轉型突破**
- 從高點跌下來很痛，但已回到1,300元附近
- **轉型方向**: 大陸Google TPU代工、無線衛星通訊、雲端設備
- 不只做手機晶片，已成功切入多元領域
- **比鴻海強**: 不會破底，長紅K的下緣就是好的買點
- **結論**: 第二隻腳回測時是好價格，把握住

**3. 力程 - 等待轉型**
- 轉型FOPLP（扇出型面板級封裝），非用玻璃做而是用其他材料
- 已投資400億元，訂單訂滿
- 與輝達買了設備廠
- 明年量產，投信一直在買
- **支撐**: 135元，來到此價位可考慮佈局
- **結論**: 需耐心等待，偏價值型投資

**4. 奇鋐 - 價值型投資**
- Wi-Fi設備龍頭，高股息概念
- 跌破4月低點（因基板漲價導致模組成本上升，投信一直賣）
- **機會**: 跌回80-90元為長線佈局好時機（原本從80漲到170）
- **結論**: 危機就是轉機，基板價格穩定後可佈局

**5. 亞力 - 傳產電力股**
- 殖利率穩定有5%，旗下壓力、穩罩穩打
- 頭信原動心、遇命等都有賺錢
- **股息保護**: 殖利率5%提供下檔保護
- **題材**: 五二停戰概念（俄烏停戰受惠）

#### 拉回不宜再抱（漲多該出場）

**1. 被動元件（國巨等）**
- 典型豬王理論：缺貨時大漲、供過於求時大跌
- 不具轉型能力，震盪幅度大

**2. 川湖**
- 做伺服器滑軌（鐵件），已漲8倍
- 總有一天伺服器需求到頂，營收不再成長
- 不能轉型，即使明年成長五六成，大戶也已經在賣
- **結論**: 跌破均線不要再做強彈介入

**3. 情誠（勤誠）**
- 同屬伺服器鐵件，轉型不易
- 與川湖類似，漲多需注意回檔風險

#### 拉回閉著眼睛抱（報景持有）

**1. 創意 (3443) - 首選**
- 原本世芯比創意好，但現在逆轉
- 世芯營收年減，創意10月營收增加150%
- 創意為台積電子公司，很多客戶找它做GPU設計（克服GPU太貴問題）
- **股價**: 2,000多元（世芯曾到4-5,000元），有比價空間
- **結論**: 就算拉回也是報景持有

**2. 漢唐博 (南亞)**
- 本益比低 + 高成長
- 電子材料漲價題材

**3. 連電/燈美食**
- 各有題材，做支撐的位置

### 二、半導體明年展望（張老師深度分析）

#### 全球半導體市場趨勢
- 2023-2027年成長率**一路下滑**（因基期墊高）
- 但仍維持正成長，並非衰退

#### 五年成長率最高族群（按排名）
1. **運算電子**: 年複合成長率 77.28%（GPU、TPU等AI基礎建設）
2. **軍工**: 成長幅度第二高
3. **車用電子**: 電動車、自駕車帶動
4. **消費電子**: 約6.6%
5. **通訊用**: 最弱（手機成長有限）
6. **儲存用電子**: DRAM成長幅度這幾年並不高

#### 子產業展望
- **晶圓代工**: 明年仍為所有子產業中成長最好的，年增18%
- **IC設計**: 排名第二，6.8%
- **封裝測試**: 先進封裝為重點

#### 台灣半導體產值
- 今年成長22%
- 明年破7兆台幣，繼續成長18%
- **一枝獨秀**: 半導體AI是台灣唯一亮點產業

#### 先進製程重大趨勢
- **3奈米**: 爆單中，AR晶片全部搶3奈米產能
- **2奈米**: 明年開始貢獻營收
- 台積電3奈米+5奈米已佔營收60%
- 若加2奈米，先進製程佔比可能高達70%

#### 台積電建廠擴產
- **高雄**: 2奈米
- **中科**: 1.5奈米以下
- 已蓋4座廠，還要再加3座（在南科）
- **結論**: 3奈米爆單、2奈米被客戶搶訂，產能持續擴充

#### 先進封裝
- **CoWoS**: 產能從7.5萬片/月增至10萬片/月（以格夜數增加）
- **矽光子**: 持續供不應求
- **結論**: 晶圓代工+先進封裝 = 明年不可或缺的秘密武器

### 三、輝達財報與科技日解讀（阿文三觀點）

#### 輝達回答不怕 - 神話不破
- **科技日公布**: 5.2兆美元AI基礎建設訂單
- **Blackwell晶片**: 光賣一年就600萬顆，比H100/H200賣三年400萬顆還多
- 預估到明年底，Blackwell+少數Rubin可賣到2,000萬顆
- **營收對比**: Blackwell一年營收 = H100/H200三年營收的5倍

#### AI投資不是泡沫的理由
- 三大科技巨頭現金流持續增長: 2024年6,471億 → 2025年7,731億 → 2026年9,411億
- 退休基金投入AI增加
- **資本支出持續調高**:
  - 亞馬遜: 1,200億 → 加碼600億
  - 微軟: 1,100億 → 1,500億
  - Meta: 700億 → 1,000億
  - Google: 從710億調高到1,000億

#### 台積電展望
- 短線整理格局（橫盤、橫著走、小漲格局）
- 等待資本支出從4,300億調高到5,000億以上
- **3奈米**: 產能從11萬片拉到16-17萬片
- **2奈米**: 從3萬片拉到9萬片
- 調高資本支出時 = 下一波上漲起點
- **台積電獲利預估**: 今年EPS約63元，明年76元，後年92元
- **毛利率**: 從45%提升到明年預估60%

#### 設備股 = 現在焦點

**弘鉅 - 今日掛牌（半導體設備新貴）**
- 上市首日漲至1,445元（中籤現賺150萬）
- 明天挑戰3,000元
- 小股本新上市股，目標價可能被法人定在3,000-4,000元
- **比價效應**: 帶動整個設備族群價格重估

**家電 (3680) - 張老師推薦**
- K線最弱但營收成長趨勢明確
- 光刻機需求因2奈米/3奈米擴產而大增
- 毛利率達50%以上
- **營收預估**: 今年7.3元EPS，明年成長45%約21元，後年再成長35%約26.5元
- **目標價**: 大摩從300元調高到380元
- **結論**: 台積電資本支出調高的最大受惠者之一

## 技術面重點

### 大盤關鍵位置
- **月線（越線）**: 已站回，為多空分界
- **第一隻腳低點**: 26,400點（絕對不能破）
- **第二隻腳條件**: 量縮止穩 + 長下影線或長紅K
- **壓力**: 28,000點（前高套牢區）

### 台積電技術面
- 今日1,435元，站回月線但未站穩
- 之前破1,400元後反彈
- **短線**: 橫盤整理1-2週
- **中線**: 等資本支出調高消息後才有下一波

### MACD觀察
- 好線不可以掉入零軸以下
- 掉下去壓力很大

## 策略總結

### 核心策略
1. **運算電子（AI基礎建設）= 未來五年最大成長主軸**: GPU、TPU、AI晶片
2. **晶圓代工 = 子產業中最佳選擇**: 台積電先進製程一枝獨秀
3. **先進封裝 = 不可或缺**: CoWoS、矽光子持續供不應求
4. **設備股 = 現在可佈局的方向**: 台積電休息時反而設備股會動

### 操作建議
- **台積電**: 整理期不追，等資本支出調高再進場
- **設備股**: 弘鉅帶動比價效應，家電為低檔佈局標的
- **拉回佈局**: 鴻海、聯發科為第二隻腳最佳買點
- **報景持有**: 創意、漢唐博、連電不要被甩出去
- **漲多減碼**: 被動元件、川湖、勤誠等不具轉型能力的個股

### 風險管理
- 降息機率持續觀察，降下去對股市不利
- 美元指數若站回100以上，資金可能回流美國
- 12月外資可能放假，台積電要拖到明年
- 反彈缺量需注意
- 一定要選有賺錢的公司，不能只靠題材

## 名詞解釋

| 名詞 | 說明 |
|------|------|
| **BDI指數** | Baltic Dry Index，波羅的海乾散貨指數，反映全球航運市場景氣 |
| **CoWoS** | Chip-on-Wafer-on-Substrate，台積電先進封裝技術 |
| **FOPLP** | Fan-Out Panel Level Packaging，扇出型面板級封裝 |
| **Blackwell** | 輝達最新一代AI晶片架構（包含GB200、GB300） |
| **Rubin** | 輝達下一代AI晶片架構（Blackwell之後） |
| **先進製程** | 一般指7奈米以下的半導體製造技術 |
| **資本支出** | Capital Expenditure，企業用於擴充產能的投資金額 |
| **歸買** | 投信中的主動型基金，相對於被動型ETF，更具主動選股攻擊性 |
| **豬王理論** | 被動元件等週期性產業的供需循環：缺貨漲價→擴產→供過於求→跌價 |
