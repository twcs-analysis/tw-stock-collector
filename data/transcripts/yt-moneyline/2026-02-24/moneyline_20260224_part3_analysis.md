| 項目 | 預估值 |
|------|--------|
| 營收 | 656.8 億美元，年增 67% |
| EPS | 1.46-1.53 美元 |

| 目前股價 | 199 美元 |
| 分析師目標價 | 最高 233 美元 |

**財報情境分析**：

| 情境 | 條件 | 股價影響 |
|------|------|----------|
| 超預期 | EPS > 1.53 × 1.05 = 1.61 以上 | 上漲，引發全球軋空 |
| 符合預期 | EPS 約 1.53，驚喜度 4-5% | 持平，不會重挫（因今年未先漲） |
| 下季指引 > 750 億 | 超越市場預期 | 強烈正面 |
| 下季指引 711-750 億 | 符合預期（預估 723 億） | 中性 |
| 下季指引 < 711 億 | 低於預期 | 修正風險 |

**重要觀察**：今年輝達股價並未像往年在財報前大漲，因此「財報魔咒」（公布後下跌）可能不適用

### 五、先蹲後跳黑馬股（其真分析）

**選股邏輯**：低位階 + 轉機題材 + 左側交易

**2028 宏觀備忘錄警示**：
- 某機構發布「來自 2028 的宏觀備忘錄」，1,700 萬次瀏覽
- 描述 AI 過度發展導致 M 型化、結構性危機的情境
- 不是預測，而是提供投資人思考的情境
- 結論：台灣作為供應鏈，持續出貨即受惠，不必過度恐慌

#### 族群一：紡織 / 自行車（關稅受惠 + 經典棒球賽）

| 個股 | 題材 | 本益比 |
|------|------|--------|
| **聚陽** | Gap 代工、殖利率 5%、關稅拉貨受惠 | 偏低 |
| 儒鴻 | 紡織龍頭 | 偏低 |
| 廣越 | 紡織 | 偏低 |
| 巨大 | 自行車，有轉機題材 | 偏低 |

**轉機催化劑**：
- 經典棒球賽等大型賽事帶動運動服飾需求
- 美國服飾銷售連 21 個月正成長
- 關稅 150 天暫緩期，補庫存拉貨潮

#### 族群二：軍工

| 個股 | 特色 |
|------|------|
| **長風航太** | 賺最多、本益比不高、營收好、穩健型 |
| 雷虎 | 活潑型，每次動第一個 |
| **中光電** | 雙題材（無人機國防訂單 + 光學本業好轉），類似面板復甦受惠 |

**操作注意**：軍工股慣性為「漲幾天又掉下來」，觀察量能是否持續增加

#### 族群三：手機 / 車用 MCU

| 個股 | 題材 |
|------|------|
| **盛群** | 車用/工控 MCU，低檔位置，量增觀察 |
| **新唐** | 車用 MCU + 無人機，營收表現不錯，股價仍偏負 |
| 新日興 | 折疊機鉸鏈，單價上看 80 美元，下半年為重點 |

**操作策略**：前方套牢壓力大，不追價，拉回布局

## 📋 投資策略總結

### 短期（1-2 週）

1. **輝達財報**：週四早上公布，下季指引 > 750 億為正面訊號，< 711 億需警戒
2. **低軌衛星**：昇達科注意慣性改變（五日線 → 十日線），華通平台支撐買
3. **期貨選股**：圓剛、耀華、臻頂 KY 可觀察下半週續航力
4. **回檔準備**：關股 188 億賣超 + 週五休市，明後天可能震盪

### 中期（1-3 個月）

1. **先蹲後跳**：紡織（聚陽）、軍工（長風航太、中光電）、MCU（盛群、新唐）
2. **低軌衛星**：西華（抗輻射石英元件）、大眾控（衛星 + 光通訊雙題材）
3. **手機直聯元年**：MWC 後題材持續發酵
4. **折疊機**：新日興下半年為重點，單價 80 美元

### 風險評估

- **輝達財報風險**：500 億美元空單部位，結果好壞都可能劇烈波動
- **美股滯漲**：那斯達克 4 個月未創高，若美股回檔台股難獨善其身
- **2028 備忘錄**：AI 過度發展的結構性風險長期需留意
- **先蹲後跳股**：位階低但前方套牢壓力大，需耐心等候

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| 軋空 | Short Squeeze，空方被迫回補導致股價急漲 |
| Put/Call Ratio | 賣權/買權比率，超過 100 代表看多氣氛濃厚 |
| 手機直聯（D2C） | Direct-to-Cell，手機直接透過低軌衛星通訊，不需地面基地台 |
| MWC | Mobile World Congress，世界行動通訊大會 |
| GTC | GPU Technology Conference，輝達 GPU 技術大會 |
| CSP | Cloud Service Provider，雲端服務供應商（微軟、亞馬遜、Google、Meta） |
| MCU | Micro Controller Unit，微控制器 |
| 灰犀牛 | 高機率但常被忽視的風險（相對於低機率的黑天鵝） |
| 滯漲 | 指數不再創高，處於高檔橫盤狀態 |
| 2028 宏觀備忘錄 | 某機構發布的情境分析報告，描述 AI 過度發展可能導致的結構性經濟危機 |
| 左側交易 | 在股價下跌過程中逐步買進（逆勢），相對於右側交易（順勢追漲） |
| Graviton 3 | Amazon 自研 ARM 架構伺服器晶片 |
