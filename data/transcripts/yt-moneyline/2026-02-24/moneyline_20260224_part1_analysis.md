### 二、記憶體產業（重點看好）

**潘董（群聯董事長）過年受訪要點**：
- 記憶體進入「超級週期」，嚴重缺貨
- Vera Rubin 每顆 GPU 需配置超過 20TB SSD
- 若賣出 1,000 萬顆 Vera Rubin，需消耗 200EB 容量
- 全球去年產出僅 1,000-1,100EB，AI 將吞掉 20% 的 Flash 產能
- 電視用 eMMC（8G）從 1.5 美元漲到 20 美元，漲 13 倍且缺貨
- 客戶滿足率不到 30%
- 擴產要到 2027-2029 年後才能量產

**投資策略**：先買上游 → 與原廠關係好的公司 → 創造被需要價值的公司

| 個股 | 代號 | 操作建議 | 備註 |
|------|------|----------|------|
| 旺宏 | 2337 | 已創歷史新高 | 上游，Flash 原廠 |
| 力積電 | 6770 | **最被低估**，收 73.7 元，大摩目標價 88 元偏低 | 切入代工 HBM + 先進低輪技術 |
| 群聯 | 8299 | 股價回檔整理，拉回可買 | 與原廠關係良好，AI 方案強 |
| 宜鼎 | 5765 | 已創歷史新高 | 全球最大工業級 SSD，輝達基金級夥伴，機器人題材 |

**力積電（6770）被低估原因**：
- 大摩預估明年 EPS 僅 2.21 元，未算入代工 HBM 及先進低輪技術
- 黃董表示退出消費電子，專注 AI 相關晶片 + 電源管理 IC + 記憶體
- 賣廠加上法距低壓後手握 700-800 億現金，用於製程升級
- 技術授權給塔塔集團，打造印度首座 12 吋晶圓廠

## 📈 技術面分析與操作策略

### 大盤技術面（郭老師分析）

**目標價推算**：
- 台積電 2026 年 EPS 93.2 元 × 25 倍本益比 = **2,330 元**
- 台積電從目前價位到 2,330 元尚有 365 元空間
- 台積電每漲 1 元 ≈ 大盤漲 8 點
- 365 × 8 = 2,920 點 → 34,700 + 2,920 = **37,620 點**
- **台股最低目標 37,620 點**，可能上看 38,800 / 39,900 / 40,000

**短線注意**：
- 日 K 值已達 85.66，過去經驗 K 值到 94.19 時短線回檔
- 關股連賣 5 天，今日賣超 188 億（前所未見的數字）
- 上次類似狀況回檔 1,832 點
- **明後天台積電挑戰 2,000 元，若回到 1,800-1,900 元區間是最佳買點**

**操作原則**：
- KD 尚未死亡交叉、MACD 尚未翻負 → 多方格局未變
- **2026 年沒有空頭走勢，只有漲多拉回**
- 大盤多方時：找 K > D 向上、MACD 柱狀體買方市場的股票
- 大盤回檔時：避開 K < D 下修、柱狀體負值的股票，重新找多方股票

### 非投資等級債（風險管理）

**為何配置非投等債**：
- 台股波動度 20%，美股 10%，美科技股 15%，非投等債僅約 3-5%
- 2026 年經濟屬中低成長環境，非投等債表現佳
- 降息環境下：公債報酬 7.2%、投等債 12.3%、**非投等債 15.3%**（最高）
- 建議選主動式非投等債 ETF（經理人選債，不受天期/信評限制）

- 信評分布：CCC 以下僅 7%，B 至 BBB 佔 89%
- 持債企業：日產汽車、博士倫、六旗娛樂、史太博等大型企業

## 📋 投資策略總結

### 短期（1-2 週）

1. **台積電挑戰 2,000 元**：明後天可能短暫回檔，回到 1,800-1,900 是絕佳買點
2. **關股連賣 5 天、188 億史上最大**：短線回檔風險升高
3. **記憶體族群**：上游優先，力積電最被低估，群聯拉回可介入
4. **ABF 載板**：南電、欣興、景碩持續強勢，注意壓力區

### 中期（1-3 個月）

1. **台積電 2,330 元前持續做多**，大盤 37,620 為最低目標
2. **記憶體超級週期**：Flash 漲價 13 倍且缺貨，擴產要 2027 年後
3. **六大明星股輪動操作**：記憶體 → ABF → 低軌衛星 → 玻纖布 → 被動元件 → 權值股
4. **資產配置**：建議 1/3 至 1/2 配置非投等債 ETF，降低波動

### 風險評估

- **短線風險**：關股大量賣超、K 值偏高、台積電 2,000 關卡心理壓力
- **中期風險**：輝達財報影響、川普關稅不確定性
- **應對策略**：任何拉回都是買點，利空大跌是最大利多，2026 年做多到台積電 2,330 出現為止

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| 關股 | 關鍵股（大型權值股），此處指外資期貨部位的方向指標 |
| KD 指標 | 隨機指標，K 值與 D 值的交叉判斷多空方向 |
| MACD 柱狀體 | 趨勢動能指標，正值為買方市場、負值為賣方市場 |
| 本益比（P/E） | 股價 ÷ 每股盈餘，衡量股票是否昂貴 |
| ABF 載板 | Ajinomoto Build-up Film，用於高階 IC 封裝的關鍵載板材料 |
| Flash | 快閃記憶體，用於 SSD 等儲存裝置 |
| EB | Exabyte，資料儲存容量單位，1EB = 1,024PB = 約 100 萬 TB |
| Vera Rubin | 輝達新一代 AI 晶片架構 |
| HBM | 高頻寬記憶體（High Bandwidth Memory），AI 晶片關鍵元件 |
| 非投等債 | 非投資等級債券（High Yield Bond），信評較低但票息較高 |
| 00984D | 聯博全球非投等債主動式 ETF |
| 含積量 | ETF 中台積電的持股佔比 |
