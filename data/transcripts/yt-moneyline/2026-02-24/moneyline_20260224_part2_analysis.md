## 💼 產業分析與投資建議

### 一、OFC 大會（2026 年 3 月 15-19 日，舊金山）

**展覽規模**：
- 91 個國家、約 16,700 位與會者、超過 700 家參展公司
- 110 位演講嘉賓、45 場專題演講
- 光纖網路論壇（OIF）將展示關鍵技術

**核心焦點：EL-SFP（外部雷射小型可插拔模組）**

技術突破說明：
- 傳統 CPO：雷射直接貼在交換晶片封裝內，但雷射怕熱，高溫導致波長偏移干擾其他通道
- 新方案 EL-SFP：將雷射外置，大幅降低散熱管理難度
- 優勢：壞掉可直接熱插拔更換，不用關機、不需整塊交換機更換
- 相較傳統可插拔光模組節省 65% 功耗，相較 LPO 節省 35% 功耗

**OIF 成員名單**（含博通、Cisco、科銳倫、邁威爾等，台灣成員：字寶、茂連）

## 📋 投資策略總結

### 短期（1-2 週）

1. **光通訊**：眾達積極買進（博通標配），環宇（平價版聯亞）即使漲停也要買
2. **被動元件**：華新科首選（位階低、空間大），國巨 300 元安全牌
3. **權值股**：鴻海已啟動（低點越來越高），拉回就買
4. **外資跟單**：力積電、國巨值得跟，聯電不如買世界先進

### 中期（1-3 個月）

1. **OFC 大會（3/15-19）**：EL-SFP 技術展示為光通訊注入新動能
2. **茂連**：被低估的 CPO 概念股，1,300 以下切入
3. **廣達、緯創**：鴻海走完後接棒發動，提前布局
4. **29 檔明星股輪動**：低檔支撐買、壓力賣，全年操作

### 風險評估

- **光通訊個股**：多檔已列處置/關警閉，流動性受限
- **被動元件**：活潑型個股風險較高
- **權值股**：廣達、緯創尚待外資東風，需耐心等候
- **回檔預警**：關股 188 億史上最大賣超，明後天可能拉回

## 📚 名詞解釋

| 名詞 | 說明 |
|------|------|
| OFC | Optical Fiber Communication Conference，美國光纖通訊展覽，光通訊領域全球最大盛會 |
| CPO | Co-Packaged Optics，光電共封裝技術，將光學引擎直接整合在交換晶片上 |
| CPC | Co-Packaged Copper，銅互聯共封裝技術 |
| EL-SFP | External Laser Small Form-factor Pluggable，外部雷射小型可插拔模組 |
| OIF | Optical Internetworking Forum，光纖網路論壇 |
| LOD | Laser Diode，雷射二極體，光通訊發射端元件 |
| PD | Photo Detector，光感測器，光通訊接收端元件 |
| MLCC | 積層陶瓷電容，被動元件核心產品 |
| 處置股 | 因股價異常波動被證交所列入處置的個股，交易須預繳款項 |
| 關警閉 | 關注、警示、處置的簡稱，限制交易的措施 |
| 正規軍 | 指直接與原廠（如博通、輝達）合作的核心供應鏈廠商 |
