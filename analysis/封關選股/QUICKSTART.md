# 封關選股 - 快速入門

## 🚀 5 分鐘快速上手

### Step 1: 確保有最新的技術指標資料

```bash
# 設定資料庫密碼
export DB_PASSWORD=tw_stock_dev_password_2024

# 轉換今天的技術指標
scripts/data-transformer/transform.sh today
```

### Step 2: 執行選股

```bash
# 使用執行腳本（推薦）
./analysis/封關選股/run.sh

# 或直接執行 SQL
psql-17 -U postgres -d tw_stock -f "analysis/封關選股/年線附近選股.sql"
```

### Step 3: 查看結果

結果會儲存在 `analysis/封關選股/results/` 目錄下：

```bash
# 查看最新的文字結果
ls -t analysis/封關選股/results/*.txt | head -1 | xargs cat

# 開啟 CSV（用 Excel 或 Numbers）
ls -t analysis/封關選股/results/*.csv | head -1 | xargs open
```

## 📊 結果解讀

### 重點欄位

1. **安全評分**（最重要）
   - > 80 分：優質標的 ⭐⭐⭐
   - 60-80 分：不錯標的 ⭐⭐
   - < 60 分：一般標的 ⭐

2. **操作建議**
   - 「回測年線，優質」= 最佳買點
   - 「站上年線，可考慮」= 可以買進
   - 「略低於年線，等待」= 再觀察

3. **距離年線(%)**
   - -1% ~ -3%：回測年線，買點
   - 0% ~ +3%：站上年線，可買
   - > +3%：偏離年線，追高

4. **建議停損價**
   - 嚴格執行，跌破立即賣出

## ⚠️ 重要提醒

### ❌ 常見錯誤

1. **追高**
   - 距離年線 > +5% 不要買
   - 等待回檔到年線再買

2. **不停損**
   - 跌破年線 3% 立即賣出
   - 不要幻想會反彈

3. **All-in 單一股票**
   - 單一個股不超過 15%
   - 至少分散 5 檔

4. **忘記保留現金**
   - 至少保留 20% 現金
   - 等待更好的買點

### ✅ 成功關鍵

1. **紀律執行停損**
   - 跌破年線立即賣出
   - 不要猶豫、不要幻想

2. **分批買進**
   - 第一次買 1/2 部位
   - 站穩年線後加碼

3. **分批獲利**
   - 獲利 10% 賣 1/2
   - 獲利 20% 全部出清

4. **資金管理**
   - 單一個股 < 15%
   - 保留現金 > 20%

## 📞 疑難排解

### Q1: 執行腳本顯示「找不到技術指標資料」？

**A**: 請先轉換技術指標

```bash
export DB_PASSWORD=tw_stock_dev_password_2024
scripts/data-transformer/transform.sh today
```

### Q2: 查詢結果為空（0 檔股票）？

**A**: 可能原因：
1. 今天沒有股票符合條件（市場太強或太弱）
2. 技術指標資料不完整

**解決方式**：
- 放寬條件：年線範圍改為 ±5%
- 檢查資料：`SELECT COUNT(*) FROM technical_indicators WHERE trade_date = '2026-02-07';`

### Q3: 如何調整選股條件？

**A**: 編輯 `年線附近選股.sql`

```sql
-- 年線範圍（第 82-83 行）
AND price_to_ma240_pct >= 95    -- 改為 ±5%
AND price_to_ma240_pct <= 105

-- 年線斜率（第 86 行）
AND ma240_slope_pct >= 0        -- 只要向上

-- 結果數量（第 240 行）
LIMIT 50                        -- 增加到 50 檔
```

### Q4: 如何匯出到 Excel？

**A**: 使用 CSV 格式

```bash
# 執行查詢並輸出 CSV
psql-17 -U postgres -d tw_stock \
    -f "analysis/封關選股/年線附近選股.sql" \
    --csv > results.csv

# 開啟 CSV（會用 Excel 或 Numbers 開啟）
open results.csv
```
