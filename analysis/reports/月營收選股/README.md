# 月營收選股報告

每月自動生成的營收選股分析報告。

## 📁 目錄結構

```
月營收選股/
├── README.md              # 本文件
├── 2026-01/               # 2026 年 1 月
│   ├── 綜合報告.md
│   ├── 營收成長股.md
│   ├── 營收成長股.csv
│   └── ...
├── 2026-02/               # 2026 年 2 月
└── archive/               # 歷史封存
```

## 📊 報告類型

| 報告 | 格式 | 說明 |
|-----|------|-----|
| 綜合報告 | .md | 包含所有策略的總覽 |
| 營收成長股 | .md / .csv | 年增率 > 20% 且月增率 > 0% |
| 營收爆發股 | .md / .csv | 月增率 > 30% 或年增率 > 50% |
| 穩定成長股 | .md / .csv | 連續 3 月年增率 > 10% |
| 轉虧為盈股 | .md / .csv | 由衰退轉成長 |

## 🚀 生成報告

```bash
# 使用 SQL 查詢（目前方式）
psql-17 -U postgres -d tw_stock \
  -v year_month='2026-01' \
  -f analysis/月營收選股/queries/revenue_growth.sql \
  -o analysis/reports/月營收選股/2026-01/營收成長股.txt

# 使用 Python 腳本（待開發）
python analysis/月營收選股/scripts/revenue_screener.py \
  --year-month 2026-01 \
  --output-dir analysis/reports/月營收選股/2026-01
```

## 📝 報告內容

每份報告包含：
1. **選股條件** - 篩選條件與參數
2. **股票清單** - 股票代碼、名稱、營收數據
3. **增率資料** - 月增率、年增率
4. **統計摘要** - 總數、平均值、極值
