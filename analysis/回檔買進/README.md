# 回檔買進型態 (Pullback Pattern)

**策略核心**：在多頭趨勢中，等待股價回檔至支撐位後再進場。

---

## 📊 策略說明

### 核心理念

回檔買進是格蘭碧八大法則中的經典策略（買點二）：
- **多頭格局**：確認股價處於上升趨勢
- **等待回檔**：耐心等待股價回測支撐
- **支撐確認**：MA20（月線）或前低不破
- **反彈確認**：紅 K 站上 MA5 + 放量

### 適用場景

- ✅ 多頭市場中的回檔
- ✅ 短中線交易
- ✅ 追求較佳進場點位
- ✅ 控制回檔風險

## 🛠️ 工具說明

### 1. pullback_buy_selector.py - 回檔買進選股器

根據四個條件篩選符合回檔買進型態的股票。

#### 四大條件

- **條件 A**：頭頭高 底底高（上升趨勢確認）
- **條件 B**：股價在月線上且前低未破（支撐有效）
- **條件 C**：今日紅 K 站上 5 均（當日力道強）
- **條件 D**：收盤過昨日高（突破確認）

#### 使用方式

```bash
python analysis/pullback-pattern/pullback_buy_selector.py
```

### 2. pullback_buy_selector.sql - SQL 查詢版本

直接在資料庫中執行相同的篩選邏輯。

```bash
psql -U postgres -d tw_stock -f analysis/pullback-pattern/pullback_buy_selector.sql
```

### 3. filter_recovery_stocks.py - 彈性條件篩選

支援調整符合條件數量（3/4 或 4/4）。

```bash
# 至少符合 3 個條件（平衡，推薦）
python analysis/pullback-pattern/filter_recovery_stocks.py --date 2026-02-02 --min-conditions 3

# 符合全部 4 個條件（嚴格）
python analysis/pullback-pattern/filter_recovery_stocks.py --date 2026-02-02
```

## 📈 策略優勢

### 優點

1. **進場點位較佳**：回檔後進場，成本較低
2. **風險較小**：有支撐保護
3. **勝率較高**：順勢 + 支撐確認
4. **符合格蘭碧法則**：經典買點二

### 缺點

1. **需要耐心等待**：不是每天都有機會
2. **可能錯過起漲點**：等待回檔時股價可能持續上漲
3. **假突破風險**：回檔可能變成反轉

---

## 🎯 實戰技巧

### 進場時機

1. **確認多頭格局**：MA20 向上，股價在月線上
2. **等待回檔**：股價回測 MA20 或 MA5
3. **觀察支撐**：前低不破
4. **反彈確認**：出現紅 K + 放量
5. **執行進場**：收盤價突破昨日高

### 停損設定

- **支撐停損**：跌破 MA20（月線）
- **前低停損**：跌破前一波低點
- **百分比停損**：-3% 至 -5%
