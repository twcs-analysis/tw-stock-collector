# 趨勢追蹤策略 (Trend Following)

**策略核心**：追蹤多頭趨勢中的強勢股票，順勢而為。

---

## 📊 策略說明

### 核心理念

趨勢追蹤是技術分析中最經典的策略之一：
- **順勢而為**：趨勢一旦形成，往往會持續一段時間
- **均線多頭排列**：短中長期均線由上到下排列
- **動能確認**：使用 RSI、MACD 等指標確認趨勢強度
- **成交量配合**：放量確認多頭力道

### 適用場景

- ✅ 多頭市場（大盤向上）
- ✅ 中長線投資（波段操作）
- ✅ 追求穩健獲利
- ❌ 不適合震盪盤整市場
