## 📋 問題摘要

### 錯誤一：月增率（MoM）計算錯誤（已修正）

#### 問題描述
所有 2025-02 至 2025-11 的月增率計算錯誤，`last_month_revenue` 欄位值不正確。

**症狀**：
- 營收上升但 MoM 為負數
- 營收下降但 MoM 為正數
- MoM 幅度與實際營收變化不符

**範例**（修正前）：
```
台積電 2025-02:
  當月營收: 2,600.09 億
  上月營收: 3,350.04 億（❌ 錯誤，應為 2,932.88 億）
  MoM: -22.39%（❌ 錯誤，應為 -11.35%）

台積電 2025-03:
  當月營收: 2,859.57 億
  上月營收: 3,350.04 億（❌ 錯誤，應為 2,600.09 億）
  MoM: -14.64%（❌ 錯誤，應為 +9.98%）
```

#### 根本原因

1. **資料收集時機問題**
   - 使用 background agent 平行收集 2025-01 至 2025-11 所有月份
   - 各月份幾乎同時執行，無法依賴「前一個月已收集完成」的假設

2. **API 限制**
   - `_get_last_month_revenue()` 使用 OpenAPI 取得「上月資料」
   - OpenAPI 對於歷史資料查詢，返回的是「查詢當時的上個月」
   - 在 2026-02-08 收集歷史資料時，所有月份都取得 2024-12 作為上月資料

3. **資料錯位**
   - 2025-01 的 `last_month_revenue` = 335,003,568（2024-12）✅ 正確
   - 2025-02 的 `last_month_revenue` = 335,003,568（2024-12）❌ 應為 2025-01
   - 2025-03 的 `last_month_revenue` = 335,003,568（2024-12）❌ 應為 2025-02
   - ...以此類推

#### 正確公式
```
MoM(%) = (本月營收 − 上月營收) ÷ 上月營收 × 100

範例：
  台積電 2025-02: (2,600.09 - 2,932.88) / 2,932.88 × 100 = -11.35%
  台積電 2025-03: (2,859.57 - 2,600.09) / 2,600.09 × 100 = +9.98%
```

#### 修正方法

建立 `/tmp/fix_revenue_mom.py` 腳本：

1. **載入所有月份資料**（2024-12 至 2025-11）
2. **按時間順序重新計算**
   - 從 JSON 檔案中取得正確的「上個月營收」
   - 重新計算月增率 MoM
3. **更新資料庫**
   - 使用 `UPDATE` 語句批次更新 `last_month_revenue` 和 `mom_change_pct`

```python
# 核心邏輯
for i, current_month in enumerate(months[1:], start=1):
    last_month = months[i-1]

    # 從上個月找到對應的營收
    last_revenue = last_data[stock_id]['current_month_revenue']

    # 重新計算 MoM
    mom_pct = ((current_revenue - last_revenue) / last_revenue) * 100

    # 更新資料庫
    UPDATE stock_revenues
    SET last_month_revenue = ..., mom_change_pct = ...
    WHERE year_month = ... AND stock_id = ...
```

#### 驗證方式

```sql
-- 驗證 MoM 計算正確性
SELECT
    year_month,
    current_month_revenue,
    last_month_revenue,
    mom_change_pct,
    ROUND(((current_month_revenue - last_month_revenue) / last_month_revenue * 100)::numeric, 2) AS "驗證MoM",
    ABS(mom_change_pct - ((current_month_revenue - last_month_revenue) / last_month_revenue * 100)) < 0.01 AS "正確"
FROM stock_revenues
WHERE stock_id = '2330' AND year_month BETWEEN '2025-01' AND '2025-12';
```
