# 個股期貨歷史資料回補指南

## 📚 概述

本指南說明如何使用平行化腳本快速回補個股期貨歷史資料。

---

## 🚀 快速開始

### 方法 1: 使用 Shell 腳本（推薦）

```bash
# 收集 2026 年全年資料
./scripts/data-collector/backfill_stock_futures.sh 2026

# 收集指定日期範圍
./scripts/data-collector/backfill_stock_futures.sh 2026-01-01 2026-12-31

# 使用 10 個執行緒加快速度
./scripts/data-collector/backfill_stock_futures.sh 2026 --workers 10
```

### 方法 2: 使用 Python 腳本

```bash
# 收集 2026 年全年資料
python3.11 scripts/data-collector/backfill_stock_futures_parallel.py --year 2026

# 收集指定日期範圍
python3.11 scripts/data-collector/backfill_stock_futures_parallel.py \
    --start 2026-01-01 --end 2026-12-31

# 使用 5 個執行緒
python3.11 scripts/data-collector/backfill_stock_futures_parallel.py \
    --year 2026 --workers 5

# 強制重新收集（覆蓋已存在檔案）
python3.11 scripts/data-collector/backfill_stock_futures_parallel.py \
    --year 2026 --force
```

---

## 🎯 功能特色

### ✅ 自動化功能

- **自動跳過非交易日** - 使用交易日曆服務自動排除週末和假日
- **自動跳過已收集資料** - 避免重複下載，支援中斷續傳
- **平行化處理** - 多執行緒同時下載，大幅提升速度
- **進度顯示** - 即時顯示收集進度和統計

### 📊 效能表現

| 執行緒數 | 預估速度 | 2026 年全年耗時（約 250 天） |
|---------|---------|---------------------------|
| 1 個 | 0.5 秒/天 | ~2 分鐘 |
| 3 個（預設） | 0.2 秒/天 | ~50 秒 |
| 5 個 | 0.15 秒/天 | ~40 秒 |
| 10 個 | 0.1 秒/天 | ~25 秒 |

## 📋 參數說明

### 必選參數（擇一）

| 參數 | 說明 | 範例 |
|------|------|------|
| `--year` | 收集整年資料 | `--year 2026` |
| `--start` + `--end` | 收集指定日期範圍 | `--start 2026-01-01 --end 2026-12-31` |

### 可選參數

| 參數 | 說明 | 預設值 | 範例 |
|------|------|--------|------|
| `--workers` | 平行執行緒數量 | 3 | `--workers 5` |
| `--force` | 強制重新收集（覆蓋已存在檔案） | False | `--force` |

## 🔍 執行結果說明

### 狀態類型

| 狀態 | 圖示 | 說明 |
|------|------|------|
| **成功** | ✅ | 成功收集並儲存資料 |
| **跳過** | ⏭️ | 檔案已存在，跳過收集 |
| **無資料** | ⚠️ | API 回傳無資料（可能是非交易日或流動性不足） |
| **錯誤** | ❌ | 收集過程發生錯誤 |

### 統計資訊

執行完成後會顯示：
- **總交易日**: 需要處理的交易日總數
- **成功**: 成功收集的天數
- **跳過**: 因檔案已存在而跳過的天數
- **無資料**: API 無資料的天數
- **錯誤**: 發生錯誤的天數
- **耗時**: 總執行時間
- **平均**: 每天平均處理時間

## ⚙️ 效能調優

### 執行緒數量建議

| 網路環境 | 建議執行緒數 | 說明 |
|---------|------------|------|
| 一般家用網路 | 3-5 | 平衡速度與穩定性 |
| 高速網路 | 5-10 | 充分利用頻寬 |
| 伺服器環境 | 10-20 | 最大化效率 |

### 注意事項

1. **不建議超過 20 個執行緒** - 可能觸發 API 限制
2. **網路不穩定時減少執行緒** - 避免過多連線失敗
3. **首次收集建議使用較少執行緒** - 測試穩定性

## 🛠️ 故障排除

### 問題 1: 部分日期無資料

**現象**: 顯示 `⚠️ 無資料`

**可能原因**:
- 該日為非交易日（交易日曆尚未更新）
- 個股期貨當日無成交（流動性不足）

**解決方式**:
- 確認是否為交易日
- 檢查 TAIFEX API 是否有該日資料

### 問題 2: 收集錯誤

**現象**: 顯示 `❌ 錯誤`

**可能原因**:
- 網路連線問題
- API 暫時無法存取
- 磁碟空間不足

**解決方式**:
- 檢查網路連線
- 稍後重新執行（會自動跳過已收集的日期）
- 檢查磁碟空間

### 問題 3: 執行速度慢

**現象**: 平均處理時間 > 1 秒/天

**解決方式**:
- 增加執行緒數量 `--workers 10`
- 檢查網路速度
- 確認 API 是否正常

## 🔄 中斷續傳

腳本支援中斷續傳功能：

1. **中斷執行** - 按 `Ctrl+C` 中斷
2. **重新執行** - 再次執行相同指令
3. **自動跳過** - 已收集的資料會自動跳過

範例：
```bash
# 第一次執行（收集到一半中斷）
./scripts/data-collector/backfill_stock_futures.sh 2026
^C  # 按 Ctrl+C 中斷

# 重新執行（自動從中斷處繼續）
./scripts/data-collector/backfill_stock_futures.sh 2026
# 會自動跳過已收集的日期
```

## 🎯 最佳實踐

### 建議流程

1. **先測試小範圍** - 收集一週資料測試
   ```bash
   ./scripts/data-collector/backfill_stock_futures.sh 2026-03-01 2026-03-07
   ```

2. **確認無誤後收集全年**
   ```bash
   ./scripts/data-collector/backfill_stock_futures.sh 2026
   ```

3. **定期更新** - 每週執行一次補齊最新資料
   ```bash
   # 補齊最近一個月
   ./scripts/data-collector/backfill_stock_futures.sh 2026-03-01 2026-03-31
   ```
