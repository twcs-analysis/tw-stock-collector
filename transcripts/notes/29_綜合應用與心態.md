## 📌 核心重點

### 1. 投資心態的建立

#### 不要讓股票成為包袱
- **心理壓力**: 套牢後的包袱比賠錢更嚴重
- **影響生活**: 晚上睡不著，白天一直想
- **解決方法**: 該斷則斷，小賠時就停損
- **心態調整**: 做股票應該是愉快的，不是沉重的負擔

#### 盤勢好壞的相對性
- **紀律操作者**: 盤跌 = 機會（滿地便宜標的）
- **套牢者**: 盤跌 = 痛苦（不知何時回本）
- **差異**: 有無遵守紀律

#### 學習的重要性
- **不要急**: 不要還沒學會就急著進場
- **基本功**: 回歸基礎學習（頭頭高底底高）
- **靜下心**: 盤勢不好正是靜心學習的時候

### 2. 選股五大步驟

#### 步驟一：選股（最重要）
- **重要性**: 選股是第一個基本功，成功一半
- **邏輯**: 股票好，容易漲；即使進場不精準，還是會賺錢
- **原則**: 一定要先把選股練好

#### 步驟二：進場
- **時機**: 在哪個位置進場才比較容易獲利
- **方法**: 回後買上漲、盤整突破

#### 步驟三：停損
- **重要性**: 進場就要設停損
- **目的**: 保護資金，避免大賠

#### 步驟四：停利
- **時機**: 到達目標價或出現反向訊號
- **方法**: 分批停利或一次出場

#### 步驟五：資金管理
- **分配**: 不要單押一檔
- **控制**: 依風險分配資金比例

### 3. 從上到下選股法（三好原則）

#### 第一層：國際盤好（大環境）
- **美股**: 對全世界影響最大
- **亞股**: 尤其是韓國（與台灣產業結構相似）
- **邏輯**: 美股跌 → 台股外資賣 → 個股漲不動
- **策略**: 美股不好時，不要隨便買股票

#### 第二層：台股類股好（中環境）
- **為什麼看類股**:
  - 1700多檔個股太多，無法全看
  - 類股好 → 裡面的個股大部分都漲

- **如何找類股**:
  - 盤中看類股漲跌幅排行
  - 觀察哪些類股連續幾天都是紅的
  - 例如：油電燃氣、化工類股強，半導體弱

- **領頭羊策略**:
  - 每個類股抓2檔領頭羊
  - 領頭羊 = 最早完成多頭的股票
  - 3個類股 × 2檔 = 6檔可操作標的

#### 第三層：個股趨勢好（小環境）
- **最終確認**: 確認個股本身的趨勢
- **工具**: 六字訣判斷

### 4. 趨勢判斷六字訣

#### 多頭：頭頭高、底底高
- **頭頭高**: 最近兩個高點，後面比前面高
- **底底高**: 最近兩個低點，後面比前面高
- **重點**:
  - 六個字要全部符合，不能只有一半
  - 看「最後兩個」高低點，不看前面的

#### 空頭：頭頭低、底底低
- **頭頭低**: 最近兩個高點，後面比前面低
- **底底低**: 最近兩個低點，後面比前面低
- **操作**: 放空或觀望

#### 盤整：頭頭低或底底高（不完整）
- **頭頭低 + 底底高**: 盤整
- **操作**: 等突破或跌破再動作

### 5. 進場前六問（六六大順）

#### 問一：趨勢是否為多？
- **檢查**: 現在還是多頭嗎？
- **注意**: 選股時是多，進場時可能已變盤整或空頭

#### 問二：位置是否在起漲點？
- **兩個位置**:
  1. 回後買上漲（回檔後上漲，但不能破前低）
  2. 盤整突破
- **避免**: 已經衝很高、連漲很多天

#### 問三：均線有沒有做好？
- **多頭排列**: 短均線在上，長均線在下（5 > 10 > 20）
- **股價位置**: 股價在均線上方，不是下方
- **成功率**: 前三個都合格，成功率約60%

#### 問四：價量有沒有配合？
- **多頭價量**: 價漲量增、價跌量縮
- **進場量能**: 進場當天有沒有放量
- **成功率**: 加上這個約70%

#### 問五：進場的紅K好不好？
- **標準**:
  - 站上5日均線
  - 突破昨天K線最高點（轉強）
- **成功率**: 加上這個更高

#### 問六：指標是否配合？
- **多頭指標**:
  - KD黃金交叉
  - MACD黃金交叉、綠轉紅、或紅柱延長
- **成功率**: 六個都符合，成功率約80%

### 6. 看圖訓練（5秒判斷法）

#### 不符合範例
- **快速判斷**: 看到底底低，立即放棄
- **理由**: 不是多頭股票，不浪費時間
- **即使**: 當天有大紅K也不看

#### 符合範例（六問全過）
1. **趨勢**: 頭頭高、底底高（今天才頭頭高，起漲點）
2. **位置**: 起漲位置
3. **均線**: 5、10、20、60四線多排，股價在上
4. **價量**: 放大量（是昨天的一倍）
5. **紅K**: 實體棒收盤確認
6. **指標**: KD黃金交叉、MACD紅柱延長

## 💡 實戰案例重點

### 案例一：塑膠類股（多頭確認）
- **檢查高低點**:
  - 高點、高點、高點 → 一個比一個高
  - 低點、低點、低點 → 後面的最高
  - 看最後兩個：頭頭高、底底高 ✓

- **前面為何不做**:
  - 前面是底底低、頭頭低 → 空頭
  - 還沒轉成多頭

- **何時開始做**:
  - 這裡底底高，這段才開始做
  - 變多頭了

### 案例二：鋼鐵類股（不符合）
- **檢查結果**:
  - 還沒有頭頭低
  - 但已經底底低了 ✗

- **結論**: 不做
- **原則**: 一定要頭頭高+底底高，六個字都要有

### 案例三：功力深厚的5秒看圖
- **第一眼**: 看趨勢（頭頭低底底低？）
- **不符合**: 2秒就不看了
- **符合**: 再依序檢查六問
- **效率**: 大量過濾，只留最好的

## 🎯 技術分析 Prompt

### 基礎檢查 Prompt（六字訣）
```
請分析 {股票代號} 的趨勢狀態：
1. 最近兩個高點在哪？後面的高點比前面高（頭頭高）還是低（頭頭低）？
2. 最近兩個低點在哪？後面的低點比前面高（底底高）還是低（底底低）？
3. 綜合判斷：目前是多頭（頭頭高底底高）、空頭（頭頭低底底低）、還是盤整（不完整）？
4. 如果是多頭，前面是從何時開始轉多的？
5. 如果是空頭或盤整，不適合做多，建議觀望。
```

### 進階分析 Prompt（進場六問）
```
請針對 {股票代號} 進行進場六問分析：

**第一問：趨勢是否為多？**
1. 最近兩個高點、低點的趨勢結構？
2. 是否為「頭頭高、底底高」的多頭？

**第二問：位置是否在起漲點？**
3. 目前是在哪個位置？
   - 回後買上漲（回檔後再上漲）？
   - 盤整突破？
   - 還是已經漲很高？
4. 如果是回後買，前低有沒有跌破？

**第三問：均線有沒有做好？**
5. 5日、10日、20日均線的排列順序？
6. 是否為多頭排列（5 > 10 > 20）？
7. 股價是在均線上方還是下方？

**第四問：價量有沒有配合？**
8. 最近的價量關係：價漲量增？價跌量縮？
9. 進場當天（或最近一天）是否放量？
10. 成交量與5日均量的比較？

**第五問：進場的紅K好不好？**
11. 最新紅K是否站上5日均線？
12. 最新紅K是否突破前一天的最高點？
13. 紅K的實體棒是否夠長（不是十字星或小紅）？

**第六問：指標是否配合？**
14. KD指標狀態：黃金交叉？數值多少？
15. MACD狀態：黃金交叉？綠轉紅？紅柱延長？
16. 指標是否在低檔或中檔（避免高檔鈍化）？

**綜合評分**:
17. 六問中符合幾項？
18. 成功率預估？（3項60%，4項70%，6項80%）
19. 建議操作：進場/觀望/等更好時機？
20. 如果進場，停損點設在哪？目標價多少？
```

### 批量篩選 Prompt（三好+六問）
```
請篩選符合三好原則與進場六問的台股標的：

**第一層：類股篩選**
- 最近3-5日漲幅前10名的類股
- 排除跌幅前10名的類股

**第二層：個股趨勢篩選**
- 符合「頭頭高、底底高」的多頭趨勢
- 最近才剛確認多頭（頭頭高在5日內發生）

**第三層：進場六問篩選**
必須符合以下條件：
1. ✓ 多頭趨勢確認
2. ✓ 在起漲點（回後買上漲或盤整突破）
3. ✓ 均線多頭排列（5>10>20），股價在均線上
4. ✓ 價漲量增（今日量能 > 5日均量）
5. ✓ 紅K站上5MA且突破前高
6. ✓ KD黃金交叉或MACD轉強

**輸出格式**:
請提供符合的股票，並註明：
- 股票代號、名稱
- 所屬類股
- 符合六問中的幾項
- 成功率預估
- 建議進場價位
- 停損價位
- 短期目標價

**限制條件**:
- 排除：已連續上漲5天以上（避免追高）
- 排除：KD值 > 80（避免高檔）
- 排除：股價已遠離均線（乖離過大）
```

### 回測驗證 Prompt（六問策略）
```
請回測 {股票代號} 在 {起始日期} 到 {結束日期} 期間的六問策略：

**策略規則**:
- 進場：符合進場六問（可設定至少符合N項）
- 停損：跌破進場紅K低點或5日均線
- 停利：KD死叉或其他反向訊號

**分級測試**:
- 情境A：符合3項就進場（趨勢+位置+均線）
- 情境B：符合4項就進場（+價量）
- 情境C：符合5項就進場（+紅K）
- 情境D：符合6項才進場（+指標）

**分析項目**:
- 各情境的進場次數
- 勝率（獲利次數/總次數）
- 平均獲利率、平均虧損率
- 最大獲利、最大虧損
- 平均持有天數
- 成功率與符合項目數的關係

**單一條件測試**:
- 哪一問最重要？（移除該條件後勝率下降最多）
- 哪一問最不重要？（移除該條件後勝率影響最小）
- 最佳組合是什麼？

**優化建議**:
- 是否需要全部六問都符合？還是部分即可？
- 哪些條件可以放寬？哪些必須嚴格？
- 不同市場環境（多頭/空頭/盤整）的最佳策略？
```

## 📚 延伸學習

### 選股體系深化
- **類股輪動**: 觀察類股強弱變化
- **領頭羊識別**: 如何找到類股中的最強股
- **強勢股排行**: 榮耀班進階教學

### 趨勢判斷進階
- **趨勢轉換**: 如何判斷從空頭轉多頭
- **假突破**: 頭頭高後又變頭頭低
- **混合趨勢**: 日線多頭、週線空頭的處理

### 位置判斷精進
- **回後買上漲**: 回檔的標準（不破前低）
- **盤整突破**: 三角收斂、矩形突破
- **起漲點**: 底部完成、突破頸線

### 資金管理
- **分批建倉**: 不要單筆全押
- **風險控制**: 單一標的不超過總資金X%
- **停損停利**: 嚴格執行，不凹單

### 心態修煉
- **紀律第一**: 訊號來就做，沒訊號就等
- **不抱希望**: 套牢不等反彈，該停損就停損
- **愉快投資**: 不讓股票成為生活負擔
