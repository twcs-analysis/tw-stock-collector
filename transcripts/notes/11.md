## 📌 核心重點

### 1. 形態學的基本概念
- **定義**: 形態即是「盤整」所形成的固定圖形
- **基礎**: 源自歐美股市幾百年的大數據統計
- **功能**: 可推測未來股價走勢並計算目標價
- **分類**:
  - **反轉形態**: 底部反轉向上、頂部反轉向下
  - **續勢形態**: 盤整後繼續原方向

### 2. 學習形態的四個心法
1. **並非 100%**: 形態是大數法則，不是絕對（通常 90% 成功率，仍有 10% 失敗率）
2. **風險控管**: 即使找到好形態，停損仍要做好
3. **有目標價**: 形態可計算統計目標價，作為操作參考
4. **日線與週線搭配**: 看週線定目標，回日線做操作

### 3. N字底的定義與特徵
- **勝率**: 高達九成（遠高於 W 底的四成）
- **性質**: 底部反轉形態（不是中繼）
- **形象**: 像爬樓梯一樣，一上一回、底底高

### 4. N字底的構成要件

#### 第一支腳（低腳）
- **定義**: 空頭中的任何反彈
- **特徵**:
  - 低檔出現大量成交
  - 長紅 K 反彈
  - 突破 5 日均線
  - 突破昨天最高點

#### 第二支腳（高腳）- 關鍵
- **條件**:
  - 反彈後回跌「不破前低」
  - 下跌不能超過反彈幅度的「二分之一」
  - 出現紅 K 止跌轉折向上
  - 突破第一支腳的高點（上頸線）
- **重要**: 必須是「高腳」，不能是低腳或平腳（否則變 W 底）

### 5. 操作策略

#### 試單時機
- **位置**: 第二支腳出現（回跌未破二分之一，紅 K 上來）
- **比例**: 預計買 3 張先買 1 張試單
- **原因**: 90% 成功率，值得提前布局
- **停損**: 第二支腳的低點不要破

#### 確認加碼
- **時機**: 突破上頸線（形態確認）
- **停損**: 買進 K 線不要跌破

### 6. 目標價計算：正波段預測法
- **公式**: 第二段漲幅 = 第一段漲幅（等幅概念）
- **範例**:
  - 第一段從 100 漲到 120（漲 20 元）
  - 回測到 110
  - 目標價 = 110 + 20 = 130 元
- **注意**: 目標價是參考，可能超過也可能未達

### 7. 選股技巧
- **原則**: 選擇第一段反彈幅度大的 N 字底
- **原因**: 第一段越大，第二段等幅空間越大
- **避免**: 反彈幅度小（如 2-3 元）的 N 字底，獲利空間有限

## 💡 實戰案例重點

### 案例一: 標準 N 字底
- **第一支腳**: 空頭反彈，站上 5 日均線，形成上頸線
- **回跌**: 跌破 5 日線但未破二分之一
- **第二支腳**: 紅 K 上來，突破上頸線
- **結果**: 形態確認後大漲

### 案例二: 大幅反彈的 N 字底
- **特徵**: 第一段反彈十幾天到二十天，幅度大
- **操作**:
  1. 預先畫好二分之一線鎖股觀察
  2. 紅 K 出現立即試單
  3. 突破確認加碼
- **優勢**: 目標價空間大，值得操作

### 案例三: 小幅反彈的 N 字底
- **特徵**: 雖符合 N 字底定義，但反彈幅度小
- **問題**: 目標價空間小，操作辛苦
- **結論**: 雖會到目標價，但獲利有限

### 案例四: 非 N 字底辨識
- **情況**: 底部後的多頭回檔再上漲
- **特徵**: 回檔未達二分之一就上去
- **判斷**: 不是 N 字底，不能用等幅算目標價
- **操作**: 仍可做「多頭回後買」，但無目標價參考

## 🎯 技術分析 Prompt

### 基礎檢查 Prompt
```
請分析 {股票代號} 是否出現 N 字底形態：

**第一支腳檢查**:
1. 是否在空頭趨勢中出現反彈？
2. 反彈是否帶大量長紅 K？
3. 是否突破 5 日均線？
4. 反彈幅度有多少？

**第二支腳檢查**:
5. 反彈後回跌是否「未破前低」？
6. 回跌幅度是否「未超過反彈幅度的二分之一」？
7. 是否出現止跌紅 K 向上？
8. 目前距離突破第一支腳高點（上頸線）還有多遠？

**形態判斷**:
9. 是否已形成標準 N 字底？
10. 目前處於哪個階段（第一腳/回測/第二腳/突破）？
```

### 進階分析 Prompt
```
請針對 {股票代號} 進行 N 字底深度分析：

**形態完整度**:
1. 第一支腳的起點、高點、反彈幅度各為多少？
2. 回測低點為多少？是否高於第一支腳起點？
3. 回測幅度是反彈幅度的幾分之幾（必須小於 1/2）？
4. 上頸線（第一支腳高點）價位為何？

**目標價計算**:
5. 使用正波段預測法，目標價應為多少？
6. 計算公式：回測低點 + 第一段反彈幅度 = ?

**操作建議**:
7. 目前是否適合試單？（第二支腳出現但未突破）
8. 突破上頸線的價位為何？（確認加碼點）
9. 停損點建議設在哪裡？
10. 若按目標價計算，潛在報酬率為多少？

**品質評估**:
11. 第一段反彈幅度是否夠大（是否值得操作）？
12. 成交量配合度如何？
13. 是否有配合均線多排？
14. N 字底的強度評分（1-10 分）？
```

### 批量篩選 Prompt
```
請篩選符合以下 N 字底條件的台股標的：

**基本條件**:
- 空頭趨勢中已出現第一支腳反彈
- 反彈幅度大於 10%
- 目前處於回測階段或第二支腳形成階段
- 回測未破前低且未超過反彈幅度的 1/2

**進階篩選**:
- 第一段反彈幅度 > 15%（優質標的）
- 第二支腳已出現紅 K 向上
- 距離突破上頸線不到 5%
- 成交量配合（第一腳有大量）

**輸出資訊**:
- 股票代號與名稱
- 第一支腳反彈幅度
- 目前所處階段
- 上頸線價位
- 預估目標價
- 潛在報酬率

請依「接近突破」優先排序
```

### 回測驗證 Prompt
```
請回測 {股票代號} 在 {起始日期} 到 {結束日期} 期間的 N 字底策略表現：

**策略規則**:
1. 試單: 第二支腳出現（未破 1/2、紅 K 向上）時買進 1/3 部位
2. 加碼: 突破上頸線時加碼到滿倉
3. 停損: 跌破第二支腳低點
4. 停利: 到達目標價（第一段等幅）

**統計分析**:
- 期間內出現幾次 N 字底？
- 形態確認（突破上頸線）的成功率？
- 平均從確認到達目標價的天數？
- 平均報酬率（從試單點/確認點/到目標價）？
- 最大報酬與最大虧損？
- 失敗案例的特徵（為何未達標）？

**優化建議**:
- 哪些條件可提高勝率（量、均線、產業等）？
- 試單與確認進場的報酬差異？
- 目標價是否常被超越？是否該調整目標？
```

## 📚 延伸學習

### 與其他形態比較
- **W 底**: 勝率僅 4 成，需配合均線多排
- **頭肩底**: 後續課程（EP12）
- **圓弧底**: 後續課程（EP14）
- **三重底**: 變形底部形態

### 進階技巧
1. **週線 N 字底**: 目標價更大，但需回日線操作
2. **N 字底 + 均線多排**: 提高勝率
3. **N 字底 + 量價配合**: 確認主力介入
4. **多頭中的 N 字底**: 非底部反轉，是回檔買點

### 常見錯誤
1. **誤把 W 底當 N 字底**: 第二腳未高於二分之一
2. **試單不設停損**: 仍有 10% 失敗率
3. **目標價當絕對值**: 可能超越或未達，需配合紀律
4. **忽略第一段幅度**: 選到獲利空間小的標的
