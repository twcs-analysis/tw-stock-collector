## 📌 核心重點

### 1. 缺口的定義
- **向上跳空缺口**: 今天的最低價 > 昨天的最高價，中間形成價格空白區
- **向下跳空缺口**: 今天的最高價 < 昨天的最低價，中間形成價格空白區
- **本質**: 該價格區間「沒有任何成交」，代表買賣力量極度失衡

### 2. 缺口產生的原因
1. **利多利空消息**: 消息面反映（影響 1-2 天）
2. **主力發動（最重要）**: 主力刻意操作的強烈訊號
   - 向上跳空: 主力拉抬，不讓低價買進
   - 向下跳空: 主力出貨或殺盤

### 3. 缺口的三大訊號特性
1. **主力的強力訊號**
   - 高檔向下: 主力跑了
   - 盤整突破: 主力要突破了
2. **力量比長紅、長黑更強**: 跳空缺口的動能大於一般長紅/黑 K
3. **決定操作方向**: 給出明確的做多或做空訊號

### 4. 四大缺口類型

#### (1) 普通缺口（Common Gap）
- **位置**: 盤整區內
- **特徵**: 力量普通，通常很快被補掉
- **意義**: 可能是小利多/利空，但未突破盤整
- **操作**: 不具參考價值，可忽略

#### (2) 突破缺口（Breakaway Gap）
- **位置**: 突破盤整區或壓力/支撐位
- **特徵**:
  - 起漲或起跌的關鍵位置
  - 成交量通常放大
  - 缺口不易被補回
- **意義**: **最棒的缺口！** 多頭確認或空頭確認的訊號
- **操作**:
  - 向上突破: 積極做多
  - 向下突破: 趕快賣出或做空

#### (3) 逃逸缺口（Runaway Gap / 量測缺口 / 中繼缺口）
- **位置**: 已經漲（跌）一波後，中途再次跳空
- **特徵**:
  - 出現在主升段（或主跌段）
  - 代表主力還要再攻一波
  - 後續漲幅大約等於初升段幅度
- **意義**: 趨勢延續的強烈訊號
- **操作**: 順勢加碼或持股不動

#### (4) 竭盡缺口（Exhaustion Gap / 消耗缺口）
- **位置**: 末升段（或末跌段）高檔或低檔
- **特徵**:
  - **爆大量紅 K（或黑 K）**
  - **在高檔（或低檔）**
  - **三天內缺口被補掉**
- **意義**: 行情尾聲，即將反轉
- **操作**:
  - 高檔竭盡: 趕快賣出，準備做空
  - 低檔竭盡: 空單回補，準備做多

### 5. 缺口的力量判斷

**判斷缺口強弱的兩大要素:**
1. **成交量**: 量越大，力量越大
2. **缺口大小**:
   - 漲停板缺口: 最強（向上）
   - 跌停板缺口: 最弱（向下）

### 6. 容易上漲的缺口位置

1. **多頭回檔起漲點**: 回檔到支撐後大量跳空，容易連續拉抬
2. **突破盤整區**: 跳空突破比長紅突破更強
3. **跳空過壓力**: 主力一次跳空越過壓力線，表態要讓股價噴發

### 7. 容易下跌的缺口位置

1. **高檔竭盡缺口**: 爆大量紅 K 但不漲，缺口一補就下來
2. **高檔壓力開低跳空**: 碰到壓力後第二天向下跳空，趕快走
3. **空頭反彈後向下跳空**: 反彈到壓力後再跳空下殺

### 8. 缺口的支撐與壓力作用

- **向上跳空缺口 = 支撐**: 站上後不易跌破，一旦補掉可能轉弱
- **向下跳空缺口 = 壓力**: 跌破後不易站回，一旦補掉可能轉強

## 💡 實戰案例重點

### 案例 1: 聯發科
- **向下缺口**: 股價下跌時出現跳空，空頭訊號
- **向上缺口**: 股價上漲時出現跳空，多頭訊號
- **結論**: 缺口方向決定操作方向

### 案例 2: 台積電
- **連續跳空**: 三天上漲中有兩天用跳空，展現強勢
- **操作**: 看到跳空突破，要趕快進場，不要怕

### 案例 3: 完整趨勢線圖解析

**空頭階段:**
1. 下跌一大段後出現「極跌」→ 低檔竭盡缺口
2. 空單準備回補

**反彈階段:**
3. 跌深反彈出現跳空 → 反彈力道強
4. 做空的要趕快補，不然會被軋

**底部階段:**
5. 反彈完開始打底（底底高、頭頭高）
6. 出現大量跳空突破 → **多頭確認的突破缺口**
7. **從此以後要做多！**

**主升段:**
8. 走了一波後主力又用跳空攻 → 逃逸缺口
9. 代表還有一段漲幅
10. 判斷不是竭盡缺口的原因: 後面沒有補掉，還繼續漲

**末升段:**
11. 股價已漲一倍（從 16 元到 34 元）
12. 高檔爆大量紅 K
13. 隔兩天黑 K 跌下來把缺口補了 → **竭盡缺口**
14. 容易轉成空頭

## 🎯 技術分析 Prompt

### 基礎檢查 Prompt
```
請分析 {股票代號} 最近的跳空缺口狀態：
1. 最近 5 個交易日是否出現跳空缺口？方向為何（向上/向下）？
2. 缺口的大小為何？（以點數或百分比表示）
3. 缺口出現時的成交量是放大還是縮小？
4. 缺口是否已被補掉？
5. 結合目前股價位置（低檔/中檔/高檔），判斷這是哪種類型的缺口？
   - 普通缺口
   - 突破缺口
   - 逃逸缺口（量測缺口）
   - 竭盡缺口
```

### 進階分析 Prompt
```
請針對 {股票代號} 進行跳空缺口深度分析：

**趨勢與位置判斷**:
1. 目前處於多頭、空頭、還是盤整？
2. 股價位於趨勢的哪個階段？（初升段/主升段/末升段 或 初跌段/主跌段/末跌段）
3. 最近的缺口出現在盤整突破、趨勢中段、還是高低檔位置？

**缺口特徵分析**:
4. 缺口大小占股價的百分比？
5. 缺口出現時的成交量相較於平均量的倍數？
6. 缺口出現後的 K 線形態（長紅/長黑/十字線等）？
7. 缺口是否有被測試或回補的跡象？

**類型判斷**:
8. 根據位置、量能、後續走勢，判斷為：
   - 突破缺口（最強）
   - 逃逸缺口（趨勢延續）
   - 竭盡缺口（是否符合「爆量+高檔+三天內補掉」特徵）
   - 普通缺口（可忽略）

**操作建議**:
9. 如果是向上突破缺口，是否應積極做多？進場點與停損點建議？
10. 如果是竭盡缺口，是否應準備出場或反向操作？
11. 缺口是否具備支撐或壓力作用？關鍵價位為何？

**風險評估**:
12. 目前追高或殺低的風險程度？
13. 是否有假突破的可能性？
```

### 批量篩選 Prompt
```
請篩選符合以下跳空缺口條件的台股標的：

**多頭突破缺口篩選**:
- 近 3 日內出現向上跳空缺口
- 缺口大小 > 2%
- 成交量放大（大於 20 日均量 1.5 倍以上）
- 突破盤整區或壓力線
- 缺口尚未被補回
- 股價在缺口之上站穩

**逃逸缺口篩選（趨勢延續）**:
- 股價已上漲一段（如 20 日內漲幅 > 15%）
- 中途再次出現向上跳空
- 成交量持續放大
- 未出現竭盡缺口特徵

**竭盡缺口警示篩選（可能反轉）**:
- 高檔（如股價創近期新高）出現向上跳空
- 爆出近期最大量
- 缺口在 3 日內被補回 50% 以上
- K 線出現長上影或吞噬型態

請提供：股票代號、名稱、缺口日期、缺口大小、成交量變化、缺口類型判斷
```

### 回測驗證 Prompt
```
請回測 {股票代號} 在 {起始日期} 到 {結束日期} 期間的跳空缺口策略表現：

**策略規則**:
1. 買進:
   - 突破缺口出現（向上跳空 > 2% + 量能放大 + 突破盤整）
   - 逃逸缺口出現（趨勢中段向上跳空）
2. 賣出:
   - 竭盡缺口出現（高檔爆量 + 3 日內補掉）
   - 或跌破缺口支撐

**分析項目**:
- 總共出現幾次跳空缺口？各類型缺口的次數？
- 突破缺口的勝率與平均報酬？
- 逃逸缺口後的延續漲幅？
- 竭盡缺口出現後的反轉準確度？
- 缺口被補回後的走勢變化？

**進階分析**:
- 哪些缺口是假突破？特徵為何？
- 缺口大小與後續漲跌幅的相關性？
- 量能大小對缺口有效性的影響？
- 不同市場環境（多頭/空頭/盤整）下缺口的表現差異？

**改進建議**:
- 如何提高突破缺口的辨識準確度？
- 如何及早識別竭盡缺口避免套在高點？
- 是否應結合其他指標（如 KD、均線、趨勢線）提高勝率？
```

## 📚 延伸學習

### 與其他技術分析結合
- **趨勢線**: 判斷缺口是否突破關鍵趨勢線（前幾集課程）
- **支撐壓力**: 跳空過壓力的力道更強（朱老師教過）
- **均線系統**: 缺口配合均線多頭排列效果更好
- **成交量**: 量價配合判斷缺口真假

### 缺口的進階應用
1. **缺口理論與波浪理論結合**:
   - 突破缺口 = 第三波起漲
   - 逃逸缺口 = 第三波中段
   - 竭盡缺口 = 第五波尾聲
2. **島狀反轉**: 兩個反向缺口形成的孤島型態
3. **缺口群**: 連續多個缺口代表極強勢或極弱勢

### 注意事項
1. **缺口一定要配合趨勢判斷**: 不能單看缺口，要看整體趨勢
2. **普通缺口不具參考價值**: 盤整中的小缺口可忽略
3. **竭盡缺口的三要素缺一不可**: 爆量 + 高檔 + 三天內補掉
4. **利多利空的缺口影響短暫**: 主力發動的缺口才是重點
