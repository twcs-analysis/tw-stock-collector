## 📌 核心重點

### 1. MACD 指標基本概念
- **定義**: 利用均線差異判斷趨勢轉折的技術指標
- **別稱**: 命運紅綠燈（紅柱綠柱決定進出場）
- **功能**: 看長線趨勢，適合抱波段，不易錯過大行情

### 2. MACD 四大組成元素

#### (1) DIF 線（快線/紅線）
- **公式**: 12 日均線 - 26 日均線
- **意義**: 短期趨勢線
- **參數建議**: 可改為 10-20（符合現代交易週期）

#### (2) MACD 線（慢線/藍線）
- **公式**: DIF 的 9 日平均值
- **意義**: 長期趨勢線（更慢、更穩定）

#### (3) 紅柱與綠柱（柱狀體）
- **公式**: DIF - MACD
- **紅柱**:
  - DIF > MACD（快線在上）
  - 代表上漲動能
  - 柱子越長 = 動能越強
  - **紅柱縮短** = 動能衰退，準備回檔
- **綠柱**:
  - DIF < MACD（快線在下）
  - 代表下跌動能
  - 柱子越長 = 跌勢越兇
  - **綠柱縮短** = 下跌減緩，準備反彈

#### (4) 零軸（多空分界線）
- **零軸之上**: 多頭趨勢 → 做多不做空
- **零軸之下**: 空頭趨勢 → 做空不做多
- **穿越零軸**: 趨勢轉折的重要訊號

### 3. 買賣訊號判斷

#### 多頭操作（零軸之上）
| 訊號 | 意義 | 操作 |
|------|------|------|
| 兩條線上零軸 | 趨勢轉多 | 開始關注做多機會 |
| 綠柱縮短 | 回檔結束 | 準備買進 |
| 黃金交叉 | 確認上漲 | 買進確認 |
| 紅柱縮短 | 動能衰退 | 準備賣出 |
| 死亡交叉 | 轉為下跌 | 賣出 |

#### 空頭操作（零軸之下）
| 訊號 | 意義 | 操作 |
|------|------|------|
| 兩條線下零軸 | 趨勢轉空 | 只做空不做多 |
| 紅柱縮短 | 反彈結束 | 準備放空 |
| 死亡交叉 | 確認下跌 | 放空 |
| 綠柱縮短 | 跌勢減緩 | 空單回補（不做多）|

### 4. 動能概念（氣象預報）
- **紅柱 = 上漲動能**: 越長越強，縮短表示動能衰退
- **綠柱 = 下跌動能**: 越長越兇，縮短表示跌勢減緩
- **提前預知**: 柱子縮短是「提前訊號」，不用等交叉
- **比喻**: 像天氣預報，烏雲密布要準備雨傘（提前準備）

### 5. MACD 與 KD 的搭配使用

| 指標 | 用途 | 週期 | 適用場景 |
|------|------|------|----------|
| **KD** | 短線進出 | 9 日 | 抓起漲點、判斷過熱 |
| **MACD** | 長線趨勢 | 10-20 日 | 抱波段、避免被洗出 |

#### 搭配策略
1. **進場**: 用 KD 抓起漲點（KD 黃金交叉）
2. **續抱**: 用 MACD 看趨勢（零軸之上持續抱）
3. **短線修正**: KD 過熱回檔，心裡有數但不出場
4. **出場**: MACD 死亡交叉或跌破零軸

### 6. 三大盲點叮嚀
1. **MACD 是長趨勢參考，不適合做短線**
   - 黃金交叉/死亡交叉常會落後
   - 短線進出要看「柱子縮短」提前佈局

2. **必須配合多空趨勢判斷**
   - 股價要完成多頭排列或空頭排列
   - 盤整時 MACD 容易失真

3. **不能只看單一指標**
   - 所有指標都成立才進場 = 行情快結束
   - 要靈活運用，不同指標搭配使用

## 💡 實戰案例重點

### 案例: 今年操作績效最好的股票
**操作流程**:
1. **趨勢確認**:
   - 股價完成多頭盤整突破（頭頭高、底底高）
   - MACD 兩條線從零軸下翻到零軸上 → 趨勢轉多

2. **買進時機**:
   - 綠柱縮短（回檔減緩）
   - 準備黃金交叉（雖然會晚 2 天）
   - 如果 KD 已經黃金交叉 → 可以提前買

3. **續抱策略**:
   - 只要 MACD 在零軸上就持續抱
   - 紅柱縮短 → 短線會回檔（心裡有數）
   - 綠柱縮短 → 回檔結束，繼續抱

4. **賣出時機**:
   - 紅柱縮短變綠柱 → 死亡交叉 → 賣出
   - 或跌破零軸 → 趨勢轉空 → 賣出

**成果**: 一路抱到現在，獲利豐厚（抓住大波段）

## 🎯 技術分析 Prompt

### 基礎檢查 Prompt
```
請分析 {股票代號} 的 MACD 指標狀態：
1. MACD 的 DIF 線與 MACD 線目前在零軸之上或之下？
2. 目前是紅柱還是綠柱？柱子是在變長還是縮短？
3. 是否出現黃金交叉或死亡交叉？
4. 最近一次穿越零軸是往上還是往下？
5. 結合零軸位置，目前應該做多還是做空？
```

### 進階分析 Prompt
```
請針對 {股票代號} 進行 MACD 指標深度分析：

**趨勢判斷**:
1. MACD 兩條線是在零軸之上（多頭）還是之下（空頭）？
2. 最近一次穿越零軸的時間與股價位置？
3. 股價是否已完成多頭排列（頭頭高、底底高）或空頭排列？

**動能分析**:
4. 目前是紅柱還是綠柱？持續幾天了？
5. 柱子是在變長（動能增強）還是縮短（動能衰退）？
6. DIF 與 MACD 兩條線的距離是擴大還是縮小？

**訊號分析**:
7. 是否出現「綠柱縮短」（準備上漲）或「紅柱縮短」（準備下跌）？
8. 如果在零軸上，最近一次黃金交叉/死亡交叉發生在何時？
9. 是否有落後現象（股價已漲但 MACD 才要交叉）？

**KD 搭配**:
10. KD 指標目前狀態如何？是否過熱（>80）或超賣（<20）？
11. KD 與 MACD 訊號是否一致？
12. 如果 KD 已黃金交叉但 MACD 還沒，可以提前進場嗎？

**操作建議**:
13. 如果做多，目前應該「買進」、「續抱」、還是「觀望」？
14. 如果做空，目前應該「放空」、「續抱空單」、還是「回補」？
15. 給出具體的進出場時機與停損停利建議
```

### 批量篩選 Prompt
```
請篩選符合以下 MACD 條件的台股標的：

**多頭起漲訊號**:
- MACD 兩條線在零軸之上
- 綠柱縮短（近 3 日內）
- 或黃金交叉在近 5 日內發生
- 股價完成盤整突破

**空頭起跌訊號**:
- MACD 兩條線在零軸之下
- 紅柱縮短（近 3 日內）
- 或死亡交叉在近 5 日內發生
- 股價跌破盤整區

**趨勢轉折訊號**:
- 穿越零軸（向上或向下）
- 發生在近 10 日內

請提供股票代號、名稱、目前 MACD 狀態、柱子變化、訊號發生日期
```

## 📚 延伸學習

### MACD 參數優化
- **標準參數**: 12-26-9（傳統設定）
- **現代參數**: 10-20-9（符合週/月線）
- **短線參數**: 可嘗試 6-13-5（更敏感）

### 與其他指標結合
- **KD**: 短線進場，MACD 續抱（本集重點）
- **均線**: 多頭排列確認（5MA > 10MA > 20MA）
- **成交量**: 突破零軸時量能是否放大
- **背離**: 價格創新高但 MACD 未創新高（高檔背離）

### 進階技巧
1. **MACD 背離**:
   - 頂背離: 股價新高，MACD 未新高 → 準備下跌
   - 底背離: 股價新低，MACD 未新低 → 準備上漲

2. **零軸附近的操作**:
   - 零軸附近來回震盪 = 盤整，不操作
   - 突破零軸且站穩 = 趨勢確立

3. **柱子長度的意義**:
   - 柱子突然拉長 = 加速訊號
   - 柱子逐漸縮短 = 提前警示

## ⚠️ 使用注意事項

### MACD 的限制
1. **不適合短線**: 黃金交叉/死亡交叉會落後
2. **盤整時失效**: 零軸附近震盪，訊號不明確
3. **需搭配趨勢**: 必須先確認多頭/空頭排列
4. **參數影響**: 參數越大越遲鈍，越小越敏感

### 最佳使用時機
- 趨勢明確（多頭或空頭）
- 想抓大波段
- 避免被短線洗出
- 搭配 KD 找進場點

### 何時不用 MACD
- 盤整市場（零軸附近震盪）
- 想做當沖或極短線
- 股價波動劇烈（如妖股）
