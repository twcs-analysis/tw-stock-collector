## 📌 核心重點

### 1. 假反彈的基本概念

#### 什麼是誘多？
- **定義**: 當天大漲吸引散戶進場，隔天卻下跌套牢
- **目的**: 主力誘騙散戶接盤
- **特徵**: 今天K線漂亮，但位置不對、勝率很低
- **關鍵**: 不是看今天好不好，而是看整體趨勢好不好

#### 順勢 vs 逆勢
- **順勢操作**: 多頭趨勢中買進，即使不漲也可等待
- **逆勢操作**: 空頭趨勢中買進（搶反彈），不漲必須立即跑
- **風險差異**: 逆勢操作風險遠高於順勢
- **心態差異**: 順勢可以等，逆勢不能等

#### 勝率的重要性
- **技術操作**: 講求勝率，而非每次都對
- **位置決定勝率**: 好位置勝率高，差位置勝率低
- **重要支撐**: 跌破重要支撐後勝率大降
- **趨勢改變**: 趨勢改變後勝率結構完全不同

### 2. 第一種危險訊號：多頭回檔跌破月線

#### 形態特徵
- **趨勢**: 仍是多頭（頭頭高、底底高）
- **關鍵**: 跌破20日均線（月線）
- **訊號**: 出現反彈紅K
- **陷阱**: 看似回後買上漲，實則月線壓制

#### 為什麼不能買？
- **月線壓力**: 月線在上方壓著
- **套牢盤**: 近一個月買進者都在賠錢
- **解套賣壓**: 反彈到月線附近會出現解套賣壓
- **趨勢轉弱**: 雖仍多頭，但已轉弱

#### 操作策略
- **避免買進**: 月線下不宜買進
- **若已買進**: 遇到月線黑K立即出場
- **停損點**: 跌破月線後的反彈若失敗，前低跌破就停損
- **確認空頭**: 月線下彎 + 跌破前低 = 空頭確認

#### 後續演變
- **情況一**: 反彈到月線受壓 → 下跌 → 頭頭低形成
- **情況二**: 月線下彎 → 空頭確認
- **情況三**: 突破月線 → 多頭恢復（但需觀察）

### 3. 第二種危險訊號：跌破前低的反彈（逃命波）

#### 形態特徵
- **趨勢**: 多頭轉空頭（底底低）
- **關鍵**: 前低被跌破
- **訊號**: 跌深3-4天後反彈
- **本質**: 這是讓多單逃命的反彈

#### 為什麼叫逃命波？
- **錯過5日線**: 跌破5日均線時沒賣
- **錯過前低**: 跌破前低時還沒走
- **最後機會**: 反彈是給多單最後逃命的機會
- **勝率極低**: 八成不會突破前高

#### 操作策略
- **多單**: 反彈時趕快出場，少賠一點
- **不宜買進**: 這不是買點，是賣點
- **空單機會**: 反彈不過前高可考慮做空
- **確認空頭**: 頭頭低 + 底底低 = 標準空頭

#### 嚴重程度
- **比第一種更嚴重**: 第一種還在多頭，這個已經空頭
- **無關均線**: 即使月線向上，趨勢已改
- **標準空頭**: 在月線、季線下方
- **做空時機**: 反彈若不過前高，就是做空好位置

### 4. 搶反彈的正確心態

#### 什麼是搶反彈？
- **定義**: 在空頭趨勢中買進，賺短線價差
- **前提**: 知道自己在逆勢操作
- **特性**: 手腳要快，搶到就跑
- **風險**: 搶不到就停損，不能越搶越多

#### 搶反彈的紀律
- **快進快出**: 不漲就跑，不能猶豫
- **不能加碼**: 搶不到不能越搶越多
- **認識風險**: 清楚知道這是逆勢
- **強勢反彈**: 若遇到強反彈（4-5天），獲利也不錯

#### 正常操作 vs 搶反彈
- **正常操作**: 順勢而為，可以等待
- **搶反彈**: 逆勢操作，快速反應
- **兩種做法**:
  1. 搶反彈（手腳快）
  2. 不動（等反轉成多再進場）

### 5. 判斷真假反彈的關鍵

#### 位置決定一切
- **高檔反彈**: 假反彈機率高
- **低檔反彈**: 真反彈機率較高
- **趨勢方向**: 順勢反彈可靠，逆勢反彈風險高
- **支撐壓力**: 是否跌破重要支撐或壓力

#### 觀察重點
1. **月線方向**: 向上還是向下或下彎
2. **前高前低**: 是否跌破前低（底底低）
3. **趨勢型態**: 頭頭高底底高 vs 頭頭低底底低
4. **成交量**: 反彈量能是否不足

#### 確認方法
- **第一種**: 觀察能否突破月線
- **第二種**: 觀察能否突破前高
- **次日確認**: 不突破就是假反彈
- **趨勢確認**: 趨勢改變才是真反轉

## 💡 實戰案例重點

### 案例一：多頭跌破月線的假反彈
- **情況**: 多頭股票回檔跌破月線
- **訊號**: 出現反彈紅K
- **陷阱**: 看似回後買上漲
- **實際**: 月線壓力，套牢盤解套賣壓
- **結果**: 反彈到月線受壓下跌，形成頭頭低

### 案例二：跌破前低的逃命波（貨櫃航運）
- **背景**: 多頭股票連跌，跌破前低
- **形態**: 底底低，空頭確認
- **反彈**: 跌深3-4天後反彈
- **本質**: 給多單逃命的機會
- **結果**: 反彈不過前高，空頭延續

### 案例三：月線下彎的空頭確認
- **過程**:
  1. 跌破5日線（第一次警訊）
  2. 跌破月線（第二次警訊）
  3. 月線下彎（空頭確認）
  4. 跌破前低（趨勢改變）
- **教訓**: 層層警訊都沒跑，最後大賠

### 案例四：標準空頭的反彈做空
- **情況**: 已在月線、季線下方
- **型態**: 頭頭低、底底低
- **反彈**: 空頭反彈（逃命波）
- **操作**: 反彈不過前高可做空
- **位置**: 這才第一波下跌，後續空間大

## 🎯 技術分析 Prompt

### 基礎檢查 Prompt
```
請分析 {股票代號} 是否出現假反彈訊號：

**第一種：多頭跌破月線**
1. 是否跌破20日均線（月線）？
2. 整體趨勢仍是多頭（頭頭高、底底高）？
3. 今日是否出現反彈紅K？
4. 月線是否已開始下彎？
5. 前低是否守住？

**第二種：跌破前低的逃命波**
6. 是否跌破前低（底底低）？
7. 是否連跌3-4天後反彈？
8. 前高是否形成壓力（頭頭低）？
9. 是否在月線、季線下方？
10. 趨勢是否已轉空頭？

**操作建議**:
11. 目前適合買進、賣出、還是觀望？
12. 多單是否應該出場？
13. 是否適合做空？
14. 停損點在哪裡？
```

### 進階分析 Prompt
```
請針對 {股票代號} 進行假反彈深度分析：

**趨勢判斷**:

2. 頭部型態：頭頭高/頭頭低？
3. 底部型態：底底高/底底低？
4. 趨勢強度如何？

**均線分析**:

7. 與60日均線（季線）的關係？
8. 月線是向上、持平、還是下彎？

**支撐壓力**:
9. 最近一個前高在哪？
10. 最近一個前低在哪？
11. 前低是否已跌破？
12. 若反彈，前高壓力位在哪？

**第一種假反彈檢查**:

**第二種假反彈檢查**:
18. 跌破前低後連跌幾天？

**操作策略**:
23. 若持有多單，應該：立即出場/反彈出場/續抱？

**風險評估**:

```

### 批量篩選 Prompt
```
請篩選符合假反彈特徵的台股標的：

**第一種：多頭跌破月線的假反彈**
- 整體仍是多頭趨勢（頭頭高、底底低）
- 股價跌破20日均線
- 今日或近3日出現反彈紅K
- 月線開始下彎或持平

→ 標示為「月線壓力假反彈（不宜買進）」

→ 標示為「逃命波假反彈（多單出場）」

**空頭反彈做空標的**
- 標準空頭型態（頭頭低、底底低）

- 接近前高壓力
→ 標示為「空頭反彈（做空機會）」

請提供：
- 股票代號、名稱
```

## 📚 延伸學習

### 假反彈的進階識別
1. **成交量萎縮** - 反彈無量是警訊
2. **均線糾結** - 多條均線壓制
3. **前高壓力** - 前高形成強阻力
4. **趨勢改變** - 從多頭變空頭的過程

### 與其他概念結合
- **葛蘭碧賣點**: 第5、6法與假反彈相關
- **變盤線**: 反彈出現上影線、吊人線
- **波浪理論**: ABC的B波反彈
- **趨勢分析**: 頭頭低、底底低的空頭確認

### 正確的反彈操作
1. **搶反彈**: 快進快出，手腳要快
2. **等反轉**: 等多頭確認再進場
3. **不追高**: 尤其是假反彈
4. **設停損**: 所有操作都要停損

### 多單的應對策略
1. **第一關**: 跌破5日線要注意
2. **第二關**: 跌破月線要減碼
3. **第三關**: 月線下彎要出場
4. **第四關**: 跌破前低要停損

### 搶反彈的進階技巧
1. **只搶強勢股** - 基本面好的股票
2. **只搶超跌股** - 短期跌幅過大
3. **快進快出** - 不貪心
4. **嚴守紀律** - 不漲就跑

### 注意事項
1. 假反彈勝率很低，不要輕易嘗試
2. 位置比K線型態更重要
3. 趨勢改變時要果斷出場
4. 順勢比逆勢容易成功
5. 執行力決定成敗
