## 📌 核心重點

### 1. M頭的形成與意義

#### M頭基本定義
- **型態**: 兩個高點形成類似英文字母 "M" 的圖形
- **關鍵條件**: 第二個頭沒有過第一個頭（頭頭低）
- **重要性**: 多頭趨勢反轉的第一個訊號

#### M頭形成三階段

**階段一：第二個頭出現（頭頭低）**
- 第一個頭回檔再上漲，但沒有突破
- 出現下跌長黑K線
- 此時狀態：多頭 → 盤整（還不是空頭）

**階段二：跌破月線（進入盤整）**
- 股價跌破5日均線、10日均線
- 確認「頭頭低」
- 中間低點成為關鍵支撐

**階段三：跌破中間低點（空頭確認）**
- **收盤價**跌破兩個頭之間的低點
- M頭確認 = 空頭趨勢確認
- 可以開始準備放空

### 2. 空頭趨勢的定義

#### 空頭六字訣
- **頭頭低、底底低**
- 必須兩個條件同時成立
- M頭確認時，同時確認空頭趨勢

#### 空頭與反彈的區別
- **空頭反彈**: 即使漲四天、均線向上，只要還是「頭頭低、底底低」就是空頭
- **不看強弱**: 空頭不是看漲跌強弱，而是看結構
- **轉多條件**: 必須「頭頭高」+「底底高」才轉多

### 3. 最佳放空點位

#### 三大放空條件（缺一不可）
1. **頭頭低、底底低**（空頭趨勢確認）
2. **跌破月線**（股價在月線下方）
3. **月線下彎**（均線方向配合）

#### 四個實際放空時機

**時機一：M頭確認後，月線下彎**
- 中間低點跌破
- 月線開始下彎
- 最早的放空點

**時機二：空頭確認後的反彈**
- 空頭反彈（彈後空下跌）
- 月線下彎時做空
- 反彈越高，空單肉越多

**時機三：K線橫盤跌破**
- 橫盤整理後跌破
- 月線已下彎
- 也是好的放空點

**時機四：季線跌破（中長空）**
- 跌破季線（60MA）可做中長空
- 只破月線屬於短空
- 空間和時間都更大

### 4. M頭檢查清單

#### 頭部特徵檢查
- 兩個頭是否都有放大量或連續雙大量
- 頭部壓力是否很重
- 第二個頭是否略低於第一個頭（可平，但不能高）

#### KD指標背離
- **背離定義**: 股價走勢與指標走勢相反
- 第一個頭與第二個頭的KD值比較
- 股價差不多但KD更低，代表動能減弱

### 5. M頭目標價計算

#### 測量方式
1. **測量高度**: M頭的最高點 - 中間低點 = H
2. **目標價**: 中間低點 - H = 目標價
3. **用途**:
   - 停損設定（做多要走）
   - 停利設定（做空要補）

#### 操作邏輯
- 到達目標價 = 支撐位置
- 出現紅K要準備回補
- 還是空頭可以再找第二段空點

## 💡 實戰案例重點

### 案例一：M頭形成與空頭確認
- **第一個頭**: 615元（最高點）
- **第二個頭**: 約600元，頭頭低
- **中間低點**: 跌破後確認空頭
- **月線狀態**: 下彎，可以放空
- **結果**: 持續下跌

### 案例二：空頭反彈的誤判（均線糾結向上）
- **現象**:
  - 均線全部向上，看似多頭排列
  - 連續上漲多天，量能配合
- **真相**:
  - 趨勢結構仍是「頭頭低、底底低」
  - 這是「強力反彈」，不是轉多
- **操作**:
  - 不能做多（趨勢是空頭）
  - 準備彈後放空
  - 如果過前高才變「頭頭高」，但還不是多頭

### 案例三：國巨（2327）的M頭慘案
- **背景**: 基本面看好、庫藏股實施
- **技術面**: M頭確認，月線、季線、半年線全壓
- **價格**: 600元跌到400多元（跌幅超過30%）
- **教訓**:
  - 不管基本面多好，技術面M頭要遵守紀律
  - 第一時間離場，不要抱基本面
  - 套牢後不知何時回本

### 案例四：偉詮電（2436）完美M頭
- **M頭確認**: 低點跌破
- **月線下彎**: 符合放空條件
- **目標價**: 精準計算，剛好跌到目標價
- **操作流程**:
  1. 月線下彎時放空
  2. 抱到目標價
  3. 目標價有紅K，補回空單
  4. 還是空頭，可找第二段
- **停損**: 空單停損設在空點上方

## 🎯 技術分析 Prompt

### 基礎檢查 Prompt
```
請分析 {股票代號} 是否形成M頭型態：
1. 是否出現兩個高點？第二個頭是否低於或平於第一個頭？
2. 兩個頭之間的低點價位是多少？
3. 目前股價是否已跌破中間低點（收盤價）？
4. M頭是否確認？目前處於哪個階段（頭頭低/盤整/空頭確認）？
5. 兩個頭部是否都有爆大量？
6. 月線是否下彎？
7. 是否符合放空條件（頭頭低底底低+跌破月線+月線下彎）？
```

### 進階分析 Prompt
```
請針對 {股票代號} 進行M頭深度分析：

**M頭結構檢查**:
1. 第一個頭的價位、日期、成交量？
2. 第二個頭的價位、日期、成交量？
3. 中間低點的價位？目前是否已跌破？
4. 第二個頭與第一個頭的價差（頭頭低的幅度）？

**趨勢確認**:
5. 目前趨勢結構：多頭/盤整/空頭？（檢查頭頭低、底底低）
6. 最近的低點是否也呈現底底低？
7. 月線（20MA）、季線（60MA）、半年線的方向？

**KD背離檢查**:
8. 第一個頭的KD值是多少？
9. 第二個頭的KD值是多少？
10. 是否出現背離（價格差不多但KD更低）？

**放空點位分析**:
11. 是否符合三大放空條件？
12. 目前最佳放空點位在哪？
13. 如果已錯過M頭確認點，下一個放空機會在哪（反彈、橫盤跌破）？

**目標價與停損**:
14. M頭目標價是多少？（最高點-中間低點，再從低點往下減）
15. 如果做空，停損應設在哪？
16. 如果持有多單，最晚出場點在哪？

**風險評估**:
17. 是否可能是「假M頭」？
18. 目前是否在強力反彈中（均線都向上但趨勢仍空）？
19. 基本面是否很好？如果是，如何平衡技術面與基本面？
```

### 批量篩選 Prompt
```
請篩選台股中符合M頭型態的標的：

**M頭確認篩選**:
- 出現兩個高點，第二個頭低於或平於第一個頭
- 已跌破中間低點（收盤價確認）
- 月線（20MA）開始下彎或已下彎
- 趨勢確認為「頭頭低、底底低」

**加分條件**:
- 兩個頭都有爆大量
- KD指標出現背離
- 已跌破季線（可做中長空）

**排除條件**:
- 已大幅下跌超過目標價（不追空）
- 出現底底高（可能轉盤整）

請提供：
- 股票代號、名稱
- 第一個頭/第二個頭的價位與日期
- 中間低點價位與跌破日期
- 月線是否下彎
- M頭目標價
- 目前距離目標價還有多少空間
- 建議操作（立即放空/等反彈放空/已接近目標價觀望）
```

### 回測驗證 Prompt
```
請回測 {股票代號} 在 {起始日期} 到 {結束日期} 期間的M頭放空策略：

**策略規則**:
- 放空時機：M頭確認（跌破中間低點）+ 月線下彎
- 停損：空點上方（或第二個頭的高點）
- 停利：M頭目標價或出現紅K

**分級測試**:
- 情境A：M頭確認立即放空（不等月線下彎）
- 情境B：月線下彎才放空
- 情境C：等反彈再放空（彈後空下跌）
- 情境D：等K線橫盤跌破再放空

**分析項目**:
- 各情境的放空成功率
- 平均持有天數
- 平均獲利幅度
- 最大獲利與最大虧損
- 到達目標價的準確度
- 假M頭（後來又創新高）的比例

**多單測試**:
- 如果在第二個頭持有多單，各階段出場的損益：
  1. 第二個頭出現就賣（頭頭低）
  2. 跌破月線才賣（盤整確認）
  3. M頭確認才賣（空頭確認）
  4. 都不賣（抱到目標價或更低）

**優化建議**:
- 哪個放空時機最佳？
- 如何判斷假M頭？
- 基本面很好的股票，M頭準確度如何？
```

## 📚 延伸學習

### 頭部型態家族
- **M頭**: 雙頭，最常見
- **三重頂**: 三個頭，更強的頭部訊號
- **圓弧頂**: 緩慢形成的頭部
- **頭肩頂**: 左肩、頭、右肩

### 底部型態對應
- **W底**: M頭的相反，雙底做多
- **頭底對稱**: 頭部型態的特徵與底部型態相反
- **目標價計算**: 原理相同，方向相反

### 趨勢與型態
- **趨勢優先**: 先看趨勢（頭頭低底底低），再看型態
- **型態確認**: M頭是趨勢反轉的確認訊號
- **做多做空**: 趨勢決定方向，型態決定時機

### 實戰心態
- **紀律第一**: 不管基本面，技術面訊號要遵守
- **第一時間**: 第二個頭就要警覺（多單減碼）
- **不抱希望**: 套牢後不要期待反彈，該停損就停損
