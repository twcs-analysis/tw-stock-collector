## 📌 核心重點

### 1. 盤整的意義與目的

#### 為什麼會盤整？
- **漲多需要休息**: 漲幅太大需要消化
- **化解壓力**:
  - 高檔獲利賣壓
  - 前面套牢賣壓
- **蓄積力量**: 壓力化解後才能再攻

#### 盤整的兩種結果
1. **回檔**: 直接下跌修正
2. **盤整**: 橫向整理化解賣壓（時間換空間）

### 2. 三角收斂型態

#### 基本特徵
- **圖形**: 呈現三角形
- **形成**: 頭頭低 + 底底高
- **收斂**: 區間越來越小，震盪幅度縮小
- **突破**: 到三角形末端必定要表態（向上或向下）

#### 兩種三角收斂

**前跌型（空頭盤整）**
- **前提**: 前面是空頭下跌
- **特徵**:
  - 頭頭低（還是空頭特徵）
  - 底底高（進入盤整，不再底底低）
- **突破方向**: 向下跌破下頸線
- **操作**: 續勢做空（前跌收斂三角續勢）

**前漲型（多頭盤整）**
- **前提**: 前面是多頭上漲
- **特徵**:
  - 頭頭低（開始回檔）
  - 底底高（沒有跌破，形成盤整）
- **突破方向**: 向上突破上頸線
- **操作**: 續勢做多（前漲收斂三角續勢）

### 3. 盤整判斷三階段

#### 階段一：進入盤整
- **空頭盤整**: 前面低點沒跌破，底底高
- **多頭盤整**: 前面上漲後回檔，底底高

#### 階段二：確認盤整
- 反彈高點沒過前高，頭頭低
- 確認在區間內震盪

#### 階段三：畫出區域
- **上頸線**: 連接兩個高點（用上影線最高點）
- **下頸線**: 連接兩個低點（用下影線最低點）
- **重點**: 用影線，不是用實體棒

### 4. 操作策略

#### 盤整期間
- **不要進場**: 盤整時不要卡位
- **等待表態**: 等突破或跌破再動作
- **去做別的**: 三角形太大、盤整太久，先做其他股票

#### 突破/跌破訊號

**做多訊號（前漲型）**
- 紅K實體棒向上突破上頸線
- 停損守紅K低點
- 第二天沒漲但沒跌破，繼續抱
- 跌破5日均線就賣（標股操作）

**做空訊號（前跌型）**
- 黑K實體棒向下跌破下頸線
- 停損守黑K高點
- 成功率非常高（盤整內買進者全被套）
- 產生多殺多，再跌一大段

#### 反轉訊號（少見但要注意）
- **前跌型**: 如果向上突破上頸線 = 反轉（空翻多）
- **前漲型**: 如果向下跌破下頸線 = 反轉（多翻空）
- **操作**: 多單一定要走，空單立即回補

### 5. 等幅目標價測量

#### 測量原理
- 三角收斂是標準型態，有目標價
- 使用「等幅測量法」

#### 測量步驟
1. **找到三角形最寬處**:
   - 第一波漲幅或跌幅的高度
   - 也就是進入盤整前的那一波

2. **測量高度**: 最高點 - 最低點 = H

3. **計算目標價**:
   - **做多**: 突破點 + H = 目標價
   - **做空**: 跌破點 - H = 目標價

#### 實例計算
- 三角形最寬處高度 = 10元
- 突破點在50元
- 目標價 = 50 + 10 = 60元

#### 目標價的用途
- **到達目標價**: 壓力或支撐位置
- **不一定要全出**: 可提高警覺或先獲利一半
- **型態壓力**: 通常在目標價附近會遇到壓力

## 💡 實戰案例重點

### 案例一：前跌型空頭續跌（近期範例）
- **背景**: 前面空頭下跌
- **盤整**:
  - 底底高（進入盤整）
  - 頭頭低（確認盤整）
  - 畫好上下頸線
- **訊號**: 黑K跌破下頸線
- **結果**: 跌破後兩天都在賺錢
- **操作**: 空單平倉在跌破前，跌破後重新放空

### 案例二：前跌型盤整兩週（近期範例）
- **背景**: 前面空頭，放空後不跌了
- **操作流程**:
  1. 彈上來，空單先回補退出
  2. 確認高點沒過、低點沒破（盤整）
  3. 畫好頸線
  4. 等跌破再放空
- **提醒**: 可能還要盤，但沒關係，等到跌破再動作

### 案例三：前漲型多頭續漲
- **背景**: 多頭上漲一波
- **盤整**:
  - 頭頭低（回檔）
  - 底底高（盤整）
  - 畫好上下頸線
- **訊號**: 紅K突破上頸線
- **操作**:
  - 突破進場，停損守紅K低點
  - 第二天沒漲但沒跌破，繼續抱
  - 一路抱到標股急漲
  - 跌破5日均線賣出
- **後續**: 又出現頭頭低，趕快跑（可能又進盤整）

### 案例四：提前卡位的風險
- **錯誤**: 多頭盤整時提前進場
- **風險**:
  - 回檔時可能賣了（沒賺錢）
  - 如果反轉向下跌破，多單被套
- **正確**: 等突破上頸線再進場
- **好處**:
  - 減少很多錯誤
  - 確定方向再進
  - 即使沒賺大錢，至少不會套牢

## 🎯 技術分析 Prompt

### 基礎檢查 Prompt
```
請分析 {股票代號} 是否形成三角收斂：
1. 前面趨勢是上漲（多頭）還是下跌（空頭）？
2. 是否出現「頭頭低」+「底底高」的盤整結構？
3. 最近兩個高點在哪？最近兩個低點在哪？
4. 上頸線與下頸線的價位分別是多少？
5. 目前股價在三角形內部、已突破、還是已跌破？
6. 如果已突破/跌破，是續勢還是反轉？
7. 等幅目標價是多少？
```

### 進階分析 Prompt
```
請針對 {股票代號} 進行三角收斂深度分析：

**型態識別**:
1. 前面趨勢：多頭/空頭？持續多久？漲跌幅多少？
2. 盤整階段判斷：
   - 何時進入盤整（底底高開始）？
   - 何時確認盤整（頭頭低確認）？
3. 盤整時間多長？三角形大小如何？

**頸線繪製**:
4. 上頸線兩個高點：日期、價位（含上影線）
5. 下頸線兩個低點：日期、價位（含下影線）
6. 上下頸線的斜率（收斂角度）
7. 預估幾天後會收斂到末端？

**突破分析**:
8. 是否已突破/跌破？是用紅K/黑K？
9. 突破/跌破時的成交量如何？
10. 是續勢（與前趨勢同向）還是反轉（與前趨勢反向）？

**目標價計算**:
11. 三角形最寬處的高度是多少？（第一波進入盤整前的漲跌幅）
12. 突破/跌破點的價位？
13. 等幅目標價計算結果？
14. 目前距離目標價還有多少空間？

**操作建議**:
15. 如果還在三角形內，建議等待還是卡位？
16. 如果已突破/跌破，建議進場價位？停損價位？
17. 目標價附近的操作策略（全出/減碼/觀察）？
18. 是否有反轉風險（前漲跌破/前跌突破）？

**風險評估**:
19. 假突破的可能性？（突破後又跌回）
20. 均線配合度如何？
```

### 批量篩選 Prompt
```
請篩選台股中符合三角收斂型態的標的：

**前漲型多頭盤整（準備做多）**:
- 前面趨勢為多頭上漲
- 形成頭頭低+底底高的盤整
- 已畫出明確的上下頸線
- 接近三角形末端（再5個交易日內可能突破）
- 還未突破上頸線（或剛突破1-2天）

**前跌型空頭盤整（準備做空）**:
- 前面趨勢為空頭下跌
- 形成頭頭低+底底高的盤整
- 已畫出明確的上下頸線
- 接近三角形末端（再5個交易日內可能跌破）
- 還未跌破下頸線（或剛跌破1-2天）

**加分條件**:
- 盤整時間適中（1-3週）
- 成交量在盤整期間萎縮（代表蓄勢）
- 均線方向配合（前漲型均線向上，前跌型均線向下）

請提供：
- 股票代號、名稱
- 盤整類型（前漲/前跌）
- 上下頸線價位
- 目前股價位置
- 預估突破/跌破日期
- 等幅目標價
- 建議操作策略
```

### 回測驗證 Prompt
```
請回測 {股票代號} 在 {起始日期} 到 {結束日期} 期間的三角收斂策略：

**策略規則**:
- 辨識三角收斂型態（頭頭低+底底高）
- 等待突破/跌破訊號
- 前漲型突破做多，前跌型跌破做空
- 停損：守突破/跌破K棒的另一端
- 停利：等幅目標價或反向訊號

**分級測試**:
- 情境A：在三角形內提前卡位
- 情境B：突破/跌破當天進場
- 情境C：突破/跌破後第二天確認再進場
- 情境D：只做續勢，不做反轉

**分析項目**:
- 三角收斂型態出現次數
- 續勢比例 vs. 反轉比例
- 各情境的成功率、平均獲利、平均虧損
- 到達目標價的準確度（100%達到/超過/未達到的比例）
- 假突破/假跌破的次數（突破後又跌回）
- 平均持有天數

**型態細節統計**:
- 盤整時間長短與成功率的關係
- 三角形大小與目標價準確度的關係
- 突破/跌破時量能與成功率的關係
- 均線配合度與成功率的關係

**優化建議**:
- 哪個進場時機最佳？
- 如何判斷假突破？
- 目標價是否需要調整（如打折或放大）？
- 什麼條件下應該避開三角收斂？
```

## 📚 延伸學習

### 盤整型態家族
- **三角收斂**: 本集重點
- **矩形（箱型）**: 橫向盤整，高低點平行
- **旗形**: 短期盤整，與趨勢相反方向傾斜
- **楔形**: 上下頸線都向同一方向傾斜

### 目標價測量法
- **等幅測量**: 三角收斂、旗形、楔形
- **型態高度測量**: M頭、W底、頭肩頂底
- **費波納契**: 回檔與延伸測量

### 續勢與反轉
- **續勢**: 盤整後延續原趨勢（機率較高）
- **反轉**: 盤整後改變趨勢（機率較低）
- **判斷**: 看均線、量能、指標配合度

### 盤整期操作心態
- **耐心等待**: 不要急著卡位
- **紀律進場**: 突破/跌破才動作
- **資金效率**: 盤整太久去做其他標的
- **停損停利**: 進場就設好停損與目標價

## 🔑 關鍵金句

> "股票本來就是多、空、盤。那你進到盤整，你就會被卡在那個地方。"

> "股票漲多了，會有兩個結果：一個是回檔，一個是盤整。"

> "盤整就是在化解壓力，否則沒辦法再攻。把壓力化解了，才有力量再往上攻一波。"

> "頭頭低，但是底底高。空頭要底底低，但底底高表示進到盤整了。"

> "區間會越來越小，越來越收斂。股價在上下頸線震盪，縮到最後一天一定要跑出來，因為兩條線會夾著它。"

> "盤整結束去放空的成功率非常高。因為跌破後，裡面所有（盤整時買進的）人又被套牢了，會產生多殺多，再跌一大段。"

> "畫在下影線最低點，跟上影線最高點。"（畫頸線技巧）

> "沒有什麼高不高，這是一定要趕快走、趕快出場。可是這三組（長紅長黑、遭遇、覆蓋）都沒有跌破紅K（底部），所以我們就要看明天會不會跌的機率。"

> "盤整有時很久，因為三角形很大，你就先去做別的股票。等到越接近收斂末端，你再去注意：今天可能突破，或今天可能跌破。"

> "只要講到型態，就有目標價。如果你不看型態,就沒有目標價。"

> "到了目標價不一定要全賣，但一定要提高警覺，或者先獲利了結一半。因為型態的壓力通常在那附近會出現。"

> "記得，沒表態前不要急著進去卡位，等那個紅K或黑K跑出來再動手。"
