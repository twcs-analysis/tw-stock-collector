## 📌 核心重點

### 1. 避雷針（上影線）基本概念

#### 定義與特徵
- **名稱**: 避雷針（因形狀像屋頂避雷針）
- **條件**: 上影線長度 ≥ 實體棒的2倍
- **紅黑皆同**: 紅K或黑K的看法相同
- **市場意義**: 盤中拉高後賣壓湧現，收盤殺低

#### 形成原因
- **誘多出貨**: 主力拉高吸引散戶買進，趁機出貨
- **買盤不濟**: 拉高後買盤力道不足，賣壓太重
- **獲利了結**: 連漲數天後，低檔買進者獲利賣出
- **壓力測試**: 碰到前高壓力，解套賣壓出現

### 2. 避雷針的判讀重點

#### 位置決定一切
- **急漲後出現**: 連拉3-4天後最危險
- **高檔出現**: 短線獲利過高，容易反轉
- **前高壓力**: 碰到前高阻力，解套賣壓湧現
- **爆量配合**: 爆量留上影線，第二天不漲易跌

#### 操作原則
- **多頭停利**: 有獲利者準備停利離場
- **觀察次日**: 次日不能下跌，若跌就確認反轉
- **不追高**: 不要追第3-4天的急漲股
- **執行力**: 看到訊號就要賣，不能猶豫

### 3. 吊人線（下影線）基本概念

#### 定義與特徵
- **名稱**: 吊人線（形狀像人頭加長腳）
- **條件**: 下影線長度 ≥ 實體棒的2倍
- **紅黑皆同**: 紅K或黑K的看法相同
- **市場意義**: 盤中下殺後拉回，但空方力量已出現

#### 形成原因與警示
- **空方現身**: 原本一路上漲無阻力，今天出現空方
- **多空對抗**: 盤中被打退，雖收盤拉回但多方受挫
- **預防心態**: 提醒空方力量出現，要預防明天
- **洗盤或出貨**: 需觀察次日確認是洗盤換手或主力出貨

### 4. 吊人線的判讀重點

#### 位置決定一切
- **高檔出現**: 多頭上漲高檔出現吊人線，易變盤
- **連續出現**: 連兩天出現吊人線，第三天要特別注意
- **空頭反彈**: 空頭反彈高檔的吊人線是做空訊號
- **誘多陷阱**: 主力可能連續兩天盤中誘多

#### 操作原則
- **次日確認**: 次日不能下跌，若跌就確認反轉
- **突破續抱**: 若次日紅K突破吊人線高點，多頭延續
- **高檔警覺**: 在高檔看到吊人線就要提高警覺
- **空頭做空**: 空頭反彈的吊人線可準備做空

### 5. 變盤線的綜合運用

#### 上影線與下影線都是變盤線
- **共同特性**: 都提醒可能變盤
- **次日確認**: 都需要觀察次日走勢
- **高檔危險**: 在高檔出現都不好
- **低檔反彈**: 在低檔空頭出現可能是反彈訊號

#### 突破確認原則
- **避雷針突破**: 次日紅K且突破上影線高點 → 換手，多頭續強
- **吊人線突破**: 次日紅K且突破吊人線高點 → 洗盤，多頭延續
- **爆量配合**: 突破當天量要大於變盤線當天的量
- **未突破**: 次日下跌就確認變盤，要立即離場

## 💡 實戰案例重點

### 案例一：急漲後的避雷針（多頭停利）
- **情況**: 連漲3-4天，第4天出現長上影線
- **訊號**: 短線獲利過高（從180漲到230）
- **技巧**: 看收盤價位置判斷多空力道（上影線佔5分之4，賣壓很重）
- **結果**: 第二天不漲就回檔，要停利離場

### 案例二：爆量上影線（誘多出貨）
- **情況**: 連續跳空上漲，第4天爆量留上影線
- **訊號**: 1、2、3、4天急漲，不要追第3-4天
- **確認**: 翌日下跌確認，進入修正
- **教訓**: 追高容易被套在高檔

### 案例三：空頭的長上影線（做空機會）
- **情況**: 空頭趨勢中反彈出現長上影線
- **訊號**: 爆量留上影線，第二天不漲易跌
- **操作**: 空頭趨勢可考慮做空
- **結果**: 跌停、跌停、跌停

### 案例四：台泥的上影線突破（換手）
- **情況**: 連漲4天後爆量黑K留上影線
- **教訓**: 不要在推薦當天馬上買，要等回檔
- **轉機**: 次日開高，收盤突破上影線高點
- **確認**: 爆量突破，把上影線吃掉，換手成功
- **結果**: 多頭延續（但仍需觀察）

### 案例五：鋼鐵股的避雷針與吊人線交錯
- **第一次避雷針**: 次日過高，換手成功
- **吊人線**: 連續兩天後突破高點，洗盤成功
- **連續漲停**: 突破後兩根漲停板
- **最後吊人線**: 兩根漲停後出現吊人線，要注意

### 案例六：吊人線的誘多（主力出貨）
- **第一天吊人線**: 盤中下殺拉回，收最高
- **第二天吊人線**: 再次盤中下殺拉回
- **第三天下跌**: 開高後下殺，主力出貨
- **教訓**: 連續兩天誘多，第三天被套牢
- **結果**: 越漲一大段想追高，反被套10-20%

### 案例七：空頭反彈的吊人線（做空訊號）
- **情況**: 空頭趨勢反彈，出現吊人線
- **訊號**: 反彈結束的警告
- **操作**: 第二天準備做空
- **確認**: 翌日一跌，空頭延續

### 基礎檢查 Prompt
```
請分析 {股票代號} 是否出現變盤線訊號：

**上影線（避雷針）檢查**:
1. 今日是否出現長上影線（上影線 ≥ 實體棒2倍）？
2. 上影線出現在急漲後第幾天？
3. 今日是否爆量？
4. 股價是否在相對高檔？
5. 是否碰到前高壓力？

**下影線（吊人線）檢查**:
6. 今日是否出現長下影線（下影線 ≥ 實體棒2倍）？
7. 是否在連續上漲後出現？
8. 盤中最低點與收盤價差距多大？
9. 是否在多頭高檔或空頭反彈高檔？

**次日觀察重點**:
10. 明天的操作建議？
11. 突破哪個價位可確認多頭延續？
12. 跌破哪個價位要停損離場？
```

## 📚 延伸學習

### 與其他指標結合
- **均線**: 搭配5日均線判斷停利點
- **成交量**: 爆量上影線更危險
- **趨勢**: 先判斷多空趨勢，決定操作方向
- **前高壓力**: 碰到前高的變盤線要特別注意

### K線組合應用
- **避雷針 + 跌破5日均線**: 確認多頭轉弱
- **連續兩天吊人線**: 誘多出貨的可能性高
- **變盤線 + 隔天黑K**: 確認變盤，要停損
- **變盤線 + 隔天突破**: 換手/洗盤，可續抱

### 進階技巧
1. **不追第3-4天的急漲股** - 容易出現避雷針
2. **次日確認原則** - 所有變盤線都要觀察次日
3. **位置決定一切** - 高檔的變盤線更危險
4. **執行力很重要** - 看到訊號就要行動

### 注意事項
1. 變盤線只是「提醒」，不是絕對
2. 必須觀察次日確認
3. 高檔的變盤線比低檔危險
4. 空頭反彈的變盤線可做空
