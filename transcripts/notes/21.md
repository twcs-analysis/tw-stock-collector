## 📌 核心重點

### 1. 技術面多空對稱概念
- **對稱理論**: 股票走勢左右對稱，做空與做多在技術面上完全一樣
- **循環本質**: 漲多必跌、跌多必漲
- **工具演進**: 現在可透過股票期貨做空，不必融券
- **公平性**: 技術分析不分多空，兩者機會均等

### 2. 葛蘭碧八大法則：四個賣點回顧

#### 第5賣點：空頭確認，跌破月線
- **條件**:
  - 空頭已確認
  - 股價跌破月線（20日線）
  - 月線下彎
- **操作**:
  - 適合「短空」
  - 注意季線支撐，可能在季線反彈
- **風險**: 多單持有者的最後逃命機會

#### 第6賣點：反彈不過月線（彈後空下跌）
- **條件**:
  - 月線已下彎
  - 股價反彈至月線受壓
  - 無法突破月線
- **操作**:
  - 最常用的做空位置
  - 可做長線，獲利空間大
  - 季線可能也已下彎，可長抱至月線向上
- **優勢**: 不容易被停損

#### 第7賣點：假突破月線，再度跌破
- **條件**:
  - 跌深後低接力量強
  - 短暫突破月線（2-3天）
  - 再度跌破月線且月線維持向下
- **操作**:
  - 等跌破月線再做空
  - 讓月線壓住股價，空單較安全
- **關鍵**: 月線必須維持向下

#### 第8賣點：極漲的正乖離回檔
- **條件**:
  - 多頭趨勢中急漲
  - 正乖離達15%以上
  - 出現黑K跌破變盤線
- **操作**:
  - 搶短空（高手操作）
  - 碰到月線就回補
  - 這只是多頭回檔，非空頭
- **技巧**: 觀察大量上影線配合乖離率

### 3. 實戰判斷要點

#### 空頭確認特徵（第5法）
- 月線由向上轉為下彎
- 股價跌破月線在下方
- 成交量縮，散戶套牢不賣
- 頭頭低的壓力型態

#### 盤整轉空（第5法）
- 紅黑K交替，看似盤整
- 月線開始下彎
- 出現「頭頭低」，壓力未過

#### 反彈壓力（第6法）
- 跌至季線反彈
- 彈至月線（下彎）過不去
- 反彈到月線、季線壓力區
- 站不上月線，空頭延續

#### 正乖離放空（第8法）
- 急漲後爆大量
- 出現變盤線（十字線或上影線）
- 黑K跌破變盤線
- 乖離率設定15%以上

## 💡 實戰案例重點

### 案例一：最後逃命機會（第5法）
- **情況**: 多頭轉空頭，月線下彎，股價跌破月線
- **訊號**: 成交量縮，高檔散戶套牢
- **操作**: 多單必須離開，這是最後逃命位置
- **結果**: 持續下跌

### 案例二：盤整轉空（第5法）
- **情況**: 紅黑K交替，月線開始下彎
- **訊號**: 股價跌破月線，頭頭低
- **操作**: 空頭確立，準備做空或離場
- **結果**: 進入空頭走勢

### 案例三：反彈不過月線（第6法）
- **情況**: 跌至季線反彈，彈至月線
- **訊號**: 月線下彎，股價過不去月線
- **操作**: 一跌就做空，不易被停損
- **結果**: 標股漲完，高點爆量後空頭延續

### 案例四：正乖離過大（第8法）
- **情況**: 急漲、爆大量、出現變盤線
- **訊號**: 正乖離超過15%，大量上影線
- **操作**: 黑K跌破變盤線時搶短空
- **結果**: 向月線靠攏（回測月線）

## 🎯 技術分析 Prompt

### 基礎檢查 Prompt
```
請分析 {股票代號} 是否出現葛蘭碧賣出訊號：

**空頭確認檢查（第5法）**:
1. 股價是否跌破20日均線（月線）？
2. 月線是否下彎？
3. 成交量是否萎縮？
4. 是否出現頭頭低型態？

**反彈壓力檢查（第6法）**:
5. 股價反彈是否碰到月線受壓？
6. 月線是否維持向下？
7. 季線是否也開始下彎？

**假突破檢查（第7法）**:
8. 是否短暫突破月線後又跌破？
9. 突破天數是否在2-3天內？

**正乖離檢查（第8法）**:
10. 與月線的乖離率是否超過15%？
11. 是否出現大量上影線或變盤線？
12. 是否有黑K跌破變盤線？

請給出具體操作建議（賣出/做空/觀望）
```

## 📚 延伸學習

### 與其他指標結合
- **葛蘭碧買點**: EP20（四個買進位置）
- **均線系統**: 月線（20MA）、季線（60MA）、半年線（120MA）
- **乖離率**: 正乖離15%以上的放空時機
- **成交量**: 量縮確認空頭、爆量上影線

### 進階技巧
1. **第6法是最常用位置** - 可做長線，獲利空間大
2. **季線是短空的回補位置** - 第5法要注意季線支撐
3. **第8法適合高手** - 正乖離放空需快速反應
4. **停損紀律** - 所有做空都要設停損

### 八大法則完整架構
- **做多（1-4法）**:
  1. 站上月線（底成）
  2. 回後買上漲
  3. 跌破月線再站回
  4. 負乖離搶反彈

- **做空（5-8法）**:
  5. 跌破月線（頭成）
  6. 彈到月線下跌（最常用）
  7. 彈上去又跌破
  8. 正乖離短空（高手）
