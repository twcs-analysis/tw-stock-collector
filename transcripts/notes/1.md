## 📌 核心重點

### 1. KD 指標基本概念
- **定義**: 用於判斷股價相對高低位置的技術指標
- **參數**: 標準使用 9 天作為比較基準
- **數值範圍**: 0-100 之間
  - **低檔**: KD < 20（股價相對低點）
  - **中性**: 20 ≤ KD ≤ 80
  - **高檔**: KD > 80（股價相對高點）

### 2. 黃金交叉與死亡交叉
- **黃金交叉**: K 線由下往上穿越 D 線 → 買進訊號
- **死亡交叉**: K 線由上往下穿越 D 線 → 賣出訊號
- **使用前提**: 必須先判斷趨勢（多頭/空頭/盤整）

### 3. 鈍化現象
#### 低檔鈍化（KD < 20 持續 3 天以上）
- **現象**: 股價持續下跌，指標停留在 20 以下
- **操作**:
  - 空單準備回補
  - 不看指標，看紅 K 出現就補

#### 高檔鈍化（KD > 80 持續 3 天以上）
- **現象**: 股價持續上漲，指標停留在 80 以上
- **特徵**: 強勢股的表現
- **操作**:
  - 不追高
  - 依紀律出場（如跌破 5 日均線）

### 4. 實戰操作策略

#### 多頭市場
- **買點**: KD 黃金交叉（尤其在 50 附近）
- **賣點**:
  - 短線: 跌破 5 日均線
  - 或 KD 死亡交叉

#### 空頭市場
- **空點**: KD 死亡交叉
- **回補**: KD 黃金交叉（短線反彈）

#### 盤整市場
- **重要**: 盤整時 KD 不準，不要使用

### 5. 關鍵紀律
1. **不追三天以上的漲停股** - K 值可能已達 80
2. **鈍化時回歸價量分析** - 不看指標交叉
3. **強勢股特徵**: 回檔時 KD 只到 40-50 就止跌
4. **指標要向上**: 紅線藍線都向上才會拉抬

## 💡 實戰案例重點

### 案例: 生技股操作（4月-7月）
- **長線獲利**: 50%
- **短線獲利**: 30%
- **操作方式**:
  1. KD 黃金交叉 + 起漲位置 → 買進
  2. 跌破 5 日均線 → 賣出
  3. 再次 KD 黃金交叉 → 買進
  4. 循環操作，賺取波段

## 🎯 技術分析 Prompt

### 基礎檢查 Prompt
```
請分析 {股票代號} 的 KD 指標狀態：
1. 目前 K 值與 D 值為多少？
2. 是否處於黃金交叉或死亡交叉？
3. KD 值在低檔(<20)、中性(20-80)、還是高檔(>80)？
4. 是否出現鈍化現象（低檔或高檔鈍化）？
5. 結合 5 日均線，目前建議的操作方向？
```

### 進階分析 Prompt
```
請針對 {股票代號} 進行 KD 指標深度分析：

**趨勢判斷**:
1. 目前處於多頭、空頭、還是盤整？
2. KD 指標的紅線（K）與藍線（D）是否都向上？

**訊號分析**:
3. 最近一次黃金交叉/死亡交叉發生在何時？位置在哪（低檔/中性/高檔）？
4. 是否出現鈍化？鈍化天數有幾天？

**操作建議**:
5. 如果是多頭，KD 黃金交叉是否出現在 50 附近（強勢股特徵）？
6. 股價是否已連續上漲三天以上？K 值是否接近或超過 80？
7. 結合價量與均線，給出具體操作建議（買進/賣出/觀望）

**風險提示**:
8. 目前是否有追高風險或超跌反彈機會？
```

### 批量篩選 Prompt
```
請篩選符合以下 KD 條件的台股標的：

**買進訊號篩選**:
- KD 黃金交叉在近 3 日內發生
- KD 值在 20-60 之間（避免高檔）
- K 值與 D 值都在上升
- 股價站上 5 日均線

**賣出訊號篩選**:
- KD 死亡交叉在近 3 日內發生
- KD 值在 70 以上
- 或出現高檔鈍化（KD > 80 超過 3 天）

請提供股票代號、名稱、目前 KD 值、交叉發生日期
```

### 回測驗證 Prompt
```
請回測 {股票代號} 在 {起始日期} 到 {結束日期} 期間的 KD 策略表現：

**策略規則**:
1. 買進: KD 黃金交叉 且 KD < 80
2. 賣出: 跌破 5 日均線 或 KD 死亡交叉

**分析項目**:
- 總交易次數
- 勝率
- 平均獲利/虧損
- 最大獲利與最大虧損
- 是否有假突破訊號
- KD 鈍化期間的表現

**改進建議**:
- 哪些情況下訊號失效？
- 如何優化進出場時機？
```

## 📚 延伸學習

### 與其他指標結合
- **均線**: 5MA、10MA、20MA（後續課程）
- **量價關係**: 成交量確認（後續課程）
- **趨勢判斷**: 多空頭判斷方法（後續課程）

### 注意事項
1. KD 只是輔助工具，不能單獨使用
2. 必須先判斷大盤與個股趨勢
3. 盤整時 KD 容易失真
4. 鈍化時要回歸價量分析
