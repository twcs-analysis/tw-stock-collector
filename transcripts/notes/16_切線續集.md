## 📌 核心重點

### 1. 切線基本概念
- **定義**: 連接低點或高點形成的趨勢線，判斷股價多空方向
- **三種趨勢**:
  - **上升**: 連接兩個低點，線往上 → 多頭
  - **盤整**: 水平線 → 橫盤整理
  - **下降**: 連接兩個高點，線往下 → 空頭

### 2. 切線的功能
1. **預判多空方向**: 線的角度決定行情強弱
2. **提供支撐壓力**: 作為買賣參考點
3. **進出場依據**: 可用切線做操作紀律
4. **轉強轉弱訊號**: 透過角度變化判斷

### 3. 上升切線畫法
#### 原始切線
- **條件**: 連接前兩個最低點
- **方向**: 底底高，線往上
- **畫法**: 從最新低點往前找低點連接

#### 動態調整
- **新低點出現**: 重新畫更陡的切線
- **跌破切線**: 股票走弱，守前一條
- **角度變化**:
  - 角度越大 = 股票越強
  - 角度變小 = 股票轉弱（但仍多頭）

### 4. 下降切線畫法
- **原始切線**: 連接前兩個最高點
- **特徵**: 頭頭低，每個高點比上次低
- **作用**: 提供壓力，做空參考
- **反轉判斷**: 突破下降切線 = 轉強訊號

### 5. 切線的關鍵判斷

#### 最後切線理論
- **跌破最後一條**: 多頭上漲開始減弱
- **連跌兩條**: 趨勢可能改變（第四條→第三條）
- **應對策略**: 跌破第一條應離場

#### 支撐壓力轉換
- **支撐跌破 → 變壓力**: 上漲遇跌破的切線會受壓
- **壓力突破 → 變支撐**: 下跌突破後回測會有支撐

### 6. 極切線（飆股專用）
#### 適用情境
- 急漲急跌的股票
- 飆股出場點判斷
- 末升段噴出
- V 型反彈
- 上下幅度盤整區

#### 畫法差異
- **一般切線**: 連接轉折高低點
- **極切線**: 連接每根 K 線的低點（上漲）或高點（下跌）

#### 出場訊號
- **黑 K 實體棒跌破**: 不看下影線
- **收盤跌破**: 賣出訊號
- **目的**: 賺到急漲段，獲利入袋

## 💡 實戰案例重點

### 案例 1: 貨櫃航運（多頭回檔判斷）
- **現象**: 跌破上升切線後快速站回
- **判斷**: 有新低點，重新畫切線
- **結論**: 底底高趨勢未改，仍可持有
- **操作**: 支撐處有支撐就是買點

### 案例 2: 萬海（長期上升切線）
- **區間**: 十幾塊漲到三十幾塊
- **切線**: 半年區間的原始切線
- **獲利**: 超過 50%
- **賣點**: 跌破切線 + 黑 K 確認

### 案例 3: 極切線實戰（飆股）
- **急漲**: 連續三天以上大漲
- **極切線**: 連接每天 K 線低點
- **出場**: 黑 K 實體跌破 → 立即賣出
- **避免**: 獲利回吐（從 50% 吐回 0%）

## 🎯 技術分析 Prompt

### 基礎檢查 Prompt
```
請分析 {股票代號} 的切線狀態：
1. 近期是否形成上升切線或下降切線？
2. 目前股價與切線的位置關係（在上/在下/測試中）？
3. 切線的角度如何？是否有變陡或變平的趨勢？
4. 最近是否有跌破或突破切線的訊號？
5. 目前切線提供的是支撐還是壓力？
```

### 進階分析 Prompt
```
請針對 {股票代號} 進行切線深度分析：

**切線繪製**:
1. 識別最近 6 個月內的關鍵低點（多頭）或高點（空頭）
2. 繪製原始切線與後續調整的切線
3. 計算每條切線的角度變化

**訊號判斷**:
4. 是否跌破最後一條上升切線？
5. 是否連續跌破兩條切線（轉折訊號）？
6. 跌破的切線是否形成新的壓力？

**強弱分析**:
7. 比較前後切線角度，判斷走強或走弱
8. 目前是第幾條切線？距離原始切線多遠？

**操作建議**:
9. 基於切線分析，給出具體進出場建議
10. 設定停損點位（以切線為準）
```

### 批量篩選 Prompt
```
請篩選符合以下切線條件的台股標的：

**上升切線篩選**:
- 近期形成上升切線（連接兩個以上低點）
- 切線角度在 30-60 度之間（穩健上漲）
- 股價目前在切線上方但距離不超過 15%
- 尚未跌破最後一條切線

**極切線飆股篩選**:
- 近 5 日內累計漲幅超過 20%
- 可繪製陡峭極切線（角度 > 60 度）
- 尚未出現黑 K 跌破極切線

**風險警示**:
- 已跌破最後切線且未站回（轉弱）
- 連續跌破兩條切線（趨勢反轉）
```

### 回測驗證 Prompt
```
請回測 {股票代號} 在 {起始日期} 到 {結束日期} 期間的切線策略：

**策略規則**:
1. 買進: 股價在上升切線上方 + 紅 K 確認
2. 賣出: 跌破最後一條上升切線
3. 極切線: 急漲後用極切線，黑 K 實體跌破就出

**分析項目**:
- 切線支撐成功率（測試後反彈）
- 跌破切線後的平均跌幅
- 極切線出場的平均獲利保護率
- 假跌破訊號的比例

**最佳化建議**:
- 什麼角度的切線勝率最高？
- 極切線適用的最佳漲幅區間？
```

## 📚 延伸學習

### 與其他工具結合
- **均線**: 5MA/10MA/20MA 搭配切線做雙重確認
- **成交量**: 跌破切線時的量能判斷
- **K 線型態**: 拇指懷抱、吞噬等轉折訊號

### 進階技巧（榮耀班）
- **軌道理論**: 上升/下降通道的繪製與應用
- **多條切線交叉**: 支撐壓力密集區判斷
- **極切線進階**: 如何在盤中即時調整

### 注意事項
1. 切線需要隨股價走勢不斷調整
2. 不是所有股票都適合用切線（盤整股不適用）
3. 切線是趨勢工具，適合中長線操作
4. 極切線只用於短線飆股
