> **來賓**: 朱家宏老師
> **主題**: 一棒三線戰法 - 抓住起漲點與起跌點
> **原始逐字稿**: [2.txt](../raw/2.txt)

## 📌 核心重點

### 1. 一棒三線戰法
- **一棒**: 大量紅 K 棒（突破訊號）
  - 必須是「開始漲的量」，非高檔爆量
  - 紅 K 代表買盤力量強（開高走低的黑 K 代表有人在賣）
- **三線**: 5日、10日、20日均線多頭排列
  - **多頭排列**: 5MA > 10MA > 20MA（由上到下）
  - **均線開花**: 均線糾結後向上發散
  - **進階版**: 加入 60 日季線 = 四線多排

### 2. 起漲點辨識三要素
1. **底部盤整**: 盤整 2 個月以上累積能量
   - 均線糾結（5、10、20 日均線交纏）
   - 橫向整理，人生空白
2. **大量紅 K**: 突破盤整區的放量長紅
3. **多頭排列**: 均線由下往上依序排列

### 3. 底部型態學

#### 均線糾結突破
- **現象**: 長期盤整（2-3個月），均線糾結在一起
- **訊號**: 大量紅 K 向上突破
- **結果**: 均線開花，產生強勁漲勢

#### 頭肩底（V型反轉）
- **特徵**:
  - V 型急跌後反彈
  - 底部有大量但股價不跌破
  - 均線糾結後向上突破
- **操作**:
  - 抓 V 型成型後的突破點
  - 沿著 5 日均線持有
  - 成功率高，想賠錢都很難

#### 碎步墊高
- **特徵**:
  - 低點連線持續往上（底底高）
  - 緩步上升，小小漲
  - 有一天大量紅 K + KD 多排
- **訊號**: 變天那天 = 大量紅 K + KD 黃金交叉

### 4. 多頭趨勢確認：六字訣
> **底底高、頭頭高**

- **底底高**: 回檔低點越來越高
- **頭頭高**: 每波高點越來越高
- **意義**: 只要六字訣沒改，不可以做空
- **操作**: 每波都可以參與，一直買一直抱

### 5. 進場時機與波段操作
- **第一波**: 大量紅 K + 均線多排 → 突破買進
  - 連續漲停 2-3 天很正常
  - 第一波沒抓到不要追
- **第二波**:
  - 長紅 + 爆量 + KD 多排
  - KD 黃金交叉在 50 附近
  - 成功率 80-90%
  - 勝率不是 100%，不漲就停損賣掉
  - **策略**: 用一根賠掉的停損去賭十根的獲利

### 6. 均線支撐邏輯
- **5 日均**: 短線支撐，常被跌破
- **10 日均**: 中短線支撐，力量較強
- **20 日月線**: 月線支撐，更強
- **60 日季線**: 季線支撐，最強
- **優勢**: 多條均線提供多道防線，讓你判斷如何處理

---

## ⚠️ 三大陷阱：避開這些位置

### 1. 第三波的高檔
- **現象**: 已經走三天以上的漲勢
- **風險**: 不要賭第四波，高點容易反轉
- **原則**: 不追三天以上的股票

### 2. 急漲的高檔爆量
- **定義**: 成交量是昨天的 2 倍以上
- **風險**: 一爆量就會下來（倒貨訊號）
- **原則**: 高檔放量要出場，不是進場

### 3. 底部季線反壓
- **現象**: 60 日季線還在往下且壓在股價上方
- **風險**: 容易被季線打下來
- **解決**:
  - 等季線轉平或向上
  - 或等股價站上季線
  - 底部要特別注意 60MA 壓力

## 💡 實戰案例重點

### 案例 1: 均線糾結突破（2019/10 - 2020/1）
- **底部**: 盤整 2-3 個月，均線糾結
- **突破**: 大量紅 K 突破，均線開花
- **漲幅**: 連續 3 支漲停
- **第二波**: 長紅爆量 + KD 多排，再次攻擊

### 案例 2: 頭肩底型態
- **底部**: V 型反轉 + 底部大量
- **突破**: 均線糾結後一棒三線向上
- **操作**: 沿著 5 日均線賺十幾天
- **特色**: 成功率極高，抓到後很難賠錢

### 案例 3: 碎步墊高
- **前期**: 小小漲，緩步墊高底部
- **訊號**: 低點連線向上 + 四線多排
- **變天**: 大量紅 K + KD 多排同時出現

## 🎯 技術分析 Prompt

### 基礎檢查 Prompt
```
請分析 {股票代號} 的一棒三線狀態：

**均線排列**:
1. 5日、10日、20日均線目前排列順序為何？
2. 是否形成多頭排列（5>10>20）或空頭排列？
3. 均線是否糾結（均線距離很近）？

**量價分析**:
4. 今日是否出現大量紅 K？（成交量是否明顯放大）
5. 是否為高檔爆量（成交量 > 昨日 2 倍）？

**底部判斷**:
6. 近期是否有 2 個月以上的盤整？
7. 60 日季線是向上、向下、還是轉平？
8. 股價與季線的相對位置？（站上/站下）

**操作建議**:
9. 目前是否符合一棒三線起漲條件？
10. 建議進場/觀望/出場？
```

### 進階分析 Prompt
```
請針對 {股票代號} 進行一棒三線深度分析：

**底部型態辨識**:
1. 是否符合以下底部型態？
   - 均線糾結突破
   - 頭肩底（V型反轉）
   - 碎步墊高
2. 盤整時間有多久？是否超過 2 個月？

**多頭確認**:
3. 是否符合「底底高、頭頭高」六字訣？
4. 近期高點與低點的變化趨勢？
5. 目前是第幾波？（第一波突破 or 第二波攻擊）

**KD 指標配合**:
6. KD 是否黃金交叉？位置在哪（20/50/80）？
7. KD 是否呈現多頭排列（K>D 且都向上）？

**風險檢查**:
8. 是否落入三大陷阱？
   - 已經漲三天以上（第三波高檔）
   - 高檔爆量（量 > 前一日 2 倍）
   - 季線反壓（60MA 向下且壓在股價上方）
9. 如果是第一波，是否已連續漲停 2-3 天不宜追？

**操作策略**:
10. 如果符合第二波條件（長紅+爆量+KD多排），建議進場價位？
11. 停損點設在哪？（跌破哪條均線）
12. 預期支撐在哪條均線？（5MA/10MA/20MA/60MA）
```

### 批量篩選 Prompt
```
請篩選符合一棒三線起漲條件的台股標的：

**起漲點篩選**:
- 底部盤整 2 個月以上
- 5、10、20 日均線多頭排列（5>10>20）
- 今日或近 3 日出現大量紅 K（量能明顯放大）
- KD 黃金交叉且在 20-60 之間
- 60 日季線轉平或向上（或股價已站上季線）

**第二波攻擊篩選**:
- 已有第一波上漲（底部突破）
- 符合「底底高、頭頭高」
- 近期出現長紅 + 爆量
- KD 黃金交叉在 50 附近
- 均線維持多頭排列

**排除條件**:
- 已連續上漲 3 天以上（避開第三波）
- 高檔爆量（量 > 前日 2 倍且股價已高）
- 季線反壓（60MA 向下且股價在季線下）

請提供：股票代號、名稱、盤整天數、均線排列狀態、KD 值、是第幾波
```

### 回測驗證 Prompt
```
請回測 {股票代號} 在 {起始日期} 到 {結束日期} 期間的一棒三線策略表現：

**策略規則**:
1. 買進條件:
   - 底部盤整 2 個月以上
   - 5、10、20 日均線多頭排列
   - 出現大量紅 K
   - KD 黃金交叉
   - 不在三大陷阱位置

2. 賣出條件:
   - 跌破 5 日均線（短線）
   - 或跌破 10 日均線（中線）
   - 或 KD 死亡交叉

**分析項目**:
- 總交易次數（第一波 vs 第二波）
- 勝率（分別統計第一波與第二波）
- 平均獲利/虧損
- 最大獲利（是否出現連續漲停）
- 第一波錯過後，第二波的成功率
- 三大陷阱位置的失敗案例

**型態統計**:
- 均線糾結突破的成功率
- 頭肩底型態的成功率
- 碎步墊高的成功率
- 底底高、頭頭高確認後的續漲機率

**改進建議**:
- 哪種底部型態成功率最高？
- 第二波進場的最佳 KD 位置？
- 用 5MA/10MA/20MA 哪條均線停損最好？
```

## 📚 延伸學習

### 搭配指標
- **KD 指標**: 黃金交叉確認買點（EP01）
- **成交量**: 大量紅 K vs 高檔爆量的區別
- **均線理論**: 5MA、10MA、20MA、60MA 的支撐與壓力

### 進階技巧
1. **均線糾結的判斷**: 如何量化「糾結」程度
2. **底部型態的變化**: 其他底部型態（W底、圓弧底等）
3. **波段數的判斷**: 如何確認是第幾波
4. **停損停利策略**: 不同波段的出場時機

### 投機的本質
> "做股票是投機，是把錢投在最佳機會"

- 起漲點就是最佳機會
- 不是每個位置都要做，等最好的訊號
- 用小賠（一根）賭大賺（十根）
