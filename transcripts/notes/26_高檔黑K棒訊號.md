## 📌 核心重點

### 1. 高檔黑K的重要性
- **第一時間原則**: 要在第一時間進場，也要在第一時間出場
- **高檔定義**: 連續上漲三天以上就算高檔
- **操作目標**:
  - 已有獲利 → 準備停利
  - 還沒賺錢 → 特別小心避免套牢

### 2. 三種高檔黑K組合

#### 組合一：長紅配長黑
- **特徵**: 兩根K棒長度相近，實體棒差不多
- **意義**: 昨天大漲、今天大跌，多空馬上易位
- **操作**: 明天如果開低往下就要趕快離場

#### 組合二：遭遇（一日封口）
- **特徵**: 長黑收盤與前一天紅K收盤價相近
- **意義**: 開高缺口當天就被封掉，隔日沖倒貨現象
- **操作**:
  - 當天還沒賠錢，只是沒賺到開高
  - 第二天如果跌破就要走

#### 組合三：長黑覆蓋
- **特徵**: 長黑跌破紅K收盤價
- **分類**:
  - **弱覆蓋**: 未跌破紅K的二分之一
  - **強覆蓋**: 跌破紅K的二分之一，下跌機率更高
- **操作**: 第二天只能漲不能跌，一跌就容易殺

### 3. 四殺加強訊號

當黑K組合出現時，如果再加上以下條件，下跌機率更高：

1. **爆大量**
   - 紅K爆量（第二天黑K會有次大量）
   - 黑K爆量（賣壓湧出，更危險）

2. **遇壓力**
   - 碰到前高未過
   - 碰到均線壓力（如月線）

3. **KD死叉**
   - 黑K出來時KD指標同時死亡交叉
   - 股價跌、指標也下來

4. **MACD紅柱縮短**
   - 代表多頭力道減弱
   - 轉折訊號出現

### 4. 高檔爆量的意義
- **紅K爆量**: 次日黑K通常有次大量，容易回檔
- **黑K爆量**: 賣壓全部湧出，明天下跌機率很高
- **結論**: 高檔爆量不管紅黑都容易回檔

### 5. 操作紀律
- **第一根黑K就要警覺**: 不要等到五根黑K才想賣
- **設定停損停利**:
  - 高檔黑K大量 → 高點很難再過
  - 即使第二天沒跌，要過也很難
- **不要凹單**: 不要猜測後續會不會跌，按紀律操作

## 💡 實戰案例重點

### 案例一：長紅配長黑（連漲四天後）
- **情況**: 多頭連漲四天，第四天紅K爆量，第五天黑K次大量
- **兩根K棒**: 長度相近，並列在高檔
- **結果**: 第二天開始下殺，原本獲利變成套牢
- **教訓**: 看到大量黑K要第一時間動作

### 案例二：遭遇（一日封口）
- **情況**: 多頭飆股，黑K收盤與紅K收盤剛好一樣
- **特點**:
  - 當天還沒賠錢，只是開高沒賺到
  - KD指標已死亡交叉
  - MACD紅柱縮短
- **操作**: 第二天一跌就確認要走
- **結果**: 如果不走會越套越深

### 案例三：長黑覆蓋（今日股票）
- **情況**: 多頭連漲四天，第五天覆蓋
- **特徵**:
  - 高檔連續兩天放大量
  - 黑K跌破紅K收盤但未破二分之一
- **操作**:
  - 短線做大盤不好要停利（已有十幾趴獲利）
  - 第二天不能跌，一跌就要走
- **策略**: 如果賣了又漲，等黑配紅（晨星）再進場

## 🎯 技術分析 Prompt

### 基礎檢查 Prompt
```
請分析 {股票代號} 的高檔黑K狀態：
1. 目前是否處於高檔（連續上漲三天以上）？
2. 最近是否出現長紅配長黑、遭遇、或覆蓋型態？
3. 黑K當天或前一天紅K是否爆量？
4. 是否遇到壓力（前高、均線）？
5. KD指標是否在黑K當天死叉？
6. MACD紅柱是否縮短？
7. 綜合判斷：有幾個「殺」出現？風險等級？
```

### 進階分析 Prompt
```
請針對 {股票代號} 進行高檔黑K深度分析：

**型態識別**:
1. 識別是哪一種黑K組合（長紅配長黑/遭遇/覆蓋）？
2. 如果是覆蓋，屬於弱覆蓋還是強覆蓋？
3. 黑K是否已經跌破紅K的收盤價？底部？

**四殺檢查**:
4. 爆量狀況：紅K爆量？黑K爆量？量能比較？
5. 壓力檢查：是否碰到前高、月線、季線等壓力？
6. KD狀態：是否死亡交叉？在高檔還是低檔？
7. MACD狀態：紅柱是否縮短？是否即將死叉？

**停利建議**:
8. 目前獲利幅度多少？
9. 第二天的關鍵價位是多少（不能跌破的價位）？
10. 建議停利還是觀望？停損設在哪？

**反向訊號**:
11. 如果賣出後，要看到什麼訊號才能重新進場（如晨星）？
```

### 批量篩選 Prompt
```
請篩選符合以下高檔黑K警示的台股標的：

**篩選條件**:
- 連續上漲三天以上（處於高檔）
- 最新一根K棒為黑K
- 黑K符合以下任一組合：
  1. 長紅配長黑（兩根長度相近）
  2. 遭遇（黑K收盤約等於前紅K收盤）
  3. 覆蓋（黑K跌破紅K收盤）

**加分條件（四殺）**:
- 黑K或前紅K爆量（量能為5日均量1.5倍以上）
- 股價遇壓力（接近前高或月線）
- KD指標死叉
- MACD紅柱縮短

請提供：
- 股票代號、名稱
- 黑K組合類型
- 符合幾個「殺」
- 風險等級（高/中/低）
- 建議操作（立即停利/觀察第二天/暫不處理）
```

### 回測驗證 Prompt
```
請回測 {股票代號} 在 {起始日期} 到 {結束日期} 期間的高檔黑K策略：

**策略規則**:
1. 進場：多頭上漲（不限天數）
2. 出場訊號：出現高檔黑K組合（長紅配長黑/遭遇/覆蓋）

**分級測試**:
- 情境A：只看黑K組合，立即出場
- 情境B：黑K組合+任一「殺」出現，立即出場
- 情境C：黑K組合+兩個以上「殺」出現，立即出場
- 情境D：等第二天確認才出場

**分析項目**:
- 各情境的出場次數
- 出場後股價繼續漲的次數（假訊號）
- 出場後股價下跌的次數（正確訊號）
- 平均出場後N日的跌幅
- 最佳出場時機（當天？第二天？）
- 哪些「殺」的準確度最高？

**優化建議**:
- 在什麼條件下可以不出場？
- 如何減少假訊號？
```

## 📚 延伸學習

### 高檔操作進階
- **停利策略**: 分批停利 vs. 一次停利
- **反向操作**: 高檔黑K後的晨星（黑配紅）進場時機
- **量價配合**: 如何精準判斷爆量的標準

### 相關型態
- **母子懷抱**: 前面課程已教（高檔黑K吞紅K）
- **長黑吞噬**: 前面課程已教（黑K完全吞噬紅K）
- **晨星**: 黑配紅，空翻多訊號

### 均線壓力判斷
- **月線（20MA）**: 常見壓力位置
- **季線（60MA）**: 中長期壓力
- **前高壓力**: 左側高點的重要性
