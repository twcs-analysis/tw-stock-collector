# EP15 - 切線（趨勢線）判斷多空

> **來賓**: 朱家泓老師
> **主題**: 如何用切線判斷多空與買賣點
> **原始逐字稿**: [15.txt](../raw/15.txt)

## 📌 核心重點

### 1. 什麼是切線（趨勢線）？
- **別名**: 趨勢線（Trend Line）
- **用途**: 看股價運行的方向與趨勢
- **原理**: 畫一條線就知道方向（向上/向下/水平）
- **三種趨勢**:
  - **多頭**: 上升切線（越陡越好）
  - **盤整**: 水平切線（不好操作）
  - **空頭**: 下降切線（往下跌）

### 2. 切線的四大功能
1. **預判股價多空運行的方向**: 一眼看出多頭或空頭
2. **判斷轉強、轉弱**: 切線告訴我們支撐與壓力
3. **進出操作參考**: 跌破切線（支撐）= 賣出訊號
4. **買點參考**: 回到切線邊緣沒跌破又上去 = 支撐買點

### 3. 切線 vs 均線
- **相同點**: 都能判斷趨勢與支撐/壓力
- **差異**:
  - **均線**: 代表平均成本，大部分人用（5MA、10MA、20MA）
  - **切線**: 自己畫，連接高低點，視覺化趨勢
- **建議**: 兩者可互相參考

### 4. 如何畫上升切線（多頭）

#### 基本畫法
- **取點**: 取股票的「兩個低點」（包括下影線）
- **連線**: 把兩個低點連起來
- **判斷**: 如果這條線向上，就是多頭走勢

#### 進階應用
- **原始切線**: 最早的那兩個低點連起來
- **變更切線**:
  - 當趨勢走強，股價漲得更快
  - 會出現新的低點（更高的低點）
  - 可以畫一條更陡的切線

#### 支撐作用
- **支撐**: 股價回測切線不破 = 持續多頭
- **長期支撐**: 如同一條切線支撐多次（半年、一年）
- **角度意義**:
  - 角度越陡 = 股票越強
  - 角度變平 = 股價變弱（但只要還向上，依然是多頭）

#### 跌破切線
- **意義**: 多頭上漲動能減弱
- **走勢**: 可能進入回檔修正或轉向
- **操作**: 考慮賣出或減碼

### 5. 如何畫下降切線（空頭）

#### 基本畫法
- **取點**: 連接「兩個高點」
- **判斷**: 兩個高點連起來向下 = 下降切線 = 「頭頭低」

#### 壓力作用
- **壓力**: 下降切線代表壓力
- **遇線不過**: 股價遇到這條線過不去，就會繼續跌

#### 突破切線
- **意義**: 突破最後一條下降切線 = 空頭轉強（轉向轉強）
- **操作**: 空單要小心，可能要轉為多頭

### 6. 切線的特性與應用

#### 支撐壓力轉換
- **原支撐**: 切線原本是支撐（多頭）
- **跌破後**: 變成壓力（反壓）
- **原壓力**: 切線原本是壓力（空頭）
- **突破後**: 變成支撐（止跌）

#### 長線操作特性
- **切線偏長線**: 做的是趨勢，適合長線操作
- **跌破賣出**: 跌破切線代表這一段賺完了，再走
- **不像均線**: 均線可能有黃金交叉、死亡交叉，切線單純看方向

## 💡 實戰案例重點

### 案例一: 航運股（萬海）上升切線
- **畫線**: 從原始上升切線看
- **趨勢**: 趨勢其實沒有變，一直在支撐之上
- **回檔**: 雖然有回檔，但沒跌破切線
- **操作**: 只要不跌破切線，就一直抱著
- **特性**: 切線比較偏趨勢，做的是長線

### 案例二: 長期支撐的上升切線
- **時間**: 同一條切線支撐半年甚至一年
- **測試**: 多次回測切線都不破
- **強度**: 每次在切線附近都是買點
- **跌破**: 一旦跌破，趨勢改變

### 案例三: 切線角度的變化
- **原始切線**: 一開始的緩升
- **加速**: 漲得更快，出現新的更高低點
- **新切線**: 畫更陡的切線
- **意義**: 角度越陡，股票越強
- **變平**: 角度變平代表走弱（但仍是多頭）

### 案例四: 下降切線（空頭壓力）
- **畫線**: 連接兩個高點
- **壓力**: 股價每次碰到切線就跌
- **頭頭低**: 明顯的空頭走勢
- **操作**: 遇壓力就可以空

### 案例五: 下降切線突破（轉強）
- **原本**: 下降切線壓制股價
- **突破**: 股價突破下降切線
- **意義**: 空頭轉強，可能轉多
- **操作**: 空單要注意，考慮回補

## 💡 極切線（進階技巧）

### 1. 什麼是極切線？
- **用途**: 專門用在「飆股、急漲、急跌」
- **解決問題**: 很多人買到飆股，每天賺錢卻不知道什麼時候要賣
- **特性**: 比一般切線更敏感

### 2. 極切線的應用場景
1. **飆股**: 連續大漲的股票
2. **急漲**: 末升段的噴出
3. **急跌**: V 型反轉的急跌段
4. **盤整區小波段**: 盤整中的小幅波動

### 3. 極切線的畫法（與一般切線不同）

#### 急漲時（上升極切線）
- **不連轉折點**: 不是連低點轉折
- **連 K 線低點**: 把每一根紅 K 線的低點連起來
- **賣出訊號**:
  - 當「黑 K 實體棒」收盤跌破這條極切線
  - 下影線不算，要看收盤價
  - 實體跌破 = 先獲利了結

#### 為什麼要用極切線？
- **離均線太遠**: 飆股乖離率大
- **一般切線不敏感**: 等到跌破一般切線已經跌很多
- **極切線更靈敏**: 能賣在相對高點

### 4. 極切線的效果
- **賣在高點**: 雖然趨勢可能還沒反轉
- **避開急跌**: 因為漲太快，會有急跌回檔
- **保護獲利**: 先出場保護獲利，避免坐雲霄飛車

## 🎯 技術分析 Prompt

### 基礎檢查 Prompt
```
請分析 {股票代號} 的切線（趨勢線）狀態：

**切線繪製**:
1. 請找出近期的兩個明顯低點（多頭）或高點（空頭）
2. 連接這兩點，切線是向上、向下、還是水平？
3. 切線的角度如何（陡峭/平緩/水平）？

**趨勢判斷**:
4. 目前是上升趨勢（多頭）、下降趨勢（空頭）、還是盤整？
5. 切線的支撐/壓力作用如何？
6. 股價目前在切線之上還是之下？

**操作建議**:
7. 切線價位在哪裡（支撐或壓力價）？
8. 是否接近切線（買點/賣點機會）？
9. 是否已跌破上升切線或突破下降切線（轉折訊號）？
```

### 進階分析 Prompt
```
請針對 {股票代號} 進行切線深度分析：

**上升切線分析（多頭）**:
1. 找出所有可能的上升切線（原始切線、新切線）
2. 各切線的起始日期、兩個低點價位、角度？
3. 哪一條切線目前最有效（最近被測試且有效）？
4. 切線角度變化（越來越陡 = 加速，越來越平 = 減速）？
5. 股價曾幾次測試該切線？每次測試後的走勢如何？

**下降切線分析（空頭）**:
6. 找出所有下降切線（連接高點）
7. 各切線的起始日期、兩個高點價位、角度？
8. 哪一條壓力線最強（多次測試不破）？
9. 是否有突破下降切線的跡象？

**支撐壓力轉換**:
10. 是否有切線被跌破後變成壓力？
11. 是否有切線被突破後變成支撐？
12. 支撐/壓力轉換的位置與效果如何？

**與均線配合**:
13. 切線與 5MA/10MA/20MA 的相對位置？
14. 切線與均線是否同向（都向上/都向下）？
15. 切線與均線哪個支撐/壓力更強？

**操作建議**:
16. 目前最重要的切線價位是多少？
17. 如果回測切線不破，建議買進價位？
18. 跌破/突破哪個價位代表趨勢改變？
19. 切線的有效性評分（1-10，考量測試次數、時間長度）？
```

### 極切線專用 Prompt
```
請針對 {股票代號} 繪製並分析極切線：

**適用性判斷**:
1. 目前是否處於飆股、急漲、急跌、或 V 型反轉狀態？
2. 近期是否有連續大漲或大跌（適合用極切線）？
3. 股價離均線的乖離率有多大？

**上升極切線（急漲時）**:
4. 找出連續上漲的紅 K 線
5. 連接每根紅 K 的低點（不是轉折點）
6. 目前是否已出現黑 K 實體跌破極切線？
7. 跌破時的價位與日期？

**賣出訊號**:
8. 黑 K 實體是否跌破極切線（下影線不算）？
9. 收盤價跌破極切線幾 %？
10. 建議獲利了結的價位？

**下降極切線（急跌時）**:
11. 找出連續下跌的黑 K 線
12. 連接每根黑 K 的高點
13. 是否出現紅 K 實體突破極切線（止跌訊號）？

**效益評估**:
14. 如果在極切線跌破時賣出，獲利多少 %？
15. 相比一般切線，極切線是否更早提供賣出訊號？
16. 極切線賣出後，股價後續走勢如何（驗證有效性）？
```

### 批量篩選 Prompt
```
請篩選符合以下切線條件的台股標的：

**上升切線（做多機會）**:
- 具備明確的上升切線（至少 2 個月）
- 近 5 日內股價回測切線
- 回測未跌破，出現止跌紅 K
- 切線角度 > 30 度（強勢）

**下降切線突破（轉強訊號）**:
- 先前有明確下降切線
- 近 5 日內突破下降切線
- 突破時帶量（量 > 近 20 日均量 1.5 倍）
- 突破後站穩（收盤價在切線之上）

**極切線賣出訊號**:
- 近期急漲（10 日內漲幅 > 20%）
- 出現黑 K 實體跌破上升極切線
- 乖離率 > 15%（離均線遠）

**切線角度變化**:
- 上升切線角度越來越陡（加速上漲）
- 新切線角度比舊切線陡 > 10 度

**輸出資訊**:
- 股票代號與名稱
- 切線類型（上升/下降/極切線）
- 切線價位
- 目前股價與切線距離
- 切線角度
- 操作建議（買進/賣出/觀望）

請依「接近切線」和「切線有效性」排序
```

### 回測驗證 Prompt
```
請回測 {股票代號} 在 {起始日期} 到 {結束日期} 期間的切線策略表現：

**上升切線做多策略**:
規則:
- 畫出上升切線（連接兩個低點）
- 買進: 股價回測切線不破，出現紅 K
- 賣出: 跌破切線

統計:
- 出現幾次上升切線？
- 切線平均有效天數（從畫出到跌破）？
- 回測切線不破的成功率（之後繼續上漲）？
- 跌破切線後平均下跌幅度？
- 平均報酬率（從買進到跌破）？

**下降切線突破做多策略**:
規則:
- 畫出下降切線（連接兩個高點）
- 買進: 突破下降切線
- 賣出: 跌破新的支撐或形成新的下降切線

統計:
- 下降切線被突破的次數？
- 突破後轉為多頭的成功率？
- 平均轉強後的漲幅？
- 假突破（突破後又跌回）的比例？

**極切線賣出策略**:
規則:
- 識別急漲段（10 日漲幅 > 15%）
- 畫極切線（連接紅 K 低點）
- 賣出: 黑 K 實體跌破極切線

統計:
- 急漲段出現次數？
- 極切線跌破後平均回檔幅度？
- 極切線 vs 一般切線的賣出時機差異（天數、價位）？
- 極切線賣出後，股價是否繼續下跌（驗證有效性）？

**切線角度與報酬關係**:
- 切線角度 > 45 度 vs < 30 度的報酬率差異？
- 角度越陡，是否漲幅越大但持續時間越短？
- 最佳的切線角度區間？

**切線有效性**:
- 切線被測試次數越多，是否越有效？
- 長期切線（> 3 個月）vs 短期切線（< 1 個月）的可靠度？
- 切線 + 均線同向 vs 切線 + 均線背離的表現差異？

**優化建議**:
- 如何提高切線突破/跌破的準確率？
- 是否該結合其他指標（量、均線、KD 等）？
- 切線在哪種市況下最有效（多頭/空頭/盤整）？
```

## 📚 延伸學習

### 切線的進階應用
1. **軌道線**: 上下各畫一條切線，形成通道
2. **扇形線**: 從同一點畫多條角度不同的切線
3. **甘氏線（Gann Line）**: 特定角度（45 度）的切線
4. **趨勢通道**: 平行的上下切線，股價在其中運行

### 切線與其他工具結合
- **切線 + 均線**: 雙重確認支撐/壓力
- **切線 + 形態**: N 字底突破切線、頭肩底突破切線
- **切線 + 缺口**: 跳空突破切線，力道更強
- **切線 + KD**: KD 黃金交叉 + 守住切線 = 強勢

### 不同週期的切線
- **日線切線**: 短線操作（數週到數月）
- **週線切線**: 中長線操作（數月到一年）
- **月線切線**: 長線投資（數年）
- **分鐘線極切線**: 當沖或超短線（飆股適用）

### 常見錯誤
1. **隨意畫線**: 沒有找到明確的高低點
2. **強行連線**: 為了畫線而忽略真實的轉折點
3. **過度依賴**: 只看切線不看其他指標
4. **忽略角度**: 不注意切線角度變化（轉強/轉弱）
5. **影線算數**: 一般切線可用影線，但極切線要看實體
