## 📌 核心重點

### 1. 成交量的迷思
- **爆大量 ≠ 絕對好壞**: 要看位置、趨勢、當天漲跌、隔天表現
- **買賣相等**: 每筆成交都是一買一賣，關鍵是誰比較強
- **兩派理論**:
  - **有量才有價**: 有人追買，價格才會上漲
  - **有價才有量**: 價格漲了，才會引來追隨者
  - **實務**: 兩者都會發生

### 2. 成交量的時代變化
- **以前**: 1000-2000 億算爆量
- **現在**: 平均 3700 億，4000 億才算爆量
- **原因**: 資金增加、開戶人數增加、通膨效應
- **結論**: 量是相對的，不是絕對的

### 3. 解讀成交量的四大關鍵

#### 關鍵一: 趨勢
- **多頭**: 頭頭高、底底高
- **空頭**: 頭頭低、底底低
- **重要性**: 同樣爆量，多頭與空頭意義完全不同

#### 關鍵二: 位置
- **起漲位置**: 爆量 + 價漲 = 攻擊量（好）
- **高檔位置**: 爆量 + 價不漲 = 出貨量（壞）
- **回檔支撐**: 爆量 + 價漲 = 換手量（好）
- **壓力位置**: 爆量 + 價跌 = 假突破（壞）

#### 關鍵三: 當天漲跌
- **價漲 + 爆量**: 買方力量強
- **價跌 + 爆量**: 賣方力量強
- **判斷**: 股價決定誰的力量強

#### 關鍵四: 隔天表現（最重要）
- **成交量是事後論**: 隔天才能確認
- **爆量後續漲**: 換手成功
- **爆量後續跌**: 出貨確認
- **結論**: 不要當天就下判斷

### 4. 爆量的定義
- **基本量**: 5 日均量
- **放量**: 比 5 日均量大 1.2-1.3 倍
- **爆量**: 比 5 日均量大 2 倍以上
- **101 大樓**: 突然一根量柱特別高 → 危險訊號

### 5. 量價口訣（朱老師心法）

#### 低檔爆大量，股價不跌，反彈
- **情境一**: 空頭跌到低檔，爆量 + 第二天不跌 = 反彈
- **情境二**: 多頭回檔低點，爆量 + 第二天不跌 = 上漲
- **關鍵**: 有人接刀子，第二天確認

#### 高檔爆大量，股價不漲，回檔
- **現象**: 高檔爆量但第二天不漲
- **判斷**: 出貨力量強
- **操作**: 容易回檔，應賣出

### 6. 量價四種關係

#### 價漲量增
- **盤整突破**: 可買進（好）
- **回後上漲**: 可買進（好）
- **高檔爆量**: 不創新高要賣（壞）

#### 價漲量縮（價量背離）
- **剛開始**: 可能只是反彈
- **持續**: 可能是飆股（惜售）
- **風險**: 追買力量不足，容易跌

#### 價跌量增
- **高檔**: 賣壓出籠，容易下跌
- **低檔**: 恐慌殺盤，可能反彈

#### 價跌量縮
- **上升段**: 正常回檔（賣壓不重）
- **盤整區**: 等待方向
- **初跌/主跌**: 不要猜底（無量下跌很危險）
- **末跌段**: 窒息量（5 日均量的 1/2）+ 紅 K = 可能落底

### 7. 空頭市場的量價
- **重點**: 空頭不看量，看趨勢與位置
- **原因**: 主力已賣掉，有量也會跌，沒量也會跌
- **操作**: 以趨勢為主

## 💡 實戰案例重點

### 案例 1: 盤整突破多頭確認
- **現象**: 盤整突破 + 爆量（101 大樓）
- **判斷**: 多頭確認，容易攻
- **結果**: 連續攻擊

### 案例 2: 高檔爆量回檔
- **位置**: 高檔沿 5 均
- **訊號**: 爆量黑 K
- **結果**: 容易回檔或盤整

### 案例 3: 換手成功
- **現象**: 盤整突破 + 爆量 + 第二天續攻
- **判斷**: 換手成功
- **操作**: 繼續持有

### 案例 4: 高檔爆量三倍
- **現象**: 紅 K 爆三倍量，第二天不漲收黑
- **判斷**: 出貨
- **操作**: 容易回檔，應賣出

## 🎯 技術分析 Prompt

### 基礎檢查 Prompt
```
請分析 {股票代號} 的成交量狀態：
1. 最近 5 日的平均成交量是多少？
2. 今日成交量與 5 日均量的比例？（是否放量或爆量）
3. 今日股價是上漲還是下跌？漲跌幅多少？
4. 目前股價位置（起漲/高檔/回檔/低檔）？
5. 結合以上四點，給出量價關係判斷
```

### 進階分析 Prompt
```
請針對 {股票代號} 進行成交量深度分析：

**趨勢與位置**:
1. 目前處於多頭、空頭、還是盤整？
2. 股價位置是起漲、高檔、回檔、還是低檔？

**量能分析**:
3. 近 10 日的成交量變化趨勢（增/減/平穩）
4. 是否出現爆量（2 倍以上 5 日均量）？
5. 爆量發生的位置與當天股價表現

**隔天驗證**:
6. 如果昨日爆量，今日股價是漲是跌？
7. 是否形成換手成功或出貨確認？

**量價關係分類**:
8. 屬於價漲量增、價漲量縮、價跌量增、還是價跌量縮？
9. 這個量價關係在當前位置的意義

**操作建議**:
10. 基於量價分析，給出具體操作建議
```

### 批量篩選 Prompt
```
請篩選符合以下量價條件的台股標的：

**起漲爆量篩選**:
- 價漲量增（成交量 > 5 日均量 1.3 倍）
- 股價處於起漲位置或回檔支撐
- 非高檔位置（避免追高）
- 隔天股價續漲確認

**高檔出貨警示**:
- 高檔爆量（成交量 > 5 日均量 2 倍）
- 隔天股價不漲或下跌
- 形成長上影線或黑 K

**低檔反彈機會**:
- 低檔爆量（空頭末段）
- 隔天股價不跌或紅 K
- 可能形成反彈或落底

**價量背離警示**:
- 價漲量縮（可能是飆股或轉弱）
- 高檔位置（風險較高）
```

### 回測驗證 Prompt
```
請回測 {股票代號} 在 {起始日期} 到 {結束日期} 期間的量價策略：

**策略規則**:
1. 買進: 起漲位置 + 價漲量增（放量 1.3 倍以上）
2. 賣出: 高檔爆量 + 隔天不漲

**驗證項目**:
- 低檔爆量後隔天不跌的勝率
- 高檔爆量後隔天不漲的下跌機率
- 價漲量增在不同位置的成功率
- 換手成功與出貨確認的判別準確度

**量能特徵**:
- 爆量的平均倍數（2 倍/3 倍/5 倍）
- 窒息量（5 日均量 1/2）出現後的反彈率
- 101 大樓量後的平均跌幅

**改進建議**:
- 如何提高量價判斷的準確度？
- 最佳的放量倍數閾值？
```

## 📚 延伸學習

### 與其他指標結合
- **均線**: 配合 5MA/20MA 判斷位置
- **K 線**: 長紅/長黑/上影線等型態
- **趨勢**: 頭頭高底底高的多空判斷

### 進階概念（榮耀班）
- **價量背離**: 詳細判斷與飆股應用
- **窒息量**: 精確定義與落底確認
- **主力進出**: 籌碼分析結合量價

### 注意事項
1. 成交量要配合趨勢、位置、當天漲跌、隔天表現
2. 不能只看成交量就決定進出
3. 空頭市場成交量參考價值降低
4. 爆量隔天的表現最重要（事後論）
5. 量是相對比較，不是絕對數字
