## 📌 核心重點

### 1. 支撐與壓力的定義

#### 支撐（Support）
- **定義**: 股價下跌到某個價位就跌不下去，出現反彈向上
- **形成原因**:
  1. **跌深撿便宜**: 股價跌多了，有人進場撿便宜，產生買盤
  2. **空單獲利回補**: 做空者平倉買回，產生買盤支撐
- **確認方式**: 第二天拉出紅 K 線，確認支撐有效

#### 壓力（Resistance）
- **定義**: 股價上漲到某個價位就漲不上去，開始下跌
- **形成原因**:
  1. **獲利賣壓**: 股價漲多，下面買進者開始賣出獲利
  2. **解套賣壓**: 前面高檔被套牢者，等股價回升趕快賣出解套
- **確認方式**: 第二天出現黑 K 線，確認壓力有效

### 2. 一線兩面原則
- **核心概念**: 支撐與壓力是一體兩面，可互相轉換
  - **股價在線下**: 該線為「壓力線」
  - **股價突破後**: 該線變成「支撐線」
- **實戰意義**: 壓力被突破後，回測時會變成支撐

### 3. 支撐壓力的三大關鍵位置

#### (1) 大量 K 線
- **紅 K 看低點**: 大量紅 K 的低點為支撐
- **黑 K 看高點**: 大量黑 K 的高點為壓力
- **原因**: 關鍵 K 線代表多空力量的交戰點

#### (2) 盤整區
- **盤整區低點**: 突破後成為強支撐
- **盤整區高點**: 跌破後成為強壓力
- **原因**: 盤整越久，累積的能量越大

#### (3) 切線（趨勢線）
- **上升切線**: 連接兩個低點，作為支撐線
- **下降切線**: 連接兩個高點，作為壓力線
- **原因**: 趨勢線代表股價運行的軌道

### 4. 均線的支撐與壓力作用
- **月線（20MA）**: 重要的支撐與壓力參考
- **季線**: 中期趨勢的支撐壓力
- **多條支撐重疊**: 力量更強（如月線 + 上升切線 + 盤整區低點）

## 💡 支撐壓力的四大功能

### 1. 進場依據
- **買進時機**: 股價回到支撐位（月線、前低）且撐住
- **確認方式**: 第二天拉出紅 K，確認支撐有效

### 2. 停損設定
- **停損點**: 進場時那根大量紅 K 的低點
- **原則**: 跌破支撐就要趕快停損出場

### 3. 停利目標
- **獲利空間**: 壓力位置告訴你上漲空間在哪
- **天花板越高**: 獲利空間越大

### 4. 選股策略
- **比較原則**: 兩支股票條件相同時，選「上方壓力遠」的
- **原因**: 壓力越遠，上漲空間越大

### 5. 預測多空趨勢
- **多頭市場**: 支撐不能破
  - 若跌破月線 + 上升切線 → 趨勢轉空
- **空頭市場**: 壓力不能過
  - 若突破重要壓力（如月線）→ 可能轉強打底

## 🎯 實戰操作要點

### 買賣訊號三要素
1. **確認多空趨勢**: 判斷目前是多頭、空頭還是盤整
2. **確認 20 日均線方向**: 月線向上或向下
3. **確認 K 線表態**: 第二天紅 K（支撐有效）或黑 K（壓力有效）

### 多頭操作策略
- **買點**: 股價回到支撐（月線、上升切線、盤整區低點）
- **賣點**: 股價到達壓力區（前高、下降切線）
- **停損**: 跌破支撐線

### 空頭操作策略
- **做空點**: 股價反彈到壓力（月線、下降切線）
- **回補點**: 股價跌到支撐區
- **停損**: 突破壓力線

### 支撐壓力重疊的威力
- **三重支撐**: 盤整區支撐 + 月線支撐 + 上升切線支撐
- **效果**: 力量非常強，一旦確認支撐有效，拉出長紅會噴很快

### 支撐壓力失效的意義
- **支撐跌破**:
  - 跌破月線 + 跌破上升切線 + 頭頭低 → 趨勢轉空
  - 要反過來做空
- **壓力突破**:
  - 突破月線 + 突破下降切線 + 底底高 → 趨勢轉多
  - 可以進場做多

## 🎯 技術分析 Prompt

### 基礎檢查 Prompt
```
請分析 {股票代號} 的支撐與壓力狀態：
1. 目前股價位置在哪？接近支撐還是壓力？
2. 最近的支撐位在哪？（大量 K 線低點、盤整區低點、月線、上升切線）
3. 最近的壓力位在哪？（大量 K 線高點、盤整區高點、月線、下降切線）
4. 是否有多條支撐或壓力重疊？
5. 目前建議操作方向？（買進、賣出、觀望）
```

```

**趨勢判斷**:

2. 月線（20MA）是向上還是向下？

6. 上方壓力距離目前股價多遠？（獲利空間評估）
```

```
請篩選符合以下支撐壓力條件的台股標的：

**多頭買進訊號篩選**:

- 有多重支撐重疊（至少兩條以上）
- 股價在支撐位止跌，第二天拉出紅 K
- 上方壓力距離遠（至少 10% 以上空間）

- 下方支撐距離遠

**趨勢轉換訊號**:
- 跌破重要支撐（月線 + 上升切線）→ 轉空

請提供股票代號、名稱、目前價位、支撐/壓力位置、距離百分比
```

## 📚 延伸學習

### 與其他技術分析結合
- **均線系統**: 5MA、10MA、20MA、季線的支撐壓力作用
- **趨勢判斷**: 頭頭高底底高（多頭）、頭頭低底底低（空頭）
- **量價關係**: 大量 K 線的支撐壓力意義
- **盤整突破**: 橫盤整理後的支撐壓力轉換

### 進階概念
1. **支撐壓力互換**: 壓力突破後變支撐，支撐跌破後變壓力
2. **多重支撐/壓力**: 越多條重疊，力量越強
3. **心理關卡**: 整數關卡（如 100 元、200 元）的支撐壓力
4. **缺口理論**: 跳空缺口也是支撐壓力的一種

### 注意事項
1. **第二天確認**: 支撐壓力要看第二天 K 線才算表態
2. **不是絕對**: 沒有 100% 有效的支撐壓力，要設停損
3. **趨勢優先**: 支撐壓力要配合趨勢判斷使用
4. **量價配合**: 要搭配成交量確認多空力道
