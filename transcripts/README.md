## 🎯 技術分析 Prompt 使用說明

每份筆記都包含 **4 種技術分析 Prompt**，可直接用於 AI 分析：

### 1. 基礎檢查 Prompt
快速檢視股票的技術狀態（適合日常檢查）

### 2. 進階分析 Prompt
深度分析含趨勢、型態、風險評估（適合研究個股）

### 3. 批量篩選 Prompt
從多支股票中篩選符合條件的標的（適合選股）

### 4. 回測驗證 Prompt
驗證技術策略的歷史績效（適合策略開發）

## 💡 使用建議

### 學習路徑建議
1. **第一週**: 看完初學者必讀 5 集，建立基礎概念
2. **第二週**: 進階學習 5 集，熟悉買賣訊號
3. **第三週**: 高手進修 5 集，掌握型態學
4. **第四週**: 實戰練習，每天使用技術分析 Prompt

### 實戰應用
1. **每日功課**: 參考 [EP08](notes/8.md) 建立操作流程
2. **選股**: 使用各集的「批量篩選 Prompt」
3. **進場前**: 使用 [EP29](notes/29.md) 的「進場前六問」
4. **持股判斷**: 結合 KD、MACD、均線綜合分析

### 搭配資料分析
本專案已收集完整的台股歷史資料（[data/](../data/) 目錄），可結合：
- 價格資料（開高低收、成交量）
- 三大法人買賣超
- 融資融券餘額
- 借券賣出資料

使用技術分析 Prompt 搭配真實資料，驗證各種技術指標與型態的有效性。
