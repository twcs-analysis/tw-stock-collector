# 教學影片逐字稿整理

此目錄用於存放技術分析教學影片的逐字稿與重點整理。

## 目錄結構

```
transcripts/
├── README.md           # 本文件
├── raw/                # 原始逐字稿 (1.txt ~ 29.txt)
└── notes/              # 每集重點整理 (1.md ~ 29.md)
```

## 使用說明

### raw/ - 原始逐字稿
- 存放從影片產生的原始逐字稿
- 檔名格式: `1.txt`, `2.txt`, ..., `29.txt`
- 保持原始內容不修改

### notes/ - 重點整理
- 從逐字稿整理出的重點筆記
- 檔名格式: `1.md`, `2.md`, ..., `29.md`
- 使用 Markdown 格式，包含：
  - 章節主題
  - 關鍵概念
  - 技術指標說明
  - 實戰應用案例
  - 個股範例（如有）

## 未來擴展

可新增 `indicators/` 目錄，整合多集內容，按技術指標分類：
- `MA.md` - 移動平均線
- `MACD.md` - MACD 指標
- `RSI.md` - RSI 指標
- `KD.md` - KD 指標
