# 理財達人秀自動整理

自動抓取理財達人秀最新一集，轉換為逐字稿並產生重點摘要。

## 功能

1. 自動抓取理財達人秀 YouTube 頻道最新影片
2. 使用 whisper-cpp 轉換為中文逐字稿
3. AI 分析逐字稿，產生結構化重點摘要

## 使用方式

```bash
/yt-finance-show
```

或在對話中：

```
請執行 yt-finance-show skill
```

## 執行流程

1. **抓取最新影片**
   - 從 YouTube 頻道 `@EBCmoneyshow` 抓取最新影片
   - 取得影片標題、網址和發布日期

2. **轉換逐字稿**
   - 使用 `scripts/media-tools/video_to_transcript.sh`
   - 下載影音並轉換為 mp3
   - 使用 whisper-cpp 轉換為中文逐字稿
   - 儲存到 `data/transcripts/{日期}/`

3. **AI 分析摘要**
   - 讀取逐字稿
   - 分析市場觀點、產業趨勢、個股建議
   - 產生結構化的 Markdown 報告
   - 儲存到 `data/transcripts/{日期}/{檔名}_analysis.md`

## 輸出內容

分析報告包含：

- 節目基本資訊（日期、來賓、主題）
- 市場總體觀察（台股、美股）
- 產業分析與投資建議（含個股）
- 前瞻技術深度解析
- 投資策略總結
- 來賓金句整理
- 名詞解釋

## 依賴

- yt-dlp（影音下載）
- whisper-cpp（語音轉文字）
- Python 3.11+

## 注意事項

- 首次執行需下載 Whisper 模型（約 140 MB）
- 影片轉換時間取決於影片長度（約 1 小時影片需 5-10 分鐘）
- 確保網路連線穩定
