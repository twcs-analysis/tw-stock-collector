# 理財達人秀自動整理 - 執行指令

當使用者呼叫此 skill 時，按照以下步驟執行：

## 執行步驟

### 1. 抓取最新影片

使用 yt-dlp 查詢 YouTube 頻道最新影片：

```bash
yt-dlp --flat-playlist --print "%(id)s|%(title)s|%(upload_date)s" "https://www.youtube.com/@EBCmoneyshow/videos" 2>/dev/null | head -1
```

解析輸出格式：`影片ID|標題|日期`

### 2. 轉換為逐字稿

使用專案的轉換腳本：

```bash
python3.11 scripts/media-tools/video_to_transcript.py "https://www.youtube.com/watch?v={影片ID}" --output "finance_show_{日期}" --model base
```

- 自動下載影音為 mp3
- 使用 whisper-cpp 轉換為中文逐字稿
- 儲存到 `data/transcripts/{當天日期}/finance_show_{日期}.txt`

### 3. AI 分析逐字稿

讀取逐字稿檔案，進行深度分析並產生報告：

#### 分析重點

1. **節目基本資訊**
   - 播出日期
   - 來賓名單
   - 主題標題

2. **市場總體觀察**
   - 台股走勢分析
   - 美股影響評估
   - 市場氛圍判斷

3. **產業分析與投資建議**
   - 各產業趨勢分析
   - 個股推薦與理由
   - 技術面/基本面評估
   - 進出場時機建議

4. **前瞻技術深度解析**
   - 新興技術說明（如：低軌衛星、鈣鈦礦等）
   - 產業應用場景
   - 台廠供應鏈機會
   - 投資價值評估

5. **投資策略總結**
   - 短期策略（1-3個月）
   - 中期策略（3-6個月）
   - 風險評估
   - 布局時機

6. **來賓金句整理**
   - 重要觀點摘錄
   - 投資建議精華

7. **名詞解釋**
   - 專業術語說明
   - 技術概念解釋

#### 輸出格式

產生 Markdown 格式報告，儲存到：
```
data/transcripts/{當天日期}/finance_show_{日期}_analysis.md
```

## 錯誤處理

- 如果 yt-dlp 抓取失敗，回報錯誤訊息
- 如果轉換失敗，檢查 whisper-cpp 是否安裝
- 如果逐字稿為空，通知使用者重新執行
- 保留中間產物以便除錯

## 注意事項

- 使用 Python 3.11 執行腳本
- 確保 yt-dlp 和 whisper-cpp 已安裝
- 轉換時間較長，建議使用背景執行
- 分析時要深入解讀技術細節，不只是摘要
