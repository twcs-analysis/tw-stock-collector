# 錢線百分百自動整理

自動抓取錢線百分百最新三集（上、中、下），轉換為逐字稿並產生重點摘要。

## 功能

1. 自動抓取錢線百分百 YouTube 頻道最新三集影片（上、中、下集）
2. 使用 whisper-cpp 轉換為中文逐字稿
3. AI 分析逐字稿，產生結構化重點摘要

## 使用方式

```bash
/yt-moneyline
```

或在對話中：

```
請執行 yt-moneyline skill
```

## 執行流程

1. **抓取最新三集影片**
   - 從 YouTube 頻道 `@TVBSMONEYGO` 抓取最新三集影片（上、中、下）
   - 取得影片標題、網址和發布日期
   - 自動識別同一天的上中下集

2. **轉換逐字稿**（針對三集分別執行）
   - 使用 `scripts/media-tools/video_to_transcript.sh`
   - 下載影音並轉換為 mp3
   - 使用 whisper-cpp 轉換為中文逐字稿
   - 儲存到 `data/transcripts/yt-moneyline/{日期}/`

3. **AI 分析摘要**（針對三集分別執行）
   - 讀取逐字稿
   - 分析市場觀點、產業趨勢、個股建議
   - 產生結構化的 Markdown 報告
   - 儲存到 `data/transcripts/yt-moneyline/{日期}/{檔名}_analysis.md`

4. **整合摘要**
   - 將三集的重點整合為每日總覽
   - 產生 `daily_summary.md`

## 輸出內容

### 個別分析報告（三集各自產生）

- 節目基本資訊（日期、來賓、主題）
- 市場總體觀察（台股、美股、國際市場）
- 產業分析與投資建議（含個股）
- 技術面分析與操作策略
- 投資策略總結
- 來賓金句整理
- 名詞解釋

### 每日整合摘要

- 三集重點統整
- 最重要的投資建議
- 關鍵個股清單
- 風險提示

## 依賴

- yt-dlp（影音下載）
- whisper-cpp（語音轉文字）
- Python 3.11+

## 注意事項

- 首次執行需下載 Whisper 模型（約 140 MB）
- 三集影片轉換時間較長（總計約 15-30 分鐘）
- 確保網路連線穩定
- 建議使用 cron 自動化執行（每日 22:00 後）
