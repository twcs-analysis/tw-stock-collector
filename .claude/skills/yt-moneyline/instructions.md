# 錢線百分百自動整理 - 執行指令

當使用者呼叫此 skill 時，按照以下步驟執行：

## 執行步驟

### 1. 抓取最新三集影片（上、中、下）

使用 yt-dlp 搜尋 YouTube 最新影片：

```bash
yt-dlp "ytsearch15:錢線百分百 完整版" --flat-playlist --print "%(id)s|%(title)s|%(upload_date)s" 2>/dev/null
```

**說明**：使用搜尋方式而非頻道 URL，因為：
- 錢線百分百在多個頻道上架（錢線百分百官方頻道、USTV 非凡電視）
- 搜尋方式更穩定，不受頻道變更影響

#### 識別上中下集

從輸出中識別同一天的三集影片：
- 標題包含「完整版（上）」或「上集」
- 標題包含「完整版（中）」或「中集」
- 標題包含「完整版（下）」或「下集」
- 三集的 `upload_date` 應該相同

解析輸出格式：`影片ID|標題|日期`

**重要**：如果找不到完整的三集（上中下），也可以處理已上傳的集數（例如只有上集或上中兩集）。

### 2. 轉換為逐字稿（三集分別執行）

針對每一集，使用專案的轉換腳本：

```bash
# 上集
python3.11 scripts/media-tools/video_to_transcript.py "https://www.youtube.com/watch?v={影片ID1}" --output "moneyline_{日期}_part1" --model base

# 中集
python3.11 scripts/media-tools/video_to_transcript.py "https://www.youtube.com/watch?v={影片ID2}" --output "moneyline_{日期}_part2" --model base

# 下集
python3.11 scripts/media-tools/video_to_transcript.py "https://www.youtube.com/watch?v={影片ID3}" --output "moneyline_{日期}_part3" --model base
```

- 自動下載影音為 mp3
- 使用 whisper-cpp 轉換為中文逐字稿
- 儲存到 `data/transcripts/yt-moneyline/{當天日期}/moneyline_{日期}_part{1,2,3}.txt`

**注意**：三集轉換建議依序執行，避免同時執行造成系統負載過高。

### 3. AI 分析逐字稿（三集分別執行）

讀取每一集的逐字稿檔案，進行深度分析並產生報告：

#### 分析重點

1. **節目基本資訊**
   - 播出日期
   - 集數（上/中/下）
   - 來賓名單
   - 主題標題

2. **市場總體觀察**
   - 台股走勢分析
   - 美股影響評估
   - 國際市場動態
   - 市場氛圍判斷

3. **產業分析與投資建議**
   - 各產業趨勢分析
   - 個股推薦與理由
   - 技術面/基本面評估
   - 進出場時機建議
   - 目標價與停損點

4. **技術面分析與操作策略**
   - 技術指標解讀（KD、MACD、均線等）
   - 關鍵支撐壓力位
   - 操作建議（突破、反彈、防守）
   - 風險管理

5. **投資策略總結**
   - 短期策略（1-2週）
   - 中期策略（1-3個月）
   - 風險評估
   - 布局時機

6. **來賓金句整理**
   - 重要觀點摘錄
   - 投資建議精華

7. **名詞解釋**
   - 專業術語說明
   - 技術概念解釋

#### 輸出格式

針對每一集，產生 Markdown 格式報告，儲存到：

## 錯誤處理

- 如果 yt-dlp 抓取失敗，回報錯誤訊息
- 如果找不到完整三集，處理已有的集數並提示使用者
- 如果轉換失敗，檢查 whisper-cpp 是否安裝
- 如果逐字稿為空，通知使用者重新執行
- 保留中間產物以便除錯

## 注意事項

- 使用 Python 3.11 執行腳本
- 確保 yt-dlp 和 whisper-cpp 已安裝
- 轉換時間較長（三集約 15-30 分鐘），建議使用背景執行
- 分析時要深入解讀技術細節，不只是摘要
- 整合摘要時要去重，避免重複相同的觀點
- 個股推薦要包含具體的目標價與停損點
